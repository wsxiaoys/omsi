# Gemini API: changelog (Nano Banana entries)

- Origin: Google, "Gemini API changelog", https://ai.google.dev/gemini-api/docs/changelog
- Evidence kind: official documentation (release notes / changelog)
- Publication date: rolling; entries captured down to the October 6, 2026 release
- Capture date: 2026-10-26
- Relevant models: `gemini-nano-banana-2.1`, `gemini-3.1-flash-image` (Nano Banana 2),
  `gemini-3-pro-image` (Nano Banana Pro), `gemini-3.1-flash-lite-image` (Nano Banana 2 Lite)

## Captured content

### October 6, 2026 (verbatim, abridged)

> **Gemini Nano Banana 2.1 generally available (GA)**: Released Gemini Nano Banana 2.1
> (`gemini-nano-banana-2.1`), the latest high-efficiency image generation and conversational
> editing model. An update to Nano Banana 2 (`gemini-3.1-flash-image`), it maintains Flash-level
> speed and cost efficiency while delivering significant improvements in visual quality, prompt
> adherence, multi-turn character consistency, text rendering, and wide and panoramic aspect
> ratio generation (1:4, 4:1, 1:8, 8:1) across 1K, 2K, and 4K resolutions.

> **Deprecation announcement**: The `gemini-3.1-flash-image` model is deprecated (no shutdown
> date announced). Migrate to `gemini-nano-banana-2.1`.

### Earlier image-model entries (verbatim, abridged)

- May 28, 2026: "Released `gemini-3.1-flash-image` (Nano Banana 2) and `gemini-3-pro-image` (Nano
  Banana Pro), the generally available (GA) versions of our native visual models". Same entry
  announces video-to-image generation, "supported exclusively on the `gemini-3.1-flash-image`
  model".
- February 26, 2026: "Launched Nano Banana 2, Gemini 3.1 Flash Image Preview, a high-efficiency
  model optimized for speed and high-volume use cases."
- November 20, 2025: "Released Gemini 3 Pro Image Preview, `gemini-3-pro-image-preview`, the next
  iteration to the Nano Banana model."

## What this establishes

- **Launch date: 2026-10-06**, as a GA release. It was not preceded by a public 2.1 preview
  entry in this changelog, so 2.1 went straight to GA.
- 2.1 is inside the one-year window (cutoff 2025-10-26) with about 11.5 months to spare.
- 2.1 supersedes Nano Banana 2 at the API level: Google deprecates `gemini-3.1-flash-image` and
  names 2.1 as the migration target in the same entry.

## Known gaps

- The entry is a changelog line, not an announcement post; no blog post, benchmark table, or
  marketing page for 2.1 was found at the usual Google URLs during capture.
- The changelog gives no pricing change, no parameter changes, and no statement about whether
  the underlying weights changed versus a serving update. The model card's "based on Gemini 3.6
  Flash" is the only statement about what 2.1 is built from.

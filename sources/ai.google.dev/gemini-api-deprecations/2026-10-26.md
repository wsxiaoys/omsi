# Gemini API: deprecations

- Origin: Google, "Deprecations | Gemini API", https://ai.google.dev/gemini-api/docs/deprecations
- Evidence kind: official documentation (support-window / lifecycle table)
- Publication date: rolling; capture taken 2026-10-26
- Capture date: 2026-10-26
- Relevant models: `gemini-nano-banana-2.1` and the rest of the Nano Banana table

## Captured content

## What this establishes

- An independent confirmation of the **2026-10-06 release date** for `gemini-nano-banana-2.1`,
  from a page whose purpose is lifecycle tracking rather than announcement.
- 2.1 is a **stable, generally available** model with no announced shutdown date. There is no
  preview row for 2.1 at all, so no preview-to-GA date pair to reconcile.
- `gemini-3.1-flash-image` (Nano Banana 2) is deprecated with 2.1 as its named replacement. Both
  are still listed as obtainable ("no shutdown date announced"), so a reader can still call
  either at capture time.

## Known gaps

- "No shutdown date announced" is not a support commitment; it only means none was published.
- The table does not say whether a deprecated model receives fixes, or whether traffic is
  silently rerouted. The changelog elsewhere describes silent rerouting for some text models
  (e.g. `gemini-3.5-flash` → `gemini-3.6-flash`), so rerouting is a real possibility for
  `gemini-3.1-flash-image` too, but it is not stated for this model.

# Gemini API: pricing

- Origin: Google, "Pricing | Gemini API",
  https://ai.google.dev/gemini-api/docs/pricing
- Evidence kind: official documentation (first-party price list)
- Publication date: not stated on the page body; the capture is the live page on the capture date
- Capture date: 2026-10-26
- Relevant model: `gemini-nano-banana-2.1` (Nano Banana 2.1) section of the image-generation
  pricing block

## Captured content

### Nano Banana 2.1 section (verbatim)

> Gemini Nano Banana 2.1 🍌 — `gemini-nano-banana-2.1`
>
> An update to Nano Banana 2 (Gemini 3.1 Flash Image), built for high-efficiency image generation
> and conversational editing with improved visual quality, multi-turn character consistency,
> accurate text rendering, and search-grounded generation across 1K, 2K, and 4K resolutions.

Standard tier (the page's two rows, input and output, split here by output type so the image rate is
visible):

| Line item | Free tier | Paid tier, per 1M tokens (USD) |
| --- | --- | --- |
| Input price | Not available | $1.50 (text/image/video) |
| Output price | Not available | $7.50 (text and thinking) |
| Output price | Not available | $30.00 (images) |

Verbatim footnote:

> Image output is priced at $30 per 1,000,000 tokens (Standard) and $15 per 1,000,000 tokens
> (Batch). Output images at 1K (1024x1024px) consume **1120 tokens** and are equivalent to
> **$0.0336 per image**. Output images at 2K (2048x2048px) consume **1680 tokens** and are
> equivalent to **$0.0504 per image**. Output images at 4K (4096x4096px) consume **3780 tokens**
> and are equivalent to **$0.113 per image**.

Batch tier: $0.75 input, $3.75 text/thinking output, $15.00 image output per 1M tokens;
"Equivalent to $0.0168 per 1K image, $0.0252 per 2K image, and $0.0567 per 4K image".

Grounding:

> Grounding with Google Web and Image Search — Not available [free tier] — 5,000 free search
> requests per month (shared across all Gemini 3 and newer models), then $14 per 1,000 requests
> for text and image-based grounding.

> Retrieved context (text or images) provided by Grounding with Google Search is not charged as
> input tokens.

Data use: "Used to improve our products: Yes [free tier], No [paid tier]".

## What this establishes

- Paid tier only: the Free tier column reads "Not available" for every 2.1 line item.
- Per-image equivalents of $0.0336 (1K), $0.0504 (2K), $0.113 (4K), derived from $30/1M image
  tokens.
- Grounding is billed per search request after a shared 5,000/month allowance, not per token.

## Contradictions with other first-party pages

- **4K image token count.** This page says a 4096x4096 4K image consumes **3780** tokens. The
  image-generation guide's "Nano Banana 2.1" token table says a 4K image consumes **2520** tokens
  for every aspect ratio. Both are Google pages read the same day. fal's cost table follows the
  3780 figure. Unresolved; treat per-image 4K cost as approximate.

## Known gaps

- No page-level publication or update timestamp in the captured text, so this is an undated
  price list. Prices can change without a visible date; re-capture before quoting.
- No statement of what a "search request" is, or whether a single generation can trigger several.

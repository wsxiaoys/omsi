# Alibaba Cloud Model Studio: HappyHorse image-to-video (first frame) API reference

- Capture date: 2026-10-26
- Relevant models: `happyhorse-1.1-i2v`, `happyhorse-1.0-i2v`

## Scope (verbatim)

> Generate realistic, smooth-motion videos from a first-frame image and an optional text prompt using
> the HappyHorse model.

> Image-to-video tasks take 1–5 minutes.

## Input constraints (verbatim)

> **prompt** `string` (optional) — Describes the video content to generate. Supports any language.
> Maximum: 5,000 non-Chinese characters or 2,500 Chinese characters. Longer input is truncated.

> **media** `array` (required) — The input image array. […] `type` `string` (required) — The type of
> media. Allowed value: `first_frame`: The first frame. Exactly one first-frame image is required.

> Image constraints: Formats: JPEG, JPG, PNG, WEBP. Resolution: Width and height must both be at
> least 300 pixels. Aspect ratio: Between 1:2.5 and 2.5:1. File size: Up to 20 MB.

Both a public URL and a Base64 data URI are accepted.

## Output parameters (verbatim)

> **resolution** `string` (optional) — The resolution of the generated video. Output pixel count
> approximates the selected tier while preserving the input image's aspect ratio. Allowed values:
> `480P`, `720P`, `1080P` (Default).

> **duration** `integer` (optional) — The duration of the generated video, in seconds. The value must
> be an integer in the range [3, 15]. Default: 5.

> **watermark** `boolean` (optional) — Adds a "Happy Horse" text watermark to the bottom-right corner.
> `true` (Default), `false`.

> **seed** `integer` (Optional) — […] range [0, 2147483647]. […] the same seed does not guarantee
> identical results.

There is **no** `ratio` parameter on this endpoint:

> Output aspect ratio matches the first frame. Unlike the HappyHorse text-to-video model,
> image-to-video does not support the ratio parameter.

## Billing fields in the response (verbatim)

> `input_video_duration` `integer` — The duration of the input video, in seconds.
>
> `output_video_duration` `integer` — The duration of the output video, in seconds.
>
> `duration` `integer` — The total video duration used for billing.

The sample response shows `"input_video_duration": 0`, `"output_video_duration": 5`.

## Notes

- Only a **first frame** is accepted. There is no last-frame, first-and-last-frame, or video-extension
  task on HappyHorse; those are Wan 3.0 features per the video-generation guide.
- The watermark string here is "Happy Horse" (with a space); the text-to-video reference renders it
  "HappyHorse". Same feature, inconsistent spelling in the vendor docs.
- No audio parameter and no lip-sync statement on this page.

## Gaps

- No stated maximum output pixel dimensions for each tier (only "approximates the selected tier").
- No guidance on how the model handles images whose aspect ratio differs sharply from 16:9.

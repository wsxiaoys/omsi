# Alibaba Cloud Model Studio: HappyHorse text-to-video API reference

- Origin: Alibaba Cloud Model Studio API reference, "HappyHorse text-to-video API reference",
  <https://www.alibabacloud.com/help/en/model-studio/happyhorse-text-to-video-api-reference>
- Evidence kind: official vendor documentation (first-party API reference)
- Publication date: page header "Last Updated: Oct 12, 2026"
- Capture date: 2026-10-26
- Relevant models: `happyhorse-1.1-t2v`, `happyhorse-1.0-t2v`

## Scope (verbatim)

> Generate physically realistic, motion-smooth video from text prompts with the HappyHorse model.

Invocation is asynchronous DashScope: `POST
https://{WorkspaceId}.{region}.maas.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis`
with `X-DashScope-Async: enable`, then `GET /api/v1/tasks/{task_id}`. Endpoints are listed for
Singapore, US (Virginia), China (Beijing), Germany (Frankfurt) and Japan (Tokyo).

> Text-to-video tasks typically take 1 to 5 minutes.

> The `task_id` is valid for 24 hours. […] After a task succeeds, a video URL valid for 24 hours is
> returned.

## Request parameters (verbatim, abridged)

> **model** `string` **(Required)** — The model name. […] Example: `happyhorse-1.1-t2v`.

> **prompt** `string` **(Required)** — Text description of the video to generate. Supports any
> language. Maximum 5,000 non-Chinese characters or 2,500 Chinese characters. Excess is truncated.

> **resolution** `string` (Optional) — Output video resolution. Valid values: `480P`, `720P`,
> `1080P` (default).

> **ratio** `string` (Optional) — Output video aspect ratio. Valid values: `16:9` (default), `9:16`,
> `1:1`, `4:3`, `3:4`, `4:5`, `5:4`, `9:21`, `21:9`.

> **duration** `integer` (Optional) — Output video duration in seconds. `happyhorse-1.0-t2v`: 3–15.
> Default: 5.

> **watermark** `boolean` (Optional) — Whether to add a watermark. Displays "HappyHorse" in the
> lower-right corner. `true` (default), `false`.

> **seed** `integer` (Optional) — The random number seed must be an integer in the range
> [0, 2147483647]. […] Because model generation is probabilistic, the same seed does not guarantee
> identical results.

## Response `usage` block (verbatim)

> `duration` integer — Total video duration for billing.
>
> `SR` integer — Output video resolution.
>
> `ratio` string — Output video aspect ratio.
>
> `video_count` integer — Number of output videos. Always 1.

The sample response shows `"SR": 720` and `"video_count": 1`.

## Notes on the documentation itself

- The `duration` line names only `happyhorse-1.0-t2v` even though the page's own sample request uses
  `happyhorse-1.1-t2v` and the sibling guide table gives 3–15 s for 1.1. The 3–15 s range is
  consistent across pages; the model-ID scoping of that sentence is not.
- No audio parameter exists on this endpoint: audio is not switchable, and the docs do not mention
  lip-sync, audio sample rate or language coverage.
- The page never states a frame rate or container; 24 fps / MP4 comes from the video-generation
  guide, not from this reference.

## Gaps

- No per-model parameter differences between 1.0 and 1.1 are documented beyond the resolution tiers
  implied by the guide (1.1 adds 480P).
- No rate limits, concurrency caps, or content-policy text on this page.

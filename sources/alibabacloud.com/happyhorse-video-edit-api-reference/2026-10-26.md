# Alibaba Cloud Model Studio: HappyHorse video editing API reference (1.0 only)

- Origin: Alibaba Cloud Model Studio API reference, "HappyHorse video editing API reference",
  <https://www.alibabacloud.com/help/en/model-studio/happyhorse-video-edit-api-reference>
- Evidence kind: official vendor documentation (first-party API reference)
- Publication date: page header "Last Updated: Oct 13, 2026"
- Capture date: 2026-10-26
- Relevant models: `happyhorse-1.0-video-edit` (the vendor exposes **no** 1.1 editing model)

## Scope (verbatim)

> The HappyHorse video editing model takes a video and a reference image as input, and performs
> editing tasks such as style transfer and local replacement based on text instructions.

> Video editing tasks are time-consuming (typically 1–5 minutes), so the API uses asynchronous calls.

## Input constraints (verbatim)

> The array must contain exactly 1 video element and can optionally contain 0–5 reference_image
> elements.

> **Video requirements:** Format: MP4, MOV (H.264 encoding recommended). Duration: 3–60 seconds.
> Resolution: the longer side must not exceed 4,096 px; the shorter side must be at least 360 px.
> Aspect ratio: 1:2.5–2.5:1. File size: up to 100 MB. Frame rate: 8-60 fps.

> **Output video duration: 3–15 seconds.** If the input video is 15 seconds or shorter, the output
> video has the same duration as the input. If the input video is longer than 15 seconds, the system
> automatically uses only the first 15 seconds, so the maximum output duration is 15 seconds.

> **Image requirements:** Format: JPEG, JPG, PNG, WEBP. Resolution: both width and height must be at
> least 300 px. Aspect ratio: 1:2.5–2.5:1. File size: up to 20 MB.

## Output parameters (verbatim)

> **resolution** `string` (Optional) — Valid values: `1080P` (default), `720P`.

> **watermark** `boolean` (Optional) — […] the text "Happy Horse". Defaults to true.

> **audio_setting** `string` (Optional) — Audio control. `auto` (default): Determined by the model.
> `origin`: Preserves the original audio from the input video.

## Billing fields in the response (verbatim)

> `duration` `float` — Total video duration of the generated video, used for billing.
>
> `input_video_duration` `float` — Duration of the input video, in seconds.
>
> `output_video_duration` `float` — Duration of the output video, in seconds.

## Notes

- Editing is a **1.0-only** capability. The 1.1 line ships text-, image- and reference-to-video only,
  and the vendor's own guide still recommends `happyhorse-1.0-video-edit` for editing, so the editing
  model is a retained 1.0 specialist rather than a superseded one.
- Both input and output seconds are billed (see the pricing record).
- `audio_setting` has only `auto` and `origin`: there is no way to generate new audio or mute it.

## Gaps

- No statement about whether editing preserves faces, text overlays, or camera motion; fal's copy
  claims motion preservation, the vendor does not.
- No documented multi-clip or extension workflow.

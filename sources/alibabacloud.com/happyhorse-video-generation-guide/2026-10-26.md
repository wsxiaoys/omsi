# Alibaba Cloud Model Studio: "Video generation and editing" — HappyHorse capability and output table

- Origin: Alibaba Cloud Model Studio documentation, "Video generation and editing",
  <https://www.alibabacloud.com/help/en/model-studio/video-generation>
- Evidence kind: official vendor documentation (first-party model-selection guide and spec table)
- Publication date: page header "Last Updated: Oct 11, 2026"
- Capture date: 2026-10-26
- Relevant models: `happyhorse-1.1-t2v`, `happyhorse-1.1-i2v`, `happyhorse-1.1-r2v`,
  `happyhorse-1.0-*`, plus the Wan 3.0 / Wan 2.7 siblings used for comparison

## Where the vendor places HappyHorse 1.1 (verbatim)

> Text-to-video
>
> Generate videos with audio from text prompts. We recommend `happyhorse-1.1-t2v`. It supports 1080P
> resolution and clips up to 15 seconds long.

> First-frame image-to-video
>
> Generate video from a single image. We recommend `happyhorse-1.1-i2v`, which supports audio, 1080P,
> and 3 to 15 seconds.

> Reference image-to-video
>
> Maintain character consistency across scenes using reference images. We recommend
> `happyhorse-1.1-r2v`. For the Wan series, use `wan3.0-video` (speed-optimized: `wan3.0-video-prime`),
> which supports all-in-one reference capabilities with multiple reference images, videos, and audio.
> It also supports file input (docx, ppt, pdf, etc.) and web links as references.

> Video editing
>
> Edit existing videos using text instructions for style transfer, element replacement, and other
> operations. We recommend `happyhorse-1.0-video-edit`.

The migration table ("Map your current Sora, Veo, Kling, or Runway model to an equivalent Bailian
model") maps "Text-to-video (t2v), Image-to-video (i2v)" from "Sora 2, Veo 3.1, Kling 3.0" to
`happyhorse-1.1-t2v`, `happyhorse-1.1-i2v`, `wan3.0-video`, `wan3.0-video-prime`, and maps
"Reference-to-video (r2v)" to `happyhorse-1.1-r2v`, `wan3.0-video`, `wan3.0-video-prime`.

## Summary

- The vendor documents HappyHorse 1.1 as **three separate model IDs**, each with a single task, and
  reserves the editing task for the 1.0 line (`happyhorse-1.0-video-edit`).
- Documented output envelope for 1.1: 480P/720P/1080P, 3–15 s, **24 fps**, MP4, with audio. 1.1 adds
  the 480P tier over 1.0's 720P/1080P.
- The "Features" column says "Audio" for every HappyHorse model but, unlike Wan 3.0, lists no audio
  toggle, no smart duration and no adaptive aspect ratio — HappyHorse is positioned as the
  prompt-to-clip model and Wan 3.0 as the controllable one.
- "Generate videos with audio from text prompts" is the only audio claim the vendor makes here; the
  word "lip-sync" does not appear on this page.

## Gaps

- No statement of model size, architecture, training data, or weights availability.
- No frame-rate or audio sample-rate specification beyond "24 fps, MP4".
- No statement about whether 1.0 remains supported after 1.1; 1.0 is still listed and priced.

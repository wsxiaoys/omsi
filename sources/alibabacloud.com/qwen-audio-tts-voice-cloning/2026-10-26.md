# Alibaba Cloud Model Studio: voice cloning guide — reference-audio contract, model binding, quota, billing

- Origin: Alibaba Cloud Model Studio, "Voice cloning",
  <https://www.alibabacloud.com/help/en/model-studio/voice-cloning-user-guide>
- Evidence kind: provider documentation (input requirements, regional model support, quota, billing
  rule)
- Publication date: page "Last Updated" 2026-10-21
- Capture date: 2026-10-26
- Relevant models: `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`, `qwen-audio-3.0-tts-plus`,
  `qwen-audio-3.0-tts-flash`, `qwen-audio-3.1-realtime-plus`; CosyVoice as the parallel route

## Binding (verbatim)

> Cloned voices for Qwen-Audio-TTS / Qwen-Audio-Realtime / CosyVoice are bound to their target_model
> at creation and cannot be used with another model. To use the same reference voice with multiple
> models, create a separate voice for each model.

The guide's worked examples set `target_model = "qwen-audio-3.1-tts-plus"`, so cloning for this model
is a documented, first-class path.

## Reference-audio requirements (verbatim)

| Item | Requirement |
| --- | --- |
| Formats | WAV (16-bit), MP3, M4A |
| Duration | "10–20 seconds recommended; no more than 60 seconds." |
| File size | ≤ 10 MB |
| Sample rate | ≥ 16 kHz |
| Channels | Mono or stereo; "Only the first channel of stereo audio is processed" |
| Content | "At least 5 seconds of continuous, clear reading, with only short pauses (≤ 2 seconds) elsewhere. Avoid background music, environmental noise, and other speakers. Use speech at a normal pace, rather than songs or singing recordings." |

Supported reference-audio languages, verbatim: Chinese (Mandarin, Cantonese, Chongqing, Northeastern,
Gansu, Guizhou, Zhejiang, Hebei, Henan, Hubei, Hunan, Jiangxi, Ningbo, Ningxia, Qingdao, Shaanxi,
Shanxi, Shandong, Shanghai, Sichuan, and Yunnan dialects), English, Japanese, Korean, Russian, French,
German, Portuguese, Thai, Indonesian, Vietnamese, Spanish, Italian, Malaysian, Filipino, and Arabic.

Recording tips include "Do not include sensitive content (such as political, pornographic, or violent
material). This will cause cloning to fail."

## Regional support (verbatim)

| Region | Qwen-Audio-TTS models that accept cloning |
| --- | --- |
| China (Beijing) | `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`, `qwen-audio-3.0-tts-plus`, `qwen-audio-3.0-tts-flash` |
| Singapore | `qwen-audio-3.1-tts-plus`, `qwen-audio-3.0-tts-plus`, `qwen-audio-3.0-tts-flash` |

`qwen-audio-3.1-tts-flash` is absent from the Singapore cloning list even though the speech-synthesis
overview lists it in Singapore and credits it with voice cloning. The Plus model is listed in both
regions.

## Quota and billing (verbatim)

> Each Alibaba Cloud Model Studio account can have up to 1,000 custom voices in total. Voice cloning
> and voice design share this account quota across models.

> Qwen-Audio-TTS / Qwen-Audio-Realtime / CosyVoice: Voice creation is free. Speech synthesis and
> real-time conversations using cloned voices are billed according to the target model.

Created voices persist: "Created voices remain valid by default." Voices can be listed, inspected,
re-recorded (`update`) and deleted; deletion frees quota.

## Summary

Cloning for `qwen-audio-3.1-tts-plus` is documented with a concrete reference-audio contract (10–20 s
recommended, ≤ 60 s, ≤ 10 MB, ≥ 16 kHz, WAV/MP3/M4A), free voice creation, a 1,000-voice
account-wide cap shared with voice design, and a per-model binding that forbids reusing one clone
across the Plus and Flash tiers.

## Gaps

- Nothing states how many reference clips a clone may combine, or how long a cloned voice's synthesis
  output may be.
- The consent requirement is one sentence about "sensitive content"; there is no speaker-consent
  attestation, no impersonation policy and no takedown process in this guide.
- Why 3.1 Flash is missing from the Singapore cloning table is unexplained.
- No measured cloning fidelity, speaker-similarity score or failure rate is published.

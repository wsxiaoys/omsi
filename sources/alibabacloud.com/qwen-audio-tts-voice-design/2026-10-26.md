# Alibaba Cloud Model Studio: voice design guide — prompt limits, preview text, supported models

- Origin: Alibaba Cloud Model Studio, "Voice design",
  <https://www.alibabacloud.com/help/en/model-studio/voice-design-user-guide>
- Evidence kind: provider documentation (input constraints, model support, quota)
- Publication date: page "Last Updated" 2026-10-21
- Capture date: 2026-10-26
- Relevant models: `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`, `qwen-audio-3.0-tts-plus`,
  `qwen-audio-3.0-tts-flash`; CosyVoice as the parallel route

## What it does (verbatim)

> Create custom voices from natural language descriptions, preview them, and use them for speech
> synthesis.

> Voice design is suited for rapid prototyping, creative content production, and game character
> voiceovers.

Qwen-Audio-TTS and CosyVoice "share the same voice creation, preview, and basic synthesis workflow";
the worked examples use `qwen-audio-3.1-tts-flash` and pass `target_model`.

## Documented limits (verbatim)

> Number of voices: Each Alibaba Cloud Model Studio account can have up to 1,000 custom voices. Voice
> cloning and voice design share this account-wide quota across models.

> Voice description: `voice_prompt` supports Chinese and English only, with a maximum length of 500
> characters.

> Preview text: `preview_text` supports Chinese and English only and must be 15–200 characters long.

> The generated voice can synthesize speech in multiple languages. The supported languages depend on
> the target speech synthesis model.

## Supported models (verbatim)

Qwen-Audio-TTS: `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`, `qwen-audio-3.0-tts-plus`,
`qwen-audio-3.0-tts-flash`.

The page's example descriptions are short character briefs ("Cute child's voice, approximately an
8-year-old girl, slightly childish speech, suited for animation character voiceover") plus a
characteristics table mapping voice traits to use cases (news broadcast, advertising, audiobook,
animation character, voice assistant, documentary narration).

## Summary

Voice design on `qwen-audio-3.1-tts-plus` is documented as available, free, and capped by a 500-
character Chinese/English prompt, a 15–200-character preview text, and the shared 1,000-voice account
quota. The design prompt language (Chinese/English) is narrower than the synthesis language list,
because the designed voice can then speak whatever the target model supports.

## Gaps

- No prompt-engineering guidance beyond examples; no statement of how description length or
  specificity affects output.
- No per-model difference is documented, even though the speech-synthesis overview says designed
  voices output "Chinese (Mandarin), English" only — a narrower claim than this page's "multiple
  languages … depend on the target model".
- No consent or impersonation rule for designing a voice that resembles a real person.

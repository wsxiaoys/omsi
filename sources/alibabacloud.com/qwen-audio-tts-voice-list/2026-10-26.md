# Alibaba Cloud Model Studio: Qwen-Audio-TTS voice list — four voices for 3.1-plus, 68 for 3.1-flash

- Origin: Alibaba Cloud Model Studio, "Qwen-Audio-TTS voice list",
  <https://www.alibabacloud.com/help/en/model-studio/qwen-audio-tts-voice-list>
- Evidence kind: provider documentation (system-voice catalogue with per-voice feature flags)
- Publication date: page "Last Updated" 2026-10-27
- Capture date: 2026-10-26
- Relevant models: `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`, `qwen-audio-3.0-tts-plus`,
  `qwen-audio-3.0-tts-flash`

## Binding rule (verbatim)

> The selected voice (voice) must be supported by the model (model). Do not use voices from another
> model. An unsupported voice returns an InvalidParameter error, such as `[cosyvoice:]Engine error
> [411]: TTS speak operation failed`.

> The input text (text) must use a language supported by the voice. Otherwise, pronunciation errors
> or unnatural speech may occur.

The page is organised as one section per model ID, so the voices listed under a heading are that
model's supported system voices.

## `qwen-audio-3.1-tts-flash` — 68 entries in four blocks

Note, verbatim: "Multilingual and dialect voices and premium English voices are available in Beijing
and Singapore. All other voice categories are available only in Beijing."

| Block | Count | Language scope |
| --- | --- | --- |
| Multilingual and dialect voices | 4 | "All four voices below support all of the following dialects and languages": Shanghainese, Cantonese, Northeastern, Chongqing, Shaanxi, Yunnan, Ningbo, Gansu; Japanese, Korean, French, German, Portuguese, Italian, Vietnamese, Indonesian |
| Premium Chinese voices | 22 | "These voices support Mandarin Chinese only." |
| Premium English voices | 17 | "These voices support English only." (British/American accents) |
| Additional system voices | 25 | per-voice use cases: social companionship, children's companionship, character voice, customer service |

Every 3.1-flash entry carries the same three flags: SSML supported, instruction control supported,
timestamps supported.

## `qwen-audio-3.0-tts-plus` / `qwen-audio-3.0-tts-flash`

Two and five named voices respectively, with `voice parameter` strings (`longanlingxin`,
`longanlufeng`, `longanfengyue`, …) rather than `_v3.1` IDs. The page also documents **base voices**:
"qwen-audio-3.0-tts-plus and qwen-audio-3.0-tts-flash each provide over 500 base voices generated
through voice cloning … named `qwen-audio-3.0-tts-{plus|flash}-{voice suffix}`". No base-voice list is
published for either 3.1 model.

## Summary

The strongest single piece of evidence that 3.1 Plus is a separate tier rather than a rename: on the
same page, under separate headings, the Plus model exposes **four** system voices and the Flash model
**68**, and the Plus voices are labelled "Flagship" with no dialect coverage stated. A Plus user who
wants a dialect or a non-Chinese/English system voice has no listed option and must clone or design
one.

## Gaps

- No per-voice language table for the four Plus voices; the family language matrix says only
  "such as Chinese and English … varies by model and voice".
- No audio previews were retrieved; voice character is documented only by name.
- Whether the four Plus voices are also usable on `qwen-audio-3.1-tts-flash` (they are listed there in
  the multilingual block under the same IDs) is asserted only by the duplicate listing — the binding
  rule says cross-model use fails, so the same ID appearing under two headings is a contradiction
  between the page's structure and its own rule.

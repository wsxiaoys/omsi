## Scope (verbatim)

> The Qwen Image Generation and Editing model supports both text-to-image (T2I) and
> image-to-image/image editing (I2I). It can generate images directly from text prompts or edit
> images based on reference images combined with editing instructions. Supports both the
> OpenAI-compatible and DashScope protocols.

## Request parameters (OpenAI-compatible mode, verbatim excerpts)

> **model**`string`**(Required)** — The model name. Available values: `qwen-image-3.0-pro`,
> `qwen-image-3.0`, `qwen-image-2.1-pro`, and `qwen-image-2.1-turbo`.

> **prompt**`string`**(Required)** — The positive prompt that describes the image content, style,
> and composition you want to generate or edit. Both Chinese and English are supported.
> Recommended maximum: 4,500 tokens. Cannot be an empty string.

> **image**`string`**or**`array` (Optional) — The URL or Base64 encoded data of the input image.
> Omit this parameter for text-to-image (T2I). Provide it for image-to-image (I2I), where the
> qwen-image-2.1 series supports 1-10 images, and the qwen-image-3.0 series supports 1-3 images.
> […] `null` and empty arrays are rejected with a 400 error.
>
> Image requirements: JPG, JPEG, PNG, BMP, TIFF, WEBP, and GIF. The width and height must be
> between 1 and 8000 pixels; exceeding this returns a 400 error. For best results, use 384 to 2048
> pixels. Aspect ratio of the longer side to the shorter side must not exceed 10:1. Up to 10 MB.

> **n**`integer` (Optional) — The number of output images. Value range: 1 to 6. Default: 1. Must be
> an integer. A string value such as `"1"` returns a 400 error.

> **size**`string` (Optional) — The output image resolution in the format `widthxheight`, for
> example `"1024x1024"`. You can also pass `auto`. […] T2I: pixel area from 512x512 to
> 2048x2048. Aspect ratio: 1:8 to 8:1. I2I: pixel area from 512x512 to 2048x2048. Aspect ratio:
> 1:8 to 8:1.

> **negative_prompt**`string` (Optional) — The negative prompt that describes content you do not
> want to appear in the image. Only the qwen-image-3.0 series supports this parameter.

> **seed**`integer` (Optional) — The random seed. Value range: `[0, 2147483647]`. If omitted, the
> service generates a random seed. Use a fixed seed for reproducible results.

> **prompt_extend**`boolean` (Optional) — Whether to enable intelligent prompt rewriting. Default:
> `true` (recommended). When enabled, the model optimizes the positive prompt using the method
> specified by `prompt_extend_mode`, which significantly improves results for simple descriptions.

> **prompt_extend_mode**`string` (Optional) — The prompt rewriting method. Default: `direct`.
> `direct`: Direct Prompt Enhancement (DPE), suitable for most scenarios. Supported for both T2I
> and I2I. `agent`: Agent Prompt Enhancement (APE), provides more refined rewriting. Only supports
> text-to-image (T2I). Passing `agent` for image-to-image (I2I) will return a 400 error.

> **enable_thinking**`boolean` (Optional) — Enables thinking mode. The default is `true`. This
> enhances model reasoning to improve image quality, but increases generation time. It requires
> `prompt_extend=true`. Supported for Direct T2I, Direct I2I, and Agent T2I. Not supported for I2I
> Agent.

> **watermark**`boolean` (Optional) — Whether to add a watermark. Default: `false`.

Model Studio extension fields note (verbatim):

> `image`, `negative_prompt`, `seed`, `prompt_extend`, `prompt_extend_mode`, `enable_thinking`, and
> `watermark` are Model Studio extension fields, not official OpenAI parameters.

## Availability and endpoints (verbatim excerpts)

> The model, endpoint URL, and API key must belong to the same region. Cross-region calls fail.

> Alibaba Cloud Model Studio has released workspace-specific domains for the China (Beijing) and
> Singapore regions. […] China (Beijing): from `https://dashscope.aliyuncs.com` to
> `https://{WorkspaceId}.cn-beijing.maas.aliyuncs.com`; Singapore: from
> `https://dashscope-intl.aliyuncs.com` to `https://{WorkspaceId}.ap-southeast-1.maas.aliyuncs.com`.

The sample code in the topic targets the **Singapore** region.

## What this establishes

- Qwen Image 3 has **one model ID per tier serving both generation and editing** — there is no
  separate `-edit` model ID, unlike the 2.1 generation.
- Documented hard limits: prompt ~4,500 tokens (recommended maximum), output 512×512–2048×2048
  with 1:8–8:1 aspect ratio, 1–6 images per request, 1–3 reference images, inputs ≤10 MB and
  ≤8000 px per side.
- `negative_prompt` is a 3.0-series-only parameter; the 2.1 series does not accept it.
- Thinking mode is on by default and cannot be combined with the `agent` rewrite mode on I2I.
- Image-to-image and text-to-image share the same parameter surface, so the host wrappers that
  split them into two endpoints are a hosting convenience, not a model-level distinction.

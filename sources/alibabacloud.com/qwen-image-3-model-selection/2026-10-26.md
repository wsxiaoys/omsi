## Qwen Image 3 positioning (verbatim)

Text-to-image section:

> We recommend `qwen-image-3.0-pro`, which excels at generating complex layouts such as
> newspapers, storyboards, menus, and exam papers, accurately rendering small text down to 10
> pixels, supporting multilingual fonts and photographic-level detail. It also supports negative
> prompts to exclude unwanted elements, can output up to 6 variant images per call, and supports
> resolutions up to 2048×2048.

Image editing section:

> Start with`qwen-image-3.0-pro`— it supports negative prompts, up to 6 outputs per call, and uses
> the same model ID for generation and editing. It accepts one to three input images, so you can
> fuse multiple references.

## When the vendor says not to use it (verbatim)

> ### When to use wan2.7-image-pro
> - You need resolution above 2K — up to 4096×4096
> - You need precise brand color control
> - You need up to 12 character-consistent images per call in sequential mode

> ### When to use z-image-turbo
> - For image generation only (no editing functionality).
> - Speed or cost is a priority: 10x faster generation at about one-fifth the cost.
> - For photorealistic portraits and product photos.

Editing-specific guidance for `wan2.7-image-pro`:

> - You need more references — up to 9 input images
> - You need bounding-box interactive editing
> - You need character-consistent multi-image sets

## What this establishes

- The vendor positions `qwen-image-3.0-pro` as its **default recommendation** for both
  text-to-image and editing, and the family as one model ID serving both tasks.
- `qwen-image-3.0` is described only as "a faster version"; the page gives no quality delta.
- Qwen Image 3 is capped at 2K and 3 reference images, while Wan 2.7 image reaches 4K and 9
  references — the vendor itself points 4K, brand-colour, and many-reference work elsewhere.
- No mention of transparency/alpha output for the 3.0 series; the API reference attributes
  automatic transparent-channel output to the 2.1 series only.

## Gaps

- No latency numbers, no benchmark numbers, no per-language or per-font accuracy claims beyond
  "clearly legible".
- The page does not say what "photographic-level detail" or "10 pixels" were measured on.
- This is a selection page, not a model card; architecture, parameter count, and training data are
  absent.

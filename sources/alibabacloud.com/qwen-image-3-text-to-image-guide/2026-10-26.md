## Model selection as stated in this guide (verbatim)

> - **qwen-image-3.0-pro**: Flagship quality. Supports intelligent prompt rewriting and excels at
>   rendering text that blends naturally with physical materials in both Chinese and English.
> - **qwen-image-2.1-pro**: Best balance of speed, quality, and cost. Supports up to 10 reference
>   images for image-to-image tasks and can automatically output images with transparent channels
>   based on the prompt.
> - **qwen-image-2.1-turbo**: Best cost-effectiveness. The most cost-efficient model in the
>   Qwen-Image series. Supports up to 10 reference images for image-to-image tasks and can
>   automatically output images with transparent channels based on the prompt.

Only `qwen-image-3.0-pro` is listed as a headline option here; `qwen-image-3.0` is not in this
three-item list even though it appears in the model-selection table on the other page.

## Negative prompts (verbatim)

> The `negative_prompt` parameter is not supported by wan2.7-image-pro, wan2.7-image, and
> qwen-image-2.1 series. To exclude unwanted elements, describe them in the prompt (for example,
> "do not include xxx").

## Prompt rewriting (verbatim)

> Parameter: `parameters.prompt_extend` (Boolean, **defaults to true**). This feature automatically
> expands and optimizes **short prompts** to improve image quality. Enabling this feature adds 3 to
> 5 seconds to the generation time, as a large model is used to rewrite the prompt.

> Parameter: `parameters.prompt_extend_mode` (string, optional, defaults to `direct`). Supported by
> the qwen-image-3.0 and qwen-image-2.1 series. […] `direct`: Direct Prompt Enhancement (DPE),
> suitable for most scenarios. […] `agent`: Agent Prompt Enhancement (APE), provides more refined
> rewriting. Only supported for text-to-image (T2I). Passing `agent` for image-to-image/editing
> (I2I) returns a 400 error.

## Resolution (verbatim)

> **qwen-image-3.0 series, qwen-image-2.1 series**: 512*512 to 2048*2048, aspect ratio 1:8 to 8:1.
> If not specified, the model auto-recommends a resolution.

Recommended 2K resolutions for the qwen-image-3.0 series (verbatim table rows):

| Aspect ratio | 2K (qwen-image-3.0 series) |
| --- | --- |
| 1:1 | 2048*2048 |
| 16:9 | 2688*1536 |
| 9:16 | 1536*2688 |
| 4:3 | 2368*1728 |
| 3:4 | 1728*2368 |

Note that the 16:9 row is 2688*1536 = 4.13 MP, i.e. larger in pixel count than the 2048*2048
"2K" square in the same column and **2688 px wide**, so "2K" here is a resolution class rather than
a per-dimension cap. This is the only reading consistent with the API reference's total-pixel
range (512*512 to 2048*2048); a 2048-px-per-dimension reading would contradict this table.

## Output count, seed, watermark (verbatim)

> Parameter: `parameters.n` (integer, optional, **default: 1**). The number of output images. The
> qwen-image-3.0 and qwen-image-2.1 series support 1 to 6 images […] The value of n directly
> affects cost: cost = unit price x number of successfully generated images.

> Parameter: `parameters.seed` (integer, optional, range: `[0, 2147483647]`). Random seed. If not
> provided, the service selects one randomly. Using the same seed produces relatively stable
> results.

> Parameter: `parameters.watermark` (bool, optional, **default: false**). Whether to add a
> watermark. The watermark appears in the bottom-right corner of the image and reads "AI-generated".

## Operational constraints (verbatim)

> **Persist results**: The API's image URLs are valid for 24 hours.

> **Content moderation**: All `prompt` and `negative_prompt` inputs are subject to content
> moderation. If the input is non-compliant, the request is blocked and a `DataInspectionFailed`
> error is returned.

> You are charged only for **successfully generated images**. Failed requests and processing errors
> do not incur charges or consume the free quota for new users.

## What this establishes

- Prompt rewriting (an LLM rewrite pass) is **on by default** and costs 3–5 seconds of latency;
  reproducibility therefore depends on turning it off, and even then the docs only promise
  "relatively stable" results from a fixed seed.
- Output URLs expire after 24 hours, so any pipeline must copy results to its own storage.
- Inputs (prompt and negative prompt) are moderated server-side; a blocked request returns
  `DataInspectionFailed`.
- The "2K" label is not a pixel cap: 16:9 output is 2688×1536.

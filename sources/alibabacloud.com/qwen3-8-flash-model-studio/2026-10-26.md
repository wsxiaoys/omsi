## There is no `qwen3.8-flash-next` model page

`/help/en/model-studio/qwen3-8-flash-next` returns a 3 KB page whose body is
`404 阿里云错误页` — Alibaba's error page. Model Studio exposes **only** `qwen3.8-flash`.
The `qwen3.8-flash` page itself never uses the string "Flash-Next".

## Rate limits (verbatim)

  tiered by your monthly Model Studio spend".
- Hong Kong, Frankfurt, Tokyo, US (Global): 30,000 RPM / 5,000,000 TPM.
- US scope: 15,000 RPM / 2,500,000 TPM.

The tier guide lists `qwen3.8-flash` under 1M-token-context models alongside
`qwen3.8-max` and `qwen3.7-plus`, and contains no mention of Flash-Next.

## What this establishes

- The production SKU's full capability, context and price surface, on seven regional
  price tables.
- That Alibaba's own API does not sell an artifact named Flash-Next; the name is the
  open-weights name only.
- That the 1M context and built-in tools the blog attributes to the production version are
  real and documented, at a 991,808-token max input.

## Gaps

- No statement of the post-training difference between `qwen3.8-flash` and the
  Flash-Next weights.
- No snapshot list on this page (unlike `qwen3.8-max`), so the serving checkpoint date is
  undocumented here.
- Region tabs are flattened in this extract; the per-region capability table above was
  reconstructed from the tab order, which the capture cannot verify independently.

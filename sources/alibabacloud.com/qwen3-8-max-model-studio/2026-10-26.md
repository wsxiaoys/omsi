## Snapshot: `qwen3.8-max-0902` (verbatim)

> Qwen3.8-Max-0902 (alias qwen3.8-max-2026-09-02) is an upgraded snapshot of qwen3.8-max.
> Coding capability breaks new ground, handling more complex engineering-scale projects
> and long-horizon autonomous development. Collaborative agent performance is significantly
> enhanced, with greater composure in multi-tool orchestration and end-to-end task delivery.
> Native vision understanding is refined across chart reasoning, document parsing, and
> multimodal perception — sharper and more reliable. Retains the 1M context window,
> thinking mode, and full tool ecosystem, evolving at a higher level of intelligence.

The snapshot repeats the same capability table, the same context limits, and the same
international price list ($2 input / $6 output; $0.25 implicit cache; $2.5 cache creation;
$0.17 cache read). Its static-region rate limit is 30,000 RPM / **150,000 TPM**, an order of
magnitude below the base model's 5,000,000 TPM.

**The base `qwen3.8-max` is described as a separate model that the 0902 snapshot upgrades**,
not as an alias of 0902. The page does not say which weights `qwen3.8-max` serves as of the
capture date, and it does not give a release date for either entry.

## Where Model Studio places this model

> We recommend `qwen3.7-plus` for balanced performance and cost, with full tool calling and
> a 1M-token context window for large codebases. For the strongest reasoning, choose
> `qwen3.8-max`.

> For non-coding office tasks such as document drafting, email composition, meeting note
> summarization, and data analytics, start with `qwen3.7-plus` … For the strongest

> import it into the knowledge base, or process it in segments.

## Thinking mode and tools (verbatim)

> Step-by-step reasoning for multi-step math, code debugging, architecture planning, and
> legal cross-referencing. Enable with the `enable_thinking` parameter, or use
> `reasoning`.`effort` in the Responses API to control thinking depth. All Qwen3+ models
> support this feature, most of which operate in a hybrid mode togglable per request.

> *   Function calling (custom tools that the model calls): Supported by all general-purpose
>     models.
> *   Built-in tools (web search, code interpreter, web scraping) with no configuration
>     required.

## Sibling and predecessor context

`qwen3.7-max` appears under **"Legacy models"** — "The following models are legacy and no
longer recommended" — with the snapshot list `qwen3.7-max-preview`,
`qwen3.7-max-2026-06-08`, `qwen3.7-max-2026-05-20`, `qwen3.7-max-2026-05-17`, all at 1M
context. The Qwen3.8 generation is therefore the current flagship line, and `qwen3.8-max`
sits at its top tier with `qwen3.8-flash` below it.

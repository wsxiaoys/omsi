- Capture date: 2026-10-26
- Relevant models: `qwen-audio-3.1-tts-plus`, `qwen-audio-3.1-tts-flash`, `qwen-audio-3.0-tts-plus`,
  `qwen-audio-3.0-tts-flash`, `cosyvoice-*`

## SSML support (verbatim)

> Supported models: qwen-audio-3.1-tts-plus, qwen-audio-3.1-tts-flash, qwen-audio-3.0-tts-flash,
> qwen-audio-3.0-tts-plus, cosyvoice-v3.5-flash, cosyvoice-v3.5-plus, cosyvoice-v3-flash,
> cosyvoice-v3-plus, cosyvoice-v2

> Voices: Only cloned voices and system voices marked as supporting SSML in the Qwen-Audio-TTS voice
> list or CosyVoice voice list are supported.

> APIs: Java SDK (version 2.20.3 or later): non-streaming and unidirectional streaming calls; Python
> SDK (version 1.23.4 or later): non-streaming and unidirectional streaming calls; WebSocket API: set
> the `enable_ssml` parameter to true, and send a single `continue-task` event

All four 3.1-plus system voices are flagged SSML-supported in the voice list, so the voice condition
is satisfied for every voice the model ships.

## LaTeX support (verbatim)

> Supported models: cosyvoice-v3.5-plus, cosyvoice-v3.5-flash, cosyvoice-v3-plus, cosyvoice-v3-flash,
> cosyvoice-v2
> Language: Chinese only.

## Tags

The page documents `<break>` (total pause capped at 10 s when stacked), pinyin for Chinese and CMU
phonetics for English, number/digit reading rules, and background-music/sound-effect tags. It does not
state which of these tags each model honours beyond the voice-level SSML flag.

## Contradiction recorded, not resolved

The speech-synthesis overview lists "Mathematical formula reading | Express formulas in LaTeX" as a
general synthesis control, and the Qwen3-TTS page in this corpus inherited that claim for the
Qwen-Audio-TTS line. This page restricts LaTeX to CosyVoice models only, so the overview's control
list overstates what `qwen-audio-3.1-tts-plus` can do.

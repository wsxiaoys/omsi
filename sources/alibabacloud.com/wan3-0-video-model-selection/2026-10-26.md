## Wan 3.0 in the "All models" specification table (verbatim)

| Model ID | Type | Features | Output specs |
| --- | --- | --- | --- |
| `wan3.0-video` | All-in-One reference | Text-to-video, first/last-frame, all-in-one reference, audio, audio toggle, smart duration, adaptive aspect ratio | 480P, 720P, 1080P. 2-30s. 30 fps, MP4 |
| `wan3.0-video-prime` | All-in-One reference (speed-optimized) | Text-to-video, first/last-frame, all-in-one reference, audio, audio toggle, smart duration, adaptive aspect ratio | 480P, 720P, 1080P. 2-30s. 30 fps, MP4 |

The `Features` cells are word-for-word identical; the only textual difference in the whole table is
"(speed-optimized)" appended to Prime's `Type`.

This is the single best first-party source for the operational envelope, because it states duration,
resolution, frame rate and container in one row: **2–30 s, 480P/720P/1080P, 30 fps, MP4** for both.

## Recommendation text (verbatim)

> For longer videos (up to 30s), adaptive aspect ratio, smart duration, audio toggle, and reference
> audio, use wan3.0-video. It supports 480P, 720P, and 1080P resolutions. The speed-optimized version
> wan3.0-video-prime significantly improves generation speed while maintaining high quality.

> For the Wan series, use wan3.0-video (speed-optimized: wan3.0-video-prime), which supports
> first-frame and first/last-frame image-to-video.

> For the Wan series, use wan3.0-video (speed-optimized: wan3.0-video-prime), which supports all-in-one
> reference capabilities with multiple reference images, videos, and audio. It also supports file
> input (docx, ppt, pdf, etc.) and web links as references.

The parenthetical "(speed-optimized: wan3.0-video-prime)" is how Alibaba names Prime when recommending
a model: not as an alternative product, but as a mode of the same recommendation.

## Sibling models named on the same page

`happyhorse-1.1-t2v`, `happyhorse-1.1-i2v`, `happyhorse-1.1-r2v` are recommended ahead of Wan for
short clips: "We recommend happyhorse-1.1-t2v. It supports 1080P resolution and clips up to 15 seconds
long." Wan 3.0 is the recommendation when longer (up to 30 s) or reference-heavy work is needed.
`wan2.7-videoedit` covers editing and camera replication; `wan2.2-animate-move` / `-mix` cover character
animation.

## Gaps

- "Speed-optimized" is never quantified on this page either.
- The page does not say whether Prime is a different checkpoint, a distilled variant, or the same
  weights behind a faster serving configuration. "Speed-optimized" and "the accelerated version" are
  consistent with either reading.

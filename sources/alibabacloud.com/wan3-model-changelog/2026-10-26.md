## Release rows (verbatim)

Singapore table (deployment scope column reads "International"):

> Video generation · 2026-08-06 · International · `wan3.0-video`
> Wan3.0 is an all-in-one video generation model that uniformly supports multiple creative functions
> including reference, editing, replication, and driving. It supports four-modal all-reference input,
> up to 30 seconds of video generation, and can parse files, web pages, and complex images. With
> production-grade character consistency and realistic audio and visuals, it delivers an immersive
> audio-visual impact.

> Video generation · 2026-08-20 · International · `wan3.0-video-prime`
> Wan3.0-Video-Prime is the high-speed version of the Wan3.0 video generation model, with capabilities
> aligned with the Wan3.0-Video standard version. It supports four-modal all-reference input and can
> generate videos up to 30 seconds long, delivering an immersive audio-visual experience with
> significantly improved end-to-end speed.

The "Global" table (US, Japan, Germany, Hong Kong and the global-scope rows) repeats both entries with
the same dates — 2026-08-06 for `wan3.0-video` and 2026-08-20 for `wan3.0-video-prime` — and the same
descriptions, with the deployment scope column reading "Global".

## What the dates establish

- **2026-08-06** — `wan3.0-video` listed as released. This is the earliest first-party release date
  found for any Wan 3.0 ID, and it is inside the roster's one-year window (after 2025-10-26).
- **2026-08-20** — `wan3.0-video-prime` listed as released, 14 days later.
- Neither row is labelled preview, beta, or limited availability in the changelog. The API reference's
  "Currently in preview" sentence (captured separately) is the only preview statement in the corpus.

## Context rows in the same changelog (Wan 2.x lineage)

The Wan 2.x family is listed earlier and with its own IDs, for example `wan2.7-t2v`,
`wan2.7-t2v-2026-06-12`, `wan2.6-t2v`, `wan2.5-t2v-preview`. The 3.0 IDs do not carry a dated suffix
and are not presented as a snapshot of a 2.x ID: the changelog treats Wan 3.0 as a new model line with
new names.

## Summary

First-party release dates: `wan3.0-video` 2026-08-06, `wan3.0-video-prime` 2026-08-20. Both are
described as released models, in two regional tables, with no preview or deprecation label. The vendor's
own one-line framing of the pair is "standard version" vs "high-speed version … with capabilities
aligned".

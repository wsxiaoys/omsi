# Alibaba Cloud Model Studio: Wan3.0 Video Generation guide

- Origin: Alibaba Cloud Model Studio user guide, "Wan3.0 Video Generation",
  https://www.alibabacloud.com/help/en/model-studio/wan3-video-generation-guide
- Evidence kind: official vendor documentation (usage guide: task routing, task-specific parameter
  recommendations, feature notes)
- Publication date: "Last Updated: Oct 11, 2026"
- Capture date: 2026-10-26
- Relevant models: `wan3.0-video`, `wan3.0-video-prime`

## Opening summary (verbatim)

> The wan3.0 series is an All-in-One video generation model with comprehensive upgrades in audio-video
> generation, multi-modal reference, and video editing capabilities. It supports up to 30 seconds per
> generation, 30fps output frame rate, natively outputs dialogue, BGM, and sound effects, supports up
> to 20 multi-modal reference materials (images, videos, audio, documents, web pages) per request, and
> supports first frame/first-last frame control, video editing and extension.

> wan3.0-video / wan3.0-video-prime is an All-in-One model that covers all the following task types
> without switching model names. The model automatically routes based on the type field in
> input.media and the prompt intent.

The guide treats the pair as one product throughout: no sample uses `wan3.0-video-prime`, no section
separates them, and the only place either name appears together is the routing sentence above.

## Task routing

| Task | Trigger | Notes (verbatim) |
| --- | --- | --- |
| Text-to-video | prompt only, no `media` | "Supports free setting of resolution, aspect ratio, and duration" |
| First frame to video | `first_frame` | "ratio recommended as adaptive, model auto-matches first frame aspect ratio" |
| First and last frame to video | `first_frame` + `last_frame` | same ratio recommendation |
| Image reference | `reference_image` | "Up to 10 images, each ≤20MB" |
| Video reference | `reference_video` | "Up to 5 clips, total duration ≤15 seconds, each file ≤100MB" |
| Audio reference | `reference_audio` | "Up to 5 clips, total duration ≤15 seconds, each file ≤15MB" |
| Combined reference | any mix of the three reference types | image+video, image+audio, video+audio, image+video+audio |
| File / web page to video | `file` or `link`, one of the two | "Documents and web links only support publicly accessible pages that do not require login" |
| Video editing | `reference_video` (+ image/audio) + editing-intent prompt | "duration recommended as -1 (auto-preserves original video aspect ratio and duration)" |
| Video extension | `reference_video` (+ image/audio) + extension-intent prompt | "Extend forward/backward/both directions" |

## Feature notes (verbatim)

> Natively supports up to 30-second multi-shot narratives with auto-generated synchronized dialogue,
> BGM, and sound effects.

> Supports single-shot and multi-shot storyboard format (4~6 seconds per shot, with timestamp
> annotations).

> Audio-video: Natively generates voice dialogue, ambient sound effects, and background music without
> post-production dubbing.

> Smart duration: When duration is set to -1, the model automatically recommends an appropriate
> duration.

> Parameter configuration: resolution=480P/720P/1080P (default), ratio=21:9/16:9/4:3/1:1/3:4/9:16,
> duration=2~30 seconds or -1 (smart duration).

The "4~6 seconds per shot" figure is the only per-shot duration the vendor publishes, and it is
guidance for writing prompts, not a parameter.

## Prompt tooling

> The platform provides a Wan 3.0 prompt optimization Skill to help you refine prompts.

Distributed as `wan3-pe.zip` and invoked as `/wan3-pe <prompt>` in a chat box. A separate
`wan3-video-generation-prompt-guide` page covers formulas and tuning examples.

## Gaps

- No latency, throughput or cost comparison between `wan3.0-video` and `wan3.0-video-prime` anywhere
  in the guide, despite it documenting both.
- No guidance on when the speed difference matters (long durations, reference-heavy requests).
- "20 multi-modal reference materials" is the headline count; the per-type caps (10 images + 5 videos
  + 5 audio) only reach 20 without counting the file or link slot, which the API reference allows in
  addition. The two pages do not reconcile the arithmetic.

- Capture method: server-rendered page fetched with `curl`, HTML stripped to text. Quoted text is the

## Overview (verbatim)

> The wan3.0 series is an All-in-One video generation model with comprehensive upgrades in audio-video
> generation, multi-modal reference, and video editing capabilities. It supports up to 30 seconds per
> generation, 30fps output frame rate, natively outputs dialogue, BGM, and sound effects, supports up
> to 20 multi-modal reference materials (images, videos, audio, documents, web pages) per request, and
> supports first frame/first-last frame control, video editing and extension.

> `wan3.0-video` / `wan3.0-video-prime` is an All-in-One model that covers all the following task types
> without switching model names. The model automatically routes based on the `type` field in
> `input.media` and the prompt intent.

The "20 reference materials" figure is the sum of the per-type caps (10 images + 5 videos + 5 audio),
and does not include the document or web link.

## Task matrix (verbatim, condensed to the routing column)

| Task type | Trigger | Usage notes |
| --- | --- | --- |
| Text-to-video | Only pass `prompt`, do not pass `media` | free resolution, aspect ratio and duration |
| Image-to-video, first frame | `type` = `first_frame` | `ratio` recommended `adaptive` |
| Image-to-video, first and last frame | `type` = `first_frame` and `last_frame` | `ratio` recommended `adaptive` |
| Image reference | `type` = `reference_image` | "Up to 10 images, each ≤20MB" |
| Video reference | `type` = `reference_video` | "Up to 5 clips, total duration ≤15 seconds, each file ≤100MB" |
| Audio reference | `type` = `reference_audio` | "Up to 5 clips, total duration ≤15 seconds, each file ≤15MB" |
| Combined reference | image/video/audio combination | any combination of the three |
| File/web page to video | `type` = `file` or `link` | "Parse document/web page content to generate video" |
| Video editing | `reference_video` + editing-intent prompt | "Add/remove/modify elements, style conversion, lighting editing, dialogue editing" |
| Video extension | `reference_video` + extension-intent prompt | "Extend forward/backward/both directions" |

For editing the guide recommends `ratio` = `adaptive` and `duration` = `-1` so the model "auto-preserves
original video aspect ratio and duration".

## Documented key features (verbatim)

> Generate videos using only a prompt, without any media input. Natively supports up to 30-second
> multi-shot narratives with auto-generated synchronized dialogue, BGM, and sound effects.

> Supports single-shot and multi-shot storyboard format (4~6 seconds per shot, with timestamp
> annotations).

> Audio-video: Natively generates voice dialogue, ambient sound effects, and background music without
> post-production dubbing.

> Smart duration: When `duration` is set to `-1`, the model automatically recommends an appropriate
> duration.

Prompt configuration line: "`resolution`=480P/720P/1080P (default), `ratio`=21:9/16:9/4:3/1:1/3:4/9:16,
`duration`=2~30 seconds or -1 (smart duration)."

## Output specification (verbatim)

> Resolution: 480P, 720P, 1080P (default).
> Aspect ratio: 16:9, 4:3, 1:1, 3:4, 9:16, adaptive (default, adapts to input materials).
> Duration: 2~30 seconds; -1 (smart duration, defaults to 5 seconds). When video input is provided,
> input + output total duration ≤30 seconds.
> Format: MP4, 30fps frame rate.
> Audio-video: Enabled by default; can be disabled with `audio`=false.
> Video URL is valid for 24 hours. Please save promptly.

The output section's aspect-ratio list **omits 21:9** while the prompt-tips line above it and the API
reference both include it. Recorded as a documentation inconsistency; see the model page.

## Reference material caps (verbatim table)

> `first_frame` … Maximum 1
> `last_frame` … Maximum 1
> `reference_image` … Maximum 10
> `reference_video` … Maximum 5, total duration no more than 15 seconds
> `reference_audio` … Maximum 5, total duration no more than 15 seconds
> `file` … Maximum 1, cannot be used with link simultaneously
> `link` … Maximum 1, cannot be used with file simultaneously

> `reference_xx`/`file`/`link` types and `first_frame`/`last_frame` types are mutually exclusive and
> cannot be used in the same request.

## Reference semantics (verbatim)

> Images, videos, and audio are counted separately. The first `reference_image` in the `input.media`
> array corresponds to "Img 1" or "Image 1" in the prompt … The three types do not conflict and can
> coexist as "Image 1", "Video 1", and "Audio 1" simultaneously.

Documented reference uses: character/object consistency, camera movement or action replication, style
reference, audio reference for "dance or lip-sync animation synchronized with the beat/tone", and
document/web-page-to-video.

## Summary

The guide is the most detailed first-party statement of what Wan 3.0 does: a single all-in-one model
that routes by media type and prompt intent across text-to-video, image-to-video (first frame and
first-last frame), multimodal reference, video editing and video extension, with native joint audio,
2–30 s output, 30 fps, up to 1080P. It also documents that reference mode and frame-control mode cannot
be mixed in one request.

## Gaps

- No release date, no preview/GA label, no deprecation note.
- No quality or benchmark claims at all — no numbers, no comparisons against Wan 2.7 or other vendors.
- "Up to 20 multi-modal reference materials" is a stated total, but no captured page tests whether all
  20 can be images; the per-type caps govern.
- Aspect-ratio list contradicts the API reference on 21:9.
- The guide links a downloadable prompt-optimisation "Skill" (`wan3-pe.zip`) that was not retrieved.

# Ai2 documentation and API surfaces — what could and could not be captured

- Origin: Ai2 documentation site <https://docs.allenai.org/>, its sitemap
  <https://docs.allenai.org/sitemap.xml>, and the Ai2 Playground <https://playground.allenai.org/>
- Evidence kind: official documentation surface (capture attempt); negative result
- Publication date: not applicable. Capture date 2026-10-26.
- Capture date: 2026-10-26
- Relevant models: Olmo 3 / Olmo 3.1 (documentation coverage)
- Capture type: HTTP status and byte counts of the responses

## Documentation site

`https://docs.allenai.org/sitemap.xml` lists model and release-note paths, including
`https://docs.allenai.org/models/olmo` and `https://docs.allenai.org/release_notes/olmo-release-notes`
(the latter is where `https://allenai.org/olmo/release-notes` redirects).

Every documentation path requested returned **HTTP 200 with the same 21,988-byte Docusaurus shell**
titled "Ai2 documentation" whose body is the "Introduction" page:

- `/models/olmo`
- `/release_notes/olmo-release-notes`
- `/quick_start`
- `/latest-releases`

The site is client-rendered (`data-has-hydrated="false"` in the served HTML) and serves the same
fallback document for these paths, so **no per-model documentation content could be captured**. The
only Olmo documentation text that came through is the Introduction's framing: "All of our flagship
models are covered in this guide, including Olmo 3, the best fully open language model to date" — a
statement about Olmo 3, not 3.1.

## API surface

- `https://playground.allenai.org/` responds (HTTP 200) and is the surface the 12/12 blog update points
  users at ("try the new checkpoints in the Ai2 Playground"); its model URLs take the form
  `?model=Olmo-3.1-32B-Instruct` / `?model=Olmo-3.1-32B-Think` (see the project-page record).
- `api.allenai.org` **does not resolve** (curl: "Could not resolve host"), so no Ai2-branded REST
  endpoint or price list could be found. The blog's own wording is "use them via API courtesy of our
  inference partners", which points at third-party hosting rather than a first-party paid API.

## Summary

Ai2 documents Olmo 3.1 through the blog update, the Hugging Face cards and the technical report; its
documentation site could not be read (SPA fallback on every path) and no first-party API domain or
published price list exists in what was reachable. Access is therefore: weights on Hugging Face,
interactive chat in the Playground, and hosted inference through partners.

## Gaps

- The documentation site's real content was never read, so any per-model page it holds (context limits,
  hosting guidance, API keys) is missing from this evidence base. A JS-capable capture is needed.
- Whether the Playground has usage limits or a waitlist is unknown — the page is a client-rendered app
  and no terms page was captured.
- No first-party price for any Olmo 3.1 endpoint was found anywhere.

## Content (verbatim)

> ABot-World turns a single NVIDIA RTX 5090 desktop GPU into a real-time interactive world simulator,
> enabling infinite action-conditioned world rollout at 720P, 16 FPS, 1.2s latency, and 19GB GPU memory.

Feature blurbs, in page order:

> **Action-Driven World Control** — Responds to user actions in real time, enabling continuous
> exploration instead of passive video playback.

> **Real-Time Desktop Inference** — Runs at 720p and up to 16 FPS on a single NVIDIA RTX 5090 desktop
> GPU, with 1.2s latency and 19GB GPU memory.

> **Infinite World Rollout** — Supports open-ended interactive world generation beyond fixed
> video-length limits.

> **Open-Ended World Imagination** — Expands the world with new scenes and dynamics during rollout,
> avoiding scene lock-in, without prompt switching.

Sections: "Explore Our Created Worlds — A continuous world lane. Click any bubble to expand and play."
and a "Try it on our Studio" link.

Page links: Tech Report (arXiv 2607.19191), Code (GitHub), Model (HuggingFace), Model (ModelScope),
Studio (`https://abot-world.amap.com`).

## Features and limits, verbatim values

- Prompt caching: "Yes"; "Min tokens per cache checkpoint 512"; "Max cache checkpoints per
  request 4"; "Supported TTL 5 minutes, 1 hour"; cacheable fields `system`, `messages`,
  `tools`.
- Both endpoints support Messages, Responses, Chat Completions, Converse and Invoke.
- `bedrock-runtime` lists response streaming, prompt caching, abuse detection, Guardrails,
  knowledge base, model evaluation, prompt management, Flows, Agents, structured outputs,
  count tokens and implicit prompt caching as supported.
- Service tiers: Standard, Priority, Flex, Reserved.

## Content restrictions, verbatim

> "Claude Fable 5.1 includes blocking classifiers for dual-use content in cybersecurity and
> life sciences. When a classifier blocks a request, the API returns a standard HTTP 200
> response with `stop_reason: "refusal"` and a `stop_details` object containing the
> restriction category. Refusal rates on this model are materially higher than on previous
> Claude models."

> "Prompt-stage refusals (blocked before inference begins) are not billed. Mid-stream
> refusals (blocked after partial output) are billed for tokens generated before the block."

That billing rule differs from the first-party rule, which bills low-false-positive
prompt-stage refusals since 2026-09-24.

## Data retention, verbatim

## Regions

The `bedrock-runtime` availability table lists 35 regions (US, Canada, Europe, Asia-Pacific,
Israel, Middle East, Africa, South America, Mexico, plus `us-gov-east-1` and
`us-gov-west-1`), each with in-region / geo / global icon cells. Those cells are icons in the
HTML and were not transcribed, so per-region availability is **not** asserted here. The
`bedrock-mantle` availability table names a single region, `us-gov-west-1` (GovCloud West).
Geo inference (`us.`) fans out from US and Canadian source regions to US destinations; the
full routing matrix is in the captured page.

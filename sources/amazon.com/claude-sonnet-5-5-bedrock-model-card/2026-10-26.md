## Capabilities, verbatim

On `bedrock-runtime`: response streaming, explicit prompt caching, abuse detection, Guardrails,
prompt optimization, knowledge base, model evaluation, prompt management, Flows, Agents,
computer use, client-side tool calling ("`tool_choice` types `auto` and `none` only"),
server-side tool use ("tool search only"), application inference profiles, invocation logs,
structured outputs, intelligent prompt routing, count tokens, implicit prompt caching.

On `bedrock-mantle`: response streaming, explicit prompt caching, abuse detection, count
tokens, computer use, structured outputs.

Prompt caching: "Explicit Prompt Caching supported: Yes; Min tokens per cache checkpoint: 512;
Max cache checkpoints per request: 4; Supported TTL: 5 minutes, 1 hour; Fields that accept
prompt cache checkpoints: `system`, `messages`, and `tools`."

Computer use tool type: `computer_20251124`, beta header `computer-use-2025-11-24`. **This is
the tool Anthropic's own docs say the Claude API and Google Cloud reject for this model**, so
Bedrock is the one captured platform where the older computer-use tool still works.

Compaction: "Compaction supported: Yes; Beta value: `compact-2026-09-04`".

## Service tiers and regions

Service tiers: Standard ("pay-per-token access with no commitment"), Priority ("the fastest
response times for a price premium"), Flex ("lower-cost access for flexible, non-time-sensitive
workloads"), Reserved ("dedicated throughput with a term commitment … set at the account level
rather than per request"), and Batch.

Regions listed for `bedrock-runtime` include `us-east-1`, `us-east-2`, `us-west-1`, `us-west-2`,
`ca-central-1`, `ca-west-1`, `us-gov-west-1`, `us-gov-east-1`, the `eu-*` set, the `ap-*` set
including `ap-southeast-5` (Malaysia) through `ap-southeast-7` (Thailand), `il-central-1`,
`me-central-1`, `me-south-1`, `af-south-1`, `sa-east-1` and `mx-central-1`.

Geo routing: `us.` sources and destinations span us-east-1/2, us-west-1/2 and the Canadian
regions; `eu.` spans eu-central-1/2, eu-north-1, eu-south-1/2, eu-west-1/2/3; `au.` spans
ap-southeast-2 and ap-southeast-4 only.

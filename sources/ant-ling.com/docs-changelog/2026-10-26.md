## The gap

**There is no entry for Ling-3.1-flash.** The changelog jumps from 2026-09-04 (Ling-3.0-flash-VL)
to 2026-10-19 (Ming audio), while the vendor's blog announced Ling-3.1-flash on 2026-09-30 and
open-sourced it on 2026-10-15, and the pricing page lists it as a first-class model
([launch post](../ling-3-1-flash-release/2026-10-26.md),
[open-source post](../ling-3-1-flash-open-source/2026-10-26.md),
[pricing](../pricing/2026-10-26.md)). The flagship model of the Ling line is therefore missing
from the platform's own release log, and so is the `1019` checkpoint.

## What this record is cited for

- The vendor's API compatibility pattern: entries for Ling-3.0-flash, Ling-3.0-flash-VL and
  Ling-3.0-tiny state that they are "兼容 OpenAI 及 Anthropic 协议" (OpenAI- and
  Anthropic-protocol compatible). No such entry exists for Ling-3.1-flash, so its protocol
  support is inferred from the platform's convention rather than documented for this model.
- The documentation gap above.

## Gaps

- No per-model API surface documentation for Ling-3.1-flash.
- The changelog mixes model launches with platform features and has no deprecation entries (those
  live on a separate page).
- No `1019` entry, consistent with the rest of the first-party documentation.

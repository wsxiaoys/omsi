## The context-window statement, verbatim

> Ling-3.1-flash：模型上下文上限 1M，当前官方服务开放 256K 上下文。

("Ling-3.1-flash: model context ceiling 1M; the current official service opens 256K context.")

> Ling-3.0-flash：原生支持 256K 上下文窗口，最高支持 1M 上下文窗口。

("Ling-3.0-flash: natively supports a 256K context window, up to 1M.")

This is the first-party resolution of the 1M-versus-256K disagreement: the model supports 1M,
the vendor's own service is capped at 256K, and every host captured here caps at 262,144 tokens.

## Family positioning, verbatim

> Ling 是蚂蚁集团自主研发并开源的通用大语言模型系列，基于 MoE（混合专家）架构构建

("Ling is Ant Group's self-developed, open-sourced general-purpose LLM series, built on MoE
architecture.")

> 需要模型作为个人助手，处理办公任务、长周期开发、复杂的 Agentic 任务？选择 Ling-3.1-flash。拥有约 560B 总参数，在多步规划、工具链调用与长时间自主纠错中保持高完成率，也有足够强的世界知识。

("Want a model as a personal assistant for office tasks, long-cycle development, complex agentic
tasks? Choose Ling-3.1-flash. With ≈560B total parameters it keeps a high completion rate across
multi-step planning, tool-chain calls and long autonomous self-correction, and has enough world
knowledge.")

For Ling-3.0-flash the docs claim a peak inference speed of 1000 tokens/s, and for Ling-3.0-flash
VL native image, text and video input with a "视觉反馈闭环" (visual feedback loop). Neither claim
is made for Ling-3.1-flash, which the docs position as text-in/text-out.

## Summary

The docs confirm the model line, the served-context cap (256K) against the 1M architectural
ceiling, the 560B/25B scale, and that Ling-3.1-flash is the text-only generalist of the family
while multimodal input lives in Ling-3.0-flash-VL. It names no checkpoint (`1019` or otherwise)
and no benchmark scores.

## Gaps

- No benchmark numbers anywhere on the page.
- No checkpoint identifiers, no release dates per model, no deprecation dates (those live on a
  separate page).
- No statement of the weights licence.
- The page footer date (October 27, 2026) is the documentation build date, not a model date.

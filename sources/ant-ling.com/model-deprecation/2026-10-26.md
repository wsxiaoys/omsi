## Policy, verbatim

> 提前通知：模型正式下架前，我们会通过文档和公告的方式告知。
> 服务终止：到达下架日期后，相关 model ID 的 API 调用将返回错误，不再提供服务。
> 平滑迁移：每个被下架的模型均会提供推荐的替代模型，且替代模型在性能和成本上均不劣于原版本。

("Advance notice: before a model is formally retired we announce it through docs and
announcements. Hard stop: after the retirement date, calls to that model ID return an error.
Smooth migration: every retired model gets a recommended replacement that is no worse in
performance and cost.")

## Ling-3.1-flash is the current, supported model

Under "当前可用模型" (currently available models), which the page describes as "处于稳定支持期，可放心用于生产环境"
(in stable support, safe for production), the table lists:

| Model ID | Family | Positioning |
| --- | --- | --- |
| **Ling-3.1-flash** | Ling 3.1 | 新一代长流程混合推理模型，专为日常办公、长周期研发与复杂 Agent 任务设计 |
| Ling-3.0-flash-VL | Ling 3.0 | 原生多模态混合推理模型，支持图像、文本与视频输入 |
| Ling-3.0-flash | Ling 3.0 | 高性价比混合推理模型，可支撑高频任务 |
| Ling-3.0-tiny | Ling 3.0 | 轻量级混合推理模型，支持端侧部署与本地离线运行 |

Ling-3.1-flash is the **recommended replacement** for three models retiring on
**2026-11-15 00:00 (UTC+8)** — `Ling-2.6-1T`, `Ring-2.6-1T`, `Ling-2.6-flash` — and for four
already-retired ones: `Ling-1T` and `Ring-1T` (2026-06-15), `Ling-2.5-1T` and `Ring-2.5-1T`
(2026-09-30). It is therefore the terminus of both the Ling and Ring migration paths.

The migration snippets use the model ID `"Ling-3.1-flash"` natively and
`inclusionai/ling-3.1-flash` on ZenMux.

## Summary

Ling-3.1-flash is the vendor's designated successor for Ling-1T/2.5-1T/2.6-1T/2.6-flash and for
Ring-1T/2.5-1T/2.6-1T, and is in stable support with no announced retirement. The vendor's policy
is advance notice plus a hard cut-off plus a replacement "no worse in performance and cost" — a
vendor claim, not a measured one.

## Gaps

- No retirement date or support window is published for Ling-3.1-flash itself.
- No checkpoint granularity: the policy is written in terms of model IDs, and the only
  Ling-3.1-flash ID is undifferentiated.
- The "no worse in performance and cost" promise is unquantified.

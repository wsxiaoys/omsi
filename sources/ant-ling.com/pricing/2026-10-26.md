## Billing mechanics, verbatim

- "按量计费，根据实际 token 消耗计算费用，无最低消费门槛" (usage-based billing on actual token
  consumption, no minimum spend).
- "通常 1 个汉字 ≈ 2 Token，1 个英文单词 ≈ 1.3 Token" (roughly 2 tokens per Chinese character,
  1.3 per English word).
- "按日结算，每日凌晨自动生成前一日账单" (settled daily, previous day's bill generated each
  morning).
- Onboarding requires binding an **Alipay** account in the API console; "当前仅支持个人支付宝账户充值缴费，暂不支持企业版支付宝账户"
  (only personal Alipay accounts can top up; enterprise Alipay accounts are not supported).

## Summary

This page pins the money: list price $0.30/$0.90 per million input/output tokens (¥2/¥6), a
75%-off promotion to $0.075/$0.225 (¥0.5/¥1.5), cache reads at $0.06 ($0.015 promotional), and
an explicit statement that the same promotion applies on OpenRouter and ZenMux. It also shows
there is **one** Ling-3.1-flash SKU — no per-checkpoint pricing, no `1019` line item.

## Gaps

- No promotion end date, so the list price is the only durable figure.
- No separate entry for a `1019` checkpoint; whether the single SKU now serves those weights is
  not stated.
- No refund/rate-limit/context-tier terms on this page (rate limits are documented separately).
- Enterprise billing is unavailable, which limits who can use the first-party API at all.

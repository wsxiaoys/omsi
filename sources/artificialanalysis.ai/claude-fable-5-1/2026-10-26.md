## Label → canonical model ID

The page title is "Claude Fable 5.1 (max with fallback)"; the body calls it "Claude Fable 5.1
(Max, Default Fallback)". Four independent facts tie this label to `claude-fable-5-1`:

1. **Release date.** AA: "Claude Fable 5.1 (Max, Default Fallback) was released on September
   1, 2026." Anthropic's model page, release notes and system card say the same.
2. **Price.** AA: "$10.00 per 1M input tokens and $50.00 per 1M output tokens (based on
   Anthropic's API)" — the first-party list price.
3. **Context and modality.** AA: "has a 1M tokens context window", "supports text and image
   input, outputs text" — matching the platform model page.
4. **Effort variants.** AA exposes exactly `max`, `xhigh`, `high`, `medium`, `low`, which is
   Anthropic's `effort` value set.

**What "with fallback" means here is weaker than it looks.** No captured AA page defines it.
Anthropic documents that Fable 5.1's safeguards return `stop_reason: "refusal"` and that
`fallbacks: "default"` retries a refused request on Claude Opus 4.8 or Opus 5
([what's new](../../claude.com/claude-fable-5-1-whats-new/2026-10-26.md)), so the most
plausible reading is that AA scored the model with a fallback path configured. Whether any
fallback actually fired during AA's runs is not stated, and no "without fallback" row exists
for comparison.

## Gaps

- AA's own page renders the per-benchmark numbers client-side; the values above come from
  OpenRouter's restatement of the same AA table
  ([OpenRouter](../../openrouter.ai/claude-fable-5-1/2026-10-26.md)) and were not read off
  AA's charts. The headline index, cost, speed and TTFT figures are AA's own printed text.
- No statement of which provider served the runs, nor whether safeguard refusals occurred.
- "Default Fallback" and "with fallback" are used without definition.
- The 166.61 s TTFT at max effort against 16.85 s at high effort is unexplained; it is either
  time to first *answer* token after a long reasoning phase or a harness artefact.

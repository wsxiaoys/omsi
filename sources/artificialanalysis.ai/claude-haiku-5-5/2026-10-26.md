## Label → canonical model ID

The page title is "Claude Haiku 5.5 (max)"; the body calls it "Claude Haiku 5.5 (Max)". Four
independent facts tie the label to `claude-haiku-5-5`:

1. **Canonical slug.** AA's own model record is `slug: "claude-haiku-5-5"`, `releaseDate:
   "2026-10-07"`, `deprecated: false`, creator `anthropic`. The five leaderboard rows carry
   slugs `claude-haiku-5-5`, `-xhigh`, `-high`, `-medium`, `-low`, all with
   `releaseSlug: "claude-haiku-5-5"`.
2. **Release date.** AA: "Claude Haiku 5.5 (Max) was released on October 7, 2026." Anthropic's
   announcement and platform model page say the same.
3. **Price.** AA: "$0.10 per 1M input tokens … and $0.50 per 1M output tokens (based on
   Anthropic's API)". That is `claude-haiku-5-5`'s first-party list price on the ≤100k-token
   tier.
4. **Effort variants.** AA exposes exactly `max`, `xhigh`, `high`, `medium`, `low`, which is
   Anthropic's `effort` value set, and `medium` is the documented default
   ([effort](../../claude.com/effort/2026-10-26.md)).

**"with fallback" is absent, and that is the point.** AA labels Opus 5.5 and Sonnet 5.5 rows
"(max with fallback)" but Haiku 5.5 rows plainly "(max)". That matches the vendor: Haiku 5.5's
safeguard classifiers "have no fallback model" and blocks "will not fall back to any other
models on our first-party products and our API"
([system card](../../anthropic.com/claude-haiku-5-5-system-card/2026-10-26.md)). The absence
is consistent with, not proof of, AA scoring the undiluted deployed model.

## Cross-checks against other measurements

- **Index 43 at max** agrees with OpenRouter's restatement of AA at 43.4, and its per-effort
  figures (37.8 / 34.5 / 29.5 / 41.2) match this capture's 38 / 34 / 29 / 41
  ([OpenRouter](../../openrouter.ai/claude-haiku-5-5/2026-10-26.md)).
- **Terminal-Bench 4.0 = 32.8%** at max per the OpenRouter restatement, against Anthropic's
  39.2% ±1.9. AA's harness is 6.4 points lower; the same direction and rough size of gap as
  AA's Opus 5.5 measurement (59.6 vs 66.4).
- **Cache discount 90%** matches Anthropic's cache read at 10% of input price ($0.01 vs
  $0.10 on the ≤100k tier).
- **Price is the ≤100k tier.** AA's $0.10/$0.50 is the first tier only; Anthropic charges
  5× above 100k prompt tokens, and the vendor's own announcement says ~90% of Haiku 4.5
  requests fell in the cheaper tier. AA's per-task cost is a weighted average, so it already
  absorbs some of this.

## Gaps

- AA's captured page prints the composite index and summary tiles but not per-benchmark
  numeric scores; those charts are client-rendered. The per-benchmark AA figures cited on the
  model page therefore come from OpenRouter's restatement of AA, not from this capture.
- No methodology note on which provider endpoint was used, or whether the 100k long-context
  tier was exercised.
- The API endpoint requires a key (`/api/v2/data/llms/models` returns 401), so no
  machine-readable capture was made.
- Claude Haiku 4.5 does not appear among the captured leaderboard's current rows, so AA's
  own delta over the predecessor cannot be read from this capture.

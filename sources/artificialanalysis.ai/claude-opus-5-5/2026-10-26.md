## Label → canonical model ID

The page title is "Claude Opus 5.5 (max with fallback)"; the body calls it "Claude Opus 5.5
(Max, Default Fallback)". Three independent facts tie this label to `claude-opus-5-5`:

1. **Release date.** AA: "Claude Opus 5.5 (Max, Default Fallback) was released on September
   22, 2026." Anthropic's model page and release notes say the same.
2. **Price.** AA: "$4.00 per 1M input tokens and $20.00 per 1M output tokens (based on
   Anthropic's API)". That is `claude-opus-5-5`'s first-party list price; Claude Opus 5 is
   $5/$25 and Claude Fable 5.1 is $10/$50.
3. **Effort variants.** AA exposes exactly `max`, `xhigh`, `high`, `medium`, `low`, which
   is Anthropic's `effort` parameter value set
   ([effort](../../claude.com/effort/2026-10-26.md)).

**What "with fallback" means.** It is not a different model. Anthropic documents that
Opus 5.5's production safeguards route some requests to a weaker model — cyber to Opus 4.8,
biology and frontier-LLM-development to Opus 5 — and that the launch-post benchmark table
was run "with its production safeguards enabled"
([announcement](../../anthropic.com/claude-opus-5-5-announcement/2026-10-26.md),
[system card §1.5](../../anthropic.com/claude-opus-5-5-system-card/2026-10-26.md)). AA's
"with fallback" therefore most plausibly means *scored with production safeguard routing
active*, as distinct from the bare model. AA's captured page does not define the term, and
no "without fallback" Opus 5.5 row appears on the captured leaderboard, so the reading is
an inference from the vendor's own description of the deployment, not an AA statement.

**Treat the 712-second TTFT with suspicion.** It is reported identically on the model page
("time to first token (TTFT) of 712.32s") and on the board, so it is AA's own figure and not

token after a long maximum-effort reasoning phase. The page does not say which, so the
number is recorded without interpretation.

## Cross-checks against other measurements

- **Cache discount 95%** matches Anthropic's cache read at 5% of input price ($0.20 vs $4).
- **Index 58 at max** is consistent with the five-variant sub-scores restated on
  OpenRouter's page, where max is 57.6 ([OpenRouter](../../openrouter.ai/claude-opus-5-5/2026-10-26.md)).
- **Terminal-Bench 4.0 = 59.6%** at max (from the OpenRouter restatement of AA's numbers)
  against Anthropic's 66.4% and Vals AI's 65.15%. AA's harness produces a materially lower
  score than either; see the model page.

## Gaps

- AA's captured page prints the composite index and summary tiles but not per-benchmark
  numeric scores; those charts are client-rendered. The per-benchmark AA figures cited on
  the model page therefore come from OpenRouter's restatement of AA, not from this capture.
- No methodology detail for how "fallback" was configured, or whether any fallback ever
  triggered.
- No confidence intervals, task counts, or prompt-set versions beyond the index composition
  line.
- The API endpoint requires a key (`/api/v2/data/llms/models` returns 401), so no
  machine-readable capture was made.

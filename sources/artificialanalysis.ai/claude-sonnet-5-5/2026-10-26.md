## Label → canonical model ID

The page title and URL slug are both `claude-sonnet-5-5`; the body calls it "Claude Sonnet 5.5
(Max, Default Fallback)". Three independent facts tie the label to `claude-sonnet-5-5`:

1. **Release date.** AA: "Claude Sonnet 5.5 (Max, Default Fallback) was released on September
   28, 2026." Anthropic's model page, system card and announcement all say 2026-09-28.
2. **Price.** AA: "$2.00 per 1M input tokens … and $10.00 per 1M output tokens, based on
   Anthropic's API." That is `claude-sonnet-5-5`'s first-party list price; Claude Sonnet 5 is
   also $2/$10, but Claude Opus 5.5 is $4/$20 and Claude Fable 5.1 is $10/$50.
3. **Effort variants.** AA publishes five rows — `max`, `xhigh`, `high`, `medium`, `low` — each
   suffixed "Default Fallback". That is exactly Anthropic's `effort` value set, and `high` is
   this model's first-party default ([effort](../../claude.com/effort/2026-10-26.md),
   [model page](../../claude.com/claude-sonnet-5-5-model-page/2026-10-26.md)).

**What "with fallback" means.** It is not a different model. Anthropic documents that Sonnet
5.5's production safeguards fall back to Claude Sonnet 5 for blocked cyber requests and
blocked frontier-LLM-development requests, that this happens automatically in Anthropic's own
apps, and that API developers must opt in
([system card §1.5](../../anthropic.com/claude-sonnet-5-5-system-card/2026-10-26.md),
[What's new](../../claude.com/claude-sonnet-5-5-whats-new/2026-10-26.md)). AA's page does not
define the term and does not say whether any fallback fired during its runs. The best
supported reading is "scored with the deployed system's fallback routing active", but that is
an inference, not an AA statement.

## Cross-checks

- **Cache discount 95%** matches Anthropic's cache read at 5% of input price ($0.10 vs $2).
- **Index 56 at max** matches the five-variant sub-scores restated on OpenRouter's page, where
  max is 56.0 ([OpenRouter](../../openrouter.ai/claude-sonnet-5-5/2026-10-26.md)).
- **Terminal-Bench 4.0 = 63.6%** at max effort, against Anthropic's 70.6% (vendor-run, with
  safeguards enabled) and Vals AI's 64.1% as restated by OpenRouter. AA's harness sits below
  both. The gap is 7.0 points; the vendor's own standard error on that benchmark is ±2.5
  points, but that figure describes within-harness trial noise, not cross-harness agreement.
- **420M output tokens on the index** is a different measurement from the announcement's claim
  that Sonnet 5.5 "typically needs far fewer tokens to do the same work" than Sonnet 5. Both
  can be true: AA measures tokens per short index question at max effort, Anthropic measures
  tokens per agentic task at a mixed effort.

## Gaps

- AA's captured page prints the composite index and summary tiles but not per-benchmark numeric
  scores; those charts are client-rendered. The per-benchmark AA figures cited on the model page
  therefore come from OpenRouter's restatement of AA.
- No methodology detail for how "fallback" was configured, or whether any fallback triggered.
- No confidence intervals, task counts, or prompt-set versions beyond the index composition
  line.
- The API endpoint requires a key (`/api/v2/data/llms/models` returns 401), so no
  machine-readable capture was made.
- No cost or token figures for the four lower-effort rows on this page; only the `max` row is
  printed in text.

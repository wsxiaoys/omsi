## Three classification notes

1. **"Open weights model."** Correct at capture: `zai-org/GLM-5.3` publishes a 141-shard fp8
   checkpoint ([model card](../../huggingface.co/glm-5-3-model-card/2026-10-26.md)). AA labels
   the licence "GLM-5.3 License" without saying whether it counts as "commercial use
   restricted"; the licence does impose a conditional security review above US$10B revenue.
2. **"A non-reasoning variant may also exist."** Generic AA caveat. The vendor states the
   opposite: reasoning cannot be disabled, only effort lowered
   ([docs](../../z.ai/glm-5-3-docs/2026-10-26.md)).
3. **"max" is an effort level, not a variant.** AA's single GLM-5.3 row is at
   `reasoning_effort: max`, which is also the API default. No low/high rows exist, so AA's
   capture cannot show the effort slope that the vendor reports as steep.

## What this establishes

- An independent composite score for the model: **45**, third in AA's open-weights-large class.
- Independent cost and verbosity measurements: $2.01 per index task, 210M output tokens.
- Parameter counts (753B / 40B) that no first-party page publishes.
- A speed figure (90.1 t/s) that is a single-provider or aggregate number, not the fastest
  available — see the [provider record](../glm-5-3-providers/2026-10-26.md), where the fastest
  measured endpoint is 708.5 t/s.

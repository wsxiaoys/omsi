## Label → canonical model ID

AA's title is "GPT-6 Astra (max)"; the roster label "GPT-6 Astra" is the same entry with
the effort suffix dropped. The mapping to `gpt-6-astra` rests on four matches:

1. **Vendor and price.** AA: creator "OpenAI", "In $10.00 / Out $50.00" — exactly the
   first-party list price for `gpt-6-astra`
   ([model page](../../openai.com/gpt-6-astra-model/2026-10-26.md)).
2. **Context window.** AA: "1M" — first-party 1,050,000.
3. **Knowledge cutoff.** AA: "Apr 30, 2026" — first-party "Apr 30, 2026 knowledge cutoff".
4. **Effort variants.** AA exposes `max`, `xhigh`, `high`, `medium`, `low`, which is
   OpenAI's `reasoning.effort` value set for this model.

"Astra" is therefore **not a codename**: it is the product name, and `gpt-6-astra` is the
canonical API ID.

## The index-version contradiction

OpenAI's launch post prints its own row for **"Artificial Analysis Intelligence Index
v4.1.1: 61.2"** and places Claude Fable 5.1 above it at 65.7
([announcement](../../openai.com/gpt-6-astra-announcement/2026-10-26.md)). AA's live board at
capture uses **v4.3.2** and gives Astra **53**, with Claude Opus 5.5 at 58. The two are not
comparable: different index versions, and the vendor quotes a number AA's current board no
longer shows. Recorded as a contradiction, not reconciled.

Note also that the direction of the comparison survives — on both versions Astra trails the
top Claude row by roughly 4–5 points — while the absolute level does not.

## What this establishes

- Independent absolute score: **53** on AA Intelligence Index v4.3.2, rank #8 of 221 at
  capture. Above the median (28) but behind Claude Opus 5.5 (58).
- Independent cost measurement: **$3.26 per index task** at max effort — despite the
  highest per-token price on the board's frontier, it is *not* the most expensive per task,
  which is consistent with OpenAI's token-efficiency claim without confirming it.
- **Effort is the dominant variable**: 46 → 53 index points and $0.82 → $3.26 per task
  across low → max. Any quotation of "Astra's score" without an effort level is
  under-specified.
- Latency is extreme at max effort (353 s to first chunk) and trivial at low (2.65 s).
- Verbosity is *below* median on the index (60M vs 81M output tokens), contradicting a
  common assumption that a $50/M-output model must be verbose.

## Gaps

- Per-benchmark scores are chart-rendered and were not captured; only the composite and the
  cost/speed/verbosity tiles are text.
- The page carries the UI string "No publicly available API" in several chart legends. Its
  meaning is not defined in the capture and it is **not** interpreted here.
- No confidence intervals, task counts or run dates.
- AA's generic note "A non-reasoning variant may also exist" contradicts OpenAI's "does not
  support the `none` reasoning effort level". Vendor documentation wins; the AA note is a
  boilerplate caveat.

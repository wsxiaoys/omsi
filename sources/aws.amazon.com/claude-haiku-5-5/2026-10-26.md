Reasoning, verbatim: "Supported (adaptive thinking is on by default and can be turned off;
effort level configurable — low, medium, high, xhigh, max; default: medium; effort capped at
high when thinking is disabled)".

This is the clearest single statement of the thinking/effort interaction: thinking can be
disabled, but disabling it also caps effort at `high` — so `xhigh` and `max` are unreachable
with thinking off. The vendor docs state the same rule more loosely ("at `high` effort or
below").

## Endpoints and APIs

Both `bedrock-runtime` and `bedrock-mantle` serve it. APIs on `bedrock-runtime`: Messages,
Responses, Chat Completions, Converse, Invoke. APIs on `bedrock-mantle`: the same five.

Bedrock features on `bedrock-runtime` (supported): response streaming, explicit prompt
caching, Guardrails, model evaluation, Flows, Agents, computer use, prompt optimization (base
model ID only), client-side tool calling, server-side tool use "(tool search only; regex and
BM25)", application inference profiles, invocation logs, structured outputs, count tokens.

Features listed as not supported on `bedrock-runtime`: abuse detection, knowledge base,
prompt management, intelligent prompt routing, implicit prompt caching.

Explicit prompt caching: minimum 512 tokens per checkpoint, max 4 checkpoints per request,
TTLs of 5 minutes and 1 hour, checkpoints accepted on `system`, `messages`, and `tools` — all
matching the first-party numbers.

Tools available on `bedrock-runtime`: `computer_20251124` (beta header
`computer-use-2025-11-24`), `computer_toolset_20260801`, `browser_toolset_20260801`,
`bash_20250124`, `text_editor_20250728`, `memory_20250818` — all with "None required" beta
headers except the first. Compaction supported with beta value `compact-2026-09-04`.

**Host divergence worth noting:** Bedrock accepts `computer_20251124` for this model, while
Anthropic's migration guide says the Claude API and Google Cloud reject `computer_20250124`
and require `computer_toolset_20260801`. Bedrock's card lists the toolset too, so both the old
and new computer-use surfaces exist on Bedrock and only the toolset on the Claude API.

## Pricing model, verbatim

> "This model is a third-party model offered and billed through AWS Marketplace. Charges
> appear on your AWS bill and in AWS Cost Explorer under the model provider (not under Amazon
> Bedrock)."

> "Claude Haiku 5.5 uses tiered long-context pricing. Prompts of 100,000 tokens or fewer are
> billed at the standard per-token rates. Prompts that exceed 100,000 tokens are billed at
> higher rates for input, output, and cache read and write operations. The rates for prompts
> over 100,000 tokens appear in a separate row, labeled Claude Haiku 5.5 - Long Context."

No dollar figures are printed on the model card; it defers to the Amazon Bedrock pricing
page. Service tiers offered: Standard ("pay-per-token access with no commitment"), Priority
("fastest response times for a price premium"), Flex ("lower-cost access for flexible,
non-time-sensitive workloads"), Reserved (account-level dedicated throughput), plus Batch.

**Contradiction to preserve:** Anthropic's migration guide states "Priority Tier is not
supported on Claude Haiku 5.5" for the Claude Platform, yet Bedrock lists a Priority service
tier for the same model. These are different products — Anthropic's Priority Tier is a
first-party commitment product — but a reader should not generalize one to the other.

## Model IDs and inference profiles

`bedrock-runtime` model ID `anthropic.claude-haiku-5-5`; in-region endpoint URL "N/A"; geo
inference IDs `us.`, `eu.`, `au.`, `jp.`, and global `global.anthropic.claude-haiku-5-5`.
`bedrock-mantle` model ID `anthropic.claude-haiku-5-5`, endpoint
`https://bedrock-mantle.{region}.api.aws/anthropic/v1/messages`, no geo or global profile.

Regional availability for `bedrock-runtime` lists 30+ regions including GovCloud
(`us-gov-west-1`, `us-gov-east-1`), while `bedrock-mantle` lists only `us-gov-west-1`.

## Summary

Bedrock's card is the most operationally precise host record: it pins the effort/thinking
interaction ("effort capped at high when thinking is disabled"), documents the 512-token
cache minimum and four-checkpoint limit, enumerates both endpoints and the tool surface, and
confirms the tiered long-context billing boundary at 100k prompt tokens. It publishes no
prices.

## Gaps

- No per-token dollar figures.
- No quota numbers ("default quotas … might change").
- Page carries no publication or revision date.
- The card does not say whether the geo/global inference profiles carry different prices.

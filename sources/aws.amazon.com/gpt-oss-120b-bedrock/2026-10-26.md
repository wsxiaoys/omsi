## What Bedrock adds to the picture

- **An AWS-side release date of August 5, 2025**, matching OpenAI's model card heading and the
  weights repository's creation timestamp. Three parties, one date.
- **A versioned model ID** (`-1:0`) — Bedrock pins a revision, whereas OpenAI's docs and
  OpenRouter both use the un-suffixed `gpt-oss-120b`. The suffix is Bedrock's revision counter,
  not a new model.
- **A narrower context figure: 128,000**, against 131,072 in OpenAI's docs and in most OpenRouter
  endpoints. Bedrock does not explain the difference; it may be a rounded or reserved-capacity
  figure rather than a different tokenizer limit. Left open.
- **A different API surface**: Bedrock serves the model through `InvokeModel`/`Converse` and an
  OpenAI-compatible Chat Completions route — while OpenAI's own docs mark Chat Completions
  "Not supported" for this model
  ([OpenAI docs](../../openai.com/gpt-oss-120b-model-docs/2026-10-26.md)).
- Guardrails are available as an AWS-side wrapper; OpenAI publishes no such system-level
  protection for the weights themselves.

## Summary

Bedrock is a live first-party-adjacent serving path for the same weights: model ID
`openai.gpt-oss-120b-1:0`, text in/out, 128,000 context, InvokeModel/Converse/Chat Completions,
batch inference, and Guardrails. It confirms continued availability and dates the release to
2025-08-05, while disagreeing with OpenAI on the context figure and on whether Chat Completions
is supported.

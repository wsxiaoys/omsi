## Captured content — verbatim

Opening description:

> FLUX 3 Image Klein is a compact, open-weights version of FLUX 3 Image. It supports the same
> features: text to image, image editing, multi reference, and bounding boxes. It runs faster
> and fits on consumer GPUs, down to an RTX 3090. Do not use it without its prompt upsampler.

### Prompt-upsampling warning (verbatim)

> Do not use Klein without the prompt upsampler. The model is trained on the captions it writes;
> a prompt sent as typed gives noticeably weaker results.

> The pipeline does not call the prompt upsampler. Do not send it a prompt as typed: the prompt
> below is a full caption, anything shorter goes through the upsampler first.

> **Diffusers:** it's a separate model that the pipeline does not call. Run it with Transformers
> and pass its output to the pipeline as `prompt`. It adds about 28 GB of GPU memory.

The upsampler is `black-forest-labs/flux-3-image-klein-pup`, a
`Qwen3_5ForConditionalGeneration` model loaded through Transformers, with
`system_prompts.json` supplying `t2i` / `i2i` scaffolds and `max_new_tokens=3584`, greedy.

### API example (verbatim, abbreviated)

```bash
curl --request POST \
  --url https://api.bfl.ai/v1/flux-3-image-klein \
  --header "x-key: $BFL_API_KEY" \
  --data '{"prompt": "A red fox curled up asleep ...", "aspect_ratio": "4:3"}'
```

The page states the request "takes the same fields as FLUX 3 Image".

### LoRA training section

- Train on **Klein Base**; a rank-32 LoRA on a handful of images on a single GPU is enough.
- A LoRA trained on Base "loads into Distilled without any conversion" because they "share the
  same architecture"; BFL recommends LoRA scale 0.75 (range 0.5–1.0) and Distilled's own 16
  steps / CFG 1.
- Reference config: 20 images, ~1 MP, rank/alpha 32/32, AdamW, lr 1e-4 with 200 warmup steps,
  4000 steps, 1 GPU, ~4.5 hours.
- AI Toolkit needs `arch: flux3` and `name_or_path: black-forest-labs/flux-3-image-klein-base`.
- "Distilled renders the same seed differently, so expect small changes in details like a hair
  color or the phase of the moon, not in the style itself."

## What this establishes

- Klein is a *compact open-weights version of FLUX 3 Image* with the same feature set, not a
  separate modality or a differently-trained family.
- Two checkpoints with different sampling settings (16 steps/CFG 1 vs 50 steps/CFG 3.5).
- Base is not served first-party; only the distilled checkpoint is on the API.
- The model is documented as unusable in practice without a separate 9B-class prompt upsampler,
  which the Diffusers path does not run for you.

## Gaps

- No benchmark numbers of any kind on this page.
- "down to an RTX 3090" is asserted without stating quantization build, framework, or image size.
- No statement of what Klein drops relative to FLUX 3 Image. FLUX 3 Image's docs describe a
  default-on web grounding search (see the FLUX 3 Image overview); this page never mentions
  grounding, and the Klein request schema has no `grounding` field. Whether Klein lacks the
  capability or merely the parameter is not stated anywhere captured.

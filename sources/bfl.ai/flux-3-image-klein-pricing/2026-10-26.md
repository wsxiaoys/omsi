# BFL API pricing page — FLUX 3 Image Klein section

- Origin: Black Forest Labs, "Overview" (API pricing), https://docs.bfl.ai/quick_start/pricing.md
- Evidence kind: official documentation (pricing page)
- Publication date: not stated; rolling
- Capture date: 2026-10-26
- Relevant models: FLUX 3 Image Klein, FLUX 3 Image, FLUX 3 Video, FLUX.2 and FLUX.1 families

## Captured content — verbatim

> **Simple credit-based pricing:** 1 credit = \$0.01 USD • Pay per image, or per second for video
> • Same price for API and Playground

FLUX 3 Image Klein section, verbatim lead-in:

> FLUX 3 Image Klein is priced per image by output resolution. Text to image and image editing
> cost the same.

The table's row and header render as:

```
| | 768 × 768 | 1K | 1.5K | 2K | 4K |
| **FLUX 3 Klein** | | | | | |
```

**Every price cell is empty in the fetched Markdown.** The same is true of the FLUX 3 Image and
FLUX 3 Video tables on this page: the numbers are injected client-side and do not survive the
Markdown rendering. The page does state that "1 credit equals \$0.01 USD" and that the submission
response includes the `cost` of each request.

For contrast, the same page's FLUX.2 [klein] section carries the explanatory note:

> **Klein pricing explained:** The first megapixel costs a flat rate, then each additional MP
> adds to the total.

That per-megapixel model is the FLUX.2 generation's; the FLUX 3 Klein section above describes
flat per-resolution prices instead.

## What this establishes

- The FLUX 3 Klein price basis is **per image by output resolution**, identical for generation and
  editing, and the API/Playground prices are stated to be the same.
- Credit conversion: 1 credit = $0.01.
- The machine-readable pricing page is **not** a usable source for the actual dollar figures on
  this capture; the numbers come from the release-note record instead.

## Gaps

- No dollar values captured here.
- No batch pricing, no per-megapixel fallback, no statement of what happens with `width`/`height`
  set to a non-tier size (the API reference says arbitrary sizes up to 16.8 MP are allowed, but
  this page prices only five tiers).
- Nothing on refunds for moderated or failed requests.

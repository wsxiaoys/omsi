## Captured content — verbatim

### October 15, 2026 — FLUX 3 Image Klein

> FLUX 3 Image Klein is a 5.6B parameter version of FLUX 3 Image with open weights. It supports
> the same features: text to image, image editing, multi reference, and bounding boxes. Run it
> through the API, download the weights from Hugging Face, or load it in ComfyUI.

Key features, verbatim bullets:

> * **Same request as FLUX 3 Image:** `prompt`, `images`, `aspect_ratio`, `resolution`, and the
>   bounding box format are unchanged. A FLUX 3 Image request runs on Klein by switching the
>   endpoint
> * **Two variants:** Klein (Distilled) runs 16 steps at CFG 1 for fast inference. Klein Base
>   runs 50 steps at CFG 3.5 and is the model for fine-tuning and LoRA training
> * **Open weights:** both variants are on Hugging Face under the FLUX Kommunity License and run
>   on consumer GPUs, down to an RTX 3090
> * **Up to 4K output:** `resolution` from `768sq` to `4k`, with up to ten reference images per
>   request
> * **LoRA training:** train on Klein Base with AI Toolkit (`arch: flux3`) or Diffusers. The
>   trained LoRA also loads into Klein (Distilled)

### Pricing table, verbatim

### Context: July 23, 2026 — Announcing FLUX 3

> FLUX 3 is our new multimodal foundation model: one model jointly trained across image, video,
> and audio, built toward real-world visual intelligence.

Rollout plan, verbatim: "Capabilities become available in phases, each after an early access
period: video generation and editing first, action prediction with selected partners, image
synthesis and editing, and open-weight access to a multimodal backbone."

## What this establishes

- Launch date **2026-10-15**, i.e. inside the one-year window (cutoff 2025-10-26).
- Canonical identity: FLUX 3 Image Klein is a **5.6B-parameter open-weights version of FLUX 3
  Image**, with the same request shape — BFL explicitly frames migration as "switching the
  endpoint".
- Full first-party price schedule: **$0.008 / $0.009 / $0.011 / $0.014 / $0.036** at
  768sq / 1K / 1.5K / 2K / 4K, identical for generation and editing.
- Klein is roughly **5× cheaper than the parent at 1K** ($0.009 vs $0.048) and **17× cheaper at
  4K** ($0.036 vs $0.607).
- Two checkpoints with distinct sampling settings; Base is the fine-tuning target.
- FLUX 3 Image Klein is the second open-weights release in the FLUX 3 family, after FLUX 3 Action.

## Gaps

- The changelog gives no benchmark, no latency figure, and no quality comparison against the
  parent — only the price ratio.
- "Down to an RTX 3090" again appears without a stated quantization build or framework.
- The parent's changelog entry lists 15 aspect ratios for FLUX 3 Image; Klein's schema also has
  15, but no captured source states whether Klein is native at 4K or upscales to it. BFL's
  launch post and ComfyUI's FAQ both say "native 4K"; the changelog does not repeat that.

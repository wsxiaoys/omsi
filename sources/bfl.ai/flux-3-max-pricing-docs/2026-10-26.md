# BFL official: pricing overview (no FLUX 3 Max row)

- Origin: Black Forest Labs, "Overview" (API pricing), <https://docs.bfl.ml/quick_start/pricing>
  — the same document the bfl.ai pricing link resolves to
- Evidence kind: official documentation (vendor price list)
- Publication date: not stated on the page
- Capture date: 2026-10-26
- Relevant models: FLUX 3 Video, FLUX 3 Image, FLUX 3 Image Klein, FLUX.2 \[max]; searched for
  FLUX 3 Max

## Captured structure

The page states "1 credit = $0.01 USD • Pay per image, or per second for video • Same price for
API and Playground", then gives one section per model family:

- **FLUX 3 Video** — a per-second rate table by resolution class. Rows: `t2v`, `i2v`, `v2v`; the
  columns are `hd`, `fhd`, `qhd`, `uhd` plus a `Draft` column. The numeric cells did **not**
  render as text in this capture (see Gaps); the rates themselves are quoted verbatim in
  `sources/bfl.ai/flux-3-max-video-page/2026-10-26.md` and in the September 10, 2026 release note.
- **FLUX 3 Image** — per image by `resolution`: `768sq` (768 × 768), `1k` (about 1 megapixel),
  `1.5k` (about 2 megapixels), `2k` (about 4 megapixels), `4k` (about 16 megapixels). Prices did
  not render in this capture.
- **FLUX 3 Image Klein** — per image by output resolution, text-to-image and editing at the same
  price.
- **FLUX Tools (Video)** — FLUX Video Upscale per megapixel-second; FLUX Video Edit \[fast] per
  second.
- **FLUX.2 Models** — a megapixel-priced table with rows for \[klein] 4B, \[klein] 9B, \[pro],
  **\[max]**, \[flex], \[dev].

## What is absent

There is **no FLUX 3 Max section, row, or price**. FLUX 3 Video is priced as one model with
resolution classes, not as named tiers.

### Disambiguation that matters

The only first-party "max" price row is **FLUX.2 \[max]**, described as "Highest quality,
grounding search". That is the 2025 FLUX.2 image model, not FLUX 3 Max. A reader who searches
BFL's price list for "max" will land on the wrong model.

## Gaps

- The numeric price cells render client-side and were empty in both the Markdown (`*.md`) and HTML
  captures. This record therefore documents the table **structure** and the absence of a FLUX 3
  Max row, not the numbers. A browser-rendered capture would be needed for exact first-party rates.
- No statement anywhere on the page about partner-hosted variants or their pricing.

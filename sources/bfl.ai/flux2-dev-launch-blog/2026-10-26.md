# BFL official: FLUX.2 launch blog (FLUX.2 [dev] announcement)

- Origin: Black Forest Labs, "FLUX.2: Frontier Visual Intelligence",
  https://bfl.ai/blog/flux-2
- Evidence kind: official documentation (model-developer launch announcement)
- Publication date: November 25, 2025 (byline on page: "November 25, 2025 · 5 min read")
- Capture date: 2026-10-26
- Relevant models: FLUX.2 [dev] (primary); [pro], [flex], [max], [klein] for family context

## Captured content

### FLUX.2 [dev] announcement (verbatim)

> **FLUX.2 [dev]**: 32B open-weight model, derived from the FLUX.2 base model. The most
> powerful open-weight image generation and editing model available today, combining
> text-to-image synthesis and image editing with multiple input images in a single checkpoint.
> FLUX.2 [dev] weights are available on Hugging Face and can now be used locally using our
> reference inference code. On consumer grade GPUs like GeForce RTX GPUs you can use an
> optimized fp8 reference implementation of FLUX.2 [dev], created in collaboration with NVIDIA
> and ComfyUI. You can also sample Flux.2 [dev] via API endpoints on FAL, Replicate, Runware,
> Verda, TogetherAI, Cloudflare, DeepInfra. For a commercial license, visit our website.

### Family framing (verbatim excerpts)

> The FLUX.2 family covers a spectrum of model products, from fully managed, production-ready
> APIs to open-weight checkpoints developers can run themselves. The overview graph below shows
> how FLUX.2 [pro], FLUX.2 [flex], FLUX.2 [dev], and FLUX.2 [klein] balance performance, and
> control

> For open-weights image models, FLUX.2 [dev] sets a new standard, achieving leading performance
> across text-to-image generation, single-reference editing, and multi-reference editing,
> consistently outperforming all open-weights alternatives by a significant margin.

[pro] is described as "State-of-the-art image quality that rivals the best closed models";
[flex] as taking "control over model parameters such as the number of steps and the guidance
scale"; [klein] as "Open-source, Apache 2.0 model, size-distilled from the FLUX.2 base model"
and "coming soon" at the time of writing.

### Architecture and capability statements (verbatim)

> FLUX.2 builds on a latent flow matching architecture, and combines image generation and
> editing in a single architecture. The model couples the Mistral-3 24B parameter
> vision-language model with a rectified flow transformer.

> FLUX.2 now provides multi-reference support, with the ability to combine up to 10 images into
> a novel output, an output resolution of up to 4MP, substantially better prompt adherence and
> world knowledge, and significantly improved typography.

> All variants of FLUX.2 offer image editing from text and multiple references in one model.

> FLUX.2 can edit images at up to 4 megapixels while preserving detail and coherence.

### What's new (verbatim bullets, family-level)

- Multi-Reference Support: "Reference up to 10 images simultaneously with the best character /
  product / style consistency available today."
- Image Detail & Photorealism: "Greater detail, sharper textures, and more stable lighting".
- Text Rendering: "Complex typography, infographics, memes and UI mockups with legible fine text
  now work reliably in production."
- Enhanced Prompt Following, World Knowledge, and "Image editing on resolutions up to 4MP".

## Notes

- This is the only first-party page captured that dates the FLUX.2 family launch: **2025-11-25**,
  which is on or after the 2025-10-26 one-year cutoff. BFL's API changelog
  ([release notes](../../bfl.ai/release-notes/2026-10-26.md)) dates the same day to
  "[pro] and [flex] Launch" and does **not** mention [dev].
- The "32B" figure is stated by BFL here for [dev] specifically, which is stronger than the
  host-level "32B architecture" claims recorded on the [pro] page.
- The blog says [dev] is "derived from the FLUX.2 base model" but does not say which hosted
  sibling, if any, shares its weights. [pro], [flex] and [max] have no public weights
  ([pricing](../../bfl.ai/flux2-pricing/2026-10-26.md)), so [dev] is not a re-release of them.
- The commercial-licensing pointer ("For a commercial license, visit our website") is not
  expanded on this page; no price or process is given.

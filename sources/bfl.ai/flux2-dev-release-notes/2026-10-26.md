# BFL official: release notes — absence of any FLUX.2 [dev] entry

- Origin: Black Forest Labs, "Release Notes", https://docs.bfl.ai/release-notes
- Evidence kind: official documentation (changelog)
- Publication date: rolling; latest entry captured dated October 15, 2026
- Capture date: 2026-10-26
- Relevant models: FLUX.2 [dev] (absent); [pro], [flex], [max], [klein] for contrast

## Why this capture exists

The shared [release-notes record](../../bfl.ai/release-notes/2026-10-26.md) documents the
FLUX.2 [pro]/[flex] and [max] launch entries. This record captures a **negative** finding that
matters for the [dev] page: BFL's API changelog contains **no FLUX.2 [dev] entry at all**, even
though [dev] launched on the same day as [pro]/[flex].

## What this establishes

- The changelog is an **API** changelog: it documents models BFL serves. [dev] has no BFL
  endpoint ([pricing](../../bfl.ai/flux2-pricing/2026-10-26.md)), so its launch appears in the
  blog, the Hugging Face card and the GitHub repository instead of here.
- A reader who only watches BFL's changelog would not learn that [dev] exists. That is a
  documentation gap worth recording rather than a contradiction: no source claims [dev] is a BFL
  API model.

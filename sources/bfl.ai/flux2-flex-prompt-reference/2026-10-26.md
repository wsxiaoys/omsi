- Evidence kind: official documentation (prompting/limits guide)
- Publication date: not stated; page metadata `dateModified` 2026-10-01

- Relevant models: FLUX.2 [flex], captured from the "Model-Specific Quick Reference" section;
  [pro]/[max]/[klein]/[dev] appear where the guide groups them

## Captured content

### "FLUX.2 (all variants)" — reference images per API request (verbatim)

| Model | References | How you send them |
| --- | --- | --- |
| **FLUX.2 \[max]**, **\[pro]**, **\[flex]** | Up to **8** (up to **10** in the BFL Playground) | `input_image` … `input_image_8` |
| **FLUX.2 \[klein] 9B**, **\[klein] 4B** | Up to **4** | `input_image` … `input_image_4` |
| **FLUX.2 \[dev]** | Recommended max **6** | Set by your inference code (open weights) |

Immediately following, verbatim:

> FLUX.2 \[pro] has a 9 MP total limit for input plus output. At 1 MP output you can use up to 8
> reference images, at 2 MP output up to 7, and so on.

Language note (verbatim, all variants):

> FLUX.2 can be prompted in multiple languages, so you don't need to write in English. English
> prompts tend to produce the most precise results, since most of the training data is in English.

### "FLUX.2 [pro] & [max]" block (verbatim)

> * No negative prompts supported
> * Excellent typography: use quotation marks for exact text
> * Hex color codes in text-to-image prompts for brand colors, text, and gradients: *"The logo text
>   'ACME' in color #FF5733"*
> * JSON structured prompts supported for production workflows
> * Reference specific camera models for authentic photorealistic looks

> **Text tips**
>
> * **Front-load text descriptions** for better accuracy
> * **Keep text short**: long strings are harder to render accurately

## What this establishes

- The 8-via-API / 10-in-playground reference ceiling applies to [flex] as well as [pro] and
  [max], and the guide gives the exact field names (`input_image` … `input_image_8`).
- **The 9 MP input+output cap is documented for [pro] only.** The guide does not state an
  equivalent cap, or its absence, for [flex]. Whether [flex] inherits the same limit is
  unresolved by this page.
- The guide's typography-prompting advice is filed under "[pro] & [max]", not under [flex] —
  even though [flex] is the family member BFL markets as the typography specialist. The guide
  simply has no [flex]-specific prompting block on the capture date, so it neither confirms nor
  denies that the same text-rendering tips apply.

## Known gaps

- No recommended steps/guidance values for [flex] anywhere on this page.
- No [flex] entry in the "negative prompts" statement, so whether [flex] understands negative
  prompts is not documented first-party (Replicate says it does not; see the Replicate record).

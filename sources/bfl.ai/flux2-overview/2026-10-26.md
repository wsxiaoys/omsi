## Captured content (summary of the page as served on capture date)

The page presents FLUX.2 as a family spanning "sub-second inference" ([klein]) to "highest
quality" ([max]), with multi-reference editing and up to 4MP output. Capability highlights
listed on the page: multi-reference, photorealism and detail, grounding search, typography
and text, exact color control, and structured (JSON) prompting.

The page also states: "[pro] — **Top performance at affordable price.** The high quality,
production-grade image editing and generation model." and "[flex] — **Specialized for
typography.** Best for text rendering and preserving small details." [max] is described as
having "highest editing consistency... vast world knowledge" and grounding web search.

### Preview endpoints section (quoted)

> Preview endpoints are where our latest improvements land first.

| Endpoint | Description |
| --- | --- |
| `flux-2-pro-preview` | Our latest FLUX.2 [pro] model. |
| `flux-2-pro` | A fixed snapshot of FLUX.2 [pro]. This endpoint will not change, making it suitable for workflows that require reproducibility. |

> For most use cases, the preview endpoints (`flux-2-pro-preview`, `flux-2-klein-9b-preview`)
> give you the best results. Choose the non-preview endpoints when you need a pinned model [...]
> Both preview and non-preview endpoints share the same API contract — the request and response
> format is identical. Only the underlying model weights differ.

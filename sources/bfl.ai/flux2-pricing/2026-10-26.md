# BFL official: API pricing (FLUX.2 section)

- Origin: Black Forest Labs, "API Pricing", https://docs.bfl.ai/quick_start/pricing
- Evidence kind: official documentation (provider price list)
- Publication date: not stated on page
- Capture date: 2026-10-26
- Relevant models: FLUX.2 family, FLUX.1 legacy models

## Captured content (verbatim table)

> FLUX.2 uses **megapixel-based pricing** — cost scales with output resolution.

| Model | Text-to-Image | Image Editing | Best For |
| --- | --- | --- | --- |
| FLUX.2 [klein] 4B | from $0.014 | from $0.015 | Real-time, high volume |
| FLUX.2 [klein] 9B | from $0.015 | from $0.017 | Balanced quality/speed |
| FLUX.2 [pro] | from $0.03 | from $0.045 | Production workflows, fast turnaround |
| FLUX.2 [max] | from $0.07 | from $0.10 | Highest quality, grounding search |
| FLUX.2 [flex] | from $0.05 | from $0.10 | Fine-grained control, typography |
| FLUX.2 [dev] | Local only | Local only | Open weights, non-commercial (no hosted API) |

Related figures on the same page:

- Legacy table lists FLUX.1 Kontext [pro] $0.04/image, FLUX1.1 [pro] $0.04, FLUX1.1 [pro]
  Ultra $0.06, FLUX1.1 [pro] Raw $0.06, FLUX.1 Fill [pro] $0.05.
- A separate "Klein pricing explained" note says the first megapixel costs a flat rate and each
  additional MP adds to the total (e.g. 2MP Klein 4B = $0.014 + $0.001 = $0.015). This
  first-MP-plus-additional-MP structure is described explicitly only for Klein on this page;
  treat the [pro] "from" prices as starting points, not a full schedule.
- Fine-tuned endpoints (public beta) are billed at the same rate as their base endpoint;
  at capture only `flux-2-klein-9b-kv-finetuned` was listed, so no fine-tuned [pro] endpoint
  is documented here.

## Known gaps

- Exact per-megapixel schedule for [pro] (first MP vs. additional MP, and input MP charges)
  is not spelled out on this page. fal's page gives a more explicit schedule (see fal source).
- Prices change. This record is a capture of the page on 2026-10-26.

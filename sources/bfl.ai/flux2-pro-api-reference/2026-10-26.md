# BFL official: FLUX.2 [pro] API reference (parameters)

- Origin: Black Forest Labs, "Generate or edit an image with FLUX.2 [pro]",
  https://docs.bfl.ai/api-reference/models/generate-or-edit-an-image-with-flux2-[pro]
  (OpenAPI: https://api.bfl.ai/openapi.json, operation `POST /v1/flux-2-pro`)
- Evidence kind: official documentation (API schema)
- Capture date: 2026-10-26
- Relevant models: FLUX.2 [pro] (endpoint `flux-2-pro`); same schema for `flux-2-pro-preview`

## Captured content

The endpoint summary describes [pro] as "the recommended default model for image editing and
generation. Supports text-to-image and image-to-image editing workflows."

Request schema `Flux2Inputs` fields observed:

| Field | Notes |
| --- | --- |
| `prompt` | required |
| `input_image` .. `input_image_8` | up to 8 reference inputs (fields present in schema) |
| `seed` | optional, for reproducibility ("Optional seed for reproducibility.") |
| `width`, `height` | integers, minimum 64, default 0 (0 = model default) |
| `safety_tolerance` | 0–7, default 2, "0 the strictest"; approved maximum depends on route and organization; unapproved levels return 422 |
| `output_format` | default `jpeg` |
| `disable_pup` | "Disable automatic prompt upsampling for this request. FLUX.2 [pro] and [max] apply prompt upsampling by default; set this to true to generate from your prompt exactly as written." |
| `webhook_url`, `webhook_secret` | async delivery options |

There are no `steps` or `guidance` parameters in the [pro] schema — consistent with [pro]
being a fixed-configuration endpoint.

## Known gaps

- Aspect-ratio presets and the numeric maximum resolution are not in the schema excerpt
  captured here; resolution limits come from other pages (4MP output).
- No stated input-megapixel cap in this schema; Replicate's page states a 9MP total input
  limit on the API.

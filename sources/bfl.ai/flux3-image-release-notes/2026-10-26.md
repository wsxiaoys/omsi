## Captured content

### July 23, 2026 — Announcing FLUX 3

> FLUX 3 is our new multimodal foundation model: one model jointly trained across image, video, and
> audio, built toward real-world visual intelligence.

Rollout (verbatim): "Capabilities become available in phases, each after an early access period:
video generation and editing first, action prediction with selected partners, image synthesis and
editing, and open-weight access to a multimodal backbone."

Image is listed as a capability of the same model, not a separate release: "Image synthesis and
editing — from the same underlying model".

### August 4, 2026 — FLUX 3 — Video With Synchronized Audio

> FLUX 3 is our first video model: one model trained across image, video, and audio, generating
> video with synchronized sound. Available now as a preview.

Endpoint `POST /v1/flux-3-video`. This is the first FLUX 3 endpoint to ship; the image capability
follows two months later.

### October 1, 2026 — FLUX 3 Image

> FLUX 3 Image gives you maximum control over every pixel. Generate an image from a prompt, edit
> specific parts of an image, and combine up to ten references, all through one endpoint.

Key features (verbatim bullets):

> * **Bounding boxes in the prompt:** place every element of a layout, such as a headline, a face in
>   a crowd, or each panel of a grid. Add a JSON list of boxes to the end of `prompt`; there is no
>   separate parameter
> * **Pixel-exact local edits:** mark the element to change and keep the rest of the image as it
>   was. Recolor, replace, move, resize, or remove several elements in one request
> * **Up to ten references:** name each image by its position in the prompt to restyle an image or
>   combine references into a new composition
> * **Up to 4K output:** `resolution` goes from `768sq` for fast previews to `4k` (about 16
>   megapixels), at 15 aspect ratios
> * **One endpoint:** the prompt decides whether to generate or edit. There is no `mode` field

Pricing, verbatim table ("Per image, by `resolution`"):

| `resolution` | Price |
| --- | --- |
| `768sq` | $0.041 |
| `1k` | $0.048 |
| `2k` | $0.100 |
| `4k` | $0.607 |

Endpoint: the entry links the FLUX 3 Image API reference (i.e. `POST /v1/flux-3-image`).

### October 15, 2026 — FLUX 3 Image Klein

> FLUX 3 Image Klein is a 5.6B parameter version of FLUX 3 Image with open weights. It supports the
> same features: text to image, image editing, multi reference, and bounding boxes.

Verbatim bullets relevant to identity:

> * **Same request as FLUX 3 Image:** `prompt`, `images`, `aspect_ratio`, `resolution`, and the
>   bounding box format are unchanged. A FLUX 3 Image request runs on Klein by switching the
>   endpoint
> * **Two variants:** Klein (Distilled) runs 16 steps at CFG 1 for fast inference. Klein Base runs
>   50 steps at CFG 3.5 and is the model for fine-tuning and LoRA training
> * **Open weights:** both variants are on Hugging Face under the FLUX Kommunity License and run on
>   consumer GPUs, down to an RTX 3090

Klein pricing, verbatim table ("Per image, by `resolution`. Text to image and image editing cost
the same."): `768sq` $0.008 · `1k` $0.009 · `1.5k` $0.011 · `2k` $0.014 · `4k` $0.036.

## What this establishes

- **Launch date for the page: 2026-10-01.** Well inside the one-year window (on or after
  2025-10-26).
- The FLUX 3 family shipped image capability as a later phase of a model announced 2026-07-23 and
  first served as video on 2026-08-04.
- The first-party price ladder is per image by resolution tier, and the 4K step is 12.6× the 1K
  price ($0.607 vs $0.048) — pricing is not linear in megapixels.
- Klein is a **5.6B open-weights sibling that accepts the same request**, priced roughly 5× lower.
  Its existence is the boundary of "FLUX 3 Image weights are private".

## Gaps

- The October 1 table lists no `1.5k` price, although `1.5k` is a valid `resolution` value in the
  API schema and Klein prices `1.5k` explicitly. The missing tier is priced at **$0.07** on the
  pricing page, captured separately in `../flux3-image-pricing/2026-10-26.md`; the release notes
  simply omit it.
- The notes do not mention FLUX 3 Max at all, and no FLUX 3 Max entry appears in this changelog.
- No benchmark, latency, or quality number accompanies any of these entries.

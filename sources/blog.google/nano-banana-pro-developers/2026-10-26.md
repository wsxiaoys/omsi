## Captured content

### Release stage (verbatim)

> Today, we're releasing Nano Banana Pro (Gemini 3 Pro Image), a higher-fidelity model built on
> Gemini 3 Pro for developers to access studio-quality image generation.

> This state-of-the-art image generation and editing model is starting to roll out in paid
> preview to build a new wave of intelligent, multimodal applications with the Gemini API in
> Google AI Studio and Vertex AI for enterprises.

"Paid preview" on 2025-11-20 is the first-party statement of the release stage; the Gemini API
changelog dates `gemini-3-pro-image-preview` to the same day and the GA ID to 2026-05-28.

### Capability claims (verbatim)

> This model unlocks high-fidelity images with higher accuracy in text rendering and robust world
> knowledge, supercharged by the model's ability to use grounding with Google Search to retrieve
> data based on the user's prompt.

> Gemini 3 Pro Image excels on Text to Image AI benchmarks.

> With 2K and 4k resolution available, you can ensure outputs meet resolution standards required
> for professional production.

> Achieve consistent resemblance for up to five individuals, integrate six high-fidelity shots, or
> blend as many as fourteen standard inputs into a single, polished ad.

> With Gemini 3 Pro Image, we've removed the barrier between image generation and localization
> logic. This advanced model grasps the semantic context of an image, enabling effortless language
> changes on elements like menus, signs, or documents utilizing image-to-image generation keeping
> original artistic style or layout.

> If you're building advanced tools that require precision, Gemini 3 Pro Image gives you control
> over the physics (lighting, camera, focus, color grading) and composition of the image to ensure
> professional-quality outputs.

> Use Gemini 2.5 Flash Image for faster, lower cost image generation, or 3 Pro Image for higher
> quality image generation, with higher cost and latency.

The benchmark sentence is backed on the page by a single image, alt text "Gemini 3 Pro Image Text
to Image AI benchmark bar chart compared to other leading competitors". No numbers, axes, dataset
names, or methodology appear in the page text, and the chart was not read.

### Reference-image budget (verbatim, the clearest first-party statement)

> Achieve consistent resemblance for up to five individuals, integrate six high-fidelity shots, or
> blend as many as fourteen standard inputs

This is three separate allowances — 5 characters, 6 high-fidelity objects, 14 inputs total — and it
is the statement the Gemini API image-generation guide's reference table matches (6 object + 5
character + 3 style = 14). The launch post's "up to 14 images and ... up to 5 people" and the
DeepMind product page's "fidelity of up to fourteen objects" both state different splits.

### Ecosystem and provenance (summary)

- Rollout to Google Antigravity so coding agents can produce UI mockups and visual assets.
- Integrations named: Adobe and Figma.
- Demo apps published in Google AI Studio (logo-plus-product mockups, comic-book generator,
  infographic generator).
- "we have integrated SynthID digital watermarks directly into every image created or edited with
  Gemini 3 Pro Image".

## Gaps

- No price, token limit, latency figure, knowledge cutoff, or shutdown date.
- The benchmark claim cannot be checked from the text: it is a bar chart with no values, and the
  competitors are not named in the prose.
- "2K and 4k resolution available" omits 1K; the Cloud model card and the API docs list 1K, 2K and
  4K.
- No statement of which snapshot the "paid preview" served, or whether preview and GA weights
  match.
- The post predates Nano Banana 2 (2026-02-26) and Nano Banana 2.1 (2026-10-06), so its
  "higher-fidelity"/"higher quality" framing compares only against Gemini 2.5 Flash Image and is
  not a current statement about the 2026 family.

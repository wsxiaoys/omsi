## What this establishes

- Fibo 2's default first-party pipeline is **two models, not one**: a VLM "bridge" that writes the
  VGL, and Fibo 2 that renders it. The standard bridge is named as **Gemini 2.5 Flash**, a
  third-party model; the privacy-oriented alternative is BRIA's own open-source FIBO-VLM with the
  smaller Fibo Lite model.
- A request through `/v2/image/generate` with a plain prompt therefore depends on that bridge. Only
  requests that pass a `structured_prompt` (or the Fibo Lite pipeline) stay inside BRIA's models.
- Fibo 2 is positioned as the high-fidelity tier and Fibo Lite as the speed/on-prem tier of the
  same VGL family — a tier split, not a version split.
- IP handling is described as producing "generic outputs" plus a warning flag; this is a documented
  behaviour claim, not an observed test.

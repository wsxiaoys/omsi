### Generate

> Text in, image out, with the [VGL](https://docs.bria.ai/vgl) behind it returned on every result.

Example request shown on the page:

```bash
curl -X POST https://engine.prod.bria-api.com/v2/image/generate \
  -H "api_token: $BRIA_API_TOKEN" -H "Content-Type: application/json" \
  -d '{"prompt": "A panoramic view of a neon-lit Tokyo street at night in the rain, glowing pink
  and cyan signs reflected in the wet asphalt, people crossing with clear umbrellas",
  "aspect_ratio": "21:9"}'
```

Three documented workflows: text prompt; prompt + reference image ("inspire"); and "Refine: the
first image's VGL with the tank top changed to hot pink, same seed".

### Edit

> Say what to change. Fibo 2 changes that and keeps the rest of the image.
>
> Combine up to four images in one edit, numbered in the order you send them.

The worked example combines three images (boulder, bottle, wordmark) into a perfume poster via
`POST /v2/image/edit` with an `images` array, an `instruction`, `aspect_ratio: "1:1"` and
`seed: 202`. Single-image example: *"Change the car's paint to glossy cherry red, keep everything
else the same"*.

### 21 aspect ratios

> Fibo 2 adds 12 ratios to the nine you know, for generation and for edits with two or more
> reference images.

The twelve new values are listed as `16:10 10:16 2:1 1:2 21:9 9:21 3:1 1:3 4:1 1:4 5:1 1:5`.

### Four photographic styles

> Kodak film, Hard flash, Hazy dreamy and Rough realism. Pass one as `style` with a text prompt and
> Fibo 2 gives the image that look.
>
> The values are `kodak_film`, `hard_flash`, `hazy_dreamy` and `rough_realism`. A style applies to
> generation from a text prompt, so it doesn't combine with `structured_prompt` or reference
> images.

## What this page establishes

- Bria's own name for the model is **Fibo 2** (the chart captions and Bria's later pages write
  "Fibo 2.0"; Hugging Face repo IDs are `Fibo-2.0-dev` and `Fibo-2.0-edit-turbo`).
- Fibo 2 replaces the model behind the existing `/v2/image/generate` and `/v2/image/edit`
  endpoints — "Same API, nothing to change in your code". There is no new version-scoped path.
- Both halves ship open weights, under non-commercial terms (see the huggingface.co record).
- Vendor-claimed capabilities: VGL returned on every result, up to 4 images in one edit, 21 aspect
  ratios, 4 named photographic styles, 1 MP-class output.
- The ranking claims are vendor transcriptions of Artificial Analysis charts. The independent
  capture of the same boards is in `sources/artificialanalysis.ai/fibo-2/2026-10-26.md`; the Elo
  figures there are 1088 (editing) and 1039 (text-to-image), one point above Bria's captions.

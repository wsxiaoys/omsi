# ByteDance Seed site: no Seedream 5.0 Flash page or launch post

- Origin: ByteDance Seed (seed.bytedance.com) — `https://seed.bytedance.com/sitemap.xml`,
  the blog index `https://seed.bytedance.com/en/blog_list/visual`, and route probes on
  `https://seed.bytedance.com/en/seedream-5-0-flash`,
  `https://seed.bytedance.com/en/seedream5-flash`,
  `https://seed.bytedance.com/en/seedream-5-flash`
- Evidence kind: first-party negative check (absence of a vendor model page / launch post), not a
  vendor statement
- Publication date: not applicable. Capture date 2026-10-26.
- Relevant models: Seedream 5.0 Flash (absent). Seedream 5.0 Pro and Seedream 5.0 Lite are present
  and serve as controls.
- Capture type: URL inventory and HTTP responses, transcribed.

## Sitemap

`sitemap.xml` returned HTTP 200 with **35 `<loc>` entries**. The only Seedream entries are:

- `https://seed.bytedance.com/en/seedream-5-0-pro`
- `https://seed.bytedance.com/en/seedream-5-0-lite`

There is no `flash` URL anywhere in the sitemap (case-insensitive search: 0 matches). For comparison,
the Pro page record documents that a probe of the invented URL `/en/seedream5` returns HTTP 200 with
an empty body
([Pro product page](../seedream-5-pro-model-page/2026-10-26.md)), so a 200 status alone means
nothing on this site.

## What this establishes

- Flash has **no Seed-site model card and no launch blog post**, unlike Pro (2026-07-08 post) and
  Lite (2026-02-13 post). Its first-party documentation is the cloud platforms' API docs
  (Volcengine Ark, BytePlus ModelArk), not developer-facing marketing on the Seed site.
- Flash is therefore not discoverable from the vendor's own research/publication index, which is
  consistent with it being a hosted-only efficiency tier rather than a research milestone.

## Gaps

- **This is a negative inventory check, not proof of absence.** The sitemap lists 35 URLs and could
  omit a route, and the site is client-rendered, so an unlisted Flash page cannot be ruled out by
  fetching it. The blog index is the stronger signal: it is server-rendered and enumerates posts.
- The blog index shows 12 posts; whether it paginates or truncates was not verified.
- No first-party technical report, benchmark, or model card for Flash was found on this domain.

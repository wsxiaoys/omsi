## Path check — the URL this page is *not* at

`https://seed.bytedance.com/en/seedream5` returns **HTTP 200 with no content**: the HTML carries
the catch-all route `(locale$)/(path)/page` instead of a page-specific loader key, the document
`<title>` stays the site default `ByteDance Seed`, and the body is an empty `<div id="root">`.
`/en/seedream5_0` behaves the same way. The site's own `sitemap.xml` lists exactly two Seedream 5
pages: `seedream-5-0-pro` and `seedream-5-0-lite`.

So `/en/seedream5` is a **soft 404**, not a model page. The first-party model page for the full
tier is `/en/seedream5_0_pro`, and the tier is named **Seedream 5.0 Pro**. No bare "Seedream 5.0"
model page exists on this site.

## Documented capability blocks (verbatim `title_en` / `description_en`)

1. **High-Density Infographics** — "Master complex reasoning and information organization. Can
   generate text-rich images for education, professional, and other specialized scenarios."
2. **Interactive Editing** — "Accurately responds to spatial annotations and sketch-based
   guidance. Supports layer separation, which unlocks more creative possibilities."
3. **Photographic Visual Quality** — "Recreates authentic physical lighting, shadows, and human
   skin textures, significantly enhancing photographic realism."
4. **Native Multilingual Generation** — "Natively supports a dozen widely used languages for
   prompting and image generation, making it ideal for international creative workflows."

Each block is a set of showcase images with the prompt that produced them. The prompts are
substantive and are the most concrete capability evidence on the page — for example a 4×4
sixteen-panel cinematic storyboard, an academic infographic poster naming a specific layout, an
"RPG character interface" with dense stat columns and a minimap, and an annotation-driven edit
("Perform precise edits based on the 6 purple boxes and handwritten English annotations in the
original image").

## Known gaps

- Showcase images are the developer's own curated outputs. They establish that the model *can*
  produce these results, not how often, at what cost, or how it handles uncurated prompts.
- The largest showcase image dimensions observed in the page data are 3136×1344, 2848×1600 and
  2496×1664 (about 4.2–4.6 MP). Whether those are the model's native outputs or retouched
  marketing assets is not stated.
- The "advanced reasoning" phrasing in the description is not explained anywhere on the page; it
  is not tied to a documented parameter or a described thinking mode.

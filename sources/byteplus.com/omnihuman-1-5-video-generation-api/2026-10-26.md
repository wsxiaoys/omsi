## Service description (verbatim)

> OmniHuman 1.5 generates video effects matching the input image based on a single image, text prompt,
> and audio file uploaded by the user.

The "Restrictions" table repeats the overview page exactly: image JPG/PNG/JFIF, <5 MB, <4096×4096;
audio "must be less than 60 seconds" or the task fails; prompt limited to Chinese, English, Japanese,
Korean, Spanish (Mexican), Indonesian.

## Transport: asynchronous task submission

| Field | Value |
| --- | --- |
| Interface address | `https://cv.byteplusapi.com` |
| Method | `POST`, `Content-Type: application/json` |
| Submit | `?Action=CVSubmitTask&Version=2024-06-06` |
| Query | `?Action=CVGetResult&Version=2024-06-06` |
| Cancel | `?Action=CVCancelTask&Version=2024-06-06` |
| Header | "The fixed values for this service are: Service=cv, Region=ap-singapore-1" |
| Auth | HMAC-SHA256 `Authorization` header (`AccessKeyId` / `ShortDate` / `Region` / `Service`) |

This is not a synchronous or streaming endpoint: submit returns a `task_id`, and the result must be
polled or delivered by callback.

## Request body parameters (verbatim descriptions)

| Name | Type | Required | Description |
| --- | --- | --- | --- |
| `req_key` | string | Yes | "Service identifier: realman_avatar_picture_omni15_cv" |
| `image_url` | string | Required | "URL of the portrait image" |
| `mask_url` | string | Optional | "List of mask image URLs to specify a specific subject in the image to speak. Separate multiple mask image URLs with semicolons (;) if there are any." |
| `audio_url` | string | Required | "URL of the audio file" |
| `seed` | int | Optional | "Random seed (used as the basis for determining the initial diffusion state). Default value: -1 (random)." |
| `prompt` | string | Optional | "Prompt, only supports Chinese, English, Japanese, Korean, Mexican Spanish, and Indonesian" |
| `pe_fast_mode` | bool | Optional | "When enabled, it will speed up generation by sacrificing some effects. Default Value: false" |
| `output_resolution` | int | Optional | "Allowed values for output video resolution: 720 or 1080"; "Default: 1080" |
| `callback_url` | string | Optional | POST on terminal state; "retry the callback three times at 1-second intervals, with a 15-second timeout for each attempt" |
| `callback_auth_info` | string | Optional | "Reserved fields for authentication purposes" |

`mask_url` is a single semicolon-separated string, not an array. Although the field accepts several
masks, the multi-character guide states that one audio clip can only drive one character (or all of
them at once) — see the multi-character demo record.

## Task lifecycle and result

`status` values, verbatim: `in_queue` ("Task submitted"), `generating` ("Task consumed and being
processed"), `done`, `not_found` ("the task does not exist or has expired (12 hours)"), `expired`,
`canceled`.

The result payload is `data.resp_data` as a JSON **string** containing `video_url` (plus progress and
timing fields). The page notes the video link is "valid for 1 hour".

## Summary

BytePlus sells OmniHuman 1.5 as a signed, region-pinned (`ap-singapore-1`) asynchronous Vision AI
task: submit with `realman_avatar_picture_omni15_cv`, poll `CVGetResult` or receive a callback, cancel
with `CVCancelTask`. Inputs are one image URL, one audio URL, an optional prompt, an optional mask
string, an optional seed, a `pe_fast_mode` speed switch and a 720/1080 `output_resolution`.

## Gaps

- No page-level "Last updated" stamp on this document, unlike the overview.
- No rate limit, queue-time, or per-account concurrency statement (the overview gives concurrency 1).
- `seed` is documented here but is not exposed by either captured host; whether the hosts forward it
  is unknown.
- `mask_url` plural semantics are unclear: the docs never show a working multi-mask example and the
  multi-character guide uses exactly one mask per call.
- No frame rate, no aspect-ratio rule, no statement of what happens to images whose aspect ratio is
  extreme.

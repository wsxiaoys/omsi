## Service description (verbatim)

> OmniHuman 2.0 generates video effects matching the input image based on an image, text prompt, and
> audio file uploaded by the user.

## Summary

OmniHuman 2.0 is a genuinely different input envelope, not a relabelled 1.5: the audio ceiling moves
from 60 s to 300 s, the image formats and size caps widen substantially, and the price falls. The
prompt-language list and the transport layer are identical, which is consistent with 2.0 being a new
generator behind the same Vision AI task API.

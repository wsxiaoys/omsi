# BytePlus ModelArk: Create video generation task API (Seedance 2.0 parameters)

- Origin: BytePlus (ByteDance) ModelArk API reference, "Create video generation task",
  <https://docs.byteplus.com/en/docs/modelark/create-video-generation-task-api>
- Evidence kind: official API reference (vendor documentation)
- Publication date: none stated; living document, capture date 2026-10-26
- Capture date: 2026-10-26
- Relevant models: Dreamina Seedance 2.0 / 2.0 fast / 2.0 mini (the page also documents Seedance 2.5,
  1.5 pro and 1.0; only 2.0-family values are transcribed)
- Capture type: parameter documentation quoted verbatim and transcribed.

## Parameters that matter for the 2.0 family

**`resolution`** (verbatim):

> Dreamina Seedance 2.5 1080p output and Dreamina Seedance 2.0 4K output both use 10-bit color depth
> and H.265/HEVC encoding.
>
> - Dreamina Seedance 2.0: Default 720p; supports 480p, 720p, 1080p, and 4k.
> - Dreamina Seedance 2.0 fast: Default 720p; supports 480p and 720p.
> - Dreamina Seedance 2.0 mini: Default 720p; supports 480p and 720p.

**`duration`** (verbatim):

> Generated video duration in seconds. Specify either duration or frames; frames takes precedence. …
> Dreamina Seedance 2.0 series: Default 5; supports [4, 15] or -1.

(`-1` means the model chooses the duration; the retrieve-task response returns an integer duration
computed as total frames / 24, rounded down.)

**`ratio`** (verbatim):

> Supported values: 16:9, 4:3, 1:1, 3:4, 9:16, 21:9, and adaptive. … Dreamina Seedance 2.0 series:
> Default adaptive.

**`generate_audio`** (verbatim):

> Default: true … true: The video output by the model includes synchronized audio. The model will
> automatically generate matching human voice, sound effects and background music based on the text
> prompt and visual content. It is recommended to put dialogue content in double quotes …
> **Note: All generated videos with audio are mono, regardless of the number of channels of the input
> audio.**

**`watermark`** (verbatim): "Default: false … true: An AI Generated watermark will be displayed in
the lower right corner of the generated video."

**`service_tier`** (verbatim): "flex: Offline inference mode, with higher TPD quota … priced at 50%
of online inference … **Dreamina Seedance 2.5 and Dreamina Seedance 2.0 series models are not
currently supported.**"

**`priority`**: integer 0–9, supported by Seedance 2.5 and the 2.0 series; affects queue position only.

**`seed`**: documented as supported by "Seedance 1.5 pro, Seedance 1.0 pro, Seedance 1.0 pro fast" —
the 2.0 series is **not** in the supported list.

**`frames`**: documented for "Seedance 1.0 pro, Seedance 1.0 pro fast" only; the 2.0 series is not in
the supported list. The formula `frames = duration × frame rate (24)` and the returned-duration rule
still imply the family runs at **24 fps**.

**`camera_fixed`**: supported by 1.5 pro / 1.0 pro / 1.0 pro fast only.

## Input requirements (2.0 family)

- Images: 1 for first-frame I2V, 2 for first+last frame, 1–9 for omni reference; jpeg/png/webp/bmp/
  tiff/gif (heic/heif from 1.5 pro onward); aspect ratio 0.4–2.5; width and height 300–6000 px;
  single image < 30 MB; request body ≤ 64 MB.
- Videos: "Dreamina Seedance 2.0 series: Each video must be 2–15 seconds long. You can submit up to 3
  reference videos with a total duration of no more than 15 seconds." Formats mp4/mov, frame rate
  [24, 60] fps for input, each ≤ 200 MB.
- Audio: "Dreamina Seedance 2.0 series: Each audio clip must be 2–15 seconds long. You can submit up
  to 3 reference audio clips with a total duration of no more than 15 seconds." wav/mp3, ≤ 15 MB
  each.

## Model capability summary on this page (verbatim)

> Dreamina Seedance 2.0 series (video with audio / silent video)
>
> - Omni reference-to-video: Input reference images (0–9), reference videos (0–3), reference audio
>   clips (0–3), and an optional text prompt to generate one target video. Audio-only input is not
>   supported; include at least one reference image or video. The models support generating new
>   videos, editing videos, and extending videos.
> - Image-to-video (first and last frames) …
> - Image-to-video (first frame) …
> - Text-to-video …

Also: "Image-to-video (first frame), image-to-video (first and last frames), and omni
reference-to-video … are mutually exclusive scenarios and cannot be mixed."

## Gaps

- The page does not state output frame rate directly; 24 fps is inferred from the `frames` formula and
  the returned-duration rule, both of which are 1.0-specific parameters. No first-party page states
  the output fps for Seedance 2.0 outright.
- No output bitrate, codec default, or file-size limits for the generated video are documented here.
- The page states the 30-day trusted-outputs window for face-containing assets ("original
  face-containing videos generated by these models under your account within the past 30 days"), but
  the companion portrait guide that lists the full workaround process was not captured.

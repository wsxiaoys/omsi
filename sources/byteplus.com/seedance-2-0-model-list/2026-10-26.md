- Capture type: model IDs and rate-limit cells extracted from the page's embedded document payload;

## Model IDs on the international platform

| Model ID | Family |
| --- | --- |
| `dreamina-seedance-2-0-260128` | Dreamina Seedance 2.0 |
| `dreamina-seedance-2-0-fast-260128` | Dreamina Seedance 2.0 fast |
| `dreamina-seedance-2-0-mini-260615` | Dreamina Seedance 2.0 mini |
| `dreamina-seedance-2-5-260628` | Dreamina Seedance 2.5 (context: the current flagship) |

The IDs carry the same date suffixes as the Volcengine (China) IDs (`doubao-seedance-2-0-260128`,
`doubao-seedance-2-0-fast-260128`, `doubao-seedance-2-0-mini-260615`) with a different product prefix
(`dreamina-` international, `doubao-` China). `260128` = 2026-01-28 and `260615` = 2026-06-15 are the
checkpoint date suffixes; the vendor does not publish what changed between them.

## Rate-limit cells found for the 2.0 rows

- `dreamina-seedance-2-0-260128`: max RPM "Non-4K enterprise: 600 / Non-4K individual: 180 / 4K, all
  users: 15"; max concurrency "Non-4K enterprise: 10 / Non-4K individual: 3 / 4K, all users: 1".
- `dreamina-seedance-2-0-fast-260128`: concurrency "Enterprise: 10 / Individual: 3".
- `dreamina-seedance-2-0-mini-260615`: present in the same table; its rate-limit cells were not
  isolated from the payload.

These match the Volcengine (China) tutorial's limits for the same models, which is expected if both
platforms front the same service.

## Region availability note (verbatim, from the page's tip block)

> Region availability: Currently, all the models listed in Model list are supported in the
> ap-southeast-1 region. The seed-2-0 and seedream-5-0-lite models are also supported in the eu-west-1
> region.

Read carefully, this says **only** the text model `seed-2-0` (and `seedream-5-0-lite`) is additionally
available in `eu-west-1`. No Seedance video model is listed for the EU region.

## Extraction caveat

The page's tables are rendered client-side from an embedded document payload. Model IDs and the rate
limit strings above appear as complete cells and are quoted as found; the surrounding capability
columns could not be re-ordered reliably, so this record does **not** claim which capability flags the
table sets for each Seedance row. Capability facts are taken from the tutorial and API records
instead.

## Gaps

- No publication date; the catalogue is a living page.
- The capability columns (which tasks each model supports) were not captured in reliable order.
- The page does not state which regions serve the video models beyond the tip above; the separate
  Region availability page says the EU region supports only `seed-2-0-lite`.

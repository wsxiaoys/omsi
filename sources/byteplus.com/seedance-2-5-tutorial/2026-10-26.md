## Summary (verbatim)

> Dreamina Seedance 2.5 … is a next-generation video creation model with major improvements in
> long-form storytelling, omni reference support, and editing. It can generate up to 30 seconds of
> video in one request, extend videos over multiple rounds, accept up to 50 omni reference assets per
> request, and perform precise timestamp-based editing. Improved visual quality produces results with
> a more realistic, cinematic look.

## Two capabilities new relative to 2.0 (verbatim)

> Seedance 2.5 increases the upper limit for assets in a single input to 50 (30 images + 10 video
> clips + 10 audio clips). You can freely combine multimodal assets such as images, videos, and audio
> to achieve richer creative expression. In addition, **Seedance 2.5 newly supports generating videos
> with pure audio references, without requiring image or video assets.**

> Seedance 2.5 can intelligently control the output aspect ratio and duration when `ratio` is set to
> `adaptive` and `duration` is set to `-1`.

The pure-audio statement is the clearest first-party confirmation that 2.5 relaxes a 2.0 restriction:
on 2.0, audio references had to be accompanied by an image or a video.

## Task types and constraints

Identical structure to the China platform: text-to-video; first-frame / first-and-last-frame;
omni reference-to-video split into reference-to-video, video editing and video extension. Editing
requires `ratio=adaptive`, `duration=-1`, a 4–30 s reference video and an edit keyword in the prompt;
extension requires `ratio=adaptive` and an extension keyword. `omni_reference_task_type`
(`auto`/`reference`/`edit`/`extend`) moves validation earlier, and a mismatch between the declared and
inferred task type still fails asynchronously.

## Output specification (verbatim)

> Default value: `720p`. Optional values: `480p` (8-bit color depth), `720p` (8-bit color depth),
> `1080p` (10-bit color depth).

> Dreamina Seedance 2.5 1080p output uses 10-bit color depth and H.265/HEVC encoding.

No 4K option is listed anywhere on the page — unlike the 2.0 series tutorial, which documents 4K for
the standard tier.

- `output_format`: `mp4` (default) or `mov` (H.264 + yuv444p + PCM, for colour-critical post).
- Duration `[4, 30]` or `-1`; editing tasks accept only `-1`; the edited source must be 4–30 s.
- Aspect ratios 21:9, 16:9, 4:3, 1:1, 3:4, 9:16, adaptive; editing, extension and first/first-last
  frame accept only `adaptive`.
- `watermark: true` burns an "AI generated" mark into the lower-right corner; default off.

## Draft mode (verbatim)

> Draft mode is a two-step video generation method that lets you quickly validate the result before
> generating a high-quality final video.

> When generating a final video from a Draft video, Dreamina Seedance 2.5 currently supports only
> 1080p output. Setting another resolution causes an error. … A Draft video task ID is valid for seven
> days … Step 1 and Step 2 tasks are billed independently.

## Languages (verbatim)

> Seedance 2.5 natively supports prompt input and videos with audio generation in multiple languages,
> including Chinese, English, Spanish, Indonesian, Malay, Thai, Arabic, Portuguese, Vietnamese,
> Japanese, and Korean.

## Input limits (transcribed)

- Images: URL / Base64 / asset ID; jpeg, png, webp, bmp, tiff, gif, heic, heif; aspect 0.4–2.5; each
  side 300–6000 px; ≤ 30 MB each; body ≤ 64 MB.
- Videos: mp4/mov; 480p–4K; **2–30 s each for non-editing tasks, 4–30 s for editing**; ≤ 10 clips,
  combined ≤ 30 s; ≤ 200 MB each; aspect 0.4–2.5; total pixels 407,696–8,295,044; **24–60 fps in**.
- Audio: wav/mp3; 2–30 s each; ≤ 10 clips, combined ≤ 30 s; ≤ 15 MB each.
- Retention: task records 7 days; output URL 24 hours with a 100-download cap.
- Rate limits: RPM and max concurrency per primary account, same model regardless of version
  (numeric cells are in the page's rendered table, not the prose payload — see Gaps).

## Restrictions (verbatim)

> Seedance 2.5 does not support directly uploading reference images or videos containing real human
> faces.

Workarounds: reuse of this account's own model outputs from the last 30 days, preset digital
characters, authorised real-person assets.

- Origin: BytePlus (ByteDance), ModelArk documentation, "Image generation API",

- Evidence kind: official vendor documentation (API reference)
- Publication date: none stated; living documentation page
- Capture date: 2026-10-26
- Relevant models: Seedream 5.0 Lite, plus the sibling tiers whose differing parameter support is

- Capture type: request/response parameter reference quoted verbatim where it names Lite; the

## `size` — Seedream 5.0 Lite (verbatim)

> **Seedream 5.0 lite**
>
> Specify the output image dimensions. Two methods are available, but they cannot be used at the
> same time.
>
> - Method 1: Specify the resolution of the generated image, and describe its aspect ratio, shape,
>   or purpose in the prompt using natural language. You let the model determine the width and
>   height.
>   - Optional values: `2K`, `3K`, `4K`
> - Method 2: Specify the width and height of the generated image in pixels:
>   - Default value: `2048x2048`
>   - Total pixels range: [`2560x1440`(3,686,400), `4096x4096`(16,777,216)]
>   - Aspect ratio range: [1/16, 16]

The documented aspect-ratio-to-pixels table for Lite (verbatim values):

By contrast the sibling tiers on the same page are documented as: Seedream 5.0 pro / flash
`1K`, `1.5K`, `2K` (pixel range 921,600–4,624,220); Seedream 4.5 `2K`, `4K`; Seedream 4.0 `1K`,
`2K`, `4K`. Lite is therefore the only Seedream 5.0 tier documented at 3K and at 4K output, and
the only one whose native pixel floor is 2560×1440.

## Reference images (verbatim)

> Seedream 5.0 pro and Seedream 5.0 flash support up to 10 reference images. Seedream 5.0 lite,
> 4.5, and 4.0 support up to 14 reference images.

Input-image requirements (verbatim, image-generation scenario):

> - Image format: jpeg, png, webp, bmp, tiff, gif, heic, or heif
> - Aspect ratio (width / height): [1/16, 16]
> - Width and height (px): > 14
> - Size: Up to 30 MB
> - Total pixels: [196, `6000×6000` (36,000,000)]

## Prompt (verbatim)

> **Prompt language support**: All models support Chinese and English prompts.
>
> `Seedream 5.0 pro` and `Seedream 5.0 flash` also support Russian, Arabic, Filipino, Thai,
> Turkish, Korean, Malay, Spanish, Portuguese, Indonesian, French, German, Vietnamese, and
> Japanese.

> **Prompt length recommendation**: Use no more than 300 Chinese characters or 600 English words.
> Excessively long prompts may scatter information, causing the model to overlook details and
> focus only on major elements, which can result in missing details in the generated image.

## Parameters with explicit per-model support lists

| Parameter | Verbatim supported-model list | Lite supported? |
| --- | --- | --- |
| `layer_decomposition` | "Seedream 5.0 pro", "Seedream 5.0 flash" | no |
| `background` (transparent alpha) | "Seedream 5.0 pro", "Seedream 5.0 flash" | no |
| `output_format` (`png`, `jpeg`, default `jpeg`) | "Seedream 5.0 pro", "Seedream 5.0 flash", "Seedream 5.0 lite" | yes |
| `sequential_image_generation` (`auto` / `disabled`) | "Seedream 5.0 lite", "Seedream 4.5", "Seedream 4.0" | yes |
| `sequential_image_generation_options` | "Seedream 5.0 lite", "Seedream 4.5", "Seedream 4.0" | yes |
| `stream` | "Seedream 5.0 lite", "Seedream 4.5", "Seedream 4.0" | yes |
| `optimize_prompt_options.mode: fast` | "Seedream 5.0 flash, Seedream 5.0 lite, and Seedream 4.5 do not currently support this mode." | no |

Other parameter facts captured on the page, model-agnostic:

- `max_images` (inside `sequential_image_generation_options`): default 15, range [1, 15], with the
  tip "Number of input reference images + number of generated images ≤ 15."
- `watermark`: default `true`; "Adds an "AI-generated" watermark to the lower-right corner of the
  image."
- `response_format`: `url` (default, valid 24 hours) or `b64_json`.
- `model` parameter: "Activate the model on the Model activation page, and then find its Model ID";
  an Endpoint ID can be used instead for per-endpoint rate limits and billing.

## What this establishes

- Lite is documented by the vendor as a 2K/3K/4K model with a native pixel floor of 3.69 MP and a
  hard pixel ceiling of 16.78 MP (4096×4096), i.e. output is never smaller than ~3.7 MP.
- Lite accepts up to **14 reference images**, more than the pro tier's 10.
- Lite is the only Seedream 5.0 tier that supports sequential (batch) generation, streaming, and
  output-format choice, and it lacks layer decomposition, transparent background, and the `fast`
  prompt-optimization mode.
- BytePlus documents only Chinese and English prompt support for Lite; the additional 15 prompt
  languages are pro/flash-only.

## Gaps

- The page is organised by parameter with per-model notes, so a parameter that is silently
  unsupported (no note) is indistinguishable from one that is supported. Only the explicit
  "Supported models" lists above are safe to rely on.
- No latency, throughput, or concurrency figures for Lite.
- The page does not document the real-time search capability that the launch blog describes.
- No statement of which snapshot of Lite the API serves, beyond the model ID.

## Billing rules (verbatim, image generation)

- "Images that are not successfully output due to reasons such as content moderation are not
  billed."
- "In Seedream 5.0 pro layer decomposition, layers returned by the same request may fall into
  different pixel tiers. Each layer is billed separately based on its actual pixel tier."
- "For Seedream 5.0 lite, Seedream 4.5, and Seedream 4.0, sequential image generation is billed
  based on the actual number of generated images."

## What this establishes

- First-party price for Lite is **$0.035 per output image, with input images free**, flat across
  resolution — no per-megapixel tiering is stated for Lite, unlike pro.
- The pricing table contains **no row for `seedream-5-0-260128`**, even though the model list keys
  its Seedream 5.0 row by that ID. Only the lite snapshot ID is priced.
- Sequential generation on Lite is billed per image actually produced, so a `max_images` request
  that returns fewer images costs less.

## Gaps

- Currency is USD on this international page; the equivalent Volcengine (China) price list was not
  captured, so cross-region price comparison is not possible here.
- No free quota or trial allowance for Lite is stated in this table.
- Whether the flat $0.035 holds for 4K output is implied by the absence of pixel tiers but not
  stated explicitly for Lite.
- Licence/usage terms for outputs are not on this page (see the model page's access section).

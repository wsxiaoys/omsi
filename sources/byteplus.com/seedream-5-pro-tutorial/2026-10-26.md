## Identity and model IDs (verbatim)

> Dola Seedream 5.0 pro (hereafter referred to as Seedream 5.0 pro) and Dola Seedream 5.0 flash
> (hereafter referred to as Seedream 5.0 flash) support text-to-image generation and image-to-image
> generation with one or multiple reference images. Both models also support interactive editing
> through coordinates and free-form markings, and can decompose one image into a base image and
> multiple layers.

> Seedream 5.0 pro: dola-seedream-5-0-pro-260628
> Seedream 5.0 flash: dola-seedream-5-0-flash-260915

So the international model ID is **`dola-seedream-5-0-pro-260628`**, with the brand prefix "Dola"
on BytePlus (BytePlus's own navigation calls it "Dola Seedream 5.0 Pro"). The China-region ID for
the same tier is `doubao-seedream-5-0-pro-260628` (see the Volcengine records): same `-260628`
snapshot suffix, different vendor prefix.

## Pro vs Flash (verbatim)

> Seedream 5.0 pro: Provides higher image quality and is suitable for scenarios where image quality
> is the priority.
>
> Seedream 5.0 flash: Generates images faster and costs less, making it suitable for latency- and
> cost-sensitive scenarios.

## Layer decomposition (verbatim)

> Seedream 5.0 pro and Seedream 5.0 flash can automatically decompose subjects, backgrounds, text,
> decorative elements, and other content in one input image into one base image and up to 16
> independently editable layers. Each layer is a PNG image with an alpha channel. The model also
> returns the position, stacking order, and content description of each layer, allowing you to move,
> scale, replace, recolor, and recompose the layers in design tools or frontend canvases.

> Set `layer_decomposition` to `true` to enable layer decomposition mode. In this mode, `image` is
> required and supports only one input image. `prompt` is optional and can specify the elements to
> decompose.

> Layers returned by layer decomposition are PNG images with alpha channels. You can use an output
> layer as the input image in another Seedream request to edit it independently, for example, to
> recolor it, change its style, or add details.

Each layer carries `z_index` (base image fixed at 0, layers from 1 upward), `bounding_box` with both
`absolute` (pixel coordinates in the output base image) and `normalized` (0–1 relative coordinates
for arbitrary canvases), `name`, and `description`. Restoring a layer means scaling it to `w × h`
and placing it at `(x, y)`, stacking in ascending `z_index`.

## Prompt-optimization speed mode (verbatim)

> To increase image generation speed, set `optimize_prompt_options.mode` to select a faster prompt
> optimization mode. For latency-sensitive applications, use Seedream 5.0 pro in fast mode or use
> Seedream 5.0 flash for faster image generation.
>
> standard (default): Standard mode. This mode produces higher-quality content but takes longer.
> fast: Fast mode. This mode takes less time to generate content. Only Seedream 5.0 pro supports
> this mode.

## Resolution (verbatim)

> Default value: 2K
> Valid values: 1K, 1.5K, 2K

> Total pixel range: [1280x720 (921600), 2048x2048x1.1025 (4624220)]
> Aspect ratio range: [1/16, 16]

> Note: 1.5K has the same price as 1K and provides better image generation quality.

For layer decomposition the page says only resolution tiers are accepted, default `auto`, valid
`1K`, `1.5K`, `2K`, `auto`; the base image uses the requested tier at the original aspect ratio, and
each layer uses a resolution close to that tier at the aspect ratio of its region in the original
image.

## Other documented behaviour

- Output formats `png` / `jpeg`; in layer decomposition `output_format` controls only the base image,
  layers are always PNG.
- `background: transparent` is supported, but only for image-to-image with exactly one input image
  that has an alpha channel; setting `output_format: jpeg` in that mode errors.
- `watermark` default `true`; `true` adds a visible watermark.
- Image URLs are retained for 24 hours.
- Layer decomposition reserves 17 IPM per request (1 base + 16 layers) and refunds the unused quota
  after generation.

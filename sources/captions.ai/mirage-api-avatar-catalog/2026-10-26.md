# Mirage API docs: avatar catalog

- Origin: Captions Help Center (Mirage API), "Avatar catalog",
  <https://captions.ai/help/docs/api/actor-catalog> (page last modified 2026-08-12)
- Evidence kind: official documentation (vendor asset catalogue)
- Publication date: page last modified 2026-08-12
- Capture date: 2026-10-26
- Relevant models: Mirage Avatar X (preset avatars for the Mirage Video API)

## Captured content (verbatim)

> Choose an avatar for your generated video. Each preview includes the avatar's visual reference and voice.

> Browse portrait and landscape avatar previews for the Mirage Video API, then copy the exact avatar enum
> value to use in create-video requests.

Portrait values (10): `Ayesha`, `Farhan`, `Giulia`, `Jasmine`, `Luke`, `Maya`, `Michael`, `Neha`, `Tariq`,
`Valerie`.

Landscape values (10): the same ten names suffixed `(16:9)`, e.g. `Ayesha (16:9)`, `Luke (16:9)`.

Each entry links a hosted reference video (Mux player URL) as the preview.

## Summary

Twenty preset avatar enum values — ten people, each in portrait and 16:9 — are offered as inputs to
"create-video requests", i.e. the same endpoint that otherwise takes a user-supplied image or video
reference. The page implies a preset path that needs no user-supplied visual reference.

## Gaps

- **The documented schema does not have this parameter.** The Create Video reference (last modified
  2026-10-16) exposes only `audio_reference` plus exactly one of `image_reference` / `video_reference` and
  no `avatar` field, so the catalog's instruction cannot be followed as written.
- No statement of whether preset avatars are licensed for commercial use, who the depicted people are, or
  whether they are synthetic.
- No statement of which model enum the presets pair with (`mirage-avatar-x` vs `mirage-video-1-latest`).

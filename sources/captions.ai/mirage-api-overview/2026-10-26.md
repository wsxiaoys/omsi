# Mirage API docs: overview and authentication

- Origin: Captions Help Center (Mirage API), "Mirage API overview",
  <https://captions.ai/help/docs/api/overview> (page last modified 2026-07-29)
- Evidence kind: official documentation (vendor API overview)
- Publication date: page last modified 2026-07-29
- Capture date: 2026-10-26
- Relevant models: all Mirage API models, including `mirage-avatar-x`

## Captured content (verbatim, selected)

> The Mirage API provides a simple interface to state-of-the-art video captioning, generation, and more.

> Prerequisites: A Mirage platform account. An API key.

> Every request to the Mirage API must include an `x-api-key` header containing your API key. You can create
> an API key in the platform dashboard.

The documentation index lists two API product areas: Video Captioning and Video Generation, the latter
containing "Get started with avatar generation using Avatar X" and an avatar catalog.

## Summary

Mirage's API is self-serve to the point of key creation: a platform account at `platform.mirage.app` plus an
`x-api-key` header. No waitlist, access request, or preview programme is described for Avatar X, which is the
only video-generation model documented.

## Gaps

- No API general-availability date or versioning policy.
- No statement of whether new accounts get Avatar X access immediately or on approval.
- The page names `platform.mirage.app` for key creation, but that host serves a Captions-branded app shell
  (`<title>Captions</title>`), not documentation.

# Mirage API docs: API pricing

- Origin: Captions Help Center (Mirage API), "API pricing",
  <https://captions.ai/help/docs/api/pricing> (page last modified 2026-08-13)
- Evidence kind: official documentation (vendor price list)
- Publication date: page last modified 2026-08-13
- Capture date: 2026-10-26
- Relevant models: `mirage-avatar-x` (video generation); Mirage video captions for contrast

## Captured content (verbatim)

> The Mirage API uses simple, usage-based pricing based on duration.

Video generation:

> * You are billed for the **length of the generated output video**, rounded up to the nearest 6-second
>   increment.
> * For example, generating a 10.2-second video will be billed as 12 seconds.

| Model | Description | Price |
| - | - | - |
| Mirage Avatar X | Expressive human video generation model (video/image + audio → video) | **$0.15 per second** (6-second increments) |

Video captions, for contrast:

> * You are billed for the **length of the input video**, rounded up to the nearest minute.
> * For example, captioning a 2.5-minute video will be billed as 3 minutes ($0.45).

| Feature | Description | Price |
| - | - | - |
| Add Captions | Apply styled captions to a video | **$0.15 per minute** |

## Summary

The only published price for Avatar X found: **$0.15 per second of generated output**, billed in 6-second
increments. The billing basis is output duration, not input duration, not resolution, and not a credit
system. A 6-second minimum bill applies because of the increment; a 10.2 s generation bills as 12 s
($1.80).

## Gaps

- No minimum charge, free tier, volume discount, or enterprise pricing is stated on the page.
- No per-request or per-segment pricing for the "generate multiple segments and join them" workflow, so
  the effective cost of a 60 s-plus video is arithmetic, not a published figure.
- The page is undated apart from its last-modified stamp; no announcement of the price or of any change to
  it was captured.
- No statement on whether failed or cancelled jobs are billed.

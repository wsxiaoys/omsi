# Cartesia: Text-to-Speech (Bytes) API reference — model enum, request schema, output schema

- Origin: Cartesia, "Text-to-Speech (Bytes)", <https://docs.cartesia.ai/api-reference/tts/bytes>
  (read as Markdown at `…/api-reference/tts/bytes.md`; page embeds the OpenAPI document `latest.yml`)
- Evidence kind: official API reference (request/response schema)
- Publication date: not stated. The embedded schema's `Cartesia-Version` header example/default is
  `2026-08-14`.
- Capture date: 2026-10-26
- Relevant models: `sonic-3.6`, `sonic-3.5`, `sonic-3`, `sonic-latest`

## Captured content

Endpoint: `POST https://api.cartesia.ai/tts/bytes`, "Stream audio from a complete transcript".

### Model enum (verbatim)

```yaml
TTSModelID:
  type: string
  enum:
    - sonic-3.6
    - sonic-3.5
    - sonic-3
    - sonic-latest
  example: sonic-3.6
  default: sonic-3.6
```

### Request fields (verbatim descriptions)

- `transcript` (string, default `"Hi there, it's awesome to meet you."`) — **no maximum length is
  declared in the schema.**
- `language` / `locale` — "The transcript's language or locale (for example `en` or `en-GB`). …
  Set one or the other, never both; setting both returns a 400 error."
- `accent` — "Usually unnecessary: Cartesia picks the closest accent the voice supports … Set it only
  to make a multilingual voice sound accented."
- `normalization` — "`auto` (default) runs the locale-aware normalizer, `off` skips it, or pass a
  language or locale code."
- `pronunciation_dict_id` — "Pronunciation dictionaries are supported by `sonic-3` models and newer."
- `generation_config` — "Available on `sonic-3` and newer models; not available on earlier models."
  `volume` ∈ [0.5, 2.0]; `speed` ∈ [0.6, 1.5]; `emotion` optional.

Required: `model_id`, `transcript`, `voice`, `output_format`.

### Output schema

- `container`: `wav` | `mp3` | `raw`.
- WAV: `encoding` defaults `pcm_s16le`, `sample_rate` ∈ {8000, 16000, 22050, 24000, 44100, 48000},
  default 44100.
- MP3: `sample_rate` ∈ same set (default 44100) and `bit_rate` ∈ {32000, 64000, 96000, 128000,
  192000}, default 128000 — both required.
- Raw: `encoding` + `sample_rate`.

### Errors

Structured JSON errors carry `error_code`, `title`, `message`, `request_id`; the API-conventions page
lists `quota_exceeded`, `concurrency_limited`, `voice_model_mismatch`, `voice_not_found`,
`model_not_found`, `language_not_supported`, `file_too_large`, `unsupported_audio_format`,
`plan_upgrade_required` as current codes.

## Summary

The API surface is small and stable: one model enum in which **`sonic-3.6` is the default**, a
`transcript` with **no documented maximum length**, and an `output_format` object covering 8–48 kHz
PCM plus WAV/MP3. `sonic-latest` is still an accepted enum value even though the Older Models page
marks it deprecated in favour of `sonic-preview` — the two pages disagree.

The absence of a `transcript` `maxLength` is itself evidence: Cartesia does not document a per-request
character ceiling, unlike ElevenLabs (10,000 characters for `eleven_v4`). Any hard cap would have to be
discovered by testing.

## Gaps

- No documented maximum transcript length, request body size, or audio duration.
- No documented rate limit on this page (plan concurrency limits appear on the pricing page instead).
- The schema is `latest.yml` at version `2026-08-14`; behaviour under earlier pinned `Cartesia-Version`
  values is not described here.

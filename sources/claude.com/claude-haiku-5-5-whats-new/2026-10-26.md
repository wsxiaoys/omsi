# What's new in Claude Haiku 5.5 (Claude Platform docs)

- **Origin:** "What's new in Claude Haiku 5.5", Claude Platform Docs (Anthropic),
  <https://platform.claude.com/docs/en/models/haiku-5-5/whats-new-haiku-5-5>.
- **Evidence kind:** first-party documentation (change list versus Claude Haiku 4.5, with
  new/changed/breaking classification).
- **Publication date:** undated page. Capture date 2026-10-26.
- **Relevant models:** `claude-haiku-5-5` against its predecessor `claude-haiku-4-5`.
- **Capture type:** full snapshot of the rendered page text. No artifacts.

## Change table, verbatim

| Change | Type | Action needed |
| --- | --- | --- |
| Adaptive thinking and effort | New | Optional: set `effort` to trade response quality against speed and cost |
| Larger context window and output | New | None; thinking tokens count toward `max_tokens` |
| Browser use tool | New | None; Claude API and Google Cloud (Google managed) only |
| Safety classifiers can decline a request | New | Handle `stop_reason: "refusal"`; "Server-side fallback isn't available" |
| Manual extended thinking returns an error | Breaking | Replace `budget_tokens` with adaptive thinking |
| Sampling parameters can return an error | Breaking | Omit `temperature`, `top_p`, `top_k` |
| Assistant message prefill returns an error | Breaking | End `messages` with a user turn |
| `computer_20250124` returns an error | Breaking | `computer_toolset_20260801` (Claude API, Google Cloud), `computer_20251124` (Bedrock) |
| Changing earlier turns invalidates thinking blocks | Breaking | Keep conversations append-only |
| Responses can start with thinking blocks | Changed | Select content blocks by `type`, not position |
| Thinking text is omitted by default | Changed | Set `thinking.display` to `"summarized"` |
| Same text counts as more tokens | Changed | Recount prompts and cost estimates |
| Replaying thinking blocks across accounts | Changed | Replay through the producing account |
| Earlier thinking blocks stay in context | Changed | Expect more input tokens; use thinking block clearing |
| Shorter prompts can be cached | Changed | Minimum cacheable length 512 tokens, "down from 4,096 on Claude Haiku 4.5" |
| Context awareness tags aren't injected | Changed | Use task budgets (beta) for an explicit agentic-loop budget |

## Key capability statements, verbatim

> "Claude Haiku 5.5 has a 1M token context window and returns up to 128k output tokens, up
> from 200k and 64k on Claude Haiku 4.5."

> "With adaptive thinking, Claude Haiku 5.5 determines when and how much to think. Adaptive
> thinking is on by default. Although you can still turn thinking off with `thinking:
> {"type": "disabled"}` at `high` effort or below, the better way to trade response quality
> against speed and cost is to use the effort parameter."

This is the decisive first-party statement that Haiku 5.5's thinking **can** be disabled —
the opposite of Claude Opus 5.5, where `thinking: {"type": "disabled"}` returns a 400 at
every effort level.

> "Claude Haiku 5.5 uses the same newer tokenizer as Claude 4.7 and later models. As with all
> models that use this tokenizer, the same input text produces approximately 30 percent more
> tokens on Claude Haiku 5.5 than on Claude Haiku 4.5. The exact increase depends on the
> content."

> "Claude Haiku 5.5 keeps thinking blocks from all earlier assistant turns in context, and
> they count as input tokens. Claude Haiku 4.5 kept only the latest turn's blocks."

## Summary

The breaking-change surface is large: a drop-in swap from `claude-haiku-4-5` breaks on
manual thinking budgets, sampling parameters, assistant prefill, and the old computer-use
tool. The page also establishes the two behaviours that make Haiku 5.5 structurally
different from its larger 5.5 siblings: thinking is disableable at `high` effort or below,
and a refusal is terminal (no server-side fallback).

## Gaps

- No pricing on this page.
- "Context awareness tags aren't injected" and "task budgets (beta)" are named but not
  explained here.
- The page does not state which effort levels are valid when thinking is disabled.

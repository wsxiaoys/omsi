The "Thinking" column is the load-bearing difference from Opus 5.5 and Fable 5.1: those two
are marked "(always on)", Sonnet 5.5 and Haiku 5.5 are not. The page's own note explains the
cache discount split — "prompt caching reads cost 10% of the base input price (2.5% on Claude
Fable 5.1 and Claude Mythos 5.1, 5% on Claude Opus 5.5 and Claude Sonnet 5.5)".

Also verbatim: "1M tokens is roughly 555k words or 2.5M Unicode characters on the current
tokenizer (introduced with Claude Opus 4.7)".

> turns off up-front thinking. It works at `high` effort or below."
>
> "Setting `temperature`, `top_p`, or `top_k` returns a 400 error."
>
> "The minimum cacheable prompt length is 512 tokens."

## Breaking changes listed on this page

The overview names five breaking changes against Claude Sonnet 5 and links each into the
"What's new" page: `between_tools` replaces `disabled`; forced tool use (`tool_choice` of
`any` or `tool`) errors; thinking blocks are tied to the model and the conversation;
`computer_20251124` is rejected on the Claude API and Google Cloud (Google managed); and the
advisor tool rejects four models as advisors.

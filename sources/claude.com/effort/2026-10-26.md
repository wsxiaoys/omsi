# Effort (Claude Platform docs)

- **Origin:** "Effort", Claude Platform Docs (Anthropic),
  <https://platform.claude.com/docs/en/build-with-claude/effort>.
- **Evidence kind:** first-party documentation (reasoning-effort levels and defaults).
- **Publication date:** undated page. Capture date 2026-10-26.
- **Relevant models:** `claude-opus-5-5` (effort levels also apply to Fable 5.1, Mythos
  5.1, Opus 5, Opus 4.6–4.8, Sonnet 5.5, Haiku 5.5).
- **Capture type:** full snapshot of the rendered page text. No artifacts.
  Inline code spans and link text are rendered as separate lines in the extracted text;
  quotes below rejoin them without changing wording.

This record exists to anchor the mapping between Anthropic's `effort` parameter and the
effort suffixes used by Artificial Analysis and OpenRouter.

## The five levels, verbatim

> "**max** — Absolute maximum capability with no constraints on token spending. Available
> on Claude Fable 5.1, Claude Mythos 5.1, …, Claude Opus 5.5, Claude Opus 5, …"

> "**xhigh** — Extended capability for long-horizon work. Available on Claude Fable 5.1,
> …, Claude Opus 5.5, Claude Opus 5, …"

> "**high** — Spends as many tokens as the task needs for excellent results. The default on
> every model that supports effort except Claude Opus 5.5 and Claude Haiku 5.5."

> "**medium** — Balanced approach with moderate token savings. The default on Claude Opus
> 5.5 and Claude Haiku 5.5."

The page does not print a separate gloss for `low` in the captured text, but it lists low
among the levels and the models above support it.

## Opus 5.5 specifics, verbatim

> "Claude Opus 5.5 supports all five effort levels, and `medium` is the default (Claude
> Opus 5 and earlier Opus models default to `high`, so a request that omits `effort` runs
> one level lower than it did on Claude Opus 5). Adaptive thinking is always on and can't
> be turned off, so effort is the primary control for how much the model reasons and what
> a request costs."

> "Requests that set `thinking: {"type": "disabled"}` return a 400 error at every effort
> level. Claude Opus 5.5 also supports changing effort mid-conversation with a per-message
> `output_config`, which preserves the prompt cache."

## Why this matters for identity

Artificial Analysis lists five variants of the model — `max`, `xhigh`, `high`, `medium`,
`low` — which is exactly this parameter's value set, in exactly this order. Combined with
matching release date, context window, and price, that is the strongest available evidence
that AA's "Claude Opus 5.5" rows denote `claude-opus-5-5` at a given effort setting rather
than five distinct models.

It also matters for one host-level discrepancy: OpenRouter's API metadata for the same
slug reports `default_effort: "high"`, against the first-party `medium` recorded above
([OpenRouter](../../openrouter.ai/claude-opus-5-5/2026-10-26.md)). The vendor statement
wins.

# Models overview (Claude Platform docs)

- **Origin:** "Models overview", Claude Platform Docs (Anthropic),
  <https://platform.claude.com/docs/en/models/overview>.
- **Evidence kind:** first-party documentation (lineup comparison, defaults, per-platform
  model IDs, retirement commitments).
- **Publication date:** undated page. Capture date 2026-10-26.
- **Relevant models:** Claude Fable 5.1, Claude Opus 5.5, Claude Sonnet 5.5, Claude Haiku
  5.5.
- **Capture type:** full snapshot of the rendered page text. No artifacts.

## Recommendation, verbatim

> "If you're unsure which model to use, start with Claude Opus 5.5 for most workloads. Use
> Claude Fable 5.1 for demanding reasoning and long-horizon agentic work, or when your
> evals on Claude Opus 5.5 at higher effort still fall short. All current models support
> text and image input, text output, multilingual capabilities, vision, and tool use."

The retirement dates are a useful side-channel on sibling chronology. For Opus 5.5 the
floor is exactly one year after its stated release date (released 2026-09-22, retires not
sooner than 2027-09-22). Sonnet 5.5 and Haiku 5.5 sit at the same one-year offset
(2027-09-28, 2027-10-07), which implies 2026-09-28 and 2026-10-07 releases. Anthropic's
launch post for Opus 5.5 said Sonnet 5.5 and Haiku 5.5 "will follow in the coming
weeks", which is consistent. Fable 5.1's floor of 2027-09-01 has no release date
captured in this wiki, so its implied 2026-09-01 launch is an inference, not a fact.

## Models API notes relevant to Opus 5.5

The page documents that the Models API returns `max_input_tokens`, `max_tokens`, a
`capabilities` object, and a `line` field. Two capability flags are worth recording
because they explain host-side labels:

- `thinking.types.disabled.supported` is `false` when a model rejects
  `thinking: {"type": "disabled"}` with a 400 — which is the case for Opus 5.5.
- `thinking.types.between_tools` reports whether a model accepts
  `thinking: {"type": "between_tools"}`, the setting that "turns off up-front thinking".

# Pricing (Claude Platform docs)

- **Origin:** "Pricing", Claude Platform Docs (Anthropic),
  <https://platform.claude.com/docs/en/about-claude/pricing>.
- **Evidence kind:** first-party documentation (list prices, multipliers, billing rules).
- **Publication date:** undated page. Capture date 2026-10-26.
- **Relevant models:** `claude-opus-5-5` (plus siblings Claude Fable 5.1, Claude Sonnet
  5.5, Claude Haiku 5.5 for comparison).
- **Capture type:** full snapshot of the rendered page text. No artifacts.
  Inline code spans and link text are rendered as separate lines in the extracted text;
  quotes below rejoin them without changing wording.

All prices USD per million tokens (MTok).

## Base and cache pricing, verbatim table row

| | Input | Output | 5m cache write | 1h cache write | Cache read |
| --- | --- | --- | --- | --- | --- |
| Claude Opus 5.5 | $4 | $20 | $5 | $8 | $0.20 |

Cache read is 5% of base input for this model: "On Claude Opus 5.5 and Claude Sonnet 5.5,
a cache hit costs 5% of the standard input price ($0.20 USD per million tokens on Claude
Opus 5.5, $0.10 USD on Claude Sonnet 5.5)." The generic multiplier is 0.1x, so Opus 5.5
gets a *better* cache discount than the default — which matches Artificial Analysis's
reported "Cache Discount 95%" for the model.

## No long-context price tier for Opus 5.5

The base table has a single flat row for Opus 5.5. Only Claude Haiku 5.5 carries a
two-tier price ("$0.10 / MTok for prompts up to 100,000 tokens … $0.50 / MTok for prompts
over 100,000 tokens"). Opus 5.5 therefore has **no** long-context premium inside its 1M
window, unlike Haiku 5.5.

## Batch API

"50 percent discount on both input and output tokens". Opus 5.5 batch row: $2 input /
$10 output per MTok.

## Fast mode

> "Fast mode provides significantly faster output for Claude Opus 5.5, Claude Opus 5, and
> Claude Opus 4.8 at premium pricing. Fast mode for Claude Opus 5 and Claude Opus 4.8 is
> in research preview. Fast mode pricing applies across the full context window, including
> requests over 200k input tokens."

| Model | Fast mode input | Fast mode output |
| --- | --- | --- |
| Claude Opus 5.5 | $8 | $40 |
| Claude Opus 5 / Claude Opus 4.8 | $10 | $50 |

Availability of fast mode, verbatim: "available on the Claude API (first-party) and, for
Claude Opus 5.5, on Claude Models on Google Cloud (Anthropic managed) and on Claude in
Microsoft Foundry for deployments hosted on Azure." Fast mode "is not available with the
Batch API", and caching and data-residency multipliers stack on top of it.

## Data residency

> "For Claude 4.6 and later models, specifying US-only inference through the
> `inference_geo` parameter incurs a 1.1x multiplier on all token pricing categories,
> including input tokens, output tokens, cache writes, and cache reads."

Applies on the Claude API, Claude Platform on AWS, and Google Cloud (Anthropic managed);
on Microsoft Foundry the same multiplier applies to "US Data Zone Standard" deployments.
"Partner-operated platforms, Bedrock and Claude Models on Google Cloud (Google managed),
have independent regional pricing."

## Refusal billing (relevant to safeguard fallbacks)

Not on this page, but the platform release notes for 2026-09-24 state that refusals
arriving before any output are billed when `stop_details.category` is `"bio"`,
`"frontier_llm"`, or `"reasoning_extraction"` — the three categories where Opus 5.5's
safeguards intervene. See [release notes](../release-notes/2026-10-26.md).

## Gaps

- No per-region price table; the page defers to Bedrock and Google Cloud pricing pages.
- No subscription-plan equivalent pricing (Pro/Max/Team usage limits are mentioned only in
  the launch post).
- Cache pricing for the 300K-output Batch beta header is not called out separately.

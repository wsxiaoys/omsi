- **Publication date:** undated index, newest entry 2026-10-23. Capture date 2026-10-26.

This record keeps the Opus 5.5 entries and the platform-wide changes that bear on the
model page. Later entries on the same index were not curated.

## September 22, 2026 — launch, verbatim

> "We've launched Claude Opus 5.5 (`claude-opus-5-5`), a model for long-running agentic
> coding and knowledge work. It has a 1M token context window by default, 128k max output
> tokens, and always-on adaptive thinking, at $4 / $20 USD per MTok (Claude Opus 5 is
> $5 / $25 USD). Claude Opus 5.5 is available on the Claude API, Claude in Amazon Bedrock,
> Claude Platform on AWS, Claude on Google Cloud, and Claude in Microsoft Foundry."

API-shape changes, verbatim:

> "On Claude Opus 5.5, thinking can't be disabled: `thinking: {"type": "disabled"}` and
> `thinking: {"type": "enabled", ...}` return a 400 error. Omit the `thinking` field and
> control thinking depth with the `effort` parameter."

> "`tool_choice` types `any` and `tool` also return a 400 error, as on Claude Fable 5.1;
> use `auto` with strict tool use."

> "On the Claude API and Google Cloud, computer use on this model requires the
> `computer_toolset_20260801` toolset and the earlier `computer_20251124` tool returns a
> 400 error; on Amazon Bedrock, `computer_20251124` keeps working."

> "Fast mode (research preview) is available for Claude Opus 5.5 on the Claude API."

The same entry announces tools defined inside a mid-conversation system message
(`inline-tools-2026-09-15` beta) and a `tool_addition` block that can carry a tool
definition.

## September 24, 2026 — refusal billing

> "We're resuming billing for refusals that arrive before any output when
> `stop_details.category` is `"bio"`, `"frontier_llm"`, or `"reasoning_extraction"`, the
> categories where we measure low volumes of false positives. … Refusals billed under this
> change are charged like any other request, at the rates of the model that ran it."

These three categories are exactly where Opus 5.5's safeguards intervene (biology,
frontier LLM development, distillation). "Fallback credit is unchanged."

## October 15, 2026 — fast mode out of research preview

> "Fast mode is out of research preview for Claude Opus 5.5, and you no longer need to
> request access. Requests to Claude Opus 5.5 no longer require the
> `fast-mode-2026-02-01` beta header … Claude Opus 5.5 now has a default fast mode rate
> limit in the Start, Build, and Scale usage tiers. Fast mode for Claude Opus 5 and Claude
> Opus 4.8 remains in research preview."

The same day's entry adds: "Fast mode for Claude Opus 5.5 is now available on Claude in
Microsoft Foundry for deployments hosted on Azure."

## October 22, 2026 — Google Cloud, Anthropic-managed

> "We've launched Claude Models on Google Cloud (Anthropic managed), the Claude API
> operated by Anthropic and reached through your Google Cloud project. … Fast mode is
> available for Claude Opus 5.5 on Claude Models on Google Cloud (Anthropic managed)."

## Capabilities, verbatim

No feature is listed under "Not supported" in the captured text.

## Regions, verbatim

Model availability (includes fixed quota and Provisioned Throughput): United States
(multi-region), Europe (multi-region), Global (`global` endpoint).

ML processing: United States (multi-region), Europe (multi-region), Asia Pacific
(`asia-southeast1`).

So inference can be served from three geographies, while ML processing is pinned to those
three including Singapore — a narrower processing footprint than serving footprint.

## Quotas, verbatim

| Scope | QPM | Input TPM | Output TPM | Context length |
| --- | --- | --- | --- | --- |
| Multi-region | 1,500 | 15,000,000 | 1,500,000 | 1,000,000 |
| Global endpoint | 3,000 | 30,000,000 | 3,000,000 | 1,000,000 |

Input TPM counts "uncached and cache write". The global endpoint gets double the throughput
quota of a multi-region endpoint.

## Summary

The Google Cloud (Vertex) host card confirms GA status, the 2026-10-07 launch date, the
one-year retirement floor, text/image/PDF input with text output, 1M/128K limits, and a
three-geography serving footprint with Singapore as an ML-processing region. It is the only
captured host that documents PDF input and Provisioned Throughput for this model.

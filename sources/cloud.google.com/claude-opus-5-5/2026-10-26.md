## Regions and quota, verbatim

Model availability "includes fixed quota & Provisioned Throughput":

- United States — multi-region; Europe — multi-region; Global — `global` endpoint.
- ML processing: United States multi-region, Europe multi-region, Asia Pacific
  `asia-southeast1`.

Quota, multi-region: QPM 1,000, input TPM 10,000,000 (uncached and cache write), output
TPM 1,000,000, context length 1,000,000. Global endpoint: QPM 2,000, input TPM
20,000,000, output TPM 2,000,000.

Pricing is not on this page: it says only "See Pricing."

## What this host record adds

- **Third-party confirmation of the first-party spec sheet.** Model ID, 1M/128K limits,
  text+image input, text output, and the 2026-09-22 release date all match Anthropic's
  docs independently.
- **PDF is a first-class input modality on this host**, alongside text and images. This is
  the same "file" modality OpenRouter lists, and it is a host-documented modality rather
  than a vendor one: Anthropic's model page says only "Text and images → text".
- **GA, not preview**, on Google Cloud at capture time — relevant because Anthropic's
  launch post did not use a preview label but did gate fast mode and the cyber/bio
  programmes.
- **Regional shape**: three serving regions plus an `asia-southeast1` ML-processing region.
  Opus 5.5 is not US/EU-only on this host.

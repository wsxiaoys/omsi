### Description (verbatim)

> Gemini 3.8 Flash is our most intelligent workhorse model yet, delivering significant improvements
> from 3.7 Flash across software engineering, agentic tasks, and critical, multi-step reasoning in
> specialized domains. 3.8 Flash delivers substantial gains from 3.7 Flash, often approaching the
> performance of higher-cost frontier models.

> At times, 3.8 Flash might use more tokens to maximize performance, especially at higher effort
> levels. For applications where compute efficiency is the primary constraint, you can use lower
> effort levels to minimize token overhead or use 3.7 Flash instead.

> Note: `thinking_level="MINIMAL"` is not available for 3.8 Flash. Explicitly setting
> `thinking_level` to `MINIMAL` will return an API validation error. The supported values for 3.8
> Flash are `LOW`, `MEDIUM` (default), and `HIGH`.

### Per-modality technical limits (verbatim)

- Image: 3,000 images per prompt; 7 MB per file for inline/console upload, 30 MB from Cloud Storage;
  MIME types `image/png`, `image/jpeg`, `image/webp`, `image/heic`, `image/heif`.
- Text: 3,000 files per prompt, 3,000 pages per file, 50 MB per file for API/Cloud Storage imports
  (application/pdf) or 7 MB (text/plain), 7 MB for console uploads.
- Video: "Approximately 45 minutes" with audio, "Approximately 1 hour" without audio, 10 videos per
  prompt, MIME list includes `video/mp4`, `video/quicktime`, `video/webm`, `video/x-flv`,
  `video/wmv`, `video/3gpp`.
- Audio: "Approximately 8.4 hours, or up to 1 million tokens" per prompt, 1 audio file per prompt,
  MIME list includes `audio/wav`, `audio/mp3`, `audio/flac`, `audio/pcm`, `audio/ogg`, `audio/x-aac`.

## Summary

The platform-side page is the most complete first-party spec sheet for the model: GA, released
2026-09-02, with a **dated support window on this platform of "September 2, 2027 or later"** — the
only concrete date attached to the ID anywhere in the captured evidence, and explicitly scoped to
platform retirement rather than to the Gemini API. It also adds capabilities the Gemini API page does
not list (RAG Engine, Parallel/Exa web-search grounding, Chat Completions, Provisioned Throughput) and
per-modality ceilings that make the 1M context concrete: ~8.4 hours of audio, ~45–60 minutes of
video, 3,000 PDF pages.

## Contradictions and gaps

- **Retirement date vs "no shutdown date announced."** This page gives 2027-09-02-or-later for
  platform support; the Gemini API deprecations table gives no shutdown date for the same model ID.
  Both can be true (different surfaces, different commitments), but the page pair gives a reader no
  single lifecycle answer.
- **Sampling parameters.** This page publishes `temperature` / `topP` / `topK` defaults, while the
  Gemini API migration guide instructs callers to remove those parameters for Gemini 3 models.
  Unresolved; possibly a GenerateContent-vs-Interactions API split.
- No price table on the page (separate pricing page, captured separately).
- No benchmark numbers, no knowledge cutoff, no rate limits.
- Region granularity is only `global` / `us` / `eu`; no per-country availability.

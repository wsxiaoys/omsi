## Differences from earlier Gemini models (verbatim)

> **Unified input and output token limit and long decodes**: 4 Argon has a unified
> 1,048,576-token limit that includes both input and output tokens (where output includes
> thinking, function calls, and the final response) across all supported API surfaces (the
> GenerateContent API, the Interactions API, and the OpenAI compatibility Chat Completions
> API).

> A single synchronous request generates up to 65,536 output tokens (or 32,768 tokens for
> non-streaming direct HTTP requests). On the GenerateContent API (`v1beta1`), you can extend
> output up to 1,048,576 tokens (minus your input tokens) using long decodes … (known issue:
> long decoding on GenerateContent is supported only in the `v1beta1` API, which the Google
> Gen AI SDK uses by default).

> **Thinking levels**: Supports thinking levels `LOW`, `MEDIUM` (default), and `HIGH`.
> Setting `thinking_budget` or `thinking_level="MINIMAL"` returns an HTTP `400` validation
> error.

> **Sampling parameters**: Custom values for sampling parameters (`temperature`, `top_p`, and
> `top_k`) are ignored.

> **Context caching**: 4 Argon supports implicit caching only (4,096-token minimum), with
> durable caching enabled by default. Explicit context caching isn't supported.

## Capability matrix (verbatim, condensed)

Supported: thinking, system instructions, structured output, implicit context caching,
agentic video understanding, grounding (Google Search, Google Maps, Agent Search, Parallel
Web Search, Exa Web Search, Web Grounding for Enterprise), code execution, function calling,
URL context, GenerateContent API, Count Tokens API, Chat Completions API, Provisioned
Throughput, batch inference, Standard and Priority PayGo.

Not supported / preview: RAG Engine (not supported), tuning (not supported), Gemini Live API
(not supported), fixed quota (not supported), computer use (preview), Interactions API
(preview).

## Regions

Model availability and ML processing: Global `global`; multi-region `us`, `eu`; Europe
`europe-west2`; Asia Pacific `asia-southeast1`. Provisioned Throughput: `global`, `us`, `eu`,
`europe-west2`, `asia-southeast1`. Standard and Priority PayGo: `global`, `us`, `eu` only.

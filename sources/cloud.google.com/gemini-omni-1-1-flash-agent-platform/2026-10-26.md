### Capability matrix (verbatim)

Supported: Thinking; Generate videos from text; Generate videos from an image; Generate videos from
references; Videos from first and last frames; Sound generation ("Speech, music, sound effects");
Video editing; Extend videos; Content Credentials (C2PA); Count Tokens API; Interactions API (marked
"Preview feature"); GenerateContent API.

Not supported: System instructions; Structured output; Context caching; RAG Engine; Tuning; Image
generation; Edit images; Interleaved images and text; Agentic video understanding; Grounding; Code
execution; Function calling; URL context; Computer use; Gemini Live API; Chat Completions API; Batch
inference; **Pay-as-you-go**.

### Consumption options (verbatim)

> Provisioned Throughput — Supported
> Batch inference — Not supported
> Pay-as-you-go — Not supported
> Fixed quota — Supported

## Summary

Google Cloud sells the same release under a **different model ID and a different launch stage**:
`gemini-omni-1.1-flash-preview`, Preview, released 2026-08-27 — the same date the Gemini API calls
general availability for `gemini-omni-1.1-flash`. Three limits differ materially from the Gemini API
model page: context is 131,072 input / 57,920 output tokens instead of a 1,048,576-token window; audio
is "Not supported" as a modality; and self-serve pay-as-you-go is "Not supported" while Provisioned
Throughput and Fixed quota are.

The 2026-10-26 page also still lists the older "Gemini Omni Flash" (`omni-flash-preview`) as a live
preview, although the Gemini API model page lists `gemini-omni-flash-preview` as shut down.

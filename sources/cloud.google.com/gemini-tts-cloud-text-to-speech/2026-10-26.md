- Publication date: not stated; continuously edited. Capture date 2026-10-26
- Relevant models: `gemini-3.1-flash-tts-preview`, `gemini-3.8-flash-tts`,
  `gemini-3.8-flash-lite-tts`, `gemini-2.5-flash-tts`, `gemini-2.5-pro-tts`

## Model entry (verbatim)

> **Gemini 3.1 Flash TTS (Preview)**
> Model ID: `gemini-3.1-flash-tts-preview`
> Optimized for: Low latency, controllable, single- and multi-speaker Cloud TTS audio generation for
> cost-efficient everyday applications
> Input and output modalities — Input: Text. Output: Audio
> Token limits — Input: 8,192. Output: 16,384
> Speaker number support — Single, multi-speaker (dialogue)
> Supported output audio formats — Unary: `LINEAR16` (default), `ALAW`, `MULAW`, `MP3`, `OGG_OPUS`,
> `PCM`. Streaming: `PCM` (default), `ALAW`, `MULAW`, `OGG_OPUS`
> Region support — See Available regions.
> Voice options — "Note that all voices for Gemini 3.1 Flash TTS are in Preview."
> Consumption options — See Standard Paygo.

This is the only first-party page captured that enumerates the **output containers** for 3.1, and it
is a different list from the Gemini API's (which names only `audio/l16` for pre-3.8 models): Cloud
TTS exposes LINEAR16, ALAW, MULAW, MP3, OGG_OPUS and PCM for unary calls.

## Input limits (verbatim)

> The size of the text field and the prompt field individually can be at most 4,000 bytes. While the
> total size of the prompt and text fields can be up to 8,000 bytes, each field must be a maximum of
> 4000 bytes. The output audio can at most be around 655 seconds. If the input text amounts to audio
> longer than this limit, the audio will be truncated.

| Limit | Value | Direction |
| --- | --- | --- |
| Text field | ≤ 4,000 bytes | input |
| Prompt field | ≤ 4,000 bytes | input |
| Text + prompt | ≤ 8,000 bytes | input |
| Output duration | ~655 seconds; longer audio truncated | output |

## Sample rate (verbatim, from code samples)

`"sampleRateHertz": 24000` and `sample_rate_hertz = 24000` in the Python/JS/REST samples;
`wave_file(..., rate=24000, sample_width=2)` — 24 kHz, mono, 16-bit.

## Languages

> Gemini-TTS supports the following languages:

The table is per-language with a launch stage column: **87 locale rows**, of which **24 are GA** and
**63 are Preview** (e.g. Arabic (Egypt) `ar-EG` GA, Bangla (Bangladesh) `bn-BD` GA, English (US)
`en-US` GA, Cebuano (Philippines) `ceb-PH` Preview, Konkani (India) `kok-IN` Preview, Maithili
(India) `mai-IN` Preview). A separate "Available regions" table lists `us`, `eu`, `us-central1`,
`us-east1`, `us-east4`, `us-east5`, `us-south1`, `us-west1`, `us-west4`.

## Status on the two Google Cloud surfaces (verbatim)

Gemini-TTS page note:

> Gemini 3.8 Flash TTS and Gemini 3.8 Flash-Lite TTS models, including voice design and voice
> replication, are available in Preview through the Gemini Enterprise API only. They aren't available
> through the Cloud Text-to-Speech API.

Gemini Enterprise Agent Platform guide, supported-models list: it names 3.8 Flash TTS, 3.8 Flash-Lite
TTS, **Gemini 3.1 Flash TTS Preview (`gemini-3.1-flash-tts-preview`)**, Gemini 2.5 Pro TTS
(`gemini-2.5-pro-tts`) and Gemini 2.5 Flash TTS (`gemini-2.5-flash-tts`), then states:

> If you use an earlier Gemini TTS model, such as `gemini-3.1-flash-tts-preview`, see the migration
> guide.

The Vertex-side catalogue page (`cloud.google.com/vertex-ai/generative-ai/docs/models`) lists only
the two 3.8 TTS models, not 3.1; there is no dedicated Vertex model page for
`gemini-3.1-flash-tts-preview` (all three URL patterns tried returned 404).

## Naming: Cloud model IDs drop `-preview` for 2.5

The Cloud pages use `gemini-2.5-flash-tts` and `gemini-2.5-pro-tts` where the Gemini API uses
`gemini-2.5-flash-preview-tts` and `gemini-2.5-pro-preview-tts` — but 3.1 keeps the `-preview`
suffix on both surfaces. The Gemini 2.5 TTS generation therefore has two spellings depending on
platform; 3.1 does not.

## Summary

Google Cloud documents `gemini-3.1-flash-tts-preview` as a Preview Gemini-TTS model with 8,192/16,384
token limits, single- and multi-speaker output, six unary output encodings (LINEAR16 default) and
four streaming encodings (PCM default), 24 kHz mono 16-bit audio, per-field caps of 4,000 bytes
(8,000 combined) and a ~655-second output ceiling with truncation. It is still listed on the Gemini
Enterprise Agent Platform but has no Vertex catalogue entry and no model card of its own.

## Gaps

- The Gemini-TTS page does not say when the 3.1 model will be removed from Cloud, and does not repeat
  the 2026-11-17 shutdown date from the Gemini API deprecations page.
- No watermarking statement.
- The language table is shared by the whole Gemini-TTS family; it is not stated whether every row is
  available on 3.1 specifically, only that voices for 3.1 are "in Preview".

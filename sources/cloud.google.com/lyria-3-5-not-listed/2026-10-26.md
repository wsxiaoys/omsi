## Summary

Google's API-facing documentation does not know about Lyria 3.5. It publishes no model ID, no model
card, no technical specification, no price, no launch stage, no rate limit and no release note for it.
The only Google-hosted surface that names Lyria 3.5 is the DeepMind product page
([captured separately](../../deepmind.google/lyria-model-page/2026-10-26.md)), which is undated and
lists 3.5 as a product, not as an API model.

This record is deliberately a negative capture: it cannot show that Lyria 3.5 is not served by Google
Cloud (the docs lag product launches routinely), only that at the capture date nothing on those pages
documents it, and that the "Lyria" price list still has exactly three rows.

## Gaps

- No Google-side statement either way about API availability; absence is not a denial.
- The release-notes page's newest entry is May 26, 2026, five months before the capture date, so the
  page may simply be behind on Lyria entries.
- No access to Google's internal model registry, so a gated or allow-listed 3.5 endpoint cannot be
  ruled out.

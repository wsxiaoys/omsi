# Google Cloud: "Lyria API" reference (`lyria-002` predict endpoint)

- Origin: Google Cloud documentation, "Lyria API", Gemini Enterprise Agent Platform reference:
  <https://docs.cloud.google.com/gemini-enterprise-agent-platform/reference/models/lyria-music-generation>
- Evidence kind: official documentation (first-party API reference)
- Publication date: page footer "Last updated 2026-10-26 UTC"; no version date on the page.
- Capture date: 2026-10-26
- Relevant models: Lyria 2 (`lyria-002`). The page does not document Lyria 3.

## Supported models (verbatim)

> The Lyria API supports the following model: `lyria-002`

## Request parameters (verbatim)

| Parameter | Location | Type | Notes |
| --- | --- | --- | --- |
| `prompt` | instances | string | "Required. The text description in US English (en-us) of the audio to generate." |
| `negative_prompt` | instances | string | "Optional. A description of what to exclude from the generated audio." |
| `seed` | instances | integer | "Optional. A seed for deterministic generation… Cannot be used with `sample_count` in the same request." |
| `sample_count` | parameters | integer | "Optional. The number of audio samples to generate. Default is 1 if not specified and seed is not used. Cannot be used with `seed` in the same request." |

Endpoint: `POST https://LOCATION[-aiplatform.googleapis.com/v1/projects/]PROJECT_ID/locations/LOCATION/publishers/google/models/lyria-002:predict`.

## Output (verbatim)

> Each generated audio clip is 30 seconds long and provided as a WAV audio file at a 48kHz sample
> rate.

> `predictions[].mimeType` — The MIME type of the audio data. For Lyria, this is `"audio/wav"`.

> Output: 30-second WAV audio clips, 48 kHz, instrumental only.

## Pricing (verbatim)

> Lyria 2 usage is priced at **$0.06 per 30 seconds** of output music generated.

## Safety statement (verbatim)

> Safety: Content safety filters, recitation checking, artist intent checks, and SynthID watermarking
> are applied.

## Two contradictions with the Lyria 2 model card

1. **Clip length.** This page says "Each generated audio clip is 30 seconds long"; the model card and
   the generate-music guide both say **32.8 seconds** ("Each clip is 32.8 seconds long"). 32.8 s is the
   figure two pages agree on; this page rounds it.
2. **Filtering and watermarking.** This page says content safety filters, recitation checking, artist
   intent checks and SynthID watermarking "are applied" to `lyria-002`. The model card's capability
   table says "Audio watermarking: **Not supported**", "Filtering: **Not supported**", "Content
   Credentials (C2PA): Not supported". Two first-party pages describe the same model ID
   incompatibly.

## Gaps

- The page is a Lyria 2 reference only; it predates Lyria 3 and was not updated for it, so it cannot be
  used to infer Lyria 3 parameter behaviour.
- No error codes, rate limits, or output-length enforcement mechanism documented.

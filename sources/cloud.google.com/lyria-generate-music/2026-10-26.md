# Google Cloud: "Generate music with Lyria" (request shape, model IDs, output)

- Origin: Google Cloud documentation, "Generate music with Lyria", Gemini Enterprise Agent Platform
  docs: <https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/music/generate-music>
  (redirect target of the old `cloud.google.com/vertex-ai/generative-ai/docs/music/generate-music`).
- Evidence kind: official documentation (first-party API guide with request/response samples)
- Publication date: page footer "Last updated 2026-10-26 UTC"
- Capture date: 2026-10-26
- Relevant models: Lyria 3 (`lyria-3-clip-preview`, `lyria-3-pro-preview`), Lyria 2 (`lyria-002`)

## Interfaces

> Supported interfaces include the Google Cloud console and the Gemini API API.

(Verbatim, including the duplicated "API API".) The console path is
"Vertex AI Studio > Generate Media > Generate media page → Music → Task: Text-to-music".

## Lyria 3 request (verbatim)

> **HTTP method and URL:** `POST https://aiplatform.googleapis.com/v1beta1/projects/PROJECT_ID/locations/global/interactions`

> `MODEL_ID`: A string representing the model ID to use. The following are accepted values:
> `lyria-3-clip-preview` / `lyria-3-pro-preview`

Request body:

```json
{
  "model": "MODEL_ID",
  "input": [
    { "type": "text", "text": "TEXT_PROMPT" },
    { "type": "image", "mime_type": "image/jpeg", "uri": "IMAGE_URI" },
    { "type": "image", "mime_type": "image/png", "data": "IMAGE_DATABYTES" }
  ]
}
```

`IMAGE_URI` is "the Cloud Storage uri where your input image is located"; `IMAGE_DATABYTES` is
"a Base64-encoded input image". Both image parts are marked optional in the surrounding prose.

Response (verbatim):

```json
{
  "status": "completed",
  "outputs": [
    { "text": "LYRICS", "type": "text" },
    { "text": "DESCRIPTION", "type": "text" },
    { "mime_type": "audio/mpeg", "data": "GENERATED_SONG_DATABYTES", "type": "audio" },
    {}
  ],
  "role": "model",
  "created": "CREATED_TIME",
  "updated": "UPDATE_TIME",
  "object": "interaction",
  "model": "lyria-3-pro-preview"
}
```

Three points about the contract:

1. **The request body has no parameters object.** `model` and `input` only. There is no `duration`,
   `bpm`, `intensity`, `negative_prompt`, `seed`, or `sample_count` field — so the model card's
   "Detailed structure controls: Duration, BPM, Intensity" are prompt-text controls, not API fields.
2. **Location is hard-coded `global`** in the documented URL, matching the model card's
   "Global: global" region row.
3. **Lyria 3 returns three outputs:** lyrics text, a prose description, and the audio part. The
   response sample's fourth array element is an empty object — an artifact of the sample, not a
   documented output type.

## Lyria 2 request and response (verbatim, for contrast)

> `POST https://LOCATION-aiplatform.googleapis.com/v1/projects/PROJECT_ID/locations/LOCATION/publishers/google/models/lyria-002:predict`

```json
{ "instances": [ { "prompt": "...", "negative_prompt": "dissonant, minor key", "seed": 12345 } ],
  "parameters": { "sample_count": 1 } }
```

Response: `predictions[].audioContent` (base64) with `mimeType: "audio/wav"` and
`modelDisplayName: "Lyria 2"`. The page states:

> Each clip is 32.8 seconds long.

Lyria 2 is a different endpoint family (`:predict`, regional `LOCATION`, `instances`/`parameters`)
from Lyria 3 (Interactions API, `global`, `input`/`outputs`). Nothing about the Lyria 3 request shape
carries over.

## Output-format contradiction on the same page

> Generated audio clips are available for preview and downloadable as **WAV** files.

(console section) versus the API response's `"mime_type": "audio/mpeg"` and the model card's
"Supported MIME types: audio/mp3". The console's download format is WAV; the API returns MP3. The
page does not reconcile the two.

## Gaps

- No documented prompt length limit, no rate-limit handling, no error taxonomy for Lyria 3.
- The Interactions API is documented for `v1beta1` only; no `v1` path is shown.
- No statement of whether multiple image parts are accepted (the sample shows two image parts, the
  prompt guide says up to 10 references).

# Google Cloud: Lyria music generation prompt guide

- Origin: Google Cloud documentation, "Lyria music generation prompt guide", Gemini Enterprise Agent
  Platform docs:
  <https://docs.cloud.google.com/gemini-enterprise-agent-platform/models/music/music-gen-prompt-guide>
- Evidence kind: official documentation (first-party prompting guide with worked examples)
- Publication date: page footer "Last updated 2026-10-22 UTC"
- Capture date: 2026-10-26
- Relevant models: Lyria 3 (explicitly named), Lyria 2 (the negative-prompt guidance is inherited
  from it)

## Supported inputs (verbatim)

> Lyria supports the following: Multimodal prompts, including support for image and text inputs;
> Vocal generation for songs; Audio generation; Safety filters

> Lyria models allow you to upload **up to 10 reference images or PDFs** to establish the emotional
> baseline and visual storytelling baseline for the generated track.

The 10-reference limit and the **PDF** modality appear only here — the Lyria 3 model card lists
"Image — Input only" and says nothing about PDFs, and the Interactions API request sample shows only
`image/jpeg` and `image/png` parts. Treat PDF input as documented-but-unconfirmed.

## Languages (verbatim)

> The model supports multi-vocal generation in **eight languages**: English, German, Spanish, French,
> Hindi, Japanese, Korean, and Portuguese.

Matches the model card's list exactly.

## Structure and duration controls

Lyria 3 is named directly in the lyrics section:

> **Lyria 3 models** lets you do the following: Use your own lyrics: Type "Lyrics:" before the lines
> you want the model to sing. Add backing vocals… Ask the model to write lyrics…

Timestamp prompting is scoped to the Pro variant:

> **Timeline sequence prompting (Pro models)** — You can design multi-scene music structures by
> formatting timed segments with `[mm:ss]` indicators.

The worked example uses `[00:00]`, `[00:15]`, `[00:30]`, `[01:10]`, `[01:50]`, `[02:10]` and ends at
`[03:00]`, i.e. a 3-minute song. A second example uses `[0:00 - 0:12] Intro: … Intensity: 1/10 (Very
Low)` style segment blocks with an explicit per-segment **Intensity** scale of 1–10.

This is the mechanism behind the model card's "Duration, BPM, Intensity" structure controls: they are
**prompt conventions** — `[mm:ss]` markers and "Intensity: n/10" text — not request parameters.

## Negative prompting contradiction

> Negative prompts help specify elements to exclude from the music. Describe what you want to
> discourage the model from generating. **The API parameter is `negative_prompt`.**

The Lyria 3 model card's capability table says "Negative prompting: **Not supported**", and fal's
`fal-ai/lyria3` schema marks `negative_prompt` `"deprecated": true` with the description "Negative
prompting is not supported by Lyria 3." The prompt guide is generic across Lyria generations and does
not scope this paragraph to Lyria 2, so it reads as Lyria 3 guidance while the two other first-party
surfaces say the parameter does not exist for Lyria 3.

**Resolution adopted on the model page:** negative prompting is a Lyria 2 capability; for Lyria 3 it
is documented only in the prompt guide and rejected/ignored elsewhere. The guide is the outlier.

## Prompt framework (verbatim structure)

> `[Genre & style] + [Mood] + [Instrumentation] + [Tempo & rhythm] + [Vocal style & language] + [Lyrics]`

Optional blocks: Arrangement/Structure, Soundscape/Ambiance, Production Quality. "Specify
'instrumental' in your prompt to exclude vocals completely" — instrumental mode is likewise a prompt
word, not a parameter.

## Sample outputs quoted on the page

> Description: A 2-minute, 50-second song clip combining classic Bossa Nova and modern R&B styles
> with a romantic male and female vocal duet singing in English and French…

The guide quotes generated **descriptions** back as evidence of output, including exact durations
(2:50), which is the closest thing to a capability measurement in any first-party Lyria 3 material.
It is vendor-selected output, not a measurement.

## Gaps

- No documented failure modes, no statement about vocal-likeness refusals beyond the model card's
  filtering row.
- The guide never states which model ID produced each example, so the 3-minute example cannot be
  attributed to `lyria-3-pro-preview` with certainty (the section heading says "Pro models").

# Google Cloud: Generate videos from references (Veo)

- Origin: Google Cloud, "Generate videos from references", Gemini Enterprise Agent Platform video
  generation guide,
  <https://cloud.google.com/gemini-enterprise-agent-platform/models/video/generate-videos-from-references>
- Evidence kind: official API guide (first-party)
- Publication date: continuously edited; page footer not captured verbatim (the sibling Veo pages
  show "Last updated 2026-10-22 UTC").
- Capture date: 2026-10-26
- Relevant models: `veo-3.1-generate-001`, `veo-3.1-fast-generate-001` (and
  `gemini-omni-*` models, which are out of scope here)

## Reference-image support (verbatim)

> You can use Gemini Omni Flash or Veo on Gemini Enterprise Agent Platform to guide video generation
> using reference images or videos.

> Veo
> Veo on Gemini Enterprise Agent Platform lets you use reference subject images to direct your
> generated video. You provide up to three images of a single person, character, or product. Veo
> preserves the subject's appearance in the output video.

Supported-model list for the Veo half of the page:

> `veo-3.1-generate-001`
> `veo-3.1-fast-generate-001`

`veo-3.1-lite-generate-001` is **not** in that list, matching the model card's "Use reference images
— Not supported" row for Lite.

## Input handling (verbatim, from the request parameters)

> `CLOUD_STORAGE_IMAGE_URI`: … a Cloud Storage URI … for the reference image. For example,
> `gs://video-bucket/input/`.

> `IMAGE_MIME`: A string representing an image MIME type. The following are accepted values:
> `image/png`, `image/jpeg`, `image/webp`

The page also states reference-to-video "only supports 8 seconds" in the model card (see that
record) and demonstrates prompt-side labelling of each reference.

## Summary

The API exposes reference-subject generation on the two GA Veo 3.1 tiers only, capped at three images
of one person, character or product, supplied as Cloud Storage URIs in PNG/JPEG/WebP, with the
subject's appearance carried into the output. Lite cannot use it. The guide documents no numeric
similarity metric and no statement about how multiple distinct subjects combine, so "preserves the
subject's appearance" is an unquantified vendor claim.

## Gaps

- No stated per-image size limit (the model card's 20 MB applies to image-to-video input).
- No statement about consent or likeness requirements for reference images here; the responsible-AI
  page carries the celebrity/child filter codes.
- No guidance on what happens when references conflict, or how many distinct subjects one request can
  carry.

# Google Cloud: Edit videos — which models support video editing

- Origin: Google Cloud, "Edit videos", Gemini Enterprise Agent Platform video generation guide,
  <https://cloud.google.com/gemini-enterprise-agent-platform/models/video/edit-videos>
- Evidence kind: official API guide (first-party)
- Publication date: continuously edited; no date captured on this page.
- Capture date: 2026-10-26
- Relevant models: `gemini-omni-flash-preview`, `gemini-omni-1.1-flash-preview` — captured here
  because the **absence of any Veo model** is the point for the Veo 3.1 page.

## What the page says (verbatim)

> You can use Gemini Omni Flash to edit videos by using the Google Cloud console or the Agent Platform
> API.
> The following models support editing videos:
> `gemini-omni-flash-preview` (preview)
> `gemini-omni-1.1-flash-preview` (preview)

The accepted `MODEL_ID` values throughout the page's samples are the two `gemini-omni-*` preview IDs
only.

## Summary

On Google Cloud at capture, prompt-driven **video editing** (insert/remove/modify) is a Gemini Omni
preview feature, not a Veo 3.1 feature. DeepMind's Veo page advertises "Add object", "Remove object",
"Outpainting", "Character controls" and "Motion controls" without naming the surface (see the
deepmind.google record); the Vertex API documents none of them for `veo-3.1-*`. The changelog's Veo 2
entry ("Veo 2 supports adding and removing objects from videos in Preview", 2025-10-15) is the only
Veo editing capability in the first-party corpus, and it is attached to Veo 2, not 3.1.

Read together: those DeepMind capability panels describe the Google Flow application or a later model,
not the documented `veo-3.1-*` API surface.

## Gaps

- No statement about whether Veo editing is planned, deprecated, or never exposed.
- The page does not say what "edit" covers beyond the samples' prompt-driven changes.

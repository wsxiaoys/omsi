# Creatify API: billing and credits

- Origin: Creatify, "Creatify API Billing and Credits", <https://docs.creatify.ai/billing>
- Evidence kind: official documentation (vendor pricing policy, first-party)
- Publication date: not stated; Mintlify `lastModified` 2026-10-13T00:12:26.778Z
- Capture date: 2026-10-26
- Relevant models: Aurora 1.0 / 1.0 Fast / 2.0, plus other Creatify APIs

## Plans (verbatim table)

| Plan | Monthly Credits | Price | Best For |
| --- | --- | --- | --- |
| API Starter | 500 credits | $99 USD/month | Small projects, testing |
| API Pro | 2,000 credits | $299 USD/month | Growing businesses |
| API Enterprise | Custom | Contact sales | High-volume, custom needs |

> Creatify uses a **subscription model** for self-serve. Subscribe to a plan to unlock API access and
> monthly credits.

Derived credit price (arithmetic, not stated by the vendor): $99 / 500 = **$0.198 per credit**;
$299 / 2,000 = **$0.1495 per credit**. Nothing captured states a pay-as-you-go rate, a per-credit list
price, or what happens to overage.

## Aurora credit rates (verbatim)

| API | Credit Cost | Billing Unit |
| --- | --- | --- |
| Aurora 1.0 | 1 credit per second | 1-second increments |
| Aurora 1.0 Fast | 0.5 credits per second | 1-second increments |
| Aurora 2.0 | 0.4 credits (480p), 0.7 credits (720p), 1.4 credits (1080p) or 2.8 credits (2k) per second | 1-second increments |

> Aurora 2.0 (`model_version: aurora_v2`) is priced by its `resolution` setting, which defaults to 720p.
> `resolution` only applies to Aurora 2.0.

The same page lists "AI Avatar | 5 credits per 30 seconds" as a separate line item, so the AI Avatar
endpoints and the Aurora endpoint are billed on different bases.

## Summary

Aurora is billed per second of audio on the Creatify API, and credits come only through a monthly
subscription. The billing page gives no per-credit USD price, so any USD figure for a Creatify API
generation is derived from the plan price.

## Gaps

- No overage, rollover, refund, or minimum-commitment terms for the API plans on this page.
- No USD-per-credit list price; the two plan ratios differ by ~25%.
- No statement of whether audio-only or failed seconds are billed (the Aurora overview page says failed
  videos are refunded automatically).

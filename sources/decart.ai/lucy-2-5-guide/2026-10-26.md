- Relevant models: `lucy-2.5` (base editing); referenced: the dedicated Lucy VTON model

## Why this record exists

This is the page that draws the vendor's own line between the base Lucy 2 editing model and the
separate virtual try-on model. The base model lists try-on as an edit type it can perform, and then
tells readers to use the dedicated try-on model instead.

Edit-type table (excerpt, verbatim):

| Edit type | Description |
| --- | --- |
| **Character swap** | Replace a person or character with a new identity from a reference image |
| **Virtual try-on** | Swap clothing or accessories onto a person |
| **Add** | Insert a new object into the scene |
| **Replace** | Swap an existing object with something different |
| **Remove** | Clean removal of objects with background reconstruction |
| **Background** | Swap the scene environment |
| **Style transformation** | Apply a global visual aesthetic to the entire video |
| **Visual effects** | Add dynamic effects - fire, explosions, smoke, particles |

Immediately after the table:

> **NOTE**
>
> Virtual try-on has a dedicated optimized model. See the [Lucy - Virtual try-on
> model](https://docs.platform.decart.ai/models/realtime/virtual-try-on.md) for details.

Use case note on the same page:

> **Virtual try-on**
>
> Let customers see clothing and accessories on themselves in realtime. Supports a wide range of
> garment types, materials, and body conditions.

Reference-image guidance for try-on on this page:

> **For virtual try-on**
>
> A front-facing, evenly lit garment shot on a plain background gives the model the clearest signal.
> Include the full item from collar to hem where possible.

The same page also states the fast-mode rule: `speed: "fast"` is available for `lucy-2.6` /
`lucy-latest`, `lucy-2.5`, `lucy-vton-3.6` / `lucy-vton-latest` and `lucy-vton-3.5`, "billed at 2x
the standard realtime rate".

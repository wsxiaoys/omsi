## Endpoints

| Page | Operation | Path |
| --- | --- | --- |
| Lucy VTON 3.6 | `lucy_vton_3_6_job` | `POST /v1/jobs/lucy-vton-3.6` |
| Lucy VTON 3.5 | `lucy_vton_3_5_job` | `POST /v1/jobs/lucy-vton-3.5` |
| Lucy VTON Latest | `lucy_vton_latest_job` | `POST /v1/jobs/lucy-vton-latest` |

There is **no** API-reference page for `lucy-2.1-vton`, `lucy-vton-2` or `lucy-vton-3`; the llms.txt
index lists only 3.6, 3.5 and latest. Authentication is the `x-api-key` header.

## Request body (identical on all three pages, `multipart/form-data`)

| Field | Type | Required | Default | Description (verbatim) |
| --- | --- | --- | --- | --- |
| `data` | binary | yes | – | "Video file to process" |
| `prompt` | string | no | `""` | "Text prompt. Defaults to an empty string." |
| `reference_image` | binary \| null | no | – | "Reference image (optional)" |
| `seed` | integer 0–4294967295 | no | – | "Seed for the video generation" |
| `resolution` | string, `const: 720p` | no | `720p` | "Resolution of the video" |
| `enhance_prompt` | boolean | no | `true` | "Whether to enhance the prompt" |

`resolution` is a single-value enum: 720p is the only accepted value on the batch surface for 3.5,
3.6 and the latest alias. Responses are `200` with an unspecified JSON body (the job envelope) or
`422` with a FastAPI-style `HTTPValidationError`.

## Gaps

- The API reference does not state duration limits, queue latency, retention of uploaded video, or
  what the job response body contains (the guide's curl examples supply `job_id` and `status`).
- No `fast`/`speed` option exists on the batch surface.
- The reference does not say whether `reference_image` may be omitted while `prompt` is also empty.

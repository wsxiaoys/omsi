## Why this record exists

The listing **omits both V4.1 models**, yet the
[`1017` model page](../../deepinfra.com/deepseek-v4.1-flash-1017/2026-10-26.md) exists,
carries live pricing, and is promoted in the site's "Latest Models" footer on other
pages. The catalogue table is therefore out of date relative to the host's own model
pages.

This is a concrete instance of the rule that host catalogues are not model identity:
a host can serve a model its own index does not list, and can list a model page whose
endpoint terms are gone. Neither the presence nor the absence of a row here establishes
availability. Confirming what a host actually serves requires the model page or a live
request, not the index.

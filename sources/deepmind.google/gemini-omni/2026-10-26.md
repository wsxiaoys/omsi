- Text to Video: "Participants viewed 1,003 prompts and respective videos on MovieGenBench, a benchmark

- Text to Video (Fast Motion): "The Fast Motion evaluation dataset consists of 500 detailed text
  prompts designed to describe a wide variety of sports, athletic performances, and other activities."
- Image to Video: "Participants viewed 355 image and text pairs from the VBench I2V benchmark, outputs

## Summary

The first-party product page establishes Gemini Omni as a Google DeepMind video generation **and**
conversational editing model, positioned as "Nano Banana, but for video", with text, image, video and
audio references, first/last-frame interpolation, extension, 360p drafting and 1080p/4K upscaling. It
names only one addressable model, "Gemini Omni Flash", and only one model ID,
`gemini-omni-1.1-flash`. All quality statements are internal human-preference studies with no numbers.

## Gaps

- No release date, no pricing, no parameter list, no duration/resolution table and no per-modality input
  limits. Those live on the Gemini API and Google Cloud pages.
- No indication of which capabilities are API-exposed versus Gemini app / Flow application features.
- No latency figures.
- The page claims audio as a reference input ("image, text, video, or audio"); no captured Google API
  page confirms audio input works (see the Gemini API guide record, which says uploading audio
  references is unsupported).

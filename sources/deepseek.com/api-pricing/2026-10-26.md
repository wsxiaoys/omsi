# DeepSeek API — models and pricing

- **Origin:** "Models & Pricing", DeepSeek API Docs,
  <https://api-docs.deepseek.com/quick_start/pricing>.
- **Evidence kind:** official documentation (first-party pricing and model mapping).
- **Publication date:** page metadata reports 2026-10-19. Capture date 2026-10-26.
- **Relevant models:** `deepseek-flash` and `deepseek-v4-pro`.
- **Capture type:** full snapshot of the rendered page text. Pricing tables reproduced
  below; no artifacts saved.

## Model mapping — the important finding

| API model name | Model version served |
| --- | --- |
| `deepseek-flash` | **DeepSeek-V4.1-Flash-1017** |
| `deepseek-v4-pro` | DeepSeek-V4-Pro-0813 |

Footnote (1) states verbatim: *"Use `deepseek-flash` as the model name. The legacy names
`deepseek-v4-flash` and `deepseek-v4-flash-vision-exp` are still accepted, but the
corresponding models have been retired, their requests are served by the
DeepSeek-V4.1-Flash-1017 model and billed at the Flash price."*

Two things follow, and they point in opposite directions:

- The **`1017` checkpoint is what DeepSeek's own API serves** under the current Flash
  name. There is no first-party model name that selects the pre-1017 base.
- The **retired** models are `deepseek-v4-flash` and `deepseek-v4-flash-vision-exp`,
  i.e. the previous V4 generation — **not** the base V4.1-Flash. This page therefore
  does not establish that the base V4.1-Flash is retired; it establishes that the base
  is not reachable through a documented first-party model name.

## Pricing, USD per 1M tokens

| | `deepseek-flash` off-peak | `deepseek-flash` peak | `deepseek-v4-pro` off-peak | `deepseek-v4-pro` peak |
| --- | --- | --- | --- | --- |
| Input, cache hit | $0.003 | $0.006 | $0.022 | $0.044 |
| Input, cache miss | $0.15 | $0.30 | $0.66 | $1.32 |
| Output | $0.60 | $1.20 | $1.98 | $3.96 |

Verbatim definition of peak: *"Off-peak rates are half of the peak rates. Peak hours are
01:00 - 04:00 and 06:00 - 10:00 UTC, Monday through Friday, excluding Chinese public
holidays. All other hours are off-peak, including weekends and Chinese public holidays in
full."*

The 2× peak multiplier is a real cost factor for scheduled batch work and is easy to miss
when comparing against flat-rate hosts.

## Search and Fetch

Billed per request, $0.75 per 1,000 successful requests each. Server-side tool calls made
through DeepSeek Harness, Claude Code, or Codex are currently free; per-request billing
starts 2026-11-01 00:00 Beijing time. That is a dated price change, not a stable
condition — any cost claim about agentic use needs to state which side of that date it
was observed on.

## Gaps

- No rate-limit detail beyond the concurrency figure; the page defers to a separate
  rate-limit document that was not retrieved.
- No statement of which checkpoint the `1017` name pins to going forward, or whether
  `deepseek-flash` will move again. The page shows a snapshot, not a policy.
- No deprecation schedule for `deepseek-v4-pro`.

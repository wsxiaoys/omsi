# DeepSeek API change log

- **Origin:** "Change Log", DeepSeek API Docs, <https://api-docs.deepseek.com/updates/>.
- **Evidence kind:** official documentation (first-party changelog).
- **Publication date:** page metadata 2026-10-19; the newest entry is dated 2026-10-17.
  Capture date 2026-10-26.
- **Capture type:** full snapshot of the rendered page text, back to 2024-05-17. Only the
  entries relevant to V4.1 Flash are reproduced here.

## 2026-10-17 — DeepSeek-V4.1-Flash-1017 update

Verbatim: *"DeepSeek V4.1 Flash has been upgraded to DeepSeek-V4.1-Flash-1017. The
official web and APP models have also been updated to the new version. The API calling
method and pricing remain unchanged — simply use `deepseek-flash` to access the latest
model."*

Reported scores, verbatim list:

| Benchmark | 1017 |
| --- | --- |
| HLE (w/o tools) | 42.6 (44.0*) |
| Terminal-Bench 4.0 | 42.3 |
| DeepSWE v1.1 | 77.0 |
| ProgramBench | 29.1 |
| NL2Repo-Bench | 68.2 |
| Automation-Bench v1.0.6 | 60.5 |
| Agents' Last Exam | 35.4 |
| Apex Bench v1.1 | 72.1 |
| Chartography (w/tools) | 83.0 |
| BabyVision (w/tools) | 92.5 |
| ZeroBench-main (w/tools) | 51.0 |

Footnotes, verbatim: *"Tested only on the pure-text subset of the HLE benchmark set.
Terminal-Bench 4.0 was tested with the Claude Code framework, and DeepSWE with the
Mini-SWE-V2 framework. ZeroBench-main was evaluated with Pass@5."*

Also stated: *"we also reduced the model's task runtime and output length"* and *"We
specifically optimized for DeepSeek Harness, Tencent CodeBuddy, WorkBuddy, and other
platforms. Please upgrade to DeepSeek Harness 0.2.1-rc.1 or later."*

**Note the harness disclosure.** Terminal-Bench 4.0 was run with Claude Code, not the
Mini-SWE-agent harness that independent leaderboards hold constant. That is the single
most important qualification on these numbers.

## 2026-09-10 — DeepSeek-V4.1-Flash release

Establishes the **base release date: 2026-09-10**, which the model card does not state.
Describes it as *"the smallest model in our new architecture family, with native
multimodal visual understanding."*

Base scores listed: GPQA Diamond 90.9, HLE 36.8 (39.1*), Codeforces 3471, MathArena Apex
65.6, Terminal-Bench 2.1 90.6, Terminal-Bench 3.0 30.0, Terminal-Bench 4.0 31.2, DeepSWE
v1.1 74.2, ProgramBench 20.3, NL2Repo 65.4, CyberGym 88.1, SEC-Bench Pro 62.8, ExploitGym
15.3, HLE w/tools 63.9, Automation-Bench 54.8, Agents' Last Exam 31.8, Chartography 78.9,
BabyVision 89.6, ZeroBench-main 49.0.

API change, verbatim: *"Change the model name to `deepseek-flash` to call the latest V4.1
Flash model. The previous-generation models V4 Flash and V4 Flash Vision Exp have been
retired; for compatibility, the model names `deepseek-v4-flash` and
`deepseek-v4-flash-vision-exp` are temporarily routed to V4.1 Flash."*

This is the first appearance of the pattern that later causes confusion: `deepseek-flash`
has always been a **rolling alias**, and it has already moved once, from the September
checkpoint to `1017`.

## Earlier entries worth keeping

- **2026-07-31** — `DeepSeek-V4-Flash-0731` is described as *"keeps the same model
  architecture and size as DeepSeek-V4-Flash-Preview, and was only re-post-trained."*
  DeepSeek uses the same post-training-only framing for that update, so the pattern is
  established rather than novel.
- **2026-08-13** — V4-Pro GA introduces low/high/max thinking effort levels and
  peak/off-peak pricing effective 2026-08-16 16:00 UTC.
- **2026-04-24** — `deepseek-chat` and `deepseek-reasoner` announced for discontinuation
  on 2026-07-24.

## Gaps

- No independent verification of any figure. This is the vendor's own table.
- No statement of what `1017` denotes beyond appearing in the model name.
- The changelog does not say whether `deepseek-flash` will continue to move to future
  checkpoints. The 2026-09-10 entry implies it will, but does not promise it.

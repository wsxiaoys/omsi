# DeepSeek-V4.1-Flash-1017 release announcement

- **Origin:** "DeepSeek-V4.1-Flash-1017: Wish-Driven Programming Made Real", DeepSeek API
  Docs news, <https://api-docs.deepseek.com/news/news261017/>.
- **Evidence kind:** official documentation (first-party release announcement).
- **Publication date:** 2026-10-17. Capture date 2026-10-26.
- **Relevant model/version:** DeepSeek-V4.1-Flash-1017.
- **Capture type:** full snapshot of the rendered page text. The benchmark table and the
  performance-cost chart on this page are **images**
  (`img/v4.1_261017_benchmark_table_en.png`, `img/v4.1_261017_perf_cost_en.png`) and were
  not transcribed; the four demo GIFs were not saved.

## Claims made

- Verbatim: *"Stronger benchmark performance, faster task completion, and shorter outputs
  than the previous version—a Pareto improvement in performance and cost. Now live on our
  website, app, and API."*
- Verbatim: *"Optimized for DeepSeek Harness, Tencent CodeBuddy, WorkBuddy, and more.
  Upgrade to DeepSeek Harness v0.2.1-rc.1 or later for the best experience with the new
  model."*
- The training change is described as *"reinforcement learning with self-feedback to
  improve end-to-end project development—from game creation to 3D modeling."* This is the
  basis for calling it a post-training update rather than a new model.
- Four demo examples are offered (3D modeling of the Forbidden City, a web racing game, a
  Portal 2 recreation in Godot, a 3D historical scene). These are curated showcases, not
  measurements.

## Open-source release

Verbatim: *"Get DeepSeek-V4.1-Flash-1017: Hugging Face
https://huggingface.co/deepseek-ai/DeepSeek-V4.1-Flash-1017 · ModelScope
https://modelscope.cn/models/deepseek-ai/DeepSeek-V4.1-Flash-1017"*

This settles a question the earlier records left open: **the `1017` checkpoint has its own
weights repository**, separate from the base `DeepSeek-V4.1-Flash` repository. It is not
API-only.

## Search & Fetch

Both APIs are announced as generally available at $0.75 per 1,000 calls. Server-side tool
calls through DeepSeek Harness, Claude Code and Codex are free until **2026-10-31 16:00
UTC**. The pricing page states the same cutover as "00:00 Beijing time on November 1,
2026", which is the same instant (UTC+8). The two pages agree.

## Gaps

- The benchmark numbers on this page are images; no figures are readable in text form.
  Numbers used elsewhere in the wiki come from the change log and the model card, which
  are textual.
- No release date is stated for the base V4.1-Flash here.
- "Wish-driven programming" is never defined. It appears to be a marketing frame for
  end-to-end project generation, not a documented capability or interface.

## What this record establishes

- **The GA date: 2026-08-13.** Three independent first-party artifacts agree (this page, the
  change log, the Hugging Face repository creation timestamp of 2026-08-13T03:05:06Z).
- **`deepseek-v4-pro` is a rolling alias.** Verbatim: *"simply set the model name to
  `deepseek-v4-pro` to use the latest version."* The name did not change at GA and is not
  promised to pin this checkpoint. This is the same pattern that moved `deepseek-flash` from
  the September V4.1-Flash base to `1017` on 2026-10-17
  ([change log](../changelog/2026-10-26.md)).
- **Three effort levels, one API name.** `low` / `high` / `max` are new at GA for both Pro and
  Flash.
- **A dated price change.** Peak/off-peak pricing starts 2026-08-16 16:00 UTC. Any cost
  statement about this model needs to say which side of that instant it was observed on.

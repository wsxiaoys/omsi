## Scope, verbatim

> OXR is SoMark's open-source document parsing model, with a free API compatible with the SoMark
> API, CLI, and SDK

> OXR only implements the core parsing capabilities. Some advanced parameters are not available,
> such as cross-page merging, title level recognition, `zip` output, and PDF to Office. These
> parameters are ignored or rejected with a parameter error.

> Paths, parameter names, and response structure match the SoMark API.

## Free endpoint, verbatim

| | somark.ai |
| --- | --- |
| Online Demo | `https://free-oxr.somark.ai` |
| API URL | `https://free-oxr.somark.ai/api/v1` |
| API documentation | `https://docs.somark.ai/api-reference` |

> somark.cn is a mirror of somark.ai. Choose the domain that works best for your region.

> The Free OXR API requires no authentication. Set `api_key` to any value, such as `dummy`.

> We'll keep the free API online until we can no longer afford to run it.

> We do not recommend using the Free OXR API in production. We do not guarantee service stability,
> and requests are queued, so processing speed may vary slightly.

## Limits, verbatim

- "Up to **10MB** per file"
- "Up to **20 pages** per request"
- "Files over these limits are rejected. For larger or longer documents, use SoMark production
  (200MB, 300 pages) or self-host OXR."

## Self-hosting, verbatim

> You can deploy OXR with Docker on your own GPU server. Use `http://<host>:8000/v1` as the Base
> URL. The 10MB / 20-page limits do not apply.

## Request shape, verbatim

```bash
curl --fail-with-body https://free-oxr.somark.ai/api/v1/parse/sync \
  -F 'file=@document.pdf' \
  -F 'api_key=dummy' \
  -F 'output_formats=markdown' \
  -F 'output_formats=json'
```

The CLI path is `pip install somark` / `npm install -g somark-js`, then
`somark --base-url … --api-key dummy parse document.pdf --formats md,json --out ./parsed-output/`.

## What this establishes

- The free API is **first-party infrastructure**, not a third-party host. It is explicitly
  best-effort, keyless, and not for production, with a 10 MB / 20-page ceiling.
- The interface is the SoMark production API minus advanced parameters, so an integration written
  against OXR can be pointed at the paid product by changing the base URL — a switching path that
  runs toward the vendor, not away from it.
- Self-hosting has no documented page or size limit; the limits are properties of the hosted free
  tier, not of the model.

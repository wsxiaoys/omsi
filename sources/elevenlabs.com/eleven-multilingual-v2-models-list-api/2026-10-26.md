# ElevenLabs docs: List models API (`GET /v1/models`) — per-model capability fields

- Origin: ElevenLabs, "List models" API reference, <https://elevenlabs.io/docs/api-reference/models/list>
  (read as Markdown via `Accept: text/markdown`)
- Evidence kind: official documentation (API reference, response schema)
- Publication date: not stated
- Capture date: 2026-10-26
- Relevant models: all ElevenLabs models, including `eleven_multilingual_v2`

## Captured content

### Endpoint (verbatim)

> GET https://api.elevenlabs.io/v1/models
>
> Gets a list of available models.

### `ModelResponseModel` fields (verbatim)

> - `model_id` (string, required) — The unique identifier of the model.
> - `name` (string, optional) — The name of the model.
> - `can_be_finetuned` (boolean, optional) — Whether the model can be finetuned.
> - `can_do_text_to_speech` (boolean, optional) — Whether the model can do text-to-speech.
> - `can_do_voice_conversion` (boolean, optional) — Whether the model can do voice conversion.
> - `can_use_style` (boolean, optional) — Whether the model can use style.
> - `can_use_speaker_boost` (boolean, optional) — Whether the model can use speaker boost.
> - `serves_pro_voices` (boolean, optional) — Whether the model serves pro voices.
> - `token_cost_factor` (double, optional) — The cost factor for the model.
> - `description` (string, optional) — The description of the model.
> - `requires_alpha_access` (boolean, optional) — Whether the model requires alpha access.
> - `maximum_text_length_per_request` (integer, optional) — The maximum number of input text
>   characters accepted per request for this model. Longer requests are rejected.
> - `languages` (list of LanguageResponseModel, optional) — The languages supported by the model.
> - `model_rates` (ModelRatesResponseModel, optional) — The rates for the model.
> - `concurrency_group` (string, optional) — The concurrency group for the model.
> - `max_characters_request_free_user` (integer, optional, deprecated) — Deprecated. Not enforced;
>   use `maximum_text_length_per_request` instead.

> `ModelRatesResponseModel` — `character_cost_multiplier` (double, required); `cost_discount_multiplier`
> (double, optional, default: 1).

The page's example response is a schema placeholder (`"model_id": "string"`), not a populated list of
real models.

## What this establishes

- The character ceiling is a **per-model server-side field** (`maximum_text_length_per_request`) whose
  documented behaviour is rejection: "Longer requests are rejected." So the 10,000-character figure on
  the docs models page is a real enforcement parameter, not a soft recommendation.
- Capability is likewise per-model and machine-readable: `can_do_text_to_speech`,
  `can_be_finetuned`, `can_use_style`, `can_use_speaker_boost`, `serves_pro_voices`,
  `requires_alpha_access`, `concurrency_group`. The vendor therefore has an authoritative per-model
  answer for style/speed support and PVC support that this knowledge base cannot read without a key.
- `token_cost_factor` / `character_cost_multiplier` show that price is also a per-model multiplier, so
  the flat "$0.08 per 1K characters" on the pricing page is a display of that multiplier, not a
  separate billing system.

## Gaps

- **The live values were not retrieved.** `GET /v1/models` requires an API key that this knowledge
  base does not hold, and the reference page shows only a placeholder example. Every per-model flag
  for `eleven_multilingual_v2` — `can_use_style`, `serves_pro_voices`, `requires_alpha_access`,
  `maximum_text_length_per_request`, `character_cost_multiplier` — is therefore undocumented here.
- No statement of whether deprecated models still appear in this list, or in what order.
- No rate limits, no per-plan differences, and no statement of how `concurrency_group` maps to the
  plan table on the docs models page.

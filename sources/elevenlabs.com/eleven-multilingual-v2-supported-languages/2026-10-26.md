# ElevenLabs help centre: "What languages do you support?" (Multilingual v2 = 29 codes)

- Origin: ElevenLabs, help centre, "What languages do you support?",

  `Accept: text/markdown`)
- Evidence kind: official documentation
- Publication date: not stated
- Capture date: 2026-10-26
- Relevant models: every ElevenLabs speech model; the Multilingual v2 section is the part used here

## Captured content

### Preamble (verbatim)

> Language codes should be passed as lowercase values. Most languages use ISO 639-1 two-letter codes
> (e.g., `en`, `fr`, `de`). Languages without an ISO 639-1 code use ISO 639-3 three-letter codes:
> Asturian (`ast`), Cantonese (`yue`), Cebuano (`ceb`), and Filipino (`fil`).

### Multilingual v2 section (verbatim, in full)

> **Multilingual v2** - our most life-like, emotionally rich model. It's best for voiceovers,
> audiobooks and content creation.
>
> Multilingual v2 supports 29 languages:
>
> **ar** Arabic, **bg** Bulgarian, **zh** Chinese, **hr** Croatian, **cs** Czech, **da** Danish,
> **nl** Dutch, **en** English, **fil** Filipino, **fi** Finnish, **fr** French, **de** German,
> **el** Greek, **hi** Hindi, **id** Indonesian, **it** Italian, **ja** Japanese, **ko** Korean,
> **ms** Malay, **pl** Polish, **pt** Portuguese, **ro** Romanian, **ru** Russian, **sk** Slovak,
> **es** Spanish, **sv** Swedish, **ta** Tamil, **tr** Turkish, **uk** Ukrainian

### Position relative to the other models on the same page (verbatim, selected)

> **Eleven v4 -** our latest and most advanced speech synthesis model.

> **Eleven v3 -** a previous expressive speech synthesis model.

> **Flash v2.5** - our latest, ultra-low-latency model, generating speech in under 75ms.

> It supports 32 languages

## What this establishes

- The 29-language claim is **enumerated, not just asserted**: exactly 29 ISO 639-1 codes, and the
  count is reproducible from the list. That is a stronger form of evidence than the "90+" / "70+"
  language claims for v4 and v3, whose enumerated lists contain fewer codes than advertised (see the
  shared models-overview record).
- The code list is the canonical per-language answer for this model: `ar bg zh hr cs da nl en fil fi
  fr de el hi id it ja ko ms pl pt ro ru sk es sv ta tr uk`.
- ElevenLabs' own help centre places Multilingual v2 behind v4 ("latest and most advanced") and
  alongside v3 ("a previous expressive model") without marking either deprecated.
- Flash v2.5's 32 languages are the 29 above plus Hungarian, Norwegian and Vietnamese, so the v2 set
  is a strict subset of the v2.5 set.

## Gaps

- The page does not state per-language quality, accent handling, or whether the 29 languages are
  equally strong; the docs models page only concedes, for the v4 family, that "some languages are
  handled more fluently than others".
- The page is undated and does not say when the language set last changed, so the 2023 launch list
  and this list are only comparable by content (they match — see the launch record).
- Regional variants named on the docs pages (English USA/UK/Australia/Canada; French France/Canada;
  Portuguese Brazil/Portugal; Spanish Spain/Mexico; Arabic Saudi Arabia/UAE) collapse to one code
  each here, so the model's ability to pick a regional accent within a code is not documented.

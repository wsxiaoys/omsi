## Captured content

### Endpoint and servers (verbatim)

> POST https://api.elevenlabs.io/v1/text-to-speech/{voice_id}

> - `https://api.elevenlabs.io` (Production, default)
> - `https://api.us.elevenlabs.io` (Production US)
> - `https://api.eu.residency.elevenlabs.io` (Production EU)
> - `https://api.in.residency.elevenlabs.io` (Production India)
> - `https://api.sg.residency.elevenlabs.io` (Production Singapore)

### `model_id` — Multilingual v2 is the default model (verbatim)

> `model_id` (string, optional, default: `eleven_multilingual_v2`) — Identifier of the model that
> will be used, you can query them using GET /v1/models. The model needs to have support for text to
> speech, you can check this using the `can_do_text_to_speech` property.

Every code sample on the page passes `"model_id": "eleven_multilingual_v2"` explicitly, including
the TypeScript, Go, Ruby, Java, PHP, C# and Swift samples.

### `language_code` — explicitly unsupported on Multilingual v2 (verbatim)

> `language_code` (string, optional, nullable) — Language code (ISO 639-1) used to enforce a language
> for the model and text normalization. If the model does not support the provided language code, it
> will be ignored. **This parameter is not supported for multilingual_v2 models.**

### `output_format` (verbatim)

> `output_format` (enum, optional, default: `mp3_44100_128`) — Output format of the generated audio.
> Formatted as codec_sample_rate_bitrate. So an mp3 with 22.05kHz sample rate at 32kbs is represented
> as `mp3_22050_32`. MP3 with 192kbps bitrate requires you to be subscribed to Creator tier or above.
> PCM and WAV formats with 44.1kHz sample rate requires you to be subscribed to Pro tier or above.
> Note that the μ-law format (sometimes written mu-law, often approximated as u-law) is commonly used
> for Twilio audio inputs.
>
> Allowed values: `alaw_8000`, `mp3_22050_32`, `mp3_24000_48`, `mp3_44100_128`, `mp3_44100_192`,
> `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `opus_48000_128`, `opus_48000_192`,
> `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `pcm_16000`, `pcm_22050`, `pcm_24000`,
> `pcm_32000`, `pcm_44100`, `pcm_48000`, `pcm_8000`, `ulaw_8000`, `wav_16000`, `wav_22050`,
> `wav_24000`, `wav_32000`, `wav_44100`, `wav_48000`, `wav_8000`

### Other body fields relevant to long-form work (verbatim, selected)

> `text` (string, required) — The text that will get converted into speech.

> `voice_settings` (VoiceSettingsResponseModel, optional, nullable) — Voice settings overriding
> stored settings for the given voice. They are applied only on the given request.

> `pronunciation_dictionary_locators` … You may have up to 3 locators per request

> `seed` (integer, optional, nullable) — If specified, our system will make a best effort to sample
> deterministically … Determinism is not guaranteed. Must be integer between 0 and 4294967295.

> `previous_text` / `next_text` … Can be used to improve the speech's continuity when concatenating
> together multiple generations …

> `previous_request_ids` / `next_request_ids` … A maximum of 3 request_ids can be send.

> `use_pvc_as_ivc` (boolean, optional, nullable) — Whether to use the IVC version of a professional
> voice. This may improve expressiveness and reduce latency.

> `apply_text_normalization` (enum, optional, default: `auto`) … Allowed values: `auto`, `on`, `off`

> `apply_language_text_normalization` (boolean, optional, default: false) … Currently only supported
> for Japanese.

> `enable_logging` (boolean, optional, default: true) — When enable_logging is set to false zero
> retention mode will be used for the request … Zero retention mode may only be used by enterprise
> customers.

> `audio_effects` … Effects don't change the cost of the request.

## What this establishes

- `eleven_multilingual_v2` is **the default `model_id`** of ElevenLabs' primary text-to-speech
  endpoint. A caller who never sets `model_id` gets this model, not v3 or v4. That is the strongest
  first-party evidence that the model is still current infrastructure rather than a legacy stub.
- The vendor's reference says `language_code` is **not supported** for `eleven_multilingual_v2`,
  while both independent hosts expose the parameter on their Multilingual v2 endpoints (see the fal
  and Replicate records). The two positions are incompatible as documented.
- Output formats are enumerated at 28 values including WAV, which the fal endpoint does not expose.
  The default is `mp3_44100_128`, and the top formats are plan-gated (192 kbps MP3 → Creator, 44.1 kHz
  PCM/WAV → Pro).
- Long-form continuity controls (`previous_text`/`next_text`, up to 3 `previous_request_ids`) and
  pronunciation dictionaries (up to 3) are endpoint-level features available to this model.
- Regional residency hosts exist for US, EU, India and Singapore, but the reference does not say
  which models each residency serves.

## Gaps

- No character limit is stated in this reference; the 10,000-character figure comes from the docs
  models page (see the shared models-overview record).
- No statement of which models are available per residency host.
- No statement about watermarking, and no `watermark` parameter exists.
- The reference does not state whether the `style` and `speed` voice settings are honoured by every
  model; it presents one shared `VoiceSettings` object.
- No per-model rate limits or concurrency in this page (they are on the models page).

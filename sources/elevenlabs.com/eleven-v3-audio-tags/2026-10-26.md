## Captured content (verbatim)

> Eleven v4 and Eleven v3 support audio tags. We recommend Eleven v4. Wrap a short instruction in
> square brackets and place it in the text where the delivery should change. The same tags work with
> both models.

> * Emotions: `[curious]` `[crying]` `[mischievously]`
> * Delivery direction: `[whispers]` `[shouts]`
> * Human reactions: `[laughs]` `[clears throat]` `[sighs]`

> You can generate via API using our Create speech and Stream speech endpoints by specifying model ID
> `eleven_v4` or `eleven_v3`.

> You can also use our Create dialogue and Stream dialogue endpoints to create a natural sounding
> dialogue with multiple speakers.

> For real-time applications, Eleven v4 Turbo (`eleven_v4_turbo`) also supports audio tags.

## What this establishes

- Audio tags are a **shared capability of v3 and v4**, with the same tag vocabulary: the vendor states
  "The same tags work with both models". Tags are a family feature, not a v3 differentiator.
- The recommendation to use v4 is repeated here, so v3's tag support is documented but no longer
  promoted.
- The real-time tag carrier in this page is `eleven_v4_turbo`; `eleven_v3_conversational` is not
  mentioned, even though the models page describes it as having "custom audio tags".

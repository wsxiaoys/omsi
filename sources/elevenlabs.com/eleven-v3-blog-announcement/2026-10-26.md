## Captured content

### Later-added status banner (verbatim, sits above the article body, undated)

> Eleven v3 is no longer in alpha, and is now generally available. We've also released Eleven v4,
> our most emotive Text to Speech model.

The banner carries no date of its own. The dated GA announcement is a separate post — see
`../eleven-v3-ga-announcement/2026-10-26.md`.

### Opening (verbatim)

> We're pleased to reveal Eleven v3 (alpha) — the most expressive Text to Speech model.

> This research preview brings unprecedented control and realism to speech generation with:
>
> - 70+ languages
> - Multi-speaker dialogue
> - Audio tags like [excited], [whispers], and [sighs]

> Eleven v3 (alpha) requires more prompt engineering than previous models — but the generations are
> breathtaking.

> If you're working on videos, audiobooks, or media tools — this unlocks a new level of
> expressiveness. For real-time and conversational use cases, we recommend staying with v2.5 Turbo or
> Flash for now. A real-time version of v3 is in development.

> Eleven v3 is available today on our website and in the API.

### Feature table (verbatim)

| Feature | What it unlocks |
| --- | --- |
| Audio tags | Inline control of tone, emotion, and non-verbal reactions |
| Dialogue mode | Multi-speaker conversations with natural pacing and interruptions |
| 70+ languages | Full coverage of high-demand global languages |
| Deeper text understanding | Better stress, cadence, and expressivity from text input |

### Audio tags and voice cloning (verbatim)

> Audio tags live inline with your script and are formatted with lowercase square brackets.

> Professional Voice Clones (PVCs) are currently not fully optimized for Eleven v3, resulting in
> potentially lower clone quality compared to earlier models. During this research preview stage it
> would be best to find an Instant Voice Clone (IVC) or designed voice for your project if you need
> to use v3 features. PVC optimization for v3 is coming in the near future.

Tag examples given: `[excited]`, `[shouts]`, `[happily]`, `[laughs]`, `[whispers]`, `[sighs]`,
`[australian accent]`, `[french accent]`, `[dismissive]`, `[cheeky]`, and stacked tags such as
`"[happily][shouts] We did it! [laughs]."`.

### Dialogue mode (verbatim)

> Eleven v3 is supported in our existing Text to Speech endpoint. Additionally, we introduce a new
> Text to Dialogue API endpoint. Provide a structured array of JSON objects — each representing a
> speaker turn — and the model generates a cohesive, overlapping audio file

> The endpoint automatically manages speaker transitions, emotional changes, and interruptions.

The request example passes `speaker_id` + `text` pairs, with parenthesised delivery hints
(`(cheerfully)`, `(laughs)`) inside the text alongside bracketed tags.

> Eleven v3 is 80% off until the end of June 2025 for self-serve users using it through the UI.

### "When not to use v3" (verbatim)

> Eleven v3 (alpha) requires more prompt engineering than our previous models. When it works the
> output is breathtaking but the reliability and higher latency means it's not suitable for real-time
> and conversational use cases. For these, we recommend Eleven v2.5 Turbo/Flash.

## What this establishes

- **Eleven v3 was announced on 2025-06-03** as a research preview / alpha. That date is roughly
  seventeen months before the capture date and therefore **before** the roster's one-year window
  (≥ 2025-10-26). The vendor's own GA post dates the end of alpha to 2026-02-02.
- At launch the model was **UI-first**: the public API was explicitly "coming soon", so the June 2025
  date is not an API availability date.
- The alpha announcement itself says v3 is unsuitable for real-time use and recommends v2.5
  Turbo/Flash — the same post also says a real-time version is "in development", which is the origin
  of the separate `eleven_v3_conversational` variant.
- **PVC quality is a vendor-acknowledged weakness of v3**, not an independent finding: ElevenLabs
  recommended IVC or designed voices instead.
- The launch pricing was a promotional 80%-off UI discount, not a per-character API rate. No API
  price appears in this post.

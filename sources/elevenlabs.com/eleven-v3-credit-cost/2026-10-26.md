## Captured content (verbatim, in full)

> The cost of generating with Eleven v3 is 1 credit per character on the website. API generations are
> discounted - see API pricing for details.

Linked from the page: "Eleven v3 overview" (`https://elevenlabs.io/v3`) and the prompting guide.

## What this establishes

- ElevenLabs bills v3 **per character** and says the API rate is *cheaper* than the website's
  1-credit-per-character rate, without giving the API number on this page.
- The API USD figure lives only on the pricing page ($0.08 per 1,000 characters), and the two pages are
  not reconciled into a dollars-per-credit rate
  (`../eleven-v4-api-pricing/2026-10-26.md`).
- No time-based or per-request billing exists for v3 in any captured source.

## Gaps

- The promised "Eleven v3 overview" link (`elevenlabs.io/v3`) no longer serves a v3 page — at capture it
  resolved to the generic text-to-speech marketing page, so the vendor's own v3 product page is gone.
- No statement of what a "discounted" API rate is in credits, or whether credits differ for
  `eleven_v3_conversational`.
- No statement about billing on failed, truncated or empty generations.

# ElevenLabs docs: Changelog — Eleven v4 / v4 Turbo launch and follow-ups

- Origin: ElevenLabs, "Changelog", <https://elevenlabs.io/docs/changelog> (read as Markdown via
  `Accept: text/markdown`)
- Evidence kind: official documentation (dated release notes)
- Publication date: entries dated **2026-09-28** (launch) and **2026-10-19** (agent default change);
  capture date 2026-10-26
- Relevant models: `eleven_v4`, `eleven_v4_turbo`, `eleven_v3`, `eleven_flash_v2`, `eleven_flash_v2_5`

## Captured content

### Entry dated September 28, 2026 (verbatim, in full)

> ### Eleven v4 and Eleven v4 Turbo
>
> [Eleven v4 and Eleven v4 Turbo](https://elevenlabs.io/docs/overview/capabilities/text-to-speech/eleven-v4) are now
> available. Eleven v4 provides higher-quality, more expressive speech and improved voice cloning
> across more than 90 languages. Eleven v4 Turbo provides the same model family for real-time
> applications, with median inference latency of approximately 100 ms.
>
> Use `eleven_v4` through the Text to Dialogue API for content creation and long-form audio. Use
> `eleven_v4_turbo` through the Text to Dialogue WebSocket for agents and interactive applications.

The same date's entry also records, under **Text to Dialogue**:

> **Generation continuity**: Text to Dialogue requests can use preceding or following text and
> request IDs to maintain continuity across generations.

> **Professional voice mode**: Text to Dialogue requests can use the Instant Voice Clone version of a
> Professional Voice Clone to reduce latency or improve expressiveness.

and, under **ElevenAgents**:

> **Agent models**: Added `gpt-6-sol`, `gpt-6-luna`, `glm-52`, `deepseek-v41-flash`, `claude-opus-5`
> and `claude-opus-5-5` to the supported agent LLM options.

### Entry dated October 19, 2026 (verbatim)

Under **Updated endpoints → ElevenAgents → Create agent / Get agent / Update agent**:

> Added `eleven_v4` and `eleven_v4_turbo` to the conversational TTS model options. The default
> changed from `eleven_flash_v2` to `eleven_v4_turbo`.

Under **Dubbing** (same page):

> The translated voice uses Eleven v4 Turbo by default, and you can switch to `eleven_v3` or
> `eleven_flash_v2_5` with `tts_model_id`.

### Other v4 mentions on the page

- SDK release notes (JS and Python `v2.71.0`): "Eleven v4 agent voice models".
- A platform charge-category enum adds `v3_addon`, `v4_addon` and `rag_addon`.

## What this establishes

- **Launch date: 2026-09-28.** That is inside the roster's one-year window (≥ 2025-10-26) with about
  thirteen months of margin, and it matches fal's catalogue `date` for both endpoints to the day.
- Eleven v4 and v4 Turbo shipped **together**, as one family with two variants.
- The vendor's stated integration path at launch is Text to Dialogue (v4) and the Text to Dialogue
  WebSocket (Turbo), not the single-voice Text to Speech endpoint.
- v4 Turbo became ElevenAgents' **default** conversational TTS model on 2026-10-19, three weeks after
  launch, and the default dubbing voice. That is fast promotion for a new model and is the strongest
  first-party signal that ElevenLabs treats v4 as production-ready rather than preview.
- No changelog entry marks v4 as preview/beta, and none announces a deprecation of v3 or
  Multilingual v2.

## Gaps

- The changelog does not date the *end* of any preview period; the word "preview" does not appear.
- No changelog entry explains why the Text to Speech endpoint is not named for v4 while the model
  guide's code samples call `text_to_speech.convert(model_id="eleven_v4")` (see
  `../eleven-v4-prompting-best-practices/2026-10-26.md`).
- No pricing, quota or regional-availability change is announced alongside the launch.

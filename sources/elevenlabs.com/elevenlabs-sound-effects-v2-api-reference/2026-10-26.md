## Captured content

### Endpoint and regions (verbatim)

> POST https://api.elevenlabs.io/v1/sound-generation
>
> Turn text into sound effects for your videos, voice-overs or video games using the most advanced
> sound effects models in the world.

Servers: `https://api.elevenlabs.io` (Production, default), `https://api.us.elevenlabs.io`,
`https://api.eu.residency.elevenlabs.io`, `https://api.in.residency.elevenlabs.io`,
`https://api.sg.residency.elevenlabs.io`.

### Query parameters (verbatim)

- `output_format` — default `mp3_44100_128`, "Formatted as codec_sample_rate_bitrate… MP3 with 192kbps
  bitrate requires you to be subscribed to Creator tier or above. PCM and WAV formats with 44.1kHz
  sample rate requires you to be subscribed to Pro tier or above." 28 allowed values:
  `alaw_8000`, `mp3_22050_32`, `mp3_24000_48`, `mp3_44100_128`, `mp3_44100_192`, `mp3_44100_32`,
  `mp3_44100_64`, `mp3_44100_96`, `opus_48000_128`, `opus_48000_192`, `opus_48000_32`,
  `opus_48000_64`, `opus_48000_96`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_32000`, `pcm_44100`,
  `pcm_48000`, `pcm_8000`, `ulaw_8000`, `wav_16000`, `wav_22050`, `wav_24000`, `wav_32000`,
  `wav_44100`, `wav_48000`, `wav_8000`.
- `enable_logging` — default `true`; "When enable_logging is set to false zero retention mode will be
  used for the request. Zero retention mode may only be used by enterprise customers."

### Body parameters (verbatim)

- `text` (string, required) — "The text that will get converted into a sound effect." No maximum
  length is stated on this page.
- `loop` (boolean, optional, default false) — "Whether to create a sound effect that loops smoothly."
- `duration_seconds` (double, optional, nullable) — "The duration of the sound which will be generated
  in seconds. **Must be at least 0.5 and at most 30.** If set to None we will guess the optimal
  duration using the prompt. Defaults to None."
- `prompt_influence` (double, optional, nullable, default 0.3) — "A higher prompt influence makes your
  generation follow the prompt more closely while also making generations less variable. Must be a
  value between 0 and 1. Defaults to 0.3."
- `model_id` (enum, optional, default `eleven_text_to_sound_v2`) — "The model ID to use for the sound
  generation." Allowed values: **`eleven_text_to_sound_v2`, `eleven_text_to_sound_v3`**.

### Response and errors

`200` returns "The generated sound effect audio, encoded in the specified `output_format`" as a file
download. `422` is a validation error. No response header, request-id, seed, or determinism statement
is documented.

## Summary

The authoritative parameter surface at capture. Three things matter for identity:

1. `model_id` defaults to `eleven_text_to_sound_v2`, so v2 is the served default.
2. A second value, `eleven_text_to_sound_v3`, is selectable but is **not** documented anywhere else in
   the docs corpus captured for this page (see the models overview record) and is not mentioned in the
   changelog.
3. The duration floor is 0.5 s here, against 0.1 s on the capability overview page, and the ceiling is
   30 s here against fal's 22 s.

The qualifier that `loop` was "Only available for the 'eleven_text_to_sound_v2' model" appeared in
earlier captures of this page and is absent at capture — see
`../elevenlabs-sound-effects-v2-docs-history/2026-10-26.md`.

## Gaps

- `eleven_text_to_sound_v3` has no description, model card, price, or changelog entry in any page
  captured here. Whether it is a preview, a rename, or a new generation is unknown.
- No input character limit is stated (the help centre says 450 — see the product-guide record).
- No statement of what happens to `loop` when `duration_seconds` is omitted, or whether looping
  changes the achievable duration.

## Summary

The vendor's canonical model-ID list contains exactly one sound-effects model, `eleven_text_to_sound_v2`,
with a one-line description and no limits, formats, languages, or dates. The page therefore establishes
v2 as the *documented* sound-effects model and simultaneously fails to document the `v3` value that the
API reference and OpenAPI schema both accept.

## Gaps

- No release date for `eleven_text_to_sound_v2` and no acknowledgement that a v1 existed.
- No explanation of `eleven_text_to_sound_v3`, its status, or why the API accepts an ID the models page
  omits.
- No duration, character, or output-format limits for sound effects, unlike the speech models.

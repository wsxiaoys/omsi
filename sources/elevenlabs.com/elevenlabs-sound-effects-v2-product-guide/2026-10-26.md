## Captured content

### Prompt length and variations

> Enter your prompt in the text box. There is a **maximum length of 450 characters** for your prompt.

> Each time you select **Generate**, the AI will generate full variations of the prompt you've given.

The product guide is more specific: "Click the arrow to generate. **Four sound effects will be created
each time.**"

### Settings (product guide, verbatim)

> * Set the duration for the sound, or choose auto to let the AI decide. **The maximum length is 30
>   seconds.**
> * Turn **Looping** on to create a seamless loop. The ending will blend into the beginning without a
>   noticeable gap.
> * Adjust the prompt influence setting to control how closely the output should match the prompt. **By
>   default, this is set to 30%.**

### Downloads (product guide, verbatim)

> Go to your **History** tab to access the generated sound effects. Click the **download** icon and
> choose **MP3 (44.1kHz) or WAV (48kHz)**.

### Cost (help centre, verbatim)

> The cost for generating sound effects varies based on the settings you choose, and whether you are
> using the website or API platform. The settings affect how many sound effects are produced and the
> duration of each sound effect.
>
> For current rates, see [ElevenCreative](https://elevenlabs.io/pricing?price.section=sound_effects#pricing-table)
> and [ElevenAPI](https://elevenlabs.io/pricing/api).
>
> **The cost is not influenced by the text input you use.**

### Prompting advice (help centre, verbatim)

> Complex prompts include multiple sound effects, or a sequence of sound effects happening in a
> specific order… While the AI does understand these prompts, for the best results, we would recommend
> generating individual sound effects and then combining them in an audio editor of your choice.

## Summary

Three numbers here exist nowhere else in the corpus: the **450-character** prompt limit (which matches
fal's `maxLength: 450` exactly, and which the API reference does not state), **four variations per
Generate click** on the product surface, and the **30% default prompt influence** expressed as a
percentage rather than the API's `0.3` decimal. Billing is explicitly **not** per input character —
"the cost is not influenced by the text input you use" — which settles the metering question in favour
of duration/audio, not prompt length.

## Gaps

- The 450-character limit is stated for the product text box; no page says whether the API enforces the
  same limit (the OpenAPI schema declares no `maxLength`).
- "Four sound effects will be created each time" is a product-surface behaviour; the API returns one
  file per request and no page reconciles the two.
- No licence terms, watermarking statement, or language support.

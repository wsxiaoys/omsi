# ElevenLabs API reference: Create transcript (`POST /v1/speech-to-text`)

- Origin: ElevenLabs API Reference, "Create transcript" (Speech to Text),
  <https://elevenlabs.io/docs/api-reference/speech-to-text/convert> (markdown:
  <https://elevenlabs.io/docs/api-reference/speech-to-text/convert.md>)
- Evidence kind: official documentation (API reference, request schema)
- Publication date: none stated; living page. Capture date 2026-10-26
- Relevant models: `scribe_v2` (also used by `scribe_v2_medical` and `scribe_v1`)

## Endpoint behaviour (verbatim)

> Transcribe an audio or video file. If webhook is set to true, the request will be processed
> asynchronously and results sent to configured webhooks. When use_multi_channel is true and the
> provided audio has multiple channels, a 'transcripts' object with separate transcripts for each
> channel is returned; set multichannel_output_style='combined' to instead receive a single transcript
> with all channels merged and sorted by time.

Request is `multipart/form-data`; "Exactly one of the file or cloud_storage_url parameters must be
provided."

## Parameters relevant to Scribe v2 (verbatim excerpts)

| Field | Type | Constraint / description |
| --- | --- | --- |
| `model_id` | string | **required**. "The ID of the model to use for transcription." |
| `file` | file | "The file to transcribe (100ms minimum audio length). All major audio and video formats are supported. […] The file size must be less than **5.0GB**." |
| `language_code` | string | ISO-639-1 or ISO-639-3; "Defaults to null, in this case the language is predicted automatically." |
| `timestamps_granularity` | enum | "'word' provides word-level timestamps and 'character' provides character-level timestamps per word." |
| `diarize` | boolean | "Whether to annotate which speaker is currently talking in the uploaded file." |
| `num_speakers` | integer | "The maximum amount of speakers that can be predicted is 32. Defaults to null, in this case the amount of speakers is set to the maximum value the model supports." |
| `diarization_threshold` | double | Only settable "when diarize=True and num_speakers=None"; "Defaults to None, in which case we will choose a threshold based on the model_id (0.22 usually)." |
| `tag_audio_events` | boolean | "Whether to tag audio events like (laughter), (footsteps), etc. in the transcription." |
| `keyterms` | list of string | "The number of keyterms cannot exceed 1000. The length of each keyterm must be less than 50 characters. Keyterms can contain at most 5 words (after normalisation)." Unsupported characters: `` < > { } [ ] \ ``. "Usage of this parameter will incur an additional 20% surcharge on the base transcription cost. When more than 100 keyterms are provided, a minimum billable duration of 20 seconds applies per request." |
| `no_verbatim` | boolean | "If true, the transcription will not have any filler words, false starts and non-speech sounds. Only supported with scribe_v2 model." |
| `entity_detection` | object/string | `'all'`, a category (`'pii'`, `'phi'`, `'pci'`, `'other'`, `'offensive_language'`) or specific types; "detected entities will be returned in the 'entities' field with their text, type, and character positions." |
| `entity_redaction` / `entity_redaction_mode` | object / string | Redaction must be a subset of detection; modes `redacted`, `entity_type`, `enumerated_entity_type`. |
| `transcript_edit` | string | "Natural-language instruction applied to the final transcript (max 2000 characters) […] Cannot be combined with entity_detection, entity_redaction or use_multi_channel. […] additional 30% surcharge on the base transcription cost, billed for at least 10 seconds of audio." |
| `use_multi_channel` | boolean | "A maximum of 5 channels is supported. Each channel is billed independently at the full audio duration, so cost scales linearly with the number of channels." |
| `multichannel_output_style` | enum | `separate` (default) or `combined`; combined "requires timestamps […] and does not support entity detection or redaction". |
| `use_speaker_library` | boolean | Matches "detected speakers […] against registered speakers in the workspace's speaker library". |
| `detect_speaker_roles` | boolean | "Requires diarize=true. Cannot be used with use_multi_channel=true. […] speaker_id values will be 'agent' and 'customer' […] additional 10% surcharge." |
| `temperature` | double | 0.0–2.0; "If omitted, we will use a temperature based on the model you selected which is usually 0." |
| `seed` | integer | "best effort to sample deterministically […] Determinism is not guaranteed." 0–2147483647. |
| `file_format` | enum | `pcm_s16le_16` or `other`; for PCM "the input audio must be 16-bit PCM at a 16kHz sample rate, single channel (mono), and little-endian byte order. Latency will be lower". |
| `source_url` | string | "Supports hosted video or audio files, YouTube video URLs, TikTok video URLs, and other video hosting services." |
| `cloud_storage_url` | string | "[Deprecated] […] The file must be accessible via HTTPS and the file size must be less than 2GB." |
| `webhook`, `webhook_id`, `webhook_metadata` | — | Async delivery; metadata "maximum depth of 2 levels and maximum size of 16KB". |
| `enable_logging` | boolean | default `true`; "When enable_logging is set to false zero retention mode will be used for the request […] Zero retention mode may only be used by enterprise customers." |

Example request body in the reference uses `"model_id": "scribe_v2"`.

## Summary

This is the authoritative first-party statement of what a Scribe v2 request can carry: word- or
character-level timestamps, diarization to 32 speakers with an adjustable threshold, audio-event
tagging, up to 1000 keyterms, entity detection and redaction, speaker library matching, agent/customer
role detection, experimental transcript editing, multichannel (≤5 channels) and YouTube/TikTok URL
input.

**Size-limit contradiction with the vendor's own FAQ:** this reference says the uploaded file must be
"less than 5.0GB"; the capabilities page says "Files up to 3 GB in size are supported" and lists 3 GB
as a key fact. Both are first-party, captured the same day; the page-level conflict is unresolved.

Pricing-relevant surcharges documented here: keyterms +20%, transcript editing +30% (min 10 s billed),
speaker-role detection +10%, and per-channel full-duration billing for multichannel.

## Gaps

- No price per hour, no latency figures, no accuracy figures.
- No statement of which model IDs accept which parameters beyond `no_verbatim` ("Only supported with
  scribe_v2 model"), so per-parameter model coverage is incomplete.

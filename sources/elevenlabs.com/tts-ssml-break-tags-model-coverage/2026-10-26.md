# ElevenLabs help center: SSML break tags and phoneme tags — which models support them

- Origin: ElevenLabs Help Center, "Do pauses and SSML phoneme tags work with the API?",
  <https://elevenlabs.io/docs/help-center/technical/do-pauses-and-ssml-phoneme-tags-work-with-the-api>
  (read as Markdown via `Accept: text/markdown`)
- Evidence kind: official documentation (vendor support answer)
- Publication date: not stated on page
- Capture date: 2026-10-26
- Relevant models: `eleven_turbo_v2_5`, `eleven_flash_v2`, `eleven_turbo_v2`, `eleven_multilingual_v2`,
  `eleven_v3`, `eleven_v4`

## Captured content (verbatim)

> **Pauses:**
>
> You can use the break tag when generating audio via the API. This will create an exact and natural
> pause in the speech. It is not just added silence between words, but the AI has an actual
> understanding of this syntax and will add a natural pause.
>
> The syntax for the break tag is `<break time="1.5s" />` and the AI can handle pauses of up to 3
> seconds in length.
>
> All of our models, **with the exception of Eleven v4 and Eleven v3**, support SSML break tags, and
> these can be used when generating audio via the API.

> **Phonemes:**
>
> Eleven v4 has improved native support for IPA. For more information, see IPA with Eleven v4.
>
> Our **Eleven Flash v2** and **Eleven Turbo v2** models support **SSML phoneme tags**, and these can
> be used when generating audio via the API using these models.
>
> Please note that phonemes are available only for English language models and are currently not
> supported for other languages.

## What this establishes

- **SSML break tags are supported by every model except v3 and v4**, which by exclusion includes
  `eleven_turbo_v2_5`. That is the clearest documented control-surface advantage Turbo v2.5 still has
  over the current flagship family: v3 and v4 cannot take `<break time="…" />`, Turbo v2.5 can.
- **SSML phoneme tags are narrower**: the page names only Flash v2 and Turbo v2 (both English), so
  Turbo v2.5 is *not* in the phoneme-tag list. A pipeline that relied on phoneme tags on Turbo v2 or
  Flash v2 has no documented equivalent here.

## Gaps

- The page states the break-tag support rule by exclusion ("all of our models, with the exception
  of…") and never names `eleven_turbo_v2_5`, so the inclusion is an inference from a vendor rule, not
  an explicit per-model statement. A second vendor page contradicts it — see
  `../tts-how-can-i-add-pauses/2026-10-26.md`.
- No statement of whether break tags work through third-party hosts (fal, Replicate), whose schemas
  pass `text` through unmodified.

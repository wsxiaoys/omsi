`GET https://api.fal.ai/v1/models?endpoint_id=alibaba/abot-world-0` returns the same description with
`status: "active"` and `updated_at 2026-10-18T16:05:18.836Z`.

**`hostingType: "serverless"` is a real distinction in this catalogue.** fal marks its own endpoints
`serverless` and marks forwarded-to-vendor endpoints `proxy`; the same catalogue records every
`alibaba/happy-horse/*` endpoint as `hostingType: "proxy"`
([Happy Horse catalogue](../happy-horse-catalogue/2026-10-26.md)). `abot-world-0` is `serverless`,
which is consistent with fal running the Apache-2.0 weights on its own GPUs rather than forwarding to
an Alibaba API — and consistent with the absence of any first-party inference API for this model.

## Price string (verbatim)

Endpoint page, in the playground footer:

> Sessions cost **$0.00125** per **second** of video generated.

`llms.txt` restates it as `- **Price**: $0.00125 per seconds`. The basis is wall-clock seconds of
generated video stream, not per request, per frame, or per token. At 16 FPS that is $0.000078 per
frame, ≈$0.075 per minute, ≈$4.50 per hour of continuous session.

`robbyant/lingbot-world-2` carries a **word-for-word identical `shortDescription`** to

## Playground presets shipped with the endpoint

The page and the AsyncAPI examples carry ten built-in starting worlds, grouped in the UI as
"Cinema collection" (5) plus one each of Adventure, Desert, Mountains, Forest and Arctic:

The Village Beneath the Peaks · The Sanctuary of Giants · The Robot Delivering Dreams · The Depot of
Forgotten Characters · The Greenhouse — An Indoor Archipelago · Ancient Ruins · Desert Valley ·
Alpine Meadow · Forest Stream · Northern Lights

Each example pairs a long English world description (≈900 characters) with a thumbnail under
`fal.ai/worlds-gallery/…`. The Village Beneath the Peaks example text is a third-person
exploration prompt that spells out the control contract in prose: "Third-person follow camera
directly behind the character … Keep the avatar visible and recognizable in every future view …
stable upright horizon, no cuts, no first-person conversion. Navigation-ready: minimum six-metre-wide
unobstructed level route … no stairs or narrow doorways."

## What this establishes

- fal hosts ABot-World-0 as a first-class endpoint in a category (`worlds`) that it created for exactly
  this kind of model, alongside five others. It is not filed under text-to-video or image-to-video.
- The billing basis is time-streamed, which only makes sense for an unbounded interactive session; fal
  publishes no per-clip price because there are no clips.
- The endpoint's metadata dates (2026-10-15) are fal's listing date, ~14 weeks after the vendor's
  2026-07-09 model release. fal does not name the checkpoint it serves.

## Gaps

- No model revision, checkpoint name, or parameter count in the catalogue row; `githubUrl` is empty.
- `licenseType: "commercial"` is fal's own field. It does not restate the upstream Apache 2.0 licence
  and should not be read as a change to it.
- No published concurrency limit, region, cold-start figure, or maximum session length.

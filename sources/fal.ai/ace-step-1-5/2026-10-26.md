**The endpoint is callable but not listed.** It has a live OpenAPI schema and an `llms.txt`, yet it
does not appear in fal's public catalogue search: `?keywords=acestep` returns the five v1 endpoints and
nothing else, and `?keywords=ace-step-1.5` returns zero items. `api.fal.ai/v1/models?endpoint_id=…`
returns the ID with no metadata block, while the same call for `fal-ai/ace-step` returns a full
`metadata` object. So a reader browsing fal's catalogue would conclude that fal hosts only v1.

## Pricing (verbatim)

> Your request will cost $0.0003 per output second. Thinking-enabled requests run at 2×.

With `thinking` defaulting to **true**, the default effective rate is **$0.0006 per output second** —
three times the v1 endpoint's $0.0002/s. A 60-second generation costs **$0.036** with thinking on and
**$0.018** with it off; a 600-second one costs $0.36 and $0.18 respectively.

## Gaps

- No output container or sample rate in the schema; `llms.txt` lists no `audio_format` field even
  though the vendor REST API and the Replicate wrapper both expose one.
- fal states no reason for `status: "unlisted"`, and no date for when, or whether, it will be listed.
- No indication of which DiT/LM checkpoint combination the endpoint runs (turbo vs base vs XL), and no
  revision field.
- No latency or queue data captured.

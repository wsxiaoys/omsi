## Endpoint identity

`fal-ai/ace-step`: title "ACE Step", `category: "text-to-audio"`, `kind: "inference"`,
`hostingType: "serverless"`, `licenseType: "commercial"`, `status: "public"`, `deprecated: false`,
`removed: false`, `group: {"key": "ace-step", "label": "Lyrics to Audio"}`,
`model_url: https://fal.run/fal-ai/ace-step`.

`hosting: "serverless"` matters: fal is running the open weights on its own hardware, not proxying a
vendor API. The listing date, **2025-05-08**, is two days after ACE-Step v1's open-source release and
five and a half months before the roster window opens.

Output schema `AceStepOutput`: `{audio: File, seed: int, tags: string, lyrics: string}`. `File` carries
`url`, `content_type`, `file_name`, `file_size` — the host returns a downloadable file, and **neither
the schema nor the price string names a sample rate or a container format**.

## Sibling endpoint differences (verbatim field names)

- `prompt-to-audio`: takes `prompt` (natural language) instead of `tags`, and exposes
  **`instrumental: boolean = false`** ("Whether to generate an instrumental version of the audio"),
  which the main endpoint expresses only through the `[inst]` lyrics sentinel. `duration` is 5–240,
  default 60.
- `audio-to-audio`: takes `audio_url` plus `original_tags`, `original_lyrics`, `original_seed`, and
  `edit_mode: "remix"` — "Whether to edit the lyrics only or remix the audio". **No `duration` field.**
- `audio-inpaint`: takes `audio_url`, `start_time` (default 0), `end_time` (default 30),
  `start_time_relative_to` / `end_time_relative_to` (`start` | end), `variance` (default 0.5).
- `audio-outpaint`: takes `audio_url`, `extend_before_duration` (default 0) and
  `extend_after_duration` (default 30).

The audio-to-audio schema reuses the outpaint description verbatim — "URL of the audio file to be
outpainted" — on a remix/edit endpoint, so fal's field copy is not reliable.

## Pricing (verbatim)

> Your request will cost **$0.0002** per second of generated audio. For **$1** you can generate 5,000
> seconds (approximately 83.33 minutes) of music from lyrics.

Billing is on **output audio duration**, not on compute time and not per request. A 60-second
generation therefore costs $0.012.

## Gaps

- No sample rate, no output container, and no maximum file size anywhere in the schema or llms.txt.
- fal does not state which checkpoint it runs; the endpoint predates v1.5, its parameters match v1's
  published inference controls (`tags`, `lyrics`, guidance scales, 27 steps), and there is no
  revision/commit field.
- No latency figures, no queue-time data and no example output captured.

## The roster's discovery path is a landing page, not an endpoint

`https://fal.ai/models/bria/fibo-edit-1.5` returns HTTP 200 but is a client-rendered family landing
page: the served HTML contains no model data ("Loading model" shell) and its `<title>` is literally
`Claude`. `GET https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=bria/fibo-edit-1.5` returns
**404**, while the suffixed IDs (`.../edit`, `.../expand`, …) each return a full schema. The callable
IDs carry a suffix.

## Billing object on the model page (verbatim)

The `/edit` model page embeds:

```json
"endpointBilling": {"endpoint": "bria/fibo-edit-1.5/edit", "billing_unit": "images", "price": 0.04,
  "provider_type": "fal", "is_partner_api": false, "balance_check": false,
  "enterprise_status": "ready"}
```

`provider_type: "fal"` with `is_partner_api: false` means fal reports running the model on its own
inference, not proxying Bria's API — unlike the legacy `fal-ai/bria/*` endpoints, which the same
catalogue marks `hostingType: "proxy"`. The rendered page states: "Your request will cost $0.04 per
image."

## Input schema for `bria/fibo-edit-1.5/edit` (verbatim field descriptions)

| Field | Type / default | Description |
| --- | --- | --- |
| `image_urls` | array of string, nullable | "1-4 reference images (files or URLs). Order is significant: the instruction is resolved against the images in the order they are sent." |
| `instruction` | string, nullable | "Instruction for image editing." Example: "Uncross her arms and place the serum bottle in her right hand raised beside her face, label toward the camera." |
| `aspect_ratio` | enum `1:1`,`2:3`,`3:2`,`3:4`,`4:3`,`4:5`,`5:4`,`9:16`,`16:9`, nullable | "Output aspect ratio. Left unset, the output keeps the ratio of the first reference image. A chosen ratio applies only with two or more reference images; with a single reference the output keeps that image's ratio either way." |
| `seed` | integer, default `5555` | "Random seed for reproducibility." |
| `mask_url` | string, nullable | "Mask (file or URL) marking the region to regenerate: white where the model should edit, black elsewhere. Single-reference requests only, and it must be the same size as that image. A masked edit comes back at the reference's own resolution." |
| `sync_mode` | boolean, default `false` | "If true, returns the image directly in the response (increases latency)." |
| `structured_instruction` | `StructuredInstruction` object, nullable | "A pre-built structured prompt, used verbatim instead of having VGL build one when no instruction is sent. Accepts what a previous edit returned." |

Output schema (`FiboEdit15EditOutput`, required `image`, `structured_instruction`):

| Field | Description |
| --- | --- |
| `image` | "The edited image, in the source aspect ratio unless aspect_ratio was set." |
| `images` | "Single-element list holding the same image, kept for callers of the earlier Fibo Edit endpoint." |
| `structured_instruction` | "The structured instruction the model ran, expanded from the built-in instruction plus anything passed in `instruction`. Returned so you can see how the brief was interpreted." |

`StructuredInstruction` fields: `context`, `edit_instruction`, `text_render[]`,
`background_setting`, `photographic_characteristics` (`lens_focal_length`, `camera_angle`, `focus`,
`depth_of_field`), `aesthetics` (`color_scheme`, `preference_score`, `mood_atmosphere`,
`aesthetic_score`, `composition`), `short_description`, `objects[]` (`description`, `location`,
`relationship` — required, `relative_size`, `shape_and_color`, `texture`, `pose`, `clothing`, …),
`artistic_style`, `lighting` (`shadows`, `direction`, `conditions`), `style_medium`.

There is **no** `output_type`, no `n`, no negative prompt, and no explicit output-resolution control
on this endpoint.

## Gaps

- fal publishes no model card, no resolution table, and no statement of which checkpoint (Base or
  Turbo) each endpoint serves.
- The catalogue's `hostingType` field is missing on three of the four Fibo Edit 1.5 rows even though
  the endpoints are listed as `serverless` in `discovery` on `/edit`; the absence is not evidence of
  proxy hosting.
- No latency figures, no rate limits, and no statement of what fal's safety checker does on these
  endpoints (the `/edit` schema has no `enable_safety_checker` field, unlike other fal image models).
- The `virtual-try-on` and `product-holding` endpoints take 1–3 reference images, while `/edit` takes
  1–4; the exact reference semantics of the task endpoints beyond their descriptions are not published.

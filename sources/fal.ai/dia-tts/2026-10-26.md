## Input and output schema (verbatim OpenAPI)

`DiaTtsInput` (title `DiaRequest`) — one property, required:

```json
{"text": {"type": "string", "description": "The text to be converted to speech.", "title": "Text",
 "examples": ["[S1] Dia is an open weights text to dialogue model. [S2] You get full control over scripts and voices. [S1] Wow. Amazing. (laughs) [S2] Try it now on Fal."]}}
```

`DiaTtsOutput` (title `DiaOutput`) — one property, required:

```json
{"audio": {"$ref": "#/components/schemas/File", "description": "The generated speech audio",
 "examples": [{"url": "https://v3.fal.media/files/elephant/d5lORit2npFfBykcAtyUr_tmplacfh8oa.mp3"}]}}
```

`DiaTtsVoiceCloneInput` (title `CloneRequest`) — **also only `text`**:

```json
{"text": {"type": "string", "description": "The text to be converted to speech.", "title": "Text",
 "examples": ["[S1] Hello, how are you? [S2] I'm good, thank you. [S1] What's your name? [S2] My name is Dia. [S1] Nice to meet you. [S2] Nice to meet you too."]}}
```

`DiaTtsVoiceCloneOutput` (title `DiaCloneOutput`) — `audio` File, example URL
`https://v3.fal.media/files/tiger/smL9a_mr1PRIvZxDSVppk_output.wav`.

Neither schema has a `maxLength`, seed, temperature, cfg, reference-audio, or voice field. The
rendered playground form for both endpoints shows a single "Text *" input.

## Contradiction captured on the host's own pages

`fal-ai/dia-tts/voice-clone` is described as cloning "from a sample audio", yet its OpenAPI input
schema and rendered form expose **only `text`**. Nothing on the page explains how a caller supplies
the reference audio. The base `fal-ai/dia-tts` README makes the same claim ("Supports voice cloning
with reference audio", "Use voice cloning for consistent character voices") without a field to
carry the reference either.

## Gaps

- fal does not state which checkpoint it serves (April `Dia-1.6B` or the June `Dia-1.6B-0626`), nor
  the container bitrate or sample rate of the returned MP3/WAV.
- No `maxLength` is published, so fal's actual character ceiling is unknown; no duration cap is
  stated.
- No seed parameter, so fal output is not reproducible.
- No content-policy, refusal, or watermark statement specific to this endpoint.
- `licenseType: "commercial"` is fal's assertion about use through fal; it is not a licence grant
  and does not restate Nari Labs' Apache 2.0 terms.
- No latency figure and no rate limit beyond `max_concurrency: 8` in the internal app metadata.

- The roster label's endpoint **exists**: `fal-ai/elevenlabs/tts/turbo-v2.5` — the legacy `fal-ai/`
  namespace, not the newer `elevenlabs/` one used for Eleven v4.
- `status: "active"`, and no `deprecated` or `removed` field is returned, so fal has **not** flagged
  the endpoint as retired even though the vendor has. (Contrast the Eleven v4 record, which carries
  explicit `deprecated: false` / `removed: false` keys on the new-namespace endpoints.)
- `category: "text-to-speech"` here. The Eleven v4 record describes the legacy `fal-ai/elevenlabs/…`
  endpoints as sitting in the older `text-to-audio` category; this record contradicts that for this
  endpoint, and the discrepancy is left open.
- `license_type: "commercial"` — fal's own assertion about use through fal, not an ElevenLabs grant.

## Input schema (verbatim parameter descriptions)

| Parameter | Type | Default / range | Description |
| --- | --- | --- | --- |
| `text` | string, required | `minLength: 1`, **no `maxLength`** | "The text to convert to speech" |
| `voice` | string | default `"Rachel"` | preset names only — 20 examples ("Aria", "Roger", "Sarah", "Laura", "Charlie", "George", "Callum", "River", "Liam", "Charlotte", "Alice", "Matilda", "Will", "Jessica", "Eric", "Chris", "Brian", "Daniel", "Lily", "Bill") |
| `stability` | float | 0–1, default 0.5 | "Voice stability (0-1)" |
| `similarity_boost` | float | 0–1, default 0.75 | "Similarity boost (0-1)" |
| `style` | float | 0–1, default 0 | "Style exaggeration (0-1)" |
| `speed` | float | 0.7–1.2, default 1 | "Speech speed (0.7-1.2)… Extreme values may affect quality" |
| `timestamps` | boolean | default false | "Whether to return timestamps for each word in the generated speech" |
| `previous_text` / `next_text` | string | — | continuity for stitched generations |
| `language_code` | string | — | "Language code (ISO 639-1) used to enforce a language for the model. An error will be returned if language code is not supported by the model." |
| `apply_text_normalization` | enum | `auto` / `on` / `off` | text normalization mode |

Notable **absences** in the fal schema: no `output_format` field (the documented output is a single
`audio` file whose example URL ends `.mp3`), no `seed`, no `optimize_streaming_latency`, no
`previous_request_ids` / `next_request_ids`, no `use_speaker_boost`, and **no documented character
cap**. The vendor's 40,000-character limit is therefore not enforced or restated by this host schema.

  `{"url":"https://v3.fal.media/files/zebra/zJL_oRY8h5RWwjoK1w7tx_output.mp3"}`
- `timestamps` (`list<void>`, optional) — "Timestamps for each word in the generated speech. Only
  returned if `timestamps` is set to True in the request."

## What this establishes

- The endpoint named in the roster row is live, priced, and documented — the evidence floor's
  independent-host requirement is met by a real billing surface, not a marketing page.
- fal charges **$0.05 / 1K characters** against a vendor list price of $0.04, and exposes **MP3
  output only** as documented.
- fal does **not** propagate the vendor's deprecation: no `deprecated`/`removed` flag, `status:
  "active"`, `updated_at` 2026-04-21 (i.e. after the vendor had moved the model to "Older Models").

## Gaps

- No `maxLength` on `text`, so fal's real ceiling is unknown from the schema; it may be enforced
  upstream by ElevenLabs and surfaced as an error, but no source says so.
- No output-format parameter and no statement of sample rate or bitrate.
- `date` 2025-02-27 is unexplained and inconsistent with the 2024-07-19 launch; it cannot be read as
  a release date.
- No independent measurement of latency, quality or language accuracy on this endpoint.

## What this establishes

- fal has served Eleven v3 since **2025-08-20** — the alpha era, before the vendor's public API was
  generally available — and still lists it `status: active` with no deprecation flag two months after
  v4 shipped.
- **fal prices v3 at $0.10 per 1,000 characters**, which is *above* the vendor's $0.08 list rate for
  the same model. That is the opposite of the v4 family, where fal matched the vendor rate exactly.
- fal's character cap (5,000) matches the vendor's v3 cap, unlike v4 where fal halves it.
- **fal strips the control surface down**: no `output_format`, no `similarity_boost`, no `seed`, no
  stitching fields, and no voice-ID input — only 20 preset names plus a free-form string. The schema
  itself asserts that `eleven_v3` "doesn't support previous_text/next_text", which agrees with the
  vendor's stitching guide.
- MP3 is the only evidenced output; the schema gives no way to request PCM, WAV or Opus.

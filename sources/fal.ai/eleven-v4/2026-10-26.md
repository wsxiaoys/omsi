## Endpoint identity — the roster label is wrong

The live endpoint IDs are **`elevenlabs/tts/eleven-v4`** and **`elevenlabs/tts/eleven-v4-turbo`** —
the `elevenlabs/` namespace, **not** `fal-ai/elevenlabs/tts/…`. Both are new-style catalogue entries
with `modelFamily: "Eleven v4"`, `modelLab: "ElevenLabs"`, `status: "public"`, `deprecated: false`,
`removed: false`, `kind: "inference"`, `licenseType: "commercial"`, `hostingType: "proxy"`, and
`group.label` "Eleven V4" / "Eleven V4 Turbo".

The legacy `fal-ai/elevenlabs/tts/eleven-v3`, `fal-ai/elevenlabs/tts/multilingual-v2`,
`fal-ai/elevenlabs/tts/turbo-v2.5`, `fal-ai/elevenlabs/music`, `fal-ai/elevenlabs/sound-effects/v2`
endpoints keep the old `fal-ai/` prefix and the old `text-to-audio` category. So Eleven v4 is the
first ElevenLabs TTS family on fal's new namespace and under the new `text-to-speech` category.

`GET https://api.fal.ai/v1/models?endpoint_id=fal-ai/elevenlabs/tts/eleven-v4` returns the bare
endpoint ID with **no** model record, while the OpenAPI schema for that path still answers 200 —
the same bare-ID pattern fal shows for other unlisted paths. The `elevenlabs/…` form returns the full
record.

## What this establishes

- fal serves Eleven v4 and v4 Turbo as **proxied partner endpoints**, priced at the vendor's own list
  rate — $0.08 and $0.04 per 1,000 characters, identical to ElevenLabs' published API pricing. There
  is no host markup on this family, and no host discount.
- fal's **5,000-character cap contradicts the vendor's 10,000** for `eleven_v4`, and fal's cap is
  hard (`maxLength: 5000` in the schema), so a request the vendor accepts is rejected at fal.
- fal exposes **20 preset voice names** in the UI and a free-form string, but no voice-ID field and
  no cloning surface. The vendor's voice IDs and cloned voices are not reachable through this schema
  as documented.
- fal exposes 19 output-format values, missing the vendor's `wav_*` and `pcm_32000`/`mp3_24000_48`
  options, and missing `wav` entirely.
- `language_code` and `seed` are exposed, so cross-language generation and best-effort determinism
  are available through the host.

## Gaps

- No statement of which ElevenLabs account/workspace proxies the calls, or whether a fal request can
  use a voice created in the caller's own ElevenLabs workspace.
- No statement about watermarking on the fal route.
- The catalogue gives no ElevenLabs checkpoint or revision, so the served v4 revision is unknown
  (the vendor says the model keeps changing under one ID).
- `date` and `publishedAt` are fal catalogue timestamps; fal does not say what `date` means.
- No latency, concurrency-per-plan or rate-limit documentation beyond the runtime config fields.

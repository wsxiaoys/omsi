## Input schema (verbatim, `fal-ai/elevenlabs/music`)

- `prompt` (string, optional) — "The text prompt describing the music to generate"
- `composition_plan` (`MusicCompositionPlan`, optional) — "The composition plan for the music"
- `music_length_ms` (integer, optional) — "Must be between 3000ms and 600000ms. Optional - if not
  provided, the model will choose a length based on the prompt." (range 3000–600000)
- `force_instrumental` (boolean, default `false`)
- `respect_sections_durations` (boolean, default `true`) — "It will only have an effect if it is used
  with composition_plan."
- `output_format` (enum, default `"mp3_44100_128"`) — 19 values: `mp3_22050_32`, `mp3_44100_32/64/96/
  128/192`, `pcm_8000/16000/22050/24000/44100/48000`, `ulaw_8000`, `alaw_8000`,
  `opus_48000_32/64/96/128/192`. No `mp3_48000_*` values at all.

Output schema: `audio` (`File`, required) — "The generated music audio file in MP3 format", example
`music_generated.mp3`.

`MusicCompositionPlan` is the **v1 shape**: `positive_global_styles`, `negative_global_styles`,
`sections[]` (`section_name`, `positive_local_styles`, `negative_local_styles`, `duration_ms`
3000–120000, `lines`). There is no `chunks` shape, no `model_id`, no `finetune_id`, no `seed`, no
`store_for_inpainting` and no `sign_with_c2pa`.

## What this establishes

- **fal's roster endpoint is pinned to the v1-era surface.** Three independent signs: the discovery
  block has no `version` field while its siblings say `2` and `2.5`; the composition plan is
  `sections`-based (which the vendor restricts to `music_v1`); and the default `output_format` is
  `mp3_44100_128` (the vendor's v1 `auto` resolution), with the 48 kHz MP3 options that the vendor
  added for v2 on 2026-06-22 absent. No `model_id` field exists, so a caller cannot select v2 or v2.5
  through this endpoint.
- **fal charges 4× the vendor list price** on this endpoint: $0.60 per output minute against the
  vendor's $0.15, and fal additionally rounds any partial minute up, so a 30-second generation bills
  a full $0.60 (vendor arithmetic: $0.075).
- fal's endpoint is older than the roster window's later generations but its catalogue `date`
  (2025-12-22) is inside the window (≥ 2025-10-26).
- Duration bound on fal matches the vendor API schema (3 s – 10 min), not the vendor's 5-minute
  marketing figure.

## Gaps

- fal does not say which `music_v1` revision it proxies, nor whether the endpoint will be migrated to
  v2/v2.5 in place.
- No output sample rate is stated for the MP3 result beyond the `output_format` enum.
- Nothing about licensing beyond `license_type: commercial`, which is fal's assertion, not the
  ElevenLabs music licence.
- No concurrency, queue-priority or latency figures.
- Whether a finetune can be used through fal is undocumented (no `finetune_id` field).

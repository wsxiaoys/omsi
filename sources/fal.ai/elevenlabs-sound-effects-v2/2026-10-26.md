>

That is $0.12 per minute — identical to ElevenLabs' own list rate. fal's catalogue carries no separate
pricing block for this endpoint.

## Input schema (verbatim, from `llms.txt`; identical to the OpenAPI schema)

- **`text`** (string, required): "The text describing the sound effect to generate", with a
  `maxLength` of **450** in the OpenAPI schema. Examples: "Spacious braam suitable for high-impact
  movie trailer moments", "A gentle wind chime tinkling in a soft breeze".
- **`duration_seconds`** (float, optional): "Duration in seconds (**0.5-22**). If None, optimal
  duration will be determined from prompt." Range `0.5`–`22`.
- **`prompt_influence`** (float, optional): "How closely to follow the prompt (0-1). Higher values mean
  less variation." Default `0.3`, range `0`–`1`.
- **`output_format`** (`OutputFormatEnum`, optional, default `mp3_44100_128`): 19 options —
  `mp3_22050_32`, `mp3_44100_32`, `mp3_44100_64`, `mp3_44100_96`, `mp3_44100_128`, `mp3_44100_192`,
  `pcm_8000`, `pcm_16000`, `pcm_22050`, `pcm_24000`, `pcm_44100`, `pcm_48000`, `ulaw_8000`, `alaw_8000`,
  `opus_48000_32`, `opus_48000_64`, `opus_48000_96`, `opus_48000_128`, `opus_48000_192`.
- **`loop`** (boolean, optional): "Whether to create a sound effect that loops smoothly." Default
  `false`.

Output: a single `audio` file object ("The generated sound effect audio file in MP3 format"), e.g.
`https://v3.fal.media/files/lion/…_sound_effect.mp3`.

**No `model_id` field exists on fal's schema** — the version is baked into the endpoint path, so a
fal caller cannot select `eleven_text_to_sound_v3` even though the vendor API accepts it.

## The v1 path

`GET /v1/models?endpoint_id=fal-ai/elevenlabs/sound-effects/v1` returns
`{"models":[{"endpoint_id":"fal-ai/elevenlabs/sound-effects/v1"}], …}` — the bare endpoint ID with **no
metadata record**. The v1 OpenAPI schema and v1 `llms.txt` both return **HTTP 404**. So v1 survives
only as a path-shaped identifier: no catalogue entry, no schema, no price, no documentation.

## Summary

fal lists exactly one sound-effects endpoint for ElevenLabs, under the roster's own ID, as a proxied
`text-to-audio` model priced at $0.002/second. Its schema is **stale against the vendor in two
places**: `duration_seconds` is capped at **22 s** (the vendor's pre-v2 limit, raised to 30 s when v2
shipped) and the `output_format` enum has **no `wav_*` values** (ElevenLabs added WAV output on
2026-10-19). It does match the vendor's 450-character prompt limit, which the vendor's API reference
never states.

## Gaps

- `updated_at` is 2026-04-21, before the 2026-10-19 vendor WAV addition, which explains the missing WAV
  formats but does not explain the 22-second cap (v2 shipped with 30 s in September 2025, well before
  fal's last update).
- No statement of how fal bills sub-second or auto-duration generations; "$0.002 per seconds" is the
  only price string.
- No statement of which ElevenLabs model revision fal proxies, or whether the watermark survives.
- The `audio` output description says "in MP3 format" even when `output_format` requests PCM or Opus.

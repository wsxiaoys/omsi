## Input schema (`FashnTryonV16Input`)

Required: `model_image` ("URL or base64 of the model image"), `garment_image` ("URL or base64 of the
garment image").

| Field | Type | Default | Description (verbatim) |
| --- | --- | --- | --- |
| `output_format` | `png` \| `jpeg` | `png` | "'png' is highest quality, while 'jpeg' is faster" |
| `segmentation_free` | boolean | `true` | "Disables human parsing on the model image." |
| `num_samples` | integer 1–4 | `1` | "Number of images to generate in a single run… trying multiple images at once increases the chances of getting a good result." |
| `sync_mode` | boolean | `false` | "If `True`, the media will be returned as a data URI and the output data won't be available in the request history." |
| `enable_safety_checker` | boolean | `true` | "Authorized callers may set false to request relaxed screening." |
| `seed` | integer \| null | null | "Sets random operations to a fixed state…" |
| `mode` | `performance` \| `balanced` \| `quality` | `balanced` | "'performance' mode is faster but may sacrifice quality… 'quality' mode is slower but produces higher quality results." |
| `garment_photo_type` | `auto` \| `model` \| `flat-lay` | `auto` | "Specifies the type of garment photo to optimize internal parameters for better performance." |
| `category` | `tops` \| `bottoms` \| `one-pieces` \| `auto` | `auto` | "'auto' will attempt to automatically detect the category of the garment." |
| `moderation_level` | `none` \| `permissive` \| `conservative` | `permissive` | "'permissive' blocks only explicit content; 'conservative' also blocks underwear and swimwear. 'none' disables moderation only for accounts authorized to disable safety filters; for all other accounts it is treated as 'permissive'." |

Output: `{"images": [File]}`, e.g. `https://cdn.fashn.ai/<uuid>/output_0.png`.

Schema differences from FASHN's own API: fal has no `return_base64` (it uses `sync_mode` instead) and
adds `enable_safety_checker`; fal's `segmentation_free` description is one line, while FASHN's is
several. Otherwise the parameter set matches the first-party endpoint, which is consistent with fal
running FASHN's pipeline rather than a re-implementation.

## Pricing

$0.075 per generation — identical to FASHN's on-demand rate for 1 credit ($0.075/credit) at 1 credit
per output image. fal does not publish a per-sample breakdown; whether `num_samples: 4` bills as one
"generation" or four is not stated on the page.

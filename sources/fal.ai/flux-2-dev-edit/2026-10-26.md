## Captured content

### Pricing (verbatim, `llms.txt`)

> - **Price**: $0.012 per processed megapixels

The richer statement lives on the aliased endpoint page
`https://fal.ai/models/fal-ai/flux-2/edit/llms.txt`, which fal describes as "Image-to-image
editing with FLUX.2 [dev] from Black Forest Labs":

> Requests cost **$0.012** per megapixel of input and output. Input images will be resized to
> 1MP. For example, a 1024x1024 generation with 512*512 size image input will cost **$0.024**
> (1 MP input + 1 MP output, each costing **$0.012**).

### Reference-image limit (verbatim)

> - **`image_urls`** (`list<string>`, _required_): The URLs of the images for editing. A maximum
>   of 4 images are allowed, if more are provided, only the first 4 will be used.

### Other parameters

Identical defaults to the text-to-image endpoint: `guidance_scale` 2.5 (0–20),
`num_inference_steps` 28 (4–50), `num_images` 1–4, `acceleration` `none|regular|high` (default
`regular`), `enable_prompt_expansion` false, `enable_safety_checker` true, `output_format` png,
`image_size` 512–2048 per dimension.

## What this establishes

- fal charges **both input and output megapixels** at $0.012 each, and resizes input images to
  1MP before billing. A 1MP output with one 1MP reference therefore costs $0.024, double the
  text-to-image price for the same output size.
- **fal caps reference images at four**, which is materially lower than BFL's launch-blog "up to
  10" and the HF/GitHub multi-reference framing. The same 4-image cap appears on the aliased
  `fal-ai/flux-2/edit` page, so it is fal's limit, not a typo on one page.

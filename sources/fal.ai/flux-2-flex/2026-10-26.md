### Request schema for this endpoint

From fal's own OpenAPI for the endpoint,
`GET https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=fal-ai/flux-2-flex`, schema
`Flux2FlexInput`:

| Field | Type / range | Default |
| --- | --- | --- |
| `prompt` | string | required |
| `num_inference_steps` | integer, 2–50 | **28** |
| `guidance_scale` | number, 1.5–10 | **3.5** |
| `seed` | integer \| null | — |
| `image_size` | preset enum (`square_hd`, `square`, `portrait_4_3`, `portrait_16_9`, `landscape_4_3`, `landscape_16_9`) or custom `ImageSize` | `landscape_4_3` |
| `output_format` | `jpeg`, `png` | `jpeg` |
| `safety_tolerance` | string enum `"1"`–`"5"` | `"2"` |
| `enable_safety_checker` | boolean | `true` ("Disabling it requires account authorization; unauthorized requests are always checked.") |
| `sync_mode` | boolean | `false` |

The playground UI on the page offers 1K / 2K / 2.3K image-size presets with a ratio lock. The
schema has **no image input field** — this endpoint is text-to-image only; editing is a separate
endpoint (see [flux-2-flex-edit](../flux-2-flex-edit/2026-10-26.md)).

## What this establishes

- fal is a second addressable [flex] surface with the same control surface but **different
  defaults from BFL's API**: steps 28 (BFL 50, range starts at 2 not 1) and guidance 3.5
  (BFL 5).
- fal's price is $0.05/MP on both input and output, rounded up — the same headline rate as BFL's
  output rate, but fal states the input charge and the rounding rule explicitly, which BFL's
  page does not.
- fal exposes no `prompt_upsampling` control for [flex], unlike BFL (default `true`) and
  Replicate (default `true`). Whether upsampling is applied on this endpoint is not stated.
- fal's safety ladder is 1–5 as strings, not BFL's 0–7 integers, so a `safety_tolerance` value is
  not portable between the two.

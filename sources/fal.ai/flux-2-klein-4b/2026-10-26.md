## Pricing (verbatim)

> Your request will cost **$0.005 per megapixel**.

That is a flat per-output-megapixel rate with no separate first-megapixel step and no stated input
charge — a different schedule from BFL's first-party one ($0.014 first MP + $0.001/MP, with input
megapixels billed). At 1 MP, fal is ~$0.005 against BFL's ~$0.014.

## Input schema (selected fields, verbatim descriptions)

| Field | Type / bounds | Description |
| --- | --- | --- |
| `prompt` | string, required | — |
| `num_inference_steps` | integer, **4–8**, default **4** | "The number of inference steps to perform." |
| `image_size` | preset enum or `{width,height}` | "The size of the image to generate." Presets: `square_hd`, `square`, `portrait_4_3`, `portrait_16_9`, `landscape_4_3` (default), `landscape_16_9` |
| `num_images` | integer | "The number of images to generate." |
| `seed` | integer or null | — |
| `output_format` | enum `jpeg`, `png` (default), `webp` | "The format of the generated image." |
| `enable_safety_checker` | boolean | "If set to true, the safety checker will be enabled. Disabling it requires account authorization; unauthorized requests are always checked, and images flagged as unsafe are returned as black images." |

There is **no `guidance_scale` field** — consistent with a distilled checkpoint — but fal does expose
a 4–8 step range, which BFL's own API does not. fal's named presets top out at roughly 1 MP, so
reaching a 4 MP output requires custom `width`/`height` (the schema accepts a custom object).

## Published example output (verbatim from the page's example result)

```json
{
  "seed": 877772820,
  "images": [{ "url": "...", "width": 1024, "height": 768, "content_type": "image/png" }],
  "prompt": "Cheetah in pre-sprint crouch, ...",
  "timings": { "inference": 0.16911567200077116, "safety_checker": 0.019458756996755255 },
  "has_nsfw_concepts": [false]
}
```

A 1024×768 (~0.79 MP) generation reporting **0.169 s** of inference and **0.019 s** of safety
checking. This is one host-published sample on fal's infrastructure, not a benchmark and not a test
run for this page; it is consistent with BFL's "sub-second" claim and with the ~0.3 s GB200 figure.

## What this establishes

- fal hosts the distilled 4B as an independent deployment with its own price ($0.005/MP), its own
  step range (4–8), and its own presets — so fal behaviour is not identical to BFL's fixed-config
  endpoint.
- fal's catalogue `date` (2026-01-15) matches BFL's launch date, so fal listed it at launch.
- `license_type: commercial` is fal's catalogue field about use through fal, not a BFL licence
  statement; the weights' actual licence is Apache 2.0 per BFL.

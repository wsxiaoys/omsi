## What this establishes

- **The Base 9B checkpoint is obtainable as a hosted inference endpoint on fal**, at
  **$0.02 per megapixel** — over 3x the distilled 9B's $0.006/MP on the same host
  ([fal t2i record](../../fal.ai/flux-2-klein-9b/2026-10-26.md)). Base is the more expensive route, which is
  consistent with it running 50 steps rather than 4.
- **A LoRA is a first-class input here**, matching the trainer's `inference_endpoint_ids`
  pointer to this endpoint ([trainer record](../../fal.ai/flux-2-klein-9b-base-trainer/2026-10-26.md)).
- BFL states that the Base variants "are not offered on the public API"
  (`../../bfl.ai/flux2-klein-9b-overview/2026-10-26.md`). This endpoint is therefore a
  **host-only** way to run Base 9B without your own GPU: first-party sells the distilled 9B
  (plus `flux-2-klein-9b-kv-finetuned` for your own LoRA on it), fal sells Base 9B inference.

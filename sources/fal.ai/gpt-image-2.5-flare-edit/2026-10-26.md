## What this establishes

- **16 reference images maximum** on fal's edit endpoint. OpenAI's own guide and API reference do
  not state a reference-image cap, so this is a host-side limit or an undocumented vendor limit —
  not established which.
- fal exposes an OpenAI-native mask path only through `image_passthrough` (or a `provider_options`
  escape hatch); the default path takes a white-on-edit/black-on-keep mask, which is the inverse
  convention of OpenAI's alpha-mask requirement. That inversion is documented here and is worth
  noting for anyone porting requests.

## Positioning (verbatim)

> OpenAI's default image model for most applications. Fast, high-quality generation with natural
> lighting, rich textures, and support for complex layouts including transparent backgrounds.

GPT Image 2.5" link, and the endpoint's group label is "Text to Image Flare".

## Pricing (verbatim from the page's pricing block)

> Text tokens (per 1M): **$5.00** input, **$1.25** cached, **$10.00** output.
> Image tokens (per 1M): **$8.00** input, **$2.00** cached, **$30.00** output. Changing the
> **quality** parameter significantly affects cost; by default we use **high**. Adjust it to your
> preference.
> See the description at the bottom of this page for more details on how much canonical image
> sizes cost. Total cost is rounded up to the closest hundredth of a cent ($0.0001.)

Note the mismatch with OpenAI: fal's **default `quality` is `high`**, OpenAI's default is `auto`.

## Endpoint structure (observed)

- The **callable** endpoints are `openai/gpt-image-2.5/flare/text-to-image` and
  `openai/gpt-image-2.5/flare/edit`. fal's `sitemap.xml` lists exactly those two under
  `flare` (and the matching pair under `sunburst`).
- The parent path `/models/openai/gpt-image-2.5/flare` renders a page but is **not itself an
  endpoint**: requesting its queue OpenAPI document returns `null` (HTTP 404). Treat it as a
  family landing page.
- There is no bare `openai/gpt-image-2.5` endpoint in the sitemap.

## Known gaps

- fal does not state which OpenAI snapshot it serves (i.e. whether it pins
  `gpt-image-2.5-flare-2026-09-08`). Its metadata `updated_at` of 2026-09-11 is not a model
  version.
- The claim that this is "OpenAI's default image model for most applications" is fal's
  characterization and conflicts with OpenAI's API reference, which documents Sunburst as the
  default for `/images/edits`. Not resolvable from fal's page.
- The pricing block promises a table of "canonical image sizes" further down the page; it was not
  captured as a data table here.
- "Authorized callers may set [the safety checker] false" implies gating that is not explained.
  This is host policy, not an OpenAI statement.

## Contradictions preserved

1. **Minimum pixel count and maximum edge disagree inside this page.** The Technical
   Specifications table says 655,340 px² minimum and a 4000 px maximum side; the "Flexible
   Resolutions" section says 655,360 px² and a 3840 px maximum edge. OpenAI's guide says 655,360
   and 3840. The table's figures look like typos; they are recorded as published, unresolved.
2. **Text output tokens are priced here but not by OpenAI.** fal lists "$10.00 output" per 1M text
   tokens; OpenAI's pricing page shows "-" for `gpt-image-2` text output, and OpenAI's 2.5 model
   pages say text output is not billed. Either fal is displaying a generic GPT Image rate card or
   billing something OpenAI does not. Unresolved.
3. **The model is also marketed as "ChatGPT Images 2.0"** in this page's pricing and feature
   sections ("The following table shows the pricing of ChatGPT Images 2.0…"). OpenAI does not use
   that name anywhere in the captured first-party docs. Treated as a host marketing alias, not an
   identity.
4. **Endpoint naming is inconsistent within fal.** The page path and description use
   `openai/gpt-image-2`, code samples use `fal-ai/gpt-image-2`, and the mask example calls
   `fal-ai/gpt-image-2/image-to-image` while the dedicated edit page is `openai/gpt-image-2/edit`.
   Which string is canonical on fal is unresolved.

## Host gaps against the first-party contract

| Capability | xAI docs | fal `xai/grok-imagine-image` |
| --- | --- | --- |
| Images per request | `n` 1–10 | `num_images` 1–4 |
| Aspect ratios | 16 values incl. `21:9`, `5:2` | 14 values, no `21:9`, no `5:2` |
| Edit references | up to 5 | "A maximum of 3 images are supported" |
| Resolution | `1k`, `2k`, `1.5k` in the schema enum | `1k`, `2k` only |
| `quality` parameter | 2.0 only | not exposed on any Grok Imagine Image endpoint |
| Safety | content policy review; no user control | `enable_safety_checker` toggle, default on |

`hostingType: "proxy"` means fal forwards to xAI rather than running the weights itself. That is
the host's own metadata field and it matches the "Partner" badge. For contrast, the same catalogue
lists fal's own deployments (for example Krea 3) as `"hosting": "serverless"`.

## Pricing contradiction inside the fal record

The catalogue `pricingInfoOverride` for this **text-to-image** endpoint is worded as
"**$0.02** for image output + **$0.002** for image input", but a text-only request has no input
image, and the model page calculator renders **$0.02 per image**. The override text appears to be
shared with the `/edit` endpoint. Treat $0.02 as the text-to-image price and $0.022 as the
single-input edit price; the catalogue string alone does not distinguish them.

## What this establishes

- fal publishes `xai/grok-imagine-image` as a **proxied** xAI endpoint from **2026-01-29**, with a
  separate `/edit` endpoint published the same day.
- fal's Grok Imagine Image line has three tiers on three different slugs, priced per image:
  standard ($0.02), quality ($0.05 / $0.07 by resolution), 2.0 ($0.04–$0.08 by quality and
  resolution). The standard tier is the cheapest and the only one without a resolution premium.
- fal's exposed parameter surface is **narrower** than xAI's documented surface on images per
  request, aspect ratios, and edit reference count, and it omits `quality` entirely.
- fal exposes a user-facing safety-checker toggle whose relaxed setting is gated on caller
  authorization.

## Gaps

- fal does not state which `grok-imagine-image` snapshot it proxies, or whether it refreshes when
  xAI moves the alias.
- No latency, throughput, or quality data on the fal page; no examples for the text-to-image
  endpoint (`"examples": []` in the catalogue record).
- `revised_prompt` implies prompt rewriting is on by default, but fal documents no way to disable
  it and xAI's image docs never mention rewriting.

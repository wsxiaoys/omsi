## Input schemas (verbatim field descriptions, condensed)

`Hunyuan3dV31ProTextTo3dInput` — required `prompt`:

| field | type | default | constraints / description |
| --- | --- | --- | --- |
| `prompt` | string | — | "Text description of the 3D content to generate. Max 1024 UTF-8 characters." |
| `generate_type` | enum `Normal`, `Geometry` | `Normal` | "Normal: textured model. Geometry: geometry-only white model (no textures). LowPoly/Sketch are not available in v3.1." |
| `enable_pbr` | boolean | false | "Enable PBR material generation (metallic, roughness, normal textures). Ignored when generate_type is Geometry." |
| `face_count` | integer | 500000 | "Target polygon face count. Range: 40,000-1,500,000. Default: 500,000." |

`Hunyuan3dV31ProImageTo3dInput` — required `input_image_url` ("Front view image URL. Resolution: 128-5000px,
max 8MB, formats: JPG/PNG/WEBP. Tips: simple background, single object, object >50% of frame."), plus the same
`generate_type` / `enable_pbr` / `face_count` fields and seven optional view images:

| field | description |
| --- | --- |
| `left_image_url`, `right_image_url`, `back_image_url` | "Optional … view image URL (JPG/PNG recommended)." |
| `top_image_url` | "Optional top view image URL (v3.1 exclusive, JPG/PNG recommended)." |
| `bottom_image_url` | "Optional bottom view image URL (v3.1 exclusive, …)." |
| `left_front_image_url`, `right_front_image_url` | "Optional …-front 45 degree angle view image URL (v3.1 exclusive, …)." |

`Hunyuan3dV31RapidTextTo3dInput` — required `prompt` ("Max 200 UTF-8 characters."), `enable_pbr` (false;
"Does not take effect when enable_geometry is True"), `enable_geometry` (false; "Generate geometry-only white
model without textures. When enabled, enable_pbr is ignored and OBJ is not supported (default output is
GLB)."). **No `face_count`, no view images, no `generate_type`.**

`Hunyuan3dV31RapidImageTo3dInput` — required `input_image_url`, plus `enable_pbr` and `enable_geometry`.

`Hunyuan3dV31SmartTopologyInput` — `input_file_url` ("URL of GLB or OBJ file to optimize topology. Max size:
200MB."), `input_file_type` (default `glb`), `face_level` (`high` | `medium` | `low`, default `medium`),
`polygon_type` (`triangle` | `quadrilateral`, default `triangle`).

`Hunyuan3dV31PartInput` — required `input_file_url` ("URL of FBX file to split into parts. ONLY FBX format
supported. Max size: 100MB, face count ≤30,000. Recommended: AIGC-generated models.").

## Output schemas

- Pro text and Pro image: `model_glb` (required, "Generated 3D object in GLB format"), `model_urls`
  (required), `thumbnail`, `seed`.
- `ModelUrls` fields: `glb`, `obj`, `fbx`, `mtl` ("MTL material file for OBJ model"), `texture` ("Texture
  image for the 3D model"), `usdz` ("USDZ format 3D model") — all nullable.
- Rapid text: `model_obj`, `model_urls`, `material_mtl`, `texture`, `thumbnail` (no `model_glb`).
- Rapid image: `model_glb` ("Contains GLB if available, otherwise OBJ"), `model_urls`, `material_mtl`,
  `texture`, `thumbnail`.
- Smart Topology: `model_glb` ("Processed 3D model with optimized topology (primary file)"), `model_urls`.
- Part: `result_files` ("List of generated part files in FBX format").
- No rig, skeleton, animation, or USDZ-only path appears as an output option anywhere in this family.

## Path checks

- `https://fal.ai/models/fal-ai/hunyuan-3d/v3.1` returns HTTP 200 as a **group landing page**, but
  `GET https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=fal-ai/hunyuan-3d/v3.1` returns HTTP 404
  (body `null`) and `api.fal.ai/v1/models?endpoint_id=fal-ai/hunyuan-3d/v3.1` returns a stub record with no
  metadata. The prefix is therefore **not callable**; every real call goes to one of the six suffixed endpoints.
- Each of the six suffixed endpoints resolves its own queue OpenAPI schema at the same `endpoint_id`.
- `fal-ai/hunyuan3d-v3` (the 3.0 family prefix) is likewise a separate group with three suffixed endpoints.

## Gaps

- fal states no model version beyond the path segment `v3.1`; no checkpoint, parameter count, or Tencent API
  tier mapping is published. The Pro/Rapid naming matches Tencent's Professional/Express tiers by parameter
  surface, but fal never says so.
- `face_count` minimum 40,000 on both Pro endpoints contradicts Tencent's documented range starting at 3,000;
  no source explains the difference.
- No latency, queue-time, texture resolution, up-axis, unit scale, or UV-layout information is published.
- `model_urls.usdz` and `model_urls.fbx` are always nullable and no example response populates them, so whether
  FBX/USDZ are actually produced by the hosted route is unverified.

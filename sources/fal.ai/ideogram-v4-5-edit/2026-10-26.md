## Captured content

### Description (verbatim)

> Edit images with Ideogram 4.5: prompt edits with up to 4 reference images, optional mask, and a
> high-precision mode that keeps unchanged pixels intact.

> Ideogram 4.5 editing. Provide a source image and a prompt, plus up to 4 reference images (3 when
> a mask is used). edit_precision: regular (default) or high, which uses Precise Edit and restores
> unchanged pixels. Quality: very_low to high for regular, low to very_high for high precision.
> Output keeps the source size by default (image_size auto).

Tags: `realism`, `typography`, `editing`.

### Pricing (verbatim)

> Your request will cost **$0.008** per image with Very Low, **$0.03** with Low, **$0.06** with
> Medium, and **$0.22** with High quality. The image size does not change the price.

This matches the first-party Precise Edit / with-references column exactly
([Ideogram model page](../../ideogram.ai/ideogram-4-5-model-page/2026-10-26.md)).

### Input schema (verbatim)

- `prompt` (required).
- `image_url` (required): "Primary source image to edit."
- `reference_image_urls`: "Up to four references plus the primary source, or three references plus
  the primary source and mask."
- `mask_url`: "Mask matching the source dimensions. Black edits, white preserves. Must contain both
  regions after rounding."
- `edit_precision`: enum `regular`, `high`; default `regular`; "regular uses Generate; high uses
  Precise Edit with unchanged-pixel restoration. Both always prepare structured edit instructions."
- `quality`: enum `very_low`, `low`, `medium`, `high`; default `medium`.
- `image_size`: default `auto`; "auto preserves source geometry, downscaled by the provider if
  needed. Only unmasked regular edits accept named presets or custom sizes: dimensions >=256,
  multiples of 32, area <=4194304, ratio <=6:1."
- `num_images` 1–8; `seed`; `sync_mode`.

### Host-side mapping of the two first-party endpoints (important)

`edit_precision` is fal's explicit switch between the two first-party modes: `regular` → Generate
(with source images), `high` → Precise Edit. That confirms the two Ideogram endpoints are two
modes of one model ID rather than two models.

### Anomaly worth tracking

The description mentions a "very_high" quality tier for high precision ("low to very_high"), but
the `quality` enum exposes only `very_low`, `low`, `medium`, `high`. Either an undocumented tier
exists or the description is stale.

## Known gaps

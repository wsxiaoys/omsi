## Endpoint identity

The roster's `fal-ai/inworld-tts` is real, but the endpoint is **not** a generic "Inworld TTS" —
fal titles it **"Inworld TTS-1.5 Max"** and sets `modelFamily: "TTS-1.5 Max"`, `version: "1.5"`,
`modelLab: "Inworld"`, `category: "text-to-speech"`, `status: "public"`, `deprecated: false`,
`removed: false`, `kind: "inference"`, `licenseType: "commercial"`, `hostingType: "serverless"`.

Short description (verbatim): *"Text to Speech Endpoint for Inworld's TTS-1.5 Max."*

The keyword search returns exactly one Inworld endpoint: fal exposes **no** TTS-1.5 Mini and **no**
TTS-2 endpoint. There is no `fal-ai/inworld-tts-mini`, `fal-ai/inworld-tts-2`, or version suffix.

| Field | Type | Default | Constraint |

| `text` | string | — | **required**, `maxLength: 2000` — "The text to synthesize into speech. Maximum 2000 characters." |
| `voice` | enum (113 values) | `"Craig (en)"` | names are `<FirstName> (<lang>)` |
| `sample_rate_hertz` | enum | `48000` | `8000`, `16000`, `24000`, `32000`, `40000`, `48000` |
| `enable_safety_checker` | boolean | `true` | "Authorized callers may set false to request relaxed screening." |

Output schema: a single `audio` file. The documented example response is a `.wav` URL
(`…/38aud4s6sF7bOWFoQHaJk_tmpvv2htrpc.wav`), and the schema exposes **no** output-format or encoding
parameter, so fal's container is WAV by observation of the schema, not a selectable option.

### Voices, and an independent check on the language count

The `voice` enum has 113 entries, tagged by language in the name:

| Tag | Count |
| --- | --- |
| `en` | 73 |
| `zh`, `nl`, `fr`, `ko`, `es`, `ru` | 4 each |
| `de`, `it`, `ja`, `pl`, `pt`, `hi`, `he`, `ar` | 2 each |

That is **15 languages** — the same set Inworld's launch post names (English, Chinese, Japanese,
Korean, Russian, Italian, Spanish, Portuguese, French, German, Polish, Dutch, Hindi, Hebrew, Arabic).
fal's enum is therefore independent corroboration of the 15-language claim for TTS-1.5, derived from
a host's own parameter list rather than a restatement of vendor copy.

There is **no voice-cloning field**. Only the fixed preset list is reachable, so a caller's own
Inworld-cloned voice cannot be selected through this endpoint as documented.

## Pricing

`pricingInfoOverride`: "Your request will cost **$0.01** per 1,000 characters." That is
**$10 per 1M characters**, billed on input characters. For comparison, Inworld's own launch list for
TTS-1.5 Max was $25/1M.

## Summary

fal serves one Inworld model — TTS-1.5 Max — as a serverless, non-proxied endpoint, at $0.01/1K
characters, capped at 2,000 input characters, 8–48 kHz selectable output, preset voices only, with a
safety checker that authorized callers can relax.

## Gaps

- fal lists no `deprecated` flag even though the vendor marks the model deprecated; fal's
  `updated_at` of 2026-10-20 is the last catalogue touch, not a quality refresh.
- No statement of which upstream snapshot is served, or of what fal does if Inworld retires the
  model.
- No published output bitrate, channel count, or confirmation that the returned WAV is 16-bit.
- `enable_safety_checker: false` is described as available to "authorized callers"; the gating
  criteria are not published.

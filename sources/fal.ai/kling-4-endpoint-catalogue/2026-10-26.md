Two labelling facts worth recording. First, on the fal model page for `kling/v4` the site navigation's
"Kling 3.0" link points at the **O3** endpoints
(`/models/fal-ai/kling-video/o3/standard/image-to-video`) — read from that page's HTML, not from this
catalogue API. Second, the separate `v3` endpoints also title themselves "Kling 3.0". The same vendor
generation therefore appears under two fal naming schemes; neither is Kling 4.0. The `kling/v4` endpoints
are the only ones titled "Kling 4.0", and no `kling/v4/flash` endpoint appears in the catalogue (43 Kling
entries, 2 pages), consistent with the landing page's statement that 4.0 Flash is playground-only early
access.

## Summary

fal's catalogue lists four public `kling/v4` endpoints created 2026-10-16 and published 2026-10-21, hosted
by proxy (`hostingType: "proxy"`, i.e. fal forwards to Kling), licensed "commercial", with per-second USD
pricing of $0.157/720p and $0.235/1080p for generation and $0.094/720p and $0.141/1080p for video-input
work, billed on input plus output length with a 2× output floor. This is the endpoint set the roster's
discovery label `kling/v4` refers to.

## Gaps

- `status: "public"` on the endpoints coexists with the landing page's "API access coming soon"; the
  catalogue does not say whether the endpoints are callable or playground-only.
- No schema captured (the per-endpoint schema endpoint returned 404 through the same API path).
- No frame rate, codec or output container.
- No checkpoint identifier.

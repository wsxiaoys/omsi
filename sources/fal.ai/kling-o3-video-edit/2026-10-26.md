## The family label

Every Omni row carries `modelFamily: "Kling O3"`, `modelLab: "Kling"`, `licenseType: "commercial"`,
`hostingType: "proxy"`, `status: "public"`, `deprecated: false`, `removed: false`.

The video rows share `group.key: "kling-o3"` and `landingPageSlug: "kling-3"`; the image rows use
`group.key: "Kling-o3-Image"` and no landing page. So fal applies "O3" to the whole Omni 3 family —
video and image — while filing it under the Kling 3 landing page.

## Edit schema (identical on standard, pro and 4K)

Schema titles: `O3StandardEditVideoV2VInput`, `O3ProEditVideoV2VInput`, `O3_4kEditVideoV2VInput`.
Required: `prompt`, `video_url`. Verbatim fields:

| Field | Type | Default | Description (verbatim) |
| --- | --- | --- | --- |
| `prompt` | string, max 2500 | — | "Text prompt for video generation. Reference video as @Video1." |
| `video_url` | string | — | "Reference video URL. Only .mp4/.mov formats, 3-15s duration, 720-3840px resolution, max 200MB." |
| `image_urls` | array of image URLs | null | "Reference images for style/appearance. Reference in prompt as @Image1, @Image2, etc. Maximum 4 total (elements + reference images) when using video." |
| `elements` | array of `KlingV3ImageElementInput` | null | "Elements (characters/objects) to include. Reference in prompt as @Element1, @Element2." |
| `keep_audio` | boolean | **true** | "Whether to keep the original audio from the reference video." |
| `enable_safety_checker` | boolean | true | "Disabling safety checks requires account authorization; unauthorized requests are always checked." |
| `shot_type` | string, **const `"customize"`** | `customize` | "The type of multi-shot video generation." |

`video_url` limit description, verbatim: "Max file size: 200.0MB, Min width: 720px, Min height:
720px, Max width: 3840px, Max height: 3840px, Min duration: 3.0s, Max duration: 15.05s, Min FPS:
23.0, Max FPS: 60.0, Timeout: 30.0s".

`KlingV3ImageElementInput`: `frontal_image_url` ("The frontal image of the element (main view).") and
`reference_image_urls` ("Additional reference images from different angles. 1-3 images supported. At
least one image is required."). Images: ≤ 50 MB, ≥ 300×300, aspect 0.4–2.5.

**There is no `duration`, no `aspect_ratio`, no `negative_prompt`, no `cfg_scale` and no
`generate_audio` field on any of the three edit endpoints.** Output length and shape follow the source
video. By contrast, the sibling `o3/pro/video-to-video/reference` endpoint does expose `duration`
(`"3"`–`"15"`, "Video duration in seconds (3-15s for reference video)") and `aspect_ratio`.

Output, all three edit endpoints: a single `video` file (`content_type: video/mp4`).

## Summary

fal's O3 family is the host's name for Kling 3.0 Omni, split across nine video endpoints and two image
endpoints. The video-edit surface is three endpoints — standard (720p), pro (1080p), and 4K — that
share one schema: a source video, a prompt, up to four images/elements as references, and a
`keep_audio` toggle defaulting to **true**. The edit endpoints are billed at the family's
"with video input" rate ($0.126 / $0.168 / $0.42 per second), which is 50% above the audio-off
generation rate at the same resolution and reproduces the vendor's own "With Video Input × No Native
Audio" list price to the cent.

Two operational facts follow from the schema and are not stated in prose anywhere: the output inherits
the source clip's duration (there is no duration field), and audio is carried over from the source
rather than generated (there is no `generate_audio` field, only `keep_audio`).

## Gaps

- fal publishes no duration, frame rate, resolution or channel count for the *output* of an edit.
- `shot_type` is a single-value const on the edit endpoints, so the "multi-shot" control that the
  generation endpoints expose is not selectable here; fal does not explain why the field exists.
- fal's `video_url` accepts up to 15.05 s and 3840px, while the vendor user guide and Replicate both
  cap the source at 10 s and 2K. Whether fal transcodes, trims or forwards the longer input is not
  documented.
- No statement of what happens when `keep_audio` is false and the source has audio.
- No independent quality signal in fal's metadata; `hostingType: "proxy"` means fal forwards to Kling.

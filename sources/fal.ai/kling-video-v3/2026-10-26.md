### The roster's endpoint ID is a family prefix, not a callable endpoint

`GET https://fal.ai/api/openapi/queue/openapi.json?endpoint_id=fal-ai/kling-video/v3` → HTTP 404
(body `null`), as does `…/v3/pro`. Only the leaf endpoints return schemas. `api.fal.ai/v1/models`
does return a bare record for `fal-ai/kling-video/v3` with no metadata, which is the catalogue's
grouping entry rather than an invocable model.

### fal's own "Kling 3.0" nav label points at the O3 family

The site navigation item labelled **"Kling 3.0"** links to
`/models/fal-ai/kling-video/o3/standard/image-to-video`, not to a `v3` endpoint. The `o3` rows carry
`modelFamily: "Kling O3"`, `landingPageSlug: "kling-3"`, the same 2026-02-04 publish date as the v3
rows, and descriptions such as "Kling O3 Omni generates new shots guided by an input reference
video" and (for the image siblings) "Kling Omni 3: Top-tier image-to-image". The O3 family is
therefore fal's name for the vendor's **Kling 3.0 Omni**. fal exposes three distinct 3.0 surfaces —
`v3`, `v3/turbo`, `o3` — under one landing page.

## Input schema (verbatim descriptions)

`fal-ai/kling-video/v3/pro/text-to-video`:

| Field | Allowed values | Default | Description |
| --- | --- | --- | --- |
| `prompt` | string, max 2500 | — | "Either prompt or multi_prompt must be provided, but not both." |
| `multi_prompt` | array of `{prompt, duration}` | null | "List of prompts for multi-shot video generation. If provided, overrides the single prompt and divides the video into multiple shots" |
| `duration` | `"3"`…`"15"` (string enum) | `"5"` | "The duration of the generated video in seconds" |
| `aspect_ratio` | `16:9`, `9:16`, `1:1` | `16:9` | |
| `shot_type` | `customize`, `intelligent` | `customize` | "'intelligent' lets the model automatically determine shot structure." |
| `generate_audio` | boolean | `true` | "Supports Chinese and English voice output. Other languages are automatically translated to English." |
| `negative_prompt` | string, max 2500 | "blur, distort, and low quality" | |
| `cfg_scale` | number 0–1 | `0.5` | |
| `enable_safety_checker` | boolean | `true` | "Disabling safety checks requires account authorization; unauthorized requests are always checked." |

Per-shot duration in `multi_prompt` is `"1"`…`"15"` seconds. The Turbo Pro schema describes the same
field as "Multi-shot storyboard (1-6 shots). Each shot has its own prompt and duration; the total
duration must not exceed 15s."

`fal-ai/kling-video/v3/standard/image-to-video` adds:

| Field | Description |
| --- | --- |
| `start_image_url` | "URL of the image to be used for the video"; max 50 MB, min 300×300, aspect 0.4–2.5 |
| `end_image_url` | "URL of the image to be used for the end of the video"; same limits |
| `elements` | "Elements (characters/objects) to include in the video. Each example can either be an image set (frontal + reference images) or a video. Reference in prompt as @Element1, @Element2, etc." |

`KlingV3ComboElementInput` (verbatim): `frontal_image_url`; `reference_image_urls` — "Additional
reference images from different angles. 1-3 images supported. At least one image is required.";
`video_url` — "The video URL of the element. A request can only have one element with a video." with
limits "Max file size: 200.0MB, Min width: 720px, Min height: 720px, Max width: 2160px, Max height:
2160px, Min duration: 3.0s, Max duration: 10.05s, Min FPS: 24.0, Max FPS: 60.0"; `voice_id` — "The
voice ID for this element. The voice will be binded to the element and references to this element
will use the binded voice."

Output is a single `video` file (mp4). No resolution field appears in the v3 schemas: resolution is
implied by the endpoint path (standard/pro/4k) rather than requested per call, and no frame-rate
output field exists.

## For contrast: the v4 family (Kling 4.0)

`kling/v4/{text-to-video,image-to-video,reference-to-video,video-to-video/edit}`:
`modelFamily: "Kling v4"`, `landingPageSlug: "kling-4"`, `date` 2026-10-16, `publishedAt`
2026-10-21. Descriptions: "generates videos from text prompts at 720p or 1080p, with durations from
3 to 30 seconds and support for per-shot prompts"; price "**$0.157** per second at **720p** and
**$0.235** per second at **1080p**". Different namespace, different family, different landing page,
different duration ceiling and price basis.

## Summary

fal treats the Kling 3.0 generation as three families — `v3` (pro/standard), `v3 Turbo`, `o3` (Omni
3) — with per-second pricing, 3–15 s durations, multi-shot via `multi_prompt`, start/end frames,
`elements` references, and native audio on by default. Its price strings reproduce the vendor's own
list prices for 720p and 1080p exactly. Its first publish date for the v3 endpoints, 2026-02-04, is
the earliest dated evidence captured for Kling 3.0 existing publicly.

## Gaps

- fal's v3 schemas document audio voice output as Chinese and English only; the vendor blog claims
  Chinese, English, Japanese, Korean and Spanish. Unreconciled.
- No frame rate, bit depth, or audio channel count is documented for v3 anywhere in fal's metadata.
- The catalogue gives one shared `date` (2026-02-04) for all four pro/standard endpoints, so it
  cannot distinguish the model's launch from fal's onboarding date.
- The bare `fal-ai/kling-video/v3` and `fal-ai/kling-video/o3` endpoint IDs return 404 from the
  schema API but resolve as pages and as `api.fal.ai` records; fal does not document the difference.

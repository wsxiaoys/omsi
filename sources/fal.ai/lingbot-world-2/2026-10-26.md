`hostingType: "serverless"` is notable: unlike fal's proxy-hosted video models (which forward to the
vendor), fal labels this endpoint as its own serverless deployment. `licenseType: "research"` is fal's
only licence value here — it is not `commercial`, which every commercial fal video/image endpoint in
this knowledge base carries.

`keywords=lingbot` returns exactly one endpoint, so fal hosts no separate v1 LingBot endpoint and no
tier variants.

## Session setup controls shown in the playground (verbatim labels)

- **Prompt** (required) — "World description"; the configure schema allows replacing the starting
  world's description.
- **Starting image** — "Use your own image instead of a built-in world."
- **Prompt expansion** — "Rewrite world descriptions, updates, and quick actions into detailed
  interactive prompts with an LLM." Default enabled.
- **Quick actions** — "Add quick Action / Up to nine actions, each on its own number key."
- **Safety checker** — "Screen prompts and images with standard thresholds. When disabled, only
  illegal content is blocked." Default enabled.
- Movement keys shown as `W A S D` plus `Reset`.

The playground ships built-in presets in two collections, **"Cinema"** and **"Exploration / Camera
exploration"**, each a named world: e.g. "The City Above the Sea", "The City Around the Planet",
"Flying Castle", "The Harbor — After the Last Track", "Stonehenge", "The Hotel Where the Sea Stopped",
"Urban Exploration", "The Stadium in the Rain — Before the Lights", "Great Wall", "Dragon Rider".

The example world description is a long paragraph of operational constraints rather than a short
scene prompt — it specifies third-person follow camera, "complete body clearly visible at lower
center", "no cuts, no first-person conversion", and navigation requirements ("minimum six-metre-wide
unobstructed level route", "no stairs or narrow doorways").

## Summary

fal is the only API-style host found for this model, and it exposes it as a real-time interactive
"world" session rather than a one-shot video endpoint. The record establishes: the fal endpoint ID
`robbyant/lingbot-world-2`, its publication on 2026-10-16 (two days before the last metadata update),
`serverless` hosting, a **research-only** licence label, and session billing of **$0.00125 per second
of generated video** (≈ $0.075/minute).

The empty `githubUrl` and the "Research only" badge mean fal's page does not link the open weights
even though the vendor's repository is public.

## Gaps

- fal does not state what "second of video generated" measures — wall-clock session time, generated
  frame count ÷ fps, or billed stream duration. No invoice example or worked total was captured.
- No published rate card beyond the single per-second figure: no minimum session, no queue or idle
  charge, no cap.
- `licenseType: "research"` is fal's label; fal's own terms for this endpoint were not captured, so
  the exact restriction (no commercial use? approval required?) is not documented here.
- The model page does not state resolution, frame rate, or maximum session length; those appear only
  in the WebRTC API contract ([separate record](../lingbot-world-2-webrtc-api/2026-10-26.md)).
- fal's page carries no version or checkpoint identifier in the catalogue; the served variant is only
  visible from the runtime `session_info` message.

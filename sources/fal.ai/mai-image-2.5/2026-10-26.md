  <https://fal.ai/models/fal-ai/mai-image-2.5> (alias of <https://fal.ai/models/microsoft/mai-image-2.5>),
  plus the catalogue endpoint <https://fal.ai/api/models?keywords=mai-image>
- Evidence kind: provider documentation (independent host; fal is not Microsoft)
- Publication date: catalogue `date`/`publishedAt` fields — `microsoft/mai-image-2.5` 2026-06-02,
  `microsoft/mai-image-2.5/edit` 2026-06-03, `microsoft/mai-image-2.5-pro` and `…-pro/edit`
  2026-07-28
- Capture date: 2026-10-26
- Relevant models: MAI-Image-2.5, MAI-Image-2.5-Pro (hosted); MAI-Image-2.6 (absent)

## Captured content

### What fal hosts

The catalogue keyword search for `mai-image` returns exactly four Microsoft entries and nothing else
from Microsoft:

| Endpoint id | Title | Category | Published |
| --- | --- | --- | --- |
| `microsoft/mai-image-2.5` | Mai Image 2.5 Text to Image | text-to-image | 2026-06-02 |
| `microsoft/mai-image-2.5/edit` | Mai Image 2.5 | image-to-image | 2026-06-03 |
| `microsoft/mai-image-2.5-pro` | MAI Image 2.5 Pro (Text to Image) | text-to-image | 2026-07-28 |
| `microsoft/mai-image-2.5-pro/edit` | MAI Image 2.5 Pro (Edit) | image-to-image | 2026-07-28 |

**No `microsoft/mai-image-2.6`, `…-2.6-flash`, or any 2.6 endpoint exists.** A direct request to
`https://fal.ai/models/microsoft/mai-image-2.6` returns fal's generic shell (no model content, no
"MAI-Image" string anywhere in the HTML), and the catalogue API never returns a 2.6 row. fal's
`modelLab` for these entries is "Microsoft" and `hosting` is `"proxy"` — fal is fronting Microsoft's
API, not running its own copy.

Catalogue blurb (verbatim, identical on all four entries):

> MAI-Image-2.5 is Microsoft's photorealistic image generation and editing model that turns text
> prompts or uploaded images into high-quality, design-ready visuals with fine-grained, pixel-level
> control.

Page badges on the 2.5 text-to-image page: "Inference", "Private", "Partner" (the catalogue API
reports `status: "public"`, `licenseType: "commercial"`, `deprecated: false`).

### Pricing as stated by fal (verbatim)

2.5 text-to-image:

> Text tokens (per 1M): **$5.00** input. Image output: ~**$0.05** per generated image (billed as
> 1024 output tokens). Each requested image is billed separately.

2.5 edit:

> Billing uses the provider-reported cost when available. Otherwise, token-based pricing is **$5 per
> million text input tokens**, **$8 per million image input tokens**, and **$47 per million image
> output tokens**. At the fallback rate, **1,024 image output tokens cost $0.048128** before input
> costs.

2.5 Pro text-to-image:

> Text input: **$7.50 / 1M tokens**. Image output: **$162 / 1M tokens**. Average text-to-image cost:
> **~$0.17 per image**.

2.5 Pro edit:

> Text input: **$7.50 / 1M tokens**. Image input: **$162 / 1M tokens**. Image output: **$162 / 1M
> tokens**. Estimated cost with one input image: **~$0.18–$0.27 per output image**.

### Request surface (from the endpoints' OpenAPI schemas)

2.5 text-to-image — `prompt` (3–5,000 chars), `num_images` (1–4), `aspect_ratio`
(`auto,1:1,4:3,3:4,16:9,9:16,3:2,2:3`), `output_format` (`jpeg,png,webp`), `sync_mode`.
2.5 edit — `prompt`, `image_urls` (array; "Edit one or more images with MAI-Image-2.5"), `aspect_ratio`,
`num_images`, `output_format`, `sync_mode`.
2.5 Pro — same shape with a single `image_url` on the edit endpoint.

No `web_grounding` or `auto_aspect_ratio` parameter exists on any fal endpoint, and no width/height
pixels parameter: fal exposes only aspect-ratio presets, so the 2.6 pixel-ceiling discussion cannot
be tested through fal at all.

## Summary

fal is the **only independent host found for any MAI-Image model, and it stops at 2.5 / 2.5-Pro**.
This is the record that answers the roster's identity question in the negative direction: the
`microsoft/mai-image-2.5` slug is a real, publicly callable endpoint, but it is an older generation,
not a rename of 2.6. fal's price for 2.5 output ($47/1M tokens, 1,024 tokens per image) matches
Azure's own 2.5 Global meter, so fal is passing through Microsoft's token economics rather than
marking up per image; its 2.5-Pro price ($162/1M) is roughly 1.5× Azure's 2.5-Pro meter ($106/1M).

The schemas also show what fal does *not* expose: no grounding, no model-chosen aspect ratio, no
explicit pixel dimensions, no seed, no negative prompt.

## Gaps

- No 2.6 endpoint, so no independent-host confirmation of 2.6 latency, cost, or output at all.
- fal does not say which Azure region or version backs its proxy, nor when it last refreshed.
- "Private" badge is unexplained; it may refer to fal's partner infrastructure rather than access
  restrictions, and the API reports the endpoint as public.
- The 2.5 page was captured via the `fal-ai/…` URL alias; the `microsoft/…` alias serves the same
  endpoint id and was not separately diffed.

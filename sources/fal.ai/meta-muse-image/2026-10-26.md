## Text-to-image input schema (`MuseImageTextToImageInput`, verbatim field text)

- `prompt` — required string, `minLength: 1`, "The text prompt used to generate or edit the image."
- `num_images` — integer, default 1, `minimum: 1`, `maximum: 10`, "The number of images to
  generate."
- `output_format` — enum `jpeg`/`png`/`webp`, default `webp`, "The format of the generated image."
- `sync_mode` — boolean, default false, "If `True`, the image is returned as a data URI and is not
  persisted in the request history."
- `aspect_ratio` — string or null, "Any custom output aspect ratio as `"width:height"`, for example
  `"16:9"`, `"5:4"`, or `"1920:1200"`. Common presets are `"21:9"`, `"16:9"`, `"4:3"`, `"3:2"`,
  `"1:1"`, `"2:3"`, `"3:4"`, `"9:16"`, `"9:21"`. The ratio must be between 1:16 and 16:1, the range
  Muse supports. Only the ratio is used: Muse renders it at its own fixed resolution of roughly 2.5
  megapixels, so `"1920:1200"` and `"960:600"` both return the same 1920x1200 image. If omitted,
  Muse chooses the output dimensions automatically."

Output: `images` array of `Image` objects with `url`, `file_size`, and the usual fal image fields.

## Edit input schema (`MuseImageEditInput`, verbatim field text)

- `image_urls` — required array, `minItems: 1`, `maxItems: 10`, "Reference images used for the
  edit. Provide between 1 and 10 HTTP(S) or data URLs."
- `prompt` — required, same text as above.
- `num_images`, `output_format`, `sync_mode`, `aspect_ratio` — identical to the text-to-image
  schema, including the same "roughly 2.5 megapixels" note.

## Path checks and negative results

- `GET https://api.fal.ai/v1/models?endpoint_id=meta/muse-image` → HTTP 404,
  `{"error":{"type":"not_found","message":"Endpoint(s) not found"}}`. The metadata API only resolves
  the full `…/text-to-image` and `…/edit` paths.
- `GET https://fal.ai/api/models/meta/muse-image` → HTTP 404 (HTML error page). There is no
  single-model JSON route; the gallery query is the catalogue surface.
- **No price was captured from fal.** Neither catalogue item carries a `pricingInfoOverride` field
  (both `hidePricing: false`), and the model page renders its price calculator client-side, so the
  served HTML contains no per-image price. Probes of `api.fal.ai/v1/pricing`,
  `fal.ai/api/pricing`, `fal.ai/api/models/…/pricing` and `fal.ai/api/model-pricing` all returned
  404.

## Summary

fal serves Muse Image as **two proxied endpoints under one family** (`meta/muse-image`), published
2026-08-26, both marked commercial use, both `hostingType: proxy`. The host schemas are the only
captured source for two engineering facts: the fixed output size of **"roughly 2.5 megapixels"**
with aspect ratios limited to **1:16–16:1**, and an edit limit of **1–10 reference images**.
`num_images` 1–10 and `webp`/`png`/`jpeg` output agree with Meta's own docs.

## Gaps

- **fal's price for these endpoints is unrecorded** — see above. Meta's list price is $0.01/image
  and Artificial Analysis reports $10.0 per 1,000 images.
- **No latency, queue-time, or throughput data**, and no `machineType` (consistent with a proxy).
- **No fal statement about which Meta revision is behind the proxy**, or whether fal adds its own
  moderation on top of Meta's.
- **The 2.5 MP figure is host-written.** Meta's own docs describe the output only as "the
  generator's own resolution"; fal is the sole captured source for the megapixel count.

## `H3MaxTextToVideoInput`

Required: `prompt`, `prompt_expansion_mode`.

| Field | Type | Default | Notes (verbatim) |
| --- | --- | --- | --- |
| `prompt` | string | — | "Text prompt for video generation" |
| `prompt_expansion_mode` | string | `balanced` | "How much effort to spend rewriting the prompt before generation. 'disabled' skips prompt expansion. 'balanced' returns in about a second. 'quality' spends up to ~30s on a richer prompt." |
| `resolution` | enum `480P`, `768P`, `1080P` | `768P` | "The native generation resolution, or 1080P latent refinement from a native 768P source." |
| `duration` | number | `5` | "Video length in seconds. The output can run up to about 0.7 s longer than requested. Use at least 2 s with target_audio_url." |
| `aspect_ratio` | enum `21:9`,`16:9`,`4:3`,`1:1`,`3:4`,`9:16` | `16:9` | "The aspect ratio of the generated video." |
| `seed` | integer or null | — | "Random seed. A random seed is selected when omitted." |
| `target_audio_url` | string or null | — | "Optional URL of an audio clip at least 2 seconds long (maximum 15 MB) to pin to the generated soundtrack. Longer clips are trimmed to the generated video's length, keeping the beginning. The original audio replaces the output soundtrack, padded with silence if shorter than the video, without changing playback speed. Exceptionally high sample rates may be resampled to 96 kHz." |
| `enable_safety_checker` | boolean | `true` | "If set to true, the safety checker will be enabled." |
| `sync_mode` | boolean | `false` | "Return the generated video as base64 instead of a CDN URL." |

`x-fal-metadata.about` for this endpoint is the string `Text To Video Turbo`.

## `H3MaxImageToVideoInput`

Required: `prompt`, `prompt_expansion_mode`. Same fields as above plus:

| Field | Type | Notes (verbatim) |
| --- | --- | --- |
| `image_url` | string or null | "Optional URL of the image to use as the first frame. When provided, the output canvas follows this image. If only end_image_url is provided, the canvas follows that last frame instead. If both images are omitted, the request is handled as text-to-video (16:9 by default)." |
| `end_image_url` | string or null | "Optional URL of the image to use as the last frame. It may be provided alone for end-only keyframe generation; in that case the output canvas follows this image." |

No `aspect_ratio` field: the canvas follows the input image.

## `H3MaxReferenceToVideoInput`

Required: `prompt`, `prompt_expansion_mode`. Adds reference inputs:

| Field | Type | Notes (verbatim) |
| --- | --- | --- |
| `reference_image_urls` | array | "URLs of subject/style reference images, referenced in the prompt as Image 1, Image 2, and so on. Reference images, videos, and audio clips must add up to at most 12 files." |
| `reference_video_urls` | array | "URLs of motion/reference video clips (2-15 seconds each, combined duration at most 15 seconds), referenced in the prompt as Video 1, Video 2, and so on." |
| `reference_audio_urls` | array | "URLs of reference audio clips (2-15 seconds each, combined duration at most 15 seconds), referenced in the prompt as Audio 1, Audio 2, and so on." |
| `reference_conditions` | array | "Ordered reference list; cross-modality order is semantic and is preserved end-to-end. Do not combine with reference_*_urls." |
| `middle_image_url` | string or null | "Optional image to guide the video at middle_frame_time. Requires start and end images and native 480P or 768P resolution." |
| `middle_frame_time` | number or null | "Target time for the middle image, in seconds from the start. **Rounded to the nearest frame at 24 fps**; it must fall strictly between the first and last frames of the requested duration. Requires middle_image_url." |
| `image_url` / `end_image_url` | string or null | First / last frame; "the video opens exactly on this image while the references keep the subjects consistent". |
| `aspect_ratio` | enum incl. `adaptive` | default `adaptive` |

The 12-file cap is stated as: "Images, videos, and audio can be provided individually or together.
Reference images, videos, and audio clips must add up to at most 12 files."

## Output

`video` (file, mp4), `timings` ("Timing breakdown in seconds. 'inference' is the DiT denoising time
on the GPU backend. Null on routes that do not report backend timings."), `expanded_prompt` ("The
prompt after expansion").

## What this establishes

- **fal's 1080P is not native.** The schema says so outright: "The native generation resolution, or
  1080P latent refinement from a native 768P source." This reconciles fal's 1080p option with
  MiniMax's 480P/768P cap: H3 Max generates at 768P natively and fal refines to 1080P, mirroring
  MiniMax's own H3-Regenerate-2K approach for H3.
- **Frame rate is 24 fps**, confirmed indirectly and precisely: `middle_frame_time` is "Rounded to
  the nearest frame at 24 fps".
- **Audio is generated by the model**, and can optionally be replaced or pinned with a supplied
  clip via `target_audio_url` (≥ 2 s, ≤ 15 MB, resampled to 96 kHz if needed). The soundtrack is
  therefore part of the generation, not a silent track.
- **The prompt-expansion control is required, not optional, on fal**, whereas MiniMax's API defaults
  it and documents it as H3-Max-only. The modes match one-for-one (`disabled` / `balanced` /
  `quality`), so fal's parameter is the same vendor feature exposed as mandatory.
- `duration` is a **`number`** on fal with a documented overshoot ("up to about 0.7 s longer than
  requested"), while MiniMax's API requires an **integer** 5–15. fal's schema states no upper bound.
- `seed` is exposed by fal but is not part of MiniMax's H3-Max request schema.

## Gaps

- The schema does not state an audio sample rate or channel count for the generated soundtrack, and
  does not say whether it is stereo (H3's card says 32 kHz stereo; H3 Max is unstated).
- No maximum duration is stated on fal; MiniMax's own cap is 15 s.
- `enable_safety_checker` is a boolean with no description of what the checker blocks or how
  refusals are reported.
- No output frame-rate field, so the 24 fps figure rests on the `middle_frame_time` description.

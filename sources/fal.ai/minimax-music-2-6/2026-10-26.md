## Endpoint identity

The roster label `fal-ai/minimax-music/v2.6` is **exact**: it is the live endpoint ID, filed under
`category: "text-to-audio"`, `kind: "inference"`, `hostingType: "proxy"`, `modelLab: "Minimax"`,
`licenseType: "commercial"`, `status: "public"`, `deprecated: false`, `removed: false`, with
`modelFamily: "Music"` and `discovery.version: "2.6"`.

Title casing differs from the vendor: fal writes **"Minimax Music 2.6"** (one lowercase `m` in
"Minimax"), MiniMax writes "MiniMax Music 2.6".

Short description (verbatim):

> MiniMax Music 2.6 creates complete tracks with singing, backing music, and detailed arrangements
> from lyrics and a style description.

The endpoint's `tags` array reads `["stylized","transform","lipsync"]`, and `discovery.tasks` is an
empty array — the same generic tags fal attaches to `v2.5`. None of the three tags describes music
generation, and "lipsync" is plainly wrong; treat fal's tags for this endpoint as unreliable metadata.

## Input schema (`MinimaxMusicV26Input`, title `TextToMusic26Request`)

| Field | Type / limits | Default | Description (verbatim) |
| --- | --- | --- | --- |
| `prompt` | string, `minLength` 10, `maxLength` 2000 | — (required) | "A description of the music style, mood, genre, and scenario. 10-2000 characters." |
| `lyrics` | string, `maxLength` 3500 | `""` | "Lyrics of the song. Use \n to separate lines. Supports structure tags: [Intro], [Verse], [Pre Chorus], [Chorus], [Post Chorus], [Hook], [Bridge], [Interlude], [Transition], [Build Up], [Break], [Inst], [Solo], [Outro]. Max 3500 characters. Required when is_instrumental is false." |
| `lyrics_optimizer` | boolean | false | "When true and lyrics is empty, auto-generates lyrics from the prompt." |
| `is_instrumental` | boolean | false | "When true, generates vocal-free instrumental music." |
| `audio_setting` | `AudioSetting25` object | — | see below |
| `enable_safety_checker` | boolean | true | "Authorized callers may set false to request relaxed screening." |

`AudioSetting25`: `sample_rate` ∈ {16000, 24000, 32000, 44100} default **44100**; `bitrate` ∈
{32000, 64000, 128000, 256000} default **256000**; `format` ∈ {mp3, wav, pcm} default **mp3**.

Output: `{ "audio": File }` — a single fal-hosted media file (`output.mp3` in the page example,
`content_type: "audio/mpeg"`, `file_size: 6241700`).

The schema exposes **no `seed` and no duration parameter**.

For comparison, the `v2.5` schema (`TextToMusic25PlusRequest`) is nearly identical but sets
`prompt.minLength: 1` and lists only 11 structure tags — it omits `[Post Chorus]`, `[Transition]` and
`[Build Up]`, which v2.6 adds. That is the only schema-level difference between the two endpoints.

## The successor on the same host: `minimax/music-3`

fal's `llms.txt` and schema for `minimax/music-3` (serverless, $0.002 per second) expose controls that
v2.6 lacks: `duration` (float, 1–300 seconds, default 60, "Upper bound on the generated audio length
in seconds"), `seed`, `num_inference_steps` (1–100, default 30) and `guidance_scale` (0–20, default
1.7). Its description reads "a high-performance music generation model for creating complete songs up
to five minutes long".

## What this establishes

- fal hosts Music 2.6 as a **proxied partner endpoint at the vendor's own list price**: $0.15 per
  generated track, flat, with no length dependence.
- fal exposes the vendor's controls except two: no `seed`, and no cover/reference-audio input. If you
  need either, fal is the wrong route.
- fal's catalogue still lists 2.6 as `public`, `deprecated: false`, three weeks after MiniMax's own
  model list retired every music model — the host has not mirrored the vendor's retirement.
- The same host already offers the successor Music 3, under a different namespace, with a different
  billing basis ($0.002/second) and a real control surface (duration, seed, steps, guidance).

## Gaps

- No duration or maximum-length statement for v2.6 anywhere on fal.
- No language statement.
- No latency data; fal publishes no p50 for this endpoint.
- No statement of what "relaxed screening" does when `enable_safety_checker` is false, or who counts
  as an "authorized caller".
- fal's `date`/`publishedAt` semantics are undocumented; the v2.5/v2.6 same-day backfill suggests
  they record when fal listed the endpoint.

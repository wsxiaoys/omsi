## Summary

fal recognises **`mirage-api/avatar-x` as an existing application** — the queue API returns the
authentication-required refusal it gives for real endpoints, not the "Application not found" it gives for
invented ones — but the application is **absent from fal's public catalogue and has no public schema, price
string, or model page**. There is no captured fal documentation, launch date, or pricing for it.

Read together with Mirage's API Terms ("These Terms do not grant you any right to access or use any
non-public Mirage APIs, which would be governed by a separate agreement"), the consistent reading is a
partner or private deployment behind fal's authentication rather than a public fal listing. That reading is
an inference from two documents; neither fal nor Mirage states it.

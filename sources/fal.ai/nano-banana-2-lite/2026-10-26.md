### Edit endpoint input schema (differences only)

Adds `image_urls` (list of strings, optional, "URLs of the images to use for image-to-image
generation or image editing"); no `num_images` change; same aspect-ratio enum, same
`thinking_level`, same `safety_tolerance`. Output `images` are described as "The edited images."

### Aspect ratios actually offered

The enum contains fourteen ratios plus `auto`: `21:9, 16:9, 3:2, 4:3, 5:4, 1:1, 4:5, 3:4,
2:3, 9:16, 4:1, 1:4, 8:1, 1:8`. The copy line "14 supported aspect ratios" matches the enum,
and the enum includes the four panoramic ratios that Google's Lite documentation does not list.

### Sibling listings on the same page

The page payload also lists `google/nano-banana-lite` and `google/nano-banana-lite/edit` under
`modelFamily` "Nano Banana Lite". Both carry byte-identical marketing copy and identical token
pricing to `google/nano-banana-2-lite`. Nothing on either page says how the two slugs differ,
or whether `google/nano-banana-lite` is a legacy listing of the original Nano Banana or a
duplicate of the 2 Lite endpoint.

## What this record establishes

- fal exposes **more controls than Google's own surface**: seed, batch count 1–4, system
  prompt, safety tolerance 1–6, three output formats, and an explicit `thinking_level` that can
  be omitted to disable thinking. Google's guide says Lite's thinking default is `minimal`, not
  off, so "thinking can be disabled" is a fal-specific behaviour.
- fal bills **token-wise**, not per image: $0.3125/1M text and image input tokens, $37.50/1M
  image output tokens. At the 1,120 tokens Google says a 1K image consumes, that is
  **$0.042 per output image** — about 25% above Google's own $0.0336 list price, and above
  Replicate's $0.034. The derivation is this record's arithmetic, not a published fal figure.
- fal also bills **image input tokens** at $0.3125/1M, so reference-image edits cost more than
  the output-only figure suggests.

## Gaps

- No per-image price is published for either endpoint; the edit endpoint's "$1 per units" is
  uninterpretable without a definition of a unit.
- No latency data: `avgLatencyMs` and `durationEstimate` are `null` in the payload, so the
  "sub-2 second latency" line is unsourced vendor copy on this page.
- No reference-image count limit is stated in either schema, unlike fal's Nano Banana 2 page
  ("up to 14 reference images").
- No technical-specifications table (resolution tiers, watermarking, character consistency)
  exists for this endpoint, unlike fal's Nano Banana 2 page.
- The extreme-ratio enum contradicts Google's documentation; whether those four ratios actually
  return panoramic images from Lite is untested here.
- The relationship between `google/nano-banana-2-lite` and `google/nano-banana-lite` is
  undocumented.
- No licence terms beyond the `licenseType: "commercial"` field and the "Commercial use" badge;
  Google's own output terms are not reproduced.

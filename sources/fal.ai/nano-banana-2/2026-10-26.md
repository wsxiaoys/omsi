### Request schema, text-to-image endpoint (summary of the published OpenAPI schema)

Required: `prompt` (3–50,000 chars). Optional and documented by fal:

- `resolution`: enum `0.5K`, `1K`, `2K`, `4K`; default `1K`.
- `aspect_ratio`: enum `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`, `3:4`,
  `2:3`, `9:16`, **`4:1`, `1:4`, `8:1`, `1:8`**; default `auto`. fal's own description:
  "Supports extreme ratios: 4:1, 1:4, 8:1, 1:8."
- `thinking_level`: enum `minimal`, `high`. fal's description: "Controls thinking effort
  ('minimal' or 'high') and requests thought summaries. Omit to use the provider default
  ('minimal'); thinking cannot be disabled."
- `num_images`: 1–4, default 1.
- `output_format`: enum `jpeg`, `png`, `webp`; default `png`.
- `seed`: integer or null.
- `temperature` (0–2), `top_p`, `max_output_tokens` (1–32,768) — fal notes that explicit
  values "use a direct Google or Vertex API" rather than the provider default.
- `safety_tolerance`: enum `"1"`–`"6"`, default `"4"`; "1 is the most strict (blocks most
  content), 6 is the least strict". Marked `frozen` in the schema UI.
- `enable_web_search` (default false), `enable_image_search` (default false; "Ground image
  generation with Google Image Search [...] Uses direct Google or Vertex APIs").
- Conversation state: `history`, `context`, `return_history`, plus `include_thoughts`,
  `system_prompt`, `image_passthrough`, `sync_mode`, `limit_generations` (default true).

Output object: `images[]`, `description`, optional `conversations[]`, and
`grounding_metadata[]` ("Provider grounding metadata for the generated images, including
search queries, source pages and image-source attribution when available").

## Known gaps

- **fal's marketing table contradicts fal's own API schema on aspect ratios.** The table lists
  11 ratios and omits `4:1`, `1:4`, `8:1`, `1:8`, while the schema enum includes them and
  describes them as supported. The schema is the operative surface.
- **Character-count disagreement with Google.** fal states "up to 5 people"; Google's image
  generation docs state 4 characters and 10 objects for `gemini-3.1-flash-image`. fal's figure
  matches Google's number for Nano Banana Pro, not for Nano Banana 2. Unresolved; fal may be
  counting reference slots rather than verified identity preservation.
- "Character-by-character validated typography" and "generating in seconds" are unquantified
  host claims; no latency distribution or text-accuracy test is published on the page.
- The `edit` endpoint (`fal-ai/nano-banana-2/edit`) is a separate route with its own schema,
  which was not captured here; the 14-reference figure above is fal's page-level statement, not
  a schema-verified limit for the edit route.
- fal does not state which upstream snapshot it serves, nor when it last refreshed it; the
  page's `updated_at` is a deployment timestamp, not a model-version record.
- "$0.08 per image" is above Google's own list price for 1K output ($0.067); the difference is
  fal's margin and is not explained on the page.

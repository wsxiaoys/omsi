### Request schema, text-to-image (summary of `/llms.txt`)

Required: `prompt`. Optional:

- `resolution`: `1K` (default), `2K`, `4K`.
- `aspect_ratio`: default `1:1`; options `auto`, `21:9`, `16:9`, `3:2`, `4:3`, `5:4`, `1:1`, `4:5`,
  `3:4`, `2:3`, `9:16`, `4:1`, `1:4`, `8:1`, `1:8`.
- `num_images`: 1–4, default 1.
- `output_format`: `jpeg`, `png` (default), `webp`.
- `seed`.
- `safety_tolerance`: `"1"`–`"6"`, default `"4"`; "1 is the most strict (blocks most content), 6 is
  the least strict".
- `enable_web_search`: default false. There is **no** `enable_image_search` field on either Pro
  endpoint, unlike fal's Nano Banana 2 endpoints.
- `thinking_level`: "Thinking effort. Pro Image supports only high; omit to retain its provider
  default. An explicit level requests summaries unless include_thoughts overrides it. Thinking
  cannot be disabled."
- `include_thoughts`, `limit_generations` (default true), `system_prompt`, `image_passthrough`,
  `sync_mode`, `temperature` (0–2, default 1), `top_p` (default 0.95), `max_output_tokens`
  (1–32,768).
- Conversation state: `history`, `context`, `return_history`. `context` accepts "Ordered text,
  original images, PDF or UTF-8 text documents"; "Images count toward the total 14-reference limit."

### Request schema, edit (summary of `/llms.txt`)

Same fields plus `image_urls` (list of URLs, optional) and `aspect_ratio` default `auto`. Price is
identical to text-to-image ($0.15 per image, 4K double, web search +$0.015).

## Gaps

- No latency distribution, no quality test, no refusal rate. "First-generation outputs align with
  complex briefs" and "industry-leading text rendering" are unquantified host claims.
- fal does not state which upstream snapshot or Google API version it serves, nor when the weights
  were last refreshed; `updated_at` is a deployment timestamp.
- The page's own spec table and its API schema disagree on aspect ratios (see above), and the
  marketing heading names Nano Banana 2.
- "Visible watermark for non-Ultra subscribers" is a consumer Gemini-app rule from Google's launch
  post; fal does not explain how a subscription tier could apply to API output.
- No statement on whether commercial use is granted by Google or only by fal's own terms.

## Hosting: two fields disagree

`hostingType: "serverless"` says fal runs the model on its own infrastructure. `provider_type:
"partner"` with `is_partner_api: true` says the endpoint is billed as a partner API, which normally
means fal forwards to the partner's own API. Both were read from fal on 2026-10-26. The schema's
example assets also live on Pixelcut's CDN (`https://cdn3.pixelcut.app/fal/background-remover/...`),
which is consistent with a Pixelcut-operated backend but is only an example URL. **Which of the two
is true is unresolved**; the practical consequence is that fal's behaviour (limits, refusals,
resolution caps) may be Pixelcut's rather than fal's.

## Output schema (verbatim)

- `image` — "Result image (for rgba/alpha output formats)", an `Image` object with `url`,
  `content_type`, `file_name`, `file_size`, `width`, `height`.
- `file` — "Result file (for zip output format)", a `File` object with `url`, `content_type`,
  `file_name`, `file_size`.

The meanings of `alpha` and `zip` are not documented beyond those two strings: whether `alpha` is a
grayscale matte, a single-channel mask, or an RGBA PNG, and what a `zip` contains, is not stated.

## Feature gap versus the first-party API

fal's schema exposes only `image_url`, `output_format`, `sync_mode`. Pixelcut's own endpoint also
accepts `format`, `shadow` (+3 credits), `crop`, `margin`, and directional margins
([Pixelcut API reference](../../pixelcut.ai/remove-background-api/2026-10-26.md)). So the fal route
is a narrower surface: no AI shadow, no subject crop, no margins. A reader who needs those must call
Pixelcut directly.

### `pixelcut/product-photo` is a naming trap

Its short description is "Pixelcut's Background Remover produces fast, high-quality cutouts built
for e-commerce product imagery", and its discovery tags include `task:remove-image-background`. But
its input schema is a full product-photo pipeline: `image_size` (presets or custom, default
`square_hd` 1024×1024), `background` (solid colour / transparent / image), `margin`, `shadow`
(generative or drop), `watermark`, `output_format` (`png`/`jpeg`). It is **not** the same endpoint as
`pixelcut/background-removal`, despite reusing the background-remover description. Anything on fal
that calls itself "Pixelcut background remover" may be either.

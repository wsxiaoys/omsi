## Input and output schema (verbatim OpenAPI)

`Qwen3TtsTextToSpeech17bInput` (title `Qwen3TTSInput`), required `text`:

| Property | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | string | — | "The text to be converted to speech." |
| `voice` | enum or null | null | `Vivian, Serena, Uncle_Fu, Dylan, Eric, Ryan, Aiden, Ono_Anna, Sohee`; "will be ignored if a speaker embedding is provided" |
| `language` | string | `Auto` | `Auto, English, Chinese, Spanish, French, German, Italian, Japanese, Korean, Portuguese, Russian` |
| `prompt` | string or null | null | "Optional prompt to guide the style of the generated speech. This prompt will be ignored if a speaker embedding is provided." |
| `reference_text` | string or null | null | "Optional reference text that was used when creating the speaker embedding. Providing this can improve synthesis quality" |
| `speaker_voice_embedding_file_url` | string or null | null | "URL to a speaker embedding file in safetensors format, from `fal-ai/qwen-3-tts/clone-voice` endpoint" |
| `max_new_tokens` | int or null | 200 | "Maximum number of new codec tokens to generate." range 1–**8192** |
| `temperature` | number or null | 0.9 | range (0,1] |
| `top_p` / `top_k` | number / int or null | 1 / 50 | sampling |
| `repetition_penalty` | number or null | 1.05 | "Penalty to reduce repeated tokens/codes." |
| `subtalker_temperature` / `subtalker_top_p` / `subtalker_top_k` / `subtalker_dosample` | — | 0.9 / 1 / 50 / true | code-predictor sampling |
| `enable_safety_checker` | boolean | **true** | "Authorized callers may set false to request relaxed screening." |

`Qwen3TtsVoiceDesign17bInput` (title `Qwen3DesignVoiceInput`), required `text` **and** `prompt`:
the same sampling fields, `language`, and `prompt` documented as "Optional prompt to guide the style
of the generated speech." — even though the schema marks it required.

`Qwen3TtsCloneVoice17bInput` (title `Qwen3CloneVoiceInput`), required `audio_url`:

| Property | Type | Description |
| --- | --- | --- |
| `audio_url` | string | "URL to the reference audio file used for voice cloning. Must be at most **300 seconds (5 minutes)** long; a short clip of clean speech is sufficient." |
| `reference_text` | string or null | transcript of the reference clip |
| `enable_safety_checker` | boolean (default true) | relaxed screening for authorised callers |

`Qwen3TtsCloneVoice17bOutput`: **`speaker_embedding`** — "The generated speaker embedding file in
safetensors format." The clone endpoint produces no audio; it must be chained into the
text-to-speech endpoint via `speaker_voice_embedding_file_url`.

`Qwen3TtsTextToSpeech17bOutput`: `audio` (`AudioFile`), with `url`, `sample_rate`, `duration`,
`bitrate`, `channels`, `content_type`, `file_name`, `file_size`.

The 0.6B schemas are identical apart from the endpoint IDs and the clone endpoint's
`speaker_voice_embedding_file_url` description pointing at the 0.6B clone endpoint.

`QwenAudio3TtsInput` (partner proxy) required `text`, with `voice` (default `Cherry`), `language`
(default `Auto`) and `enable_safety_checker` — the Model Studio system-voice parameter set, no
reference audio and no voice design.

## Gaps

- fal publishes no character limit for `text`, no duration cap on output, and no statement of what
  it does when `max_new_tokens` truncates an utterance.
- No sample rate, container or bitrate is fixed by the schema; `AudioFile.sample_rate` is a response
  field, so the delivered rate is whatever the deployment reports.
- fal's `licenseType: "commercial"` is the host's assertion, not the weights licence.
- `enable_safety_checker` is documented but the screening behaviour, refusal surface and
  watermarking are not described anywhere on the endpoint pages.
- No indication of which of the three listed GPUs a request actually lands on.

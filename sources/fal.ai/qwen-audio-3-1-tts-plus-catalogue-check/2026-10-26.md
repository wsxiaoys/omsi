## What fal carries

fal's only Alibaba speech-synthesis endpoint is `alibaba/qwen-audio-3-tts`, titled "Qwen Audio 3.0 TTS
(Flash)", `category: text-to-speech`, `status: public`, `deprecated: false`, `licenseType:
commercial`, `provider_type: partner`. No 3.1-tier Qwen TTS endpoint exists in any of the three
catalogue queries, and the model-metadata API 404s on every 3.1 slug tried.

The 3.0-flash proxy's OpenAPI is a thin forward of the older hosted API, not the 3.1 contract:

| Property | fal's 3.0-flash proxy |
| --- | --- |
| `text` | `maxLength: 2000` |
| `voice` | 45-value enum headed by `Cherry`, `Serena`, `Ethan` — the legacy Qwen-TTS voice list, not the `_v3.1` IDs |
| `language` | `Auto, Chinese, English, Spanish, Russian, Italian, French, Korean, Japanese, German, Portuguese` |
| `enable_safety_checker` | boolean, default true |
| Price | $0.05 per 1,000 characters |

None of the 3.1 features documented by Alibaba — `sample_rate` up to 48 kHz, opus, `enable_aigc_tag`,
`instruction`, emotion/paralinguistic tags, `word_timestamp_enabled`, cloned/designed voices — appear
in the proxy schema.

## Summary

fal is **not** a host record for `qwen-audio-3.1-tts-plus`. Its one Qwen TTS endpoint is a partner
proxy for the 3.0 Flash tier at $0.05/1k characters, with a 2,000-character input cap and the legacy
voice list. Any capability or price read from that endpoint describes a different model.

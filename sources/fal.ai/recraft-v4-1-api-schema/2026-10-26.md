## Summary

The schema confirms fal's V4.1 endpoint is prompt-only text-to-image with optional size, color,
background, and safety-checker controls. `prompt` is capped at 10,000 characters, matching
Recraft's V4.1 limit. There is no batch (`n`), style, seed, or output-format parameter, so one
request yields one image and the $0.035 unit price maps 1:1 to a call.

## Gaps

- The schema does not state pixel dimensions for any of the six named `image_size` presets. Only
  the `{width, height}` form is unambiguous.
- No image input, mask, or editing parameter; this endpoint is text-to-image only.
- No `n`/batch parameter, no `random_seed`, no `style_id`/`style_reference_urls`, and no
  `image_format`/`response_format`.
- `maxLength: 10000` matches Recraft's documented V4.1 limit, indirect evidence that fal forwards
  to Recraft's API rather than running its own inference.

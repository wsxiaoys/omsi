geometry and fills, no embedded raster. This is an artifact observation, not a model test.

## Summary

fal resells Recraft's V4.1 API at Recraft's list prices: $0.035 for the base 1K raster, $0.08 for
vector, $0.21 for Pro 2K, $0.30 for Pro vector, and $0.035/$0.21 for Utility/Utility Pro. The
host is marked `provider_type: "partner"` and `hostingType: "proxy"`, consistent with a
pass-through rather than a local deployment. fal exposes prompt, image size, color/background
controls, and a safety-checker toggle, but not Recraft's style, seed, batch, or output-format
parameters.

## Gaps

- The named `image_size` presets carry no stated pixel dimensions. The example artifact is
  1344×768, which matches Recraft's 1K 16:9 row, but the preset mapping is not documented for all
  six presets or for arbitrary `{width, height}` up to 14142.
- No latency, throughput, or rate-limit information is published on the page.
- The page does not state which Recraft agreement covers resale, or whether the partner proxy
  imposes its own content policy beyond the safety-checker toggle.
- No Utility vector endpoint on fal, although Recraft's API documents two Utility vector model
  IDs.
- `publishedAt` (2026-05-14) matches Recraft's announcement date, but no source explains why the
  endpoint `date` is earlier the same day.

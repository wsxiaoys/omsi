### Observation: example output resolution

On 2026-10-26 the curator downloaded the page's own example output
(`https://storage.googleapis.com/falserverless/example_outputs/recraft-v4/pro-output.webp`,
1,949,504 bytes, `image/webp`) and parsed its WebP header: **3072 × 1536** pixels. That size appears
only in Recraft's 2K ("Pro") size table, not the 1K table
(`../../recraft.ai/limits-and-sizes/2026-10-26.md`). This is a measurement of a static host-published
example artifact, **not** a model test: it does not establish what any given `image_size` preset
returns, and 3072×1536 is 2:1 while the schema's example input asked for `landscape_16_9`.

## Gaps

- fal's named `image_size` presets (`square_hd`, `square`, `portrait_4_3`, …) carry no stated pixel
  dimensions on this page. `square_hd` is a 1K-sounding name on a 2K tier, so the mapping between
  preset names and Recraft's 14-size table is unresolved.
- No latency, throughput, or rate-limit information is published on the page.
- The page states "commercial licensing" but links only fal's terms of service; it does not state
  which Recraft agreement covers resale (Recraft's Developer Terms §1.4 acknowledges such
  agreements exist without publishing them).
- `publishedAt` (2026-02-12) precedes Recraft's own announcement date (2026-02-17). Not explained.

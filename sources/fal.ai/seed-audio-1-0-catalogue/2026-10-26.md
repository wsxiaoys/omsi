The page badges are **"Inference", "Commercial use", "Partner"**. `hostingType: "proxy"` with
`is_partner_api: true` means fal proxies ByteDance's own API rather than running the model on fal
hardware — the opposite of fal-run endpoints such as `fal-ai/dia-tts`.

Short description (verbatim):

> Seed Audio 1.0 is a new audio model from Bytedance that can generate high-quality, natural
> sounding audio using text, reference audios or an image.

Note the category/task mismatch: `category` is `text-to-audio` but `discovery.tasks` says
`text-to-speech`, and the model does both plus reference-audio and reference-image conditioning.

## Pricing (rendered on the model page)

> Your request will cost **$0.1875 per minute**.

`endpointBilling` / `publicEndpointBilling` payload:

```
{"endpoint":"bytedance/seed-audio-1.0","billing_unit":"minutes","price":0.1875,
 "provider_type":"partner","is_partner_api":true,"balance_check":false,
 "enterprise_status":"ready"}
```

Billing unit is **minutes of audio**, at $0.1875/min — i.e. $0.375 for a full 2-minute generation.
fal publishes no minimum charge, no per-character rate, and no separate TTS/T2A rate.

## Summary

- fal serves Seed Audio 1.0 as a **partner proxy** of ByteDance's API at **$0.1875/minute**, listed
  2026-06-25 — roughly four weeks **before** the Seed blog announcement of 2026-07-20.
- The endpoint exposes a reduced but wide control set: prompt, voice preset/clone ID, up to 3
  reference clips, one reference image, format/rate/speed/volume/pitch, a multilingual variant, and
  a safety checker.
- fal's `multilingual` flag is the only host-side evidence that the multilingual release shipped:
  the flag exists, but fal publishes no language list.

## Gaps

- No latency, concurrency, or region information for this endpoint.
- Whether `voice` presets map 1:1 to Doubao TTS 2.0 voice IDs is unstated.
- No documented maximum speakers per prompt and no seed/reproducibility control.
- The 2048-character prompt cap is fal's, not the vendor's; behaviour above it is undocumented.
- fal publishes no deprecation or version policy for partner-proxied endpoints.

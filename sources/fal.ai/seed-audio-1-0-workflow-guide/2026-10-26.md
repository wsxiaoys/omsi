  <https://fal.ai/learn/tools/how-to-use-seed-audio>
- Evidence kind: provider documentation (host-written editorial guide; host claims, not measurements)
- Publication date: **2026-06-26**
- Capture date: 2026-10-26
- Relevant models: Seed Audio 1.0 (`bytedance/seed-audio-1.0` on fal)

## Verbatim quotes

Capability summary:

> Seed Audio 1.0 is ByteDance's audio generation model that produces multi-character dialogue,
> sound effects, and background music in a single pass. It supports English and Chinese, accepts up
> to 3 reference voice clips (30s each), generates up to 2 minutes per pass.

> It runs in two modes: text-to-speech, with no background sound effects or music, and text-to-audio,
> where you generate cinematic audio alongside the dialogue.

Editing and extension framing:

> It generates net-new, film-quality audio from a text prompt, and it repairs and reshapes audio you
> already have, filling silent gaps, swapping lines, extending clips, and generating alternate
> endings. It is a cinematic audio generator and an audio editor in a single model, which is rare.

Language statement (the important one):

> Seed Audio 1.0 currently supports English and Chinese audio generation, which makes it a strong
> option for English and Chinese voice workflows today. When writing your prompt, specify the
> language of the desired output. Broader multilingual support is planned for the July 2026 update.

Endpoint and reference syntax:

> The model is available at the endpoint `bytedance/seed-audio-1.0`. Reference audio inputs by order
> in your prompt with `@Audio1`, `@Audio2`, and `@Audio3`.

Workflow list advertised by the guide: sound-design-heavy scenes; TTS with saved reference voices;
text-and-audio-to-audio; T2A/TTS without references; personalized TTS; combining audios with
background effects or music; audio extending; audio inpainting; audio stitching; audio editing.

Terminology the guide defines: **T2A** (text-to-audio), **TA2A** (text-and-audio-to-audio, prompt +
`@Audio#` references), **TTS**.

## Summary

- A host-written guide, dated **2026-06-26**, one day after fal listed the endpoint. It is a
  workflow/tutorial document, not a measurement; every quality statement in it is a host opinion.
- It documents the practical modes (TTS vs full-scene T2A) and the `@AudioN` reference convention
  that the vendor API also uses.
- **It is stale on languages.** It says English and Chinese only and promises "broader multilingual
  support … planned for the July 2026 update". The Seed blog of 2026-07-20 and the Volcengine API
  doc list 17+ languages, and the fal schema now carries a `multilingual` flag — so the July update
  shipped and this guide was not updated.
- It claims the model produces **"background music"** in a single pass, and lists a workflow for
  "combining multiple audios with background effects or music". The vendor does not claim a music
  model: the Seed model page lists "voice, sound effects, ambience, and other audio elements", and
  the launch blog names music only as an element whose fine-grained control is *future* work.
  Music can appear inside a generated scene (the vendor's own API example specifies a marimba/synth
  bed), but no source documents music-specific control.
- The "audio editor" framing (extending, inpainting, stitching, editing) describes prompt-level
  workflows built from reference audio, not separate API operations: the fal schema has no
  extend/inpaint/stitch field.

## Gaps

- No latency, price, sample-rate, or output-format statements in the guide (price comes from the
  model page: $0.1875/minute — [catalogue record](../seed-audio-1-0-catalogue/2026-10-26.md)).
- No statement of how many speakers one prompt can carry, or of failure modes/refusals.
- The guide's example snippets use only `prompt`; it does not show `voice`, `image_url`, or
  `multilingual` usage.
- All "we tested … the results are excellent" language is unattributed host opinion; no test
  protocol, prompt set, or evaluation criteria are given.

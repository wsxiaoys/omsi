## Input schema — text-to-image (verbatim descriptions)

| Parameter | Type / default | Description |
| --- | --- | --- |
| `prompt` | string, required | "The text prompt used to generate the image" |
| `image_size` | `SeedreamLiteImageSize` or enum, default `auto_2K` | "The size of the generated image. Custom dimensions within the provider's pixel and aspect limits are sent unchanged. Other sizes use compatible scaling. The provider's native pixel range is 2560x1440 to 4096x4096, with aspect ratio between 1/16 and 16." |
| `num_images` | integer 1–6, default 1 | "Number of separate model generations to be run with the prompt." |
| `max_images` | integer 1–15, default 1 | "Maximum images per generation in sequential mode. Ignored when sequential generation is disabled. Combined input references and outputs per generation cannot exceed 15." |
| `sequential_image_generation` | `auto` / `disabled` | "Generate related images with `auto`, or one image per generation with `disabled`. When omitted, values of `max_images` above one enable `auto`." |
| `output_format` | `jpeg` (default) / `png` | "The file format of the generated images." |
| `enable_safety_checker` | boolean, default `true` | "If set to true, the safety checker will be enabled. Disabling it requires account authorization; unauthorized requests are always checked." |
| `watermark` | boolean, default `false` | "Whether to add the provider's visible watermark." |
| `image_passthrough` | boolean, default `false` | "Preserve original reference and output image bytes, formats, and dimensions without resizing or re-encoding." |
| `return_byteplus_urls` | boolean, default `false` | "If set to true returns seedance-2 trusted URLs. Please note these urls expire in 24 hours." |
| `sync_mode` | boolean, default `false` | "If `True`, the media will be returned as a data URI and the output data won't be available in the request history." |

`image_size` enum values (verbatim): `square_hd`, `square`, `portrait_4_3`, `portrait_16_9`,
`landscape_4_3`, `landscape_16_9`, `auto_2K`, `auto_3K`, `auto_4K`, plus an object form
`SeedreamLiteImageSize` with `width` and `height` (each 1–16384, default 512).

Output schema: `images` (list) and `seed` (integer) — the seed used is returned.

## Input schema — edit (differences only)

- `prompt`: "The text prompt used to edit the image".
- `image_urls` (list of strings, required): "List of URLs of input images for editing. By default,
  when more than 10 references are provided, only the last 10 are used. With image_passthrough
  enabled, all references are preserved, supporting up to 14; combined references and outputs per
  generation cannot exceed 15."
- Same `image_size`, `num_images`, `max_images`, `output_format`, `enable_safety_checker`,
  `watermark`, `image_passthrough`, `sequential_image_generation`, `return_byteplus_urls`,
  `sync_mode` parameters as text-to-image.

## URL forms observed at capture

- `https://fal.ai/models/bytedance/seedream/v5-lite` returns HTTP 200 but is a client-rendered
  page shell with no model content in the HTML, and
  `https://api.fal.ai/v1/models?endpoint_id=bytedance/seedream/v5-lite` returns HTTP 404
  `{"error":{"type":"not_found","message":"Endpoint(s) not found"}}`. The `/v5-lite` path is not a
  catalogue endpoint ID; the two `/v5/lite/*` endpoints above are.
- `fal.ai/sitemap.xml` lists, for the Seedream v5 family, `bytedance/seedream/v5/lite/{edit,text-to-image}`,
  `bytedance/seedream/v5/flash/{edit,layerize,text-to-image}` and
  `bytedance/seedream/v5/pro/{edit,layerize,text-to-image}`, plus a family landing page
  `https://fal.ai/seedream-5.0`.

## What this establishes

- fal exposes Lite through two separate endpoints (generation and editing) at $0.035 per output
  image, the same price as BytePlus and Replicate.
- fal's schema supports `auto_2K`/`auto_3K`/`auto_4K`, so 4K is reachable on fal even though
  Replicate stops at 3K, and the native pixel range fal publishes (2560×1440 to 4096×4096) matches
  BytePlus's documented Lite range exactly — evidence that fal is proxying the BytePlus model.
- fal's `enable_safety_checker` default is on, and turning it off requires account authorisation;
  fal's `watermark` default is off, whereas BytePlus's `watermark` default is on. Outputs from the
  two surfaces therefore differ by default in watermarking.
- fal's `return_byteplus_urls` parameter exists to hand BytePlus-hosted URLs to Seedance 2.0 while
  bypassing face-detection moderation — a host-specific affordance, not a documented Lite feature.

## Gaps

- No prose documentation beyond one-sentence descriptions: no prompting guide, no stated
  limitations, no licence statement beyond the catalogue `license_type: commercial`.
- The catalogue `date` field is a fal timestamp; the API does not say whether it means creation,
  first publication, or first successful inference. It is not a model release date.
- No statement of which BytePlus snapshot fal serves, or of refresh cadence.
- `num_images` (1–6) is a fal-level fan-out parameter with no BytePlus equivalent documented.

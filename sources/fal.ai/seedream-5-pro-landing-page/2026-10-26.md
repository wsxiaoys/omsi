# fal.ai: Seedream 5.0 landing page

- Origin: fal.ai, "Seedream 5.0 Pro API - Multimodal AI Image Model", <https://fal.ai/seedream-5.0>
  (the page fal's own model pages link to as "Learn more about Seedream 5")
- Evidence kind: provider documentation (third-party hosting page written by the host)
- Publication date: none stated. The page describes the Pro endpoints, whose fal catalogue `date`
  values are 2026-07-07 (see [endpoints record](../seedream-5-pro-endpoints/2026-10-26.md)), and it
  still says the family "ships in two tiers", which the catalogue contradicts from 2026-09-23
  onward — so the page is stale relative to fal's own catalogue. Capture date 2026-10-26.
- Relevant models: **Seedream 5.0 Pro** (the page's subject). Seedream 5.0 Lite appears only as a
  comparison row; no Lite capability claims are extracted here.
- Capture type: server-rendered page text, quoted verbatim.

## Positioning (verbatim)

> Seedream 5.0 Pro API is now live on fal

> Seedream 5.0 Pro is a multimodal image model built for professional work: high-density
> infographics, interactive precision editing, photographic realism, and native multilingual text.
> Available now on fal.

The page's three capability sections are "Layer Separation", "Native Multilingual Generation" and
"Precision Editing", each restating ByteDance's launch framing.

## Tier split (verbatim)

> Seedream 5.0 ships in two tiers on fal. Pro is the flagship for production-grade quality; Lite is
> tuned for fast, cost-efficient generation. Both share the same API.

Pro column of the "Pro vs Lite" table:

> Best for: Production, campaigns, and final delivery
> Visual quality: Flagship photographic realism with the highest detail and text fidelity
> Price: From $0.0675 / image
> API endpoints: `bytedance/seedream/v5/pro/text-to-image`, `bytedance/seedream/v5/pro/edit`

**Contradiction to record:** fal's own model catalogue lists a third 5.0 tier —
`bytedance/seedream/v5/flash/{text-to-image,edit,layerize}` — created 2026-09-23, and ByteDance's
Ark model list likewise has a `flash` tier. This landing page was not updated. "Two tiers" is
therefore wrong as of the capture date.

## FAQ (verbatim, selected)

> **How realistic is the output, and what resolution does it support?**
> Seedream 5.0 Pro reconstructs real-world lighting, materials, and skin texture for photographic
> realism, and generates at resolutions up to 2048x2048. Text stays clean and legible in posters,
> labels, and infographics.

> **Which languages can Seedream 5.0 Pro handle?**
> Beyond Chinese and English, it natively supports direct input and high-quality text rendering in
> over ten widely used languages, including French, German, Russian, Japanese, Korean, Spanish, and
> Arabic.

> **Can I use Seedream 5.0 for commercial projects?**
> Yes. Images generated through the fal.ai API can be used in commercial projects. Check fal.ai's
> terms of service for full details on usage rights and licensing.

> **How do I use Seedream 5.0 via API?**
> Call it through the fal.ai serverless API, with no GPUs or infrastructure to manage. Pro lives at
> `bytedance/seedream/v5/pro/text-to-image` and `bytedance/seedream/v5/pro/edit` [...]

Note the "2048x2048" resolution answer: it is the 1:1 ceiling only. ByteDance's own API documents a
2K tier that reaches 2848×1600 (16:9) and 3136×1344 (21:9), i.e. ~4.6 MP, and fal's own schema
allows up to 4,624,220 total pixels. The FAQ sentence understates the wide-format ceiling.

## Path check

- `https://fal.ai/models/bytedance/seedream/v5` returns HTTP 200 but is **not an endpoint**: fal's
  model metadata API answers `{"error":{"type":"not_found","message":"Endpoint(s) not found"}}` for
  that ID, and for `bytedance/seedream/v5/pro` as well. The callable endpoints are the leaf paths.
- `https://fal.ai/seedream-5.0` (this record) is a marketing landing page, not a catalogue entry.

## Known gaps

- fal does not state which ByteDance snapshot each endpoint serves, or when it was last refreshed.
- "From $0.0675 / image" is a floor with no stated conditions (resolution tier, reference images,
  layer count). The per-endpoint price breakdown was not captured — fal's pricing endpoint requires
  an API key, and the pricing block on the model page is client-rendered.
- "Commercial use" is fal's assertion about use through fal; it is not a statement of ByteDance's
  licence terms, and there are no public weights to license.
- This landing page also carries the Lite tier's comparison row. If the Seedream 5.0 Lite curation
  captures the same URL, one of the two records should be folded into the other.

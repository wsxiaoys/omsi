Descriptions (verbatim): `fal-ai/trellis-2` "Generate 3D models from your images using Trellis 2. A native 3D
generative model enabling versatile and high-quality 3D asset creation." The retexture endpoint carries the
identical description and the same display name "Trellis 2" — its only catalogue-level distinction is the
path segment; the OpenAPI `about` field is a one-word label (`"Generate"`, `"Retexture"`, `"Inference"`,
`"Lora"`).

`fal-ai/trellis` (TRELLIS 1) carries `github_url` `https://github.com/microsoft/TRELLIS/blob/main/LICENSE`
and `group: {key: trellis, label: Single Image}`; `fal-ai/trellis-2` carries an empty `githubUrl` and no
group. No fal endpoint in this family exposes text-to-3D.

"price":0.05}`; `…/retexture` `{"billing_unit":"units","price":0.04}`; `…/trellis-2-lora`

The headline strings are exact multiples of the unit price (5/6/7 units at 512/1024/1536 for generation;

`license_type: "commercial"` is fal's statement about use *through fal*, not Microsoft's weights licence
(MIT, see [repo record](../../github.com/trellis-2-repo/2026-10-26.md)).

## `fal-ai/trellis-2` output schema (`Trellis2Output`)

One required field: `model_glb` — "Generated 3D GLB file" (`File` with `url`, `file_name`, `file_size`,
`content_type`). Example filename `…_trellis2_68d6300f70f34d23b69a912b5fe60487.glb`. No OBJ, FBX, USDZ, STL,
USD or separate texture-map output, and no timings or seed echo (unlike `fal-ai/trellis`, whose output is
`model_mesh` + `timings`).

## `fal-ai/trellis-2/retexture` (`Trellis2RetextureInput`)

Required `image_url` ("URL of the reference image for texturing") **and** `mesh_url` ("URL of the untextured
3D mesh to retexture. Supports GLB, OBJ, PLY, and STL formats."). `resolution` is an enum of 512/1024 only
("Internal resolution for texture generation"), default 1024; `tex_slat_*` controls as above plus `seed`.
Output is again a single `model_glb`. This is the host's exposure of the paper's shape-conditioned texture
stage, and it is the only route in this family that accepts a mesh as input.

## `fal-ai/trellis-2-lora` (`Trellis2LoraInput`)

Input adds three optional adapter URLs — `sparse_structure_lora_url`, `geometry_lora_url`,
`texture_lora_url` ("Optional safetensors LoRA checkpoint trained for the … denoiser") — and pins
`resolution` to 512/1024 with "Generation resolution. Must match the resolution the provided LoRA adapters
were trained at". Also present: `enable_safety_checker` (boolean, default true, "Authorized callers may set
false to request relaxed screening"). Output echoes `seed`, `resolution`, `decimation_target`, `texture_size`
and the three applied adapter URLs plus `model_glb`. The base `fal-ai/trellis-2` schema has no
`enable_safety_checker` field at all.

## `fal-ai/trellis-2-lora-trainer` (`Trellis2LoraTrainerInput`)

`data_url` required: "URL to a .zip archive containing raw 3D assets or a TRELLIS.2 preprocessed dataset zip
returned by the data_preprocessing endpoint". `denoisers` (1–3 of `sparse_structure`, `geometry`, `texture`,
"One LoRA adapter is trained per entry, and all selected denoisers are trained in parallel from the same
preprocessed dataset"), `resolution` (512/1024), `rank` (16/32/64, default 32), `learning_rate`
(default 0.0001, 1e-6–0.01), `training_steps` (100–10000, default 1000). Output: `adapters[]` (one per
denoiser, each with `lora_file`, `rank`, `resolution`, `training_steps`, `learning_rate`),
`preprocessed_data_file`, and `failed[]`. A `data_preprocessing` endpoint is referenced but was not captured.

## TRELLIS 1 on fal (contrast)

`fal-ai/trellis` (`TrellisInput`) has no `resolution` field and no stage controls: `image_url`,
`texture_size` (512/1024/2048, default 1024, "Texture resolution"), `mesh_simplify`, `seed`,
`ss_guidance_strength`, `ss_sampling_steps`, `slat_guidance_strength`, `slat_sampling_steps`. Output
`model_mesh` ("Generated 3D mesh file") + `timings`. Two display-name variants exist (`fal-ai/trellis`,
`fal-ai/trellis/multi`), the latter for multi-image input; TRELLIS 2 has no multi-image endpoint on fal.

## Gaps

- No input-image constraints anywhere: no max dimensions, aspect ratio, format or file size.
- `resolution` "512/1024/1536" is not mapped to the vendor's voxel-grid terminology; the vendor's released
  checkpoint files stop at 1024, and only the paper describes 1536 as a cascade. Whether fal's 1536 option
  runs that cascade is not stated.
- `decimation_target` is described as a *vertex* count on fal; Replicate describes the same knob as a *face*
  count (see [Replicate record](../../replicate.com/trellis-2/2026-10-26.md)).
- No statement of which checkpoint (weights revision) fal serves, and `githubUrl` is empty on the TRELLIS 2
  endpoints, so the link to Microsoft's repository is not asserted by the host.
- No moderation, retention or commercial-use terms on the endpoint pages; fal's platform terms were not
  captured. `enable_safety_checker` exists only on the LoRA endpoint, with no explanation of what the check
  screens.
- The `data_preprocessing` endpoint referenced by the trainer schema was not captured.

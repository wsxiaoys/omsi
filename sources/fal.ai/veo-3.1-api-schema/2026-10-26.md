# fal.ai: `fal-ai/veo3.1` API schema

- Origin: fal.ai, "Veo 3.1 Text to Video API Docs", <https://fal.ai/models/fal-ai/veo3.1/api>
- Evidence kind: host API documentation and input/output schema (independent host)
- Publication date: none stated; the endpoint carries "This endpoint will be deprecated on November
  17, 2026."
- Capture date: 2026-10-26
- Relevant models: `fal-ai/veo3.1` (standard tier, text-to-video)

## About (verbatim)

> Generate videos using Google's Veo 3.1 model.
> For best results, prompts should be descriptive and clear. Include: Subject … Context … Action …
> Style … Camera motion (optional) … Composition (optional) … Ambiance (optional)

> The model supports:
> 720p or 1080p resolution videos
> 5-8 second duration at 24 FPS
> Both 16:9 (landscape) and 9:16 (portrait) aspect ratios
> Safety filters prevent generation of inappropriate content.

## Input schema (transcribed exactly)

| Field | Type / enum | Default | Note (verbatim) |
| --- | --- | --- | --- |
| `prompt` | string, required | — | "The text prompt describing the video you want to generate" |
| `aspect_ratio` | `16:9`, `9:16` | `16:9` | "Aspect ratio of the generated video" |
| `duration` | `4s`, `6s`, `8s` | `8s` | "The duration of the generated video." |
| `negative_prompt` | string | — | "A negative prompt to guide the video generation." |
| `resolution` | `720p`, `1080p`, `4k` | `720p` | "The resolution of the generated video." |
| `generate_audio` | boolean | `true` | "Whether to generate audio for the video." |
| `seed` | integer | — | "The seed for the random number generator." |
| `auto_fix` | boolean | `true` | "Whether to automatically attempt to fix prompts that fail content policy or other validation checks by rewriting them." |
| `safety_tolerance` | `1`–`6` (API only) | `4` | "The safety tolerance level for content moderation. 1 is the most strict (blocks most content), 6 is the least strict." |

Output: a single `video` file object with a URL.

Two things the schema establishes that no Google document does:

- **`duration` is 4s / 6s / 8s, not "5-8 second"** — the page's own prose is stale relative to its
  schema.
- **`auto_fix` silently rewrites prompts that fail policy**, which means a hosted generation may not
  be the generation the prompt asked for. `safety_tolerance` (1–6) is a fal-side moderation dial with
  no equivalent in Google's documented parameters, and `negative_prompt` and `seed` are host-side
  additions.

## Summary

Standard-tier text-to-video on fal: prompt plus optional negative prompt, 16:9 or 9:16, 4/6/8
seconds, 720p/1080p/4k, audio on by default, optional seed, plus two host-specific controls
(`auto_fix`, `safety_tolerance`). The parameter surface is wider than Google's documented API, which
is evidence that fal wraps rather than passes through the vendor call — fal does not say so.

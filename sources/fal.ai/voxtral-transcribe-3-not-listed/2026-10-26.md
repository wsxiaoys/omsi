# fal.ai — model catalogue: no Voxtral transcription endpoint (negative record)

- Origin: fal.ai model catalogue search API
  <https://fal.ai/api/models?keywords=voxtral&page=1&size=40> (and the same endpoint queried with
  `keywords=transcribe` and `keywords=mistral` as controls). Retrieved 2026-10-26.
- Evidence kind: independent host catalogue, read for what it does *not* contain.
- Publication date: not applicable (live catalogue).
- Capture date: 2026-10-26
- Relevant models: Voxtral Small Transcribe 3, Voxtral Mini Transcribe 3 (absent); other
  transcription models (present).
- Capture type: JSON API response, quoted below.

## Captured content

Query `keywords=voxtral`, verbatim response:

```json
{"items":[],"page":1,"size":40,"pages":0,"total":0,
 "discovery":{"resolved":{"keywords":"voxtral","rankingKeywords":"voxtral"},
 "facets":{"tasks":[],"families":[],"versions":[],"variants":[],"hosting":[],"labs":[]}}}
```

`total: 0` — no fal entry matches "voxtral" in any field.

Control query `keywords=transcribe` returned 12 items, so the endpoint was answering normally:
`fal-ai/cohere-transcribe`, `fal-ai/elevenlabs/speech-to-text/scribe-v2`,
`fal-ai/elevenlabs/speech-to-text`, `nvidia/nemotron-asr-multilingual/asr`,
`kotoba-technologies/kotoba-stt/v1/speech-to-text`, `fal-ai/speech-to-text`,
`fal-ai/speech-to-text/turbo`, `kotoba-technologies/kotoba-streaming-stt/v1/realtime`,
`fal-ai/speech-to-text/stream`, `fal-ai/speech-to-text/turbo/stream`, plus two lip-sync/router
entries.

Control query `keywords=mistral` returned 3 items, none of them Mistral models
(`openrouter/router`, `openrouter/router/vision`, `openrouter/router/openai/v1/chat/completions`) —
so fal does not index Mistral as a model family at all.

## What this establishes

- fal, one of the roster's discovery hosts and a large speech-to-text host, listed **no** Voxtral
  transcription endpoint at capture — neither the Voxtral 3 models nor the Voxtral 2 ones. Voxtral
  transcription is not distributed through fal.
- This is an absence record, not evidence about the model. Absence from fal does not imply absence
  elsewhere.

## Gaps

- Only the catalogue search API was queried; a partner-only or unlisted endpoint would not appear.
- fal's search may match on curated keywords rather than endpoint text, so a Voxtral model could in
  principle exist without matching "voxtral". The empty `facets` block makes that unlikely but does
  not exclude it.

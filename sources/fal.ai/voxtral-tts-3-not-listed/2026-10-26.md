# fal: no Voxtral TTS endpoint (negative record)

- Origin: fal model catalogue search and model probes, `GET https://fal.ai/api/models?keywords=voxtral`, `…?keywords=mistral`, `…?keywords=tts`, and <https://fal.ai/models?search=voxtral>
- Evidence kind: provider documentation (host catalogue, read for what it does *not* contain)
- Publication date: not applicable (live catalogue, no publication date)
- Capture date: 2026-10-26
- Relevant models: Voxtral TTS 3 (`voxtral-mini-tts-3-0`), Voxtral TTS (`voxtral-mini-tts-2603`) — both absent

## Captured content

- `GET https://fal.ai/api/models?keywords=voxtral` → `{"items":[],"page":1,"size":40,"pages":0,"total":0}`.
  **Zero models** match "voxtral".
- `GET https://fal.ai/api/models?keywords=mistral` → `total: 3`, and all three are generic routers
  (`openrouter/router`, `openrouter/router/vision`,
  `openrouter/router/openai/v1/chat/completions`). No Mistral-authored endpoint.
- `GET https://fal.ai/api/models?keywords=tts` → `total: 63`. The speech-synthesis catalogue includes
  ElevenLabs (`eleven-v3`, `eleven-v4`, `eleven-v4-turbo`, `multilingual-v2`, `turbo-v2.5`), Google
  (`gemini-3.8-flash-tts`, `gemini-3.8-flash-lite-tts`, `gemini-3.1-flash-tts`, `gemini-tts`), Qwen
  (`fal-ai/qwen-3-tts/*`), Inworld, Index TTS 2.0, F5 TTS, ByteDance Seed Speech, Kling TTS, xAI TTS
  and `alibaba/qwen-audio-3-tts`. **No Mistral/Voxtral entry.**
- The rendered search page <https://fal.ai/models?search=voxtral> contains the string "voxtral" only
  as the search query echo.
- **fal model pages are soft-404.** <https://fal.ai/models/fal-ai/voxtral-tts> returns HTTP 200 and a
  client-rendered shell reading "Loading model fal-ai / voxtral-tts"; a deliberately invented path
  (`/models/fal-ai/zzz-not-a-model-xyz`) returns the same 200 with "404" markers in the body. A 200 on
  a fal model URL therefore proves nothing, and the catalogue API is the only usable signal here.

## Summary

fal hosts neither Voxtral TTS 3 nor the March 2026 Voxtral TTS at capture, so fal is not a host record
for this model and no fal price exists for it. fal's catalogue does carry a broad third-party TTS
line-up, so the absence is specific to Mistral's speech models rather than to TTS on fal.

## Gaps

- Catalogue search is keyword-based; a Mistral TTS endpoint under an unrelated name would not be
  caught by these queries. The `tts` listing (63 entries) was read in full and contains none.
- No archived catalogue snapshot exists to date the absence.

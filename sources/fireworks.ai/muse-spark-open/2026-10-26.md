## Captured content (verbatim)

> Muse Spark Open is an open weights reasoning model from Meta for coding and agentic workflows. It
> supports tool calling and native image understanding in a single checkpoint. It uses a sparse
> Mixture-of-Experts architecture with 816B total / 42B active parameters, routing each token to 8 of
> 256 experts, and hybrid attention that repeats three sliding-window layers (2,048-token window) for
> every full-attention layer. Inputs: text and images. Output: text.

> → **Serverless:** Available on serverless on US-only capacity at standard serverless pricing, with
> no US-only premium.
> → **Production:** For dedicated capacity, deploy on-demand or move to reserved throughput.
> → **Fine-tuning:** Train LoRA adapters through the Serverless Training API using base model
> `accounts/fireworks/models/muse-spark-open-nvfp4`. Managed fine-tuning in the Fireworks UI isn't
> available for this model yet. Fine-tuned models deploy on-demand.

## Summary

Fireworks is the second independent host captured, and its price matches OpenRouter's six-provider
tier exactly: **$1.25 / $0.15 cached / $4.25 per 1M tokens**. It adds architectural detail no
first-party page captured here states — **8 of 256 experts per token**, and hybrid attention at
roughly three 2,048-token sliding-window layers per full-attention layer (Meta's own docs give
46 sliding-window and 16 full layers of 62, also ≈3:1). Its "Created on 14 OCT, 2026" is one day
before Meta's own release date.

## Contradictions to preserve

- **Modalities.** Fireworks says "Inputs: text and images" and "native image understanding";
  Meta's docs, blog and Artificial Analysis all list video and audio input as well. Fireworks may be
  describing the modality set its own serving stack accepts.
- **Fine-tuning.** The page's own description says LoRA training is available through the Serverless
  Training API, while its specification table says "Fine-tuning: Not Supported". Read as
  "serverless LoRA training via API, no managed UI fine-tuning".
- **Context.** "1040k tokens" here vs 1,048,576 in Meta's docs and 1,048,576 on OpenRouter's
  Fireworks endpoint.
- **Creation date** 14 Oct 2026 precedes Meta's 15 Oct 2026 announcement date.

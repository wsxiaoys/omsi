# gemma.ai: serving Gemma 4 through the Gemini API

- Origin: Google DeepMind, "Run Gemma with the Gemini API", Gemma Documentation,
  <https://gemma.ai/deployment/gemini-api/>
- Evidence kind: official documentation (Google-hosted serving guide)
- Publication date: not stated on the page.
- Capture date: 2026-10-26
- Relevant models: Gemma 4 31B, Gemma 4 26B A4B

## Captured content

### Which sizes Google hosts (verbatim)

> The Gemini API hosts the two largest Gemma 4 models:

| Model | Identifier |
| --- | --- |
| Gemma 4 31B | `gemma-4-31b-it` |
| Gemma 4 26B A4B | `gemma-4-26b-a4b-it` |

> The smaller sizes are not hosted — run those yourself with Ollama , llama.cpp or LiteRT-LM .

REST endpoint used in the examples:
`https://generativelanguage.googleapis.com/v1beta/models/gemma-4-26b-a4b-it:generateContent`

### Thinking control (verbatim)

> Gemma 4 utilizes an internal "thinking process" that optimizes its multi-step reasoning,
> delivering superior performance in logically demanding domains such as algorithmic coding
> and advanced mathematical proofs.

> While Gemma 4 strictly supports toggling this feature on or off, you can control it using
> the API by setting the thinking level to "high" for enabled or "minimal" for disabled.

Code sample sets `types.ThinkingConfig(thinking_level="high")`.

### Other documented capability

Image input via `client.files.upload(...)`; a "Ground Gemma 4 responses in real-time web
data with Google Search" example appears on the page.

## Summary

Google's own hosted route covers only the 31B and 26B A4B sizes, under `gemma-4-*-it`
identifiers, with a binary thinking switch exposed as `thinking_level` `high` / `minimal`.
This is the only first-party statement of Gemini-API model IDs for Gemma 4.

## Gaps

- No context length, output limit, rate limit, or price on this page; pricing lives on the
  Gemini API price schedule (captured separately).
- The grounding example implies Search grounding is available for Gemma 4 on the Gemini API,
  but the Gemini API price schedule lists "Grounding with Google Search: Not available" for
  Gemma 4. Contradiction left open.
- No audio or video example for Gemma 4 on this page, and the 26B/31B sizes have no audio
  input in the first place.

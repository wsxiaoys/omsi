## README: TL;DR and highlights (verbatim)

> **TL;DR:** ABot-World turns a single NVIDIA RTX 5090 desktop GPU into a real-time interactive world
> simulator, enabling infinite action-conditioned world rollout at 720P, 16 FPS, 1.2s latency, and
> 19GB GPU memory.

> * 🎮 **Action-Driven World Control:** Responds to user actions in real time, enabling continuous
>   exploration instead of passive video playback.
> * ⚡ **Real-Time Desktop Inference:** Runs at 720p and 16 FPS on a single NVIDIA RTX 5090 desktop
>   GPU, with 1.2s latency and 19GB GPU memory.
> * ♾️ **Infinite World Rollout:** Supports open-ended interactive world generation beyond
>   fixed video-length limits.
> * 🧠 **Open-Ended World Imagination:** Expands the world with new scenes and dynamics during
>   rollout, avoiding scene lock-in, without prompt switching, by our *LongForcing* training.

## FAQ.md (verbatim key statements)

> Peak GPU memory usage is approximately **19 GB**, with at least **64 GB** of system RAM recommended.
> Under these constraints, GPUs such as the RTX 3090 (24 GB) and RTX 4090 (24 GB) are in principle
> capable of running the released causal student model.
>
> We have verified inference on **RTX 4090**. RTX 3090 has not yet been evaluated on our side, though
> we expect it to be feasible given the memory footprint.

> ### Is multi-GPU inference supported?
> Not at present. The current release targets **single-GPU** desktop inference.

> We have tested **CUDA 12.8** and **CUDA 12.9** (`cu128` / `cu129`).
> We strongly recommend **Linux**. Support for certain components under Windows is limited or fragile.

i.e. the local demo's only inputs are a **first-frame reference image plus a prompt**. The file's

> "A realistic outdoor world scene with a navigable path, natural lighting, detailed ground texture,
> and stable forward motion."

## `web_client/datasets/actions/default_action.json` (structure)

An action log keyed per frame: `{"keys": {"W": …, "A": …, "S": …, "D": …, "I": …, "J": …, "K": …,
"L": …}, "frame_id": "000561"}`. Control is eight discrete keys — WASD for movement, IJKL for camera
look — sampled once per frame, matching the paper's "raw keyboard actions" interface.

## What this establishes

- The model is an **action-conditioned video world model** driven by keyboard input, not a
  text-to-clip video generator: there is no duration parameter and no clip output anywhere in the
  repository, only a live rollout loop.
- Inputs are a first-frame image, a text prompt, and per-frame key states.
- The published artefact is the **5B causal student** (`-LF`), under **Apache 2.0**, derived from
  Wan2.2 TI2V 5B components; the bidirectional teacher is withheld.
- The vendor's own real-time figures are 720P, 16 FPS, 1.2 s latency, ~19 GB VRAM on one RTX 5090,
  and ~64 GB system RAM recommended.

## README abstract (verbatim)

> 🚀 We present ACE-Step v1.5, a highly efficient open-source music foundation model that brings
> commercial-grade generation to consumer hardware. […] The model runs locally with less than 4GB of
> VRAM […] the Language Model (LM) functions as an omni-capable planner: it transforms simple user
> queries into comprehensive song blueprints—scaling from short loops to 10-minute compositions—while
> synthesizing metadata, lyrics, and captions via Chain-of-Thought to guide the Diffusion Transformer
> (DiT). […] maintaining strict adherence to prompts across 50+ languages.

## Feature table (verbatim claims)

> - ✅ **Ultra-Fast Generation** — Under 2s per full song on A100, under 10s on RTX 3090 (0.5s to 10s
>   on A100 depending on think mode & diffusion steps)
> - ✅ **Flexible Duration** — Supports 10 seconds to 10 minutes (600s) audio generation
> - ✅ **Batch Generation** — Generate up to 8 songs simultaneously
> - ✅ **Commercial-Grade Output** — Quality beyond most commercial music models (between Suno v4.5
>   and Suno v5)
> - ✅ **Rich Style Support** — 1000+ instruments and styles with fine-grained timbre description
> - ✅ **Multi-Language Lyrics** — Supports 50+ languages with lyrics prompt for structure & style
>   control

Control features listed as supported: reference-audio input, cover generation, repaint/edit, track
separation, multi-track ("Add Layer"), vocal2BGM, metadata control (duration, BPM, key/scale, time
signature), simple mode, query rewriting, audio understanding (BPM/key/caption extraction), LRC
timestamp generation, one-click LoRA training ("8 songs, 1 hour on 3090 (12GB VRAM)") and automatic
quality scoring.

## Model zoo (verbatim quality ratings, vendor-assigned)

DiT (2B class): `acestep-v15-base` (50 steps, CFG, quality Medium / diversity High),
`acestep-v15-sft` (50 steps, High / Medium), `acestep-v15-turbo` (8 steps, no CFG, **Very High** /
Medium). XL (4B class): `acestep-v15-xl-base` (High / High), `acestep-v15-xl-sft` (Very High / Medium),
`acestep-v15-xl-turbo` (8 steps, Very High / Medium). LM planners: `acestep-5Hz-lm-0.6B`,
`1.7B`, `4B`, pretrained from Qwen3-0.6B/1.7B/4B. A `acestep-v15-turbo-rl` row is marked "To be
released". All DiT rows claim reference-audio, text2music, cover and repaint support; `extract`,
`lego` and `complete` are base-model only.

VRAM guidance table: ≤6 GB → 2B turbo with no LM; 20–24 GB → XL without offload; ≥24 GB → XL sft with
the 4B LM.

## REST API parameters (`docs/en/API.md`, verbatim rows)

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `audio_format` | string | `"mp3"` | Output format: `flac`, `mp3`, `opus`, `aac`, `wav`, `wav32` |
| `audio_duration` | float | null | Generation duration (seconds), range 10-600. Aliases: `duration`, `target_duration` |
| `batch_size` | int | `2` | Batch generation count (max 8) |
| `vocal_language` | string | `"en"` | Lyrics language (en, zh, ja, etc.) |
| `thinking` | bool | `false` | Whether to use 5Hz LM to generate audio codes (lm-dit behavior) |
| `bpm` | int | null | Specify tempo (BPM), range 30-300 |
| `key_scale` | string | `""` | Key/scale (e.g., "C Major", "Am") |
| `time_signature` | string | `""` | Time signature (2, 3, 4, 6 for 2/4, 3/4, 4/4, 6/8) |
| `inference_steps` | int | `8` | Turbo model: 1-20 (recommended 8). Base model: 1-200 (recommended 32-64). |

`docs/en/INFERENCE.md` documents the Python result field `"sample_rate": int, # Sample rate (default:
48000)` and lyrics "Max 4096 characters" with `"[Instrumental]"` for instrumental tracks.

  give a 48 kHz default for returned audio.

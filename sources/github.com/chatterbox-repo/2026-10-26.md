## Watermarking (verbatim)

> Every audio file generated by Chatterbox includes Resemble AI's Perth (Perceptual Threshold)
> Watermarker - imperceptible neural watermarks that survive MP3 compression, audio editing, and
> common manipulations while maintaining nearly 100% detection accuracy.

The README gives an extraction script: `perth.PerthImplicitWatermarker().get_watermark(...)` returns
`0.0` (no watermark) or `1.0` (watermarked).

## Source code: sample rate, watermark default, unsupported controls

- `src/chatterbox/models/s3gen/const.py`: `S3GEN_SR = 24000`. `ChatterboxTTS.__init__`,
  `ChatterboxTurboTTS.__init__` and `ChatterboxMultilingualTTS.__init__` all set
  `self.sr = S3GEN_SR  # sample rate of synthesized audio`. **Native output is 24 kHz.**
- All three classes construct `self.watermarker = perth.PerthImplicitWatermarker()` in
  `__init__` and apply it unconditionally at the end of `generate()`
  (`watermarked_wav = self.watermarker.apply_watermark(wav, sample_rate=self.sr)`). There is no
  parameter, flag or branch that skips it.
- `tts_turbo.py` `generate()` accepts `exaggeration=0.0` and `cfg_weight=0.0` only to warn:
  `"CFG, min_p and exaggeration are not supported by the {self.model_label} version and will be
  ignored."` **Emotion exaggeration, the original Chatterbox's headline control, is not available on
  Turbo or Nano**; those two use paralinguistic tags instead.
- `tts.py` `generate(exaggeration=0.5, cfg_weight=0.5, ...)` is the original model's control surface.
- `mtl_tts.py` `generate(text, language_id, exaggeration=0.5, cfg_weight=0.5, ...)`;
  `ChatterboxMultilingualTTS.from_pretrained(..., t3_model="v3"|"v2")` selects the multilingual
  checkpoint, defaulting to v2 when the argument is omitted.
- Checkpoint repositories hard-coded in the package: `REPO_ID = "ResembleAI/chatterbox"` (English and
  multilingual), `"ResembleAI/chatterbox-turbo"`, `NANO_REPO_ID = "ResembleAI/chatterbox-nano"`.

## Summary

First-party confirmation that Chatterbox is an MIT-licensed, self-hostable TTS family with 24 kHz
native output, mandatory PerTh watermarking, and four current members (original 500M English,
Multilingual 500M at v2/v3, Turbo 350M English, Nano 110M English). The original model dates to
April–May 2025; the in-window members are Turbo (Dec 2025), Multilingual v3 (Jun 2026) and Nano
(Jul 2026). Emotion exaggeration and paralinguistic tags are mutually exclusive across the family.

## What Dia2 is (verbatim)

> **Dia2** is a **streaming dialogue TTS model** created by Nari Labs.

> The model does not need the entire text to produce the audio, and can start generating as the
> first few words are given as input. You can condition the output on audio, enabling natural
> conversations in realtime.

> We provide model checkpoints (1B, 2B) and inference code to accelerate research. The model only
> supports up to 2 minutes of generation in English.

> ⚠️ Quality and voices vary per generation, as the model is not fine-tuned on a specific voice. Use
> with prefix or fine-tune in order to obtain stable output.

Generation details, verbatim:

> Generation runs until the runtime config's `max_context_steps` (1500, 2 minutes) or until EOS is
> detected. `GenerationResult` includes audio tokens, waveform tensor, and word timestamps relative
> to Mimi's ~12.5 Hz frame rate.

> **Conditional Generation (recommended for stable use)** … `--prefix-speaker-1 example_prefix1.wav
> --prefix-speaker-2 example_prefix2.wav` … Whisper is used to transcribe each prefix file

## What distinguishes it from Dia 1.6B

- Different repository, different package (`dia2`), different checkpoints (1B / 2B), different
  codec (Kyutai Mimi at ~12.5 Hz instead of Descript Audio Codec at 86 tokens/s).
- Streaming/incremental generation is the stated design goal; Dia 1.6B generates a whole utterance
  in one pass from a complete transcript.
- 2-minute generation ceiling versus Dia 1.6B's 3072-token default (~35 s).
- Acknowledgements name KyutaiTTS and Sesame as inspirations; Dia 1.6B named SoundStorm, Parakeet
  and Descript Audio Codec.
- Still English-only, still Apache 2.0, same identity-misuse disclaimer wording.

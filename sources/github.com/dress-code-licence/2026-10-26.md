## Why this record exists

Leffa's README states that `virtual_tryon_dc.pth` is the "virtual try-on model trained on DressCode".
The released weights are declared MIT while this dataset is academic/non-commercial only. The model
page records the tension; this record preserves the dataset's own wording rather than paraphrasing it.

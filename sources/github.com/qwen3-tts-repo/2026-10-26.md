## Voice cloning (verbatim usage contract)

> to clone a voice and synthesize new content, you just need to provide a reference audio clip
> (`ref_audio`) along with its transcript (`ref_text`). `ref_audio` can be a local file path, a URL,
> a base64 string, or a `(numpy_array, sample_rate)` tuple. If you set `x_vector_only_mode=True`,
> only the speaker embedding is used so `ref_text` is not required, but cloning quality may be
> reduced.

A `create_voice_clone_prompt` helper caches the reference prompt for reuse; a documented workflow
is "Voice Design then Clone" — synthesise a reference clip with the VoiceDesign model, then feed it
to `create_voice_clone_prompt` so a designed voice can be reused like a cloned one.

## Evaluation (vendor-run, verbatim numbers)

Setup, verbatim: "we ran inference for all models with `dtype=torch.bfloat16` and set
`max_new_tokens=2048`", "For the Seed-Test and InstructTTS-Eval test sets, we set `language="auto"`".

- Seed-TTS test-zh / test-en WER: 12Hz-0.6B-Base **0.92 / 1.32**; 12Hz-1.7B-Base **0.77 / 1.24**;
  CosyVoice 3 **0.71** / 1.45; MiniMax-Speech 0.83 / 1.65; F5-TTS 1.56 / 1.83.
- Multilingual test set (10 languages) WER and SIM per language for 25Hz and 12Hz Base models
  against MiniMax and ElevenLabs. Bolded best WER per row varies by language; 12Hz-1.7B-Base is
  bolded for Italian (0.948), Portuguese (1.526), Spanish (1.126), Russian (3.212) and is not best
  for German (ElevenLabs 0.572) or Japanese (MiniMax 3.519).
- Cross-lingual benchmark (12 directions, zh/en/ja/ko): 12Hz-1.7B-Base is best in 10 of 12 rows;
  CosyVoice3 wins ja-to-zh (3.05) and en-to-ja (6.80).
- InstructTTSEval (APS/DSD/RP): 12Hz-1.7B-VoiceDesign beats Gemini-flash/pro on several
  voice-design columns; Gemini-flash leads Target-Speaker EN.
- Long speech (long-zh / long-en WER): 12Hz-1.7B-CustomVoice **2.356 / 2.812**; the 25Hz
  CustomVoice **1.517 / 1.225**; VibeVoice 22.619 / 1.780; VoxCPM 4.835 / 7.474.
- Tokenizer: `Qwen-TTS-Tokenizer-12Hz` PESQ_WB 3.21, PESQ_NB 3.68, STOI 0.96, UTMOS 4.16, SIM 0.95
  (16 quantizers, codebook 2048, 12.5 FPS).

Note the 25Hz tokenizer (`Qwen-TTS-Tokenizer-25Hz`) appears in the evaluation tables but is **not**
in the released-models table; only the 12Hz tokenizer has a download entry.

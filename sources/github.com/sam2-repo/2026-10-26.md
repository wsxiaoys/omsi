## Captured content (verbatim)

> **Segment Anything Model 2 (SAM 2)** is a foundation model towards solving promptable visual
> segmentation in images and videos. We extend SAM to video by considering images as a video with a
> single frame. The model design is a simple transformer architecture with streaming memory for
> real-time video processing.

Checkpoints named in the README (SAM 2.1, 09/30/2024): `sam2.1_hiera_tiny.pt`,
`sam2.1_hiera_small.pt`, `sam2.1_hiera_base_plus.pt`, `sam2.1_hiera_large.pt` — four size tiers on a
Hiera backbone.

> For promptable segmentation and tracking in videos, we provide a video predictor with APIs for
> example to add prompts and propagate masklets throughout a video. SAM 2 supports video inference on
> multiple objects and uses an inference state to keep track of the interactions in each video.

The README's prompting examples use click and box prompts; no text-prompt or open-vocabulary
concept API appears anywhere in it.

## Why this record exists

SAM 3's own paper and blog describe SAM 1 and SAM 2 as the **promptable visual segmentation (PVS)**
line — "points, boxes or masks to segment a single object per prompt" — and SAM 3 as adding
promptable **concept** segmentation on top. This record supplies the SAM 2 side of that comparison
from Meta's own repository: four size tiers, Apache 2.0, and no text-conditioned API.

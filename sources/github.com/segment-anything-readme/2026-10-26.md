## Verbatim excerpts

> The **Segment Anything Model (SAM)** produces high quality object masks from input prompts such as
> points or boxes, and it can be used to generate masks for all objects in an image. It has been
> trained on a [dataset](https://segment-anything.com/dataset/index.html) of 11 million images and
> 1.1 billion masks, and has strong zero-shot performance on a variety of segmentation tasks.

> Three model versions of the model are available with different backbone sizes.
>
> - **`default` or `vit_h`: ViT-H SAM model** (checkpoint `sam_vit_h_4b8939.pth`)
> - `vit_l`: ViT-L SAM model (checkpoint `sam_vit_l_0b3195.pth`)
> - `vit_b`: ViT-B SAM model (checkpoint `sam_vit_b_01ec64.pth`)

(The README renders these as download links to `dl.fbaipublicfiles.com`; the checkpoint file names
are reproduced verbatim, the surrounding link markup is not.)

Two inference modes are documented: prompt-driven (`SamPredictor` with "input prompts", returning
`masks, _, _ = predictor.predict(<input_prompts>)`) and automatic (`SamAutomaticMaskGenerator`,
"generate masks for an entire image").

> By downloading the datasets you agree that you have read and accepted the terms of the SA-1B
> Dataset Research License.

The README's first section points to the successor project: "**Segment Anything Model 2 (SAM 2)** is
a foundation model towards solving promptable visual segmentation in images and videos… We extend
SAM to video by considering images as a video with a single frame."

## Facts usable for a comparison with BiRefNet

- **Promptable vs prompt-free.** SAM's documented interface takes points, boxes, or masks as prompts
  and can also emit many masks per image automatically; BiRefNet takes an image only and returns one
  foreground map (see the [BiRefNet paper record](../../arxiv.org/birefnet-paper/2026-10-26.md)).
- **Many objects vs one salient foreground.** SAM's automatic generator produces a set of object
  masks for an image; BiRefNet is trained for dichotomous image segmentation, i.e. one foreground
  against background.
- **Backbone family.** SAM v1 ships ViT-H/ViT-L/ViT-B image encoders; BiRefNet ships Swin-L and
  Swin-T (plus PVTv2 variants in the paper).
- **Licence.** SAM code is Apache-2.0 and the SA-1B dataset carries a separate research licence;
  BiRefNet code and weights are MIT.
- **Precision of edges.** Neither README makes a comparable edge-quality claim. SAM's README claims
  "high quality object masks" and "strong zero-shot performance"; BiRefNet's paper claims SOTA on
  DIS5K/HRSOD/COD/SOD. **These are not comparable claims** — different tasks, different benchmarks,
  no shared measurement.

## Gaps

- No SAM-vs-BiRefNet measurement exists in either project's documentation; any comparison on this
  page is about interface, task framing, size, and licence, not about which produces better masks.
- SAM 2 and SAM 3 are out of scope here; this record captures SAM v1 only.
- The SA-1B dataset licence terms were not captured, only the README's reference to them.

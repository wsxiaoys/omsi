## Interpretation

Absence of a repository is not a vendor statement that no weights exist, but combined with Tencent's own FAQ
answer that private deployment of Tencent HY 3D Global is "Not supported"
([product pages](../../tencentcloud.com/tencent-hy-3d-product/2026-10-26.md)), it supports the reading that
Hunyuan 3D 3.0 and 3.1 are **closed, API-only** models and that Hunyuan3D 2.1 remains the newest open-weights
release in the family.

## Gaps

- Repositories can be private; the listing shows only public repositories.
- No Tencent page captured for this knowledge base states "no weights will be released" for 3.x.
- Whether `Hunyuan3D-Buffalo1.0` or `Hunyuan3D-WorldClaw` ship downloadable weights, and how they relate to
  the 3.x generation model, was not checked.

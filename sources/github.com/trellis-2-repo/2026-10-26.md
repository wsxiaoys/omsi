## README — identity and headline claims (verbatim)

> **TRELLIS.2** is a state-of-the-art large 3D generative model (4B parameters) designed for high-fidelity
> **image-to-3D** generation. It leverages a novel "field-free" sparse voxel structure termed **O-Voxel** to
> reconstruct and generate arbitrary 3D assets with complex topologies, sharp features, and full PBR
> materials.

Badge row: Paper (`arxiv.org/abs/2512.14692`), Hugging Face Model (`microsoft/TRELLIS.2-4B`), Hugging Face
Demo (`spaces/microsoft/TRELLIS.2`), Project Website (`microsoft.github.io/TRELLIS.2`), License MIT.

### Feature claims (verbatim bullets)

- "Our 4B-parameter model generates high-resolution fully textured assets with exceptional fidelity and
  efficiency using vanilla DiTs. It utilizes a Sparse 3D VAE with 16× spatial downsampling to encode assets
  into a compact latent space."
- Timing table: "**512³** ~3s (2s + 1s)"; "**1024³** ~17s (10s + 7s)"; "**1536³** ~60s (35s + 25s)";
  footnote "\*Tested on NVIDIA H100 GPU."
- "The **O-Voxel** representation breaks the limits of iso-surface fields. It robustly handles complex
  structures without lossy conversion: ✅ Open Surfaces (e.g., clothing, leaves) ✅ Non-manifold Geometry
  ✅ Internal Enclosed Structures"
- "Beyond basic colors, TRELLIS.2 models arbitrary surface attributes including **Base Color, Roughness,
  Metallic, and Opacity**, enabling photorealistic rendering and transparency support."
- "Data processing is streamlined for instant conversions that are fully **rendering-free** and
  **optimization-free**." — "**< 10s** (Single CPU): Textured Mesh → O-Voxel", "**< 100ms** (CUDA):
  O-Voxel → Textured Mesh".

## README — usage and output

The single documented output path is a rendered preview plus a GLB:

> `sample.mp4`: A video visualizing the generated 3D asset with PBR materials and environmental lighting.
> `sample.glb`: The extracted PBR-ready 3D asset in GLB format.

Export parameters in the README example (`o_voxel.postprocess.to_glb`): `decimation_target = 1000000`,
`texture_size = 4096`, `remesh = True`, `remesh_band = 1`, `remesh_project = 0`, `extension_webp=True`,
with `aabb = [[-0.5,-0.5,-0.5],[0.5,0.5,0.5]]`. The pipeline call is `pipeline.run(image)[0]` followed by
`mesh.simplify(16777216) # nvdiffrast limit` — i.e. the raw mesh is simplified only because the *renderer*
caps at ~16.7M faces, not because the model has a documented polygon limit.

Transparency caveat (verbatim): "The `.glb` file is exported in `OPAQUE` mode by default. Although the alpha
channel is preserved within the texture map, it is not active initially. To enable transparency, import the
asset into your 3D software and manually connect the texture's alpha channel to the material's opacity or
alpha input."

There is a second documented entry point, `example_texturing.py` / `app_texturing.py`: "an example of how to
generate PBR textures for a given 3D shape" — the shape-conditioned texture stage used on its own.

No FBX, OBJ, USDZ, STL, USD or glTF-separate export is documented in the README; no rigging, skinning,
animation, scene, or camera output appears anywhere in it.

## Code-derived findings (not stated in the README or model card)

- **The image conditioner is DINOv3 ViT-L/16.** `configs/gen/ss_flow_img_dit_1_3B_64_bf16.json` sets
  `"image_cond_model": {"name": "DinoV3FeatureExtractor", "args": {"model_name":
  "facebook/dinov3-vitl16-pretrain-lvd1689m", "image_size": 512}}`.
- **Input images are resized to a 512×512 square** before conditioning:
  `image = [i.resize((self.image_size, self.image_size), Image.LANCZOS) for i in image]` in
  `trellis2/modules/image_feature_extractor.py` (`DinoV3FeatureExtractor.__call__`), with the
  ImageNet mean/std normalisation used for the DINOv2 class in the same file. Aspect ratio is therefore not
  preserved in the conditioner.
- **The released pipeline is a three-stage cascade** of ~1.3B-parameter DiTs (sparse structure → shape →
  texture); the config filenames encode `512` and `_ft1024` fine-tunes, matching the paper's 512/1024/1536
  resolution ladder.
- Hugging Face metadata for `facebook/dinov3-vitl16-pretrain-lvd1689m` at capture: `license: other` and
  access "restricted" (gated). The DINOv3 licence is separate from TRELLIS.2's MIT grant.

> We collected a 1024×768 virtual try-on dataset for **research purposes only**.

## Why this record exists

Leffa's README states that `virtual_tryon.pth` is "trained on VITON-HD". The model's own artefacts are
declared MIT, while the primary training dataset is CC BY-NC 4.0 (non-commercial). This record
preserves the dataset terms so the model page can state the tension without asserting a legal
conclusion: whether a model trained on a non-commercial dataset inherits any restriction is a question
these two documents do not answer.

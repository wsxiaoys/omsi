> multi-turn image generation and editing, having improved accuracy and enhanced image quality.

The 65,536 / 32,768 limits are half or less of the DeepMind model card's "up to 1M" context and
"64K token output" for the same model ID.

The capability row claims "Image generation from video input" while the modality row says Video is
"Not supported". The Gemini API image-generation guide lists video input as available only for Nano
Banana 2.1, Gemini 3.1 Flash Image and Gemini 3.1 Flash Lite Image — not for Pro. The two statements
cannot both describe the same surface, and the capture does not resolve which is stale.

### Image specifications (verbatim)

> Maximum images per prompt: 14 (up to 10 HTTP or HTTPS URLs)

> Maximum file size per file for inline data or direct uploads through the console: 7 MB

> Maximum file size per file from Google Cloud Storage: 30 MB

> Maximum number of output images per prompt: Limited to 32,768 output tokens

> Supported aspect ratios: 1:1, 3:2, 2:3, 3:4, 1:4, 4:1, 4:3, 4:5, 5:4, 1:8, 8:1, 9:16, 16:9, 21:9

> Supported resolutions: 1K, 2K, 4K

> Supported MIME types: image/png, image/jpeg, image/webp, image/heic, image/heif

> Prompts support up to 14 input images. When you pass images by using HTTP or HTTPS URLs in the
> Part.from_uri method, requests are limited to a maximum of 10 image links. To include up to 14
> images, pass images as Cloud Storage URIs (gs://) or as inline data.

This is the only first-party page captured that states a **complete supported aspect-ratio list** for
`gemini-3-pro-image`: 14 ratios, including the panoramic `1:4`, `4:1`, `1:8`, `8:1` that the February
2026 Nano Banana 2 launch post presents as newly added to Nano Banana 2.

### Parameter defaults (verbatim)

### Token consumption (verbatim table)

> Gemini 3 Pro Image consumes 560 tokens per input image.

| Output resolution | Approximate megapixels | Output image tokens |
| --- | --- | --- |
| 1K | 1 | 1,120 |
| 2K | 4 | 1,120 |
| 4K | 16 | 2,000 |

At Google's published image-output rate of $120 per 1M tokens, this table is what produces the
pricing page's "$0.134 per 1K/2K image and $0.24 per 4K image".

## Gaps

- No price on the card; it links to a separate Vertex pricing page that was not captured. The only
  first-party prices captured are the Gemini API list prices.
- No latency, throughput, or quality figures.
- The "Interactions API: preview / Preview feature — Not supported" row is self-contradictory, the
  same defect the Nano Banana 2 Cloud card shows.
- The card does not say whether video input actually works for this model.
- "May 28, 2027 or later" is an Agent Platform support statement, not a Gemini API shutdown date; the
  Gemini API deprecations table lists no shutdown date for `gemini-3-pro-image`.

## Known gaps

- The "Retirement date: May 28, 2027 or later" is a Vertex/Agent Platform support statement
  only, and the footnote explicitly separates it from Gemini API availability. It is not a
  Gemini API shutdown date, and the Gemini API deprecations page (captured separately) says no
  shutdown date has been announced.
- The Cloud card's Interactions API row is self-contradictory ("preview" plus "Not supported");
  the docs elsewhere use the Interactions API for this model, so the row could not be resolved
  from the captured text.
- Cloud pricing is on a separate page that was not captured; the card only links to it.
- No latency, throughput, or quality figures.

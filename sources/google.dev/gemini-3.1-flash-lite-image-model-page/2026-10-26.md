> - Fast multi-turn local edits (swapping colors, sticker creation, background adjustments).

> - Supported image_size values: 1024px (1K). (Note: 2K and 4K are unsupported).

## What this page establishes

- The marketing name maps to a stable Gemini model code, and the code is the same one the
  Gemini API models catalogue and the deprecations table use.
- **Search grounding is not supported at all** on this model, on the vendor's own card. That is
  a hard capability difference from Nano Banana 2, 2.1 and Pro, not a host limitation.
- **2K and 4K are unsupported.** 1K (1024px) is the only `image_size`, so the model cannot
  serve print or 4K-poster workflows.
- **The token budget is a quarter of its siblings'.** 65,536 input / 4,096 output against
  131,072 / 32,768 on Nano Banana 2 and 2.1.
- The latency claim is stated as a design target ("targeting a sub-2 second latency") and then
  restated as a capability ("Sub-2 second end-to-end latency"). Neither statement names a
  harness, prompt set, image size or region.

## Contradictions inside this single page

- **"14 aspect ratios" vs a list of 10.** The page says "a discrete set of 14 aspect ratios"
  and then enumerates ten: `1:1, 3:2, 2:3, 3:4, 4:3, 4:5, 5:4, 9:16, 16:9, 21:9`. The
  image-generation guide's Lite bullet lists the same ten. fal's and Replicate's schemas
  enumerate fourteen, adding `1:4, 4:1, 1:8, 8:1`. Unresolved on this record.
- **"Maintains high character alignment matching original Nano Banana standards"** sits next to
  a reference-image table (captured separately) that grants Lite **no** character slots —
  objects only, characters "N/A". "Character alignment" here is unquantified marketing and does
  not establish a character-consistency budget.
- The aspect ratios are labelled "New" for a model whose siblings already had them.

## Gaps

- No price on this page.
- No release date beyond "June 2026"; the GA date (2026-06-30) comes from the changelog and
  deprecations table.
- No knowledge cutoff, no per-resolution token counts, no aspect-ratio-to-pixel table.
- No safety, moderation or refusal documentation specific to this model.
- No statement about which upstream snapshot or training run this code serves, and no note on
  whether the 2026-06-30 GA code differs from anything that preceded it.
- "Sub-2 second end-to-end latency" is not scoped to region, prompt length, reference count or
  output count, so it cannot be checked against a host measurement as stated.

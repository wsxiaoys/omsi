### Absent from the block

There is **no grounding price row** for this model — consistent with the model page's "Search
grounding: Not supported". The Nano Banana 2 and 2.1 blocks on the same page do carry a
"Grounding with Google Web and Image Search" row; the Lite block does not.

## Arithmetic worth stating explicitly

- 1,120 tokens x $30/1M = **$0.0336 per 1K image**, matching Google's own derivation.
- Batch halves exactly: 1,120 x $15/1M = **$0.0168**.
- **Lite's per-image price equals Nano Banana 2.1's** ($30/1M image tokens, 1,120 tokens per 1K
  image, $0.0336). It is cheaper than Nano Banana 2 ($60/1M, $0.067 per 1K) and much cheaper
  than Pro ($120/1M, $0.134 per 1K). What Lite actually undercuts 2.1 on is input
  ($0.25 vs $1.50) and text/thinking output ($1.50 vs $7.50), not the image rate.

## Gaps

- No effective date for any price, so this record cannot show whether the Lite price changed
  since the 2026-06-30 GA.
- Vertex AI / Gemini Enterprise Agent Platform pricing is a separate page and was not captured.
- No per-aspect-ratio pixel dimensions are given; only the 1024x1024 reference point.
- The page does not say whether reference images (image input) are billed at the same $0.25
  input rate as text; the row reads "$0.25 (text/image/video)" but the token accounting for an
  input image is not stated here.

## Status banner (verbatim)

> **Note:** `gemini-3.1-flash-tts-preview` is a legacy preview model. For new and production
> workloads, migrate to [Gemini 3.8 Flash TTS] (`gemini-3.8-flash-tts`) or [Gemini 3.8 Flash-Lite
> TTS] (`gemini-3.8-flash-lite-tts`). See the migration guide.

## Position in the models catalogue

The Gemini 3 model list on the same documentation set shows the display name "Gemini 3.1 Flash TTS"
mapped to endpoint `gemini-3.1-flash-tts-preview`, described as: "Legacy TTS preview model. We
recommend updating to Gemini 3.8 Flash TTS or Gemini 3.8 Flash-Lite TTS." The same catalogue lists
`gemini-3.8-flash-tts` and `gemini-3.8-flash-lite-tts` above it
(see [models catalogue](../gemini-api-models/2026-10-26.md)).

## Summary

First-party confirmation that "Gemini 3.1 Flash TTS" is the marketing name for the API model
`gemini-3.1-flash-tts-preview`: text-in, audio-out, 8,192 input / 16,384 output tokens, Batch API
available, no Flex or Priority tier, no caching, no tools. The vendor labels it a **legacy preview**
model as of capture and points to the 3.8 TTS pair.

## Gaps

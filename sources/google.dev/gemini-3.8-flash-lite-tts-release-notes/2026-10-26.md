# Google Gemini API docs: release notes (Gemini 3.8 TTS GA entry)

- Origin: Google, "Gemini API release notes", <https://ai.google.dev/gemini-api/docs/changelog>
- Evidence kind: official documentation (first-party changelog)
- Publication date: entries dated; the relevant entry is dated September 22, 2026
- Capture date: 2026-10-26
- Relevant models: `gemini-3.8-flash-lite-tts`, `gemini-3.8-flash-tts`

## Captured content

Entry header (verbatim):

> **September 22, 2026**
>
> **Gemini 3.8 Flash TTS and Gemini 3.8 Flash-Lite TTS generally available (GA):** Released our
> next-generation text-to-speech (TTS) audio models and the Gemini API Voices endpoint
> (`/v1beta/voices`):

> **Gemini 3.8 Flash TTS** (`gemini-3.8-flash-tts`): Flagship creative TTS model engineered for
> studio-grade voice fidelity, nuanced acting, regional dialects, and long-form multi-turn stability.

> **Gemini 3.8 Flash-Lite TTS** (`gemini-3.8-flash-lite-tts`): Fast, cost-efficient TTS model built
> to replace `gemini-3.1-flash-tts-preview` for high-throughput production and real-time voice agent
> cascades.

> **Voice design, Voice replication, and the Extended Voice Library:** Create persistent custom vocal
> personas from text prompts, replicate voices with consent verification, and query 150+ prebuilt and
> custom voices.

The same page carries a later, unrelated entry dated **September 18, 2026** below it, so entries are
not strictly in descending date order on this capture.

## Summary

**2026-09-22 is the first-party GA date** for both 3.8 TTS models, announced in the same entry, which
also launched the `/v1beta/voices` endpoint that backs Voice design, Voice replication and the
Extended Voice Library. The entry is inside the roster's one-year window (≥ 2025-10-26) by eleven
months, so no out-of-window exception applies.

Two date disagreements to keep visible: the model pages say "Latest update: September 2026" (no day),
and the Cloud/Vertex card gives a **September 28, 2026** release date with launch stage **Preview**
(see the `cloud.google.com` record). The Gemini API changelog's "GA" and the Vertex "Preview" are
different platforms' launch stages for the same model ID.

## Gaps

- The entry does not date the model pages, nor say whether 3.1 Flash TTS preview's retirement was
  announced at the same time (it was not — see the deprecations record, which schedules its shutdown
  for 2026-11-17).
- "150+ prebuilt and custom voices" here disagrees with the guide's "30 prebuilt" + "hundreds" and the
  Cloud page's "more than 2,000 curated voices"; the numbers count different pools.

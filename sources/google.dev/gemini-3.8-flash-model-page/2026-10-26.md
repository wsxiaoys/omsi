## Summary

The first-party identity is exactly `gemini-3.8-flash`: one stable version, no preview or snapshot
suffix, text output only, multimodal input (text, image, video, audio, PDF), a 1,048,576-token input
limit and a 65,536-token output limit. Thinking is tunable over `low`/`medium`/`high` with no
off/`minimal` setting. The capability matrix rules out audio generation, image generation and the
Live API, which is what separates this ID from the `gemini-3.8-flash-tts` / `gemini-3.8-flash-lite-tts`
audio models and from `gemini-3.8-live`.

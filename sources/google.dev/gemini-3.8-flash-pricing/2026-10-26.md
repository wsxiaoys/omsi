- Origin: Google, "Pricing", <https://ai.google.dev/gemini-api/docs/pricing> (publisher recorded as
  `google.dev`)
- Evidence kind: official documentation (first-party price schedule)
- Publication date: not stated; continuously edited. Prices are list prices on the capture date,
  including an already-published 2027 step, not a historical record.
- Capture date: 2026-10-26
- Relevant models: `gemini-3.8-flash`. The `gemini-3.6-flash` block was read only to confirm the

### Contributor tier (verbatim note)

> The Gemini API Contributor Tier is offered as a private preview on an invite-only basis. Speed and
> reliability are equivalent to Standard Tier inference.

Its block repeats the Batch/Flex numbers: input $0.375 → $0.75, output $1.875 → $3.75, cache
$0.0375 → $0.075, with "Used to improve our products: Yes" on both free and paid.

### Tool-side billing notes relevant to this model (verbatim)

> Code execution: ... The generated code and execution results are billed as Output tokens when
> created, and as Input tokens when the model uses them as part of its iterative reasoning process.

> URL context — Charged as input tokens per model pricing.

> Computer use — Charged as regular tokens per model pricing (e.g., standard Gemini 3.8 Flash pricing).

> File search — Charged for embeddings at $0.15 / 1M tokens. Retrieved document tokens charged as
> regular tokens per model pricing.

## Summary

Every paid tier carries a dated step: current prices are introductory and roughly double on
January 1, 2027. The four serving modes form a clean ladder on input/output per 1M tokens —
Batch = Flex at half of Standard, Priority at 1.8× Standard — and the free tier exists on Standard
and Priority but not on Batch or Flex. Free-tier traffic is also the only traffic used to improve
products.

## Gaps

- No effective date for the *introductory* price (only its expiry), so this capture cannot tell when
  $0.75/$3.75 started. The launch date in the release notes is the best available anchor.
- No statement of what happens to in-flight context caches at the price step.
- Rate limits, per-region pricing and Provisioned Throughput are on separate pages and were not
  captured here.
- Audio output is priced per audio token on a separate block (`gemini-3.8-flash-tts`), not on this
  one; the text model cannot emit audio.

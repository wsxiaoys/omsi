# Gemini API release notes: Gemini 3.8 Flash launch and Gemini 3.7 Flash retirement routing

- Origin: Google, "Release notes" (Gemini API changelog), <https://ai.google.dev/gemini-api/docs/changelog>
  (publisher recorded as `google.dev`)
- Evidence kind: official documentation (changelog entries)
- Publication date: rolling; the newest entry captured is dated October 26, 2026.
- Capture date: 2026-10-26
- Relevant models: `gemini-3.8-flash`, predecessor `gemini-3.7-flash`, and the adjacent
  `gemini-3.8-live` / `gemini-3.8-flash-tts` entries used only for the family timeline.

## Captured content

### September 2, 2026 — general availability (verbatim)

> **Gemini 3.8 Flash generally available (GA)**: Released `gemini-3.8-flash`, our most intelligent
> Flash model, engineered for long-horizon software engineering, autonomous agents, and complex
> enterprise workflows.

> To get started, see the Gemini 3.8 Flash model page and the Gemini 3.8 Flash guide.

There is no earlier `gemini-3.8-flash` entry in the captured changelog, which reaches back to
February 26, 2026. On this record the model shipped **GA-first**, with no public preview ID.

### October 8, 2026 — predecessor retirement (verbatim)

> **Gemini 3.7 Flash deprecation**: `gemini-3.7-flash` is deprecated and has been replaced by
> `gemini-3.8-flash`. It is no longer available to select in Google AI Studio, and API requests to
> `gemini-3.7-flash` are automatically routed to `gemini-3.8-flash`. Update your model string to
> `gemini-3.8-flash` and review the Gemini 3.8 Flash guide.

The same entry deprecates `gemini-3.5-flash` in favour of `gemini-3.6-flash`, and offers
`gemini-3.8-flash` as an alternative target.

### Family-timeline entries on the same page (verbatim headings)

- September 15, 2026: "Gemini 3.8 Live and Gemini 3.8 Live Extended Thinking generally available".
- September 22, 2026: "Gemini 3.8 Flash TTS and Gemini 3.8 Flash-Lite TTS generally available".
- October 13, 2026: "Gemini 4 Argon (`gemini-4-argon`) generally available (GA)".

### October 26, 2026 entry (relevant only for the Interactions API default)

> ... `batchGenerateContent`) on the paid tier now store requests by default (`store=true`), matching
> the Interactions API.

## Summary

`gemini-3.8-flash` became generally available on **2026-09-02**, as a GA release rather than a
promotion out of a preview ID, and it replaced `gemini-3.7-flash` on 2026-10-08 — under eight weeks
after 3.7's own 2026-08-13 release (release dates from the deprecations table, captured separately) — when that model's endpoint began silently routing to it. The 3.8 generation then added Live (September 15)
and the two TTS tiers (September 22), so "Gemini 3.8 Flash" alone names only the text model.

## Gaps

- The changelog does not say whether a `gemini-3.8-flash-preview` ever existed internally; it only
  shows no public preview entry.
- Silent routing of `gemini-3.7-flash` requests means a caller pinned to the old string now gets a
  different model without an error. The changelog does not say when the routing started beyond the
  announcement date.
- No capability deltas, benchmark numbers or price statements in the 3.8 entry.

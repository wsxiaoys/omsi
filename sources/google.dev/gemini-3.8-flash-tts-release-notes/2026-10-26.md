# Google Gemini API docs: release notes (Gemini 3.8 Flash TTS GA entry)

  <https://ai.google.dev/gemini-api/docs/changelog>
- Evidence kind: official documentation (first-party changelog)
- Publication date: rolling; page footer reads "Last updated 2026-10-26 UTC". The relevant entry is
  dated **September 22, 2026**.
- Capture date: 2026-10-26

## Captured content

### September 22, 2026 — general availability (verbatim)

> **Gemini 3.8 Flash TTS and Gemini 3.8 Flash-Lite TTS generally available (GA):** Released our
> next-generation text-to-speech (TTS) audio models and the Gemini API Voices endpoint
> (`/v1beta/voices`):

> **Gemini 3.8 Flash TTS** (`gemini-3.8-flash-tts`): Flagship creative TTS model engineered for
> studio-grade voice fidelity, nuanced acting, regional dialects, and long-form multi-turn stability.

> **Gemini 3.8 Flash-Lite TTS** (`gemini-3.8-flash-lite-tts`): Fast, cost-efficient TTS model built to
> replace `gemini-3.1-flash-tts-preview` for high-throughput production and real-time voice agent
> cascades.

> **Voice design, Voice replication, and the Extended Voice Library:** Create persistent custom vocal
> personas from text prompts, replicate voices with consent verification, and query 150+ prebuilt and
> custom voices.

> See the Text-to-speech guide to get started.

## Summary

**2026-09-22 is the first-party GA date** for `gemini-3.8-flash-tts`, announced in the same entry as
its Flash-Lite sibling and the `/v1beta/voices` endpoint that backs Voice design, Voice replication
and the Extended Voice Library. The launch is inside the roster's one-year window (≥ 2025-10-26) by
eleven months, so no out-of-window exception applies.

Three details matter beyond the date:

1. **Only the sibling is described as a replacement.** The entry names Flash-Lite as the model "built
   to replace `gemini-3.1-flash-tts-preview`"; the flagship's one-line description carries no
   replacement role, even though the deprecations table lists both 3.8 IDs as replacements for the
   3.1 preview (`sources/google.dev/gemini-3.8-flash-tts-deprecations/2026-10-26.md`).
2. **The voice count is "150+" here**, against "hundreds" in the speech-generation guide and "more
   than 2,000 curated voices" on the Cloud/Vertex card. The three figures count different pools —
   prebuilt-plus-custom here, prebuilt-only in the guide's "30", curated library on Vertex — but no
   page reconciles them.
3. **GA on this platform, Preview on Vertex.** The Vertex model card for the same ID says "Launch
   stage: Preview", release date 2026-09-28
   (`sources/cloud.google.com/gemini-3.8-flash-tts-model-card/2026-10-26.md`).

## Gaps

- The entry does not date the model page, which says only "Latest update: September 2026".
- It announces no preview phase for either 3.8 ID, so there is no first-party record of a 3.8 TTS
  preview period before 2026-09-22.
- It gives no price, no rate limits, no region list and no deprecation schedule.
- No latency, streaming-time-to-first-audio, or quality figure accompanies the launch.

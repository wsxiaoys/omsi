# Google Gemini API docs: deprecations (Nano Banana rows)

- Origin: Google, "Deprecations", https://ai.google.dev/gemini-api/docs/deprecations
- Evidence kind: official documentation (support-window table)
- Publication date: not stated; continuously edited.
- Capture date: 2026-10-26
- Relevant models: `gemini-3.1-flash-image` (Nano Banana 2) and its preview ID, plus the
  neighbouring Nano Banana rows used to date the family.

### What these rows establish

- First availability of the Nano Banana 2 model ID is **2026-02-26**, as
  `gemini-3.1-flash-image-preview`; the GA ID `gemini-3.1-flash-image` is dated
  **2026-05-28**. The preview was shut down 2026-06-25.
- `gemini-3.1-flash-image` has **no announced shutdown date** as of the capture, but the table
  names `gemini-nano-banana-2.1` as its recommended replacement. A replacement recommendation
  and "no shutdown date" coexist, so the table is not a statement that NB2 is being retired on
  a known date.
- The table's "Release date" column means GA release date for stable IDs; the earlier preview
  availability appears only in the preview section.

## Known gaps

- "No shutdown date announced" is not a support commitment; no minimum notice period or
  deprecation policy for image models is stated on this page.
- The table does not say whether `gemini-3.1-flash-image` and
  `gemini-3.1-flash-image-preview` were the same weights; only the dates are given.
- Vertex AI / Gemini Enterprise Agent Platform maintains its own retirement dates (captured
  separately on the Cloud model card), which do not have to match this page.

## Additional caveat from the merged capture

- "No shutdown date announced" is not a support commitment; it only means none was published.
- The table does not say whether a deprecated model receives fixes, or whether traffic is
  silently rerouted. The changelog elsewhere describes silent rerouting for some text models
  (e.g. `gemini-3.5-flash` -> `gemini-3.6-flash`), so rerouting is a real possibility for
  `gemini-3.1-flash-image` too, but it is not stated for this model.

## Captured content

### Model-selection entry (verbatim)

> **Nano Banana 2 Lite** (Gemini 3.1 Flash Lite Image) (`gemini-3.1-flash-lite-image`): The
> fastest and cheapest Gemini image model, engineered for velocity and scale where speed and
> cost are the primary operational constraints. Not optimized for multiple reference inputs or
> multi-turn sequential editing.

### Feature bullets that name Lite (verbatim)

> **High-resolution output**: [...] Gemini 3.1 Flash Lite Image only supports 1K resolution.

> **Grounding with Google Search**: The model can use Google Search as a tool to verify facts
> and generate imagery based on real-time data (e.g., current weather maps, stock charts,
> recent events). Not supported by Gemini 3.1 Flash Lite Image model.

> **New aspect ratios**: Gemini 3.1 Flash Lite Image adds `1:1`, `3:2`, `2:3`, `3:4`, `4:3`,
> `4:5`, `5:4`, `9:16`, `16:9`, `21:9` aspect ratios.

> Note: Gemini 3.1 Flash Lite image model only supports 1K images.

Read literally, Lite gets **14 object references and no character-consistency or style slots**.

### Family-wide limitations that apply to Lite

> Image generation does not support audio inputs. [...]

> The model won't always follow the exact number of image outputs that the user explicitly asks
> for.

> For best performance, use the following languages: EN, ar-EG, de-DE, es-MX, fr-FR, hi-IN,
> id-ID, it-IT, ja-JP, ko-KR, pt-BR, ru-RU, ua-UA, vi-VN, zh-CN.

Every generated image is stated to carry a SynthID watermark.

## What this guide establishes about Lite

- **Lite is the documented successor to the original Nano Banana** (`gemini-2.5-flash-image`),
  not to Nano Banana 2. The deprecations table says the same in its "Recommended replacement"
  column.
- **No search grounding of any kind**, stated in the vendor's own feature list. The guide's
  Image Search grounding paragraph is scoped to 2.1 and Nano Banana 2 only.
- **1K is the only resolution**; the guide repeats it twice.
- **Reference budget is objects-only.** 14 objects, no characters, no style references. This
  directly contradicts the model page's "Maintains high character alignment matching original
  Nano Banana standards".
- **"Not optimized for multiple reference inputs or multi-turn sequential editing"** directly
  contradicts fal's marketing line "fast multi-turn local edits" for the same model. Both are
  first-party-or-host copy; neither is a measurement.

## Gaps and internal defects

- **No per-aspect-ratio resolution/token table for Lite.** The guide's resolution tables cover
  Nano Banana 2.1, Gemini 3.1 Flash Image, Gemini 3 Pro Image and Gemini 2.5 Flash Image only.
  A sibling record (`gemini-api-image-generation`) captured on the same date reports a Lite
  table with ten ratios; this capture cannot reproduce that table, so the discrepancy is left
  open rather than reconciled.
- The Limitations paragraph states the object/character split for `gemini-nano-banana-2.1`,
  `gemini-3.1-flash-image` and `gemini-3-pro-image` but is silent on Lite, so the only source
  for Lite's N/A character slots is the table column.
- The ten ratios are labelled "adds" / "New" even though the same set is standard across the
  family; the guide does not say what they are new relative to.
- No latency figure appears here, so the "fastest" claim cannot be checked against the model
  page's "sub-2 second" claim.

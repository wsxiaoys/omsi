# Google Gemini API docs: pricing (Nano Banana entries)

- Origin: Google, "Pricing", https://ai.google.dev/gemini-api/docs/pricing
- Evidence kind: official documentation (first-party price list)
- Publication date: not stated; continuously edited. Prices are list prices on the capture
  date, not a historical record.
- Capture date: 2026-10-26
- Relevant models: `gemini-3.1-flash-image` (Nano Banana 2) as the primary subject; the
  Nano Banana 2.1 and Nano Banana Pro blocks are captured only for comparison.

## Captured content

### Gemini 3.1 Flash Image (Nano Banana 2) — verbatim

> Designed for speed and efficiency, the Gemini 3.1 Flash Image generation model is effective
> for quick, interactive responses and high throughput.

Standard, paid tier, per 1M tokens (USD):

| Item | Price |
| --- | --- |
| Input | $0.50 (text/image) |
| Output, text and thinking | $3 |
| Output, images | $60.00 |

> Equivalent to $0.045 per 0.5K image\*, $0.067 per 1K image\*, $0.101 per 2K image\*, and
> $0.151 per 4K image\*.

Batch, paid tier, per 1M tokens (USD):

| Item | Price |
| --- | --- |
| Input | $0.25 (text, image) |
| Output, text and thinking | $1.50 |
| Output, images | $30.00 |

> Equivalent to $0.022 per 0.5K image\*, $0.034 per 1K image\*, $0.050 per 2K image\*, and
> $0.076 per 4K image\*.

Footnote (verbatim):

> Image output is priced at $60 per 1,000,000 tokens. Output images at 0.5K (512px) consume
> 747 tokens and are equivalent to $0.045 per image. Output images at 1K (1024x1024px) consume
> 1120 tokens and are equivalent to $0.067 per image. Output images at 2K (2048x2048px)
> consume 1680 tokens and are equivalent to $0.101 per image. Output images at 4K
> (4096x4096px) consume 2520 tokens and are equivalent to $0.151 per image.

Free tier: "Not available" for both standard and batch. Grounding with Google Web and Image
Search: "Not available" on the free tier; on the paid tier, "5,000 free search requests per
month (shared across all Gemini 3 and newer models), then $14 per 1,000 requests for text and
image-based grounding". The search-request footnote adds that retrieved grounding context "is
not charged as input tokens".

### Comparison blocks on the same page (verbatim figures only)

- `gemini-nano-banana-2.1` (Nano Banana 2.1): input $1.50, text/thinking output $7.50, image
  output $30.00 per 1M tokens — "$0.0336 per 1K image, $0.0504 per 2K image, and $0.113 per 4K
  image". Batch is exactly half.
- `gemini-3-pro-image` (Nano Banana Pro): input $2.00, text/thinking output $12.00, image
  output $120.00 per 1M tokens — "Equivalent to $0.134 per 1K/2K image and $0.24 per 4K
  image".

## Known gaps

- No effective date is given for any price, so this record cannot show whether a price changed
  since launch. Re-capture on a later date is the only way to establish that.
- Vertex AI / Gemini Enterprise Agent Platform pricing is a separate page and was not captured
  here; the Cloud model card links to it.
- The page states prices in both per-token and per-image terms; the per-image figures are
  rounded derivations and assume the stated token counts per resolution.
- Host prices (fal, Replicate) are set by the hosts and are recorded separately, not derived
  from this page.

## Nano Banana 2.1 details (verbatim, from the same capture)

Standard tier: $1.50 input (text/image/video), $7.50 text and thinking output, $30.00 image
output per 1M tokens. Batch is exactly half ($0.75 / $3.75 / $15.00).

Footnote (verbatim):

> Image output is priced at $30 per 1,000,000 tokens (Standard) and $15 per 1,000,000 tokens
> (Batch). Output images at 1K (1024x1024px) consume **1120 tokens** and are equivalent to
> **$0.0336 per image**. Output images at 2K (2048x2048px) consume **1680 tokens** and are
> equivalent to **$0.0504 per image**. Output images at 4K (4096x4096px) consume **3780 tokens**
> and are equivalent to **$0.113 per image**.

Data use, verbatim: "Used to improve our products: Yes [free tier], No [paid tier]."

### Contradiction with the image-generation guide

This page says a 4096x4096 4K image consumes **3780** tokens. The image-generation guide's 2.1
token table says a 4K image consumes **2520** tokens for every aspect ratio. Both are Google
pages read the same day. fal's cost table follows the 3780 figure. Unresolved; treat per-image
4K cost as approximate.

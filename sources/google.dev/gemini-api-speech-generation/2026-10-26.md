## What this revision is about

Every code sample in the live guide uses `gemini-3.8-flash-tts`. The 3.1 model appears only in the
supported-models table, in "when to use which model", and in the migration guide. **This revision no
longer documents the 3.1 request surface**; the 3.1-era schema (natural-language prompt plus
bracketed tags in the transcript) is described only in the archived revision.

## 3.1 in the live revision (verbatim)

> Use **Gemini 3.8 Flash-Lite TTS** (`gemini-3.8-flash-lite-tts`) as your fast, cost-efficient
> workhorse **replacement for `gemini-3.1-flash-tts-preview`**. It is optimized for high-volume bulk
> production, conversational voice agent cascades, read-aloud features, reliable voice replication,
> and everyday single-speaker speech across major languages.

Migration guide, opening line:

> If you are migrating from `gemini-3.1-flash-tts-preview` or earlier Gemini TTS models to Gemini 3.8
> TTS:

Migration guide, output-format clause — the only first-party statement about 3.1's default container:

> **Account for default WAV (`audio/wav`) output on unary requests:** Unlike
> `gemini-3.1-flash-tts-preview` and earlier TTS models (which returned headerless raw PCM
> `audio/l16` by default), Gemini 3.8 TTS returns WAV audio (`audio/wav`) with a standard RIFF header
> by default for unary requests.

Migration guide, prompt-shape clause — establishes what changed from 3.1 to 3.8:

> **Move turn-level directions into `speech_metadata`:** Gemini 3.8 TTS treats input text strictly
> as a verbatim transcript. Move sustained delivery instructions (`style` — such as "whispering",
> "out of breath", or "speaking slowly") and speaker labels (`speaker`) into structured
> `speech_metadata` annotations rather than embedding stage directions in the transcript text.

> **Use angle-bracket inline tags only for point-in-time vocal events:** Keep momentary non-speech
> vocalizations and pauses inline in the transcript using angle brackets (such as `<laugh>`, `<sigh>`,
> `<cough>`, `<breath>`, or `<short pause>`).

## Audio output formats (3.8, for contrast)

| Format | `mime_type` | Description |
| --- | --- | --- |
| WAV (unary default) | `audio/wav` | 16-bit signed little-endian PCM, mono, 24 kHz default |
| Raw PCM (L16) (streaming default) | `audio/l16` | headerless 16-bit signed LE PCM, 24 kHz, mono |
| Mu-law | `audio/mulaw` | 8-bit G.711 mu-law |
| A-law | `audio/alaw` | 8-bit G.711 A-law |

`sample_rate` can be set in Hertz ("for example, `24000`, `16000`, or `8000`").

No comparable count is given for 3.1 in this revision.

## Summary

The live TTS guide has moved past Gemini 3.1 Flash TTS. It confirms four things about 3.1: it is
still listed as a supported model with single- and multi-speaker output; it lacks voice design and
voice replication; it defaulted to headerless raw PCM (`audio/l16`) rather than WAV; and its prompt
format embedded stage directions in the transcript, which 3.8 replaced with structured
`speech_metadata`.

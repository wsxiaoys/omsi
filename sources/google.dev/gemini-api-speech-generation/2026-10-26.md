- Evidence kind: official documentation (first-party feature guide)
- Publication date: not stated; page footer reads "Last updated 2026-10-12 UTC"
- Capture date: 2026-10-26

## Captured content

### Scope (verbatim)

> This guide shows you how to generate single-speaker and multi-speaker audio from text using Gemini
> 3.8 Flash TTS (`gemini-3.8-flash-tts`) and Gemini 3.8 Flash-Lite TTS
> (`gemini-3.8-flash-lite-tts`).

> TTS models accept text-only inputs and produce audio-only outputs.

SDK floor: "`google-genai >= 2.25.0` for Python or `@google/genai >= 2.24.0` for
JavaScript/TypeScript".

### Audio output formats and sample rate (verbatim)

> Unary requests (`stream=False`): Return complete WAV (`audio/wav`) audio with a standard RIFF
> header (24 kHz, mono, 16-bit signed little-endian PCM).

> Streaming requests (`stream=True`): Return headerless raw Linear PCM (`audio/l16`) chunks (24 kHz,
> mono, 16-bit signed little-endian PCM) by default.

| Format | `mime_type` | Description (verbatim) |
| --- | --- | --- |
| WAV (unary default) | `audio/wav` | Uncompressed WAV file with a RIFF header (16-bit signed little-endian PCM, mono, 24 kHz default). Default for unary requests. |
| Raw PCM (L16) (streaming default) | `audio/l16` | Uncompressed, headerless 16-bit signed little-endian linear PCM audio (24 kHz, mono). Default for streaming requests. |
| Mu-law | `audio/mulaw` | 8-bit G.711 mu-law encoded audio (commonly used in North American and Japanese telephony/IVR systems). |
| A-law | `audio/alaw` | 8-bit G.711 A-law encoded audio (commonly used in European and international telephony systems). |

> You can also specify `sample_rate` in Hertz (for example, `24000`, `16000`, or `8000`).

### Voices (verbatim)

> Gemini 3.8 TTS supports four ways to select or create voices:
>
> - Prebuilt studio voices: 30 curated voices listed in the following table.
> - Extended Voice Library: Hundreds of additional voices across languages, accents, and character
>   archetypes accessible using `client.voices.list()` (`GET /v1beta/voices`).
> - Voice design: Generate a custom vocal persona from a natural-language description … (`type="prompted"`).
> - Voice replication: Replicate a speaker's voice from reference and consent audio … (`type="replicated"`).

### Custom voice storage limits and TTL (verbatim)

> Stateful voices (`store=True`, prompted or replicated): Maximum of 200 voices per project with a
> 1-year TTL (time-to-live).

> Stateless voice keys (`store=False`, `voicekey_...`): 7-day TTL (time-to-live).

> TTL extension: The 1-year retention window resets each time the voice is actively used … Voices
> with no activity for 1 year are automatically deleted.

### Limitations (verbatim)

> TTS models accept text-only inputs and generate audio-only outputs.

> Single-request multi-speaker generation (`speech_config.speakers`) supports up to 2 speakers using
> prebuilt voices. To combine custom designed (`voice_...`) or replicated (`voice_...` /
> `voicekey_...`) voices in multi-character dialogue, synthesize each speaker's turn individually.

> Because unary requests return `audio/wav` with a 44-byte RIFF header by default, request raw PCM
> (`{"type": "audio", "mime_type": "audio/l16"}`) or strip the WAV header from each turn before
> concatenating the 24kHz PCM audio frames.

> Review the Supported languages section for language coverage.

### Prompting contract (verbatim, abridged)

> Gemini 3.8 TTS models treat input text strictly as a **verbatim transcript**.

- Turn-level delivery goes in `speech_metadata.style` ("angry tone", "speaking rapidly", "out of
  breath", "whispers", "sarcastic").
- Point-in-time events stay inline in angle brackets: `<cough>`, `<breath>`, `<sigh>`, `<short pause>`.
  "Avoid sound-effect tags (such as applause or thuds)".
- Every turn of a multi-speaker request must carry `speaker` in `speech_metadata`.
- "In multi-speaker dialogue, wrap listener reactions in pipe characters".

### When to use which (verbatim)

> Use Gemini 3.8 Flash-Lite TTS … as your fast, cost-efficient workhorse replacement for
> `gemini-3.1-flash-tts-preview`. It is optimized for high-volume bulk production, conversational
> voice agent cascades, read-aloud features, reliable voice replication, and everyday single-speaker
> speech across major languages.

> Use Gemini 3.8 Flash TTS … when maximum acoustic fidelity, nuanced acting, and expressive control
> are top priority.

## Summary

This is the document that carries the operational facts the model cards omit: 24 kHz mono 16-bit
output in WAV (unary default), `audio/l16` (streaming default), mu-law and A-law for telephony, and
a configurable `sample_rate` of 24000 / 16000 / 8000 Hz. Voice surface is 30 prebuilt names plus a
"hundreds"-strong Extended Voice Library, with Voice design and Voice replication available on both
3.8 IDs but **not** on the 3.1 or 2.5 TTS previews — the clearest capability delta from the model
Flash-Lite replaces.

Hard limits documented here are qualitative rather than numeric: 2 speakers per request, 200 stored
voices per project, 1-year / 7-day TTLs. The token limits (8,192 in / 16,384 out) live on the model
pages, not here.

## Gaps

- **No character or duration limit is stated anywhere in this guide**, and no maximum audio length.
- **No watermarking or SynthID statement** — the words "SynthID" and "watermark" do not appear on this
  page. Provenance marking is therefore not first-party documented for Gemini TTS here.
- No latency figures, no streaming-token-rate figures, no concurrency guidance.
- No statement on whether style/metadata strings bill as input tokens.
- The guide says "Hundreds" of Extended Voice Library voices; the changelog says "150+" and the Cloud
  page says "more than 2,000". Unresolved count.

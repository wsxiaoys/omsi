# Gemini API docs: pricing, Gemini Omni Flash block

- Origin: Google, "Gemini Developer API pricing", https://ai.google.dev/gemini-api/docs/pricing
  (publisher recorded as `google.dev`, the registrable domain). The page is shared across every Gemini
  model; this capture is the Gemini Omni Flash slice only, and the shared page already has an earlier
  record for the Nano Banana entries, which was not edited.
- Evidence kind: official documentation (first-party list price)
- Publication date: not stated; continuously edited. Prices are list prices on the capture date, not a
  historical record.
- Capture date: 2026-10-26
- Relevant models: `gemini-omni-1.1-flash`

## Captured content

### Block heading and description (verbatim)

> Gemini Omni Flash
> `gemini-omni-1.1-flash`
> Our next-generation video generation and editing model, now generally available to developers on the
> paid tier of the Gemini API.

### Price table (verbatim)

| Item | Free tier | Paid tier, per 1M tokens (USD) |
| --- | --- | --- |
| Input price | Not available | $1.50 (text / image / video / audio) |
| Output price (including thinking tokens) | Not available | $9.00 (text); $17.50 (video) |
| Used to improve our products | Yes | No |

### Billing basis (verbatim)

> Billing is based on total output token consumption, calculated at a rate of 5,792 tokens per second
> of 720p video. Under Standard pricing, this equates to an effective price of approximately $0.10 per
> second.

## Summary

Gemini Omni 1.1 Flash has no free tier. Billing is **token-based, not per-second**: input at $1.50 per
million tokens across text, image, video and audio; output at $9.00 per million text tokens and $17.50
per million video tokens. Google converts the video rate to "approximately $0.10 per second" at 720p
using 5,792 tokens per second, which is an arithmetic restatement of the token price rather than a
separate per-second SKU. The same page states the model is "generally available to developers on the
paid tier", i.e. GA on the Gemini API.

Only the 720p conversion is published. Google does not state token-per-second rates for 360p, 1080p or
4K, so the effective per-second price at those resolutions is not derivable from this page — the host
record is the only source for them.

## Gaps

- No 360p/1080p/4K token rates, and no statement of whether upscaled output is billed at native rates.
- No per-image, per-second or per-video cap; no monthly quota.
- No date attached to the "generally available" sentence, so GA cannot be dated from this page (the
  release notes record supplies 2026-08-27).
- Input token accounting for image/video references is not explained; only output video is quantified.

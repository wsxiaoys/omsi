## Summary

This is the page that resolves the roster label. The model's own Gemini API identity is
`gemini-omni-1.1-flash`, currently **Stable**, and the only retired ID in the version list is
`gemini-omni-flash-preview`. There is no non-Flash "Gemini Omni" and no "Gemini Omni 1.1" without the
Flash tier suffix. The page also states the operational envelope: 3–10 s output at 24 FPS, 360p/720p/
1080p/4K, 1,048,576-token context, video input up to 10 s for editing and extension, video-only output.

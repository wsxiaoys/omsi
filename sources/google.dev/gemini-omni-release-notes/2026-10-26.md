# Gemini API docs: release notes, Gemini Omni Flash entries

- Origin: Google, "Release notes", https://ai.google.dev/gemini-api/docs/changelog (publisher recorded as
  `google.dev`, the registrable domain). The page is a rolling changelog covering all Gemini models;
  this capture is the two Gemini Omni Flash entries only. The shared page already has an earlier record
  for the Nano Banana entries, which was not edited.
- Evidence kind: official documentation (first-party dated release notes)
- Publication date: entries are dated 2026-06-30 and 2026-08-27; the page itself is continuously edited.
- Capture date: 2026-10-26
- Relevant models: `gemini-omni-flash-preview`, `gemini-omni-1.1-flash`

## Captured content

### 2026-06-30 (verbatim)

> Gemini Omni Flash in public preview: Released `gemini-omni-flash-preview`, a high-performance
> multimodal model designed for high-speed video generation and conversational video editing. Using the
> Interactions API, you can generate 3–10 second videos at 720p from text descriptions or animate still
> images, and then conversationally edit and refine the outputs.

### 2026-08-27 (verbatim)

> Gemini Omni Flash generally available (GA): Released `gemini-omni-1.1-flash`, the GA version of our
> fast, conversational video generation and editing model. This release includes significant new
> capabilities:
> - Video extension: Seamlessly extend existing videos by generating continuations at the end of a clip
>   using the `extend` task or directly with a prompt.
> - Interpolation (first + last frame): Generate a video transitioning between two images using the
>   `image_to_video` task with up to 2 images.
> - Resolution control: New `resolution` parameter in `video_config` supports 360p, 720p (default),
>   1080p, and 4k outputs. 1080p and 4K outputs are generated using upscaling.
> The existing `gemini-omni-flash-preview` endpoint will be deprecated on September 30, 2026.

## Summary

The changelog supplies the two dated events that make this a versioned model rather than a label:

- **2026-06-30** — first Gemini API appearance, as `gemini-omni-flash-preview`: 3–10 s clips at 720p
  only, text-to-video and image-to-video, conversational editing.
- **2026-08-27** — GA as `gemini-omni-1.1-flash`, adding extension, first+last-frame interpolation and
  resolution control up to 4K (upscaled). The preview endpoint was to be deprecated 2026-09-30, and the
  model page now lists it as shut down.

So "1.1" is the GA version of the preview model, and the delta between them is documented: extension,
interpolation and resolution control. Nothing in this record indicates a quality improvement claim; the
vendor describes capability additions only.

## Gaps

- No statement of quality differences between `gemini-omni-flash-preview` and `gemini-omni-1.1-flash`.
- The 2026-08-27 entry does not mention audio, pricing, regions or rate limits.
- No entry explains the model card's "Initially Published: May 2026" — a date one month before the API
  preview.
- The changelog does not confirm that the 2026-09-30 deprecation actually executed; only the model
  page's "Shut down" list does.

> Muse Spark Open is Meta's open-weight model, an 816-billion-parameter Mixture-of-Experts reasoning
> model with 42B parameters active per token. It always reasons before answering, with adjustable
> reasoning effort, and supports tool calling, structured outputs, and image input for agentic and
> coding workflows. On Groq, Muse Spark Open is in limited preview. Contact us to discuss access for
> your organization.

Limits:

> MAX INPUT IMAGES 5

Quantisation:

> This uses Groq's TruePoint Numerics, which reduces precision only in areas that don't affect
> accuracy, preserving quality while delivering significant speedup over traditional approaches.

Architecture summary:

> A Mixture-of-Experts model with 816B total parameters and 42B activated per token, accepting text
> and image input and producing text output. Served on Groq with a 131K-token context window and up
> to 131K output tokens. Released under the Muse Model License.

Capabilities:

> * Reasoning is always on, with `reasoning_effort` set to `low`, `medium`, `high`, or `xhigh`
>   (default `xhigh`)
> * Tool calling, including parallel tool calls
> * Structured outputs with JSON schema
> * Image input alongside text

Best practices:

> Sampling: Muse Spark Open is tuned to perform best at its default temperature and top_p, so you can
> leave both unset.
>
> Stop sequences: stop applies to the final answer, so you can use stop strings freely without
> cutting reasoning short.

## Summary

Groq serves the model as an **enterprise-gated limited preview** with a **131,072-token context** —
one eighth of the 1,048,576 Meta documents — and **at most 5 input images per request**. It quotes
~350+ output tokens per second, the highest figure in the capture set (OpenRouter's best provider
measured 294 tps P50). No price is published on the page. The page's modality list is text + images
only, matching Fireworks and differing from Meta's text/image/video/audio claim.

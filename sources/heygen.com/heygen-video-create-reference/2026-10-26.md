## Endpoint summary (verbatim)

> Generates a scene with its sound from a prompt using HeyGen Video (`heygen-video-1`). Set `mode` to
> `text_to_video`, `image_to_video` or `reference_to_video`; **reference-to-video takes up to fifteen
> references in total, and reference videos must be between 1:4 and 4:1.** Returns 202 with a
> `video_id`; poll GET /v3/models/videos/{video_id}. Send an Idempotency-Key to retry safely; without
> one, each submission creates a new generation. To have an avatar speak a script, use POST
> /v3/videos.

Server: `https://api.heygen.com`. Tags in the same OpenAPI document: "Video Agent — Create videos
from text prompts using AI", "Videos — Create, list, retrieve, and delete videos".

## Request fields (verbatim descriptions)

| Field | Schema | Verbatim description |
| - | - | - |
| `model` | `const: heygen-video-1` | "Required video generation model. Only heygen-video-1 is supported." |
| `mode` | `const` per request variant | `text_to_video`, `image_to_video`, `reference_to_video` |
| `prompt` | `minLength: 1`, `maxLength: 16000` | "Instructions for the video to generate. At most 16,000 Unicode characters." |
| `prompt_enhancement` | enum `turbo`, `quality`, `default`, `disabled`, `ultraquality`; default `quality` | "Defaults to quality; default is an alias for turbo." |
| `resolution` | enum `480p`, `768p`, `1080p`, `2k`; default `768p` | "At 1080p and 2k, text-to-video and reference-to-video require aspect_ratio 16:9 or 9:16; image-to-video follows the image proportions." |
| `duration` (T2V/I2V) | integer 5–30 or `auto`; default `5` | "Above 15 requires text_to_video or image_to_video, 480p/768p/1080p/2k, and turbo/default/quality enhancement." |
| `duration` (Ref2V) | integer 5–15 or `auto`; default `5` | "Auto estimates quoted speech between 8 and 15 seconds." |
| `duration` (MCP variant) | integer 5–15 or `auto` | `x-mcp-schema` caps the same field at 15 |
| `aspect_ratio` | `21:9`, `16:9`, `4:3`, `1:1`, `3:4`, `9:16`, `adaptive` | "Adaptive uses the first reference image, or the first reference video when no images are supplied; audio-only references use 16:9." |
| `aspect_ratio` (I2V) | nullable | "The output follows the image proportions, aligned to supported pixel dimensions. Any supplied aspect ratio is ignored." |
| `seed` | integer 0–4294967295, nullable | "Generation seed. A random seed is chosen when omitted." |
| `image` | asset (url / asset_id / base64), required for I2V | "First-frame image." |
| `reference_images` | array, `maxItems: 9` | "Reference images. At most nine." |
| `reference_videos` | array, `maxItems: 3` | "Reference videos. At most three." |
| `reference_audio` | array, `maxItems: 3` | "Reference audio recordings. At most three." |
| `end_user_id` | 1–128 non-whitespace chars | "Stable, opaque end-user identifier … Used for usage attribution and abuse investigation; does not change billing, authorization, or rate limits." |
| `callback_url` / `callback_id` | string / ≤256 chars | "HTTPS webhook URL for the terminal generation event." / "Client tracking ID echoed in the terminal webhook event." |

`ReferenceToVideoRequest` requires only `mode`, `model` and `prompt` — the "at least one reference
image or video" rule from the developer guide is not encoded as a schema requirement here.

`CreateModelVideoResponse` returns `video_id`, `status: pending`, and `input_video_duration`: "Total
reference-video duration used, in seconds, capped at 5 seconds per video (15 seconds maximum)."

Errors are `StandardAPIError` objects: `code` (e.g. `invalid_parameter`), `message`, `param`,
`doc_url`, optional `errors[]`, and `request_id` ("also returned in the X-HeyGen-Request-Id response
header").

## What this establishes

- The request surface is one model ID, `heygen-video-1`, with three mutually exclusive mode schemas.
- Duration caps differ by mode and enhancement level: 30 s for text/image with `turbo`/`quality`, 15 s
  for reference-to-video, `ultraquality`, `disabled`, and MCP.
- Reference limits are 9 images + 3 videos + 3 audio (15 total), with a 5-second read per reference
  video and an aspect-ratio window of 1:4 to 4:1 for reference videos.
- Abuse handling is exposed as `end_user_id` attribution, not as a consent check.

## Contradictions with the developer guide (same capture date)

- Prompt ceiling: **16,000** here versus **32,000** in the guide and in fal's schema.
- Reference total: **fifteen** here versus "Total across all three | 12" in the guide (the guide's own
  list sums to 15).

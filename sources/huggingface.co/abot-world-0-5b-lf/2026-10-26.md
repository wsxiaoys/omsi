## Card headline (verbatim)

> **TL;DR:** ABot-World turns a single NVIDIA RTX 5090 desktop GPU into a real-time interactive world
> simulator, enabling infinite action-conditioned world rollout at 720P, 16 FPS, 1.2s latency, and
> 19GB GPU memory.

The card is the same README as the GitHub repository, with two differences that matter:

1. **No Docker option.** The card's setup is the manual conda/PyTorch/FlashAttention/SageAttention
   path only; the repository adds the prebuilt `amapcvlab/abot-world:v0-env` image and the Alibaba
   Cloud Container Registry mirror.
2. **A different tested environment.** The card says "This installation was tested on: Ubuntu 22.04,
   **CUDA 13.3**, NVIDIA RTX 5090", while the repository README says "Ubuntu 22.04, **CUDA 12.8**,
   Python 3.12, NVIDIA RTX 5090" and `FAQ.md` lists only "CUDA 12.8 and CUDA 12.9" as tested. The
   card's 13.3 appears on no other first-party page and is not in the FAQ's tested list, so the
   supported CUDA range is genuinely ambiguous between 12.8 and 13.3.

The news list on the card stops at 2026-08-15 and so omits the repository's 2026-09-08 Docker entry.
The roadmap is present and identical, including the unchecked "Bidirectional Teacher Model Release".

## What this establishes

- The released weights are **open** (Apache 2.0, ungated, no access request) and small enough for one
  consumer GPU: 5.27B BF16 parameters, ~24.8 GB on disk.
- The architecture is a **Wan2.2 TI2V-5B derivative** with Wan2.2 VAE, a TAeW2.2 streaming VAE and a
  UMT5-XXL text encoder — i.e. an image-and-text-conditioned base, adapted to action conditioning.
- The suffix `LF` is not expanded on the card, but the repository, paper and config
  (`configs/long_forcing_dmd.yaml`) tie it to LongForcing.
- Names are bilingual: English (`en`) and Chinese (`zh`), consistent with the UMT5 text encoder and
  the China-facing Studio.

## Gaps

- The card does not state output resolution in pixels, aspect ratios, context length, maximum session
  length, or whether a safety filter exists.
- No inference example beyond the gradio demo; no documented Python API for a programmatic rollout.
- The `en`/`zh` language tags describe prompt language support and were not tested.

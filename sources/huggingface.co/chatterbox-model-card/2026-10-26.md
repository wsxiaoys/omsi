Weight files in the repository include both the original English checkpoint (`conds.pt`,
`t3_cfg.safetensors`, `s3gen.safetensors`, `ve.safetensors`) and multilingual T3 checkpoints
(`t3_mtl23ls_v2.safetensors`, `t3_mtl23ls_v3.safetensors`, `t3_23lang.safetensors`) plus a v3 decoder
(`s3gen_v3.safetensors`). The repository holds the original **and** both multilingual generations;
there is no separate `ResembleAI/chatterbox-multilingual` weights repo under this org.

## Release notes on the card (verbatim)

> **09/04 🔥 Introducing Chatterbox Multilingual in 23 Languages!**
>
> We're excited to introduce **Chatterbox** and **Chatterbox Multilingual**, Resemble AI's
> production-grade open source TTS models. […] Licensed under MIT, Chatterbox has been benchmarked
> against leading closed-source systems like ElevenLabs, and is consistently preferred in
> side-by-side evaluations.
>
> It's also the first open source TTS model to support **emotion exaggeration control** […]

Key details list (verbatim):

> - Chatterbox Multilingual V3, a 0.5B general-purpose multilingual TTS model supporting 23 languages
> - Dedicated single-language finetunes for Chinese, LatAm Spanish, Brazilian Portuguese, Spain
>   Spanish, Portugal Portuguese, and Hindi
> - SoTA zeroshot English TTS
> - 0.5B Llama backbone
> - Unique exaggeration/intensity control
> - Ultra-stable with alignment-informed inference
> - Trained on 0.5M hours of cleaned data
> - Watermarked outputs
> - Easy voice conversion script
> - Outperforms ElevenLabs

Tips (verbatim):

> The default settings (`exaggeration=0.5`, `cfg=0.5`) work well for most prompts.
>
> If the reference speaker has a fast speaking style, lowering `cfg` to around `0.3` can improve pacing.
>
> ***Note:*** Ensure that the reference clip matches the specified language tag. Otherwise, language
> transfer outputs may inherit the accent of the reference clip's language. ***To mitigate this, set
> the CFG weight to 0.***

Multilingual quickstart selects the checkpoint explicitly:
`ChatterboxMultilingualTTS.from_pretrained(device="cuda", t3_model="v3")`, with the comment "To use
the legacy V2 multilingual checkpoint, omit `t3_model` or pass `t3_model="v2"`."

Watermarking section is identical to the GitHub README ("Every audio file generated by Chatterbox
includes Resemble AI's Perth (Perceptual Threshold) Watermarker […] nearly 100% detection accuracy").

## Summary

The weights are MIT-licensed and publicly downloadable at no cost, at 24 kHz output (per the
package source, see the GitHub record), for both the English model and the 23-language multilingual
model. The card mixes three generations under one repository — original English, multilingual v2
(2025-09-04) and multilingual v3 (2026-06-10) — and the only first-party quality claim is
"Outperforms ElevenLabs", with no number attached on this page.

## Gaps

- No stated input-length or output-duration limit.

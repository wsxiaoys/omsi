## Identity statements (verbatim, both cards)

> Dia is a 1.6B parameter text to speech model created by Nari Labs.

> Dia directly generates highly realistic dialogue from a transcript. You can condition the output
> on audio, enabling emotion and tone control. The model can also produce nonverbal communications
> like laughter, coughing, clearing throat, etc.

> To accelerate research, we are providing access to pretrained model checkpoints and inference
> code. The model weights are hosted on Hugging Face. The model only supports English generation at
> the moment.

> We also provide a demo page comparing our model to ElevenLabs Studio and Sesame CSM-1B.

> Play with a larger version of Dia: generate fun conversations, remix content, and share with
> friends. 🔮 Join the waitlist for early access.

The "larger version" waitlist is the only forward-looking statement on either card.

## Sample rate (verbatim usage snippet, both cards)

```python
import soundfile as sf
from dia.model import Dia
model = Dia.from_pretrained("nari-labs/Dia-1.6B")
text = "[S1] Dia is an open weights text to dialogue model. [S2] You get full control over scripts and voices. [S1] Wow. Amazing. (laughs) [S2] Try it now on Git hub or Hugging Face."
output = model.generate(text)
sf.write("simple.mp3", output, 44100)
```

44,100 Hz is the only sample rate stated on the cards; there is no bitrate or container guidance.

## Differences between the two cards (full diff)

The 0626 card is the 1.6B card plus a new section, with the checkpoint path swapped:

> ### As part of transformers
>
> #### Generation with Text
>
> `model = DiaForConditionalGeneration.from_pretrained(model_checkpoint)` …
> `outputs = model.generate(**inputs, max_new_tokens=256)  # corresponds to around ~2s`
>
> #### Generation with Text and Audio (Voice Cloning)
>
> `inputs = processor(text=text, audio=audio, padding=True, return_tensors="pt").to(torch_device)`
> … `prompt_len = processor.get_audio_prompt_len(inputs["decoder_attention_mask"])` …
> `outputs = processor.batch_decode(outputs, audio_prompt_len=prompt_len)`

Nothing else changes: same disclaimer, same non-verbal tag list, same "CPU support is to be added
soon", same Apache 2.0 statement, same hardware paragraph ("on a A4000 GPU, Dia roughly generates
40 tokens/s (86 tokens equals 1 second of audio)"). No quality, latency, or capability claim
distinguishes 0626 from the April weights; the only stated difference is the Transformers
integration and, per the repository's PR #243, "updated weights" and "new logit controls".

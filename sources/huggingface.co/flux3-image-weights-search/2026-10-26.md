- Origin: Hugging Face model API, `GET https://huggingface.co/api/models?search=FLUX.3&limit=50`
  (used to check whether FLUX 3 Image weights are published)
- Evidence kind: host catalogue metadata (machine-readable index of published repositories)
- Publication date: n/a — live API; each repository's `createdAt` is recorded below
- Capture date: 2026-10-26
- Relevant models: FLUX 3 Image (absent), FLUX 3 Image Klein, FLUX 3 Action

image generation.

## What this establishes

- The open-weights surface of FLUX 3 image generation is Klein only, published 2026-10-13/14 —
  two days before the Klein announcement, and twelve days after FLUX 3 Image's API launch.
- FLUX 3 Image itself is weights-private. Combined with the launch plan in
  `../../bfl.ai/flux3-announcement/2026-10-26.md` ("private weight access") and the product page's
  "commercial weights license", the conclusion is consistent across three independent statements
  from the same publisher.
- Community adoption concentrates on Klein within days (download counts in the tens of thousands to
  ~700k for the Comfy variant), which is consistent with Klein being the only locally runnable
  option.

## Gaps

- Absence is established from the **search index only**. Direct probes of
  `https://huggingface.co/black-forest-labs/<name>` return HTTP 401 for every name tried, including
  a deliberately nonexistent control (`flux-3-nonsense-xyz`), so a 401 says nothing about whether a
  repository exists. A gated or private repository would not appear in this query.
- This is an index query, not a licence read. The FLUX Kommunity License terms were not captured;
  the claim that the weights are open is the vendor's and the host's, not a legal reading.
- Download counts are a popularity signal, not evidence of quality.

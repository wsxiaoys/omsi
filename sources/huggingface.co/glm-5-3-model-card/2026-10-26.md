## Harnesses, verbatim from the footnotes

- **Terminal-Bench 2.1:** "Claude Code 2.1.207 with temperature=1.0, top_p=1, max_new_tokens=65536 with 6h timeout".
- **Terminal-Bench 3.0:** "Claude Code 2.1.207 harness (reasoning effort=max, 400K context, and 128K maximum output), reporting avg@3 over three rollouts per task … capped at 600 agent turns with a 10-hour timeout. Tool Search is disabled".
- **DeepSWE:** "mini-swe-agent harness with temperature=0.95, top_p=1.0, timeout=6h and 400K context".
- **Agent's Last Exam (CLI):** "Claude Code harness (reasoning effort=max, 1M context, and 64K maximum output)".
- **HLE w/ tools:** "maximum generation length of 163,840 tokens … maximum context length of 300,000 tokens … GPT-5.6-luna (medium) as the judge model".
- **CyberGym:** "single-run Pass@1 over 1,507 tasks"; git information removed and a domain whitelist applied "to prevent the agent from cheating".
- **ExploitGym:** "single-run Pass@1 on 869 tasks under two timeout budgets: 2 hours and 6 hours … rescaled by per-model tokens per second rate (per-model TPS sourced from Artificial Analysis; that is, we rescale GLM-5.3's results by 115 TPS …)".
- **GDPval-AA v2:** "Models are evaluated by Artificial Analysis." — one of only two rows on
  the card that is not vendor-run, the other being FrontierSWE (run by Proximal).
- **FrontierSWE:** "The evaluation was conducted by Proximal with 1M context length, max
  effort level, and 128K maximum output tokens."

Almost every row is vendor-run under the Claude Code harness, with competitor cells quoted
from the competitors' own publications rather than re-run.

## Reasoning controls, verbatim

> "GLM-5.3 supports controlling the thinking budget through the `reasoning_effort` parameter,
> which accepts three levels: `low`, `high`, and `max`. It defaults to `max` if not passed (or
> if set to any other value). … For benchmark and leaderboard reproduction, keep the default
> `max`."

> "In the chat template for GLM-5.3, `clear_thinking` defaults to `false` if not passed. For
> chat scenarios, explicitly pass `clear_thinking=true`."

That second note matters operationally: the default keeps prior turns' reasoning in context,
which inflates token use in multi-turn chat unless the caller opts out.

## Architecture, from `config.json`

Selected fields: `model_type: glm_moe_dsa`, `architectures: [GlmMoeDsaForCausalLM]`,
`num_hidden_layers: 78`, `hidden_size: 6144`, `num_attention_heads: 64`, `head_dim: 192`,
`q_lora_rank: 2048`, `kv_lora_rank: 512`, `n_routed_experts: 256`, `n_shared_experts: 1`,
`num_experts_per_tok: 8`, `moe_intermediate_size: 2048`, `first_k_dense_replace: 3`,
`max_position_embeddings: 1048576`, `vocab_size: 154880`, `rope_theta: 8000000`,
`num_nextn_predict_layers: 1`, and an `fp8` `quantization_config` (e4m3, 128×128 blocks).

The `mlp_layer_types` list marks 3 dense layers followed by 75 sparse (MoE) layers, and
`indexer_types` describes a DeepSeek-style sparse-attention indexer shared across groups of
layers — consistent with the `glm_moe_dsa` name ("MoE + DSA").

**Derived, not stated by the vendor:** 75 MoE layers × (256 routed + 1 shared) experts ×
3 × 6144 × 2048 weights ≈ 728B parameters in the expert matrices alone; adding attention,
embeddings and the three dense layers puts the total in the 730–750B range, consistent with
Artificial Analysis's published **753B total / 40B active** figures
([AA](../../artificialanalysis.ai/glm-5-3/2026-10-26.md)). With 8 of 257 experts active, the
active path is ~40B. Z.ai does not state GLM-5.3's parameter counts on the card, in the
docs, or in the blog — only GLM-5.3-Flash's (320B / 18B).

## Deployment notes, verbatim

Local serving is documented for SGLang, vLLM, TokenSpeed, Transformers, KTransformers and
Unsloth, plus "deployment on the `Ascend NPU` platform" via "vLLM-Ascend, xLLM and SGLang".

## Summary

First-party confirmation that GLM-5.3 is an **open-weights** (fp8, 141-shard) model under a
custom licence, with the full vendor benchmark table and its harnesses. The card is the
authoritative source for the vendor's numbers and for the post-training-only identity claim;
it is not independent evidence of quality.

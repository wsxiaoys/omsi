# Hugging Face: ideogram-ai model repositories

- Origin: Hugging Face Hub API query for models by the `ideogram-ai` organization,
  https://huggingface.co/api/models?author=ideogram-ai
- Evidence kind: provider catalogue metadata (host listing; not documentation)
- Publication date: none stated
- Capture date: 2026-10-26
- Relevant models: Ideogram 4.0 (open weights), Ideogram 4.5 (absence of weights)

## Captured content

The query returned exactly three repositories, verbatim `modelId` values:

```
ideogram-ai/ideogram-4-fp8
ideogram-ai/ideogram-4-nf4
ideogram-ai/ideogram-4-nf4-diffusers
```

No repository matching `ideogram-4.5`, `ideogram-4-5`, or any 4.5 variant was listed.

Corroborating first-party statements: the docs blog index describes Ideogram 4.0 as "our first
open-weight model" (Jun 3, 2026)
([blog index](../../ideogram.ai/ideogram-blog-posts-index/2026-10-26.md)), and the licensing page
describes the open weights as "a quantized version of the model published on Hugging Face"
([licensing](../../ideogram.ai/ideogram-licensing/2026-10-26.md)).

## Interpretation

Ideogram 4.5 is **hosted-only** as of capture: no public weights, no self-host path, and therefore
no weight-license decision for a reader. Absence of a repository on the organization listing is
strong but not absolute evidence — a gated or private repository would not appear.

## Known gaps

- The query lists public repositories only; gated/private repos and other organizations are not
  covered.
- No model card, license file, or parameter count was captured for the Ideogram 4 repositories
  (out of scope for this page).

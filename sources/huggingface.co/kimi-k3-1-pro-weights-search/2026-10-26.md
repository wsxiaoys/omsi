# Kimi K3.1 Pro weights search on Hugging Face (absence record)

- **Origin:** Moonshot AI organisation on Hugging Face, <https://huggingface.co/moonshotai>;
  attempted model repositories <https://huggingface.co/moonshotai/Kimi-K3.1-Pro> and
  <https://huggingface.co/moonshotai/Kimi-K3.1-Pro-Highspeed>. Retrieved 2026-10-26.
- **Evidence kind:** direct observation of a repository listing (negative result).
- **Publication date:** n/a. Capture date 2026-10-26.
- **Relevant models:** Kimi K3.1 Pro, Kimi K3.1 Pro Highspeed; Kimi K3 (for contrast).
- **Capture type:** summary of the organisation page's rendered text and HTTP status of the
  two candidate repository URLs.

## Observation

- `https://huggingface.co/moonshotai/Kimi-K3.1-Pro` returned **HTTP 401**, as did
  `…/Kimi-K3.1-Pro-Highspeed`. (401, not 404: the path is not an anonymous public repository;
  whether it is gated-but-existing or simply unauthorised is not distinguishable from an
  unauthenticated request.)
- The organisation page's model list on the same capture contains `moonshotai/Kimi-K3`,
  `moonshotai/Kimi-K2.7-Code`, `moonshotai/Kimi-K2.6`, `moonshotai/Kimi-K2.5`,
  `moonshotai/Kimi-K2-Instruct`, `moonshotai/Kimi-VL-A3B-Thinking-2506` and older repos —
  **no K3.1 Pro entry**. Recent-activity entries are all K3 edits.

This matches the vendor's own statement that "the full model weights will be released by
Nov 4" (see the [tech blog](../../kimi.ai/kimi-k3-1-pro-tech-blog/2026-10-26.md) and the
[model guide](../../kimi.ai/kimi-k3-1-pro-quickstart/2026-10-26.md)). At capture the
open-weight claim is a promise with a date, not a downloadable artefact.

## Kimi K3, for contrast (predecessor card, same capture)

The `moonshotai/Kimi-K3` card declares:

- `license:other`, with a `LICENSE` file at the repository root (the "Kimi K3 License" —
  captured separately in
  [kimi-k3-license](../../huggingface.co/kimi-k3-license/2026-10-26.md)).
- Safetensors totals: `BF16` 57,179,884,544 + `U8` 2,722,740,830,208 + `F32` 11,122,432
  parameters, i.e. ≈2.78T total — the source of the vendor's "2.8 trillion parameters".
- Tags include `image-text-to-text`, `compressed-tensors`, `8-bit`, `custom_code`
  (`modeling_kimi_k3.KimiK3ForConditionalGeneration`).

So the predecessor is downloadable at ~2.8T parameters in 8-bit compressed form. K3.1 Pro's
parameter count and quantisation are not published on any captured page.

## Summary

At 2026-10-26 there are **no K3.1 Pro weights to licence**. The licence question is therefore
open, not merely unread: the vendor has committed to open weights but has not published the
weights or their licence text. The K3 licence is the only first-party indication of what an
open Kimi licence looks like, and it is not evidence about K3.1 Pro's terms.

## Gaps

- The 401 could hide a gated repository that exists but requires authentication; an
  unauthenticated capture cannot tell "gated" from "absent".
- No attempt was made to authenticate, and no organisation-level "coming soon" notice was
  found.
- No parameter count, quantisation scheme, or context/tokenizer details for K3.1 Pro.

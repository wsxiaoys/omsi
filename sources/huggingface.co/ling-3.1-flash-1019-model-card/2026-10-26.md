## Introduction, verbatim

> We introduce **Ling-3.1-flash-1019**, an upgraded version of [Ling-3.1-flash](https://huggingface.co/inclusionAI/Ling-3.1-flash), with **560B** total parameters, **25B** active parameters per token, and a **1M-token context window**. With further post-training optimizations, **Ling-3.1-flash-1019** demonstrates significant improvements in reasoning and real-world agentic capabilities. Its **AA-Briefcase** score rises from approximately 1400 to **1524 Elo**, while performance on **AutomationBench-AA** increases from 62% to **68%**. The model also makes gains on scientific benchmarks, including **CritPt** (18% → **26%**) and **SciCode** (54% → **57%**). Overall, it scores **44** on the **Artificial Analysis Intelligence Index v4.3.2**, up from 41 for its predecessor.

So the card describes the change as **"further post-training optimizations"** — no architecture,
parameter or context change. The architecture table is byte-for-byte the same as the parent
card's (Hybrid-linear MoE, 63 KDA + 9 Gated MLA, 512 routed experts, 8 activated + 1 shared,
hidden 4096, vocab 157184).

## Provenance of those numbers

Every figure in that paragraph is an **Artificial Analysis measurement restated**, not a
vendor-run evaluation. The independent capture matches each one:

| Claim in card | Artificial Analysis | Card vs AA |
| --- | --- | --- |
| AA-Briefcase "~1400 → 1524 Elo" | 1397.34 → 1520.99 Elo | card rounds both |
| AutomationBench-AA "62% → 68%" | 61.74% → 67.55% | card rounds both |
| CritPt "18% → 26%" | 0.18 → 0.26 | exact |
| SciCode "54% → 57%" | 54.05% → 56.83% | card rounds both |
| AA Index "41 → 44" | 41.09 → 43.90 | card rounds both |

Source: [AA, Ling 3.1 Flash](../../artificialanalysis.ai/ling-3.1-flash/2026-10-26.md) and
[AA, Ling 3.1 Flash 1019](../../artificialanalysis.ai/ling-3.1-flash-1019/2026-10-26.md).

This cuts two ways and both matter. The claims are **not invented** — they trace to an
independent evaluator that measured both checkpoints. But they are also **not a second
measurement**: the vendor is quoting the same run the reader can already see, and no source
independent of Artificial Analysis has measured this checkpoint.

## What the card does not say

- **No release date.** The `1019` suffix reads as 19 October, and AA dates the release
  2026-10-22; neither the card nor any other first-party page states a date.
- **No mention in any other first-party document.** The docs model page, the docs pricing page,
  the docs changelog and the deprecation page all name only `Ling-3.1-flash`
  ([docs](../../ant-ling.com/ling-model-docs/2026-10-26.md),
  [pricing](../../ant-ling.com/pricing/2026-10-26.md)). No blog post covers a `1019` release.
- **No separate pricing, SKU or support window.** There is no first-party statement that `1019`
  is a distinct product rather than the current build of one SKU.
- **No benchmark outside AA's index composition**, and no scores for the vendor's own headline
  names (GDPVal-AA V2.1, HealthBench Professional, FrontierSWE) as vendor runs.

## Summary

`1019` is a post-training refresh of Ling-3.1-flash with unchanged architecture, unchanged
context claim, MIT weights, fp8, published on Hugging Face after the nominal capture date of this
batch. Its only evidence is (a) this card, which restates Artificial Analysis's numbers, and
(b) Artificial Analysis itself, which measured both checkpoints separately through InclusionAI's
first-party API. No host lists a `1019` SKU.

## Gaps

- No independent-of-AA measurement of the checkpoint.
- No host listing, so this page cannot supply an independent host record for a standalone model
  page (see the wiki page's split analysis).
- No first-party date, changelog entry, pricing line or support statement.
- Whether the vendor API's single `Ling-3.1-flash` SKU now serves these weights is not stated
  anywhere; AA's measurement basis implies it did at measurement time, which is inference, not
  documentation.
- The 350M-token verbosity and $1.49 cost per index task reported by AA

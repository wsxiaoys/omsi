## Summary

The weights exist and are downloadable, under **CC BY-NC-SA 4.0** (non-commercial), for four
variants: 14B causal-fast (plus a `-diffusers` conversion), 14B causal-pretrain, 14B bidirectional,
and 1.3B causal-fast. Repository creation dates (2026-07-08, 2026-09-04) corroborate the two release
waves announced in the main repository, with the second wave's Hugging Face repositories created six
days before the 2026-09-10 announcement.

Download counters are near zero on four of five repositories while likes are non-zero (124 on the 14B
causal-fast), and the `-diffusers` conversion carries the only meaningful download count (130). The
counters are therefore not usable as adoption evidence either way.

## Gaps

- No card content on training data, architecture, compute, or evaluation; the four cards are copies of
  the repository summary.
- No file inventory captured (no size, precision, or safetensors metadata), so the "14B" and "1.3B"
  figures are the vendor's labels only.
- The main repository README states the 1.3B package "currently contains the DiT weights only" and
  that T5, VAE and the tokenizer must be borrowed from the 14B release; the card does not repeat that
  caveat, and whether it still holds for the 2026-09-04 upload is not stated anywhere.
- Download counts are inconsistent with the like counts and with the `-diffusers` repository; treat
  them as unreliable.

# Hugging Face: MiniMaxAI organisation model list — no Music 2.6 weights

- Origin: Hugging Face, MiniMaxAI organisation model listing,
  `GET https://huggingface.co/api/models?author=MiniMaxAI&limit=100`, plus the model pages
  <https://huggingface.co/MiniMaxAI/MiniMax-Music3> and
  <https://huggingface.co/MiniMaxAI/MiniMax-Music2.6>
- Evidence kind: provider catalogue (negative evidence on weight availability)
- Publication date: `MiniMaxAI/MiniMax-Music3` `createdAt` 2026-08-07T12:23:29Z. Capture date
  2026-10-26
- Capture date: 2026-10-26
- Relevant models: MiniMax Music 2.6, MiniMax Music 3

## Observation

The organisation API returns 22 public repositories. The only music repository is:

```json
{"id": "MiniMaxAI/MiniMax-Music3", "createdAt": "2026-08-07T12:23:29.000Z",
 "downloads": 5754, "likes": 1478,
 "tags": ["diffusers", "safetensors", "minimax_music3", "music-generation", "text-to-music",
          "pytorch", "sglang-omni", "text-to-audio"]}
```

There is **no** Music 1.5, 2.0, 2.5 or 2.6 repository in the public listing. A search for
`music` within the organisation returns only `MiniMaxAI/MiniMax-Music3`.

Method note: `https://huggingface.co/MiniMaxAI/MiniMax-Music2.6` answers **HTTP 401**, but so does a
deliberately bogus name (`MiniMaxAI/bogus-nonexistent-xyz`), so the 401 is Hugging Face's generic
response for unlisted repos and is **not** evidence of a private or gated Music 2.6 repository. The
organisation API listing is the reliable signal.

## What this establishes

- MiniMax did not publish Music 2.6 weights. The first open-weights music release is Music 3
  (2026-08-07 repository creation, matching the vendor's Music 3.0 announcement).
- Music 2.6 is therefore a **hosted-only, closed model**: first-party API (retired) plus third-party
  hosts, with nothing to self-host and no weights licence to check.
- The vendor's own music-generation guide points users wanting to run music generation themselves at
  `MiniMaxAI/MiniMax-Music3`, not at 2.6 (`../minimax.io/music-generation-guide/2026-10-26.md`).

## Gaps

- The listing does not say whether a Music 2.6 checkpoint exists privately.

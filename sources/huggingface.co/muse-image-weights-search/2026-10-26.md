# Hugging Face: search for Muse Image weights (no repository found)

- **Origin:** Hugging Face Hub API searches:
  - `GET https://huggingface.co/api/models?search=muse-image&limit=50`
  - `GET https://huggingface.co/api/models?search=muse%20image&limit=50`
  - `GET https://huggingface.co/api/models?author=meta-models&limit=100`
- **Evidence kind:** model-hub search (record of absence of published weights, not of a model).
- **Publication date:** not applicable; searches run on the capture date.
- **Capture date:** 2026-10-26.
- **Relevant models:** Meta Muse Image (`muse-image-1.0`).
- **Capture type:** JSON search results, transcribed.

## What was searched and what came back

`search=muse-image` and `search=muse image` both returned the same ten unrelated repositories:
`valhalla/test-muse-imagenet`, `valhalla/muse-imagenet-mr`, `valhalla/muse-imagenet-mr-2`, and seven
`gianma/museums3k_*` feature-extraction repositories. No repository from Meta or Meta
Superintelligence Labs appears.

`author=meta-models` (Meta's official model organisation) returns six repositories, all text models:

- `meta-models/Muse-Spark-Open-816B-A42B`
- `meta-models/Muse-Spark-Open-816B-A42B-NVFP4`
- `meta-models/Muse-Glimmer-30B`
- `meta-models/Muse-Glimmer-30B-GGUF`
- `meta-models/Muse-Glimmer-30B-assistant`
- `meta-models/Muse-Glimmer-30B-ExecuTorch-PTE`

No image model, and no repository whose name contains "image".

## What this establishes

No Muse Image weights are published on Hugging Face under Meta's organisation as of 2026-10-26,
consistent with Meta's own docs, which list Muse Image as a hosted model on Meta Model API and
describe only Muse Spark Open, Muse Glimmer and SAM 3.1 as open-weight
([Meta models doc](../../meta.com/muse-image-models-and-pricing/2026-10-26.md)), and with
Artificial Analysis recording `openWeightsUrl: null`
([AA](../../artificialanalysis.ai/muse-image/2026-10-26.md)). Muse Image should be treated as
**closed-weight, API-only**.

This is evidence of a failed search, not proof that no checkpoint exists privately or under a
non-obvious name.

## Gaps

- The Hub search is name-based; a Meta image checkpoint published under an unrelated repository name
  would not be found this way. The `author=meta-models` enumeration is the stronger check, and it
  covers only Meta's public organisation, not other Meta accounts.
- No licence file was inspected, because no candidate repository exists to inspect.

## Bolt 74B-A9B (24GB)

| Field | Value |
| --- | --- |
| Total / active parameters | 74B / 9B |
| Architecture | "Mamba-2–Transformer hybrid LatentMoE with a C-RADIO v4-H vision encoder" |
| Context length | "Up to 256K tokens" |
| Inputs / outputs | "Text, images, and video / text" |
| Deployment | "vLLM on NVIDIA Ampere (A100), Hopper (H100-80GB), or Blackwell" |
| Speculative decoding | "LiLiCorr drafter via DFlash; 7 speculative tokens in the supplied vLLM recipes" |
| Reasoning mode | `enable_thinking=True/False`, "inherited from the Super 3.5 VL client" |
| Licence | OpenMDW-1.1 |
| HF `pipeline_tag` | `image-text-to-text` |

The card describes it as intended for "Customization, post-training, and producing quantized
variants for local agentic tasks". The newsroom post gives the mechanism for the 24GB target:
"using a native 2-bit quantization to fit in 24GB of memory". The card's own description is
explicit about the modality: "NVIDIA Nemotron 3.5 Bolt 74B-A9B is a vision-language model (VLM)
designed to run everyday agentic tasks locally."

The IQ2 build loses little: 2.2 points on GPQA Diamond and 2.9 on HLE against BF16, and it
still beats both listed baselines on every benchmark except AA-Omniscience accuracy and
non-hallucination. That is the interesting property of Bolt 74B — the 24GB quantized variant
is close enough to BF16 to be the practical deployment target.

Two things are worth flagging. First, Bolt 74B-A9B is **multimodal** (C-RADIO v4-H encoder,
`image-text-to-text`), which contradicts the impression that Bolt is a text edge model. Second,
the card states the reasoning-mode plumbing was "inherited from the Super 3.5 VL client", i.e.
Bolt reuses Super VL's chat-template contract.

## Bolt E4B 4GB

| Field | Value |
| --- | --- |
| Total / active parameters | "8B (4B effective)" |
| Architecture | **"Gemma-4-E4B"** |
| Context length | "Input: up to 64K tokens; output: up to 64K tokens" |
| Base model | `google/gemma-4-E4B-it` (HF `base_model` metadata) |
| Inputs / outputs | Text / text |
| Deployment | vLLM |
| Reasoning mode | chat-template `enable_thinking` plus "runtime thinking budget" |
| Extra mode | `conversational_mode=True/False` |
| Licence | OpenMDW-1.1 |
| HF `pipeline_tag` | `text-generation` |

This is the outlier in the generation. The card's description states it plainly:

> "**NVIDIA-Nemotron-3.5-Bolt-E4B-BF16** is a small language model (SLM) further post-trained
> from [Gemma-4-E4B-it](https://huggingface.co/google/gemma-4-E4B-it) by NVIDIA."

The licence section adds: "This model has been post-trained on the Google Gemma 4 model, and
use of the Google Gemma 4 model is governed by Apache License, Version 2.0" — so two licences
apply: OpenMDW-1.1 to NVIDIA's derivative (captured at
[OpenMDW-1.1](../../openmdw.ai/openmdw-1-1-license/2026-10-26.md)) and Apache-2.0 upstream.
The `language:` list is much wider than the other 3.5 cards (en, ar, bg, cs, da, de, el, es,
…), and the vLLM recipes use `--tool-call-parser gemma4 --reasoning-parser gemma4`. Whatever
"Nemotron 3.5 Bolt E4B" is, it is not a Nemotron-architecture model. That is the strongest
single argument against treating "Nemotron 3.5" as one entity.

The card benchmarks it against Gemma4-E4B-it, Qwen3.5-4B and Nemotron-3-Nano-4B across 21
tasks (MultiChallenge, RoleBench, BFCL-v3, ToolSandbox, Tau2-Bench, IFBench, RULER 64K,
LongMemEval, RAGTruth and others). It beats Gemma4-E4B-it on 19 of 21 and loses on EQ-Bench v3
(39.40 vs 41.17). Qwen3.5-4B still wins Tau2-Bench (75.06 vs 55.10) and RULER 64K (95.15 vs
86.99).

## Summary

The two Bolt cards establish a third and fourth distinct checkpoint inside the 3.5 generation:
a 74B/9B-active multimodal local model with 256K context and a 24GB 2-bit target, and an
8B/4B-effective Gemma-4-E4B derivative with 64K context and a conversational mode. Both are
OpenMDW-1.1 and both are positioned for on-device agent work, not for hosted API traffic.

## Gaps

- Bolt 74B-A9B's card states no explicit release date beyond the Hugging Face line; the newsroom
  post's 2026-10-15 matches it.
- Both Bolt cards' benchmark numbers are NVIDIA-run on NeMo Gym; no independent re-run of the
  Bolt 74B table was found. AA has an Intelligence Index for 74B-A9B but none for E4B (see
  [AA](../../artificialanalysis.ai/nemotron-3-5-bolt/2026-10-26.md)).
- E4B's "4GB" figure refers to the Q4_K_M build (`NVIDIA-Nemotron-3.5-Bolt-E4B-4GB`); the BF16
  weights are 8B parameters and do not fit in 4GB. The cards never say this in one sentence.
- No per-token price: Bolt E4B is listed on build.nvidia.com, but that page is client-rendered
  and no rate could be captured. No hosted endpoint was found for Bolt 74B-A9B.

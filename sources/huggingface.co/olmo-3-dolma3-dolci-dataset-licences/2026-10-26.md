# Hugging Face datasets: Dolma 3 and Dolci licence metadata

- Origin: Hugging Face dataset repositories under `allenai`, queried through
  <https://huggingface.co/api/datasets?author=allenai&search=dolma3> and the equivalent `dolci` query
- Evidence kind: dataset repository metadata (developer-published licences)
- Publication date: none on the API; dataset repositories tagged `arxiv:2512.13961`. Capture date
  2026-10-26.
- Capture date: 2026-10-26
- Relevant models: Olmo 3 / Olmo 3.1 (the data these checkpoints were trained on)
- Capture type: licence tags from the dataset API responses

## Dolma 3 (pretraining, midtraining, long-context)

Every `dolma3_*` dataset repository returned by the query carries `license:odc-by`:

- `allenai/dolma3_mix-6T` and `allenai/dolma3_mix-6T-1025-7B` — pretraining mix
- `allenai/dolma3_dolmino_mix-100B-1025`, `-100B-1125`, `-10B-1025` — midtraining mixes
- `allenai/dolma3_longmino_mix-50B-1025`, `-100B-1125` — long-context mixes
- `allenai/dolma3_pool`, `allenai/dolma3_pool_staging`, `allenai/dolma3_dolmino_pool`,
  `allenai/dolma3_longmino_pool`, `allenai/dolma3.5_pool`
- All are tagged `language:en`, `modality:text`, `arxiv:2512.13961`

## Dolci (post-training)

Most Dolci repositories carry `license:odc-by`, including `allenai/Dolci-Instruct-SFT`,
`allenai/Dolci-Instruct-DPO`, `allenai/Dolci-Think-SFT-32B`, `allenai/Dolci-Think-DPO-32B`,
`allenai/Dolci-Think-DPO-7B`, `allenai/Dolci-RL-Zero-{Math|Code|IF|General}-7B`,
`allenai/Dolci-Instruct-SFT-No-Tools`, `allenai/Dolci-DPO-Model-Response-Pool`.

Two tool-use subsets carry a share-alike licence instead:

- `allenai/Dolci-Instruct-SFT-Tool-Use-SA` — `license:cc-by-sa-4.0`
- `allenai/Dolci-Think-SFT-Olmo-Hybrid-Tool-Use-SA` — `license:cc-by-sa-4.0`

Some repositories the model cards link to return no licence tag through this query
(`allenai/Dolci-Think-RL`, `allenai/Dolci-Instruct-RL`, `allenai/Dolci-Think-SFT-7B`,
`allenai/Dolci-Think-RL-7B`, `allenai/Dolci-RL-Zero-Mix-7B`) — absence of a tag is not absence of a
licence, but it is not evidence of one either.

## Summary

The "fully open" claim on the model cards extends to the data: the Dolma 3 mixes that trained the Olmo 3
32B base (and therefore 3.1) are published under **ODC-BY**, and the Dolci post-training corpora are
mostly ODC-BY with two tool-use subsets under **CC-BY-SA-4.0**. Weights are Apache 2.0 (see the model
card records), so 3.1 is reproducible and redistributable, with attribution obligations on the data and
share-alike obligations on two tool-use corpora.

## Gaps

- Licences were read from repository tags, not from the full licence texts; ODC-BY version and any
  dataset-specific carve-outs were not captured.
- The RL corpora actually used for the 3.1 runs (`Dolci-Instruct-RL`, `Dolci-Think-RL`) expose no licence
  tag through this query, so their terms are unresolved.
- The card text for the 3.1 Instruct checkpoint names the *Think* corpora in its training-stage section,
  which conflicts with the repository metadata; see the model-card record.

## Result

The `qwen-audio` search returns the pre-Qwen3 multimodal audio-understanding family
(`Qwen/Qwen-Audio`, `Qwen/Qwen-Audio-Chat`, `Qwen/Qwen2-Audio-7B-Instruct`) plus community quants and
fine-tunes of those. The `qwen-audio-3.1` search returns nothing. No repository, model card, config or
licence file exists for `qwen-audio-3.1-tts-plus`, and nothing under that name is published by the
Qwen organisation.

The Qwen organisation's speech-*generation* weights are the six `Qwen3-TTS-12Hz-*` repositories
(Apache-2.0), which are a different model family documented on
[`wiki/models/qwen3-tts.md`](../../../wiki/models/qwen3-tts.md).

## Summary

`qwen-audio-3.1-tts-plus` is a closed, hosted-only model. There are no weights to download, self-host,
inspect or licence-check, and no Apache-2.0 grant of the kind that covers Qwen3-TTS.

## Gaps

- Absence on the Hub is not a licence statement; the service terms that do govern the hosted API were
  not captured for this page.
- A gated or private repository would not appear in a public search.

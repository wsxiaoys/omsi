# Hugging Face Transformers documentation: SAM3 / SAM3 Video

- Origin: Hugging Face, Transformers docs, https://huggingface.co/docs/transformers/model_doc/sam3
  (and the sibling pages `sam3_video`, `sam3_litetext` linked from the same nav)
- Evidence kind: third-party integration documentation (library docs, contributed by Meta engineers)
- Publication date: page states "This model was contributed to Hugging Face Transformers on
  **2025-11-19**."
- Capture date: 2026-10-26
- Relevant models: SAM 3 (Transformers `Sam3Model`, `Sam3VideoModel`)

## Captured content (verbatim)

> SAM3 (Segment Anything Model 3) was introduced in SAM 3: Segment Anything with Concepts.
>
> SAM3 performs **Promptable Concept Segmentation (PCS)** on images. PCS takes text and/or image
> exemplars as input (e.g., "yellow school bus"), and predicts instance and semantic masks for
> **every single object** matching the concept.

> This model was contributed by yonigozlan and ronghanghu.

The page then reproduces the paper abstract and gives `Sam3Model` / `Sam3Processor` usage examples
under headings "Text-Only Prompts" and (via the sibling page) video.

Transformers model pages present three related entries: **SAM3**, **SAM3 Video**, and
**SAM3-LiteText**. The docs page for `Sam3Model` scopes itself to images; video is a separate
`Sam3VideoModel` page, which matches the Hub repo's `sam3_video` architecture tag.

## Use

This is a second, independent date anchor for the SAM 3 release (2025-11-19) and evidence that SAM 3
is integrated into the `transformers` library rather than being GitHub-only. It is Hugging Face's
documentation, written with Meta contributors, so it is treated as integration documentation rather
than as a vendor source of record.

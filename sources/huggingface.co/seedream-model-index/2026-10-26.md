# Hugging Face model index: no ByteDance Seedream repository

- Origin: Hugging Face model index API — `GET https://huggingface.co/api/models?search=seedream&limit=100`
  and `GET https://huggingface.co/api/models?author=ByteDance&limit=500`
- Evidence kind: provider documentation (host catalogue query; machine-readable, not prose)
- Publication date: n/a — live index. Capture date 2026-10-26.
- Relevant models: Seedream 5.0 Pro (and the Seedream family generally)
- Capture type: JSON query results, transcribed.

## Captured result

`?search=seedream` returned **3** models, none of them ByteDance's:

| Repo | Note |
| --- | --- |
| `ash12321/seedream-4.5-specialist-h100` | third-party, unofficial |
| `tm-hf-repo/seedream-pixar` | third-party, unofficial |
| `seedream55ai/seedream55ai-docs` | third-party, documentation-only repo |

`?author=ByteDance` returned **57** models. Filtering those IDs for "seed" yields **none** — the
ByteDance organization publishes no Seedream (or Seedance/Seed) weights repository.

## What this establishes

- **Seedream 5.0 Pro is not open-weights.** No official weights repository exists on the largest
  open-weights host as of the capture date, and no first-party page captured for this model links to
  one: the ByteDance Seed product page's `full_tech_report_src` field is empty, and the Ark/BytePlus
  documentation describes API access only.
- The three `search=seedream` hits are third-party uploads. They are not evidence of an official
  release and should not be cited as such.

## Known gaps

- This checks one host. Weights could be distributed elsewhere (ModelScope, a ByteDance CDN, a
  gated repo not indexed by the search endpoint), and this record does not rule that out.
- The search API is not an exhaustive index of gated or private repositories.
- No check was made for a ByteDance licence document covering Seedream output, so the licensing
  section of the model page remains partly unverified.

# Hugging Face — mistralai organization listing: no Voxtral Transcribe 3 weights

- Origin: Hugging Face Hub API, organization listing
  <https://huggingface.co/api/models?author=mistralai&limit=200>, plus a model-name search
  <https://huggingface.co/api/models?search=voxtral&limit=50>. Retrieved 2026-10-26.
- Evidence kind: developer's public weights host (catalogue read for what it does *not* contain).
- Publication date: not applicable (live API).
- Capture date: 2026-10-26
- Relevant models: Voxtral Small Transcribe 3, Voxtral Mini Transcribe 3, Voxtral Mini
  Transcribe Realtime 3 (all absent); Voxtral 2 generation (present).
- Capture type: JSON API response, summarised (the response lists 81 repositories in the
  `mistralai` org at capture).

## Captured content

The `mistralai` organization listing contained 81 repositories. Every Voxtral repository on it:

| Repository | Generation |
| --- | --- |
| `mistralai/Voxtral-4B-TTS-2603` | Voxtral 2 TTS |
| `mistralai/Voxtral-Mini-4B-Realtime-2602` | Voxtral 2 realtime |
| `mistralai/Voxtral-Mini-4B-Realtime-Arabic` | Voxtral 2 realtime (Arabic) |
| `mistralai/Voxtral-Small-24B-2507` | Voxtral 2 (2025-07-15) audio-LLM |
| `mistralai/Voxtral-Mini-3B-2507` | Voxtral 2 (2025-07-15) audio-LLM |

**No repository matches `voxtral-small-transcribe-3`, `voxtral-mini-transcribe-3` or
`voxtral-mini-transcribe-realtime-3`.** A name search for `voxtral` (50 results) returned the same
Voxtral 2 repositories plus community conversions and quantisations of them; nothing from the Voxtral
3 generation, and no third-party re-upload of a Transcribe 3 checkpoint.

## What this establishes

- The Voxtral 3 transcription models are **closed at capture**: no weights are published on Hugging
  Face under any name. This is a negative weights record, not a statement that weights will never
  appear.
- It contradicts, or at least does not support, the launch post's "Available today … or for
  self-deployment on your own infrastructure" claim for the transcription models
  (`../../mistral.ai/voxtral-3-launch/2026-10-26.md`). The 2025/2026 Voxtral 2 weights (Apache 2.0 for
  Realtime, per the Transcribe 2 post) are still the only ones available.
- Artificial Analysis independently records `openWeights: false` for both Voxtral 3 transcribe models
  (`../../artificialanalysis.ai/voxtral-transcribe-3/2026-10-26/index.md`).

## Gaps

- Only Hugging Face was checked. A self-deployment artefact could exist through a Mistral enterprise
  channel, a private registry or a licence agreement, none of which is publicly checkable.
- The API listing was read without authentication; gated or private repositories would not appear.

# Hugging Face: Wan 3.0 model card, and no Wan 3.0 weights from the official Wan-AI org

- Origin: Hugging Face Hub:
  - `GET https://huggingface.co/api/models/wanvideo/wan-3-0-video` and
    `https://huggingface.co/wanvideo/wan-3-0-video/raw/main/README.md`
  - `GET https://huggingface.co/api/models?author=Wan-AI&limit=100` (27 repositories)
- Evidence kind: model card (unofficial author) plus a catalogue listing of an official
  organisation — a record of what is and is not published as weights
- Publication date: `wanvideo/wan-3-0-video` created 2026-09-04T16:22:54Z, last modified
  2026-09-04T16:41:43Z
- Capture date: 2026-10-26
- Relevant models: Wan 3.0 / `wan3.0-video` / `wan3.0-video-prime`

## No downloadable checkpoint exists for Wan 3.0

`GET https://huggingface.co/api/models?author=Wan-AI` returns **27 repositories**, the newest being
`Wan-AI/Wan2.2-Animate-2-14B-Distilled-Diffusers` (2026-08-06) and `Wan-AI/Wan-Dancer-14B`
(2026-07-10). The list stops at the Wan 2.2 generation: there is **no `Wan-AI/Wan3*` or
`Wan-AI/Wan3.0*` repository**, open or gated, as of 2026-10-26.

That is consistent with the rest of the corpus: every Wan 3.0 route captured is a hosted API
(Alibaba Cloud Model Studio first-party; fal with `hostingType: "proxy"`), and no vendor page mentions
a weights release, licence, or repository. Treat Wan 3.0 and Wan 3.0 Prime as **closed-weight,
hosted-only** models.

## The one Wan 3.0 Hugging Face repository carries no files

`wanvideo/wan-3-0-video` is the only Wan 3.0 repository the search API returns. Its metadata:

- `author: "wanvideo"` — not `Wan-AI`, the organisation that publishes Wan's open weights
- `siblings: [".gitattributes", "README.md"]` — two files, no weights, no configs
- `usedStorage: 0`, `downloads: 0`, `likes: 27`, `gated: false`

So it is a **model card without a model**. Its README is a launch-style post describing Wan 3.0's
positioning. Verbatim, on the two variants:

> Wan 3.0 is the new-generation reference-video model in the Wan video family. wan3.0-video provides
> standard generation, while wan3.0-video-prime significantly improves end-to-end speed with the same
> core capability set.

> Wan 3.0 generates 2–30 second video in a single run and includes smart duration and video extension.
> Output is 30fps MP4 at 480P, 720P, or 1080P with adaptive, 16:9, 4:3, 1:1, 3:4, and 9:16 aspect
> ratios.

> A task can contain up to 20 multimodal reference assets, including as many as 10 images, five
> reference videos, and five reference-audio clips.

Those three statements agree with the first-party Alibaba Cloud documentation. Two other statements in
the same card are **not** corroborated by any Alibaba page captured:

> Wan 3.0 Standard, Video Prime, and the very-low-cost Draft Mode are available to access and explore
> through [wan30.io](https://wan30.io/).

> Audio texture and on-screen text accuracy remain areas for continued improvement. Content involving
> complex physical interaction, dense readable text, real people, or protected source material should
> retain human review and rights verification.

- **"Draft Mode"** appears nowhere in Model Studio's Wan 3.0 documentation. The vendor's price list
  gives exactly two model IDs, `wan3.0-video` and `wan3.0-video-prime`, and the API reference accepts
  only those two values for `model`, and the word "draft" appears nowhere in the captured Model Studio
  Wan 3.0 price list, API reference or guide.
- **`wan30.io`** is a third-party site, not an Alibaba domain, and is not linked from any vendor page
  captured. It was not treated as a host record.
- The **self-criticism** ("audio texture and on-screen text accuracy remain areas for continued
  improvement") has no counterpart on any Alibaba page. It reads like the vendor's own gap list, but
  the publishing account is unverified, so it is recorded as an unsigned claim rather than a vendor
  admission.

## Gaps

- The identity behind the `wanvideo` Hugging Face account was not established. It may be an official
  side account, a partner, or a third party; the API exposes no verification field, and the profile
  page was not captured.
- The card is undated apart from Hub timestamps; it states no release date for either variant.
- Absence of a `Wan-AI/Wan3*` repository is evidence about Hugging Face only. A weights release
  hosted elsewhere (ModelScope, GitHub) was not searched.

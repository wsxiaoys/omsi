## A search hit that is not vendor evidence

`GET /api/models?search=wan3` returns ten repositories. None is owned by `Wan-AI`. Two are named
`wan-3-0-video`:

- `wanvideo/wan-3-0-video` — created 2026-09-04, 0 downloads, two files (`.gitattributes` and a 4.4 KB
  `README.md`), no licence tag. The README is launch-article prose ("Wan 3.0 has launched with a focus
  on realistic human rendering…") and ends by pointing readers at `https://wan30.io/`, a third-party
  site, claiming "Wan 3.0 Standard, Video Prime, and the very-low-cost Draft Mode are available to
  access and explore through wan30.io". It contains **no weights, no config, no model card metadata**.
- `calamansi/wan-3-0-video` — created 2026-10-10, same pattern.
- Others (`Mohammedf3/Wan3`, `Danielbsittler/wan3`, `intchous/wan3`, `yasserrajeb/wan-3-0-video`,
  `emilyjohnson2610/wan3-ai-video-notes`, `hotel-lobby-video-ai/hotel-lobby-ai-wan30-video-generator`)
  are unrelated user repositories or SEO-style pages.

These are third-party reposts, not vendor model cards. In particular the "Draft Mode" claim on
`wanvideo/wan-3-0-video` appears in no Alibaba Cloud document captured for this page, so it is recorded
here as an unverified third-party claim and is not used on the model page.

## Summary

Alibaba's own Hugging Face organisation publishes open weights up to Wan 2.2 under Apache-2.0 and has
published nothing for Wan 2.5, 2.6, 2.7 or 3.0. Wan 3.0 has no public checkpoint on Hugging Face at
capture. Any "Wan 3.0" Hugging Face repository is a third-party repost.

## Gaps

- This is an absence of evidence on one host; it does not prove Alibaba will never publish weights.
  ModelScope was not successfully queried (its search endpoint returned 404 for this capture).
- The organisation index was read through the API only; individual Wan 2.2 model cards were not opened
  for this page, so the Apache-2.0 attribution comes from the API's `license:` tag, not the card text.

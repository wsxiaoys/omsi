# Hyper3D: homepage / Rodin workspace marketing surface

- Origin: Hyper3D (Deemos), <https://hyper3d.ai/> (the `/rodin` path redirects here).
- Evidence kind: official vendor product page (marketing copy plus an embedded UI mock of the
  generation panel).
- Publication date: undated live page.
- Capture date: 2026-10-26.
- Relevant models: Rodin Gen-2.5 (named in the embedded generator panel).
- Capture type: page text transcribed; quoted text verbatim.

## Content

> "Meet Hyper3D, the world's highest-quality, most controllable AI 3D model generator. Turn text
> prompts or images into detailed 3D assets in seconds — no 3D experience required."

The embedded generator panel names the model and its effort ladder with approximate times:

| Thinking Effort | Approx. time |
| --- | --- |
| Extreme-Low | ~4s |
| Low | ~9s |
| Medium | ~20s |
| High | ~40s |
| Extreme-High | ~80s |

Other labelled features: "Bounding Box ControlNet", "Voxel ControlNet", "PointCloud ControlNet",
"Image to 3D", "Text to Image/3D", "Remix Gen", "Turbo Gen", "3D Editing" ("Supports .obj .fbx .glb",
"Parts", "Refine", "Modify"), "Free Retry" (V1–V4, "x50"), "Smart Low-Poly", "BANG" partial edit
("Edit selected regions of a 3D asset without rebuilding the model").

> "Rodin generates high-quality assets with ready-to-use UVs; advanced spatial controls are available
> when desired."

> "Rodin delivers high reference fidelity, strong silhouette and proportion preservation, and coherent
> detail across views."

Add-ons listed: native Blender/Unity/Unreal/Godot/Maya/3ds Max/ComfyUI plugins; enterprise SSO (SAML
2.0), team management, shared asset workspace, audit logs.

## What this establishes

- The **consumer-visible effort ladder is a time/quality trade with a 20× span** (~4 s to ~80 s), which
  is the vendor's own admission that "seconds" means the bottom rung. It maps to the API's
  `tier=Gen-2.5-*` values.
- ControlNet-style spatial conditioning (bounding box, voxel, point cloud) is advertised as a Rodin
  capability; only the bounding box is exposed in the public API (`bbox_condition`). Voxel and point
  cloud are workspace features without a documented API field.
- UVs are claimed as part of the generated asset ("ready-to-use UVs"), which the API reference does not
  mention.

## Gaps

- No release date for Gen-2.5 anywhere on the page.
- The ControlNet claims are shown as UI panels with no API mapping documented.
- "x50" free retries is unexplained (per task? per day? plan-gated?).

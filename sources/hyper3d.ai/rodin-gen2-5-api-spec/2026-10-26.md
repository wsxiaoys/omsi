  `docs.hyper3d.ai`; `developer.hyper3d.ai` redirects there).
- Evidence kind: official documentation (vendor API reference).
- Publication date: the page carries no date. Hyper3D's API changelog lists "New docs: New Rodin

  when this tier set was documented.
- Capture date: 2026-10-26.
- Relevant models: Rodin Gen-2.5 (`tier=Gen-2.5-*`) on `POST https://api.hyper3d.com/api/v2/rodin`.
- Capture type: page text transcribed; parameter descriptions quoted verbatim.

## Endpoint and workflow

`POST /api/v2/rodin`, `multipart/form-data`, bearer auth. Generation is asynchronous: submit, poll
`Check Status` with `jobs.subscription_key`, then `Download Results` with the top-level `uuid`.

The vendor states that HTTP 201 does not mean success: "This is returned in the response body
alongside HTTP 201, so clients must check this field rather than relying on the HTTP status alone."
Error codes include `API_NO_ACTIVE_SUBSCRIPTION`, `API_SUBSCRIPTION_PLAN_TOO_LOW`,
`API_PARALLELISM_LIMIT_REACHED`, `API_INSUFFICIENT_FUNDS`, `IMAGE_CONTENT_VIOLATION`.

## Tiers

| Tier | Vendor's stated intended use |
| --- | --- |
| `Gen-2.5-Extreme-Low` | "Quick generation of simple assets." |
| `Gen-2.5-Low` | "Clean assets and small hard-surface props." |
| `Gen-2.5-Medium` | "Balanced structure and detail." |
| `Gen-2.5-High` | "Richer structure and smoother surfaces." |
| `Gen-2.5-Extreme-High` | "High-frequency detail reproduction." "This tier also returns an additional mesh with up to 10M of faces." |

"`tier` selects the generation family and how much detail the model resolves. It is independent of the
mesh and texture controls below: any tier can be combined with any `mesh_mode`, `quality`, or
`texture_mode` the schema allows."

`geometry_instruct_mode=creative` "is available for Gen-2.5-Medium and higher tiers."

**Fast mode** is automatic, not a parameter: it "is triggered" when `tier` is not
`Gen-2.5-Extreme-High`, `geometry_file_format` is `glb`/`fbx`/`usdz`, `mesh_mode` is `Raw`, and
`quality_override <= 20000`.

## Texture resolution

"jointly determined by `texture_mode`, `uhd_texture`, and `addons`":

| `texture_mode` | addons | `uhd_texture` | resolution |
| --- | --- | --- | --- |
| extreme-low, low, medium, high | `[]` | false | 2K |
| extreme-low, low, medium, high | `[]` | true | 4K |
| extreme-low, low, medium, high | HighPack | false | 4K |
| extreme-low, low, medium, high | HighPack | true | 8K |
| extreme-high | `[]` | false | 6K |
| extreme-high | `[]` | true | 6K |
| extreme-high | HighPack | false | 12K |
| extreme-high | HighPack | true | 12K |

| `tier=Gen-2.5-Extreme-High` | +0.5 credits |

"Charges are additive. Base generation costs only 0.5 credits, and parameters not listed above do not
incur additional charges." The page does not price `HighPack` or the rigging endpoint here, and the

independently of this documentation."

## Gaps

- No release date, no version number, no statement of which base model or training data.
- `HighPack` has no credit price on this page.
- No documented queue time, throughput, or maximum concurrent task count (only the error code for
  exceeding it).
- Nothing about output scale/units, UV layout guarantees, or watertightness in the API reference.
- The page does not say whether `seed` gives bit-identical reproducibility.

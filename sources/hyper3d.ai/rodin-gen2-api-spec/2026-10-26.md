# Hyper3D Docs: Rodin Gen-2 API specification (contrast record)

- Origin: Hyper3D (Deemos) API documentation, "Rodin Gen-2",
  <https://docs.hyper3d.ai/en/api-specification/rodin-gen2>.
- Evidence kind: official documentation (vendor API reference).
- Publication date: undated page; the API changelog records "New docs: New Rodin Gen-2 API
  documentation" under **September 2025**.
- Capture date: 2026-10-26.
- Relevant models: Rodin Gen-2 (`tier=Gen-2`), and by contrast Rodin Gen-2.5 and Rodin Gen-1/1.5.
- Capture type: page text transcribed; parameter descriptions quoted verbatim.

## Endpoint

Same endpoint as every other generation family: `POST https://api.hyper3d.com/api/v2/rodin`, with
`tier` required.

> "Required. Set this field explicitly to `Gen-2`. If omitted, the endpoint falls back to `Regular` and
> generates a Gen-1/1.5 asset."

## Differences from Gen-2.5 documented on this page

| Aspect | Gen-2 | Gen-2.5 (per its own page) |
| --- | --- | --- |
| `tier` values | one value, `Gen-2` | five: `Gen-2.5-Extreme-Low` … `Gen-2.5-Extreme-High` |
| `mesh_mode` default | `Quad` | `Raw` |
| `quality` face counts (`Raw`) | high 500000, medium 150000, low 20000, extra-low 2000 | high 1000000, medium 500000, low 60000, extra-low 20000 |
| `quality_override` | "from 500 to 1000000 for Gen-2… `Quad` mode has an additional maximum of 200000; `Raw` mode supports up to 1000000." | 500–2000000, with 2000000 only on High/Extreme-High |
| `texture_mode`, `is_micro`, `uhd_texture`, `geometry_instruct_mode`, `image_label`, `texture_delight`, `preview_render` | absent from the field list | present |
| `hd_texture`, `soft`, `detail_level`, `is_symmetric`, `quad_normal`, `TAPose`, `use_original_alpha`, `bbox_condition`, `addons` | present | present |
| Credit price | "Base Gen-2 generation 0.5 credits", no add-ons listed | 0.5 base, +0.5 Extreme-High, +2.0 extreme-high texture |

Shared vocabulary: `material` has the same five values (`PBR`, `Shaded`, `All`, `Hybrid`, `None`) with
`PBR` default; `geometry_file_format` supports the same five formats (`glb`, `usdz`, `fbx`, `obj`,
`stl`) with `glb` default; `images` is 1–5 files; `prompt` is ≤ 1024 characters; `seed` is 0–65535;
`HighPack` "upgrades pack textures from 2K to 4K. For Gen-2 it does not change geometry or generate an
additional high-poly model."

## What this establishes

- **Gen-2 and Gen-2.5 are one endpoint with one parameter surface, differentiated by the `tier`
  string.** There is no separate model ID, host slug or versioned endpoint on the vendor side.
- The capability gap is real and specific: Gen-2.5 adds quality tiers, a texture-quality axis up to
  12K, a higher face-count ceiling, micro-detail, and two generation-behaviour switches
  (`geometry_instruct_mode`, `is_symmetric`). Gen-2 has none of the tier or texture-mode machinery.
- Both are billed from the same 0.5-credit base, so the tier string is the only price lever.

## Gaps

- No date for Gen-2's own launch; only the September 2025 documentation entry.
- The page never says what Gen-2.5 changed in the underlying model, only in the API.
- Neither page states a deprecation or support window for Gen-2.

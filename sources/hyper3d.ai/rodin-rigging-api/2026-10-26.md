# Hyper3D Docs: Rigging API

- Origin: Hyper3D (Deemos) API documentation, "Rigging",
  <https://docs.hyper3d.ai/en/api-specification/rigging>.
- Evidence kind: official documentation (vendor API reference).
- Publication date: undated page; the API changelog lists "New Docs: New Rigging API
  documentation" under **October 2026**.
- Capture date: 2026-10-26.
- Relevant models: any Rodin asset (`asset_id`) or uploaded mesh, including Rodin Gen-2.5 output.
- Capture type: page text transcribed; descriptions quoted verbatim.

## Endpoint

`POST /api/v2/rigging`, `multipart/form-data`, bearer auth, asynchronous like the generation endpoint.
`asset_id` (a confirmed Rodin model UUID) and `model` (an uploaded file) are mutually exclusive.

Accepted upload formats (verbatim): "`obj`, `glb`, `stl`, `fbx`, `usd`, `usda`, `usdz`, and `usdc`.
Embedded materials and textures are not preserved."

## Skeleton control

`bone_template` (required):

> "Generate presets: `human`, `quadruped`, `human_UE`, `human_Unity`, `human_ActorCore`, `bird`,
> `dragon`, and `kaiju`… Generate `custom`: provide exactly one of `hierarchy` or
> `skeleton_description`."

`rigging_mode`: `generate` (default) or `modify`. `modify` "accepts the selected template and requires
`skeleton_description` containing the complete baseline skeleton and requested changes".

`skinning_method`: `shell` — "Surface-prioritized and more general-purpose, producing smoother weight
distributions on the visible outer mesh"; `core` — "Structure-prioritized and specifically optimized for
humanoid characters".

`hierarchy`: a flat node list of 1–256 entries, JSON-encoded, only with `bone_template=custom`.

## Animations

Optional, up to 10 inputs total: `animation_preset` (stock IDs) or `animation_files` (FBX, ≤ 25 MiB
each, "exactly one animation clip (Take)" per file). "Omit both fields to export without animations."

## Output and pricing

`geometry_file_format`: `glb` (default), `fbx`, `usdz`. `material`: `PBR` (default for textured
assets), `Shaded`, `All`, `Hybrid`, `None`; non-`None` "require confirmed textures for `asset_id`, or an
`image` to generate textures for `model`".

> "Base Rigging generation: 0.5 credits"

"Credits reserved at submission. Charged on successful packaging; released on failure or cancellation."

## What this establishes

- **Rigging is a separate, post-generation endpoint, not a property of the 3D generator.** Rodin Gen-2.5
  itself emits an unrigged mesh; a skeleton and skin weights come from a second call at a second price.
- The rigging surface is unusually specific for a hosted 3D model: engine-specific humanoid templates
  (Unreal, Unity, ActorCore), creature templates, custom hierarchies, and clip playback.
- It is the newest documented capability in the family (October 2026), i.e. newer than Gen-2.5 itself.

## Gaps

- No statement of which templates exist as stock `animation_preset` IDs, or how many.
- No quality claims, no weight-painting metrics, no claim about deform quality on Gen-2.5's dense
  triangle output.
- No limit on input mesh size or face count.
- Whether `modify` preserves existing user edits is not described.

## Summary

The vendor's own product page treats **Granite 4.2 as the current Granite language family**
(the page's only language-model content is the 4.2 table), confirms Apache 2.0 and names the
distribution channels including watsonx.ai, OpenRouter and Replicate. It carries no release
date, no context-window figure, no parameter counts and no pricing.

## Gaps

- No release date, parameter counts, context window, pricing or model-ID list on this page.
- The τ³-bench row here (66.34 / 68.05 / 68.05) disagrees with the Granite 4.2 technical
  blog and the model cards (45.78 / 58.06 / 62.00). See
  `sources/huggingface.co/granite-4-2-technical-blog/2026-10-26.md`.
- `watsonx.ai` is linked as a route but the watsonx documentation pages that would give
  model IDs and prices returned HTTP 403 to an unauthenticated fetch on capture date.

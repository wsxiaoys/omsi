## Captured content

### Positioning (verbatim)

> **Ideogram 4.5: The most precise edit model.**
>
> With each edit, leading image models introduce artifacts, pixel shifts, and color changes.
> Ideogram 4.5 eliminates artifact buildup, making multi-turn editing possible. Live in the
> Ideogram App, MCP, and the API in four quality modes at native 2K resolution.

Page `<meta name="description">`: "Ideogram 4.5 edits images without artifact buildup, so details
hold across multi-turn edits. Use it in the Ideogram app, MCP, or the image editing API at
native 2K."

### Vendor comparison against other models (verbatim)

> Here's a side-by-side comparison of the same edits on Ideogram 4.5 vs. GPT Image 2.5 Sunburst,
> Nano Banana Pro, and Nano Banana 2. GPT Image and Nano Banana outputs become unusable within a
> few edits, while Ideogram 4.5 stays clean edit after edit.

No methodology, sample size, prompt list, or rater protocol is published for this comparison.

### Endpoints (verbatim)

> Ideogram 4.5 is available through two endpoints. `POST /v2/image/generate/ideogram-4-5` […]
> Generate creates new images from a prompt and up to 5 optional reference images.
> `POST /v2/image/precise-edit/ideogram-4-5` […] Precise Edit changes part of an existing image
> while leaving the rest untouched.
>
> Both endpoints offer four quality modes, so you can choose the right balance of cost and
> fidelity.

### Resolution claim (verbatim)

> **Edit at any resolution**
>
> Edit high-resolution images without downsizing them. Ideogram 4.5 preserves the edges of an
> edited crop, so you can stitch it seamlessly back into the original. Create new colorways or
> fix a detail while keeping the rest of your image sharp and untouched—ready for close-ups and
> large-format print.
>
> Source image: 4,016 × 6,016 pixels (24.2 MP)

The API reference caps whole-image edits at 4,194,304 pixels and requires `context_window` to
keep full resolution above that
([Precise Edit reference](../ideogram-api-precise-edit-4-5/2026-10-26.md)). The marketing
page does not mention the cap or the edit-window mechanism.

## Known gaps

- No publication date on the page and no dated first-party launch announcement was found; the
  release date has to be triangulated from host metadata and an archive first-capture
  ([archive record](../../archive.org/ideogram-4-5-model-page/2026-10-26.md)).

- No latency figures, no benchmark numbers, and no definition of "artifact buildup".

# Ideogram developer docs: API overview (v2)

- Origin: Ideogram developer documentation, "API Overview" (v2),
  https://developer.ideogram.ai/v2/ideogram-api/api-overview (Markdown:
  https://developer.ideogram.ai/v2/ideogram-api/api-overview.md)
- Evidence kind: official documentation (first-party API docs)
- Publication date: none stated
- Capture date: 2026-10-26
- Relevant models: Ideogram 4.5 (primary), 4.0, 3.0, plus hosted partner models

## Captured content

### Positioning (verbatim)

> ## Ideogram 4.5: the most precise edit model
>
> Tell Ideogram 4.5 what to change and it leaves everything else alone. With Precise Edit, pixels
> the edit doesn't touch are copied exactly from your image, and the result comes back at your
> image's own width and height.
>
> #### Targeted edits
> Change a colour, material, or detail and keep the rest of the image untouched. Add a `mask` to
> limit the edit to one area.
>
> #### Consistent across edits
> Chain edit after edit with minimal drift: shape, texture, and colour hold steady from one turn
> to the next.
>
> #### Guided by references
> Add up to four `reference_images` to steer the edit with a product, a material, or a style.

### Typography statement (verbatim)

> [Generate] Create images from a prompt with Ideogram 4.5 and 4.0, known for prompt fidelity and
> crisp typography, or with GPT Image and Nano Banana.

This is the only first-party sentence found that attaches typography to 4.5 by name; it attaches
the same words to 4.0 and gives no comparison or measurement.

### Endpoint convention (verbatim)

> Every v2 endpoint follows one pattern, `POST /v2/{content}/{action}/{model}`, so the model you
> call is always in the URL: for example `/v2/image/generate/ideogram-4-5`.

### Operational statements

- Image URLs expire: "image URLs expire, so download anything you want to keep."
- Default rate limit: "If you need more than the default rate limit of 10 in-flight requests,
  contact us".
- v1 is still served; each v1 endpoint has a v2 equivalent with the model in the path. The v1→v2
  table lists `POST /v1/ideogram-v4/generate` → `POST /v2/image/generate/ideogram-4`; no v1
  Ideogram 4.5 endpoint appears, i.e. 4.5 is a v2-only model.
- The v2 index also lists a tool endpoint "Replace background with Ideogram 4.5"
  (`/v2/api-reference/tool/replace-background-ideogram-45`).

## Known gaps

- No release date, changelog, or deprecation policy for 4.5 is published in the captured docs.
- "Known for […] crisp typography" is not backed by any example, measurement, or comparison on
  this page.

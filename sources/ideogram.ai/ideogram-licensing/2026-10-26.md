# Ideogram: Licensing page

- Origin: Ideogram, "Licensing", https://ideogram.ai/licensing/
- Evidence kind: official documentation (vendor licensing terms and FAQ, first-party)
- Publication date: none stated
- Capture date: 2026-10-26
- Relevant models: Ideogram 4.5 (hosted API), Ideogram 4.0 (open weights)

## Captured content

### Output ownership and commercial use (verbatim FAQ)

> **Can I use Ideogram outputs commercially?**
>
> Yes. Ideogram does not claim ownership of outputs generated with the model. You can use outputs
> commercially as long as you respect third-party rights and follow the Acceptable Use Policy. The
> exception is using outputs to train models that compete with Ideogram.

### Prohibited uses (verbatim)

> Ideogram models cannot be used for surveillance, biometric identification, military
> applications, CSAM, non-consensual intimate imagery, or any unlawful or rights-violating
> activity. The full list is in the Acceptable Use Policy.

### Weight licensing tiers

The three licensing paths on this page — "Non-commercial license", "Self-Serve Commercial License"
($300/mo, 10K–100K images/month) and "Enterprise" — all concern **self-hosting Ideogram 4 public,
quantized weights**. Verbatim:

> The open weights release is a quantized version of the model published on Hugging Face under the
> Ideogram Non-Commercial Model Agreement. The self-serve commercial license adds commercial-use
> rights for those public, quantized weights. Full-precision weights, customer-facing products,
> API-like access, and custom terms require Enterprise.

> Does not include […] Ideogram-hosted API access

The page's comparison table lists "Ideogram API" as "Hosted API / Usage based", distinct from the
weight licenses.

## Interpretation

- The commercial-use answer is written generally ("outputs generated with the model") but sits on
  a licensing page about Ideogram 4 weights. It was **not** captured from a page of API terms. The
  hosted-API grant therefore rests on this FAQ plus the Acceptable Use Policy, and the underlying
  API terms were not captured.
- Ideogram 4.5 has no published weights, so none of the weight-license tiers apply to it; 4.5 is
  hosted-only and billed per image.

## Captured content

### Precise Edit uses 4.5 (verbatim)

> Ideogram 4.5 and GPT Image 2.5 both take masks.

> Ideogram 4.5 masks work in the **Precise Edit** app. The result keeps your image's exact size.

> Precise Edit uses Ideogram 4.5 and keeps the image's exact size. You can add up to 4 reference
> images without a mask, or 3 with one.

### Precise Edit settings (verbatim)

> - **Quality**: Very low, Low, Medium or High. The default is Medium.
> - **Number of images**: 1 to 8 results per run. The default is 1.
>
> Changing either setting changes the cost shown on **Apply edit**.

### Edit window (verbatim)

> If **Use Edit Window** is available on your account, it keeps the edit inside one part of the
> image. […] The rest of the image stays unchanged. A **mask** marks what you want to change; an
> **edit window** limits the region that the edit can use. You can use a specific window without a
> mask, while **Auto (requires mask)** is unavailable until you add one.

> If the window switch is unavailable, check its explanation. A very small image cannot use an
> edit window. An image that is too wide or tall to edit as a whole always uses one, so you cannot
> turn it off.

### Multi-turn editing (verbatim)

> Multi-turn editing means using one edit's result as the source for the next. Change one thing
> per turn, say what should stay the same, and inspect each result before continuing.

> Three edits in a row with Ideogram 4.5. Each prompt changed one thing and kept the rest:

The three documented prompts, verbatim:

1. "Change the sofa upholstery to deep forest green velvet. Keep the sofa's shape and the rest of
   the room exactly the same."
2. "Replace the abstract print inside the black frame with a vintage botanical illustration of a
   large fern. Keep the frame and everything else exactly the same."
3. "Make it evening: dusky blue light through the window, and the table lamp switched on. Keep
   every object exactly where it is."

The page also shows "A storefront rebrand over nine edits. Four of them are shown here" and a
three-edit photo restoration sequence, with no statement of how many attempts were needed or
whether failures were discarded.

### Access (verbatim)

> Free accounts can make a limited number of Precise Edit edits. After that, Precise Edit needs a
> paid plan or bought credits.

## Known gaps

- Vendor-curated examples only: no failure cases, no prompt-by-prompt retention measurement, and
  no statement of how much drift is tolerated before an edit counts as failed.
- "Keeps the image's exact size" is true for the output dimensions; the API caps the *edited
  area* at 4,194,304 pixels unless an edit window is used
  ([Precise Edit reference](../ideogram-api-precise-edit-4-5/2026-10-26.md)).

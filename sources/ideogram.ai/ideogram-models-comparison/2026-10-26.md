# Ideogram docs: Models (model comparison)

- Origin: Ideogram documentation, "Models",
  https://docs.ideogram.ai/create/models (Markdown: https://docs.ideogram.ai/create/models.md)
- Evidence kind: official documentation (first-party help docs)
- Publication date: none stated; page footer at capture: "Last updated 11 days ago" on the docs
  welcome page (this page carries no own date)
- Capture date: 2026-10-26
- Relevant models: Ideogram 4.5, 4.0, 4.0 Transparent, 3.0, 3.0 Transparent, 2.0/2a, plus
  partner and custom models

## Captured content

### Choosing a model (verbatim rows)

> | To edit or combine up to five reference images with an Ideogram model | **Ideogram 4.5**. Use
> Precise Edit when the change needs a mask. |
> | Style presets, style references, a negative prompt or a color palette | **Ideogram 3.0**.
> Style references guide the look; they aren't source images to edit. |
> | A transparent image from a prompt | **Ideogram 4.5** with Background set to Transparent, or a
> dedicated **Transparent** model. |

> **Ideogram 4.5** accepts reference images in the Image app, so you can edit or combine images
> with a prompt. […] In the Precise Edit app you can mask the area you want to change
> (inpainting).

> **Ideogram 3.0** is the only model with style presets, style reference images, negative prompts
> and color palettes.

### Ideogram 4.5 comparison row (verbatim)

| Setting | Ideogram 4.5 |
| --- | --- |
| Prompt | "Text or [JSON], up to 10,000 characters" |
| Reference images | "Up to 5" |
| Aspect ratio | "Auto or a ratio, then **Resolution** 1K or 2K. With references, **Size** replaces both" |
| Quality options | "Very low (with references only), Low, Medium, High" |
| Magic Prompt | "On/off toggle. Hidden when you attach references" |
| Background | "Auto, Transparent or Opaque, under **Advanced settings**" |
| 3.0-only settings | "No" |

Sibling rows: Ideogram 4.0 has no reference images, "Turbo, Default, Quality" and 1K/2K;
Ideogram 3.0 has no reference images, "style reference images instead", 15 ratios from 1:3 to
3:1 and no resolution choice.

### Other statements

- "Every plan, free included, can use Auto and all Ideogram models."
- "Ideogram 2.0 and 2a may still appear in the picker. For new work, use Ideogram 4.5 or 4.0."
- "The list comes from Ideogram's servers, so what you see can change over time."
- Ideogram 4.0 Transparent and 3.0 Transparent are listed as the dedicated transparent models;
  there is no "Ideogram 4.5 Transparent" entry.

## Known gaps

- The docs do not state a release date for any model, so this page cannot date 4.5.
- No quality, latency, or typography comparison numbers appear here; positioning is by controls
  and settings, not by measured output quality.

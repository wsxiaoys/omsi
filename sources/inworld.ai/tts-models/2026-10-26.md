## Captured content

### The deprecation notice — the central identity fact for this page

> **Using an earlier model?** Previous-generation models (`inworld-tts-1`, `inworld-tts-1-max`,
> `inworld-tts-1.5-max`, `inworld-tts-1.5-mini`) are deprecated and not recommended for new
> projects. `inworld-tts-1` and `inworld-tts-1-max` were discontinued on **June 15, 2026**. Requests
> to those two models are automatically routed to newer models. If you still use any of these earlier
> models, we recommend the TTS-2 family for better quality, latency, and cost.

Read carefully, the notice distinguishes two states:

| Model ID | Vendor status at capture | Consequence stated |
| --- | --- | --- |
| `inworld-tts-1` | discontinued 2026-06-15 | requests auto-routed to newer models |
| `inworld-tts-1-max` | discontinued 2026-06-15 | requests auto-routed to newer models |
| `inworld-tts-1.5-max` | deprecated | not recommended for new projects; no discontinuation date |
| `inworld-tts-1.5-mini` | deprecated | not recommended for new projects; no discontinuation date |

The page therefore **does not state an end-of-life date for TTS-1.5**, and the four IDs are the only
place in the current documentation where TTS-1.5 appears at all.

### Current lineup (the models this page replaces TTS-1.5 with)

| Name | Model ID | Vendor description |
| --- | --- | --- |
| Realtime TTS-2 | `inworld-tts-2` | "Our most powerful model with natural language steering and the strongest multilingual capabilities — the best choice for production quality" |
| Realtime TTS-2 Flash | `inworld-tts-2-flash` | "Our fastest, most cost-efficient model — significantly lower latency than `inworld-tts-2`, ideal for real-time agents and high-volume workloads" |

Feature comparison for the current models: TTS-2 100 ms P90 TTFB, TTS-2 Flash 20 ms; instant voice
cloning on both; professional voice cloning (Beta) on `inworld-tts-2` only; steering on
`inworld-tts-2` only; inline pronunciation, pause controls, timestamp alignment and zero data
retention on both. The footnote defines the latency unit as "P90 time to first audio byte, measured
server-side — excludes network latency."

## Summary

The vendor's own documentation marks TTS-1.5 Max and Mini as deprecated, and marks TTS-1 and
TTS-1-Max as discontinued on 2026-06-15. No replacement or shutdown date is given for TTS-1.5, so a
caller on a host endpoint that still serves `inworld-tts-1.5-max` has no published support window.

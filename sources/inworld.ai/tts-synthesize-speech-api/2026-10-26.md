- Origin: Inworld AI API reference, "Synthesize Speech",

- Evidence kind: official documentation (API reference)
- Publication date: none stated; captured 2026-10-26
- Capture date: 2026-10-26
- Relevant models: TTS API generally; examples use `inworld-tts-2`

## Captured content

### Request fields relevant to output shape

- `audioConfig.audioEncoding` (enum, default `MP3`): `LINEAR16`, `MP3`, `OGG_OPUS`, `ALAW`, `MULAW`,
  `FLAC`, `PCM`, `WAV`.
- `audioConfig.sampleRateHertz` (integer): "Accepts values within the range [8000, 48000]. Common
  sample rates include: 8000, 16000, 22050, 24000, 32000, 44100, 48000."

> If you request a supported rate that differs from the model's native output rate, the service
> converts the audio to that rate. Conversion may reduce audio quality. The request fails if the
> chosen encoding does not support the rate, or if the rate exceeds a known native output rate.

> When omitted, the default is 8,000 Hz for `MULAW` and `ALAW`. For other encodings, it is 48,000 Hz,
> capped at the model's native output rate when known.

- `modelId` (string, required): "The ID of the model to use for synthesizing speech." The field is
  not enumerated; the page points at the models page. Callers must "Set the model explicitly. SDK
  defaults may refer to older models."
- `deliveryMode`: "Only supported by `inworld-tts-2`. The field is ignored on other models."
- `synthesisContext`: at most 5 previous requests, 2,000 characters combined, and "Context text is
  not billed."
- `lipsyncConfig`: viseme timing; "work with every model and language".

### Metering

- `usage.processedCharactersCount` — "Number of input UTF-16 code units processed. For HTTP
  streaming, the first response message carries the full count and subsequent messages report zero.
  Sum across messages rather than reading only the last message. Cancelling after the request is
  metered does not reduce the count to the audio played."

### Character limits

The API reference itself does not state a character limit; the transport-by-transport figures are
in the companion guide, recorded at
[`sources/inworld.ai/tts-synthesize-speech-guide/2026-10-26.md`](../tts-synthesize-speech-guide/2026-10-26.md).

## Summary

Billing is per processed UTF-16 code unit of input text, counted even for cancelled requests, and
the non-streaming REST ceiling is the one both host endpoints expose.

## Gaps

- `modelId` is not enumerated, so this record cannot confirm from the API reference alone whether
  `inworld-tts-1.5-max` is still accepted; only the models page's "deprecated" wording applies.
- No native output sample rate is published for any model.
- Nothing on this page mentions watermarking, provenance metadata, or determinism/seed control.
- No character limit is stated here, so the API reference cannot be used alone to size requests.

- Publication date: none stated; captured 2026-10-26

- Relevant models: TTS API generally (examples use `inworld-tts-2`)

## Captured content

The page opens: "Send up to 2,000 characters and receive the complete audio in a single HTTP
response … It accepts up to **2,000 characters** per request."

Its own routing table, verbatim:

| If you need | Use | Why |
| --- | --- | --- |
| The lowest possible latency | WebSocket API | "Reuses a persistent connection and streams audio chunks as they are generated." |
| Low latency with a simpler integration | Streaming API | "Streams audio over HTTP and accepts up to **4,000 characters** per request." |
| A drop-in replacement for OpenAI text-to-speech | OpenAI compatibility | "streams audio like the Streaming API" |
| Long-form audio such as audiobooks, podcasts, or voiceovers | Async API | "Accepts up to **100,000 characters** per job … On-Demand accounts are capped at 10,000 characters per job." |
| Lower-cost generation that can finish later | Batch API | "Costs 20% less per character and processes many independent requests in the background." |
| The simplest integration for short text | Synthesize Speech | "with a **2,000-character** request limit" |

Async and Batch are marked **Preview** in the docs index; the async page also notes results are
delivered as signed URLs, and a separate "Results Delivery" preview page covers upload to the
customer's own S3/GCS/Azure bucket.

## Summary

The vendor's own routing table is the authority for input limits: 2,000 characters on the plain
non-streaming call, 4,000 on HTTP streaming, 100,000 per async job (10,000 on the free On-Demand
plan). Both independent hosts cap at 2,000, i.e. they expose only the non-streaming ceiling.

## Gaps

- No per-model limit is given; the table is presented as a property of the API, not of a model ID,
  so it does not establish whether TTS-1.5 has different limits from TTS-2.
- No audio-duration limit is stated in seconds or minutes on any transport.
- No statement on whether an over-limit request is rejected or truncated.

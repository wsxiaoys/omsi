## Documented capabilities

- **Model IDs:** `kimi-k3.1-pro` and `kimi-k3.1-pro-highspeed`, called through an
  OpenAI-compatible endpoint at `https://api.moonshot.ai/v1`.
- **Reasoning:** "K3.1 Pro always has thinking mode enabled and supports configuring its
  reasoning effort with the top-level `reasoning_effort` request field. Reasoning effort
  supports `low`, `high`, and `max` (default `max`)." The FAQ: "You can't [turn off
  chain-of-thought] — K3.1 Pro always thinks."
- **Streaming:** separate `reasoning_content` and `content` deltas.
- **Vision:** image parts as base64 or `ms://<file-id>`; video parts as `video_url` with
  `ms://<file-id>` after `files.create(..., purpose="video")`.
- **Structured output:** `response_format` with `json_schema` and `strict: true`, applied to
  `message.content` only.
- **Partial mode:** assistant message with `partial: True` continues from a prefix.
- **Tool use:** function tools, `tool_choice` including `"required"`, and dynamic tool
  loading via a `system` message that carries `tools`.
- **Context caching:** automatic, TTL `5m` (default) or `1h`.

### Limits, verbatim from "Important limits"

> - "`max_completion_tokens` defaults to 131072 and can be set up to 1048576."
> - "`temperature=1.0`, `top_p=0.95`, `n=1`, `presence_penalty=0`, and
>   `frequency_penalty=0` are fixed; omit them from requests."
> - "Return the complete assistant message unchanged in multi-turn conversations and tool
>   calls."
> - "Vision input does not support public image URLs. Use base64 or `ms://<file-id>`, and make
>   `content` an array of objects."
> - "Web search is being updated and is not recommended for production workflows in the near
>   term."

**Access requirement:** "Kimi K3.1 Pro is a flagship model: it is unlocked after a successful
top-up (minimum $1)."

**Billing FAQ:** "Kimi K3.1 Pro offers a 1M-token context and uses flat pay-as-you-go pricing
— there is no tiering by context length. Billable items include cache writes (with separate
TTL 5min and TTL 1h tiers), input (with separate rates for cache hits and misses), and output,
all billed at uniform per-token prices."

## Summary

First-party confirmation of the API surface: one always-thinking reasoning model with three
effort levels, text/image/video input, text output, 1M context, 1M max output, fixed sampling
parameters, function calling plus structured output and partial mode, automatic prompt
caching, and a top-up gate for access. It is the page to cite for anything a client
implementation depends on.

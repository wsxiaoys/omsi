- **Origin:** "Model Inference Pricing Explanation", Kimi API Platform (Moonshot AI),
  <https://platform.kimi.ai/docs/pricing/chat>. Retrieved 2026-10-26.
- **Evidence kind:** official documentation (first-party list prices and billing rules).
- **Publication date:** none stated; live pricing page. Capture date 2026-10-26.
- **Relevant models:** `kimi-k3.1-pro`, `kimi-k3.1-pro-highspeed`, `kimi-k3` (and the K2

- **Capture type:** the Markdown rendition of the page (`…/pricing/chat.md`) renders both

## K3 series — USD per million tokens

Page statement: "All K3 series models support a 1,048,576-token context window."

| Model | Input | Output | Cached input | 5m cache write | 1h cache write |
| --- | --- | --- | --- | --- | --- |
| `kimi-k3.1-pro` | $2.00 / MTok | $10.00 / MTok | $0.20 / MTok | $2.00 / MTok | $4.00 / MTok |
| `kimi-k3.1-pro-highspeed` | $4.00 / MTok | $20.00 / MTok | $0.20 / MTok | $4.00 / MTok | $8.00 / MTok |
| `kimi-k3` | $3.00 / MTok | $15.00 / MTok | $0.30 / MTok | $3.00 / MTok | $6.00 / MTok |

Column tooltips, verbatim: cached input is "billed at this rate; each hit automatically
refreshes the cache entry's TTL"; "5m writes" is "the default tier when no TTL is specified".

Two things follow from the table. K3.1 Pro is **cheaper than its own predecessor** on both
sides ($2/$10 against K3's $3/$15, a 33% cut), and the highspeed sibling is exactly 2× the
base model on every token class rather than a differently-shaped price.

## Billing rules, verbatim

> "Note: The Kimi API automatically enables context caching billing for repeated request
> prefixes, with a default TTL (time-to-live) of 5m."

> "For K3 series models, cache writes are billed separately by TTL (5min / 1h); cached input
> is billed at the cache-hit price only, with no additional cache write charge."

> "Here, 1 MTok = 1,000,000 tokens. The prices in the table represent the cost per MTok
> consumed."

> "Prices exclude applicable taxes. Specific tax obligations are subject to local tax
> regulations and will be calculated at checkout based on your jurisdiction."

> "Model inference on the Kimi API platform is billed on a pay-as-you-go basis, with no
> subscription plan."

Also: the file APIs (content extraction, file storage) are "temporarily free"; extracted
document content passed as input is billed as input.

## Summary

First-party list prices: **$2.00 input / $10.00 output / $0.20 cached input per million
tokens** for `kimi-k3.1-pro`, with cache writes at $2 (5m) and $4 (1h); the highspeed variant
is double on every line. Flat rate across the whole 1,048,576-token window — the guide states
there is "no tiering by context length".

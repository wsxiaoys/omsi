## Verbatim: endpoint

```
POST /image-to-video/kling-4.0
```

Example request in the docs posts to `https://api-singapore.klingai.com/image-to-video/kling-4.0` with
`Authorization: Bearer ${KLING_API_KEY}`.

## Verbatim: request body

> Supports video generation from multiple keyframes, including first frame, middle frame and last frame,
> with up to 10 images per request.

`contents[]` types: `prompt`, `first_frame`, `middle_frame`, `last_frame`.

- Keyframe images: ".jpg, .jpeg, .png"; "cannot exceed 30MB"; "width and height […] should not be less
  than 300px"; "aspect ratio […] between 2:5 and 5:2"; "Maximum number of images: 10".
- Prompt: "English-only input supports up to 26,000 characters, and non-English-only input supports up to
  11,000 characters. Mixed input must satisfy E / 26000 + N / 11000 <= 1".

`settings`:

| Field | Type | Default | Values |
| --- | --- | --- | --- |
| `resolution` | string | 1080p | `720p`, `1080p` |
| `duration` | int | 10 | `3`–`30` (every integer) |

> When this parameter is provided, the specified duration takes precedence. […] When this parameter is
> omitted, the model detects and follows the duration intent in the Prompt, for example, "Generate a
> 15-second video."

`options`:

- `callback_url`, `external_task_id`.
- `watermark_info.enabled`: "true: generate watermarked result; false: do not generate; default: false";
  "Custom watermarks are not currently supported".

No `aspect_ratio` field is documented on this endpoint, although the product UI and user guide offer
21:9 / 16:9 / 1:1 / 9:16 / Auto. The API's resolution enum stops at 1080p, while the product documents
list 4K (coming soon).

## Verbatim: reference handling

> The Kling 4.0 API supports multi-reference video generation and video editing through prompts that
> describe reference roles, scene content, event sequences, and audio requirements.
>
> 1. **Reference input materials using custom IDs.** […] assign it an `id` and use `@id` to reference it
>    in the prompt.
> 2. **Specify the purpose and scope of each reference.** […] If a material is referenced without an
>    explicit purpose, the model will infer how to use it, which may produce results that differ from
>    your intent.

The page also carries tabs for "Text to Video", "Omni Video Generation", "Element Management" and "Voice
Management".

## Summary

First-party API reference for Kling 4.0, labelled PREVIEW and scheduled for full availability on
2026-10-28 (two days after capture). Documents a single flat endpoint per task
(`/image-to-video/kling-4.0`) with a `contents[]` array of prompt plus up to 10 keyframes, `resolution`
720p/1080p and `duration` 3–30 (default 10, or inferred from the prompt), a watermark toggle defaulting
off, and prompt limits of 26,000 English / 11,000 non-English characters.

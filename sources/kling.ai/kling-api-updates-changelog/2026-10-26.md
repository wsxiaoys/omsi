## Verbatim: every lip-sync entry, oldest first

### 12/23/2024

> **Video Generation | New Feature: Lip-Sync**
> - Videos generated by the Video V1.0 model and Video V1.5 model support lip-sync as long as the video
>   meets the facial requirements
> - Includes create task, query task (single), and query task (list) interfaces

### 03/12/2025

> **Video Generation | Lip-syncing supports customized videos and more available tones**
> - Supports lip-syncing for any 1080p or 720p video within 10s
> - Added 8 new Chinese and English tones that can be used directly to dub lip-sync videos

### 06/30/2025

> **Lip-Sync | New version new capabilities**
> - Supports increasing the maximum video duration from 10 seconds to 60 seconds
> - Generating videos takes as little as 2 minutes
> - No need to modify the code

### 09/15/2025

> **Lip-Sync | Feature Update：Support multi person screen lip-sync and start lip-sync time**
> - Specify the speaker through face_id and start lip-sync time through sound_insert_time
> - Support clipping audio
>
> **TTS | New Feature: Online text-to-speech and enable trial listening function**
> - Can generate audio_id simultaneously, can be used for any Kling API

No later lip-sync entry appears in the changelog, up to the newest section dated 09/15/2026.

## Verbatim: related entries

### 09/29/2025

> ❗️ Notice: To ensure data security, all images and videos generated via our API will be automatically
> purged after 30 days. To avoid any disruption to your service, please download and save them locally
> in a timely manner after generation

### 10/15/2025

> **Avatar | New Feature Launched**
> Generate videos based on images, audio, or text that have natural facial expressions, consistent
> rhythms, and vocals. It's currently not supported to specify faces if there are multiple faces in the
> input image.

This matters for identity: **Avatar** — the image-driven talking-head product — is a separate launch
(2025-10-15), five months after the lip-sync API had already reached 60-second videos. Lip Sync and
Avatar are different services, not two names for one.

## Summary

The lip-sync API's release history, from the vendor's own changelog:

| Date | Change |
| --- | --- |
| 2024-12-23 | Lip Sync API released; only Kling V1.0/V1.5 generated videos |
| 2025-03-12 | Any 720p/1080p video up to 10 s; 8 new Chinese/English TTS tones |
| 2025-06-30 | "New version": max video duration 10 s → 60 s; ~2 min generation |
| 2025-09-15 | Multi-person frames, `face_id` speaker selection, `sound_insert_time`, audio clipping; online TTS producing reusable `audio_id` |

**The model is not a 2025-10-26-or-later release.** Its first appearance is 2024-12-23, ten months
before the roster's one-year window opens. This is the single most important fact on the page it
supports.

## Gaps

- The changelog never names the endpoint path, so it cannot be used to date `/v1/videos/advanced-lip-sync`
  itself. The "new version" of 2025-06-30 is the natural candidate for the `advanced-` route, but no
  captured page says so.
- No entry describes a quality change, a model swap, or a resolution change; "new version new
  capabilities" is the only version-like statement in the whole history.
- The changelog does not reconcile 09/15/2025's "multi person screen lip-sync" with the current
  reference's "Currently only supports one person lip-sync".

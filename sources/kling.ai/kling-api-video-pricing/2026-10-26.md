Lip Sync carries **no resolution column** — unlike every video-model row on the same page, which is
split into 720P / 1080P / 4K. Face Recognition is a separate line item, so the workflow is billed twice
per run.

## Unit price

The sibling `/dev/pricing` page states the unit basis: "1 Unit = $0.14 (list price)" (see the existing
`kling-api-pricing` record, captured 2026-10-26).

At that list price: Lip Sync = 0.5 × $0.14 per 5 s = **$0.07 per 5 s, i.e. $0.014 per second**; Face
Recognition = $0.007 per call. The lip-sync figure matches both hosts' published $0.014/s exactly, which
cross-validates the arithmetic. The /dev/pricing page's own table lists no Lip Sync row at all — the
docs price page is the only first-party schedule that prices it.

## Summary

First-party billing basis for Kling Lip Sync: **0.5 Units per 5 seconds of video**, plus 0.05 Units per
Face Recognition call, plus 0.05 Units per TTS call if the audio is generated rather than uploaded. At
the $0.14 list unit price that is $0.014/s for the lip sync itself, before the two per-call fees.

## Gaps

- The page does not say whether the 5-second block rounds up (a 3 s video billed as 5 s) — the hosts do
  round up, the vendor page does not say.
- No discount tiers, concurrency terms or regional price differences are shown for this row, unlike the
  video-model packages.
- Whether the Face Recognition call is charged on failure is not stated.

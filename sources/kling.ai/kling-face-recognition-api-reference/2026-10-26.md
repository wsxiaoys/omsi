## Verbatim: purpose

> Identify faces in the video for lip-sync processing.

## Endpoints

| Operation | Method | Path |
| --- | --- | --- |
| Identify faces | POST | `/v1/videos/identify-face` |

Base URL in every example: `https://api-singapore.klingai.com`.

## Verbatim: request body

`video_id` (string, optional) —

> The ID of the video generated by Kling AI. Used to specify the video and determine whether it can be
> used for lip-sync services. This parameter and 'video_url' are mutually exclusive—only one can be
> filled, and neither can be left empty. Only supports videos generated within the last 30 days with a
> duration of no more than 60 seconds.

`video_url` (string, optional) —

> The URL of the video. Used to specify the video and determine whether it can be used for lip-sync
> services. … Supported video formats: .mp4/.mov, file size ≤100MB, duration 2s–60s, resolution 720p or
> 1080p, with both width and height between 512px–2160px. If validation fails, an error code will be
> returned. The system validates video content and returns an error code if any issues are detected.

## Verbatim: response body

```
"data": {
  "session_id": "id",
  "face_data": [ { "face_id", "face_image", "start_time", "end_time" } ],
  "final_unit_deduction": "string",
  "final_balance_deduction": { "quota", "list_price" }
}
```

- `face_data[]` — "Face data list"; `face_image` is "Face image URL"; `start_time` / `end_time` are the
  "Face appearance start time / end time, unit: ms".

## Summary

Any 720p or 1080p mp4/mov between 2 and 60 seconds and ≤100 MB is accepted, whether Kling-generated
(`video_id`, last 30 days) or user-supplied (`video_url`). The response is a session plus, per detected
face, an ID, a cropped face image URL and the interval the face is on screen. That session and face ID
are what the lip-sync call consumes.

The endpoint is billed separately (see the price-list record: 0.05 Units per call).

## Gaps

- The page never says how many faces it will return, what happens with zero detected faces, or what
  "meets the facial requirements" means in detail.
- `face_image` is a face crop served from Kling's CDN. That is face data in the ordinary sense; it sits
  awkwardly with the API privacy policy's statement that Kling AI "will not collect, share or store any
  face data" (see the privacy-policy record).
- No statement of retention for `session_id` or the face crops beyond the general 30-day output purge.

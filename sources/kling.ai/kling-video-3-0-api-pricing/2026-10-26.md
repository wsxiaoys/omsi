# Kling video API price list (kling.ai developer pricing)

- Origin: Kling AI (Kuaishou) developer pricing page, <https://kling.ai/dev/pricing>. The table is
  not in the rendered HTML: it ships as a JSON config blob inside the page,
  `window['kConf_ytech.klingWeb.devModelPageInfo_18n']`, keyed by locale (`en`, `ja`, `ko`, `zh`).
  The `en` branch was read out of the page source. The `klingai.com` host serves the same blob with
  the same numbers.
- Evidence kind: official price list (vendor), machine-readable config transcribed
- Publication date: none on the page; the blob is undated
- Capture date: 2026-10-26
- Relevant models: Kling 3.0, Kling 3.0 Turbo, Kling 3.0 Omni; also Kling Image 3.0 / 3.0-omni /
  O1 / 2.1 (image, out of scope here)
- Capture type: reconstruction from embedded JSON. Every figure below is copied from the blob; the
  table layout is editorial.

## Unit and billing basis

`Video API Pricing 1 Unit = $0.14 (list price)`, `Image API Pricing 1 Unit = $0.0035 (list price)`.
Every video row is `"spec": "Per second"` — video is billed per second of output at a resolution- and
audio-dependent rate.

## What the page does not list

There is **no Kling 4.0 row** anywhere in the video table, although the API-reference bundle linked
from the same site registers doc routes `api/video/4-0/{text-to-video,image-to-video,video-omni,
elements,voice-customization}` alongside `api/video/3-0-turbo/*` and `api/video/3-0-omni/*`
(route strings read out of `kling-api-doc` asset `index-Dqppacy9.js`, captured 2026-10-26). So as of
capture the developer price list covers the 3.0 generation and not 4.0, while 4.0 documentation
routes and third-party hosts already exist.

Note also that the route table has **no plain `api/video/3-0/*` group** — the documented 3.0 API
surfaces are `3-0-turbo` and `3-0-omni`. Whether a bare `kling-v3` API model ID exists is therefore
unresolved from this evidence.

## Summary

Vendor list price for Kling 3.0 video is $0.084–$0.168 per second at 720p/1080p depending on audio
and tier, and $0.42 per second at 4K. Turbo is $0.112/s at 720p and $0.14/s at 1080p, audio
included. Omni adds a surcharge when a video input is supplied. These are the vendor's own list
prices and match fal's per-second strings exactly for the standard (720p) and pro (1080p) tiers.

## Gaps

- No effective date, no changelog, no currency other than USD (the CN site quotes the same figures).
- No voice-control row for the base "Kling 3.0" tier, although fal lists a voice-control price
  ($0.154 standard / $0.196 pro) — see the fal record.
- The 4K rate being flat regardless of audio is stated but unexplained.
- Consumer credit pricing is separate; see the credit-cost-guide record.

## Endpoint and request body (Image to Video tab)

```
POST /image-to-video/kling-3.0
```

Example posts to `https://api-singapore.klingai.com/image-to-video/kling-3.0` with
`Authorization: Bearer ${KLING_API_KEY}`.

`contents[]` types: `prompt`, `first_frame`, `last_frame`, `element`.

- prompt: "should not exceed 3072 characters in length, and it is recommended not to exceed 2500
  characters".
- Multi-shot prompt format, verbatim: `"shot n, m, words; shot n, m, words;"` where "n: shot sequence
  number (1–6 shots supported)", "m: shot duration in seconds (each shot ≥ 1s; sum of all shot
  durations must equal the total video duration)", "words: shot prompt (max 512 characters)".
- Elements are referenced as `@xxx`; "Up to 3 Elements can be specified."
- Images: .jpg/.jpeg/.png, "cannot exceed 50MB", width/height ≥ 300px, aspect ratio 1:2.5 to 2.5:1.
- "Supports first-frame-to-video and first-and-last-frame-to-video generation; last-frame-only video
  generation is not supported."

`settings`:

| Field | Type | Default | Values |
| --- | --- | --- | --- |
| `multi_shot` | boolean | true | — |
| `audio` | string | off | `native`, `off` |
| `resolution` | string | 720p | `720p`, `1080p`, `4k` |
| `duration` | int | 5 | 3–15 |

`options`: `callback_url`, `external_task_id`, `watermark_info.enabled` ("true = include watermark,
false = no watermark. Default: false"; "Custom watermark is not supported at this time").

## Summary

The vendor's developer API documents 3.0 and 3.0 Omni as **one model group** under the path segment
`3-0-omni`, with a single generation endpoint per task (`/image-to-video/kling-3.0`) and a separate
"Omni Video Generation" tab for the video-input workflows. There is no model named "O3" in the
reference, no `o3` path segment in the navigation, and no route in the sidebar that names the Omni
video-edit surface explicitly.

What this record establishes for the Kling O3 page: the canonical vendor name is **Kling 3.0 Omni**,
and "O3" is a host-side label. What it does not establish is the edit endpoint's request schema, which
sits behind the unrendered tab.

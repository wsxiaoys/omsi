## Deprecation notice (verbatim)

> **Deprecated:** After October 26, 2026 at 11:59 PM UTC, requests to this endpoint will no longer
> work.

## Behaviour (verbatim)

> Generate a video driven by an audio track. Supply dialogue, music, or ambient sound and the model
> produces visuals synchronized to the audio. Optionally condition on a reference image for visual
> direction, a last frame for interpolation, and camera motion. Output frame rate defaults to 24 fps;
> its length is set by the audio.

## Maximum input audio duration (verbatim table)

| Model | Resolution | Maximum audio duration |
| --- | --- | --- |
| `ltx-2-5-fast` | 720p, 1080p | 20 seconds |
| `ltx-2-5-fast` | 1440p, 4K | 10 seconds |
| `ltx-2-5-pro` | 720p, 1080p | 10 seconds |
| `ltx-2-5-pro` | 1440p, 4K | 10 seconds |
| `ltx-2-3-pro` | 720p, 1080p | 20 seconds |
| `ltx-2-3-pro` | 1440p, 4K | 10 seconds |

Minimum audio length: 2 seconds.

## Request body (verbatim field list)

- `audio_uri` (string, required) — soundtrack; sets the output length
- `image_uri` (string, optional) — "Input image to be used as the first frame … Required if prompt is
  not provided"
- `prompt` (string, optional) — "Required if image_uri is not provided. Can be empty string when
  image_uri is provided"
- `resolution` (string, optional) — "When omitted, the resolution is automatically determined based on
  the input image orientation — portrait images produce 1080x1920 video, landscape images produce
  1920x1080 video. If no image is provided, defaults to 1920x1080."
- `model` (enum, optional, **default: `ltx-2-3-pro`**) — allowed `ltx-2-3-pro`, `ltx-2-5-fast`,
  `ltx-2-5-pro`
- `fps` (integer, optional, default: 24)
- `last_frame_uri` (string, optional) — "Requires `image_uri`. When provided, the video interpolates
  between the first and last frame."
- `camera_motion` (enum, optional) — same eight values as text-to-video

The default model on this endpoint is still `ltx-2-3-pro`, i.e. audio-to-video does not default to
LTX-2.5. Callers must pass `ltx-2-5-fast` or `ltx-2-5-pro` explicitly.

## Summary

Audio-to-video on LTX-2.5 takes 2–20 s of audio (Fast at 720p/1080p), 2–10 s otherwise, and derives
output length from the audio rather than from `duration`. It accepts an optional first frame and an
optional last frame, and bills per second of input audio.

## Gaps

- The `duration` parameter does not exist on this endpoint, so "auto duration" is not applicable.
- No statement of how speech, music and ambience are handled differently, or of lip-sync quality.
- No captured statement about whether the input audio is re-emitted in the output alongside generated
  audio, or replaced.

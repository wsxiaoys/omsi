# LTX documentation: text-to-video request reference (V1)

- Origin: LTX documentation, "Generate video from text — POST https://api.ltx.io/v1/text-to-video",
  <https://docs.ltx.io/api-documentation/api-reference/video-generation/text-to-video>
- Evidence kind: official vendor API reference (request schema, error taxonomy, deprecation notice)
- Publication date: undated; carries a deprecation deadline of 2026-10-26 23:59 UTC. Capture date
  2026-10-26.
- Capture date: 2026-10-26
- Relevant models: `ltx-2-3-fast`, `ltx-2-3-pro`, `ltx-2-5-fast`, `ltx-2-5-pro`
- Capture type: transcription of the page's markdown variant

## Deprecation notice (verbatim)

> **Deprecated:** After October 26, 2026 at 11:59 PM UTC, requests to this endpoint will no longer
> work. See Migrate from V1 to V2.

The synchronous V1 text-to-video endpoint is therefore withdrawn on the capture date itself; the
replacement is `POST /v2/text-to-video`, an asynchronous job endpoint.

## Request body (verbatim field list)

- `prompt` (string, required) — "Text prompt describing the desired video content"
- `model` (enum, required) — allowed values `ltx-2-3-fast`, `ltx-2-3-pro`, `ltx-2-5-fast`, `ltx-2-5-pro`
- `duration` (integer, required, nullable) — "Video duration in seconds. … Pass `null` to let
  `ltx-2-5-fast` or `ltx-2-5-pro` choose the length from your prompt"
- `resolution` (string, required) — "Output video resolution. See Supported Models for available
  resolutions per model."
- `fps` (integer, optional, default: 24) — "See Supported Models for available FPS per model and
  resolution."
- `generate_audio` (boolean, optional, default: true) — "Generate audio for the video. When true, the
  generated video will include AI-generated audio matching the scene. When false, only silent video is
  generated."
- `camera_motion` (enum, optional) — `dolly_in`, `dolly_out`, `dolly_left`, `dolly_right`, `jib_up`,
  `jib_down`, `static`, `focus_shift`

There is no `seed`, no `negative_prompt`, and no reference-image or multi-image parameter on
text-to-video. Image-to-video is a separate endpoint with `image_uri` / `last_frame_uri`.

## Errors (verbatim)

- 413 "The request body exceeds 32 MB"
- 422 "Content rejected by safety filters"
- 429 "Concurrency or queue limit exceeded"
- 400 / 401 / 500 / 503 / 504 as conventional

The 422 entry is the only captured first-party statement of a safety filter in the LTX API. No
moderation policy, refusal taxonomy, or appeal path is published on this page.

## Summary

The vendor's request surface for LTX-2.5 text-to-video is seven parameters, with duration a required
field that may be explicitly `null` for model-chosen length, and audio on by default. The V1 sync
endpoint this reference documents expires on 2026-10-26 23:59 UTC; the V2 async endpoint takes the same
body.

## Gaps

- Only the V1 reference was captured; the V2 async reference was not fetched, so any V2-only fields are
  unknown here.
- No prompt length limit is stated.
- No documentation of what `camera_motion` does to the output beyond the enum names.

# LTX documentation: input formats and size limits

- Origin: LTX documentation, "Input Formats — Complete guide to providing image and video inputs to the
  LTX API", <https://docs.ltx.io/input-formats>
- Evidence kind: official vendor API documentation (input constraints)
- Publication date: undated; capture date 2026-10-26
- Capture date: 2026-10-26
- Relevant models: all LTX API models, including `ltx-2-5-fast` / `ltx-2-5-pro`
- Capture type: transcription of the page's markdown variant

## Size limits (verbatim tables)

| Method | Max size |
| --- | --- |
| Cloud Storage (`POST /v1/upload`, `ltx://` URI) | 200 MB |
| HTTPS URL | 15 MB (images), 32 MB (videos/audio) |
| Data URI (base64) | 7 MB (images), 15 MB (videos/audio) |

Uploaded files: "Upload URL expires 1 hour", "File available 24 hours". The whole JSON request body is
capped at 32 MB; exceeding it returns `413 request_too_large_error`.

HTTPS input requirements, verbatim: "HTTPS only · Domain names (no IPs) · Publicly accessible · No
redirects · The response's `Content-Type` must be one of the MIME types in Supported Formats. For
example, `image/jpg` and `application/octet-stream` are rejected."

## Supported formats (verbatim)

Images: PNG (`image/png`), JPEG (`image/jpeg`), WEBP (`image/webp`).

Videos: MP4 (`video/mp4`), MOV (`video/quicktime`), MKV (`video/x-matroska`), H.264 or H.265.

Audio: WAV (`audio/wav`; AAC, MP3, Vorbis, FLAC inside), MP3 (`audio/mpeg`), M4A (`audio/mp4`, AAC),
OGG (`audio/ogg`; Opus, Vorbis). "PCM audio is not supported."

## Summary

Inputs to the LTX API are images (PNG/JPEG/WEBP, ≤15 MB by URL or ≤7 MB inline), audio (WAV/MP3/M4A/OGG,
≤32 MB by URL) and video for the video-to-video endpoints (MP4/MOV/MKV H.264/H.265, ≤32 MB by default,
100 MB for extend, 200 MB for reframe). LTX-2.5's own endpoints take images and audio only.

## Gaps

- No pixel-dimension limits for input images, and no aspect-ratio constraints stated beyond "no
  redirects" style transport rules.
- No audio sample-rate or channel limits.
- The video limits apply to endpoints LTX-2.5 does not have (extend, reframe), so they are context only.

# Luma Agents API docs: FAQ (moderation, limits, reproducibility, licensing)

- Origin: Luma AI, Luma Agents API docs, "FAQ",
  <https://docs.agents.lumalabs.ai/guides/faq/>
- Evidence kind: official documentation (vendor API FAQ)
- Publication date: no page-level date
- Capture date: 2026-10-26
- Relevant models: `uni-1`, `uni-1-max` (Ray 3.2 answers out of scope)

## Captured content

Model identity (verbatim):

> `uni-1` is Luma's unified image generation and editing model. It handles text-to-image and
> image-to-image through the same endpoint, with support for text rendering, spatial reasoning,
> multi-panel output, and style transfer.

> `uni-1-max` produces higher-quality output than `uni-1`. Same wire format and parameter set [...]
> Available to all accounts.

> Use `uni-1` for the broad set of generation and editing tasks — it's the default and the lowest
> cost. Use `uni-1-max` when you want higher-quality output [...] (e.g. final hero images, ad
> creative, anything where re-generations are expensive).

Prompting and language (verbatim):

> 6,000 characters. Prompts must be between 1 and 6,000 characters; anything outside that range is
> rejected.

> Does `uni-1` support non-English prompts? `uni-1` is optimized for English. Other languages may
> work to varying degrees, but results are less reliable. Write prompts in English, or translate
> before sending, for best output.

> Does the API support negative prompts? No. There is no `negative_prompt` parameter. Describe what
> you do want, positively.

> Can I reproduce the same image from the same prompt? Not deterministically. Each generation uses a
> different random seed and there is no public `seed` parameter. For visual consistency across
> multiple images, pair the same prompt with one or more `image_ref` references as style anchors.

Output resolution (verbatim):

> For `type: "image"`, the model picks the resolution based on the chosen aspect ratio — there is no
> `1K/2K/4K` selector. For `type: "image_edit"`, the output preserves the source image's original
> dimensions.

Async behaviour (verbatim): "Image generations typically take 30–60 seconds"; `POST
/v1/generations` returns 201 immediately with `state: "queued"`, then poll.

Content moderation (verbatim):

> The model blocks: Child sexual abuse material (zero tolerance); Sexually explicit content;
> Non-consensual intimate imagery and deepfakes of real people; Graphic violence and gore; Content
> promoting self-harm or dangerous acts; Hateful content targeting protected groups; Infringing or
> trademarked imagery in misleading contexts.
>
> Moderation runs on inputs (`prompt`, `source`, `image_ref`) and outputs.

> Can I disable content moderation? No. Moderation is enforced on every input and output and cannot
> be disabled.

> Moderation is conservative by design. Common causes of false positives include named public
> figures, words with dual meanings (violence-adjacent verbs, medical terminology), and reference
> images depicting real people.

Billing (verbatim): "Synchronous errors are never charged; the reserve is released the moment the
request is rejected."

Data handling and licensing (verbatim):

> Does Luma train on my API inputs or outputs? Review the current data-handling policy in the Terms
> of Service and privacy policy. For enterprise agreements with custom data-handling guarantees,
> contact sales.

> Who owns the generated images? Ownership and licensing are governed by Luma's Terms of Service,
> which covers commercial-use rights.

Reference-URL constraints (verbatim): "The URL redirects to HTML (e.g. a login wall) [...] The URL is
`http://` (proxy is HTTPS-only) or resolves to a private IP. A short-lived signed URL expired between
copy and fetch."

## What this establishes

- **No seed, no negative prompt, no resolution selector.** Reproducibility is explicitly not
  guaranteed, and style consistency is steered with reference images instead of seeds.
- English-optimised prompting; other languages "less reliable".
- Moderation is mandatory on inputs and outputs and cannot be disabled by the caller — a structural
  constraint, not a per-account setting. Named public figures and reference photos of real people
  are documented false-positive triggers.
- Commercial rights are delegated to the ToS; the docs do not themselves grant a licence, and the
  no-train guarantee appears only on the Provisioned Throughput plan
  ([pricing](../luma-agents-api-pricing/2026-10-26.md)).
- Latency guidance: 30–60 s per image, asynchronous.

## Gaps

- The ToS and privacy policy were not captured; the licensing and training-use statements are

- No failure-rate, refusal-rate, or retry data.
- No statement on output image dimensions in pixels for each aspect ratio at 2K.

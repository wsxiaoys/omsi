# Luma AI: "Introducing the Uni-1.1 API" announcement

- Origin: Luma AI, "Introducing the Uni-1.1 API: Intelligence You Can Direct. Aesthetic You Can
  Ship.", <https://lumalabs.ai/news/uni-1-1-api> (Markdown at
  <https://lumalabs.ai/news/uni-1-1-api.md>)
- Evidence kind: official announcement (vendor blog post)
- Publication date: 2026-05-05 (byline on the post)
- Capture date: 2026-10-26
- Relevant models: Luma Uni-1 / Uni-1.1 and Uni-1.1 Max

## Captured content

Byline: `May 5, 2026`. Opening (verbatim):

> Today we're opening access to the Uni-1.1 API: a REST interface to our Unified Intelligence model
> for image generation and natural-language editing. Now, the power of Uni-1 is the hands of
> developers [...]

> **Built for builders shipping in production — and ranked top 3 lab in the Image Arena across
> Text-to-Image and Image Edit.**

> Launched last month, Uni-1 takes a different approach to generative AI: reasoning and image
> generation run in the same model rather than in separate systems stitched together at inference
> time. [...] It currently ranks #1 on Human Preference Elo across overall, style & editing, and
> reference-based generation, and leads RISEBench on both overall reasoning and spatial logic.

> **Uni-1.1 API is already in production with commitments across Envato, Comfy, Runware, Flora,
> Krea, Magnific (formerly Freepik), Fal, and LovArt.**

Architecture restatement (verbatim):

> It's a decoder-only autoregressive transformer where text and image tokens share a single
> sequence; both as input and output, treated equally in the same forward pass.

API capabilities (verbatim):

> - **Generate Image** handles text-to-image and reference-guided generation. Pass up to nine
>   reference inputs per request to preserve identity, composition, style, or any combination of
>   them. [...]
> - **Modify Image** exposes natural-language editing — swap backgrounds, shift lighting, apply a
>   reference aesthetic, make localized changes — described in plain language and executed without
>   prompt scaffolding.

> Both endpoints are available through Python and JavaScript/TypeScript SDKs. Output controls
> include standard aspect ratios (1:1, 9:16, 16:9, and more) and PNG or JPEG format. Generation time
> is approximately 31 seconds per image, at less than half the price and latency of comparable
> models. It is available as of today via Uni-1.1 and Uni-1.1 Max.

Availability / tiers (verbatim):

> At less than half the price and latency of comparable models, the Uni-1.1 API is available today
> in two tiers for Uni-1.1 and Uni-1.1 Max:
> - **Build** — full API access with usage-based billing. [...]
> - **Scale** — higher rate limits and dedicated support for production workloads.

Other claims: "Native multilingual rendering across non-Latin scripts including Chinese, Japanese,
and Arabic, with regional aesthetic awareness"; "trained in collaboration with Hollywood
cinematographers, VFX artists, and world-class artists".

## What this establishes

- **Two dates, one name.** Uni-1 launched "last month" relative to 2026-05-05, and the API shipped
  on 2026-05-05 under the name **Uni-1.1**, with a second tier **Uni-1.1 Max**. The post never
  explains whether "Uni-1.1" is a new checkpoint or a rename of the API surface; the model IDs in
  Luma's own API docs are `uni-1` and `uni-1-max`
  ([models doc](../luma-agents-api-models/2026-10-26.md)).
- Luma names eight partners (Envato, Comfy, Runware, Flora, Krea, Magnific/Freepik, Fal, LovArt).
  Only the fal endpoints were verified for this page; the rest are vendor claims.
- Vendor latency claim: ~31 s per image; vendor price claim: "less than half the price" of
  comparable models.
- The "#1 Human Preference Elo" and "top 3 lab in the Image Arena" claims are dated only to this
  post. An independent Image Arena read on 2026-10-26 puts the two Luma UNI rows mid-board
  ([AA](../../artificialanalysis.ai/luma-uni-1/2026-10-26.md)).

## Gaps

- No per-image dollar prices in this post; the $ figures live on
  [lumalabs.ai/api](../luma-api-overview/2026-10-26.md).
- "Image Arena" is not identified. Luma's phrase collides with Artificial Analysis's own "Image
  Arena" product, and the AA numbers do not support a top-3 position on 2026-10-26.
- No statement of whether Uni-1.1 replaced Uni-1 for existing `uni-1` API callers.
- The launch date of the original Uni-1 is only "last month" here; see the
  [TechCrunch record](../../techcrunch.com/luma-uni-1-launch/2026-10-26.md) for a dated third-party
  launch report.

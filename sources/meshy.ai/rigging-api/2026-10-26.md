# Meshy: Rigging API reference

- Origin: Meshy Docs, "Rigging API", https://docs.meshy.ai/en/api/rigging
- Evidence kind: official documentation (vendor API reference)
- Publication date: none stated; live documentation as of capture.
- Capture date: 2026-10-26
- Relevant models: Meshy 7.1 output and any Meshy-produced humanoid mesh (rigging is a separate
  endpoint, not a Meshy 7.1 parameter)

## Captured content (summary with verbatim quotes)

Endpoint: `POST https://api.meshy.ai/openapi/v1/rigging`.

Applicability, quoted: "Rigging works well only with standard humanoid (bipedal) characters that have a
clearly defined limb and body structure." The page also lists model types it is "not suitable for".

Inputs:
- `input_task_id` (required unless `model_url`): "The ID of the task whose model you want to rig.
  Meshy supports textured humanoid models."
- `model_url`: "The model must be a GLB (.glb) file of at most 400 MB from an http or https URL, or
  100 MB as a data URI." Only `.glb`; over 100 MB the file must have ≤10,000,000 faces and must not be
  Draco-compressed.
- `height_meters` default 1.7: "The character's approximate height, in meters. Meshy uses it to scale
  and rig the model more accurately."
- `texture_image_url` (deprecated 2026-10-23): omit it; sending it "becomes the rigged model's only
  texture, and the model loses its PBR maps".

Outputs: `rigged_character_fbx_url`, `rigged_character_glb_url`, plus walk and run clips
(`walking_glb_url`, `walking_fbx_url`, `running_glb_url`, `running_fbx_url`) and armature-only GLBs.
Cost at capture: `consumed_credits: 5`.

Failure modes: 403 when "input_task_id is a bas-relief model, which this endpoint can't rig"; 422 when
"Pose estimation failed. The model might not be a valid humanoid character", and for `model_url` "also
check that the character faces the +Z axis".

## Summary

Rigging is a post-process over any Meshy mesh, not a Meshy 7.1 capability, and it is restricted to
humanoid bipeds facing +Z. A rigged character is the prerequisite for the Animation API. The 5-credit
price is separate from the 20–35 credits a 7.1 generation costs.

# Meshy: Text to 3D API (v2) reference

- Origin: Meshy Docs, "Text to 3D API", https://docs.meshy.ai/en/api/text-to-3d
- Evidence kind: official documentation (vendor API reference)
- Publication date: none stated; the page is live documentation. Content reflects the state at
  capture, including changelog entries up to 2026-10-26.
- Capture date: 2026-10-26
- Relevant models: Meshy 7.1 (`ai_model: "meshy-7.1"`, and `latest` resolves to it), Meshy 7
  (deprecated), Meshy 6, Meshy 6 Lite, Meshy T2 / T2.5 (Smart Topology)

## Endpoint and two-step workflow

`POST https://api.meshy.ai/openapi/v2/text-to-3d`, with `mode: "preview"` then `mode: "refine"`.
"First, create a preview task (`mode: "preview"`) to generate a 3D mesh without texture, so you can
check the shape. Then, send the successful preview's task ID to a refine task (`mode: "refine"`) to
texture the mesh. Both steps use the same endpoint." Companion routes: `GET /openapi/v2/text-to-3d/:id`,
`DELETE`, `GET` (list), and a stream route.

## Model selection

`ai_model` default `latest`. Standard models: `meshy-6-lite`, `meshy-6`, `meshy-7.1`,
`latest` ("latest: Meshy 7.1"), and `meshy-7 (deprecated): send meshy-7.1 instead`. Smart Topology
models (with `model_type: "smart-topology"`): `meshy-t2`, `meshy-t2.5` (default).

`model_type` values: `standard`, `smart-topology`, `lowpoly` (deprecated). "Meshy retires lowpoly on
October 30, 2026. After that date, a request with `model_type: "lowpoly"` returns an error."

## Geometry (preview)

- `geometry_resolution`: `standard` (default), `2k`, `4k`. "`2k` needs meshy-7.1, latest, or the
  deprecated meshy-7. `4k` needs meshy-7.1 or latest. Other models return 400." Applies only to
  preview tasks; a refine with it "returns 400".
- `ultra_mode` (deprecated 2026-09-18): "`ultra_mode: true` is the same as `geometry_resolution: "2k"`."
- `should_remesh` default "true (meshy-6-lite), false (other models)". "For the highest-quality 3D
  model, send false."
- `topology`: `triangle` (default) or `quad` ("a quad-dominant mesh"). Smart Topology is
  triangle-only.
- `decimation_mode`: 1 ultra / 2 high / 3 medium / 4 low; overrides `target_polycount`.
- `target_polycount`: "The number of faces to aim for. The result can differ from the target,
  depending on the geometry." Ranges: Remesh 100–300,000 (default 30,000); `meshy-t2` 100–15,000
  (default 4,000); `meshy-t2.5` 100–30,000 (default 15,000).
- `pose_mode`: `a-pose`, `t-pose`, or `""` (no specific pose).
- `symmetry_mode` (deprecated 2026-05-11): "Leave it out. This parameter doesn't affect the output."
- `art_style` (deprecated 2026-01-22): "Meshy ignores it."

## Texturing (refine)

- `enable_pbr` default false: "Whether to also generate PBR maps (metallic, roughness, and normal)
  with the base color." "`meshy-6-lite`, `meshy-7`, `meshy-7.1`, and `latest` don't generate an
  emission map." Only `meshy-6` does.
- `texture_resolution`: `2k` (default, 2048×2048), `4k` (4096×4096), `8k` (8192×8192).
  "`4k` and `8k` need `ai_model` `meshy-6`, `meshy-7.1`, or `latest`. At `8k`, Meshy doesn't generate
  an emission map." (Per the changelog record, at 8K PBR maps are generated at 4K.)
- `texture_prompt` / `texture_image_url`: up to 800 characters / 20 MB image; "Send `texture_prompt`
  or `texture_image_url`, not both."
- `remove_lighting` default true: "Takes effect only when `ai_model` is `meshy-6`. `meshy-7.1` and
  `latest` accept it and ignore it."
- `ai_model` on refine "default inherited from the preview task", so "the preview and its refine run on
  the same model end to end".

## Other inputs and outputs

- `prompt`: "up to 800 characters. Longer text returns 400."
- `target_formats`: `glb`, `obj`, `fbx`, `stl`, `usdz`, `3mf`. "If you leave it out, Meshy generates
  every format except `3mf`, which it generates only when you request it."
- `alpha_thumbnail`, `auto_size`, `origin_at` (`bottom`/`center`), `moderation` (default false:
  "Whether to screen prompt for harmful content ... If Meshy detects harmful content, the request
  returns 400 and Meshy doesn't create a task").
- Task object returns `model_urls` per format (plus `mtl` for OBJ), `thumbnail_url`, `texture_urls`,
  `consumed_credits`, `progress`, timestamps, `task_error`.

## Summary

The text-to-3D reference is the primary evidence for what Meshy 7.1 can be asked to do: a two-step
preview/refine workflow, three geometry passes (with `4k` reserved for 7.1), remesh with a 100–300,000
polycount target, 2K/4K/8K base colour with optional PBR maps but no emission map, six output formats,
and a subscription-gated task-creation path. The capability gap to Meshy 7 is exactly one enum value
(`geometry_resolution: "4k"`); the gap to Meshy 6 runs the other way in two places (emission map,
`remove_lighting`).

## Failure modes recorded

- 400 for missing parameter, prompt over limit, unsupported model for low-poly, unsupported model for
  Ultra, preview not succeeded, model mismatch between preview and refine.
- 402: "Insufficient credits ... Free plan: Creating a task requires a paid plan."
- 429 rate limits (see the rate-limits record).
- `DELETE` on an `IN_PROGRESS` task returns 409 and the task keeps running: "Credits for a task the
  worker has already started are not refundable."

## Gaps

- No `seed` parameter is documented for Text to 3D, unlike the fal host schema (see the fal record).

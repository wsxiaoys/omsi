## Summary

Meta's own product page for the API version of Muse Image. It fixes the headline price at
**$0.01 per image** with search grounding and reasoning both included at that price, describes the
model as reasoning/planning/searching before rendering, and lists fal, Runway and OpenRouter as the
places to run it. It gives no model ID on the page itself (the ID `muse-image-1.0` appears in the
linked docs — see the models and pricing record), no release date, no resolution, and no
reference-image or output-format limits.

## Gaps

- **No release or GA date** on the page, so it cannot date the API launch by itself.
- **No resolution/aspect-ratio specification**, no reference-image count, no output formats, no
  latency figures.
- **No licence statement** beyond the site footer's "Terms of Service" link; commercial use of
  outputs is not addressed here.
- The page says OpenRouter "routes across multiple inference providers"; OpenRouter's own page for
  the model says it is "hosted by one provider" (see `sources/openrouter.ai/muse-image/2026-10-26.md`).

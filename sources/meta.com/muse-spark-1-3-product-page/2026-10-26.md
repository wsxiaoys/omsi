## Summary

The closed Muse Spark line is versioned (1.1, 1.2, 1.3) and hosted on Meta Model API at
**$1.25 input / $0.15 cached / $4.25 output per 1M tokens** — exactly the price every captured host
charges for the open-weight Muse Spark Open. Muse Spark 1.3 scores higher than Muse Spark Open on
the benchmarks the two pages share (Terminal-Bench 2.1 88.8 vs 76.4; GDPval-AA v2 1754 vs 1401;
JobBench 64.9 vs 61.8; DeepSWE 1.1 75.4 vs 60), so the open release is not the current closed
checkpoint. Meta's own product page for the open model says it derives from "the Muse Spark model we
released in August" with added safety post-training.

## Gaps

- **Which Muse Spark version the open weights derive from is never stated.** The blog and product
  page say only "Muse Spark" and "the Muse Spark model we released in August".
- No release dates for 1.1/1.2/1.3 on this page.
- The two pages' benchmark tables are not directly comparable row-for-row: Muse Spark 1.3 is
  measured at `max` reasoning effort, Muse Spark Open at `xhigh`, and the open-model table uses a
  partly different benchmark list.

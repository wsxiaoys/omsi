## Captured content (verbatim)

> Download Muse Spark Open from Meta or Hugging Face and pick the checkpoint that matches your
> hardware. Everything runs offline once the weights land: there's no API key.

Checkpoint table:

| Checkpoint | Repository | Weight footprint | Serving recipes |
| --- | --- | --- | --- |
| BF16 | `meta-models/Muse-Spark-Open-816B-A42B` | About 1.65 TB | TP8/EP8 on 8 × B300 |
| NVFP4 | `meta-models/Muse-Spark-Open-816B-A42B-NVFP4` | About 537 GB | TP4/EP4 on 4 × B300 |

> The weight footprint doesn't include the key-value cache, activations, or runtime overhead.

Download from Meta (gated):

> 1. Sign in and open the Muse Spark Open download page.
> 2. Under **Choose a checkpoint**, select **BF16 checkpoint** or **NVFP4 checkpoint**.
> 3. Under **Licensing Terms**, select **License and Terms** and scroll to the end of the license to
>    accept it. **Accepted** appears next to **Licensing Terms**.
> 4. In the **Files** list, select the download icon next to each file. Download every file in the
>    list: the weight shards, `LICENSE.md`, and the config, tokenizer, and chat template files.

> Your browser downloads each file separately: BF16 has 65 weight shards and NVFP4 has 127. A
> runtime can't load the checkpoint if any file is missing or renamed.

Download from Hugging Face:

```bash
hf download meta-models/Muse-Spark-Open-816B-A42B --local-dir ./muse-spark-open
hf download meta-models/Muse-Spark-Open-816B-A42B-NVFP4 --local-dir ./muse-spark-open-nvfp4
```

Tokenizer check: `pip install -U "transformers>=5.19"`; the rendered prompt uses `<|start|>`,
`<|message|>` and `<|eot|>`.

## Summary

Two checkpoints, both gated: BF16 `meta-models/Muse-Spark-Open-816B-A42B` (~1.65 TB, 65 shards) and
NVFP4 `meta-models/Muse-Spark-Open-816B-A42B-NVFP4` (~537 GB, 127 shards). Both repositories ship
tokenizer, chat template, config and processor config. Download is licence-gated on both Meta's site
and (per the Hugging Face metadata) on the Hub.

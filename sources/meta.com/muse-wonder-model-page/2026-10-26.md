## Notes

- The page calls both variants "New" and does not label either "Preview"; the docs page does label
  Muse Wonder preview. The two first-party pages disagree on status.
- "Muse Wonder Full" is not a reasoning-effort setting. Meta's docs state that setting effort to
  `"max"` on Muse Wonder does not select Full.
- The vendor table's "Artificial Analysis Index" row (56 Full / 52 Wonder) matches Artificial
  Analysis's independently published 55.8 / 52.4 at capture, but Meta's other rows are vendor-run
  or vendor-selected and should not be read as independent measurements.

## Gaps

- No model card, context limits beyond "1M", per-modality input limits, knowledge cutoff, or
  deprecation policy on this page.
- The benchmark table has no per-benchmark harness notes; those are in the linked model card.
- No statement of what "New" means in time, or whether the preview label on the docs page applies
  to the same deployment.

## Muse Wonder pricing (verbatim)

> Model: `muse-wonder-1.0`.

| Usage | Standard mode (per 1M tokens) | Contributor mode (per 1M tokens) |
| --- | --- | --- |
| Cached input | $0.20 | Not available |
| Input | $4.00 | Not available |
| Output | $20.00 | Not available |

Token-pricing notes:

> - **Cached input costs less**: When part of your prompt matches a cached prefix, you pay the
>   cached-input rate for those tokens. Check `cached_tokens` in the response to see how many were
>   served from cache.
> - **No long-context premium**: you pay the same rate whether your context window is mostly empty
>   or almost full.
> - **Web search grounding**: **$2.50 per 1,000 search queries**, in addition to the request's token
>   cost. This applies to the `web_search` tool on text models such as Muse Wonder and Muse Spark.

Contributor mode:

> On Model API, use Contributor mode with Muse Spark 1.3 or 1.2 by calling its Contributor-mode
> variant ... Contributor mode isn't available for Muse Wonder on Model API.

## Rate limits (verbatim)

| Model | Requests per minute (RPM) | Tokens per minute (TPM) | Other limits |
| --- | --- | --- | --- |
| `muse-wonder-1.0` | 3,000 | 4,000,000 | |

> Creating background responses (`background: true`) is limited to **600 submissions per minute,
> per team**, in addition to the limits above.

Rate limits apply per team, not per API key. Injected steering/system context is not billed and is
excluded from reported `usage` token counts.

## Notes

- Billing is **per token** on Model API, with a separate per-query charge for web search. There is
  no long-context premium.
- **Muse Wonder Full has no price on this page** because it is not sold on Model API. Muse Code
  subscription pricing appears on the product page instead.
- Muse Wonder's Contributor-mode discount exists only inside Muse Code, not on pay-as-you-go.

## Gaps

- No published price for Muse Wonder Full.
- No per-modality input-token conversion rules for images, video, audio or PDFs.
- No statement of how cached-prefix matching is scoped or how long the cache persists.

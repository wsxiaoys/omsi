## Captured content (verbatim, page 1)

> Developer Microsoft Corporation
> Description MAI-Image-2.6 is a diffusion-based generative model designed for both high-quality
> text-to-image synthesis and precise, controllable image-to-image editing. It progressively
> transforms random noise into a coherent image aligned with a given text prompt, leveraging a
> flow-matching loss to learn a continuous transformation between the noise distribution and the
> data distribution.
> Model architecture Diffusion-based generative architecture for text-to-image synthesis and
> image-to-image editing
> Parameters 2×10¹⁰ (20B) non-embedding parameters
> Inputs Text input; Image input (for editing workflows)
> Context length 32K tokens
> Outputs Image output. Maximum total pixel count: 2,359,296 (equivalent to 1536×1536). Either
> dimension can exceed 1536 as long as the total stays within the limit.
> Training dates April 17, 2026 – July 22, 2026
> Release date Aug 14, 2026 (2.6), Sep 4 (2.6-Flash)
> Release date in the EU 4 Sep 2026
> License Various product and service terms where the model is deployed, such as those for Azure
> AI Foundry and MAI Playground.

## Summary

This is the strongest identity record for the model: it fixes the developer (Microsoft), the two
release dates (2026-08-14 for 2.6, 2026-09-04 for 2.6-Flash), the parameter count (20B
non-embedding), the 32K context, the 2,359,296-pixel output ceiling, and the fact that Flash is an
optimized 2.6 rather than a separate architecture. It also states the distribution is first-party
only (Foundry + MAI Playground) and that licensing is the hosting product's terms — there is no
weights licence because no weights are published.

The card names a "private preview, expanding to public preview" Foundry route, which is why the
Foundry catalogue still labels both models Preview.

## Gaps

- No price, no per-image token accounting, no latency figures.
- No statement of which languages are supported; Foundry's own model table says English only.
- "Release date Aug 14, 2026" is not corroborated by any announcement captured here; the public
  Foundry announcement is dated 2026-09-04.
- The card's evaluation section describes human-preference Elo rating but publishes no scores.

# Azure / Microsoft Foundry — Mistral models sold directly by Azure (availability check)

- **Origin:** "Models sold directly by Azure", Microsoft Learn, Microsoft Foundry documentation,
  <https://learn.microsoft.com/en-us/azure/ai-foundry/foundry-models/concepts/models-sold-directly-by-azure>.
  Retrieved 2026-10-26.
- **Evidence kind:** host catalogue (independent of Mistral).
- **Publication date:** none stated; live page.
- **Capture date:** 2026-10-26
- **Relevant models:** Mistral models in Microsoft Foundry; used here as a negative availability
  check for Mistral Large 4 and as a contrast with Mistral Large 3.
- **Capture type:** rendered page text (the model tables are in the HTML, not script-loaded).

## The "Mistral models sold by Azure" table, verbatim

| Model | Type | Capabilities |
| --- | --- | --- |
| mistral-document-ai-2512 | Image-to-Text | input image or PDF pages (30 pages, max 30MB PDF); output text; English; no tool calling |
| mistral-medium-3-5 — **Preview** | chat-completion | input text (128,000 tokens), image; output text (128,000 tokens); tool calling: No |
| mistral-ocr-4-0 — **Preview** | Image-to-Text | input image or PDF pages; output text; English; no tool calling |
| **Mistral-Large-3 — Preview** | chat-completion | input text, image; output text; languages en, fr, de, es, it, pt, nl, zh, ja, ko, ar; tool calling: Yes |

The page then adds: "Several Mistral models are also available from partners and community."

## Reading

**Mistral Large 4 is absent.** The four Mistral entries Azure sells directly are document AI, OCR,
Medium 3.5 and Large 3 — the previous Large generation, and still labelled Preview. A search of the
page for "Large 4" returns nothing. At capture, Azure is not a second source of Mistral Large 4
capacity.

This corroborates the independent picture from two other records: OpenRouter's three endpoints for
`mistralai/mistral-large-4-0` all route to "Mistral", and Artificial Analysis's provider page lists
"Mistral" as the only provider. Mistral Large 4 is, at capture, single-source.

## Gaps

- Absence from this table is not proof of a global absence: Mistral could be on Azure through a
  partner/community path, through a private offer, or added after the capture date. The page's own
  "from partners and community" link was not followed.
- AWS Bedrock was not checked in a usable way: the Bedrock "supported models" page served only
  ~11 KB with no model names in the HTML at capture, so it is neither a positive nor a negative
  record here.

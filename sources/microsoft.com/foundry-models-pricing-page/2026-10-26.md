All price cells render as "$-" in the static HTML (the table hydrates client-side), so this capture
carries the row inventory but **no prices**.

## Summary

This record exists to document a documentation gap, not a price: the public Azure price list that
Microsoft's own catalogue links to for MAI-Image-2.6 does not list the 2.6 models at all, while it
does list the 2.5 family. The 2.6 meters are nonetheless live in the billing API with an
`effectiveStartDate` of 2026-09-01. A reader who prices 2.6 from the price list alone will conclude
it is unavailable.

## Gaps

- Prices unreadable from this capture (client-side rendering); the authoritative figures come from
  the Retail Prices API record instead.

- Absence here is not proof of unavailability — the catalogue and the billing meters contradict it.

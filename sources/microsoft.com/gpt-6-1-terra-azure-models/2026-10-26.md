# Microsoft Learn: "Foundry Models sold by Azure" — `gpt-6.1-terra` rows

- **Origin:** Microsoft Learn, "Foundry Models sold by Azure",
  <https://learn.microsoft.com/en-us/azure/ai-foundry/openai/concepts/models>. Retrieved
  2026-10-26.
- **Evidence kind:** official documentation from the hosting platform (Azure's own model
  inventory, written by Microsoft — a host record, not a vendor record).
- **Publication date:** none stated on the page header; the page is a live inventory.
- **Capture date:** 2026-10-26
- **Relevant models:** `gpt-6.1-terra`, with `gpt-6.1-sol`, `gpt-6-astra`, `gpt-6-sol`,
  `gpt-6-luna`, `gpt-5.6-terra`.
- **Capture type:** rendered HTML, text-extracted. The capability tables are in the HTML, not
  script-loaded, so cell values extracted cleanly. The page is 184 KB; only the GPT-6.1 and
  GPT-6 sections are reproduced.

## Model highlights, verbatim

> | GPT-6.1 series | NEW | `gpt-6.1-sol`, NEW | `gpt-6.1-terra` |
> | GPT-6 series | NEW | `gpt-6-astra`, NEW | `gpt-6-luna`, `gpt-6-sol` |
> | GPT-5.6 series | `gpt-5.6-sol`, `gpt-5.6-terra`, `gpt-5.6-luna` |

Terra is marked NEW and listed inside the GPT-6.1 series, corroborating that OpenAI treats 6.1
as its own series with two members.

## GPT-6.1 capabilities table, verbatim

| Model ID | Description | Context window | Max output tokens | Training data (up to) |
| --- | --- | --- | --- | --- |
| `gpt-6.1-sol` (2026-09-29) | Reasoning · Responses API · Multi-agent orchestration (preview) · Chat Completions API · Streaming · Structured outputs · Text and image input with text output · Functions, tools, and parallel tool calling (Responses API only) · Reasoning effort and verbosity · Computer use | 1,050,000 (Input: 922,000 / Output: 128,000) | 128,000 | April 2026 |
| **`gpt-6.1-terra` (2026-10-26)** | Reasoning · Responses API · Multi-agent orchestration (preview) · Chat Completions API · Structured outputs · Text and image processing · Functions, tools, and parallel tool calling · Computer use | 1,050,000 (Input: 922,000 / Output: 128,000) | 128,000 | **June 2026** |

Azure dates the model `2026-10-26`, matching OpenAI's changelog, and states the same 1,050,000
context, 922,000 input, 128,000 output figures as the vendor
([model page](../../openai.com/gpt-6-1-terra-model-page/2026-10-26.md)). Its "training data
(up to)" of **June 2026** agrees with OpenAI's "Jun 01, 2026 knowledge cutoff".

Two differences from the Sol row are worth noting: Azure lists **Streaming** for Sol but not
for Terra, and lists "Text and image **input with text output**" for Sol against "Text and
image **processing**" for Terra. Whether Terra lacks streaming or Azure's row is simply less
complete is unresolved — OpenAI's model page lists `streaming` as a supported feature for
Terra.

Azure also documents multi-agent orchestration as **preview** for both 6.1 models, whereas
OpenAI's own guide lists it as an inherited GPT-5.6 capability without a preview label.

## Summary

Azure confirms Terra's identity, its 2026-10-26 date, its full context/output limits, its June
2026 training cutoff, and that it is sold as a first-class Azure OpenAI model rather than a
partner-hosted one. It also shows the GPT-6.1 series as a two-model family on Azure and
independently corroborates the June cutoff that distinguishes Terra from Sol's April cutoff.

## Gaps

- **No prices.** The capability table has no pricing columns; Azure's separate pricing page is

  page that was not captured.

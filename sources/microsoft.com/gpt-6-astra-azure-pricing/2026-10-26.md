## What this establishes

- Azure bills Astra on the **same four axes as OpenAI** — short vs long context, cached
  input, cache writes — and adds **deployment geography as a price axis** (Global vs Data
  Zone), which the first-party OpenAI page does not expose.
- **Flex pricing exists only for the long-context Global row** in this capture; the
  short-context rows show N/A for Flex. Priority Processing is N/A across all four Astra
  rows, so Astra has no priority tier on Azure.
- Provisioned throughput (PTU) is offered with a 15-PTU minimum for short-context Global
  and Data Zone.

## What this does not establish

- **No Azure price comparison is possible from this record.** The `$-` placeholders mean
  the capture cannot support any claim about an Azure premium or discount versus OpenAI's
  $10/$50. Anyone asserting parity would be guessing.

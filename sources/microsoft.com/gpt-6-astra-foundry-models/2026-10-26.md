## What this establishes

- A second, Microsoft-operated endpoint serves the same model ID with the same limits —
  the model is not OpenAI-API-exclusive.
- The release date 2026-09-03 is corroborated by a host that dates model *versions*, not
  just releases.
- Azure adds an inference-time safety layer on top of OpenAI's own, so "GPT-6 Astra on
  Azure" is not byte-identical in behaviour to the OpenAI API.
- Quota is not automatic below tier 5, and short/long context are separate price
  categories, as on the first-party page.

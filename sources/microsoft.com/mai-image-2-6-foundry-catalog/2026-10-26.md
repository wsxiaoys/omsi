## Summary

The catalogue confirms the deployment identity used by every Azure call: model name
`MAI-Image-2.6`, **version `2026-07-31`**, lifecycle **Preview**, sold "Direct from Azure" (i.e.
billed by Microsoft, not a partner marketplace listing). The 4096-output-token limit is the only
place the output token budget is stated.

The version string (2026-07-31) predates the model card's release date (2026-08-14), so the version
is best read as a build/snapshot label rather than a launch date.

# Project page `microsoft.github.io/TRELLIS.2` — marketing claims, author affiliations, research-use disclaimer

- Origin: Microsoft Research project page <https://microsoft.github.io/TRELLIS.2/> ("TRELLIS.2: Native and
  Compact Structured Latents for 3D Generation"), page footer "© 2025 Microsoft"
- Evidence kind: official documentation (developer marketing page)
- Publication date: not stated on the page; the page first went live with the paper release (repository
  commit "Fix website url", 2025-12-16, and "update paper link", 2025-12-17)
- Capture date: 2026-10-26
- Relevant models: TRELLIS.2 (4B image-to-3D)

## Headline claims (verbatim)

> An open-source **4B-parameter** image-to-3D model producing **up to 1536³ PBR textured assets**, built on
> **native 3D VAEs** with **16× spatial compression**, delivering **efficient, scalable, high-fidelity** asset
> generation.

Speed tiles: "3s (2s+1s) 512³ resolution", "17s (10s+7s) 1024³ resolution", "60s (35s+25s) 1536³
resolution", footnote "\* Total generation time (shape + material). \*\* Tested with NVIDIA H100 GPU."

Other verbatim claims: "arbitrary surface attributes such as Base Color, Roughness, Metallic, and Opacity
(i.e., Transparency or Alpha channel), enabling Physically Based Rendering (PBR) and photorealistic
relighting"; "< 10s on single CPU — Textured Mesh → O-Voxel"; "< 100ms with CUDA acceleration — O-Voxel →
Textured Mesh"; "16× Downsampling, ~9.6K Latent Tokens for 1024³".

## Contradiction to preserve

The same project states two different things about commercial use:

- Repository and model card: "This model and code are released under the **MIT License**"
  ([repo](../../github.com/trellis-2-repo/2026-10-26.md),
  [model card](../../huggingface.co/trellis-2-4b-model-card/2026-10-26.md)), and MIT permits commercial use.
- Project page: "These materials are not intended for commercial exploitation or use", and "TRELLIS.2 is
  purely a research project".

The disclaimer is scoped to "the materials made available on this page" (videos, images, demos), which is a
plausible reading that reconciles the two, but neither Microsoft page says so. The MIT `LICENSE` file in the
repository is the operative grant for code and weights; the project page is the only Microsoft statement that
mentions research-only use.

## Gaps

- No licence link, no terms of use and no moderation or content-policy statement beyond the disclaimer above.
- No changelog, no version label and no publication date on the page itself.
- The page says "open-source" but does not name the dataset licence; the repository says code and dataset are
  released, and the dataset itself (TRELLIS-500K-derived, PBR-filtered) was not captured.

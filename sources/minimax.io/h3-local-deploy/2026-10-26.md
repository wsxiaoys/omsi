## Deployment facts (verbatim)

> MiniMax H3-Base jointly generates 768p video and synchronized stereo audio.

| Field | Value |
| --- | --- |
| Model | [`MiniMaxAI/MiniMax-H3`](https://huggingface.co/MiniMaxAI/MiniMax-H3), revision `42ed227ee7df40d41602854ae760620d6eb651fe` |
| SGLang deployment status | **Preview** — H3 support ships in SGLang v0.5.17 and later |
| ComfyUI support | Native T2V, I2V, and R2V templates in ComfyUI `0.30.0` or later; uses converted Comfy-Org weights |
| SGLang Quickstart checkpoint | FL2VA, official mixed BF16/FP32 weights |
| SGLang Quickstart hardware | One node with 8 × NVIDIA B200, Ulysses degree 8 |
| Local disk | Exact requirement not published; the upstream cookbook reports approximately **108 GB** of model weights |

> The ComfyUI templates use pruned and quantized files from
> [`Comfy-Org/MiniMax-H3`](https://huggingface.co/Comfy-Org/MiniMax-H3), including INT8/NVFP4
> components. They are different artifacts from the official mixed BF16/FP32 H3 checkpoint used by
> the SGLang baseline. Output quality, memory use, and reproducibility can differ; do not mix
> benchmark claims between the two paths.

Named weight files include `minimax_h3_fl2va_pruned_int8_convrot.safetensors`,
`minimax_h3_ref2va_pruned_int8_convrot.safetensors`, `qwen3vl_32b_minimax_h3_nvfp4_awq.safetensors`
(text encoder), `minimax_h3_video_vae_fp16.safetensors`, `minimax_h3_audio_vae_fp32.safetensors`.

## What this establishes

- **H3 has downloadable weights and a named community licence**, with a documented, non-trivial
  territory restriction. Weights are ~108 GB; the reference deployment is 8×B200; SGLang support is
  explicitly "Preview" and not a stable contract.
- Two different artifact families exist (official BF16/FP32 vs Comfy-Org INT8/NVFP4), and the
  vendor warns they are not numerically comparable.
- **No equivalent self-host path is documented for H3 Max.** H3 Max is not mentioned on this page,
  no weights repository for it exists (see `../../huggingface.co/minimax-h3-model-card/2026-10-26.md`),
  and every host and vendor route to it is an API.

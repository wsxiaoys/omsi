# MiniMax launch post: MiniMax M3 ("Frontier Model")

- Origin: MiniMax, research/blog post "MiniMax M3", <https://www.minimax.io/blog/minimax-m3>,
  dated 2026-06-01 and linked from MiniMax's model changelog entry for the same date.
- Evidence kind: official documentation (vendor launch announcement and vendor benchmark
  claims).
- Publication date: **2026-06-01**.
- Capture date: 2026-10-26
- Relevant models: MiniMax-M3 (predecessor of MiniMax-M3.1-Flash).
- Capture type: rendered page text; benchmark tables are text on this page, the illustrated
  charts are images and were not extracted.

## Captured content

Opening, verbatim:

> MiniMax M3 is officially released today.
>
> M3 reaches frontier-level performance on specialized tasks such as coding and agentic work. It
> uses MSA (MiniMax Sparse Attention), a new attention architecture proposed by our team, and
> supports ultra-long context windows of up to 1M tokens. To much anticipation, it is also a
> natively multimodal model that supports image and video input and can operate a desktop
> computer.
>
> These three capabilities are now table stakes for closed-source frontier models. M3 is
> currently the first and only open-weight model to bring all three together.

MSA, verbatim excerpts:

> MSA is a clean and easily extensible new sparse attention architecture. It gives M3 a 1M
> context window and makes context truly another dimension that can be scaled.
>
> […] at a context length of 1 million, M3's per-token compute is just 1/20 that of the
> previous-generation model. We achieved a speed up of more than 9× in the prefilling stage and
> more than 15x in the decoding stage.

Coding and agentic results, verbatim list: "SWE-Bench Pro: 59.0%", "Terminal-Bench 2.1:
66.0%", "SWE-fficiency: 34.8%", "KernelBench Hard: 28.8%", "MCP Atlas: 74.2%".

Long-context and multimodality claims on the same page include an autonomous 12-hour ICLR paper
reproduction ("18 commits and 23 experimental figures") and a CUDA kernel optimisation run
("147 Iterations, 9.4× Speedup"), both vendor anecdotes rather than benchmark rows.

The page ends with a long "Evaluation Notes" appendix giving per-benchmark harness conditions
(e.g. VideoMMMU "max 512 frames", Video-MME "1 FPS, max 1024 frames", MCP Atlas scored with
"Gemini 2.5 Pro as scoring model").

## Summary

- M3 is the predecessor: released **2026-06-01**, same 1M context, same native multimodality,
  same MSA attention family, and the vendor's first claim to "the first and only open-weight
  model" with coding + 1M context + multimodality.
- M3's benchmark slate is a **different benchmark set** from M3.1 Flash's (SWE-Bench Pro,
  Terminal-Bench 2.1, MCP Atlas vs BankerToolBench, DeepSWE v1.1, OSWorld V2, ALE, CyberGym),
  so the two launch posts' numbers are not directly comparable.
- The vendor describes M3 as open-weight; the weights are on Hugging Face
  ([M3 model card](../../huggingface.co/minimax-m3-model-card/2026-10-26.md)).

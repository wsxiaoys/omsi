# MiniMax launch post: "MiniMax M3.1 Flash: Redefining Agent Performance and Cost"

- Origin: MiniMax, research/blog post "MiniMax M3.1 Flash: Redefining Agent Performance and
  Cost", <https://www.minimax.io/blog/minimax-m31f>. Linked as the release announcement from
  MiniMax's own model changelog and from the `text-generation` API guide.
- Evidence kind: official documentation (vendor launch announcement and vendor benchmark
  claims).
- Publication date: **2026-10-19** (printed under the headline, beside the tags "AI",
  "M3.1 Flash").
- Capture date: 2026-10-26
- Relevant models: MiniMax M3.1 Flash (`MiniMax-M3.1-Flash`); mentions M3 as predecessor.
- Capture type: rendered page text; the benchmark charts are images and were **not**
  extracted, so only figures quoted in prose are captured.

## Summary

- This is the canonical first-party identity document: name, release date **2026-10-19**,
  price ($0.15 / $0.60 / $0.015 per M tokens, flat), and the vendor's own benchmark figures.
- Five vendor benchmark numbers are stated in prose: BankerToolBench 76.2, DeepSWE v1.1 73.7%,
  OSWorld V2 61.7, Agents' Last Exam 29.6, CyberGym 82%.
- The post frames M3.1 Flash as an efficiency play: "nearly three times faster" inference and
  "70% lower" usage cost than "its predecessor" (M3), with "more aggressive sparsity" as the
  mechanism.
- The **weights statement is forward-looking** ("will be released later") even though a
  Hugging Face repository for the model already existed on 2026-10-17, two days before this
  post. See the [model card record](../../huggingface.co/minimax-m3.1-flash-model-card/2026-10-26.md).
- "Space Bunny" is presented as a pre-release anonymous deployment of M3.1 Flash. That is a
  vendor claim about provenance, not a measurement.

## Gaps

- The four benchmark charts are images (`m31-flash-en-2` … `m31-flash-en-5`) and were not
  transcribed; comparator columns (DeepSeek V4.1 Flash-1017, Kimi K3, GLM-5.3, GPT-5.6 Sol,
  Opus 5) exist only in those images and in the Hugging Face card's HTML table.
- No harness, no context length, no effort setting and no sample count are stated for the
  prose numbers. The card supplies some of this; see
  [model card](../../huggingface.co/minimax-m3.1-flash-model-card/2026-10-26.md).
- No parameter count, no architecture detail beyond "more aggressive sparsity", no licence, no
  rate limits, no deprecation or support-window statement.
- "70% lower usage cost" is not defined (per token? per task? at which effort?), and it is not
  consistent with the published list price alone: M3 lists at $0.30/$1.20 (already 50% off) to
  M3.1 Flash's $0.15/$0.60, i.e. 50% cheaper per token, so the 70% figure must include
  token-count effects at a fixed task set.

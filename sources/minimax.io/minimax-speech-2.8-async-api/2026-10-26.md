## Two input paths with different ceilings (verbatim)

> `text`: Text content to convert to audio, max length **50,000 characters**. Mutually exclusive with
> `text_file_id` (one is required).

> `text_file_id`: ID of the text file to synthesize. Max **1,000,000 characters**. Supported formats:
> **txt, zip**. Mutually exclusive with `text` (one is required).

The async guide summarises the same limit at the top of the page: "a maximum limit of 1M characters
per request for text input."

## Interjections on this route (verbatim)

> **Interjection tags**: Only supported when using `speech-2.8-hd` or `speech-2.8-turbo` models.
> Supported interjections: `(laughs)`, `(chuckle)`, `(coughs)`, `(clear-throat)`, `(groans)`,
> `(breath)`, `(pant)`, `(inhale)`, `(exhale)`, `(gasps)`, `(sniffs)`, `(sighs)`, `(snorts)`,
> `(burps)`, `(lip-smacking)`, `(humming)`, `(hissing)`, `(emm)`, `(whistles)`, `(sneezes)`,
> `(crying)`, `(applause)`.

**22 tags** — the same list as the voice-clone reference, and three more than the synchronous T2A
reference. So the vendor's counts are: sync 19, async 22, clone 22.

## Audio settings (verbatim, differences from sync)

> `audio_sample_rate`: … Supported values: [`8000`, `16000`, `22050`, `24000`, `32000`, `44100`].
> Note: When the output format is `opus`, only [`8000`, `12000`, `16000`, `24000`, `48000`] are
> supported. Using other sample rates with `opus` format will cause the task to fail.

> `format`: Supported values: [`mp3`, `pcm`, `flac`, `wav`, `pcmu_raw`, `pcmu_wav`, `opus`]. … `opus`
> is Ogg/Opus encoded and only supports sample rates [`8000`, `12000`, `16000`, `24000`, `48000`].

> `channel`: … default: `2`

> `bitrate`: [`32000`, `64000`, `128000`, `256000`] … only applies to audio in `mp3` format.

Same seven formats as sync, but **the async default channel is stereo (2)**, not mono, and Opus
accepts a different sample-rate set (12000 and 48000 are Opus-only; 44100 is invalid with Opus).

## Retrieval and billing (verbatim)

> The download URL is valid for **9 hours (32,400 seconds)** from the time it is generated. After
> expiration, the file will no longer be available and the generated data will be lost …

> `usage_characters`: Number of billed characters

Error codes include `1042` ("More than 10% invalid characters") and `2013` ("Invalid input format").

## What this establishes

- **The real long-form ceiling is 50,000 characters of inline text.** The headline "1M characters"
  figure applies only to a `txt`/`zip` file uploaded first and passed as `text_file_id`. A pipeline
  sized on the marketing number will fail if it posts the text inline.
- **Async is the only route above the sync 10,000-character limit**, and it is priced identically
  ($100/M for HD).
- **Output is not returned inline.** Async returns a `file_id`; the audio must be fetched within
  9 hours or it is lost.
- The interjection list on this route matches the voice-clone page (22), which makes the synchronous
  reference's 19-tag list the outlier rather than a general rule.
- Async is also where stereo is the default, so a caller who never sets `channel` gets different
  audio geometry on async and sync for the same script.

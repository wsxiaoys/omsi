## What this establishes

- **There is no release-note entry for MiniMax H3 Max anywhere in the changelog**, including in the
  Aug–Oct 2026 range where the model first appears on hosts. The only H3-family launch date the
  vendor publishes is **2026-07-31, for H3**.
- H3's lineage is Hailuo 02 (2025-06-18) → Hailuo 2.3 (2025-10-28) → H3 (2026-07-31). The V2 video
  API is labelled "Hailuo-03", so H3 is the third Hailuo generation.
- H3 is described as "open", consistent with the published weights (see
  `../../huggingface.co/minimax-h3-model-card/2026-10-26.md`).

## Gaps

- The changelog is not a complete model list: H3 Max, H3-Highspeed, H3-Lite and H3-Regeneration all
  exist in the API and price list without changelog entries. Absence of an entry is therefore weak
  evidence about launch date, and is recorded here only as a gap in vendor disclosure.

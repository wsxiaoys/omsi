# MiniMax API Docs: Music Generation API reference (`POST /v1/music_generation`)

- Origin: MiniMax, "Music Generation" API reference (embedded OpenAPI 3.1 document),
  <https://platform.minimax.io/docs/api-reference/music-generation>
- Evidence kind: official documentation (API schema, field limits, example response)
- Publication date: not stated; live reference, `info.version: 1.0.0`. Capture date 2026-10-26
- Capture date: 2026-10-26
- Relevant models: `music-2.6` (and `music-3.0`, `music-cover`, and their `-free` variants)

## `model` enum (verbatim)

> - `music-3.0` (recommended): Text-to-music generation. Rate limit: 120 RPM.
> - `music-2.6`: Previous-generation text-to-music model. Rate limit: 120 RPM.
> - `music-cover`: Cover generation from a reference audio. Rate limit: 120 RPM.
> - `music-3.0-free`: Free-tier version of `music-3.0`. Rate limit: 3 RPM.
> - `music-2.6-free`: Free-tier version of `music-2.6`. Rate limit: 3 RPM.
> - `music-cover-free`: Free-tier version of `music-cover`. Rate limit: 3 RPM.

`music` is the only required field. The reference calls Music 3.0 "recommended" and Music 2.6
"Previous-generation".

## Request fields

| Field | Type / limits | Default | Notes (verbatim where quoted) |
| --- | --- | --- | --- |
| `model` | enum, 6 values (above) | — | required |
| `prompt` | string, `maxLength` 2000 | — | "A description of the music, specifying style, mood, and scenario." For `music-2.6`: required (1–2000 chars) when `is_instrumental: true`, optional (0–2000) otherwise. For `music-cover`: required, 10–300 characters. |
| `lyrics` | string, `minLength` 1, `maxLength` 3500 | — | "Use `\n` to separate lines." Structure tags: `[Intro]`, `[Verse]`, `[Pre Chorus]`, `[Chorus]`, `[Interlude]`, `[Bridge]`, `[Outro]`, `[Post Chorus]`, `[Transition]`, `[Break]`, `[Hook]`, `[Build Up]`, `[Inst]`, `[Solo]`. Required (1–3500) for `music-2.6` when not instrumental. |
| `stream` | boolean | false | "Whether to use streaming output." |
| `output_format` | `url` / `hex` | `hex` | "When `stream` is `true`, only `hex` is supported." ⚠️ "`url` links expire after 24 hours, so download promptly." |
| `audio_setting` | object | — | see below |
| `lyrics_optimizer` | boolean | false | "Only supported on `music-3.0` / `music-3.0-free` / `music-2.6` / `music-2.6-free`." Auto-generates lyrics from `prompt` when `lyrics` is empty. |
| `is_instrumental` | boolean | false | Same model restriction; "When set to `true`, the `lyrics` field is not required." |
| `audio_url` / `audio_base64` / `cover_feature_id` | — | — | **`music-cover` only**; mutually exclusive with each other. Reference audio: 6 s – 6 min, ≤ 50 MB, mp3/wav/flac etc. |

`audio_setting`: `sample_rate` ∈ {16000, 24000, 32000, 44100}; `bitrate` ∈ {32000, 64000, 128000,
256000}; `format` ∈ {mp3, wav, pcm}. No defaults are stated in the reference; the guide's examples use
44100 / 256000 / mp3.

## Response

`data.status` (1 = in progress, 2 = completed), `data.audio` (hex when `output_format: hex`), and
`extra_info`. The reference's example response carries:

```json
"extra_info": {
  "music_duration": 25364,
  "music_sample_rate": 44100,
  "music_channel": 2,
  "bitrate": 256000,
  "music_size": 813651
}
```

So the documented output is **stereo (2 channels)** and the duration is reported in milliseconds —
25,364 ms ≈ 25 s for the example track.

## Errors

`1002` rate limit, `1008` insufficient balance, `1026` "Content flagged for sensitive material",
`2013` invalid parameters, `2049` invalid API key. Security: HTTP Bearer API key.

## What this establishes

- `music-2.6` and `music-3.0` share one schema, one price band and one rate limit (120 RPM paid,
  3 RPM free); the vendor's own distinction between them is ordinal ("recommended" vs
  "previous-generation"), not a capability flag.
- The API exposes **no duration control and no seed**. Song length is not a request parameter.
- Cover is a separate `model` value; `music-2.6` cannot take `audio_url`/`cover_feature_id` per this
  schema.
- Output is 16–44.1 kHz, 32–256 kbps, mp3/wav/pcm, stereo.

## Gaps

- No maximum or minimum song duration is stated anywhere in the reference.
- No language parameter and no language list for sung vocals.
- No statement of what `music_duration` bounds the model to, or whether a request can fail for
  length.
- The reference does not say whether `music-2.6` is still callable for non-grandfathered accounts
  (the guide's notice and the model list disagree in emphasis — see the wiki page).

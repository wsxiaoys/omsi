# MiniMax API Docs: Video Generation guide (H3 vs H3 Max)

- Origin: MiniMax, "Video Generation", <https://platform.minimax.io/docs/guides/video-generation>
- Evidence kind: official documentation (vendor capability guide, output specs, input limits)
- Publication date: not stated; live guide. Capture date 2026-10-26.
- Capture date: 2026-10-26
- Relevant models: MiniMax H3, MiniMax H3 Max

## Model descriptions (verbatim)

> MiniMax currently offers two video generation models — **MiniMax H3** and **MiniMax H3 Max**:
>
> * **MiniMax H3**: an open, general-purpose multimodal video model. It understands text, image,
>   video, and audio inputs in a unified way, and supports video generation, reference-based
>   creation, and video editing.
> * **MiniMax H3 Max**: jointly released by MiniMax and [fal.ai](https://fal.ai/); a video
>   generation model post-trained by fal.ai on MiniMax H3 and optimized for high-speed generation.
>   It delivers mainstream 480P and 768P output and generates faster than MiniMax H3. It supports
>   T2V (Text-to-Video), I2V (Image-to-Video), and Reference Generation.

> Note: To use MiniMax H3 or MiniMax H3 Max, please select the
> [Pay-as-you-go API](https://platform.minimax.io/docs/pricing/overview.md#models/video).

## Output specs (verbatim table)

| Item | MiniMax H3 | MiniMax H3 Max |
| --- | --- | --- |
| Model name | `MiniMax-H3` | `MiniMax-H3-Max` |
| Output resolution | 768P / 2K | 480P / 768P |
| Output duration | 4–15 seconds, integer values only | 5–15 seconds, integer values only |
| Aspect ratio | Common ratios supported, or adaptive | Common ratios supported, or adaptive |

## Input requirements (verbatim, shared by both models)

| Item | Requirement |
| --- | --- |
| First/last-frame entry | Images: 0, 1, or 2; width/height in [256, 5760]; aspect ratio in 2:5 – 5:2 |
| | With no image input, this becomes Text-to-Video |
| Reference entry | Images: ≤ 9; width/height in [256, 5760]; aspect ratio in 2:5 – 5:2 |
| | Videos: ≤ 3 clips; per-clip duration [2, 15] s; total duration ≤ 15 s; width/height in [256, 5760]; aspect ratio in 2:5 – 5:2 |
| | Audio: ≤ 3 clips; per-clip duration [2, 15] s; total duration ≤ 15 s |
| | Mixed input is capped at 12 files in total |
| | With no image, video, or audio input, this becomes Text-to-Video |
| Supported input formats | Video: H.264/AVC, H.265/HEVC; in-video audio: AAC, MP3 |
| | Image: JPG, JPEG, PNG, WEBP, HEIC, HEIF |
| | Audio: WAV, MP3 |
| File size limits | Video ≤ 50 MB per file; image ≤ 30 MB per file; audio ≤ 15 MB per file |
| | API request body ≤ 64 MB (URL input is recommended for large assets) |
| Prompt length limit | ≤ 7000 characters |

## Workflow

Asynchronous: `POST /v2/video_generation` returns a `task_id`; poll
`GET /v2/query/video_generation/{task_id}` (vendor recommends a 10-second interval) until
`status == "succeeded"`, then download `task.content.url`. Terminal failure states are `failed`
and `cancelled`.

The code samples use `BASE_URL = "https://api.minimax.io"` and `MODEL = "MiniMax-H3"`; the four
sample functions cover t2va, i2va, first+last frame, and r2va. For t2va, `ratio` is required and
cannot be `adaptive`; for i2va the ratio follows the input image.

## What this establishes

- H3 Max is described as **"jointly released by MiniMax and fal.ai"** and "post-trained by fal.ai
  on MiniMax H3". MiniMax thus endorses the derivative and treats it as one of its two video
  models, not as an unaffiliated host fork.
- The vendor states the purpose directly: "optimized for high-speed generation… generates faster
  than MiniMax H3". No quality claim is made for H3 Max here; the words "premium", "flagship" and
  "higher quality" do not appear in this guide.
- H3 Max is a **strict subset of H3's envelope** on the vendor API: same input limits and prompt
  length, but 480P/768P instead of 768P/2K, and a 5-second floor instead of 4.
- Reference Generation *is* listed for H3 Max in this guide (with the same ≤ 9 images / ≤ 3 videos
  / ≤ 3 audio / 12-file cap), contradicting the models-overview page, which lists only T2V and
  I2V for H3 Max.

## Gaps

- No frame rate, audio channel count, or sample rate on this page.
- No latency figure behind "generates faster" — no seconds-per-clip, no throughput ratio.
- No statement of which H3 checkpoint H3 Max was post-trained from.
- No moderation policy beyond the API-level `failed` state.

# Mistral API reference: POST /v1/audio/speech

- Origin: Mistral AI, "Audio Speech — Speech", API Reference, <https://docs.mistral.ai/api/endpoint/audio/speech>
- Evidence kind: official vendor API schema (first-party)
- Publication date: none stated; live page
- Capture date: 2026-10-26
- Relevant models: Voxtral TTS 3 (`voxtral-mini-tts-3-0`)
- Capture type: rendered API reference page, request/response fields transcribed

## Verbatim

> "API for speech generation."

Request body (`application/json`):

| Field | Type | Note |
| --- | --- | --- |
| `input` | `string` (required) | "Text to generate a speech from" |
| `metadata` | `map<any> \| null` | — |
| `model` | `string \| null` | no enum, no default printed |
| `phoneme_hints` | `map<array<"a" \| "aɪ" \| … \| "θ">> \| null` | "Optional pronunciation hints mapping a (case-sensitive) word to its ordered list of IPA phones." |
| `prompt_cache_key` | `string \| null` | — |
| `ref_audio` | `string \| null` | "The audio reference for generating the speech." |
| `response_format` | `"pcm" \| "wav" \| "mp3" \| "flac" \| "opus"` | — |
| `stream` | `boolean` | "Default Value: false" |
| `voice_id` | `string \| null` | "The preset or custom voice to use for generating the speech." |
| `AdditionalProperties` | `map<any>` | — |

Responses: `200 (application/json)` → `{ "audio_data": "<base64>" }`; `200 (text/event-stream)` →
`SpeechStreamEvents`.

## Summary

The schema is the strongest negative evidence on length: `input` is a bare `string` with no
`maxLength`, no `pattern`, and no documented ceiling, while every constrained field on the same
schema (`response_format`, phoneme values) is enumerated. A hard character cap would show up here.

It also shows two documented-in-prose fields missing from the schema: `expressiveness` and
`instruction`/`conversation_history` do not appear in the request body, though the guides use them
(the guides pass them through `additional_properties`).

`prompt_cache_key` exists on a TTS endpoint, which is the only hint of any caching concept in the
speech API.

## Gaps

- The schema gives no default `model`, so it does not pin which model an omitted field selects.
- No rate-limit, quota or size annotations.
- `AdditionalProperties` makes the real accepted field set unknowable from the schema alone.

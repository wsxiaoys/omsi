## Usage example, verbatim (Python)

```python
response = client.chat.complete(
    model="mistral-large-4",
    messages=[{"role": "user", "content": "Write a Python function to merge two sorted linked lists into one sorted list."}],
    reasoning_effort="high",
)
```

The page states: "Send a request to the Chat Completions API with the `mistral-large-4` model
name." The curl example posts to `https://api.mistral.ai/v1/chat/completions`.

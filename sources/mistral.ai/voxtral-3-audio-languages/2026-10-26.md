## Supported languages by model, verbatim

| Model | Capability | Supported languages |
| --- | --- | --- |
| `voxtral-mini-transcribe-3-0` | File transcription | 50 languages |
| `voxtral-small-transcribe-3-0` | File transcription | 50 languages |
| `voxtral-mini-transcribe-realtime-3-0` | Realtime transcription | 45 languages and dialects |
| `voxtral-mini-tts-3-0` | Speech generation | 35 languages, 50+ dialects |

> "Each model has its own list of supported languages"

File transcription language handling, verbatim: "`language`, a two-letter ISO 639-1 code such as `fr`.
Any other value returns a `422` error." — and "Without a language … The model detects the language of
the recording."

## Reading

- **The page states counts, not lists.** Only the TTS section enumerates its languages (35 rows with
  ISO codes and preset-voice counts); the 50 transcription languages are never named. The launch post
  gives the only description of the set — "50, including 24 official EU languages and many
  low-resource Asian and Indic languages" (`../../mistral.ai/voxtral-3-launch/2026-10-26.md`).
- **Counts disagree across first-party pages**: 50 for both offline models here; "50+" in the launch
  post and the audio overview; 45 "languages and dialects" for realtime here versus "over 35
  languages" in the launch post's realtime section.
- Both offline tiers claim the same 50 languages, so language coverage does not separate Small from
  Mini.

## Gaps

- No language list for transcription, no per-language accuracy, no statement of whether the 50 are
  the same 50 for Small and Mini.

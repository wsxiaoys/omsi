# Mistral docs — Speech to Text overview (Voxtral 3)

- Origin: "Speech to Text", Mistral AI documentation,
  <https://docs.mistral.ai/studio/audio/speech-to-text/overview>. Retrieved 2026-10-26.
- Evidence kind: official vendor documentation (first-party).
- Publication date: none stated; live page.
- Capture date: 2026-10-26
- Relevant models: Voxtral Mini Transcribe 3, Voxtral Small Transcribe 3, Voxtral Mini
  Transcribe Realtime 3 (and `voxtral-small-latest`, i.e. Voxtral 2, for audio in chat).
- Capture type: rendered page text.

## Verbatim

> "Speech to text turns recorded files and live audio into text, with speaker labels, timestamps, and
> custom vocabulary."

Model choice table, verbatim:

| If you need | Use | Why |
| --- | --- | --- |
| Text while people speak | Voxtral Mini Transcribe Realtime 3 | It's the realtime model: sessions, turn detection, and a streaming delay that you set. |
| Transcripts of recorded files | Voxtral Mini Transcribe 3 | It supports every offline feature. Start with it. |
| Higher-quality transcripts of recorded files | Voxtral Small Transcribe 3 | A larger model. Switch to it when the transcripts still have errors that custom vocabulary doesn't fix. |
| Answers about a recording, such as a summary or a translation | Audio in chat completions | A chat model that hears the audio and answers in text. At launch, use `voxtral-small-latest` (Voxtral 2). |

> "Once you know the mode, the model is a small choice: realtime has one model, and offline has two."

Features by mode, verbatim:

| Feature | Offline | Realtime |
| --- | --- | --- |
| Speaker labels (diarization) | Yes, with segment timestamps | Yes |
| Speaker references | | Yes, with diarization |
| Context biasing | Yes | Yes |
| Language | Pin it, or let the model detect it | Pin it in the session configuration, or let the model detect it |
| Segment timestamps | Yes, per segment. Word timestamps aren't available. | No: realtime segments carry a speaker label, but no start or end time. |
| Turn detection | No | Yes |
| Streaming response | Yes: the text of a complete file arrives in pieces | Not applicable: results always arrive as events |

> "Diarization and turn detection can't share a realtime session: a session that sets both returns an
> error."

## Reading

- **Word timestamps are gone in Voxtral 3** — segment granularity only, stated twice on this page.
  Voxtral Transcribe 2 offered word-level timestamps.
- **Summaries and translations are not a Transcribe 3 feature at launch**: the docs route them to
  audio-in-chat, which still uses `voxtral-small-latest` (Voxtral 2). This is the second first-party
  statement against the Small card's "translation, speech Q&A, summarization, and function calling".
- Speaker references are realtime-only; offline diarization is labels plus segment times.

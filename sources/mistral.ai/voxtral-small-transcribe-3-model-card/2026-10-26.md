## Reading

- **Preview, not GA**: "Public Preview" is a lifecycle stage Mistral defines as "Near-final before
  General Availability" with silent updates allowed and no guaranteed path to GA
  (`../../mistral.ai/model-lifecycle-policy/2026-10-26.md`).
- **No licence is named** and the payload's `licenses` array is empty, so the card gives no weight
  or licence claim for a transcription model.
- **The description overstates the launch scope.** It claims translation, speech Q&A, summarization
  and function calling; the docs' own model table says "Transcription only at launch" and the STT
  overview routes summarization/translation to `voxtral-small-latest` (Voxtral 2)
  (`../../mistral.ai/voxtral-3-audio-overview/2026-10-26.md`,
  `../../mistral.ai/voxtral-3-speech-to-text-overview/2026-10-26.md`). Treat the description as
  marketing copy for the family.
- **Card context is 32k, docs say 65,536 tokens** shared by audio and `context_bias`. Not reconciled
  by any captured page.
- The "SOTA … outperforming" sentence is an unsourced comparative claim; no numbers appear on the
  card. Numbers exist only in the launch post and in Artificial Analysis.

The page also carries a "Regional inference / Standard / Batch / Priority" control and a USD/EUR
toggle; only the default view was captured.

Marketing FAQ on the same day, from <https://mistral.ai/pricing/>:

> "A few APIs are priced differently: OCR is per 1,000 pages, speech models are per minute, and tool
> APIs are priced per call."

That FAQ sentence is wrong for TTS: both the docs schedule above and the launch post bill TTS per
1M characters, and only the transcription models are per minute.

## Summary

The canonical price schedule: **Voxtral TTS 3 at $13 per 1M characters**, against **$16 per 1M
characters** for the previous Voxtral TTS — a 19% cut for the successor. Billing is per input
character; output is unpriced ("—").

The "Cached input" column reproduces a 10× discount for every audio row, including per-minute
transcription rows, where a cache has no meaning. It is treated here as a template artefact, not a
second real price.

## Gaps

- The page does not define what counts as a character (whitespace, tags, punctuation).
- No statement of whether emotion/pace tags in `input` are billed.
- Whether the Batch column halves the per-character rate, as the marketing FAQ implies for token
  models, is not visible in the captured default view.

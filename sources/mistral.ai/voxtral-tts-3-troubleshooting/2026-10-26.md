- Evidence kind: official vendor documentation (first-party)
- Publication date: none stated; live page

## Verbatim

Speech request errors:

| Error | Cause | Fix |
| --- | --- | --- |
| 404 "Voice 'x' not found." | "The voice_id doesn't match a preset voice or a voice saved in your workspace." | list voices, copy exact slug or ID |
| 400 "Either ref_audio or voice must be provided." | "The request has no voice." | "Add voice_id." |
| 422 "Extra inputs are not permitted" | "A misspelled or unknown field name, such as instructions instead of instruction." | check the field name |
| 422 | "The value is out of range." | "Use a value from 1.0 to 5.0." |
| 422, list of accepted phonemes | "A phoneme in phoneme_hints isn't in the accepted list." | replace it |
| 422 `string_type` | "instruction isn't a string." | send as text |
| — | "Style instructions are not available at launch. The instruction is over the length limit. It isn't shortened for you." | "Shorten the instruction." |
| 400 "Failed to load audio file." | "The ref_audio recording is a URL, or not an MP3 or WAV file." | send base64 MP3/WAV |

Emotion and delivery:

> "A tag has no audible effect — The tag value isn't in the supported list. The API doesn't reject it,
> and the tag isn't spoken."

> "The audio stops after the first part of a sentence that has an emotion tag — A tag before a long
> sentence can end the audio early, at a comma. Keep tagged sentences short, or split a long sentence
> in two."

Slow first audio: "A speech request returns the audio once all of it is generated. Stream the
response, and play each chunk as it arrives. The total time stays the same."

Cloned voices: "Each request clones from the clip it receives, so a different clip gives a different
voice. Save the voice once, and pass its ID in every request."

## Summary

Two operational facts that no other page states: an **unsupported tag value is silently ignored** (no
error, no effect), and **a tag placed before a long sentence can truncate the audio at a comma** — a
reported failure mode of inline control.

The error table also implies a length limit exists for `instruction` ("over the length limit … isn't
shortened for you") with no number given, while style instructions remain unavailable at launch.

## Gaps

- No numeric instruction length limit.
- No error or guidance for over-long `input`.
- No refusals, content-policy or safety errors are listed on this page.

### Voice management

> "A preset voice has a slug, such as gb_jane_neutral or voice_478. A voice saved in your workspace
> has no slug: use the ID that the API returns when you create it. If the ID doesn't match any voice,
> the request fails with a 404 error."

> "Saved voices carry a retention_notice field (default 30 days, min 1, max 365). Set it when
> creating or updating a voice via the API. Voices created from the AI Studio UI default to 30 days."

> "Saved voices can be shared within your workspace. Sharing is managed in AI Studio: workspace
> admins control whether a voice is private or shared with the workspace. The sharing_scope field in
> the voice list response indicates the current scope (private, workspace, or global). The sharing
> API endpoints are internal for now."

`voices.list` is deprecated in favour of `voices.search`.

## Summary

This is the authoritative voice inventory for the model. It shows the two-generation design: Voxtral
3 presets are single voices directed by inline tags, while Voxtral 2 presets are per-emotion variants
that still work.

It also resolves the language count question in one direction: 22 languages carry a Voxtral 3 preset,
not the 18 the launch post claims. And it exposes a small contradiction with the language page, which
credits English (UK) with 6 presets where this table lists 7.

## Gaps

- The page does not say whether `voice_*` IDs are stable across model versions.
- No gender, age or accent metadata is tabulated beyond the language label.
- Retention is documented as a per-voice notice field; no policy text explains what happens to a
  saved voice at expiry.

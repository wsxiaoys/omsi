## Thinking-mode documentation (verbatim)

> Granite 4.2 features a built-in thinking capability controlled by two parameters:
> `enable_thinking` — true (default) / false; `reasoning_effort` — "low" / "high" (default).
> When set to "low", the model appends `{reasoning effort: low}` to the user turn, signalling
> a faster, less thorough reasoning pass.

This is a **host-side simplification** of the vendor's three-mode scheme: Ollama exposes
`enable_thinking` plus a two-level `reasoning_effort`, whereas the model card documents
`enable_thinking` plus a boolean `low_effort` and OpenRouter exposes three effort levels
(`high`/`low`/`none`).

## 2026-09-08 — release of both GPT Image 2.5 models (verbatim)

> ### Sep 8
>
> Feature · Model: gpt-image-2.5-sunburst · Model: gpt-image-2.5-flare · API: v1/images ·
> API: v1/responses
>
> Released [GPT Image 2.5 Sunburst](https://developers.openai.com/api/docs/models/gpt-image-2.5-sunburst)
> and [GPT Image 2.5 Flare](https://developers.openai.com/api/docs/models/gpt-image-2.5-flare)
> for image generation and editing through the Image API and the Responses API image generation
> tool.
>
> Use Sunburst for workflows where editing precision matters most, or Flare for fast,
> high-quality everyday image generation. Both models support the new `xhigh` and `max` quality
> settings and use GPT Image 2 token rates. See the [image generation
> guide](https://developers.openai.com/api/docs/guides/image-generation) and
> [pricing](https://developers.openai.com/api/docs/pricing#image-generation).

## What this establishes

- **Release date: 2026-09-08**, which is inside the roster's one-year window (models launched on
  or after 2025-10-26). It also matches the `-2026-09-08` snapshot suffix on the model page.
- Flare and Sunburst shipped **the same day**, as a pair, through the same two surfaces.
- `xhigh` and `max` are described as **new** quality settings introduced with this pair.
- OpenAI's own one-line split of the two tiers is speed/everyday (Flare) vs editing
  precision (Sunburst). No quantitative difference is given.
- `v1/responses` appears in the entry's API tag list, which sits awkwardly beside the model
  page's endpoint table marking Responses "Not supported" — see the model-page record for that
  contradiction.

## Earlier entry relevant as context (paraphrase)

- **Apr 21, 2026 — GPT Image 2 released**, verbatim: *"a state-of-the-art image generation model
  for image generation and editing. GPT Image 2 supports flexible image sizes, high-fidelity
  image inputs, token-based image pricing, and Batch API support with a 50% discount."* This is
  the generation whose token rates the 2.5 pair inherits.
- `gpt-image-1` shutdown on 2026-10-23 is recorded in the Images API reference, not in this
  changelog excerpt; the reference names `gpt-image-2.5-sunburst` / `gpt-image-2.5-flare` as
  the replacement. See the Images API reference record.

## Known gaps

  changelog's contents, not a guarantee that no silent changes occurred.
- No benchmark, latency, or quality numbers accompany the release note.
- The changelog does not say whether `gpt-image-2.5-flare` is a rolling alias that will move to a

- The changelog gives no consumer-product (ChatGPT) naming or availability for these models.

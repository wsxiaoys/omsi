## Notes and gaps

- **Sunburst and Flare are priced identically.** Any cost difference between them comes from
  token consumption per image, not from the rate card. OpenAI says so explicitly in the image
  generation guide ("Equal token rates don't mean equal cost per image").
- The page gives no per-image dollar example for GPT Image 2.5; only per-token rates. The
  guide's token calculator is a client-side widget and was not captured.
- Prices are a live value, not a dated announcement. A later capture should be added rather
  than editing this record if they change.

## What this establishes

- GPT Image 2 is billed per token, not per image: $8/1M image input tokens, $2/1M cached image
  input, $30/1M image output, $5/1M text input, $1.25/1M cached text input.
- Batch halves the image rates ($4 in / $15 out / $1 cached) and the text rates ($2.50 in /
  $0.625 cached).
- **Text output is listed as "-" (not billed) for `gpt-image-2`**, unlike `gpt-image-1.5` and
  `chatgpt-image-latest`, which show $10/1M. The page does not explain the dash; read it as "no
  published text-output charge for this model", which is also consistent with the model producing
  images only.
- GPT Image 2 and both 2.5 models have identical token rates, so this page cannot be used to
  argue that 2.5 is more or less expensive per request — token consumption per image is what
  differs, and this page does not publish that.

## Known gaps

- This page gives token rates only. Per-image cost depends on output tokens, which are not
  tabulated here; the image generation guide publishes a small per-image example table (see
  that record).
- No statement of when these rates took effect or of any scheduled change.
- No regional or priority-tier pricing for image models is listed.

# OpenAI: API pricing

- **Origin:** "Pricing", OpenAI API documentation,
  <https://developers.openai.com/api/docs/pricing>. Retrieved via the Markdown export
  (`…/pricing.md`).
- **Evidence kind:** official documentation (first-party price list).
- **Publication date:** not stated (rolling). Capture date 2026-10-26.
- **Relevant model/version:** `gpt-image-2.5-flare`, with `gpt-image-2.5-sunburst` and
  `gpt-image-2` as comparison rows.
- **Capture type:** verbatim excerpt of the "Image generation models" tables (Standard and
  Batch).

### Batch — prices per 1M tokens

| Model | Modality | Input | Output | Cached input |
| --- | --- | --- | --- | --- |
| gpt-image-2.5-flare | Image | $4.00 | $15.00 | $1.00 |
| gpt-image-2.5-flare | Text | $2.50 | - | $0.625 |
| gpt-image-2.5-sunburst | Image | $4.00 | $15.00 | $1.00 |
| gpt-image-2.5-sunburst | Text | $2.50 | - | $0.625 |

Page note, verbatim: *"Cached input rates for GPT Image 2 and GPT Image 2.5 only apply to images
generated with the Responses API."* The page also says to use the calculator in the image
generation guide for cost estimates, i.e. it publishes **no per-image price** for these models.

## What this establishes

- Flare is priced **identically to Sunburst and to GPT Image 2** on both Standard and Batch
  rates.
- Batch halves the effective rates (50% discount), consistent with the GPT Image 2 changelog
  note.
- Text *output* is not billed for the image models (shown as `-`).

## Known gaps

- Token rates do not translate to a per-image price without knowing token consumption per size
  and quality, which OpenAI publishes only through a client-side calculator (not captured as a
  data table).
- No statement of whether Flare and Sunburst consume the same number of output tokens for the
  same size/quality, which is what would make their per-image costs differ despite equal rates.

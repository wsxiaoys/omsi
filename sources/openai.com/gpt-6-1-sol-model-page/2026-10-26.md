> - Cached input tokens are priced at 5% of the uncached input token rate.
> - Cache writes are billed at 1.25x the uncached input token rate.

## Summary

The model page is the densest first-party statement about this model: one model ID, one
snapshot alias (no dated snapshot), text+image in / text out, 1,050,000-token context with
a 922,000-token maximum input, 128K max output, an Apr 30, 2026 knowledge cutoff, five
reasoning efforts (no `none`), and $2/$10 per 1M tokens with a 5% cached-input rate and a
272K long-context step-up.

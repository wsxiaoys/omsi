## Captured content, verbatim

> Ultrafast mode is the fastest service tier in the OpenAI API. It is broadly available for
> GPT-6 Astra and GPT-6.1 Sol. Use it when speed justifies the higher cost.

> Ultrafast mode for GPT-6 Astra and GPT-6.1 Sol is available to all API users.

> Ultrafast has separate rate limits from Standard and Fast modes.

> GPT-6.1 Sol has the following default Ultrafast token rate limits:
>
> | API usage tier | Tokens per minute (TPM) |
> | -------------- | ----------------------- |
> | Build          | 1,000,000               |
> | Launch         | 4,000,000               |
> | Grow           | 40,000,000              |

> Ultrafast mode for GPT-6.1 Sol supports US and EU data residency and global processing.
> GPT-6 Astra Ultrafast supports US data residency and global processing only.

Request form: `model: "gpt-6.1-sol"` with `service_tier: "ultrafast"` on each
`response.create` event (Responses API).

## Summary

Ultrafast is a service tier, not a model: same `gpt-6.1-sol` ID, same context and output
limits, 6× the Standard token price
([pricing](../gpt-6-1-sol-pricing/2026-10-26.md)), with separate rate limits whose default
TPM values happen to equal the Standard tier's (1M / 4M / 40M TPM, per the model page's
Standard table). Sol is the more broadly available of
the two Ultrafast models — it has EU data residency where Astra does not.

## Gaps

- No latency or throughput number is given for Sol in Ultrafast mode; "fastest service
  tier" is unquantified here. The GPT-5.6-era changelog claimed "up to 14x faster" for that
  model, which is not a Sol figure.
- No SLA statement for Sol Ultrafast (Astra's Fast mode explicitly lacks one).

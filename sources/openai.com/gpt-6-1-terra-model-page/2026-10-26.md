## One-liner and intended uses, verbatim

> A fast, efficient model for visual reasoning, precise computer use, and clear, natural
> writing.

> Use GPT-6.1 Terra to match product photos to catalog entries, interpret technical
> drawings, act on application screens, or draft and revise text.

## Reasoning, verbatim

> `reasoning.effort` supports `none`, `low`, `medium` (default), `high`, `xhigh`, and `max`.

> Tool calling requires the Responses API.

## Model details, verbatim

> - Default snapshot: `gpt-6.1-terra`
> - Input modalities: text, image
> - Output modalities: text
> - Unsupported modalities: audio, video
> - 1,050,000 context window
> - Maximum input tokens: 922,000
> - 128,000 max output tokens
> - Jun 01, 2026 knowledge cutoff

## Pricing, verbatim

| Metric | Price | Unit |
| --- | ---: | --- |
| Input | $1 | 1M tokens |
| Cached input | $0.05 | 1M tokens |
| Cache writes | $1.25 | 1M tokens |
| Output | $5 | 1M tokens |

> - Cached input tokens are priced at 5% of the uncached input token rate.
> - Cache-write prices shown use 30-minute retention. Standard cache writes cost $1.25 per
>   million tokens for 30-minute retention and $2.50 for 12-hour retention, before
>   long-context adjustments.
> - Prompts with more than 272K input tokens are priced at 2x input and cache rates and 1.5x
>   output for the full request.
> - Batch and Flex prices are 50% lower than Standard.
> - Regional processing adds a 10% premium where available.
> - Fast mode prices are 2x Standard.

## Summary

The canonical first-party specification: one snapshot under a non-preview ID, text+image in
and text out, 1,050,000 context with a 922,000 maximum input, 128,000 maximum output, a
2026-06-01 knowledge cutoff, and a six-value effort set that **includes `none`** — unlike
GPT-6 Astra and GPT-6.1 Sol. The page carries no benchmark scores.

## Gaps

- No benchmark table, no system-card link, no deprecation notice on this page.
- Nothing states whether `reasoning.mode: "pro"` or `reasoning.context: "all_turns"` apply to
  Terra; both are documented family features whose support lists name other models.
- The page lists modalities as text and image only; OpenRouter additionally advertises a
  `file` input ([host record](../../openrouter.ai/gpt-6-1-terra/2026-10-26/index.md)).

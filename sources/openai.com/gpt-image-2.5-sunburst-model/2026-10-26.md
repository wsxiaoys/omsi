## Captured content (verbatim)

Title and one-line positioning:

> # GPT-Image-2.5 Sunburst
> > Our most capable model for image generation and editing
> Model ID: `gpt-image-2.5-sunburst`

Model description:

> GPT Image 2.5 Sunburst generates and edits images from text and image inputs. Use it for
> workflows where editing precision matters most. It supports `low`, `medium`, `high`,
> `xhigh`, `max`, and `auto` quality settings. Select it directly in the Image API or as the
> model of the Responses API image generation tool.

Model details:

> - Default snapshot: `gpt-image-2.5-sunburst-2026-09-08`
> - Input modalities: text, image
> - Output modalities: image

Pricing tables as printed (per 1M tokens): text input $5, cached text input $1.25; image input
$8, cached image input $2, image output $30.

> - Image output costs $30 per million tokens with Standard processing or $15 with Batch
>   processing. Text output is not billed because this model outputs images, not text.
> - Token rates match GPT Image 2. The GPT Image 2 calculator does not estimate GPT Image 2.5
>   token consumption.

Endpoint support table — supported: `v1/batch`, `v1/images/generations`, `v1/images/edits`.
Everything else in the table is "Not supported", including `v1/responses`, `v1/chat/completions`,
`v1/fine-tuning`, and `v1/moderations`.

> ## Supported features
> - inpainting

Snapshots:

> - `gpt-image-2.5-sunburst`
> - `gpt-image-2.5-sunburst-2026-09-08`

Rate limits, default tier (TPM / IPM): Build 250,000 / 20; Launch 3,000,000 / 150; Grow
8,000,000 / 250. The HTML rendering of the page additionally lists the Free tier as "Not
supported".

## Notes and gaps

- **The page contradicts itself about the Responses API.** The description says the model can
  be selected "as the model of the Responses API image generation tool", and the changelog and
  image generation guide agree, but the endpoint table marks `v1/responses` "Not supported".
  The most likely reading is that the table row describes the model as a top-level
  text-generation model (which it is not) rather than the `image_generation` tool's `model`
  field — but that explanation is an inference, not something the page states.
- The page publishes no per-image price example, no latency figure, no benchmark, and no
  statement of how Sunburst relates to the ChatGPT Images 2.5 product model. Only token rates
  and rate limits are quantified.
- No deprecation or support-window statement appears on the page.

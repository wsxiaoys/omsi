The all-zero rate-limit table is the page's own text. Read alone it suggests OpenAI's API does
not actually serve this model at any tier; read against the "Responses — Supported" row above,
it contradicts it. Artificial Analysis measures this model as a median across third-party
providers, stating that its figures represent "the median across providers where a first-party
API is not available"
([AA record](../../artificialanalysis.ai/gpt-oss-120b/2026-10-26.md)). The page does not explain
the zero table.

## Pricing page check (same retrieval session)

The OpenAI API pricing page, <https://developers.openai.com/api/docs/pricing.md> (Markdown
variant, 632 lines, retrieved 2026-10-26), contains **no `gpt-oss` row**: a case-insensitive
search for "oss" returns no match. The page does list paid text models including
`gpt-4.1`, `gpt-4o`, and `gpt-5`-family entries. So OpenAI publishes no first-party per-token
price for `gpt-oss-120b`; all pricing comes from hosts.

## Summary

OpenAI's own developer docs give the model a first-class page — model ID, 131,072 context and
131,072 max output, June 2024 knowledge cutoff, Responses/Batch endpoint support, and tool
support — while also publishing zero rate limits for it and no price. The documentation
therefore establishes identity and nominal limits, not that OpenAI sells inference.

# OpenAI: Images API reference

- **Origin:** "Images", OpenAI API reference,
  <https://developers.openai.com/api/reference/resources/images>. Retrieved via the Markdown
  export (`…/images.md`).
- **Evidence kind:** official documentation (first-party API reference).
- **Publication date:** not stated (rolling reference; it records `gpt-image-1` being "shut down
  on October 23, 2026", so it was current after that date). Capture date 2026-10-26.
- **Relevant model/version:** `gpt-image-2.5-flare` and `gpt-image-2.5-flare-2026-09-08`;
  endpoints `POST /images/generations` and `POST /images/edits`.
- **Capture type:** verbatim excerpts plus paraphrase of the request-parameter documentation.

## Model identifiers accepted (verbatim)

For **image edits**:

> The GPT image model to use for image editing, including `gpt-image-2`, its dated snapshot
> `gpt-image-2-2026-04-21`, `gpt-image-2.5-sunburst`, `gpt-image-2.5-sunburst-2026-09-08`,
> `gpt-image-2.5-flare`, and `gpt-image-2.5-flare-2026-09-08`. **Defaults to
> `gpt-image-2.5-sunburst`.**

For **image generation**: *"The GPT image model to use for image generation. **Specify a model
explicitly.**"* — no default is documented for `/images/generations`.

Also verbatim, in both places: *"`gpt-image-1` was shut down on October 23, 2026. Use
`gpt-image-2.5-sunburst` or `gpt-image-2.5-flare` instead."*

## Parameters that matter for Flare

- `quality` — *"One of `low`, `medium`, `high`, `xhigh`, or `max`"*, with `auto` also allowed;
  *"`gpt-image-2.5-sunburst` and `gpt-image-2.5-flare`, including their `2026-09-08` snapshots,
  also support `xhigh` and `max`. Defaults to `auto`."*
- `size` — for `gpt-image-2.5-flare` and `gpt-image-2.5-flare-2026-09-08`, *"arbitrary
  resolutions are supported as `WIDTHxHEIGHT` strings, for example `1536x864`. Width and height
  must both be divisible by 16 and the requested aspect ratio must be between 1:3 and 3:1.
  Resolutions above `2560x1440` are experimental, and the maximum supported resolution is
  `3840x2160`."* The standard sizes `1024x1024`, `1536x1024`, `1024x1536` are also supported.
- `n` — *"The number of images to generate. Must be between 1 and 10."*
- `background` — *"`gpt-image-2.5-sunburst` and `gpt-image-2.5-flare`, including their
  `2026-09-08` snapshots, support `opaque` and `transparent` backgrounds."* For `gpt-image-2`
  the same support is marked preview. Transparent requires `png` or `webp` output.
- `output_format` — `png`, `jpeg`, or `webp`; `output_compression` 0–100, *"defaults to 100"*.
- `moderation` — `low` or `auto`.

## What this establishes

- The **default image model for `/images/edits` is Sunburst, not Flare**, on the capture date.
  This is the first-party statement that contradicts fal's marketing line that Flare is "OpenAI's
  default image model for most applications" (see the fal record).
- Transparency is documented as generally available (not preview) for both 2.5 models, which is
  a real difference from `gpt-image-2`.
- `n` is capped at 10, matching Replicate's "up to 10 images in a single call".

## Known gaps

- The reference does not say whether `input_fidelity` is accepted by the 2.5 models; it discusses
  the parameter only for `gpt-image-2`.
- No reference-image count limit for `/images/edits` is stated.
- No per-image or per-token price appears in the reference; see the pricing record.

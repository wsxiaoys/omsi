Two things to note in that payload:

- **`canonical_slug` is `anthropic/claude-sonnet-5.5-20260928`** — a dated snapshot that
  matches Anthropic's stated 2026-09-28 release date. Anthropic's own docs print only the
  undated `claude-sonnet-5-5`, so this is host naming, not a first-party snapshot ID.
- **`reasoning.mandatory: true` and `default_effort: "high"`.** The default matches the
  first-party default (`high`). `mandatory: true` is OpenRouter's way of saying thinking
  cannot be fully disabled; Anthropic's `between_tools` setting turns off *up-front* thinking
  but still returns progress updates as thinking blocks, so both statements can be true.

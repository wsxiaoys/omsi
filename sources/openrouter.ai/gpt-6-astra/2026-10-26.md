- **`canonical_slug` is `openai/gpt-6-astra-20260903`** — a dated snapshot matching the

  Three parties agree on the date; only OpenAI's own model page omits it.
- `created` 1788552838 = **2026-09-04T20:13:58Z**, one day after release: the catalogue
  entry's creation time, not the model's.

  $1/M, cache write $12.50/M. The `overrides` entry at `min_prompt_tokens: 272000` doubles

- `reasoning.mandatory: true` matches "does not support the `none` reasoning effort level".

- **`input_modalities` includes `"file"`**, while OpenAI's model page lists only "text,

## What this establishes

- A third-party router serves the same model ID at the same list price with the same
  context and output caps and the same long-context multiplier — independent corroboration
  of OpenAI's price and limit table.
- The dated snapshot `20260903` exists at host level even though OpenAI publishes only the
  undated alias.
- Astra Pro is a reasoning mode, and `gpt-astra-latest` is a floating family alias; neither
  is a separate model.

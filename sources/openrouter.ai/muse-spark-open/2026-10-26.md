## Notes

- **Upstream snapshot string is dated:** every endpoint is named `meta/muse-spark-open-20261015`,
  i.e. the 2026-10-15 release. There is no other dated snapshot in this capture.
- **Uniform price across six hosts.** All six list exactly $1.25 input / $4.25 output / $0.15 cache
  read per 1M — no discount tier and no provider undercutting at capture.
- **Context and max output disagree by host.** Modal caps context at 1,000,000 and max output at
  262,144; Makora caps max output at 131,072; the rest list 1,048,576 / 943,718.
- **`supports_image_reference: false` on a model whose docs document `image_url` input parts.** The
  flag looks like a text-model capability field and should not be read as evidence against image
  input here (the same flag pattern appears on `meta/muse-image`, where it is likewise wrong).
- **Vals AI's Terminal-Bench 4.0 score of 6.6 %** is far below Meta's vendor-reported Terminal-Bench
  **2.1** score of 76.4 %. Different benchmark versions and different harnesses; the two numbers
  cannot be compared, and neither can be checked against the other.
- The GPQA Diamond / TAU-Bench table does not say who ran those evaluations (OpenRouter or
  AutoExacto); treat it as an unattributed aggregator figure.
- EU in-region routing is unavailable.

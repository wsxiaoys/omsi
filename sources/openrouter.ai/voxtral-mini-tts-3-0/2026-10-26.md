## Summary

The independent host record for the model, with three useful contributions.

**A second date confirmation.** `created` decodes to 2026-10-20 16:13:33 UTC, agreeing with the model
card and the AA board against the launch page's 2026-10-22 JSON-LD.

**A length figure Mistral does not publish.** 4,096-token context with 3,276 maximum completion
tokens — a host-side cap that is the only numeric input ceiling attached to this model anywhere in
the corpus.

**A price reconciliation.** The EU endpoint's $14.30 is exactly Mistral's $13 list price × 1.1, the
regional-inference upcharge documented in
[`sources/mistral.ai/regional-inference/2026-10-26.md`](../../mistral.ai/regional-inference/2026-10-26.md).
OpenRouter's "66 voices" is also exactly 36 Voxtral 3 presets + 30 retained Voxtral 2 presets, so the
aggregator's count reconciles with the vendor voice library.

**But it is not an independent inference host.** Every endpoint is `provider_name: "Mistral"`; the
aggregator proxies Mistral's API and restates Mistral's price. It is a host record, not a second
implementation, and its latencies measure Mistral's own service.

## Gaps

- `supports_voice_cloning: false` on all three endpoints, so cloning is not reachable through
  OpenRouter even though Mistral's own API documents it — an aggregator capability gap, not a model
  limitation.
- The voices list the FAQ points to ("listed with the model in the models API") was not found at the
  documented path; `/api/v1/models/mistralai/voxtral-mini-tts-3-0` and `.../voices` both return 404.
- No batch, priority or caching tier exposed.
- Uptime and latency are 1-day/3-day snapshots, not measurements this page took.

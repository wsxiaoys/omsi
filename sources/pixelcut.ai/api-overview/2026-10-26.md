## Verbatim content

> The Pixelcut API is designed to help you easily integrate the same powerful photo editing tools
> available in the Pixelcut app into your workflows and applications.

> **What you can build**
> - Background removal for listings and catalogs
> - Upscaling for higher-resolution exports
> - Background generation for studio-style product scenes
> - Virtual try-on workflows (async job model)
> - Usage monitoring via credit balance

## Why this record exists

It is the vendor's own statement that the API serves the **same** editing tools as the Pixelcut
app. That is the identity link between the app's background remover and the API's
`/v1/remove-background`: the vendor claims one engine behind both surfaces, while publishing no
model name, version, or separate model page for either.

It also confirms that the API is a multi-capability product (background removal, upscale,
background generation, outpaint, try-on, video), not a single-model endpoint set, so "Pixelcut
Background Removal" names one operation inside a larger platform.

## Gaps

- "The same powerful photo editing tools" is a claim about parity, not evidence that the app and the
  API run identical checkpoints at the same time.
- No version history, no model card, no architecture or training description.
- The page lists no limits, pricing, or dates.

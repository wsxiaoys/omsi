# Pixelcut API: pricing (credits, plans, free credits)

- **Origin:** Pixelcut Docs, "Pricing", <https://pixelcut.ai/docs/developer-guide/getting-started/pricing>
  (markdown at <https://pixelcut.ai/docs/developer-guide/getting-started/pricing.md>).
- **Evidence kind:** official documentation (first-party pricing page).
- **Publication date:** not stated. Capture date 2026-10-26.
- **Capture date:** 2026-10-26
- **Relevant models:** Pixelcut API, including background removal; credit costs for the other
  endpoints are recorded for context.
- **Capture type:** verbatim transcription of the cost table and plan table.

## Credit cost per operation (verbatim table, "Image Tools")

| Tool | Credits per image |
| - | -: |
| Background Removal | 5 |
| Upscaler | 10 |
| Background Generation | 10 |
| Outpaint | 10 |
| Try On | 10 |

Video tools (verbatim): "Video Background Removal | 1 credit per 50 frames"; "Looping Video | 8
credits per second (480p), 16 credits per second (768p), 32 credits per second (1080p)".

## Plans (verbatim)

> Pixelcut API uses a credit-based pricing. Every developer account is automatically granted 100
> free credits when they sign up.
>
> Note that API credits are not the same as app credits. API credits are used for API requests,
> while app credits are used for app usage.

| API Credits | Price (monthly) |
| - | -: |
| 1,000 | $10 |
| 5,000 | $50 |
| 10,000 | $100 |
| 25,000 | $250 |
| 50,000 | $500 |
| 100,000 | $1,000 |
| 250,000 | $2,500 |
| 500,000 | $5,000 |
| 1,000,000 | $10,000 |

> For volumes above 1 million credits, please contact us at api@pixelcut.ai for a custom quote.
>
> **Flat Rate**: All API Credits are priced at 1 cent each.

Renewal terms (verbatim): credits "renew at the start of each billing period"; "API Credits do not
rollover between billing periods". Upgrades grant new credits immediately and expire the old ones at
the end of the original period.

Also verbatim: "Credit costs can change over time. The **developer dashboard** is the source of
truth for current credit pricing."

## Arithmetic (this record's own, not vendor-stated)

- 5 credits × $0.01 = **$0.05 per background removal** at list rates.
- With `shadow.enabled`, the API reference adds 3 credits → 8 credits = **$0.08 per image**
  ([API reference](../remove-background-api/2026-10-26.md)).
- 100 signup credits ÷ 5 = **20 free background removals**.
- The 1,000-credit plan ($10) = **200 background removals** per month.

## Gaps

- No per-endpoint price table in currency; only credits. The dollar figure depends on the stated
  flat rate of 1 cent/credit.
- The page says the developer dashboard is authoritative, so this table may lag live pricing.
- No free-tier expiry is stated for the 100 signup credits beyond the general "do not rollover"
  rule; whether signup credits expire on their own schedule is not documented.
- No stated overage, refund, or proration policy on this page (the API ToS says payments are
  non-refundable — see [API ToS](../api-terms-of-service/2026-10-26.md)).

## Upload limits — the two renders disagree

Rendered HTML (verbatim): "Supports JPG, PNG, and HEIC. Up to **50MB** and **6000 × 6000px**"

Agent-markdown variant (verbatim): "Supports JPG, PNG, and HEIC. Up to **100MB** and **8000 ×
8000px**"

Both were fetched on 2026-10-26. Neither figure matches the API's documented limits (25MB; 6000×6000
on one docs page, 10000×10000 on another — see
[image requirements](../image-requirements/2026-10-26.md) and
[API reference](../remove-background-api/2026-10-26.md)). The app tool and the API are separate
surfaces, so different caps are plausible, but the page contradicts itself within one day.

> Pixelcut's AI detects your subject, maps the edges, and removes the background in seconds. Use

No test set, metric, or comparison run is published for any of these claims. "Less than 3 seconds"
is a web-app latency claim, not an API latency figure.

## Workflow features documented on this page

- **Output:** "Download your image as a PNG with no background"; transparent PNG or white
  background.
- **Refine brush:** manual edge correction in the editor. This is an app-side tool; the API has no
  equivalent parameter ([API reference](../remove-background-api/2026-10-26.md)).
- **Batch:** "strips backgrounds from up to 10,000 images in a single batch ... download the set as
  a ZIP" (app bulk tool, <https://www.pixelcut.ai/bulk/background-remover>).
- Social proof on the page: "Trusted by 70 million people", "918,707 Reviews". Unverified marketing
  figures.

## Gaps

- No model name or version anywhere on the page.
- The page's own limits disagree between its HTML and markdown renders.
- The claim "keeps the original resolution" is not reconciled with the documented maximum
  resolution, and no statement covers whether very large inputs are downscaled.
- No statement about commercial licensing on this page; that appears on the plans page
  ([pricing plans](../pricing-plans/2026-10-26.md)).

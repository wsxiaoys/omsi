# Pixelcut Docs: Image Requirements (formats and per-endpoint limits)

- **Origin:** Pixelcut Docs, core concepts, "Image Requirements",
  <https://pixelcut.ai/docs/developer-guide/core-concepts/image-requirements>
  (markdown at <https://pixelcut.ai/docs/developer-guide/core-concepts/image-requirements.md>).
- **Evidence kind:** official documentation (first-party).
- **Publication date:** not stated. Capture date 2026-10-26.
- **Capture date:** 2026-10-26
- **Relevant models:** Pixelcut API endpoints; the remove-background row is the one this record is
  cited for.
- **Capture type:** full text capture (the page is short).

## Verbatim content

> ## Supported formats
>
> * Images must be JPEG or PNG format
> * File size is limited to **25MB**
>
> ## Per-endpoint limits (summary)
>
> * **Remove background**: min `64×64`, max `6000×6000`
> * **Generate background**: min `64×64`, max `6000×6000` (outputs are `1024×1024` by default)
> * **Upscale**:
>   * min `64×64`
>   * max input `3000×3000` for 2×, `1500×1500` for 4×
>   * max output `6000×6000`
> * **Virtual try-on**: min `256×256`, max `1920×1920`

## Why this record exists

It is the source of two unresolved contradictions on this page:

1. **Max resolution for remove-background is 6000×6000 here but 10000×10000 in the API
   reference** ([API reference](../remove-background-api/2026-10-26.md)). Both are first-party and
   were live on the same day.
2. **Supported formats are "JPEG or PNG" here, while the API reference lists JPEG, PNG, WebP, HEIC,
   AVIF** for the same endpoint ([API reference](../remove-background-api/2026-10-26.md)). The FAQ
   also says "JPEG and PNG" ([FAQ](../api-faq/2026-10-26.md)). The hosts accept more than either
   list (see [fal record](../../fal.ai/pixelcut-background-removal/2026-10-26.md)).

The 25MB file-size limit is consistent across the docs pages.

## Gaps

- No statement of which document wins when they disagree.
- No colour-space, bit-depth, EXIF-orientation, or animated-format guidance.
- No per-endpoint note on whether an oversized image is rejected or downscaled; the API reference's
  `resolution_too_high` error code implies rejection.

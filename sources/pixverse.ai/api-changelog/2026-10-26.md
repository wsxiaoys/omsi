## Summary

The changelog is the vendor's own dated model history and the source for distinguishing the V5 line
from V6:

- **V5** — API release 2025-08-29
- **V5.5** — 2025-12-02
- **V5.6** — 2026-01-26
- **V6** — API support added 2026-03-31 (text-to-video, image-to-video, first/last frame, extend)
- **V6 Fusion (video references)** — 2026-05-21
- **C1** — 2026-04-07 (a separate sibling model, not a V6 checkpoint)
- **V6 Max** — 2026-10-22 (a tier above V6)

The 2026-03-31 entry is a documentation event, two days after fal published V6 endpoints and one day
after the vendor's public launch post (2026-03-30). The three dates are consistent with a launch
around 2026-03-29/30 followed by documentation, but no captured page states which is the true GA
moment.

## Gaps

- Documentation events only: a row means an endpoint learned to accept the model, not necessarily
  that the model was released that day.
- No deprecation rows for any V5-line model, so the changelog cannot be used to date retirement.

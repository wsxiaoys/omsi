# PixVerse Platform Docs: FAQ

- Origin: PixVerse Platform Docs, "FAQ", <https://docs.platform.pixverse.ai/faq-2394993m0>
- Evidence kind: official API documentation (first-party)
- Publication date: undated; current at capture
- Capture date: 2026-10-26
- Relevant models: all PixVerse API models

## Captured content (verbatim)

> ### Can uploaded resources be shared across accounts or regions?
> No. Use images, videos, audio, and generated IDs with the same API account and region that created
> them.

> ### Are failed tasks refunded automatically?
> Qualifying failed, moderated, or timed-out tasks may be refunded. Treat a refund as complete only
> after the refund record appears in the account ledger and the balance is restored.

> ### Is `Resp.credits` the final billing record?
> Use `Resp.credits` for display and preliminary reconciliation. Valid debit and refund entries in the
> account ledger are the final charging record.

> ### How often should I query task status?
> Poll every 3-5 seconds and use a new `Ai-trace-id` for each request.

> ### Why is an uploaded image or video rejected by a generation endpoint?
> Confirm the media type, format, dimensions, file size, account, region, and compatible endpoint.

## Summary

Two operational facts for the model page: uploaded media cannot cross **account or region** boundaries,
and moderation/failure refunds are conditional ("may be refunded") and only final once the ledger
shows them. The FAQ does not define what qualifies, or what the region set is.

## Gaps

- No refund rate, no qualification criteria, no timeline.
- No list of regions, dimensions, formats, or file-size limits — it defers to the upload endpoint
  documentation.

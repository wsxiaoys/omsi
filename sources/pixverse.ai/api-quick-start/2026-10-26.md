# PixVerse Platform Docs: Quick Start

- Origin: PixVerse Platform Docs, "Quick Start",
  <https://docs.platform.pixverse.ai/quick-start-2394985m0>
- Evidence kind: official API documentation (first-party)
- Publication date: undated; current at capture
- Capture date: 2026-10-26
- Relevant models: all PixVerse API models (example uses `v5.6`)

## Captured content (verbatim)

> Production Base URL: `https://app-api.pixverse.ai`

Required headers: `API-KEY`, `Ai-trace-id` (a new UUID per request), `Content-Type`.

> `Ai-trace-id` is a tracing identifier, not an idempotency key. Reusing it may create another task.

Media upload: `POST /openapi/v2/image/upload` → `Resp.img_id`;
`POST /openapi/v2/media/upload` → `Resp.media_id`. "Use the returned ID only with compatible
endpoints in the same API account and region."

Task status values:

| `status` | Meaning |
| --- | --- |
| `1` | Generation completed |
| `5` | Generating |
| `7` | Content moderation failed |
| `8` | Generation failed |

Poll `GET /openapi/v2/video/result/{video_id}` every 3–5 seconds.

The worked example sends `{"model":"v5.6","prompt":"…","duration":5,"quality":"720p","aspect_ratio":"16:9"}`.

## Summary

Establishes the operational surface: a single global base URL (`app-api.pixverse.ai`), a key plus a
per-request trace UUID, asynchronous tasks identified by `video_id`, and four status codes. Two
points matter for the model page:

- **Region is a real constraint**: uploaded media IDs are scoped to the account *and region* that
  created them, so a key moved between regions cannot reuse assets. The docs do not enumerate which
  regions exist.
- **Moderation is an explicit terminal state** (`status=7`), not an inference from a price page.

The example still uses `v5.6`, which is documentation lag rather than an availability statement —
`v6` is in every endpoint enum captured.

## Gaps

- No list of regions or regional base URLs.
- No documented per-account concurrency number ("Check the PixVerse API console for the current
  account limit").
- No latency or generation-time guidance beyond polling cadence.

# PixVerse Platform Docs: Image-to-Video and Video Templates (`POST /openapi/v2/video/img/generate`)

- Origin: PixVerse Platform Docs, "Image-to-Video and Video Templates",
  <https://docs.platform.pixverse.ai/image-to-video-and-video-templates-13016633e0>
- Evidence kind: official API specification (first-party)
- Publication date: undated; current at capture
- Capture date: 2026-10-26
- Relevant models: PixVerse V6, V6 Max, C1, V5.6, V5.5, V5

## Captured content (verbatim)

Endpoint description:

> Generate from an uploaded image, or use template_id for a template-based task. Normal image
> generation requires img_id. For templates, provide the image field and count required by that
> template (img_id or ordered img_ids). Template metadata determines supported model, duration, and
> quality; do not assume every template accepts the same combination.

Per-field documentation that constrains V6:

> `prompt`: "Generation prompt." `maxLength: 2048`

> `duration`: "Duration in seconds. C1/V6: 1-15; V5.5/V5.6: 5, 8, or 10; older models: 5 or 8. Do not
> use unsupported duration/quality combinations."

> `generate_audio_switch`: "Generate native audio with V5.5, V5.6, V6, or C1. Set to true to enable
> audio or false for silent output."

> `generate_multi_clip_switch`: "Enable multi-clip generation with V5.5 or V6. Not supported with
> other models or template_id."

> `img_id`: "Uploaded image ID. Required for ordinary image generation."

> `img_ids`: "Ordered image IDs for a multi-image template only."

> `template_id`: "Optional current template ID returned by Get Effect Template List."

Legacy fields still present but scoped: `sound_effect_switch`, `sound_effect_content`,
`lip_sync_switch`, `lip_sync_tts_content`, `lip_sync_tts_speaker_id` — each described as a "Legacy"
option applicable "only when supported".

`model` enum matches text-to-video: `v6-max`, `c1`, `v6`, `v5.6`, `v5.5`, `v5`, `v3.5`, `v4`,
`v4.5`, `v5-fast`.

## Summary

Image-to-video is the same parameter surface as text-to-video plus `img_id` (or `img_ids` +
`template_id` for templates), with two differences that matter for V6:

- **Prompt cap is 2,048 characters**, not 5,000. Anyone porting a long V6 text prompt to
  image-to-video will hit a lower ceiling at the vendor.
- **Audio generation is explicitly scoped** to V5.5, V5.6, V6, and C1 — so V5 and older cannot
  produce native audio, and V6 can.

Template-based generation exists for V6 ("determined by the template" in the capability map) but its
parameters live in a live template-list API, not in this document.

## Gaps

- No image input constraints here (dimensions, aspect, file size) — those live in the upload endpoint
  documentation, which was not captured in detail.
- No statement of how V6 handles an input image whose aspect ratio conflicts with the requested
  `aspect_ratio` (the field is documented for the endpoint but its precedence is not stated).

## Request schema (verbatim field definitions)

Required: `model`, `prompt`, `duration`, `quality`, `aspect_ratio`.

| Field | Type / constraint |
| --- | --- |
| `model` | enum: `v6-max`, `c1`, `v6`, `v3.5`, `v4`, `v4.5`, `v5`, `v5-fast`, `v5.5`, `v5.6` |
| `prompt` | string, `maxLength: 5000` |
| `duration` | integer, minimum 1, maximum 15 |
| `quality` | enum: `360p`, `540p`, `720p`, `1080p` |
| `seed` | integer, minimum 0, maximum 2147483647 |
| `webhook_id` | string |
| `aspect_ratio` | enum: `16:9`, `9:16`, `4:3`, `3:4`, `1:1`, `2:3`, `3:2`, `21:9` |
| `generate_audio_switch` | boolean, default false |
| `generate_multi_clip_switch` | boolean, default false |

Documented examples include a "Minimal request" using `model: v6-max` at `duration: 1`,
`quality: 360p`; a "Complete scenario" using `model: v6-max` at `duration: 5`, `quality: 720p`,
`seed: 20260804`, `generate_audio_switch: true`, `generate_multi_clip_switch: true`; and a `c1`
example.

Response: `ErrCode` (0 = business success), `ErrMsg`, `Resp.video_id` (int64) and `Resp.credits`.
Errors carry `Error.Type`, `Error.Message`, `Error.Param.Fields` and `Error.Param.AllowedValues`.

## Documented error text that pins model behaviour

> `generate_multi_clip_switch` is supported in model v5.5, v6 only.

with

> `"AllowedValues": ["v5.5", "v6"]`

A quality error example lists `"AllowedValues": ["360p", "540p", "720p", "1080p"]`.

## Summary

The endpoint accepts V6 as the model string `v6` (V6 Max is the separate string `v6-max`). The
parameter surface is small and shared across the model line: prompt, duration, quality, aspect ratio,
seed, audio switch, multi-clip switch. Two details matter for the page:

1. **Multi-clip is a V5.5/V6 feature at the vendor.** The documented error enumerates only `v5.5` and
   `v6`, which means `v6-max` is not accepted for multi-clip on this endpoint — matching the
   capability map's narrower V6 Max column.
2. **The vendor exposes no `thinking_type`, no `style`, and no `negative_prompt`** on text-to-video.
   Both hosts add parameters the vendor does not document (see the fal and Replicate records).

Text-to-video allows a 5,000-character prompt; image-to-video allows 2,048 (captured separately).

## Gaps

- No frame rate, container/codec, or bitrate is specified.
- No documented latency or queue-time expectation.
- Duration/quality compatibility for V6 specifically is only bounded by "1–15" and the four qualities;
  the vendor does not publish a matrix of which combinations are rejected.

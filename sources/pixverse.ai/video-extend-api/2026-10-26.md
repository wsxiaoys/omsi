# PixVerse Platform Docs: Video Extend (`POST /openapi/v2/video/extend/generate`)

- Origin: PixVerse Platform Docs, "Video Extend",
  <https://docs.platform.pixverse.ai/video-extend-43051216e0>
- Evidence kind: official API specification (first-party)
- Publication date: undated; current at capture
- Capture date: 2026-10-26
- Relevant models: PixVerse V6

## Captured content (verbatim)

> Continue a source video. Provide exactly one source. V6 supports a 1-15 second extension. Source
> video up to 30 seconds / 50 MB; cumulative duration after extension up to 40 seconds. The result
> may include the source plus the extension, so task duration is not necessarily final file duration.

`model` enum on this endpoint is exactly one value: **`v6`**. No other model can extend.

Other fields: `source_video_id` **or** `video_media_id` (the schema uses an `if/then/else` so exactly
one is required), `prompt` (`maxLength: 5000`), `duration` (1–15), `quality`
(360p/540p/720p/1080p), `seed` (0–2147483647), `webhook_id`.

A documented error on this endpoint repeats the multi-clip rule:

> `generate_multi_clip_switch` is supported in model v5.5, v6

## Summary

Video extend is the second V6-exclusive capability (the capability map gives "Video Extend:
Supported" only to V6). The limits are explicit and useful: a source clip up to 30 s / 50 MB, an
extension of 1–15 s, and a cumulative cap of 40 s after extension. The vendor warns that the returned
file may contain the source plus the extension, so billed duration and delivered duration can differ.

Combined with the pricing note ("V6 Extend uses the applicable V6 resolution, audio, and
generated-duration rate, not a separate flat rate"), this means extending is priced like generating
the extension seconds, not the whole output.

## Gaps

- No documented source-video resolution, fps, or codec requirements.
- No statement of how many successive extensions are permitted before the 40-second cumulative cap
  bites, or whether the cap applies per chain or per file.
- "The result may include the source plus the extension" is deliberately vague about whether it
  sometimes does not.

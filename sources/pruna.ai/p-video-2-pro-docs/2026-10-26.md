## Overview (verbatim)

> p-video-2-pro is Pruna's video generation model, built on Minimax H3. It supports text-to-video
> and first/last-frame conditioning at 480p and 768p, plus 1080p, 2k and 4k, which upscale the 768p
> video with p-video-upscale (24 fps kept). Duration is 5–15 seconds (default 5). Output is 24 fps
> and includes generated audio. Audio input is not exposed.

> `mode` selects the generation recipe: `speed` (default, faster), `quality`, or `cost`.

> `prompt_upsampler` is independent: `off`, `turbo` (default), or `max`.

> Rate Limit: 250 requests per minute

> Category: Video Generation

> Pricing: billed per second of the video returned.

The page's `<title>`/OG description is "p-video-pro video generation from text and first/last-frame
images, built on Minimax H3" — the short description drops the "2".

## Price table (verbatim, USD per second of returned video)

| Resolution | `mode=cost` | `mode=speed` | `mode=quality` |
| --- | --- | --- | --- |
| 480p | $0.01 | $0.02 | $0.04 |
| 768p | $0.025 | $0.035 | $0.075 |
| 1080p | $0.045 | $0.055 | $0.095 |
| 2k | $0.065 | $0.075 | $0.115 |
| 4k | $0.105 | $0.115 | $0.155 |

> The length is measured from the finished video rather than from the request, so the final price is
> known once generation completes. Omitted `mode` is billed as `speed`.

> 1080p, 2k and 4k are the 768p rate plus the p-video-upscale rate for that target (+$0.02, +$0.04
> and +$0.08 per second).

> `prompt_upsampler` does not change the price. The table shows list prices; until October 13, 2026
> the billed rate is 50% off.

## Parameters (verbatim from the reference table)

| Parameter | Type | Default | Description |
| --- | --- | --- | --- |
| `prompt` | string | required | Text prompt for video generation |
| `prompt_upsampler` | string | `"turbo"` | Expand the prompt before generation: `"off"`, `"turbo"`, or `"max"`. Independent of `mode` |
| `image` | string (URI) | — | First-frame reference image |
| `last_frame_image` | string (URI) | — | Last-frame reference image |
| `duration` | integer | 5 | Video duration in seconds (5-15) |
| `resolution` | string | `"768p"` | `"480p"`, `"768p"`, `"1080p"`, `"2k"` or `"4k"`. 1080p, 2k and 4k upscale the 768p video |
| `mode` | string | `"speed"` | Generation recipe: `"quality"`, `"speed"`, or `"cost"` |
| `aspect_ratio` | string | `"16:9"` | `"16:9"`, `"9:16"`, `"4:3"`, `"3:4"`, `"3:2"`, `"2:3"`, `"1:1"`. Reference images determine the canvas when provided |
| `seed` | integer | random | Random seed for reproducible generation |
| `enable_safety_filter` | boolean | `false` | Check the inputs against the content policy. When off, only the always-on categories (sexual content involving minors, self-harm intent or instructions) are still blocked |

## API surface (verbatim from the quickstart)

- Endpoint: `POST https://api.pruna.ai/v1/predictions`, headers `apikey: YOUR_API_KEY` and
  `Model: p-video-2-pro`, JSON body `{"input": {...}}`.
- Synchronous mode: same endpoint plus `Try-Sync: true`; the page's FAQ says long sync requests
  "can hit timeouts" and recommends async for video.
- Image upload: `POST https://api.pruna.ai/v1/files` (multipart `content=@file`), returns a file URL
  that is then passed as `image`.

## Summary

The authoritative first-party surface for the model: text-to-video and first/last-frame
conditioning, 5–15 s, 24 fps, generated audio, no audio input, three generation recipes, per-second
billing from $0.01 to $0.155, 250 requests/min. Native generation is 480p/768p; the three higher
labels are an upscale pass over the 768p render.

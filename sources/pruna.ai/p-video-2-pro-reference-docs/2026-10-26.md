## Overview (verbatim)

> p-video-2-pro-reference generates a video from a prompt and at least one image or video reference.
> It is built on MiniMax H3. Audio references are optional. Resolutions are 480p and 768p, plus
> 1080p, 2k and 4k, which upscale the 768p video with p-video-upscale (24 fps kept). Duration is
> 5–15 seconds (default 5).

> `mode` is `speed` (default) or `cost`. There is no `quality` mode.

> Reference limits, enforced by the model: up to 9 images including start and end frames (20 MiB,
> 4096 px), 3 videos (100 MiB, 1080p, 60 fps, 2–15 seconds each, 15 seconds combined), and 3 audio
> files (50 MiB, 15 seconds combined).

> `keep_audio` is off by default. Set it with exactly one audio file to keep that file as the video's
> audio instead of only using it as a reference.

> `first_frame_image` and `last_frame_image` are optional soft keyframes. They count as reference
> images. A start or end frame needs prompt upsampling, so `prompt_upsampler=off` still runs `turbo`
> when one of those frames is set.

## Pricing basis (verbatim)

> Output seconds use a rate for `resolution` and `mode`. Reference video seconds use a rate for the
> same pair. Each reference image has a per-image rate, and reference audio has a per-second rate.
> Start and end frames count as images. Image and audio rates do not depend on resolution.

Rates: output 480p cost $0.015/s, 480p speed $0.02/s, 768p cost $0.025/s, 768p speed $0.035/s,
1080p/2k/4k cost $0.045/$0.065/$0.105 and speed $0.055/$0.075/$0.115; reference video $0.03/s (480p
cost) to $0.06/s (768p); reference images $0.005 each (cost) or $0.01 each (speed); reference audio
$0.0015/s (cost) or $0.0025/s (speed). 1080p/2k/4k reference video seconds keep the 768p rate.

> Output seconds are the wrapper's whole-second count, `int(num_frames / 24)`. A 5 second request is
> 124 frames and bills as 5 seconds. A 15 second request is 345 frames and bills as 14 seconds.

> The shortest run is 5 seconds, so the cheapest request is $0.075 (cost, 480p, no references).

## Summary

The reference-guided sibling. It is the only page in the family that states the MiniMax H3 licence
inheritance in full, and it confirms two facts the base `p-video-2-pro` page leaves implicit: the
24 fps output (`num_frames / 24`), and that the 5-second request is 124 frames — i.e. billing rounds
a 15-second request down to 14 billed seconds.

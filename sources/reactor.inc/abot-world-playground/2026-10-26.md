## What this establishes

- An independent host reproduces the vendor's framing: image-conditioned, action-conditioned,
  live-per-frame rollout, "runs endlessly", credited to AMAP.
- The control scheme in the third-party description — **WASD to walk, IJKL to look, prompts to
  reshape** — matches the repository's `default_action.json` key set (`W`, `A`, `S`, `D`, `I`, `J`,
  `K`, `L`) and the eight command names in fal's WebRTC contract. Three independent surfaces agreeing
  on the control surface is the strongest cross-source agreement on this page.
- "Reshape it with prompts" confirms mid-session prompt updates are a user-facing feature, not just an
  API affordance.

## Gaps

- "Every frame is generated live" is marketing prose with no measured frame rate or latency attached;
  it should not be read as an independent performance measurement.

## Summary

Reactor is an independent commercial host for the real-time version of LingBot World 2, with a public
per-second price of **$0.007/s ($0.42/minute)** — 5.6× fal's $0.00125/s — and a simpler control
surface: prompt, WASD movement, and a look/rotation control with a degrees-per-frame slider.

Reactor's "exclusively on Reactor" claim conflicts with the vendor's own list of two demo partners
(Reactor for PC/web internationally, LingGuang for mobile in China), captured on the project page. The
vendor's Hugging Face model card describes Reactor and LingGuang as convenience demos where "some
functions are missing"
([model card](../../huggingface.co/lingbot-world-v2-model-files/2026-10-26.md)), a caveat Reactor's
copy does not repeat.

## Gaps

- No technical specification: no resolution, frame rate, latency, or session length published on the
  model page.
- The price has no published unit definition — whether a "SEC" is streamed video time, wall-clock
  session time, or generated frames ÷ fps is not stated, and no minimum, cap, or included minutes are
  documented.
- No API reference was captured (the "API" tab content is not in the static HTML), so the programmatic
  contract, model variant served, and rate limits are unknown.
- Reactor publishes no licence or usage terms specific to this model on the captured pages.
- The landing page's "exclusively" wording is not reconciled with the vendor's LingGuang mobile
  partner; treat it as host marketing.
- No date is available for when Reactor's LingBot World 2 page went live, so host availability cannot
  be ordered against fal's 2026-10-16 publication.

## Captured content

### Billing model (verbatim)

> The Recraft API is pay as you go. You buy API units in advance and each request deducts its
> cost. The `credits` field of every response shows how many units it used.

> **$1 = 1,000 units** ... Buy any number of packages.
> **From $0.007** per image, with V4.1 Flash.
> **No expiry** Purchased units don't expire.

> API unit packages are non-cancellable and non-refundable. All tokens of one account share the
> same balance.

> Price per image. Multiply by 1,000 for API units: $0.035 is 35 units.

Image editing (image to image, inpainting, outpainting, replace/generate background) is priced
only for **V3** on this page ("Price per image, with `recraftv3` (raster) or `recraftv3_vector`
(vector)").

## Gaps

- The price is per **image**, with no megapixel, token, or resolution multiplier stated — so the
  $0.25 V4 Pro rate appears to be flat across the whole 2K size table, but the page never says so
  explicitly.
- No statement of whether `n > 1` multiplies the price (the generation endpoint allows `n` 1–6);
  the response `credits` field is the only feedback.
- No V4-family image-to-image price is listed, only V3's.
- Prices are undated and there is no changelog, so a later price change will not be visible in
  this capture.

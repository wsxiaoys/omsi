- Publication date: none stated

- Capture type: page fetched in full; the size table is quoted verbatim

## Captured content

Stat tiles: **100 / min** rate limit, **24h** image URL lifetime, **10,000** prompt characters
"V4 and newer".

> Generated images are stored for about **24 hours**. Download the files you need to keep. This
> policy may change, so don't rely on the exact duration.

> Image URLs are public and need no authentication. They contain a unique signed identifier, so a
> lost URL can't be recovered.

### Prompt length (verbatim table)

| Models | Max characters |
| - | - |
| V4.1, V4.1 Utility, V4.1 Flash, V4, V4 Styles, including all Pro and Vector variants | 10,000 |
| V3, V3 Vector, V2, V2 Vector | 1,000 |
| Enhance prompt input | 2,000 |

### Supported sizes (verbatim table, abridged to the 2K column)

> When `size` is omitted, the size is picked from the prompt.

| Ratio | 1K models | 2K models (Pro) | V2, V3 |
| - | - | - | - |
| `1:1` | `1024x1024` | `2048x2048` | `1024x1024` |
| `2:1` | `1536x768` | `3072x1536` | `2048x1024` |
| `1:2` | `768x1536` | `1536x3072` | `1024x2048` |
| `3:2` | `1280x832` | `2560x1664` | `1536x1024` |
| `2:3` | `832x1280` | `1664x2560` | `1024x1536` |
| `4:3` | `1216x896` | `2432x1792` | `1365x1024` |
| `9:16` | `768x1344` | `1536x2688` | `1024x1820` |

(The page lists 14 ratios in total; the rows above are the ones this capture checked.)

> * **1K models:** `recraftv4_1`, `recraftv4_1_utility`, `recraftv4_1_flash`, `recraftv4`,
>   `recraftv4_styles`.
> * **2K models:** `recraftv4_1_pro`, `recraftv4_1_utility_pro`, `recraftv4_pro`,
>   `recraftv4_styles_pro`.
> * **V2, V3:** `recraftv2`, `recraftv3`.
> * **Vector models** (every `_vector` model) accept the same 14 ratios as `w:h` only; SVG output
>   has no fixed pixel size.

## Gaps

- The 14-row table is quoted only in part here; the full set was not transcribed. The Replicate
  schema enumerates all 14 sizes and matches this table
  (`../../replicate.com/recraft-v4-pro-schema/2026-10-26.md`).
- No maximum megapixel or dimension limit for the Pro tier is stated beyond the table.
- No statement about whether arbitrary `width x height` (non-table) sizes are accepted for
  `recraftv4_pro`; the generation parameter doc says "exact size (`1024x1024`)" without a range.

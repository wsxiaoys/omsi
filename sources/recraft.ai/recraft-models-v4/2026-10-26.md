## Captured content

> Recraft V4 was released in **February 2026**. With a focus on visual and design taste, V4
> produces images with balanced composition, cohesive color, and refined detail that feel
> intentional rather than stock-like, across both raster and vector outputs.

### The four V4 versions (verbatim table)

| Service description | Cost (USD) | Cost (API units) | Billing Basis | Time |
| :- | - | - | - | - |
| Recraft V4 | $0.04 | 40 | Per image | 10s |
| Recraft V4 Pro | $0.25 | 250 | Per image | 30s |
| Recraft V4 Vector | $0.08 | 80 | Per image | 15s |
| Recraft V4 Pro Vector | $0.30 | 300 | Per image | 45s |

> **Pro** delivers higher resolution and finer detail, perfecting anatomy issues and improving
> realism across complex scenes. It produces more reliable results for detailed compositions,
> print-ready visuals, and other high-fidelity applications.

> All versions of Recraft V4 are available on all plan types, including the Free plan.

Note: this page gives **30s** for V4 Pro, while the launch blog gives **~28 seconds** and
Replicate states "about 28 seconds" (`../../replicate.com/recraft-v4-pro/2026-10-26.md`). The two
first-party figures disagree by ~2s and neither states conditions.

### Key features (verbatim, condensed to the Pro-relevant items)

- "**Design-forward visual judgment**": "balanced composition, cohesive color relationships, and
  controlled detail"; outputs "tend to feel deliberate rather than generic or stock-like".
- "**Exceptional prompt understanding**": "accurately following visual relationships such as
  reflections, materials, and background interactions."
- "**Readable, structured text generation**": "clear, legible text for infographics, menus,
  signage, and packaging designs. Handles short and mid-length phrases with high fidelity to
  layout and typography."
- "**High-quality vector generation**: The only model capable of generating editable,
  production-quality **SVG** graphics."
- "**Higher native resolution (Pro version)**: Ideal for professional production workflows that
  require large formats or pixel-dense detail. The Pro model outputs at 2048x2048 px for
  design-grade clarity across print, product, and marketing use cases."
- "**Supported formats** Export results in **SVG**, **PNG**, **JPG**, **PDF**, **TIFF**, and
  **Lottie**." (app-level; the API exposes only `webp`/`png`, and SVG for `_vector` models)
- "**Default availability** All V4 models are available in the web app and via the API."

### Limitations (verbatim)

> The following features are not yet supported in Recraft V4:
> * Style creation
> * Prompt-based editing
> * Image sets
> * Artistic level control

Also on the page: "Exploration mode is temporarily unavailable." and a pricing note for
exploration mode ("Each image in exploration mode costs 2 credits ... 8 images per generation").

## Gaps

- "Style creation" is listed here as unsupported, contradicting the API model page, which lists
  `Create style: Yes` for V4 (`../recraft-v4-api-model/2026-10-26.md`). This page reads as the
  launch-time product page; the API docs also document creating a `recraftv4` style and a
  dedicated V4 Styles family released August 2026, which suggests this list is stale, but no
  source states that the limitation was lifted.
- "Prompt-based editing" as unsupported sits alongside "Image to image: Yes" on the API page;
  the two are presumably different features (edit-instruction editing vs. strength-based
  img2img), but no source reconciles them.
- No pixel-size table and no statement of what distinguishes Vector from Vector Pro.
- Timings are given to the second without hardware or queue conditions.

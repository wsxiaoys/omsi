### Parameters (verbatim, condensed)

| Parameter | Type, default | Description |
| - | - | - |
| `prompt` | string, required | "What to generate. Up to 10,000 characters." |
| `model` | string, `recraftv4_1` | "One of the variants below." |
| `size` | string, auto | "Aspect ratio (`1:1`, `16:9`, `3:4`, ...) or exact size (`1024x1024`). Picked from the prompt when omitted." |
| `n` | integer, `1` | "Number of images, 1 to 6." |

| `style_reference_urls` | array of strings | "Up to 10 image URLs to use as style references instead of `style_id`." |

> Not supported by V4.1: `negative_prompt`, `style` (curated styles), `text_layout`, and the
> `artistic_level` and `no_text` controls.

### Variants and prices (verbatim table)

| `model` | Output | Price per image |
| - | - | - |
| `recraftv4_1` | Raster, 1K | $0.035 |
| `recraftv4_1_vector` | Vector, SVG | $0.08 |
| `recraftv4_1_pro` | Raster, 2K | $0.21 |
| `recraftv4_1_pro_vector` | Vector, SVG | $0.30 |
| `recraftv4_1_utility` | Raster, 1K | $0.035 |
| `recraftv4_1_utility_vector` | Vector, SVG | $0.08 |
| `recraftv4_1_utility_pro` | Raster, 2K | $0.21 |
| `recraftv4_1_utility_pro_vector` | Vector, SVG | $0.30 |

> **Pro** variants generate at 2K with finer detail, for print-ready and large-scale assets.
> **Utility** variants trade the main line's artistic point of view for predictability: flat
> lighting, front-facing composition, simple scenes. Use them for mockups and product listing
> photos.
> **Vector** variants return editable SVG, built for logos, typography, and illustration.

### Capabilities table (verbatim)

| Capability | Support |
| - | - |
| Generate image | Yes, default model |
| Image to image | Yes, default model |
| Create style | Yes |
| Vector output | Yes, `_vector` variants |
| Styles | Custom styles and style references |
| Controls | Partial: `colors` and `background_color` |
| Negative prompt, curated styles, text layout | No, see Recraft V3 |

> For high-volume generation, see Recraft V4.1 Flash: about 1.3 seconds and $0.007 per image,
> raster only, no styles.

### Endpoint and response

- `POST https://external.api.recraft.ai/v1/images/generations`, bearer token auth.
- Response: `{created, credits, data:[{image_id, url}]}`; "`credits` is the number of API units
  charged for the request."
- "Image URLs are temporary: files are kept for about 24 hours".
- Style note (verbatim): "A style works only with the model it was created for, so create it with
  `"model": "recraftv4_1"`. This creates the style ($0.005) and generates with it".

## Summary

This page documents eight API model IDs: a 1K base raster, a vector variant, a 2K Pro raster and
Pro vector, plus four Utility variants (1K/2K raster and two vector). V4.1 Flash is documented on
its own page and is not part of this table. V4.1 is the API default. The page documents text-to-image, image-to-image, custom styles and style references,
color/background controls, 1–6 images per request, 10,000-character prompts, WebP/PNG output,
and SVG for `_vector` models. It explicitly excludes negative prompts, curated styles, text
layout, and the `artistic_level` / `no_text` controls.

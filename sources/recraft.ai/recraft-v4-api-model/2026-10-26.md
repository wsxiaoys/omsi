## Captured content

Header: "Recraft V4 raster and SVG models: design taste, prompt accuracy, and production-grade
vector output, from $0.04 per image."

> Recraft V4, released in February 2026, is a ground-up rebuild of the Recraft model line, focused
> on design taste, prompt accuracy, and output quality at any size.

Stat tiles on the page: **$0.04** per image standard raster; **1K / 2K** WebP, PNG, or SVG;
**10,000** characters of prompt; **recraftv4** `model` value.

### Variants and prices (verbatim table)

| `model` | Output | Price per image |
| - | - | - |
| `recraftv4` | Raster, 1K | $0.04 |
| `recraftv4_vector` | Vector, SVG | $0.08 |
| `recraftv4_pro` | Raster, 2K | $0.25 |
| `recraftv4_pro_vector` | Vector, SVG | $0.30 |

> **Pro** variants generate at 2K with finer detail, improving anatomy and realism in complex
> scenes. Use them for print-ready visuals.
> **Vector** variants return editable SVG.

### Parameters (verbatim, condensed)

| Parameter | Type, default | Description |
| - | - | - |
| `prompt` | string, required | "What to generate. Up to 10,000 characters." |
| `model` | string | "`recraftv4` or another of the variants below. Without it the API uses `recraftv4_1`." |
| `size` | string, auto | "Aspect ratio (`1:1`, `16:9`, `3:4`, ...) or exact size (`1024x1024`). Picked from the prompt when omitted." |
| `n` | integer, `1` | "Number of images, 1 to 6." |
| `style_id` | UUID | "Apply a custom style." |
| `response_format` | string, `url` | "`url`, `b64_json`, or `multipart`." |
| `image_format` | string, `webp` | "`webp` (lossless) or `png`. Ignored for vector output, which is always SVG." |
| `style_reference_urls` | array of strings | "Up to 10 image URLs to use as style references instead of `style_id`." |
| `style_match` | string | "`flexible` or `precise`: how closely to follow the style." |
| `random_seed` | integer | "Seed for reproducible results." |
| `controls.colors` | array of colors | "Preferred colors, e.g. `[{"rgb": [255, 102, 0]}]`." |
| `controls.background_color` | color | "Desired background color." |

> Not supported by V4: `negative_prompt`, `style` (curated styles), `text_layout`, and the
> `artistic_level` and `no_text` controls.

### Capabilities table (verbatim)

| Capability | Support |
| - | - |
| Generate image | Yes |
| Image to image | Yes |
| Create style | Yes |
| Vector output | Yes, `_vector` variants |
| Styles | Custom styles and style references |
| Controls | Partial: `colors` and `background_color` |
| Negative prompt, curated styles, text layout | No, see Recraft V3 |

### Endpoint and response

- `POST https://external.api.recraft.ai/v1/images/generations`, bearer token auth.
- Response: `{created, credits, data:[{image_id, url}]}`; "`credits` is the number of API units
  charged for the request."
- "Image URLs are temporary: files are kept for about 24 hours".
- Example request for the Pro tier (verbatim):
  `{"prompt": "jazz festival poster, bold geometric shapes, warm palette", "model": "recraftv4_pro", "size": "2:3", "image_format": "png"}`
- "A style works only with the model it was created for, so create it with `"model": "recraftv4"`.
  This creates the style ($0.005) and generates with it".

## Gaps

- No pixel dimensions are given here for "2K" (the size table lives in
  `../limits-and-sizes/2026-10-26.md`).
- The `Create style: Yes` row on this page contradicts the V4 product page, which lists "Style
  creation" as not yet supported (`../recraft-models-v4/2026-10-26.md`). Both are first-party and
  were captured the same day.
- No statement of what `_pro` changes for *vector* output, or why `recraftv4_pro_vector` costs
  $0.30 against $0.08 for `recraftv4_vector`.
- Image to image is listed as supported for the family, but this page does not say whether
  `recraftv4_pro` is accepted by that endpoint or at what price.

## `lucataco/ace-step` input schema (verbatim bounds)

| Field | Type | Default | Bounds | Description |
| --- | --- | --- | --- | --- |
| `tags` | string, **required** | — | — | "Text prompts to guide music generation, e.g., 'epic,cinematic'" |
| `lyrics` | string | — | — | "Lyrics for the music. Use [verse], [chorus], and [bridge] to separate different parts of the lyrics. Use [instrumental] or [inst] to generate instrumental music" |
| `duration` | number | `60` | **1–240** | "Duration of the generated audio in seconds. -1 means a random duration between 30 and 240 seconds." |
| `number_of_steps` | integer | **`60`** | 10–200 | "Number of inference steps." |
| `seed` | integer | `-1` | — | "Random seed. Set to -1 to randomize." |
| `scheduler` | enum | `euler` | — | `euler`, `heun` |
| `guidance_type` | enum | `apg` | — | `apg`, `cfg`, `cfg_star` |
| `guidance_scale` | number | `15` | 0–30 | "Overall guidance scale." |
| `min_guidance_scale` | number | `3` | 0–100 | — |
| `tag_guidance_scale` | number | `0` | 0–10 | "Guidance scale for tags (text prompt)." |
| `lyric_guidance_scale` | number | `0` | 0–10 | — |
| `granularity_scale` | number | `10` | −100–100 | "Omega scale for APG guidance, or similar for other CFG types." |
| `guidance_interval` | number | `0.5` | 0–1 | — |
| `guidance_interval_decay` | number | `0` | 0–1 | — |

Output: `{"type": "string", "format": "uri"}` — a single URL, no metadata echo. There is **no output
format or sample-rate field**, so the caller gets whatever the wrapper writes.

Defaults differ from fal's on the same model: Replicate runs **60 steps** by default (fal 27), allows
up to 200 steps (fal 60), caps `guidance_scale` at 30 (fal 200), and defaults both
`tag_guidance_scale` and `lyric_guidance_scale` to **0** where fal uses 5 and 1.5. The same prompt
therefore produces different audio on the two hosts before any user choice is made.

## README (verbatim excerpts)

> ACE-Step is a novel open-source foundation model for music generation […] **Key Features:** - 15×
> faster than LLM-based baselines (20s for 4-minute music on A100) […] - full-song generation, duration
> control and accepts natural language descriptions

> **Limitations** — Performance varies by language (top 10 languages perform best); Longer generations
> (>5 minutes) may lose structural coherence; Rare instruments may not render perfectly; Output
> Inconsistency: Highly sensitive to random seeds and input duration, leading to varied "gacha-style"
> results. […] Vocal Quality: Coarse vocal synthesis lacking nuance

> **Model Details** — Developed by: ACE Studio and StepFun; Model type: Diffusion-based music
> generation with transformer conditioning; License: Apache 2.0

The README is the Hugging Face card verbatim, including the ">5 minutes" caveat that the wrapper's own
`maximum: 240` makes unreachable.

## Gaps

- Replicate's price is a hardware-time approximation, not a per-second audio rate; the page says only
  "approximately … this varies depending on your inputs", so a 240-second generation cannot be priced
  from the listing.
- Neither wrapper names the checkpoint revision it loaded, the output sample rate, or the container
  beyond `fishaudio`'s `audio_format` default.
- No official ACE-Step organization, so no vendor statement about these routes exists to check.
- The `visoar/ace-step-1.5` page was not captured beyond its search-index row.

## What this record establishes

- Replicate's BRIA integration stopped at the January 2026 editor. Anyone reading the roster's fal
  discovery path and expecting a second host for 1.5 will not find one.
- Replicate's price for the 1.0 editor ($0.04/image) equals fal's price for the 1.5 endpoints, and
  sits above Bria's own list price for "Fibo Edit" ($0.032/image).
- The Replicate listing confirms the 1.0 model is a Bria model resold through a host, not a
  Replicate-trained derivative.

## Gaps

- Replicate's page does not state whether the wrapper calls Bria's API or runs the open weights; the
  `CPU` hardware class and the private `internal-model` wrapper suggest a remote call, but this is an
  inference.
- No 1.5 endpoint exists here, so this record cannot corroborate 1.5 behaviour, only its absence.
- No moderation documentation on the page.

There is no Cartesia organization page at all, so this is stronger than a missing model: the vendor has
no presence on Replicate. Replicate's public API (`GET https://api.replicate.com/v1/models?query=…`)
requires a token and returned 401, so absence is established from the public catalogue and the 404s.

For contrast, Replicate does host other TTS vendors' models under their own namespaces (e.g.
`elevenlabs/v3`, `google/gemini-3.8-flash-tts`), so a 404 here is a vendor-absence, not a Replicate
policy against TTS.

only independent host captured for this model is LiveKit Inference

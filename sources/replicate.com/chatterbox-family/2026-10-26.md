## Schemas

**`resemble-ai/chatterbox`** — `prompt` (required), `audio_prompt` (reference clip URI),
`exaggeration` 0.25–2 default 0.5 ("Neutral = 0.5, extreme values can be unstable"), `cfg_weight`
0.2–1 default 0.5, `temperature` 0.05–5 default 0.8, `seed` 0 (random). Output is a URI; no format or
sample-rate field.

**`resemble-ai/chatterbox-multilingual`** — `text` "maximum 300 characters", `language` enum of 23 ISO
codes (`ar da de el en es fi fr he hi it ja ko ms nl no pl pt ru sv sw tr zh`) default `en`,
`reference_audio` (optional; "If not provided, uses default voice for the selected language"),
`exaggeration` 0.25–2 default 0.5, `cfg_weight` 0.2–1 default 0.5, `temperature` 0.05–5 default 0.8,
`seed`.

**`resemble-ai/chatterbox-turbo`** — `text` "maximum 500 characters" with tags
`[clear throat], [sigh], [sush], [cough], [groan], [sniff], [gasp], [chuckle], [laugh]`; `voice` enum of
20 presets (default `Andy`, "Ignored if reference_audio is provided"); `reference_audio` "Must be
longer than 5 seconds"; `top_k` 1–2000 default 1000; `top_p` 0.5–1 default 0.95; `temperature` 0.05–2
default 0.8; `repetition_penalty` 1–2 default 1.2; `seed`. **No `exaggeration` or CFG parameter**, which
is consistent with the vendor's statement that Turbo ignores both.

**`resemble-ai/chatterbox-pro`** — `prompt`, `voice` enum of 9 presets (`Luna`, `Ember`, `Hem`,
`Aurora`, `Cliff`, `Josh`, `William (Whispering)`, `Orion`, `Ken`, default `Luna`), `custom_voice`
("The uuid of the voice to use (this overrides the voice selection)"), `pitch` enum
`x-low|low|medium|high|x-high`, `exaggeration` 0.1–1 default 0.5, `temperature` 0.1–5 default 0.8,
`seed`.

## What this establishes

Replicate is the only host in the corpus carrying four Chatterbox tiers including the 2025-12 Turbo
release, and it is the only route where a caller can reach the **hosted commercial tier** (Pro: preset
voices plus a Resemble voice UUID) next to the open weights. Run counts rank Turbo above the original
model (1.2M vs 460K), which is the only usage signal in the corpus.

The Pro tier's nine preset voices differ from the nine preset voices on fal's ChatterboxHD (fal:
Aurora, Blade, Britney, Carl, Cliff, Richard, Rico, Siobhan, Vicky; Replicate: Luna, Ember, Hem, Aurora,
Cliff, Josh, William (Whispering), Orion, Ken) — the same product name exposes different voice libraries
on the two hosts.

## Gaps

- "Model created" is the Replicate listing date, not the model release date; chatterbox's 2025-06-11 is
  three weeks after the vendor's May 2025 launch.
- The per-second price and `p50price` are not explained: it is not stated whether the second-based
  figure is output audio duration, GPU time, or a fallback when the character metric does not apply.
- No sample rate, output format, duration limit or watermarking statement on any page.
- `chatterbox-pro` is not identified by any vendor document captured for this page.

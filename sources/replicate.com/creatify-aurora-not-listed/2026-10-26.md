# Replicate: Creatify Aurora not listed

- Origin: Replicate site and search API:
  - `GET https://replicate.com/creatify/aurora` → HTTP 404
  - `GET https://replicate.com/creatify` (owner page) → HTTP 404
  - `GET https://replicate.com/api/search?query=aurora` (25 results, page 1)
  - `GET https://replicate.com/api/search?query=creatify` (25 results, page 1)
  - `GET https://replicate.com/api/search?query=creatify%20aurora`
- Evidence kind: host catalogue absence check (independent host)
- Publication date: not applicable (negative result)
- Capture date: 2026-10-26
- Relevant models: Creatify Aurora

## Observations

- No Creatify owner account exists at `replicate.com/creatify`; the path returns 404, as does
  `replicate.com/creatify/aurora`.
- The site search API returns 25 results for "aurora", none of them a Creatify model: `zsxkib/aura-sr`,
  `zsxkib/aura-sr-v2`, `fofr/aura-flow`, `lucataco/aura-flow-v0.2`, plus unrelated audio and video models
  (`openai/sora-2`, `xai/grok-imagine-video`, and others).
- The search API returns 25 results for "creatify", all incidental substring matches
  (`creatorrr/*`, `catacolabs/cartoonify`, `zsxkib/create-rvc-dataset`, …). No Creatify model, and no
  model whose description mentions Aurora.
- "creatify aurora" returns the same generic 25-row page with no Aurora entry.

## Summary

Replicate does not host Creatify Aurora as of 2026-10-26. The roster's discovery path for this row named
only the fal endpoint, so this check confirms the second host expected by the brief is absent rather than
merely unindexed by the search used to build the roster.

This is a host-availability finding, not evidence about the model. It does not weaken the evidence floor:
fal and Runware are both independent host records.

## Gaps

- A negative search result cannot prove absence for all time; it proves absence from Replicate's public
  catalogue and search index on the capture date.
- Replicate's search API paginates (25 per page); only the first page was inspected for each query, and
  the responses contained no further Aurora/Creatify rows in the returned `total`.

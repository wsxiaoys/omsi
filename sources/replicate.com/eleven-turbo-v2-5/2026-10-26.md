## Price (verbatim from `billingConfig`, abridged)

The blob below is the returned JSON with the null `current_description` and tier `title` fields
omitted; the price entry is copied exactly.

```json
{"current_tiers":[{"criteria":[],"description":null,"prices":[{"description":"or 20,000 characters for $1","metric":"character_input_count","metric_display":"input character","price":"$0.05","title":"per thousand input characters","type":"per-unit"}]}]}
```

So: **$0.05 per 1,000 input characters**, i.e. 20,000 characters for $1. The same JSON block also
carries `"price": "$0.0001 per second"` and `"p50price": "$0.00014"`; the page does not explain which
figure governs a TTS call, so the per-character unit is treated as the billing basis and the
per-second figures are left unexplained.

$0.05 / 1K characters is 25% above the vendor's $0.04 list for the Flash/Turbo tier and identical to
fal's rate for the same model.

## What this establishes

- Replicate is an **independent host with a real billing surface** for this model, and it accepts a
  **custom voice ID** (the README says "Voice ID or name", default is the Adam voice ID), unlike fal's
  preset-name-only field.
- Replicate independently restates the vendor's **~250–300 ms** latency, the **40,000-character**
  ceiling and the **32-language** coverage — host restatement, not measurement.
- Replicate exposes the **widest input surface of the two hosts**: `output_format`, `seed`,
  `optimize_streaming_latency`, `use_speaker_boost`.
- Replicate still lists the model as official and usable (121,511 runs at capture) and does **not**
  mark it deprecated, mirroring fal and contradicting the vendor's "Older Models" label.

## Gaps

- The README is host-written and its performance claims ("3x faster than Multilingual v2", "25% faster
  in English") are the vendor's launch claims restated, with no measurement method or date.
- No statement of which sample rates or bitrates `output_format` actually accepts beyond the three
  examples; no per-model format restrictions.
- No deprecation/retirement notice, and no statement of what happens when ElevenLabs retires the
  model.
- Run count is a usage signal only; it says nothing about output quality.

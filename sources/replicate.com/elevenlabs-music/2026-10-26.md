## Input schema (verbatim, from the page's embedded OpenAPI)

| Field | Type / default | Description |
| --- | --- | --- |
| `prompt` | string, **required** | "Description of the music you want to generate" |
| `output_format` | enum, default `mp3_standard` | `mp3_standard` (128 kbps MP3), `mp3_high_quality` (192 kbps MP3), `wav_16khz`, `wav_22khz`, `wav_24khz`, `wav_cd_quality` (44.1 kHz WAV) |
| `music_length_ms` | integer, default **10000**, min **5000**, max **300000** | "Target duration of the music in milliseconds (optional, defaults to ~10 seconds)" |
| `force_instrumental` | boolean, default **true** | "If true, removes vocal elements from the generated music" |

Output: a single URI string. No `composition_plan`, no `model_id`, no `seed`, no `finetune_id`, no
`sign_with_c2pa`.

## What this establishes

- Replicate is a genuine independent host with a large run count (181.8K), and its wrapper is the
  **narrowest** surface in the corpus:
  - `prompt` is the only generation input — **composition plans are not exposed** at all.
  - Length is capped at **300000 ms (5 min)** and floored at **5000 ms (5 s)**, so Replicate cannot
    express the vendor API's 3 s minimum or its 10-minute maximum.
  - Default length is 10 s when the field is omitted, and the default is **instrumental**, so an
    unconfigured call produces a 10-second instrumental — the opposite of the vendor default
    (`force_instrumental: false`, length chosen by the model).
  - `output_format` uses Replicate's own six names (`mp3_standard` … `wav_cd_quality`), not the
    vendor's `codec_sample_rate_bitrate` enum, so a request cannot be transcribed between the two.
    WAV *is* reachable here, which the vendor's own ElevenCreative guide says is not yet available.
  - No `model_id` field means the wrapper cannot select v2 or v2.5 — and Replicate lists neither.
- **Replicate's price is ~3.3× the vendor's and ~0.83× fal's**: $8.30 per 1,000 seconds ≈ $0.498 per
  minute, against vendor $0.15/min and fal $0.60/min. Its own README claim "Pay-per-second generated"
  is consistent with the duration-based metric.
- Replicate's README says "No training on your outputs", a data-use commitment the vendor pages do not
  make in the same words.

## Gaps

- Replicate does not state which ElevenLabs model version the wrapper calls. The schema (prompt-only,
  v1-era format names) suggests v1; nothing confirms it.
- The billing JSON also contains an unrelated `"price": "$0.0001 per second"` string in the same
  document; it does not match the duration metric above and is treated as a different model's field
  in the shared payload, not as this endpoint's price.
- No statement of output sample rate for `mp3_standard`/`mp3_high_quality` beyond the bitrates.
- No licence beyond a link to the ElevenLabs Music Terms and a "commercial" claim.
- No latency or queue figures; no mention of watermarking or C2PA.

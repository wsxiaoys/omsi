## What this establishes

- Replicate hosts this model as an **official** ElevenLabs entry, priced at **$0.10 per 1,000 input
  characters** — the same markup as fal, and 25% above the vendor's $0.08 list. Two independent hosts
  agreeing on a marked-up price is a stronger signal than either alone.
- Billing is metered on `character_input_count`, i.e. per input character, matching the vendor's
  basis rather than per second of audio.
- The input field is **`prompt`**, not `text` — a host-specific rename that breaks drop-in code
  portability against both the vendor API and fal. `language_code` is exposed and **defaults to
  `en`**, which is a live contradiction of the vendor reference's "not supported for
  `multilingual_v2` models" (a default `en` that were truly unsupported would be inert at best).
- Replicate states the 10,000-character / ~10-minute limit in its README, corroborating the vendor
  figure on an independent host.
- The page contradicts itself on language count: the short description says "over 30 languages"
  while the README enumerates 29.
- The page's "highest-quality model in the ElevenLabs lineup" and "Choosing between ElevenLabs
  models" copy lists v3 but **not** v4, so the README is stale relative to the 2026-09-28 v4 launch.

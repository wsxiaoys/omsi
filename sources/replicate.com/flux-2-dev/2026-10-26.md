### README (verbatim excerpts)

> Black Forest Labs' FLUX.2 Dev generates and edits images from text descriptions. This 32
> billion parameter model combines image generation and editing in one, letting you create new
> images from scratch, modify existing ones, or blend multiple reference images together.

> **Edit existing images** — Upload an image and describe what you want to change. The model can
> modify specific parts while keeping the rest intact, working with images up to 4 megapixels.

> **Combine multiple references** — Use up to 10 reference images simultaneously. The model
> maintains character consistency, product details, or style elements across all your references
> without needing additional training.

> The dev variant is optimized for efficiency through guidance distillation, making it faster
> than typical models of this size while maintaining high quality output.

Architecture paragraph:

> FLUX.2 Dev uses a latent flow matching architecture that combines the Mistral-3 24 billion
> parameter vision-language model with a rectified flow transformer. [...]

> The model trains on a new variational autoencoder designed to balance quality, learnability,
> and compression.

"Improvements over FLUX.1" bullets: multi-reference support "across up to 10 input images",
improved text rendering, better prompt following, enhanced photorealism, "Higher resolution
support up to 4 megapixels for editing", stronger real-world grounding.

## Notes and contradictions

- Replicate's README says "up to 10 reference images". fal's `[dev]` edit endpoint accepts 4
  ([fal edit record](../../fal.ai/flux-2-dev-edit/2026-10-26.md)); BFL's family overview says
  "recommended max 6" for [dev]
  ([BFL overview](../../bfl.ai/flux2-overview/2026-10-26.md)). Replicate's prose matches BFL's
  launch blog, but the served schema was not captured, so Replicate's actual cap is unverified.
- "available for commercial use on Replicate" is the host's statement about its own service. It
  does not change the weights licence, which is non-commercial
  ([BFL licence](../../bfl.ai/flux2-dev-non-commercial-license/2026-10-26.md)). Replicate's page
  does not say whether it has a commercial agreement with BFL covering self-serve use.
- "Model created" 2025-11-24 is one day before BFL's launch blog (2025-11-25) and two days after
  the HF repository creation (2025-11-22).

## Two contradictions with first-party material

1. **"Distilled" vs "undistilled".** This page says Base is "distilled from Black Forest Labs' larger
   FLUX 2 base architecture", while BFL says the Base variants are "Undistilled, preserving complete
   training signal" and "Trained without step or guidance distillation"
   ([BFL blog](../../bfl.ai/flux2-klein-4b-blog/2026-10-26.md),
   [HF base card](../../huggingface.co/flux-2-klein-base-4b/2026-10-26.md)). BFL's account is
   internally consistent (the page header here even says "Un-distilled"); the readme paragraph
   contradicts its own header. Recorded, not resolved — but the first-party sources agree with the
   header, not the paragraph.
2. **"Before safety modifications".** The page says Base is "the architecture before additional
   fine-tuning and safety modifications" and "hasn't undergone additional safety fine-tuning". BFL's
   cards describe pre-release safety fine-tuning applied to the release checkpoints of both 4B
   models and make no exception for Base
   ([HF 4B card](../../huggingface.co/flux-2-klein-4b/2026-10-26.md)). Whether Base is a pre-safety
   checkpoint is unresolved; do not rely on either claim.

Additionally, "**up to 10 reference images**" is almost certainly wrong for klein: BFL documents
"[klein] Up to 4" multi-reference, the BFL API schema exposes exactly four `input_image*` fields, and
fal's klein edit endpoint caps `image_urls` at 4
([BFL overview](../../bfl.ai/flux2-klein-4b-overview/2026-10-26.md),
[fal edit](../../fal.ai/flux-2-klein-4b-edit/2026-10-26.md)). Ten is the [pro]/[flex]/[max] figure.

## What this establishes

- Replicate hosts the undistilled 4B too, at $0.009/MP, so the distilled-vs-Base comparison is
  available on two hosts without local hardware.
- Replicate's readme copy for the klein family is unreliable on architecture, safety, reference
  count, and distillation; only its pricing config and run counters should be used as host data.

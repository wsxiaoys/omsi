## What this establishes

- **Replicate treats Base 9B as a separate product from distilled 9B**: different slug,
  different readme, different hardware (H100 vs H200), different price
  ($0.011/MP input *and* output vs $0.015/output MP + $0.002/input MP) and a much higher median
  cost (`p50price $0.029` vs `$0.0063`). That is ~4.6x the median run cost of the distilled
  model — consistent with Base running far more inference steps.
- **Reference-count contradiction**: this readme says "Combine up to 5 reference images", while
  BFL's API schema exposes exactly four `input_image*` fields and fal enforces "A maximum of 4
  images". Three sources, two numbers. The Base checkpoint may genuinely accept one more
  reference than the distilled one, or the readme may be stale/wrong; nothing captured
  resolves it.
- **VRAM claim conflict inside one paragraph**: "~29GB VRAM" on the BFL card versus "running on
  consumer hardware like the RTX 4090" here (24GB). Replicate repeats BFL's phrasing rather
  than measuring it.
- **"Matches or exceeds models five times its size"** is repeated from BFL's card with no
  benchmark, harness, or dataset named. It is a marketing claim in both places.
- **The non-commercial licence is stated by the host as well as the vendor**, which makes it a
  robust fact rather than a single-source assertion.
- **Base 9B was on Replicate from launch day**: the page's initial prediction completed
  2026-01-15T16:02:43Z, hours after BFL's announcement, on a version created
  2026-01-15T14:08:19Z. The currently served version dates from 2026-03-19.

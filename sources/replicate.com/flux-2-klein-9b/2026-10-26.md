## What this establishes

- **Replicate sells the distilled 9B, and says so**: "4 step distilled version", matching BFL's
  step-distilled 4-step specification. Replicate separates it from
  `black-forest-labs/flux-2-klein-9b-base`, which it describes as undistilled
  (`../../replicate.com/flux-2-klein-9b-base/2026-10-26.md`).
- **Output pricing is $0.015 per output megapixel**, identical to BFL's "from $0.015 / image"
  release-note figure at a 1MP image — the one host that lines up with first-party. Input
  megapixels are charged separately at **$0.002/MP** ($2 per thousand input MP), which BFL's
  release notes do not mention.
- **`p50price: $0.0063`** is Replicate's own median-cost estimate per run. It is a billing
  statistic, not a latency or quality measurement, but it implies most runs are well under
  1MP of billed output plus input.
- **The served version is not the launch version**: the current version was created
  2026-05-05, four months after launch. Replicate does not say which BFL checkpoint (pinned
  `flux-2-klein-9b` or `flux-2-klein-9b-preview`) it corresponds to.
- **Model creation is January 2026**, consistent with the 2026-01-15 launch: the page renders
  "Model created 9 months ago" and shows a sample prediction from 2026-01-21.
- **4.3M runs** is a usage figure and evidence that the endpoint is heavily used, not evidence
  about output quality.

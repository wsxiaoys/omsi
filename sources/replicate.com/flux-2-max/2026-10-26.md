## Findings worth carrying to the model page

- **Replicate corroborates eight API reference images** independently of BFL's overview, and
  states it as a hard schema limit ("Maximum 8 images").
- **Replicate's price decomposes differently but lands on the same totals.** $0.04/run +
  $0.03/output MP gives $0.07 for a 1MP generation, $0.10 for 2MP, $0.16 for 4MP — identical to
  BFL's "first MP $0.07 + $0.03 each additional". Add $0.03/input MP and a 1MP edit is $0.10,
  again matching BFL. Three hosts, one effective schedule, three different decompositions.
- **`safety_tolerance` is 1–5 here**, as on fal, against BFL's 0–7. A value valid on BFL's API
  (0 or 6–7) is out of range on both hosts.
- **No prompt-upsampling control** and no grounding-search control in the schema, though the
  README advertises real-time grounding as a [max] use case.
- **4MP is a recommendation-limited ceiling here**: the schema caps output at 2048×2048 and
  advises ≤2MP, so a 4MP result is only achievable near 1:1.
- The relative "created 10 months, 1 week ago" timestamp is consistent with a mid-December 2025
  creation, i.e. with BFL's 2025-12-16 launch, but it is a derived reading of a relative date.

## Captured content (summary with key quotes)

Overview: "Flux 2 Pro is an image generation and editing model by Black Forest Labs. It
creates high-quality images from text prompts and can edit existing images using natural
language instructions. The model handles complex text rendering, photorealistic details, and
maintains consistent characters or styles across multiple reference images."

Reference images: "The model understands detailed instructions and can work with up to eight
reference images at once on the API."

Stated strengths:

- **Text rendering** — legible text "including complex typography, infographics, and user
  interface mockups. This works reliably in production, not just for simple cases."
- **Photorealism** — "useful for product photography, architectural visualization, and scenes
  that need to look like real photographs."
- **Character consistency** — across multiple reference images.
- **Structured prompting** — JSON prompts controlling "scene composition, including camera
  angles, lighting, color palettes, and the positioning of subjects."

Editing: reference images by index, e.g. "Replace the background with the beach in image 3".

Limitations and conditions stated:

- "**No negative prompts** - The model doesn't understand negative prompts like 'no text' or
  'no extra fingers.' If you try using them, it might actually add what you're trying to avoid."
- "The total input size is limited to 9 megapixels on the API."
- "The model can edit images at resolutions up to 4 megapixels while keeping detail and
  coherence."
- Hex color codes can be used in prompts for exact colors.

Architecture (as described on this page): "a latent flow matching architecture that combines
the Mistral-3 24 billion parameter vision-language model with a rectified flow transformer.
The vision-language model brings real-world knowledge and context, while the transformer
handles spatial relationships, materials, and composition. The model was trained from scratch
with a new latent space optimized for both image quality and efficient learning."

Positioning: part of BFL's "open core approach - releasing both open-weight models for
research and community use, alongside production-ready endpoints for teams that need
reliability and scale."

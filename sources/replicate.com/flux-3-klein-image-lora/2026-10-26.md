## Identity and ownership

The model lives in the **`replicate`** namespace, not `black-forest-labs`, and carries Replicate's
"Official" badge on its catalogue card. Slug: `replicate/flux-3-klein-image-lora`. Tagline:
"Generate images from Flux 3 Klein Image using your own LoRA". Public, 236 runs at capture.

Replicate's BFL org listing on the same date shows `flux-3-image` (FLUX 3 Image), `flux-3` (FLUX 3
video) and `flux-video-upscale`, but **no FLUX 3 Klein entry**. Probes:

- `https://replicate.com/black-forest-labs/flux-3-klein` → HTTP 404
- `https://replicate.com/black-forest-labs/flux-3-image-klein` → HTTP 404
- `https://replicate.com/black-forest-labs/flux-3-klein-base` → HTTP 404

So on Replicate, Klein is served by a Replicate-authored deployment of the open weights, not by a
BFL-published model.

## What this establishes

- A second independent host record for FLUX 3 Klein, and the only captured host that exposes the
  **base** checkpoint for plain inference (via a `distilled` toggle) rather than only through LoRA
  endpoints.
- The deployment is **text-to-image only**: the parameter table has no image or reference input,
  and the README says "Generate an image from a text prompt". Klein's headline editing and
  multi-reference capabilities are not reachable on this host, even though the model behind it
  supports them.
- Replicate's pixel cap for this deployment is **4,194,304 px (4 MP)** and side length ≤4096 —
  one quarter of BFL's 16.8 MP ceiling. "Native 4K" is therefore not available on this host.
- Step counts are exposed here (0 = 16 distilled / 50 base, or 1–100 explicit), unlike fal, where
  the step count is fixed.
- Replicate's `upsample_prompt` default is on, matching BFL's warning that the model needs an
  upsampler; this host performs it server-side.
- Price is per run (~$0.035 on an L40S) rather than per megapixel or per resolution tier, so it is
  not directly comparable with BFL's $0.009/1K or fal's $0.012/MP.

## Gaps

- Replicate does not state which checkpoint revision, quantization build, or upsampler model it
  runs, nor whether `upsample_prompt` uses BFL's `flux-3-image-klein-pup`.
- No editing or multi-reference endpoint is published for FLUX 3 Klein on Replicate, and no
  LoRA-training endpoint is published either — fal has both, BFL has editing only.
- The ~$0.035 figure is a typical-run estimate, not a published schedule; cost at 4 MP is unknown.
- "236 runs" is a point-in-time count and says nothing about quality.
- The page's licence link points at the *base* repository's `LICENSE.md`, which is gated; the
  actual terms were not retrievable from here.

## Why this record exists

It is the independent-host check for this page. It establishes two things:

1. FLUX 3 Max is **not** a general FLUX 3 tier that every host renames — it is served only where
   the post-trained checkpoint lives (fal), which is consistent with fal being its author.
2. Replicate's own blurb still calls FLUX 3 video an "early access preview", months after BFL's
   August 4, 2026 general-availability post. Host copy goes stale; do not date the model from it.

## Gaps

- A 404 on one URL is not proof that no Replicate endpoint exists under another owner namespace;
  no authenticated catalogue search was run (the public API requires a token and returned 401).
- Absence on Replicate says nothing about whether Max is a distinct model — only about who serves
  it.

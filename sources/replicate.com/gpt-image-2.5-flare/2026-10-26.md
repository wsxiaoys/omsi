## Pricing (transcribed from the page's billing config, per output image)

| `quality` | Price per output image |
| --- | --- |
| `low` | $0.012 ("around 83 images for $1") |
| `medium` | $0.047 ("around 21 images for $1") |
| `high` | $0.128 ("around 78 images for $10") |
| `xhigh` | $0.25 ("40 images for $10") |
| `max` | $0.50 ("20 images for $10") |
| `auto` (default) | $0.25 |

These are flat per-image prices by quality tier — unlike OpenAI's token billing, the price does
not depend on prompt length or reference images at this granularity. `auto` is priced at the
`xhigh` rate, which is a host simplification (an `auto` run that resolves to `low` presumably
still bills at $0.25).

## README claims (verbatim, condensed)

- *"When you pass reference images, Flare processes them at high fidelity automatically."*
- Quality settings: `low`, `medium`, `high`, `xhigh`, `max`, `auto` (default). *"Lower quality is
  faster and cheaper; `xhigh` and `max` push detail and fidelity further for final assets."*
- Key capabilities listed: photorealism and detail; text rendering ("Dense text, small lettering,
  and complex layouts like infographics, UI mockups, and marketing materials"); precise editing
  ("preserves identity, composition, and lighting"); style control.
- Use cases listed: infographics, logos, UI mockups, photorealistic scenes, comic strips,
  marketing visuals; style transfer, virtual try-ons, product mockups, text translation in images,
  lighting adjustments, object removal, scene compositing; character consistency across
  multi-page illustration.

## Known gaps

- Replicate does not say which OpenAI snapshot it serves or whether `openai_api_key` passthrough
  changes the served version.
- Replicate's README does not state a reference-image cap.
- No independent quality evaluation, and no comparison against Sunburst on Replicate beyond
  price (see the Replicate Sunburst record).
- The 23 s sample has no matching Sunburst sample, so it cannot support a speed comparison.

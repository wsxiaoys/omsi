- **Origin:** Replicate model page, <https://replicate.com/openai/gpt-image-2.5-sunburst>. Model
  identifier `openai/gpt-image-2.5-sunburst`.
- **Evidence kind:** provider documentation (third-party hosting page written by the host).
- **Publication date:** not captured (relative timestamps only). Capture date 2026-10-26.
- **Relevant model/version:** GPT Image 2.5 Sunburst.
- **Capture type:** summary plus verbatim quote; pricing transcribed from the page's embedded
  `billingConfig` JSON.
- **Why this record exists:** to test the roster's "are Flare and Sunburst the same model?"
  question at a second host. It is not a source for a Sunburst page.

## What this establishes

- Both independent hosts price the two tiers identically and describe them with the same
  capability vocabulary, differing only in the speed-vs-precision axis.
- Three independent pricing surfaces (OpenAI token rates, fal token rates, Replicate per-image
  tiers) all give Flare and Sunburst the same numbers. Any real cost difference between them would
  have to come from token consumption per image, which none of the three publishes for both
  models side by side.

## Known gaps

- No Sunburst run latency was captured to compare against Flare's 23.1 s sample.

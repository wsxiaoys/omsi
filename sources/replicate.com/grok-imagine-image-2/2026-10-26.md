## README (verbatim, abridged)

> xAI's Grok Imagine Image 2.0 generates and edits images from text prompts. It's the latest
> generation of the Imagine image family, with a quality control that lets you trade speed for
> fidelity, output up to 2k resolution, and a wide range of aspect ratios.

> Grok Imagine Image 2.0 is a general-purpose text-to-image model. Give it a prompt and it generates
> an image; give it an image plus a prompt and it edits that image.

> If you want the fastest, cheapest generations, use `xai/grok-imagine-image`. If you want xAI's
> highest-fidelity output, use `xai/grok-imagine-image-quality`. Image 2.0 sits in between, with a
> quality knob so you can tune the tradeoff yourself.

> The `quality` input accepts `low` or `medium` (default `medium`). Use `low` for quick drafts and
> `medium` for final output.

> Pick `1k` (1024px on the long edge) for a faster image, or `2k` (2048px on the long edge) for a
> high-resolution deliverable. The default is `2k`.

> Choose from square, landscape, portrait, ultrawide, and vertical ratios to match wherever the
> image is going.

## What this establishes

- Replicate is an independent second host for the 2.0 model, added **2026-08-13**, five days after
  fal's 2.0 endpoints and consistent with a launch in the first half of August 2026.
- Replicate's slug differs (`-2`, not `-2.0`), so searching for xAI's model ID does not find it.
- Replicate exposes **one** image input, no multi-reference edit, no `auto` quality, no `1.5k`
  resolution, and 14 aspect ratios without `21:9` / `5:2` — a narrower surface than fal's 2.0
  endpoints and narrower than xAI's documented 5-reference edit.
- Replicate's default `resolution` is **2k** while xAI's and fal's default is 1k, and the price is a
  flat **$0.04 per output image regardless of quality or resolution**. That contradicts fal's
  2.0 table, where 2K medium is $0.08.
- Replicate's own README places 2.0 between the cheap 1.0 and the higher-fidelity quality tier, and
  says "latest generation of the Imagine image family" — a host claim about generation, not an xAI
  statement.

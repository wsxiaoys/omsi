## README (verbatim, abridged)

> **Grok Imagine Video 1.5 (preview)**
>
> Animate still images into short videos with synchronized audio using xAI's Grok Imagine Video 1.5
> preview model.
>
> This preview release is image-to-video only — every prediction needs an input image. For
> text-to-video, use `xai/grok-imagine-video`.

> **Technical details**
>
> Mode : Image-to-video only (every prediction requires an input image)
> Video duration : 1–15 seconds
> Resolution : 480p or 720p
> Aspect ratios : auto (matches the input image), 16:9, 9:16, 1:1, 4:3, 3:4, 3:2, 2:3
> Audio : Automatically generated and synchronized with video
> Status : Preview release

> Shorter clips are more stable. 5–8 seconds is the sweet spot. 15-second clips work but are more
> likely to have artifacts.

## What this establishes

- **Replicate still serves the preview-era product**: image-to-video only, 480p/720p, no 1080p, no
  reference or voice inputs — while xAI's own model page and the 2026-06-16 announcement describe GA
  with T2V, R2V, native 1080p, 14 references and 3 voices. A reader arriving via Replicate would
  under-estimate the model on every axis except price.
- **Replicate's model was created 2026-06-18**, two days after xAI's GA post, but its version
  payload dates to 2026-06-01 — before GA. The listing therefore appears to have been created
  against the preview and never re-versioned; the page says "Model updated 4 months, 1 week ago",
  i.e. roughly June, and no 1.5 refresh appears in the catalogue.
- **Pricing is a flat $0.08 per second of output**, with no resolution tiers and no per-image
  charge — so at 720p Replicate ($0.40 for 5 s) charges less than xAI billed upstream for the same
  run ($0.71). Either the host absorbs the difference or its `video_output_duration_seconds` metric
  is priced below cost at 720p; no captured page explains which.
- **Replicate's README says "preview" in 2026-10-26 terms**, contradicting xAI's "out of preview and
  generally available" (2026-06-16). Recorded as a host lag, not a vendor statement.
- **24 fps is not stated**; Replicate's schema has no fps field at all, unlike fal's output object.

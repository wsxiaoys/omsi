## Captured content

- `https://replicate.com/tencent/hy-motion`, `/tencent/hy-motion-1.0`, `/tencent/hunyuan-motion` and
  `/fal/hunyuan-motion` each returned **HTTP 404**.
- `GET https://replicate.com/api/search?query=hunyuan` returned Tencent's other hosted families —
  `tencent/hunyuan-3d-3.1`, `tencent/hunyuan-video`, `tencent/hunyuan-image-3`,
  `tencent/hunyuan-image-2.1`, `tencent/hunyuan3d-2`, `tencent/hunyuan3d-2mv`,
  `tencent/hunyuanvideo-foley` — and **no motion-generation model**.
- `GET https://replicate.com/api/search?query=hy-motion` returned only unrelated fuzzy matches
  (`leonardoai/motion-2.0`, `zsxkib/mimic-motion`, `kwaivgi/kling-v3-motion-control`,
  `daanelson/motion_diffusion_model`, `uthana/text-to-motion-diffusion-v2`, …).
- `GET https://replicate.com/api/search?query=text%20to%203d%20motion` returned other text-to-motion
  models (`sprited/kimodo`, `uthana/text-to-motion-diffusion-v2`, `wanjon/ardy2vrm`,
  `uthana/create-character-v1`) and no Tencent motion model.

## What this establishes

- Replicate is **not** an independent host for HY-Motion 1.0 as of 2026-10-26. The single independent
  host record for this model is fal (see `sources/fal.ai/hunyuan-motion/2026-10-26.md`).
- Replicate's search does surface unrelated text-to-motion models, so the absence is specific to this
  model rather than to the modality.

## Gaps

- Replicate's model API returns HTTP 401 to unauthenticated metadata requests, so `created_at` and
  schema data could not be read programmatically; the negative claim rests on search results and 404s
  from the rendered routes.
- A private, unlisted, or community-hosted copy could exist without appearing in search.
- Whether Replicate plans to host it is not stated anywhere captured.

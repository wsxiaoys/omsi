## Captured content

### Readme (verbatim)

> Ideogram 4.5 generates images from text prompts and edits source images using natural language
> instructions.
>
> You can run it as a text-to-image model by providing only a prompt, or edit up to five source
> images by passing them in `images`. Use `size="source"` to preserve source proportions. If you
> provide a mask, black pixels are edited and white pixels are preserved.
>
> Billing is per generated image. Source-image edits have separate rates for some quality levels.

Page subtitle: "Generate and edit images with Ideogram 4.5, the latest for precise image
generation." Run count at capture: 3.9K.

### Input schema (verbatim field descriptions)

- `images`: "Up to 5 source images to edit. Omit for text-to-image generation. When a mask is
  provided, the first image is edited and the rest are used as references."
- `mask`: "Optional black and white mask for editing. Black pixels are edited, white pixels are
  preserved. Only used when at least one source image is provided. When a mask is used, the output
  matches the source size and the size input is ignored."
- `size`: enum `source`, `1024x1024`, `1280x896`, `896x1280`, `1344x768`, `768x1344`, `1536x640`,
  `640x1536`; default `source`; "Output size. 'source' preserves the source image proportions.
  Ignored when a mask is provided."
- `quality`: enum `very_low`, `low`, `medium`, `high`; default `medium`; "Edit quality. Higher
  quality is slower and more expensive."
- `num_images`: 1–8, default 1.
- `seed`: "Random seed. Set for reproducible generation."

### Billing tiers (verbatim from the page's `billingConfig`)

Summary line: "Billed per generated image by quality. Source-image requests have separate rates."

| Tier | Price |
| --- | --- |
| Low | "$0.03" per output image |
| Medium | "$0.06" per output image |
| High | "$0.10" per output image |
| Very low with source images | "$8" per thousand output images ($0.008/image) |
| Low with source images | "$0.03" per output image |
| Medium with source images | "$0.06" per output image |
| High with source images | "$0.22" per output image |

These match the first-party table exactly
([Ideogram model page](../../ideogram.ai/ideogram-4-5-model-page/2026-10-26.md)).

Note the asymmetry: `quality` exposes `very_low` for every request, but only a
"very_low-with-source-images" tier is priced. A prompt-only `very_low` request therefore has no
listed rate and its behavior is unverified.

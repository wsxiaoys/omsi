## Three Inworld models, three slugs

The organisation page lists `inworld/realtime-tts-1.5-max`, `inworld/realtime-tts-1.5-mini` and
`inworld/realtime-tts-2`. So Replicate distinguishes the two TTS-1.5 variants by slug — unlike fal,
which exposes Max only and calls it plain `inworld-tts`.

Run counts at capture: 332.4K (1.5 Max), 185.1K (1.5 Mini), 104.3K (TTS-2).

## Readme content, 1.5 Max (verbatim, abridged)

> Inworld Realtime TTS 1.5 Max is Inworld's flagship realtime text-to-speech model, offering the best
> balance of quality and speed. With <200ms median latency and support for 15 languages, it delivers
> the most natural, expressive speech for demanding applications.

> Ranked #1 on Artificial Analysis, Inworld Realtime TTS delivers natural, expressive speech at a
> fraction of the cost of alternatives.

Claimed features: "<200ms median latency"; "15 languages: English, Chinese, Japanese, Korean, Russian,
Italian, Spanish, Portuguese, French, German, Polish, Dutch, Hindi, Hebrew, and Arabic"; emotion
markups `[happy]`, `[sad]`, `[angry]`; non-verbal `[laugh]`, `[sigh]`, `[cough]`; "SSML pauses: Use
`<break time="1s" />`"; "Multiple formats: MP3, WAV, OGG Opus, and FLAC output".

The Mini page is the same text with "~120ms median latency" and "Ultra-fast, most cost-efficient" in
place of the Max positioning.

## Voices — and a self-contradiction worth preserving

> Set voice_id to one of these preset voices. Custom voices you clone in your own Inworld account are
> scoped to that account's API key and aren't usable here.

Four presets are documented in the README (Ashley, Dennis, Alex, Darlene), while the input schema
accepts an arbitrary string: "Use a preset voice name (e.g. 'Ashley', 'Dennis', 'Alex') **or a custom
cloned voice ID**." The README and the schema therefore disagree about whether a caller's own clone
works. The README's claim is the more specific one; the schema may simply be permissive.

## Input schema (from the embedded prediction schema)

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `text` | string | — | "Maximum 2,000 characters. Supports SSML break tags … emotion markups … non-verbal vocalizations" |
| `voice_id` | string | `"Ashley"` | preset name or custom cloned voice ID |
| `temperature` | number | `0` | 0–2; "Set to 0 to use the model default (1.1)" |
| `audio_format` | enum | `mp3` | `mp3`, `wav`, `ogg_opus`, `flac` |
| `sample_rate` | enum | `48000` | `8000`, `16000`, `22050`, `24000`, `32000`, `44100`, `48000` |
| `speaking_rate` | number | `0` | 0–1.5; "Set to 0 for normal speed (1.0)" |
| `text_normalization` | enum | `auto` | `auto` / `on` / `off` |

Note the default `temperature` of **1.1**, which differs from the 1.0 default stated in Inworld's
current docs (written for TTS-2).

| `inworld/realtime-tts-2` | $0.025 per 1,000 input characters | "or 40,000 characters for $1"; note "Price cut: $35/M → $25/M chars" |

Replicate bills on `character_input_count`. Its Max rate ($35/M) is **above** Inworld's own launch
list ($25/M) and 3.5× fal's ($10/M).

## Summary

Replicate is the more complete host for this generation: both variants, an explicit output-format
enum including FLAC and OGG-Opus, 44.1/22.05 kHz sample rates that fal does not offer, and a
temperature control. It is also the more expensive host for Max and the one whose README and schema
disagree about cloned voices.

The readme also documents the 15 production languages by name, steering examples
(`[say excitedly]`, `[whisper in a hushed style]`), single-property steering axes, inline non-verbals
(`[laugh]`, `[breathe]`, `[clear throat]`, `[sigh]`, `[cough]`, `[yawn]`), capitalisation for emphasis,
and a "Choosing between Inworld TTS models" section that recommends 1.5 Max "for raw 1.5-era quality".

The language figures here (15 + 90 experimental, and "100+ languages" in the tagline) are the launch
framing; the vendor's current language page claims 623 codes / 470 languages
([`tts-language-support`](../../inworld.ai/tts-language-support/2026-10-26.md)). The readme is stale
against the vendor docs.

## Input schema (from the embedded prediction schema)

| Field | Type | Default | Notes |
| --- | --- | --- | --- |
| `text` | string | — | "Maximum 2,000 characters. Supports natural-language steering with bracketed instructions … Inline non-verbal tags … SSML break tags … Capitalize words for emphasis" |
| `language` | enum | `auto` | `auto` + 15 production codes (`en`, `zh`, `ja`, `ko`, `ru`, `it`, `es`, `pt`, `fr`, `de`, `pl`, `nl`, `hi`, `he`, `ar`) |
| `voice_id` | string | `"Ashley"` | preset name "or a custom cloned voice ID" |
| `temperature` | number | `0` | 0–2; "Set to 0 to use the model default (1.1)" |
| `audio_format` | enum | `mp3` | `mp3`, `wav`, `ogg_opus`, `flac` |
| `sample_rate` | enum | `48000` | `8000`, `16000`, `22050`, `24000`, `32000`, `44100`, `48000` |
| `speaking_rate` | number | `0` | 0–1.5; "Set to 0 for normal speed (1.0)" |
| `text_normalization` | enum | `auto` | `auto` / `on` / `off` |

Output schema: a single `output` URI (audio file). Two schema facts conflict with the vendor's
current docs: the host exposes **`temperature`** (which Inworld's docs say is "Not supported by
`inworld-tts-2`", replaced by `deliveryMode`) and it exposes **no `deliveryMode`**, no
`synthesisContext`, no steering-mode switch and no `languageSettings`. The readme and schema also
disagree on cloning: the readme says an account's cloned voices "aren't usable here", while the
schema says `voice_id` accepts "a custom cloned voice ID".

## Pricing (billing config embedded in the page)

| Rate | Restated | Note |
| --- | --- | --- |
| $0.025 per 1,000 input characters | "or 40,000 characters for $1" | "Price cut: $35/M → $25/M chars (requested by irtefa)" |

Billed on `character_input_count`, i.e. the same meter as the vendor's own per-character billing. The
$25/M rate equals Inworld's pay-as-you-go list price for TTS-2
([`pricing`](../../inworld.ai/pricing/2026-10-26.md)), so Replicate is not marking the model up at
capture — unlike its 1.5 Max rate ($35/M against a $25/M launch list). Hardware is listed as CPU;
the sample prediction log reads "Synthesized 0.14MB audio in 2.32sec / Processed characters: 169".

## Summary

Replicate is the only host in this corpus with a documented TTS-2 schema, and the only one exposing
the 15 production languages, all four output containers and 8–48 kHz selectable rates. It is also a
non-realtime integration: no `deliveryMode`, no `synthesisContext`, no WebSocket, so the model's
headline features (steering modes, multi-turn audio) are not reachable through this endpoint. The
readme's "#1 on Artificial Analysis" line is stale — the 2026-10-26 board ranks TTS-2 7th
([AA](../../artificialanalysis.ai/text-to-speech-leaderboard/2026-10-26.md)).

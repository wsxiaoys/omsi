  - https://replicate.com/explore?query=lingbot (HTTP 200; no "lingbot" string in the response)

## What was observed

Replicate returns **404** for the model path, for the owner page, and for plausible alternative owner
slugs, and its search and explore pages return no result containing "lingbot". Replicate's public
search API requires authentication (`401 Unauthenticated`), so the check is limited to the public web
surface.

A 404 on an owner page is the stronger signal: Replicate renders `/<owner>` for any account that
publishes at least one model, so the absence of `/robbyant` indicates the organisation publishes
nothing on Replicate, not merely that this one model is unlisted.

## Summary

As of 2026-10-26, LingBot World 2 is **not** hosted on Replicate. The only captured independent host
records are fal (API sessions) and Reactor (real-time playground and API), plus the vendor's own
demo partner LingGuang for mobile in China.

This record exists so the model page can state the host gap with a dated, reproducible check rather
than an unverified impression.

## Gaps

- Replicate's authenticated catalogue API (`/v1/models?query=…`) was not queried, so a private,
  unlisted, or differently-named endpoint cannot be excluded.
- No equivalent check was made on other aggregators (OpenRouter, Together, Bedrock, Vertex) because
  none of them serves world-model sessions in this knowledge base.
- Absence is a snapshot: a host can publish the model at any time without notice.

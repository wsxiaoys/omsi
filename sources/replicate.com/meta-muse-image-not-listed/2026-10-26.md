# Replicate: search for "muse" / "muse image" and Meta's owner page (no Muse Image listing found)

- **Origin:** Replicate public search API and direct page requests:
  - `GET https://replicate.com/api/search?query=muse`
  - `GET https://replicate.com/api/search?query=muse+image`
  - `https://replicate.com/meta` (Meta's owner page)
  - `https://replicate.com/meta/muse-image`
- **Evidence kind:** provider catalogue search (record of absence, not of a hosted model).
- **Publication date:** not applicable; searches run on the capture date.
- **Capture date:** 2026-10-26.
- **Relevant models:** Meta Muse Image (`muse-image-1.0`), expected but not found.
- **Capture type:** JSON search results and HTTP status codes, transcribed.

## What was searched and what came back

`GET https://replicate.com/api/search?query=muse` returned HTTP 200 with a `models` array of six
loosely matched entries — `elevenlabs/music`, `lebonze/museai`, `meta/musicgen`,
`douwantech/musepose`, `minimax/music-01`, `douwantech/musev` — and **no model named or described
as Muse Image**. Every hit matches "muse" inside "music", "museai", "musepose" or "musev"; none is
a Meta image model.

`GET https://replicate.com/api/search?query=muse+image` returned 25 image models
(`prunaai/p-image`, `minimax/image-01`, `openai/gpt-image-2`, `qwen/qwen-image`,
`xai/grok-imagine-image`, …) with **no Muse Image**.

`https://replicate.com/meta` returned HTTP 200 with Meta's owner page; the served HTML contains
**zero** occurrences of "muse" (case-insensitive), so Meta's Replicate presence does not include it.

`https://replicate.com/meta/muse-image` → HTTP 404 (Replicate's not-found template).

## What this establishes

As of 2026-10-26 Replicate does not host Meta Muse Image. This is evidence of a failed search, not
proof that no private or differently named deployment exists, and it does not speak to whether
Replicate will list it later. Meta's own model page names fal, Runway and OpenRouter as the places
to run Muse Image and does not mention Replicate
([Meta model page](../../meta.com/muse-image-model-page/2026-10-26.md)), which is consistent.

Consequence for the page: Replicate cannot serve as the independent host record, and no Replicate
price or default-parameter comparison exists.

## Gaps

- Search ranking may hide low-traffic models; a listing under an unrelated owner name could have been
  missed.
- The authenticated API (`GET https://api.replicate.com/v1/models?query=…`) was not queried; it
  requires a token.
- Replicate's `/meta` page renders client-side, so a model absent from the served HTML could still
  appear after hydration — the search API result is the stronger evidence.

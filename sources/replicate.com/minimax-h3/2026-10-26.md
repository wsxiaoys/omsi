# Replicate: `minimax/h3` — and the absence of `minimax/h3-max`

- Origin: Replicate model page <https://replicate.com/minimax/h3>; search results for
  <https://replicate.com/search?query=minimax>; direct probes of
  <https://replicate.com/minimax/h3-max> and <https://replicate.com/minimax/hailuo-03>
- Evidence kind: provider documentation (host model page and README) plus a host-absence observation
- Publication date: the page shows "Model created — 2 months, 1 week ago" at capture (≈ 2026-08-17);
  no absolute date is printed. Capture date 2026-10-26.
- Capture date: 2026-10-26
- Relevant models: MiniMax H3 (hosted); MiniMax H3 Max (not hosted)

## Hosted model, verbatim README

> Generate videos with MiniMax H3, a multimodal video model from MiniMax that supports text-to-video,
> first- and last-frame image-to-video, and reference-based video generation.

> The model supports 4–15 second videos at 768P or 2K resolution.

Inputs listed: `prompt`, `first_frame_image`, `last_frame_image`, `reference_image_urls`,
`reference_video_urls`, `reference_audio_urls`, `duration` (4 to 15), `resolution` (768P or 2K),
`ratio` (concrete ratio for text-to-video; image-to-video uses `adaptive`).

Billing, verbatim:

> MiniMax H3 is billed per second of generated video. 768P outputs cost $0.08 per second, and 2K
> outputs cost $0.13 per second.

Page statistics at capture: 82.5K runs.

## Host absence

| Probe | Result |
| --- | --- |
| `https://replicate.com/minimax/h3` | HTTP 200 (hosted) |

The Replicate search results for "minimax" contain no H3 Max entry; the H3 page's README does not
mention H3 Max, a fal relationship, or any second H3 variant.

## What this establishes

- **Replicate is a second independent host for H3 but not for H3 Max.** On the same day fal served 21
  H3 Max endpoints, Replicate served only the parent H3. H3 Max is therefore a **single-host model**
  among the hosts checked (fal and Replicate), and a MiniMax-API model.
- Replicate's H3 prices match MiniMax's own list exactly ($0.08/s 768P, $0.13/s 2K), which supports
  the reading that Replicate's H3 is a straight resale of the vendor endpoint rather than a
  re-optimised deployment.
- Replicate's H3 exposes the same 4–15 s, 768P/2K envelope as MiniMax's own API and **not** fal's
  extra 480p/4K options — so the 480p and 4K tiers seen on fal's `minimax/h3` endpoints are
  host-specific configurations, not model capabilities.
- The absence of `minimax/h3-max` on Replicate is consistent with fal developing and training the
  derivative itself: a post-trained variant exists only where its author serves it (and where the
  base-model vendor chose to resell it, i.e. MiniMax's own API).

## Gaps

- No absolute creation date; "2 months, 1 week ago" is relative to the capture date.
- The Replicate HTTP API (`api.replicate.com/v1/models?query=…`) requires authentication (401
  "Unauthenticated"), so the version list, schema JSON, and `supports_cancelation` flags could not be
  read. The README and page prose were captured instead.
- A 404 on `replicate.com/minimax/h3-max` proves Replicate does not publish that slug; it does not
  prove no Replicate account offers H3 Max under another owner.

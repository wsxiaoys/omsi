## Endpoint identity

`minimax/speech-2.8-hd` is a public model under the vendor's own `minimax` namespace on Replicate.
Status checks in the same capture: `minimax/speech-2.8` returns 404 (no untiered 2.8 alias);
`minimax/speech-2.8-turbo`, `minimax/speech-2.6-hd`, `minimax/speech-2.6-turbo` and
`minimax/speech-02-hd` all return 200. Run count shown: **379.2K**.

The Turbo sibling is priced the same way and on the same schedule: `minimax/speech-2.8-turbo` bills
"$0.06 per thousand input tokens" ("or around 16,666 tokens for $1") plus the same `$0.0001 per
second` hardware line, and shows the same "Model created 8 months, 3 weeks ago" age.

Note the schema is **flat** — no `voice_setting`/`audio_setting` nesting, no `voice_modify`, no
`pronunciation_dict`, no `text_normalization_mode`, no `output_format` (hex/url), and `channel` is a
string enum rather than an integer.

## Pricing (verbatim from the embedded billing config)

> per thousand input tokens — $0.10 — "or 10,000 tokens for $1"

Page-level `price` field: `$0.0001 per second` (p50 `$0.00021`), i.e. the CPU hardware line, which is
dwarfed by the per-token charge.

## What this establishes

- **A second independent host** exists and prices the model identically: $0.10 per 1,000 input
  characters, matching fal and MiniMax's own $100/M list. Three publishers, one number.
- Replicate's schema **exposes the most control of the three routes** — emotion including `auto`,
  `neutral`, `calm` and `fluent`; `subtitle_enable`; and a documented path from its own
  `minimax/voice-cloning` model into `voice_id`. That is the only route captured where a cloned
  voice is documented as usable end-to-end.
- Replicate's language list is the **largest of the three**: it keeps Persian, Filipino and Tamil
  (which fal drops), adds a standalone `Cantonese` value next to the vendor's combined `Chinese,Yue`,
  and adds `None`/`Automatic` sentinels.
- **Four of the README's numeric claims conflict with the vendor or with measurement:**
  - "ranked first on the Artificial Analysis Speech Arena" — at capture, the AA TTS leaderboard
    places Speech 2.8 HD at Elo 1174.05, 24th of 98 entries and ~159 Elo below the leader
    ([AA record](../../artificialanalysis.ai/minimax-speech-2.8-hd-leaderboard/2026-10-26.md)).
  - "32 languages" — the vendor says 40, and Replicate's own `language_boost` enum lists 40 names.
  - "5 seconds of reference audio" — the vendor's clone API requires "minimum 10 seconds".
  - "over 20 interjections including (whistles) … and (applause)" — the vendor's T2A reference lists
    19 and omits both; only the voice-clone reference lists 22.
- The "autoregressive Transformer architecture with a Flow-VAE decoder" sentence is the **only
  architecture description found anywhere in the corpus** for this model, and it is unattributed
  host copy — no MiniMax page captured here describes the architecture.
- Replicate's relative "created" date (≈2026-02-05) is within a day of fal's 2026-02-04 listing and
  ~13 days after the vendor's 2026-01-23 announcement.

## Gaps

- No measurement behind "ranked first"; no date, no arena snapshot, no methodology.
- No statement of which MiniMax API account proxies calls, or of rate limits and concurrency.
- No watermark or provenance statement.
- No version identifier for the served checkpoint (the page shows a version hash but no model
  revision semantics).
- The page does not say whether `subtitle_enable` output format is documented anywhere.

## Result

- A case-insensitive search for `pixelcut` in `sitemap-models.xml` returns **0 matches**, and 0 in
  the sitemap index.
- All five direct URLs return **HTTP 404** (including `/pixelcut`, so there is no Pixelcut owner
  page at all).
- `https://api.replicate.com/v1/models?query=pixelcut` returns 401 without a token, so the API search
  could not be used; the sitemap and URL probes are the evidence.

Replicate therefore does **not** host Pixelcut's background removal. This matters because the roster
lists Replicate as a general discovery source: the model is a fal-only host entry among the hosts
checked.

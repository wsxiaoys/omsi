## Readme (verbatim)

> Qwen-Image-3.0
>
> Qwen-Image-3.0 is Alibaba's image generation and editing model, with a focus on accurate text
> rendering and complex layouts.
>
> **What it's good at**
>
> Accurate text. Renders small, legible text and handles native rendering across many languages and
> fonts.
>
> Complex layouts. Generates posters, infographics, and multi-element compositions in a single
> pass.
>
> Photographic detail. Produces sharp, detailed images.
>
> Image editing. Pass a reference image to edit, restyle, or transform it.
>
> **Inputs**
>
> prompt — what to generate or how to edit the image.
>
> image — optional reference image for editing and image-to-image.
>
> aspect_ratio — output aspect ratio (1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 2:1, 1:2).
>
> match_input_image — when editing, keep the input image's aspect ratio.
>
> negative_prompt — elements to avoid.
>
> enable_prompt_expansion — automatically expand and optimize your prompt.
>
> seed — set for reproducible results.
>
> **Pricing**
>
> $0.03 per output image.

## Input schema (from the page's embedded OpenAPI, verbatim descriptions)

| Field | Type / default | Description |
| --- | --- | --- |
| `prompt` | string, required | "Text prompt for image generation or editing" |
| `image` | uri, nullable | "Optional reference image for image editing, style transfer, or image-to-image generation" |
| `match_input_image` | boolean, default false | "When true and an image is provided, use the input image's aspect ratio and resolution instead of the aspect_ratio parameter" |
| `aspect_ratio` | enum, default `1:1` | "Aspect ratio of the generated image" — `1:1, 16:9, 9:16, 4:3, 3:4, 3:2, 2:3, 2:1, 1:2` |
| `enable_prompt_expansion` | boolean, default true | "Automatically expand and optimize the prompt for better results" |
| `negative_prompt` | string, default `""` | "Negative prompt to specify elements to avoid in the generated image" |
| `seed` | integer, nullable | "Random seed for reproducible generation. Range: 0-2147483647" |

Output: a single `uri` (one image). There is **one** endpoint for both generation and editing: no
`image` means text-to-image.

## What this establishes

- Replicate exposes Qwen Image 3 as **one endpoint** that switches between generation and editing
  on the presence of `image`, at **$0.03 per output image** — 25% below Alibaba's own
  `qwen-image-3.0-pro` 1K price and level with Alibaba's `qwen-image-3.0` price.
- The host's interface is materially narrower than the vendor API: no `num_images` (one image per
  call), no pixel `size` (nine aspect-ratio presets only), **one** reference image instead of the
  vendor's 1–3, and no `prompt_extend_mode` or thinking-mode control.
- Replicate's own copy uses "Qwen-Image-3.0" without a pro/standard qualifier, so the listing does
  not disclose which vendor tier it serves.
- Outputs are marked commercially usable by the host, with the claim anchored to Alibaba's own
  Model Studio documentation rather than to a Replicate licence grant.

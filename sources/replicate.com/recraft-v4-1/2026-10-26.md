## Summary

Replicate hosts the base V4.1, Pro, Utility, and Utility Pro raster endpoints as official models
on CPU hardware, consistent with a pass-through to Recraft's API. Every Replicate price is above
Recraft's list: base $0.04 vs $0.035, Pro $0.25 vs $0.21, Utility $0.04 vs $0.035, Utility Pro
$0.25 vs $0.21. The base endpoint exposes only prompt and aspect ratio; there is no exact-size
control, style, seed, color, batch, or format parameter. No vector endpoint exists on Replicate.

## Gaps

- Replicate does not state which Recraft API model value it calls, nor which Recraft distribution
  agreement covers the resale.
- The base endpoint's `aspect_ratio` has no accompanying pixel-size table; the README says
  "~1024px" but does not enumerate the sizes.
- No `size`, `colors`, `background_color`, `style_id`, `style_reference_urls`, `style_match`,
  `random_seed`, `n`, `image_format`, or `response_format`.
- The page lacks the "Data privacy" and "Zero training" badges that the V4 Pro listing carries;
  no source explains whether retention/training terms differ or the badges were simply omitted.
- Replicate's prices are above list with no published explanation; the model was created
  2026-05-11, three days before Recraft's 2026-05-14 announcement.
- Run count is a popularity signal, not a quality signal.

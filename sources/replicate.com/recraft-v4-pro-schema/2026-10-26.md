## Captured content

Input object — only `prompt` is required. Exactly three properties:

| Property | Schema |
| - | - |
| `prompt` | string, required, "Text prompt for image generation (up to 10,000 characters)" |
| `aspect_ratio` | enum, default `"Not set"`: `Not set`, `1:1`, `4:3`, `3:4`, `3:2`, `2:3`, `16:9`, `9:16`, `1:2`, `2:1`, `4:5`, `5:4`, `6:10`, `14:10`, `10:14` — "Aspect ratio of the generated image" |
| `size` | enum, default `"2048x2048"`: `2048x2048`, `3072x1536`, `1536x3072`, `2560x1664`, `1664x2560`, `2432x1792`, `1792x2432`, `2304x1792`, `1792x2304`, `1664x2688`, `2560x1792`, `1792x2560`, `2688x1536`, `1536x2688` — "Width and height of the generated image. Size is ignored if an aspect ratio is set." |

Output: a single URI string (`"output": {"type": "string", "format": "uri"}`), i.e. one image per
prediction.

Status enum: `starting`, `processing`, `succeeded`, `canceled`, `failed`.

### Cross-check against Recraft's own size table

The 14 values in Replicate's `size` enum match Recraft's "2K models (Pro)" column exactly
(`../../recraft.ai/limits-and-sizes/2026-10-26.md`): `2048x2048`, `3072x1536`, `1536x3072`,
`2560x1664`, `1664x2560`, `2432x1792`, `1792x2432`, `2304x1792`, `1792x2304`, `1664x2688`,
`2560x1792`, `1792x2560`, `2688x1536`, `1536x2688`. That is direct evidence that the Replicate
endpoint is backed by `recraftv4_pro` (the 2K tier), not `recraftv4`.

### Not exposed by Replicate

`colors`, `background_color`, `style_id`, `style_reference_urls`, `style_match`, `random_seed`,
`n`, `image_format`, `response_format`, and any image input. Recraft's own API exposes the first
five of those for V4.

## Gaps

- Replicate exposes no color or background control, so Recraft's documented "color palette control"
  (which fal does expose) is unavailable through this host.
- `aspect_ratio` and `size` overlap; the schema says `size` "is ignored if an aspect ratio is set",
  but does not say which pixel size a given ratio resolves to on the Pro tier.
- No seed parameter means generation is not reproducible through Replicate even though
  `random_seed` exists upstream.

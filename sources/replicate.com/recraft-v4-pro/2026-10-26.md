### README (verbatim)

> Recraft V4 Pro is the high-resolution version of Recraft V4. It shares the same design taste,
> prompt accuracy, and creative capabilities, but generates images at 2x resolution (~2048px base)
> for print-ready assets, large-format work, and any use case where fine detail matters.

> V4 is a ground-up rebuild focused on visual taste — the model makes intentional decisions about
> composition, lighting, color relationships, and material realism. The result is images that feel
> art-directed rather than stock-like, even from simple prompts. V4 Pro takes that same quality and
> delivers it at a resolution suitable for professional production.

> V4 Pro takes about 28 seconds per image. If you need faster iteration and don't need the extra
> resolution, use the standard Recraft V4 model (~10 seconds per image).

Features as listed (verbatim, condensed):

- "**High-resolution output.** Generates at 2048×2048 base resolution and other large formats up to

- "**Design taste in every output.**" — aesthetic decisions about arrangement, color interaction,
  and where the eye moves.
- "**Strong prompt accuracy.** Whether your prompt is a few words or a detailed paragraph (up to

- "**Integrated text rendering.** Typography is treated as a structural part of the composition, not

- "**Production-ready outputs.**" — "product shots, editorial photography, posters, packaging".
- "**Multiple aspect ratios.** Generate in 1:1, 4:3, 3:2, 16:9, 9:16, and other common ratios."

### V4 vs V4 Pro, as Replicate frames it (verbatim)

> **V4 Pro** (this model): Print production, large-format work, high-detail output. ~28 seconds per
> image.
> **V4**: Fast iteration, social media, web assets, concept exploration. ~10 seconds per image.
> Both produce the same art-directed quality — the difference is resolution.

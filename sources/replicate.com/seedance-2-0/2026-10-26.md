## README (verbatim, selected)

> Generate high-quality video from text, images, video clips, and audio — all in one pass with
> synchronized sound. Seedance 2.0 is ByteDance's next-generation video model, built on a unified
> multimodal architecture that accepts mixed inputs and produces coherent, audio-synced output.

> Seedance 2.0 is a significant upgrade from 1.5 Pro:
>
> - **Multimodal reference inputs** — combine up to 9 images, 3 video clips, and 3 audio files in a
>   single generation. Reference them in your prompt as [Image1], [Video1], [Audio1], etc.
> - **Better motion and physics** — more realistic rendering of complex interactions like sports,
>   dancing, and object collisions.
> - **Video editing and extension** — modify existing videos or extend them by providing a reference
>   video and describing what should happen next.
> - **Intelligent duration** — set duration to -1 and let the model pick the best length for the
>   content.
> - **Adaptive aspect ratio** — set aspect ratio to "adaptive" and the model will choose the best fit
>   based on your inputs.

> When using reference images, the model maintains facial features, clothing, and style across the
> generated video. This makes it possible to create multi-shot narratives with consistent characters.

> For technical details and architecture, see the official Seedance 2.0 page.

Two differences from the vendor API are worth recording. Replicate exposes `seed` for Seedance 2.0
although BytePlus's parameter documentation lists `seed` as supported only on 1.5 pro / 1.0 pro /
1.0 pro fast. Replicate also allows a `9:21` aspect ratio, which is not in BytePlus's documented list
(16:9, 4:3, 1:1, 3:4, 9:16, 21:9, adaptive). Neither host nor vendor explains the discrepancy.

# Resemble AI: "Chatterbox Multilingual v3: TTS with embedded watermarking for 25 languages"

- Origin: Resemble AI (Research), Zihan Jin, "Chatterbox Multilingual v3: TTS with embedded
  watermarking for 25 languages", <https://www.resemble.ai/resources/chatterbox-multilingual-v3-tts-with-embedded-watermarking-for-25-languages>
- Evidence kind: official documentation (first-party release post: capability claims, CER evaluation,
  latency, deployment paths, stated limitations)
- Publication date: 2026-06-10 ("Today, June 10, 2026, we are releasing Chatterbox Multilingual v3").
  Capture date 2026-10-26
- Relevant models: Chatterbox Multilingual v3, Single Language Pack (six finetunes), NVIDIA NIM
  deployment of v3

## Release claims (verbatim)

> Chatterbox Multilingual v3 is the next general-purpose multilingual TTS model in the Chatterbox
> family. It supports 25 total languages (including 4 dialects and 6 tuned Language Pack models), keeps
> the same 0.5B Llama backbone as v2 under MIT license, and ships meaningful improvements in speaker
> similarity, hallucination rate, and conversational naturalness.

> Chatterbox Multilingual v3 open source ships with PerTh watermarking embedded by default on every
> self-hosted audio output, across every supported language.

Training changes: "We expanded the multilingual training mixture from 25.6k hours to 36.7k hours, and
improved balancing across script reading, narration, and conversational data". Same 0.5B backbone as
v2; improvements "come primarily from data, training, and language-specific specialization rather than
from any increase in model size."

## Languages (verbatim list)

Arabic (ar), Chinese (zh, Language Pack), Czech (cs), Dutch (nl), English (en), Finnish (fi), French
(fr), German (de), Hebrew (he), Hindi (hi, Language Pack), Italian (it), Japanese (ja), Korean (ko),
Norwegian (no), Polish (pl), Portuguese (pt), Portuguese Brazilian (pt-br, dialect), Portuguese
Portugal (pt-pt, dialect), Russian (ru), Spanish (es), Spanish Mexico/LATAM (es-mx, dialect), Spanish
Spain (es-es, dialect), Swedish (sv), Turkish (tr), Vietnamese (vi).

This list is **25 entries but a different set from the 23 in the repository README**: it adds Czech and
Vietnamese, drops Greek, Malay and Swahili, and splits Portuguese and Spanish into dialect variants.

## Evaluation (vendor-run, CER)

Protocol (verbatim): "For each language, we generated 100 samples from held-out prompts, transcribed
the synthesized audio with `whisper-large-v3` set to the target language, and computed CER against the
source text."

Reported results:

| Band | Languages (CER) |
| --- | --- |
| Under 1% | Italian and German base "under 0.20%"; LatAm Spanish pack 0.28%, Mandarin pack 0.41%, European Spanish pack 0.55%, English 0.65%, Hebrew 0.93% |
| 1–5% | Dutch, Russian, base Spanish (2.89%), European Portuguese, Brazilian Portuguese, base Portuguese (3.85%), Norwegian, Turkish |
| 6–8% | Hindi, French, Polish, Arabic |
| Caveated | Finnish 17.52%, Japanese 21.87%, Czech 32.21% |
| Not production quality | Korean 70.90%, Vietnamese 75.21% |

Vendor's own caveat (verbatim): "CER is still an imperfect proxy for what we actually care about. It
captures intelligibility and stability, but it does not measure prosody, speaker similarity, or
expressive delivery". And: "We recommend against using v3 for commercial deployments in either
language [Korean or Vietnamese] until we have shipped an improvement."

## Latency and deployment (vendor-run)

- "On a single H100 with our unoptimized PyTorch implementation": TTFB "Under 300ms", RTF "approximately
  5" (generates "roughly five times faster than real time").
- NVIDIA NIM: v3 is available in the NVIDIA build catalog with TensorRT-LLM acceleration, claimed
  "2x-39x throughput vs unoptimized PyTorch", free API for evaluation via build.nvidia.com.

## Watermarking (verbatim)

> PerTh is a neural watermarking system that encodes an imperceptible signal into the audio waveform at
> generation time. It is designed to survive the manipulations that strip metadata-based provenance:
> MP3 and Opus compression, telephony codecs, audio editing, format conversion, partial clipping, and
> the resampling that happens when audio moves between platforms.

Stated limits: "we have not yet published systematic robustness curves under adversarial conditions";
the watermark "produces a binary signal for 'this audio was generated by Chatterbox,' not a
model-version signal or a tenant-attribution signal". Regulatory framing: "EU AI Act Article 50
requires that AI-generated audio be marked in a machine-readable format starting in August 2026".

## Summary

First-party evidence that Multilingual v3 shipped 2026-06-10 (inside the roster window) under the same
MIT licence and 0.5B backbone as v2, with a 25-language claim that does not match the repository's
23-language list, a CER evaluation the vendor itself calls incomplete, and an explicit admission that
two of the advertised languages are not production-ready.

## Gaps

- CER protocol uses one ASR model and 100 samples per language; no confidence intervals, no human
  evaluation, no speaker-similarity numbers ("we will publish those numbers when they are ready").
- No per-language TTFB/RTF table is present in the captured text, only the summary figures.
- No pricing for the NIM route; no statement of which languages the Single Language Pack covers beyond
  the six named.
- No sample rate, input-length limit or maximum output duration stated.

## Summary

The product page confirms three tiers by name and repeats the 6-minute ceiling, "trained on fully
licensed datasets", and the Enterprise indemnification. It adds one detail the launch post does not:
the API route is described as "our latest model", which in the same page's tier list is **Large**.
That is the closest first-party statement to "the API serves Large" — it is a marketing page, not the
API reference, and the API reference itself never names a size (see
`../../stability.ai/stable-audio-3-api-reference/2026-10-26.md`).

## Gaps

- No parameter counts, sample rate, output formats, languages, prices, or release dates.
- "Up to six minutes" here versus "up to 6:20" on the launch post and 380 s in the API — the page
  rounds.
- The page does not say which size the free web app runs.

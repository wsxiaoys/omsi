## Positioning, verbatim

> "StepFun offers a range of reasoning models covering text reasoning, multimodal understanding,
> agent, and code analysis scenarios. We recommend `step-5-preview` for software engineering,
> professional knowledge work, and multi-step agent tasks. It supports text, image, and video
> input with a 1M-token context window. Use `step-3.7-flash` for high-speed multimodal reasoning
> or `step-3.5-flash` for pure-text workloads."

This is the vendor's own tier split: Step 5 Preview is the capability tier; `step-3.7-flash`
(196B / ~11B active, 256K context) is the speed tier; `step-3.5-flash` is the text-only budget
tier.

## Reasoning effort, verbatim

> "Models that support three levels of reasoning effort let you tune thinking depth via a
> parameter. The Chat Completion API uses `reasoning_effort`; the Messages API uses
> `output_config.effort`."

| Reasoning effort | Use cases |
| :- | :- |
| `low` | Simple Q&A, summarization, rewriting, information extraction |
| `medium` | Default recommendation, suitable for general reasoning and multi-step tasks |
| `high` | Complex reasoning, math, planning, code analysis |

The page does not say whether reasoning can be switched off entirely for Step 5 Preview; it
describes only the three levels. The model card states its published benchmark results use
**High** ([model card](../../huggingface.co/stepfun-step-5-preview-model-card/2026-10-26.md)),
and OpenRouter reports reasoning as mandatory with a `medium` default
([OpenRouter](../../openrouter.ai/step-5-preview/2026-10-26.md)).

## Access surface, verbatim from the example

```
BASE_URL = "https://api.stepfun.ai/v1"
COMPLETION_MODEL = "step-5-preview"
```

The example uses the OpenAI Python SDK against StepFun's own OpenAI-compatible base URL,
streaming. This is the only captured evidence of the vendor's own endpoint hostname.

## Summary

The reasoning guide establishes the vendor's tier positioning (Step 5 Preview = flagship
reasoning/agentic tier), the three-level effort control with per-level intended use, and the
`https://api.stepfun.ai/v1` OpenAI-compatible base URL.

## Gaps

- No statement about whether reasoning is mandatory, nor about token accounting for reasoning
  beyond the pricing page's "output tokens include both the reasoning process and final answer".
- No Messages API capture; the `output_config.effort` parameter is named but not documented here.

## Opening, verbatim

> "**Step 5 Preview is StepFun's flagship model for agentic work.** It delivers frontier-level
> performance across software engineering and professional knowledge work, with particular
> strength in finance. It natively supports text, image, and video input and provides a **1M-token
> context window**, making it suitable for tasks that require large amounts of information, tool
> calls, and continuous progress toward a deliverable."

## At a glance, verbatim table

| Specification | Step 5 Preview |
| :- | :- |
| **Model ID** | `step-5-preview` |
| **Context window** | **1M tokens** |
| Input types | Text, images, and video |
| Output type | Text |
| Maximum input | **1M tokens** |
| Maximum output | **64k tokens** |

`step-5-preview` is the API model ID. This page is the only captured source that prints an
output-token ceiling; the [model card](../../huggingface.co/stepfun-step-5-preview-model-card/2026-10-26.md)
says "Up to 1M tokens" for maximum output instead.

## Core capabilities, verbatim

> "**Long-context understanding and reasoning** — Analyze long documents, multiple source
> materials, and conversation history within a 1M-token context. **Typical tasks**:
> cross-document question answering and research material organization."

> "**Programming and software engineering** — Work across multiple programming languages and
> engineering tasks, with tools to advance development, modification, and verification.
> **Typical tasks**: troubleshooting, code changes, and test creation."

> "**Multi-step Agent tasks** — Use tools provided by an application to retrieve information,
> process documents, and continue through multi-step work. **Typical tasks**: deep research and
> analytical reporting."

> "**Multimodal understanding** — Combine images, video, and text to extract and analyze
> multimodal information. **Typical tasks**: chart analysis, screenshot question answering, and
> video summarization."

Tool-use scoping, verbatim — this is the vendor's own boundary statement:

> "Tools, search, and code execution capabilities are provided by the application that integrates
> the model; the model does not itself access your local environment or external services."

## Input limits, verbatim table

| Item | Supported range |
| :- | :- |
| Image input method | URL or Base64 |
| Image formats | JPG/JPEG, PNG, WebP, and static GIF |
| Images per request | Up to 60 images |
| Image detail level | `low`, `high` |
| Video input method | URL, Base64, or a `stepfile://` reference from the Files API |
| Video formats | MP4, QuickTime, and Matroska |
| Video URL limit | Individual MP4 files under 128 MB; less than 5 minutes is recommended |

## Features and configuration, verbatim table

| Feature / configuration | Supported range / parameter |
| :- | :- |
| Streaming output | Supported |
| Tool calling | Supported |
| Structured output | JSON Mode and JSON Schema supported |
| Reasoning effort | Supports `low`, `medium`, and `high`; `reasoning_effort` on the Chat Completions API, `output_config.effort` on the Messages API |
| Prompt caching | Supported |
| Output length | `max_tokens` defaults to `INF`; no limit is applied and the model determines it automatically |

Note the collision: the table above says `max_tokens` defaults to `INF` with "no limit", while
the At-a-glance table caps maximum output at 64k. Both statements are on the same page.

## Integration, verbatim essentials

1. "Create an API key on the StepFun Open Platform."
2. "Open the Quickstart, select Step 5 Preview, and switch between the text chat, image
   understanding, and video understanding examples."
3. "Send a request with cURL or Python and read the result from `choices[0].message.content`."

A separate page in the same docs set uses `BASE_URL = "https://api.stepfun.ai/v1"` with
`model = "step-5-preview"`

## Preview status

The page never uses the word "preview" as a status term — not in the heading, not in a banner,
not in a note. "Preview" appears only inside the model ID `step-5-preview` and the product name.
There is no GA date, no end-of-preview date, no support window, and no statement of what changes
at GA.

## Summary

The docs page is the strongest first-party statement of the model's operational envelope: 1M
input context, 64k output, text/image/video input with concrete per-request limits (60 images,
128 MB / ~5 min video), three reasoning-effort levels, tool calling, JSON mode and schema,
prompt caching, streaming. It supplies no date, no benchmark, and no preview lifecycle terms.

## Gaps

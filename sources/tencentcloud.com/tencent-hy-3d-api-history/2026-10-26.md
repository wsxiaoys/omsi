Release 4 is the only changelog entry that introduces model-version selection: the `Model` parameter
(3.0/3.1) appears on the Pro submit API on **2026-01-20**. Release 1 (2025-12-15) is the first publication
of any Hunyuan 3D generation API on this endpoint, and the first release with no `Model` parameter is
therefore version 3.0 only.

## Gaps

- No release note describes what model version 3.1 changed in quality, geometry or texture; the only 3.1
  content in the changelog is the arrival of the `Model` switch.
- The changelog has no entry for the original 3.0 *model* launch announcement (only for the API publication),
  and no entry for any 3.1 announcement outside the API surface.
- `SubmitAutoRiggingJob` and `SubmitHunyuanTo3DTextureEditJob` have no dedicated page captured here, so their
  inputs (and whether they accept 3.1 output) are not recorded.

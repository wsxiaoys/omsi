# Tencent Cloud international docs: Tencent HY 3D Global Billing Overview

- Origin: Tencent Cloud (international) documentation — "Tencent HY 3D Global Billing Overview",
  <https://intl.cloud.tencent.com/document/product/1284/75281> (product 1284)
- Evidence kind: official documentation (vendor pricing and quota terms)
- Publication date: "Last updated: 2026-05-08 19:51:49"
- Capture date: 2026-10-26
- Relevant models: Tencent HY 3D Global — Professional (hosts: "Pro") and Express (hosts: "Rapid"), plus the
  post-processing APIs (3D Part Generation, Smart Topology, 3D Texture Edit, UV Unfold, Auto Rigging,
  Convert 3D Format)

## Billing unit

Billing is in **credits**, one credit pool shared by the whole product. Settlement order: purchased prepaid
resource package first, then postpaid. "Failed tasks do not deduct credits (no deduction for any failure,
including failures caused by risk control policy)."

| Mode | Price |
| --- | --- |
| Prepaid, 1,000 credits | USD 15 → USD 0.015/credit |
| Prepaid, 10,000 credits | USD 145 → USD 0.0145/credit |
| Prepaid, 50,000 credits | USD 700 → USD 0.014/credit |
| Prepaid, 100,000 credits | USD 1,350 → USD 0.0135/credit |
| Postpaid | USD 0.02/credit, "daily settlement" |

Free tier: "Upon first-time activation of the Tencent HY service, the following APIs will grant a free call
tier" — 200 credits/user, one-time package valid 1 year, covering every listed API.

## Credits per call (verbatim tables, condensed)

Professional edition — "By default, it is text/image-to-3D in ordinary texture mode, consuming 25 credits per
call":

| GenerateType | Consume Credits |
| --- | --- |
| Normal (textured geometry) | 25.00 |
| LowPoly (textured geometry with intelligent mesh reduction) | 30.00 |
| Geometry (white model, no textures) | 15.00 |
| Sketch (sketch/line drawing in, textured geometry out) | 25.00 |

Additional Professional parameters, additive: `MultiViewImages` +10.00, `EnablePBR` +10.00,
`FaceCount` (custom face count) +10.00. "Selecting version 3.0 or 3.1 from the [Model] parameter will not
consume extra credits."

Express edition — "generating 3D models from text or images, normal texture mode, which consumes 15 credits
per use"; `EnablePBR` +10 credits/call.

Post-processing: 3D Part Generation 30 credits/call; Smart Topology 50 credits/call; 3D Texture Edit 30
credits/call; UV Unfold 10 credits/call; **Auto Rigging 10 credits/call**; Convert 3D Format 5 credits/call.

Worked example given by Tencent: LowPoly with PBR = 30 + 10 = 40 credits per call; 1,000 postpaid credits
with 100 free credits remaining = (1000 − 100) × 0.02 = USD 18.

## Concurrency

- Defaults: Professional 3 concurrent tasks, Express 1; shared across root and sub-accounts.
- Concurrency add-on packages: "5,000 USD/concurrency/month" for each API listed (Professional, Express, 3D
  Part Generation, Smart Topology, 3D Texture Edit, UV Unfold, Auto Rigging, Convert 3D Format).

## Derived per-call prices (editorial arithmetic, not vendor statements)

At the postpaid rate of USD 0.02/credit: Professional Normal = USD 0.50/call; +PBR = USD 0.60; +PBR
+multiview +custom face count = USD 1.10; Geometry = USD 0.30; Express = USD 0.30/call (USD 0.40 with PBR);
Auto Rigging = USD 0.20. At the best prepaid rate (USD 0.0135/credit) the same Professional Normal call is
USD 0.3375.

## Gaps

- The page states credit prices, not USD per call; any per-call figure is arithmetic.
- No regional price variation is stated; `Region` is a required API parameter but this page does not list
  supported regions.
- No statement of whether 3.1 generation is priced differently on the Express tier (which has no version
  parameter at all).

## Cross-check against the Tencent Cloud SDK

The page's parameter table does **not** list `ResultFormat` for the Pro API; the Tencent Cloud Go SDK for
the same product (`tencentcloud/ai3d/v20250513`, `models.go`, Apache-2.0-licensed, fetched
2026-10-26 from <https://raw.githubusercontent.com/TencentCloud/tencentcloud-sdk-go/master/tencentcloud/ai3d/v20250513/models.go>)
does. Relevant SDK comments, verbatim:

- `ResultFormat` (Pro submit): "生成模型的格式，仅限制生成一种格式； 生成模型文件组默认返回obj、glb格式（开启时Geometry参数时，默认为glb格式）；
  可选值：STL，USDZ，FBX" — one output format only; the default file set is OBJ + GLB, GLB only under
  Geometry; optional STL, USDZ, FBX.
- `Prompt` (Pro submit): "文生3D，3D内容的描述，中文正向提示词。<br>最多支持1024个 utf-8 字符。" — calls the prompt a
  *Chinese* positive prompt, 1024 UTF-8 characters.
- `TextureSize` (the sibling `SubmitTextureTo3DJob`, not the generation API): "仅支持正方形贴图，分辨率区间为720～4096，默认为4096"
  — square textures only, 720–4096 px, default 4096.
- `File3D`: `Type`, `Url`, `PreviewImageUrl`.

The SDK is machine-generated from Tencent's API definition and is therefore closer to the live contract
than the human-edited reference page; where they differ, the difference is recorded rather than resolved.

## Task model

- "This API is used to provide 3 concurrent tasks by default. Up to 3 submitted tasks can be processed
  simultaneously. A new task can be processed only after the previous one is completed."
- "A maximum of 20 requests can be initiated per second for this API."
- Domain `hunyuan.intl.tencentcloudapi.com`; common `Version` parameter `2023-09-01`; `Region` required.
- Submit returns `JobId` ("Task ID (valid period: 24 hours)") + `RequestId`.
- Query input: `JobId`. Query output: `Status` ("WAIT: waiting RUN: running; FAIL: failed DONE: successful"),
  `ErrorCode`, `ErrorMessage`, `ResultFile3Ds` ("Describes the generated 3d file array"), `RequestId`.
- The `File3D` structure (new in API release 1, see the history record) is not expanded on these pages;
  its fields are `Type`, `Url`, `PreviewImageUrl` per the SDK model definitions.

## Gaps

- No statement of what changed between model versions 3.0 and 3.1 beyond parameter availability, and no
  quality, polycount-accuracy, texture-resolution, or speed claim.
- `File3D` field list, up-axis, unit scale, and texture resolution of Pro output are not documented here.
- The docs are marked "AI-Translated"; wording is Tencent's machine translation, not a human-authored English
  text, so phrasing is evidence of the original Chinese meaning only approximately.
- The SDK is one published version of the API definition; it is not dated on the page, so whether its
  `ResultFormat` and prompt-language comments are current with the 2026-05-27 reference page is unknown.
- Whether `FaceCount`'s documented 3,000 floor is enforced (both hosts cap the low end at 40,000) is not stated.

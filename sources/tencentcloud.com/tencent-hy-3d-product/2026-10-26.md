## Marketing claims (verbatim, unquantified)

- "Native Large Model Architecture — A novel decoupled generation architecture for geometry and texture,
  employing a two-step process with dedicated geometry and texture large models, resulting in more refined
  geometric structures and richer texture colors." (landing page)
- "High-Precision Geometry Generation Large Model — Utilizes high-precision geometry generation technology to
  ensure accurate texture structures and contours, achieving physically realistic detail representation."
- "High-Definition Texture Generation Large Model — Enables high-resolution texture mapping, supports
  multi-material layer management on model surfaces, generates diverse appearances, and provides multiple
  surface rendering solutions."
- Product Strengths: "Supports physical based rendering (PBR) textures and texture style selection, with
  one-click switching between realistic and cartoon styles"; "Using high-precision 3D generation technology
  to fully restore structural details and micro-features".
- Use Cases: gaming 3D production, e-commerce display ("shooting for model development"), 3D printing.
- Product Overview: "Tencent Hunyuan (Tencent HY) is a general-purpose and multimodal large model family
  fully self-developed by Tencent. It covers modalities such as text and 3D".

No page in this set mentions model version 3.0 or 3.1, no benchmark, no polycount, and no texture resolution
figure. The version distinction lives only in the API reference.

## Operating constraints stated here

- **Moderation:** "Tencent HY 3D Global performs text content moderation and image content moderation by
  default on input content to block non-compliant content." The customer carries the information-security
  duty as a deep-synthesis service provider.
- **Private deployment:** "Is Private Deployment Method Supported? Not supported."
- **Service form:** "Provide API technology services"; async task model — `WAIT`/`RUN`/`FAIL`/`DONE`, results
  via `ResultFile3Ds`.
- **Prompt guide:** recommends `{quantifier, recommend 1} + {subject}, {optional detail}, {optional style}`,
  single subject, and says "There is no need to include frequently used prompt skills like negative prompt or
  4k". Its worked examples are English: "A deep brown, big-eyed owl", "A yellow dress printed with yellow and
  green patterns, presenting an authentic photography style."
- **Activation:** Tencent Cloud account, real-name authentication, accept terms, IAM policy
  `QcloudAI3DFullAccess`.

## Contradiction recorded

The Chinese-language SDK documentation for the same product describes `Prompt` as "中文正向提示词" (a Chinese
positive prompt), while this English prompt guide gives only English examples and the English API reference
says merely "describes 3D content". Whether English prompts are officially supported, and how well, is
unresolved by these pages.

## Gaps

- No statement of what the "3.1" model changes, and no first-party page describes the Pro/Rapid tier
  difference beyond billing and concurrency.
- "Texture style selection" (realistic/cartoon) is claimed as a product strength but no API parameter in the
  captured reference exposes a style switch.
- The Chinese documentation site `cloud.tencent.com/document/product/1804` is behind a JavaScript challenge
  and returned only a bot-check script on 2026-10-26, so the Chinese product pages (which may carry
  announcement and version detail) were not captured.

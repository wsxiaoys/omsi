## Verbatim parameter descriptions

| Parameter | Req. | Type | Vendor description (verbatim) |
| --- | --- | --- | --- |
| `Prompt` | No | String | "Text-To-3D, description of 3D content, forward Prompt content Supports up to 200 utf-8 characters Either ImageBase64, ImageUrl, or Prompt is required, and Prompt cannot coexist with ImageBase64/ImageUrl" |
| `ImageBase64` | No | String | "unilateral resolution requirement not less than 128, not greater than 5000, size not greater than 6mb (after encoding, size increases by approximately 30%). format: jpg, png, jpeg, webp" |
| `ImageUrl` | No | String | "size not greater than 8mb", same resolution and format limits |
| `ResultFormat` | No | String | "Returns the 3D file format. valid values: OBJ, GLB, STL, USDZ, FBX, MP4, GIF Recommended input models below 50W, may timeout when selecting USDZ, MP4, or GIF format Example value: STL" |
| `EnablePBR` | No | Boolean | "Specifies whether PBR material generation is enabled, false by default." |
| `EnableGeometry` | No | Boolean | "Specifies whether to enable the single geometry generation option When enabled, it generates a 3D model without textures (white model) When enabled, the generative model does not support OBJ format Default model file format is GLB" |

- Concurrency: "This API is used to provide 1 concurrent task by default, which means only 1 submitted task
  can be processed simultaneously." Rate limit 20 requests/second.
- Output: `JobId` ("Task ID (valid period: 24 hours)") and `RequestId` only; results are fetched with
  `QueryHunyuanTo3DRapidJob`.

## Notes

- The Express/Rapid request has **no `Model` parameter**, no `MultiViewImages`, no `FaceCount` and no
  `PolygonType`: there is no documented way to choose a model version or a polygon budget on this tier.
- `MP4` and `GIF` appear only here, as Rapid output formats, and the doc warns those formats "may timeout".
- "50W" is Chinese shorthand for 500,000 faces ("Recommended input models below 50W").

## Gaps

- Which Hunyuan 3D model version (3.0 or 3.1) the Express tier runs is not stated anywhere on this page.
- No statement of the default face count or the topology type the Express tier produces.

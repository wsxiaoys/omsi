> Gemma 4 31B is Google DeepMind's 31B parameter dense multimodal model supporting text and
> image input with a 256K token context window. It features configurable thinking mode for
> step-by-step reasoning, native function calling for agentic workflows, and pre-training on
> 140+ languages.

> • 30.7B parameter dense transformer with hybrid attention (interleaved local sliding window +
> full global attention)
> • 256K token context window with proportional RoPE for long-context optimization
> • Multimodal: text and image input with variable aspect ratio and resolution support via
> ~550M parameter vision encoder
> • Configurable thinking mode for step-by-step reasoning before generating answers
> • Native function calling and structured JSON output for agentic workflows
> • Native system prompt support
> • FP8 quantization

## Summary

Together serves the 31B serverless at **$0.20 in / $0.50 out** per 1M tokens — above the
OpenRouter third-party median but the same order of magnitude, and in FP8 rather than FP4.
Together describes the model as text-and-image only (no video modality is claimed), which
differs from OpenRouter's `text+image+video->text`.

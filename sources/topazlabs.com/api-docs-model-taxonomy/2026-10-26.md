### Introduction

> All of our AI models are developed in-house by our team of PhD researchers in Dallas, Texas.

> Topaz Labs offers three AI model familes:
>
> * **Precision**: Models designed to improve quality while preserving original source
>   characteristics.
> * **Generative**: Models designed to improve quality by intelligently adding detail and texture
>   while preserving artistic intent.
> * **Creative**: Models designed to add new levels of detail that can transform objects, identity,
>   and stylization.
>
> Additionally, we offer various other families of models, such as Sharpen, Denoise, Utilities, and
> more.

Image family table (verbatim, "Capability" column):

| Family | Capability |
| --- | --- |
| `Gigapixel` | Precision Upscaling |
| `Wonder` | Generative Upscaling |
| `Bloom` | Creative Upscaling |
| `Sharpen` | Sharpening |
| `Denoise` | Denoising |
| `Removal & Cleanup` | Inpainting & Object Removal |
| `Color & Lighting` | Color & Lighting Correction |

> Topaz models have default, automatic settings, which can produce the highest quality outcome with
> no manual tuning.

The page links a "Credit Calculator" at `https://developer.topazlabs.com/credit-calculator` and

### Model Selection — "Upscale an Image"

Verbatim table (the clearest first-party statement that "upscale" is three tiers, not one model):

| | Gigapixel | Wonder | Bloom |
| --- | --- | --- | --- |
| **Tier** | Precision | Generative | Creative |
| **Description** | Precision Image Upscale & Enhancement | Generative Image Upscale & Enhancement | Creative Image Upscale & Enhancement |
| **Intent** | Improve resolution, preserve source characteristics. | Improve and restore by adding detail and texture, while preserving intent. | Transform with new, creative detail or stylization. |
| **Use Case** | General purpose upscaling & enhancement. | Upcaling, restoring and improving low resolution or compressed sources. | Upscaling, improving, and transforming GenAI sources. |

Per-model guidance, verbatim:

**Gigapixel**

| Model | Use Case |
| --- | --- |
| `Standard 2` | Default — works for most images |
| `High Fidelity 2` | Maximum source preservation |
| `Low Resolution 2` | Very small inputs (thumbnails, web scrapes) |
| `Art & CGI` | Illustrations, renders, game assets, digital art |
| `Text & Shapes` | Documents, screenshots, text-heavy images |
| `Recover Faces` | Portraits where facial detail is the priority |
| `Transparent Image Upscale` | PNGs with alpha channels |

**Wonder**

| Model | Use Case |
| --- | --- |
| `Standard Max` | Default generative upscaling |
| `Wonder 2` | Stronger generation for more detail |
| `Redefine: Realistic` | Generative enhancement grounded in photorealism |
| `Redefine: Creative` | Generative enhancement with more creative freedom |
| `Recover 3` | Heavily degraded or damaged sources |

**Bloom**

| Model | Use Case |
| --- | --- |
| `Bloom Creative` | Maximum stylization |
| `Bloom Realism` | Creative but more grounded |

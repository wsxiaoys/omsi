# Tripo: Image to 3D Model — H Series (API reference)

- Origin: Tripo (Holymolly Ltd), "Image to 3D Model — H Series",
  <https://developers.tripo3d.ai/en/docs/generation-image-to-model/standard>
- Evidence kind: official documentation (API reference)
- Publication date: none stated.
- Capture date: 2026-10-26
- Relevant models: Tripo H3.1 (`v3.1-20260211`, documented default); H3.0 / H2.5 for contrast

## Captured content

> **Base URL:** `https://openapi.tripo3d.ai/v3`
> **Endpoint:** `POST /generation/image-to-model`
> Generate a 3D model from an image. The system infers geometry and texture from the input.

### Image input (verbatim)

> `input` … Image source. The subject should be clearly visible with minimal occlusion. … **Choose
> exactly one** of the following — do not pass multiple types simultaneously.
>
> - file_token — Upload an image via the File Upload API first, then pass the returned token.
> - URL — A publicly accessible direct link to an image.
> - task_id — The task ID from a previous image generation task (`text_to_image` or `image_to_image`).
>   The system automatically extracts the output image.
>
> - Supported formats: `PNG`, `JPEG`, `WebP`
> - Max file size: **20 MB**
> - Recommended resolution: at least **256 × 256 px**. Subject should be clearly visible with a clean
>   background and minimal occlusion.

### Image-specific parameters (verbatim)

- `enable_image_autofix` default `false`: "Whether to automatically optimize the input image before
  generation. … the system will enhance low-resolution or low-quality images to improve 3D generation
  results."
- `texture_alignment` default `original_image`: `original_image` "prioritize matching the input image
  colors"; `geometry` "prioritize matching the generated geometry".
- `orientation` default `default`: `align_image` "align the model to the input image viewpoint. Only
  effective when `texture` is `true`."

The remaining parameter block — `model` (default `v3.1-20260211`), `face_limit`, `texture`, `pbr`,
`texture_seed`, `texture_quality`, `texture_version`, `delight`, `geometry_quality`, `auto_size`, `quad`,
`smart_low_poly`, `generate_parts`, `compress`, `export_orientation`, `model_seed`, `export_uv` — is
identical, wording included, to the [text-to-3D reference](../tripo-text-to-model-api/2026-10-26.md),
including the same face-limit table (v3.1 standard 1,500,000 / Ultra 2,000,000; v3.0 standard 1,000,000 /
Ultra 2,000,000; quad 150,000) and the same "only valid when `model ≥ v3.0-20250812`" note.

## Summary

Image-to-3D takes exactly one image, as a Tripo file token, a public URL, or the `task_id` of an earlier
Tripo image-generation task — the last of these chains a Tripo text-to-image step directly into 3D without
an intermediate download. Accepted formats are PNG/JPEG/WebP, 20 MB maximum, with a recommended floor of
256 × 256 px. Everything downstream of the image (geometry, texture, PBR, topology, export) is the same
surface as text-to-3D, so the two endpoints differ only in the conditioning input and the two
image-specific controls (`enable_image_autofix`, `orientation`).

## Gaps

- No guidance on background removal: the vendor asks for "a clean background" but does not say whether a
  transparent PNG alpha is used, ignored, or composited.
- No stated behaviour for multi-object images, occlusion, or non-photographic input (line art, renders).
- No texture-resolution figures for the `standard`/`detailed` tiers.
- The 256 × 256 "recommended" floor is advisory; no rejection threshold is given.

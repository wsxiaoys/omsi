# Tripo: "Models and Versions" (vendor model ID table)

- Origin: Tripo (Holymolly Ltd), "Models and Versions", <https://developers.tripo3d.ai/en/docs/models-and-versions>
- Evidence kind: official documentation (API reference / model registry)
- Publication date: none stated.
- Capture date: 2026-10-26
- Relevant models: Tripo H3.1 (`v3.1-20260211`), H3.0 (`v3.0-20250812`), H2.5 (`v2.5-20250123`),
  P2 (`P2-20260801`), P1 (`P1-20260311`)

## Captured content

The page is the vendor's canonical list of the values accepted by the `model` parameter of
`POST /v3/generation/text-to-model` and `POST /v3/generation/image-to-model`.

### 3D Generation Models (verbatim table)

> | Model ID | Description | Recommended Use Case |
> | `v3.1-20260211` | H3.1, latest high-precision model (default) | AAA production pipelines / 3D printing & flexible manufacturing |
> | `v3.0-20250812` | H3.0, previous-generation stable version | Backward compatibility |
> | `v2.5-20250123` | H2.5, legacy version | Historical project compatibility |
> | `P2-20260801` | P2 Preview, native quad topology; 48–50,000 triangles or 48–25,000 quads | Game characters and props / Hard-surface assets / Real-time production pipelines |
> | `P1-20260311` | P1, best low-poly performance; 50–20,000 faces | Game pipelines / UGC generative gameplay / Mobile 3D assets |

### Version selection guidance (verbatim)

> - **New projects**: Use the default versions — `v3.1-20260211` for 3D, `seedream_v4` for text-to-image
>   and `seedream_v5` for image-to-image — for the best balance of quality and stability
> - **Production environments**: Pin a specific model version to avoid output inconsistencies caused by
>   model updates
> - **Highest quality**: Use `v3.1-20260211` for 3D (optionally with `geometry_quality=detailed`) …
> - **Low-poly / game assets**: Use the P Series for 3D — cleaner topology and more precise face-count
>   control: `P2-20260801` (Preview, native quads and a higher face budget) or `P1-20260311`

The same page also lists the image-generation models the API can call (`seedream_v4`, `seedream_v5`,
`banana`, `banana_pro`, `banana2`, `chat_image_1`, `chat_image_1.5`, `chat_image_2`,
`chat_image_2.5_flare`, `chat_image_2.5_sunburst`); `chat_image_1` retires 2026-10-23 and
`chat_image_1.5` on 2026-12-01.

## Summary

This page supplies the vendor's own H-number-to-snapshot mapping: **H3.1 = `v3.1-20260211`**,
**H3.0 = `v3.0-20250812`**, **H2.5 = `v2.5-20250123`**. It is the only first-party text that spells
"H3.0" at all. It places H3.1 as the default and current model, H3.0 as a retained
backward-compatibility version, and H2.5 as legacy. The P1/P2 series is presented as a separate,
low-poly-oriented product line rather than as a version of H3.

## Gaps

- No dates for any model ID. `2026-02-11`, `2025-08-12`, `2025-01-23` etc. are readable from the strings
  but not stated as release dates.
- No deprecation or support-window commitment for H3.0 or H2.5.
- No description of what changed between H3.0 and H3.1 beyond "latest high-precision".
- The `P2-20260801` row describes itself as "Preview" while sitting in the same table as stable IDs.

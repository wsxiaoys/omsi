# Tripo: "Tripo Texture" model page (v3.5 texturing, used by H3.1 requests)

- Origin: Tripo (Holymolly Ltd), "Tripo Texture — Tripo Developers",
  <https://developers.tripo3d.ai/en/models/texture>
- Evidence kind: official documentation (vendor model page)
- Publication date: none stated; the page names `v3.5-20260815`.
- Capture date: 2026-10-26
- Relevant models: Tripo Texture `v3.5-20260815` (also `v3.0-20250812` default, `v2.5-20250123`); the
  texturing stage of Tripo H3.1 generation

## Captured content (verbatim)

> v3.5-20260815
> PBR texturing for existing 3D models.
> Max Resolution — 8K
> Quality Levels — 4 (fast / standard / detailed / 8K)
> Guidance — Text / Image / 2–4 Views
> Input — GLB/GLTF/FBX/OBJ/STL
> Output — PBR Textured Model

> Generate or regenerate PBR textures for an existing 3D model — pass it in as a task_id, an uploaded file
> or a URL, and guide the result with text, a single image or multi-view images. … v3.5 must be set
> explicitly: use model on the texture endpoint or texture_version on the generation endpoints; otherwise
> the default v3.0 is used.

> Lighting control (delight, on by default): keep it on for realistic games — clean base color under
> Unity, Unreal or Godot lighting; turn it off for rendering, VFX and CG to preserve stylized lighting
> Fast mode: texture_quality=fast, same credits as standard
> Better geometry alignment: details land where they belong, with more consistent results across views

Pricing:

> Fast (fast) — 10 · Standard (standard) — 10 · HD (detailed) — 20 · 8K (extreme) — 30
> When texturing inside a generation task, textured output costs 10 credits more than geometry only; HD
> adds another 10 and 8K another 20

Parameters:

> model — Texture version on /v3/models/texture: v3.0-20250812 (default, for v3.0 / v3.1 models),
> v3.5-20260815 (newest; set explicitly) or v2.5-20250123 (for v2.5 models)
> texture_version — Texture version on the generation endpoints; same values as model. If omitted it
> follows the geometry model (v2.5 → v2.5, otherwise v3.0)

## Summary

This page settles the texture-stage question for H3.1: the geometry snapshot and the texture snapshot are
versioned independently, and the vendor's own parameter note describes `v3.0-20250812` as the default
"for v3.0 / v3.1 models". So a default H3.1 request runs H3.1 geometry with the **older** texture model
unless `texture_version=v3.5-20260815` is set explicitly. The four texture tiers are `fast`, `standard`,
`detailed`, `extreme` (8K), with `fast` costing the same as `standard`.

The page also confirms that texturing can be run as a separate post-process on any GLB/GLTF/FBX/OBJ/STL
model, guided by text, one image, or two to four views — which is how an H3.1 mesh can be re-textured
without regenerating geometry.

## Gaps

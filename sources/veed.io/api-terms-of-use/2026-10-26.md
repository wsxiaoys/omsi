# VEED API Terms of Use

- Origin: VEED API legal page, "API Terms of Use", <https://api.veed.io/terms-of-use>. Header reads
  "LAST UPDATED: OCTOBER 2026". Provider named in the text: "VEED Limited".
- Evidence kind: provider policy (first-party contract terms)
- Publication date: "LAST UPDATED: OCTOBER 2026" (month only)
- Capture date: 2026-10-26
- Relevant models: all VEED API models, including Fabric 1.0

## Captured content

Scope and audience, verbatim:

> References in these API Terms to "you" or "your" are to the commercial user of the API (being the
> company, organisation, firm or individual that accesses or uses the API, or on whose behalf the API is
> accessed or used, in each case acting for purposes relating to its trade, business, craft or profession
> and not as a consumer). The API is not available to consumers.

Account separation, verbatim:

> API Accounts are currently separate from VEED editor accounts, and API usage is paid for with Credits.
> VEED subscriptions or VEED editor AI credits are not eligible for use with the API or your API
> Account.

Licence and restrictions, verbatim:

> we grant you a non-exclusive, non-transferable, revocable licence to use the API and access Models to
> build and run Customer Applications and to make them available to End Users, in line with the
> Documentation.

> you shall not […] (b) reverse engineer the API or any Model, or try to derive, extract or reconstruct
> its model weights, source code or training data […] (c) use Output to develop AI models that compete
> with any Models or Applications; (d) bypass or interfere with any of our security, safety or content
> moderation systems, usage limits, or any provenance markings we may apply to Output

Moderation, verbatim:

> We reserve the right to use automated and other systems to check Input and Output. Input that we deem

Ownership and data, verbatim:

> 6.1 Ownership. As between you and us, you are the owner of your Input and Output, subject to any third
> party rights therein.

> 6.3 Improving our services. We will not use your Input or Output to train our Models. We may create and

> 6.4 Your responsibilities for content. You warrant and represent that you have all the rights,
> licences and consents needed to […]

> you shall procure that End Users shall not remove any watermark, notice or other marking from any

End users, verbatim:

> 5.2 You must give End Users and other relevant third parties any notices, and obtain any consents, that
> the law requires for us to process their Input as envisaged in the Agreement.
> 5.4 You shall ensure that all End Users are at least eighteen (18) years old.

## Summary

The API contract establishes the commercial terms for the direct route: business/professional use only
("The API is not available to consumers"), a revocable licence to build on the API, customer ownership
of input and output subject to third-party rights, no training on API input or output, mandatory
end-user consent for processing their input, an 18+ end-user requirement, and a ban on removing
provenance markings or using output to train a competing model.

## Gaps

- No statement about who owns the *model* beyond "We and/or our licensors own all intellectual property
  rights in the API, the Models"; VEED does not say whether Fabric weights are VEED's own or licensed
  from a third party.
- The consumer exclusion sits awkwardly with the API FAQ's "including individual developers"
  ([API FAQ](../veed-api-faq/2026-10-26.md)); the terms qualify "individual" with "acting for purposes
  relating to its trade, business, craft or profession".
- No liability, indemnity, or SLA figures were extracted for this record; only the clauses relevant to
  model use and content rights were read.
- These terms govern api.veed.io only. Use through fal is governed by fal's terms, which were not
  captured.

# VEED Help Center: "VEED Fabric 1.0 API"

- Origin: VEED Help Center (Intercom-hosted), "VEED Fabric 1.0 API",
  <https://support.veed.io/en/articles/15230480-veed-fabric-1-0-api>. Listed under Collections > APIs >
  APIs Live on Fal.
- Evidence kind: official documentation (first-party vendor support article)
- Publication date: none stated; the article header reads "Updated over 3 weeks ago" at capture, i.e.
  approximately 2026-10-05.
- Capture date: 2026-10-26
- Relevant models: VEED Fabric 1.0

## Captured content

Verbatim:

> The VEED Fabric 1.0 API turns a static character image into a talking video. Send an image and an
> audio file, and receive a video where the character speaks with lifelike lip-sync - in a single API
> call.
>
> Unlike avatar tools that limit you to a preset library, Fabric works with any character image you own
> - a brand mascot, a stylized illustration, or a user-uploaded photo.

"What Does It Do?", verbatim:

> Make any image talk - no avatar library or avatar selection required. Use any character image you own.
> Lifelike lip-sync driven by your audio file
> Up to 1 minute of generated video per API call
> Built for high-volume, programmatic generation - not just one-off clips
> Pure API access - no VEED account or editor required. Drop it directly into your product.

Two routes, verbatim:

> There are two routes, and they're billed separately. Pick whichever suits your stack.
>
> Direct from VEED — Fabric 1.0 is available on VEED's own API platform at api.veed.io, billed in API
> credits. To get started, you will need: A VEED API account. This is separate from a VEED editor
> account. Prepaid API credits, added in Billing. A VEED API key, created in the API keys section.
>
> Via fal.ai — Fabric 1.0 is also hosted on fal.ai, a third-party AI model marketplace that manages
> authentication and billing, and provides official Python and JavaScript SDKs. […] No VEED account or
> VEED credentials are required for this route.

> The two routes are billed separately. Credits or spend on one don't carry over to the other.

Length, verbatim:

> Each API call supports up to 1 minute of generated video. Longer content requires multiple calls.

Billing, verbatim:

> Is there a minimum charge per job?
>
> Billing is per second on both routes, with no stated minimum. Confirm current billing details before
> going live.

Inputs, verbatim:

> Can I use any image of a character?
>
> Yes. Fabric works with any character image you own, including brand mascots, illustrated characters,
> and user-uploaded photos. There is no preset avatar library.

## Summary

The vendor's API-facing article is the most specific first-party statement of the API envelope: one
image plus one audio file in, one MP4 out, up to 1 minute per call, billed per second on both routes
with no stated minimum. It also states the differentiator explicitly — Fabric is not tied to a preset
avatar library — and warns that VEED credits and fal spend are separate wallets.

## Gaps

- No audio duration limit in seconds, no accepted audio/image codecs, no output resolution or frame
  rate. The article defers: "For specific supported formats and technical requirements, refer to the
  model page for the route you're using."
- No per-second price on this page; the rate is on the companion guide and api.veed.io
  ([lipsync API guide](../lipsync-apis-fabric-1-0-and-lipsync-2-0/2026-10-26.md)).
- No publication date, no changelog, and no statement of when the 1-minute ceiling changed.

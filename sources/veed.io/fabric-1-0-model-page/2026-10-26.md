## Summary

The vendor's model page describes Fabric 1.0 as VEED's proprietary image-plus-audio lip-sync model,
sold on AI credits inside the editor, available as an API through fal, and capable of "up to 5 minutes"
per talking video. It positions the model against generic text-to-video models on cost and against
preset avatar libraries on input freedom, and claims style transfer (realistic, clay, anime) via prompt
or image.

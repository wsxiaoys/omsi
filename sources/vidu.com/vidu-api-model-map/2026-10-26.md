Q3 is a **five-model series** (`pro`, `mix`, `drama`, `ad`, `turbo`) in which no single model has all
four modes; Q4 is a **single model** with two modes.

## Summary

First-party capability matrix. It gives the only first-party frame rate for Q4 (**24 fps**) and the
only first-party resolution ladder (540p/720p/1080p/2K/4K). Its duration row says "1-16s selectable"
for Q4, which disagrees with the same vendor's Q4 API reference (3–16) and with the product page's
mode-specific minimums (R2V 1 s, I2V 3 s).

The document's own introduction lists "ViduQ3, ViduQ2, ViduQ1, and Vidu2.0" as the offered models and
then adds Q4 as a section, so the prose is one generation behind its own tables.

## Gaps

- No release dates, prices, or per-mode parameter detail.
- "1-16s" for Q4 is not qualified by mode, and contradicts two other first-party pages.
- No statement on whether Q4 Preview is time-limited or will be renamed at GA.

# Vidu API docs: "Platform Introduction"

- Origin: Vidu Open Platform documentation, "Platform Introduction",
  https://platform.vidu.com/docs/overview/introduction (read as Markdown via `…/introduction.md`)
- Evidence kind: official documentation (first-party)
- Publication date: not stated on the page
- Capture date: 2026-10-26
- Relevant models: the Vidu Q series as a whole (Q1–Q4); Vidu S2 (avatar models)

## Verbatim: vendor and series framing

> The Vidu Q series is China's first long-duration, high-consistency, high-dynamics video generation
> model, released by Shengshu Technology. Vidu holds a leading advantage in semantic understanding,
> inference speed, and motion dynamics, and has launched the world's first "multi-subject reference"
> feature, breaking through the challenge of consistency generation in video models and ushering in the
> era of visual context.

> The Vidu S series is built on a globally leading streaming inference video model released by Shengshu
> Technology, providing enterprise (B2B) customers with a new generation of near-real-time, interactive,
> bidirectionally-aware digital human services.

> ## Video Generation Model Q Series:
>
> Reference-to-Video: Input a reference image and text description to generate a video. Currently
> supports referencing people, objects, and other types of subjects;
>
> Image-to-Video: Input a first-frame image, or first-and-last-frame images, along with the corresponding
> text description, to generate a video;
>
> Text-to-Video: Input a piece of text to generate a video; currently supports a general style as well as
> a specially optimized anime style.

## Summary

The only first-party page captured that names the developer: **Shengshu Technology** publishes the Vidu Q
series (and the real-time S series). It is a series-level page, written for Q1–Q2-era capabilities — it
describes text-to-video, first-and-last-frame and reference-to-video as universal Q-series modes and
never mentions Q4. Read as identity evidence it is useful (vendor name, brand structure); read as a
capability description it is stale and should not be used for Q4, which has neither text-to-video nor
first-and-last-frame generation.

## Gaps

- No model list, no dates, no prices, no per-model capabilities.
- "China's first long-duration … model" and "world's first multi-subject reference" are unverified
  marketing claims with no comparator named.
- Nothing on Q4, on the Q3 `drama`/`ad` vertical models, or on licensing.

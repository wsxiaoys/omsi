## What this establishes

- ByteDance's China-region platform announced **`doubao-seedream-5-0-flash-260915` as a newly
  released image-generation model in September 2026**, with no day given.
- The vendor's own positioning is relative to Pro, not to Lite: "capabilities fully consistent with
  Seedream 5.0 pro", plus "faster" and "cheaper". The named shared capabilities are interactive
  editing, layer decomposition and native multilingual generation.
- No benchmark, Elo, latency figure, or comparison number appears in the row.

## Gaps

- **Month granularity only.** September 2026 is the finest date this page supports; the model ID
  suffix (`260915`) and host endpoint creation dates are the only finer signals, and neither is a
  release date (see the model page).
- The page has no per-row "publication date" column and no link to a launch blog, tech report or
  model card for Flash.
- "Capabilities fully consistent with Seedream 5.0 pro" is contradicted in scope by the API
  reference, which documents `optimize_prompt_options.mode: fast` as Pro-only
  ([Ark image-generation API](../seedream-5-image-generation-api/2026-10-26.md)). Read the release
  note as a marketing summary, not a parameter-level parity claim.
- Whether this announcement is the GA date or a regional rollout date is not stated.

## Endpoint and scope (verbatim, Chinese)

> 基于 HTTP 协议的非流式音频生成接口。支持通过参考音频、参考图片或自然语言描述生成定制化音频，
> 涵盖音效、音色等多种创作维度，单次最长可生成 120 秒音频，适用于有声书、影视配音、游戏音效等场景。
>
> `POST https://openspeech.bytedance.com/api/v3/tts/create`

Translation: a non-streaming HTTP audio-generation interface that accepts reference audio, a
reference image, or a natural-language description; covers sound effects and timbre and other
creation dimensions; **up to 120 seconds per call**; aimed at audiobooks, film/TV dubbing and game
SFX.

Auth: `X-Api-Key` (new console) or `X-Api-App-Id` + `X-Api-Access-Key` (legacy); optional
`X-Api-Request-Id` for tracing. Note the path is the **TTS** namespace (`/api/v3/tts/create`) even
though the model is the audio-creation model.

> 模型版本标识，当前支持模型如下：`seed-audio-1.0`

Languages, verbatim and in order: 中文, 英文, 日语, 韩语, 墨西哥-西班牙语, 西班牙语, 德语, 法语,
巴西-葡萄牙语, 泰语, 越南语, 马来语, 菲律宾语, 意大利语, 俄语, 荷兰语, 波兰语, 土耳其语 — **17 named**
(zh, en, ja, ko, es-MX, es, de, fr, pt-BR, th, vi, ms, fil, it, ru, nl, pl, tr).

> 支持时间轴控制，可通过 text_prompt 自然语言描述控制音频总时长及人声说话的具体时间段

Translation: timeline control is supported — `text_prompt` can specify total audio duration and the
exact time spans in which a voice speaks. The doc states no numeric precision (the Seed blog and
model page claim 100 ms).

## `text_prompt`

> 用于合成音频的提示词或者待合成的文本内容，最大支持3000字符。

Three generation modes are documented:

| Mode | Input | Behaviour |
| --- | --- | --- |
| 纯文本生成 (text only) | `text_prompt` | generates audio from the description |
| 参考音频生成 (reference audio) | `references` + `@音频N` markers | conditions on up to 3 clips; may also name a `speaker` voice ID |
| 参考图片生成 (reference image) | one image + `text_prompt` | "本字段可只传入待合成的文本内容" — the image conditions the voice, the text is the script |

> 支持纯文本、文本 + 图片、文本 + 音频的组合生成音频

## `references` / `speaker` / `audio_data` / `audio_url` / `image_data` / `image_url`

- Up to **3** reference audios: "单条时长 ≦ 30秒，单条大小 ≦ 10 MB", formats `wav` / `mp3` / `pcm` /
  `ogg_opus`. Upload order must match `@音频1`, `@音频2`, `@音频3` numbering.
- Up to **1** reference image: ≤ 10 MB, `jpeg` / `png` / `webp`.
- `speaker`, `audio_data`, `audio_url` are mutually exclusive (exactly one). `speaker` is described as
  > 音色 ID，支持使用"豆包语音合成模型2.0"的音色或声音复刻音色

  i.e. a voice ID from the **Doubao TTS 2.0 voice library** or a **voice-cloning (声音复刻) voice**.
- Image references **cannot** be combined with audio references: "图片参考不能与音频参考混用".

## `audio_config`

| Field | Default | Range / values |
| --- | --- | --- |
| `format` | `wav` | `wav`, `mp3`, `pcm`, `ogg_opus` |
| `sample_rate` | `40000` for wav/pcm, `44100` for mp3 | wav/pcm: 8000, 16000, 24000, 32000, 40000, 44100, 48000; mp3: same minus 40000; `ogg_opus`: **48000 only** |
| `speech_rate` | 0 | [-50, 100]; -50 = 0.5×, 100 = 2.0× |
| `loudness_rate` | 0 | [-50, 100]; -50 = 0.5× volume, 100 = 2.0× |
| `pitch_rate` | 0 | [-12, 12] semitones |
| `enable_subtitle` | `false` | when true, returns word-level timestamps |

## `watermark`

> 水印配置，不传时默认不添加水印

- `aigc_watermark` (bool, default `False`): "开启后可在合成结尾增加音频节奏标识" — an **audible**
  marker appended at the end.
- `aigc_metadata` (object, `enable` default `False`): implicit watermark, "开启后可在合成音频 header
  加入元数据" — metadata written into the audio header.
- `content_producer` / `produce_id` / `content_propagator` / `propagate_id`: free-text provenance
  labels (Chinese AIGC labelling convention).

So both watermark forms are **opt-in and off by default** on the first-party API.

## Response

| Field | Notes |
| --- | --- |
| `audio` | base64 audio |
| `duration` | post-processing duration (differs from original if speed/pitch changed) |
| `original_duration` | "该值为计费依据，上限为120秒" — **the billing basis**, capped at 120 s |
| `url` | audio URL valid for **2 hours** |
| `subtitle` | sentence and word timestamps, only when `enable_subtitle` is true |

Documented example response: `{"duration": 82.8, "original_duration": 82.8, ...}`.

## Documented example request (verbatim `text_prompt`)

> 先是一声手机震动的声音，环境中持续的 鸟鸣声 。音乐以 马林巴为主奏乐器 ，加入合成器lead、电贝斯、
> 打击乐，整体情绪紧张悬疑。 男子1 （中青年男性，台湾口音，嗓音低沉，浑厚）用严肃语气说道：…

The example is a two-character suspense scene with a named music bed (marimba, synth lead, electric
bass, percussion), dialogue direction per speaker (gender, age, accent, timbre, emotion), and timed
SFX (car passing, brakes, high heels). It shows music is *producible as part of a scene*, while no
documented parameter controls music separately.

## Summary

- This is the **most detailed first-party technical record** for Seed Audio 1.0 in the corpus:
  model ID, endpoint, three input modes, reference limits, output formats and sample rates,
  prosody controls, subtitle timestamps, watermark switches, and the billing basis.
- Billing basis is **`original_duration` in seconds**, capped at 120 s per call — not per character.
- Output defaults: `wav` at 40 kHz; max 48 kHz; `ogg_opus` fixed at 48 kHz.
- Voice identity can come from the Doubao TTS 2.0 voice library, a cloned voice ID, or reference
  audio; a reference image can also condition the voice (mutually exclusive with audio references).

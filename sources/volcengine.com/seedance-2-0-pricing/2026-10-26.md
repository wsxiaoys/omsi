## Billing basis (verbatim, translated)

> 视频价格由 token 单价 和 token 用量 共同决定。… 仅对成功生成的视频计费。因审核等原因导致生成失败的，不收取费用。
>
> [Video price is determined by the token unit price and the token consumption. … Only successfully
> generated videos are billed. No fee is charged when generation fails, for example due to content
> review.]

> token 用量估算公式：(输入视频时长+输出视频时长) × 输出视频的宽 × 输出视频的高 × 输出视频的帧率/1024
>
> [Token consumption estimate: (input video duration + output video duration) × output width ×
> output height × output frame rate / 1024.]

For the Seedance 2.0 series and Seedance 2.5, a **minimum token consumption** applies when the input
includes video: if the estimate is below the minimum, the video is billed at the minimum. The minimum
depends on resolution, aspect ratio and output duration.

stated rule.

## Gaps

- Prices are in CNY and apply to Volcengine Ark in China; the USD schedule on BytePlus ModelArk and
  the host schedules differ (separate records).
- The page gives no date, so it is not evidence of a price at any particular earlier time.
- Frame rate is a term in the token formula but its value is not stated on this page (BytePlus's API
  documentation gives 24 fps for the same family).
- The 4K pricing structure (lower token rate, higher per-video cost) is unexplained.

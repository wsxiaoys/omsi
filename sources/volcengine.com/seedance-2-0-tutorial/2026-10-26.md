## Input combination rules (verbatim, translated)

> 您可任意组合以下模态内容，注意不支持“文本+音频”、“纯音频” 输入。文本；图片：0~9 张；视频：0~3 个；音频：0~3 个
>
> [You may combine the following modalities freely; note that "text + audio" and "audio only" inputs
> are not supported. Text; images 0–9; videos 0–3; audio 0–3.]

Advanced usage note: omni-reference generation can designate reference images as first/last frame in
the prompt, but for strict first/last-frame adherence the dedicated first-and-last-frame task should
be used (`role` = `first_frame` / `last_frame`).

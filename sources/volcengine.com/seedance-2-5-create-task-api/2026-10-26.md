## Public-release statement (verbatim, translated)

> Seedance 2.5 已全面公开，您可在火山方舟平台调用 API 及在线体验。

[Seedance 2.5 is now fully public; you can call the API and use it online on Volcengine Ark.] This is

## Input combinations (verbatim, translated)

> Supported combinations: text only; text (optional) + image; text (optional) + video; **text
> (optional) + audio (only Seedance 2.5 supports passing audio alone)**; text + image + audio; text +
> image + video; text + video + audio; text + image + video + audio; draft task ID.

> Seedance 2.5, Seedance 2.0 series models do not support directly uploading reference images or videos
> containing real human faces.

The audio-alone row is marked "仅 Seedance 2.5" — the only capability in this table that is 2.5-exclusive.

## Prompt languages per model (verbatim, translated)

> Prompt language support: all models support Chinese and English prompts; **Seedance 2.5 additionally
> supports Spanish, Indonesian, Portuguese, Japanese, Malay, Thai, Arabic, Vietnamese, Korean**; the
> Seedance 2.0 series additionally supports Spanish, Indonesian, Portuguese, Japanese.

So 2.5 takes eleven languages against 2.0's six, and the five added are Malay, Thai, Arabic, Vietnamese
and Korean.

> Prompt length guidance: Chinese prompts should not exceed 500 characters, English prompts 1,000 words.
> Too many words scatter the information; the model may ignore details and focus only on the main
> points, causing parts of the video to be missing.

## Parameter notes specific to 2.5

- `omni_reference_task_type` (new in 2.5, default `auto`): `auto` infers the subtask then validates and
  fails asynchronously with `InvalidParameter.TaskTypeConstraint`; `reference` / `edit` / `extend`
  validate at submission and fail synchronously. Even when specified, the model re-judges the task type
  from the prompt and can still fail asynchronously if the two disagree.
- `draft` (default `false`): "only 480p Draft video generation is supported (other resolutions raise an
  error)"; the draft task ID is valid 7 days.
- `service_tier`: `default` (online) or `flex` (offline, "priced at 50% of online inference") —
  "**Seedance 2.5, Seedance 2.0 series do not currently support**" flex. This is the API-level
  confirmation that there is no cheap offline queue for 2.5.
- `content.type: "draft_task"` is the second-step input, supported only by Seedance 2.5.
- Reference-video limits differ by model: 2.5 allows 10 clips of 2–30 s (4–30 s in editing tasks) with
  combined duration ≤ 30 s; 2.0 allows 3 clips of 2–15 s with combined ≤ 15 s. The same split applies to
  audio: 2.5 allows 10 clips of 2–30 s (combined ≤ 30 s); 2.0 allows 3 clips of 2–15 s (combined ≤ 15 s).
- Image formats: jpeg, png, webp, bmp, tiff, gif, and "Seedance 2.0 series and above additionally
  support heic, heif".

## Gaps

- The `frames` parameter (documented for 1.0 models) is not documented for 2.5, consistent with a fixed

## Billing basis (verbatim, translated)

> 视频价格由 token 单价 和 token 用量 共同决定 … 每条视频的价格可使用 Seedance 2.0 系列价格计算器、
> Seedance 2.5 系列价格计算器估算

[Video price is determined by the token unit price and token usage … per-video prices can be estimated
with the Seedance 2.0 series and Seedance 2.5 series price calculators.]

> token 用量估算公式：(输入视频时长+输出视频时长) × 输出视频的宽 × 输出视频的高 × 输出视频的帧率/1024

[Estimated token usage = (input video duration + output video duration) × output width × output
height × output frame rate / 1024.]

> 仅对成功生成的视频计费。因审核等原因导致生成失败的，不收取费用。

[Only successfully generated videos are billed. Generations that fail for reasons such as content
moderation are not charged.]

## Minimum token charge

> 对于 Seedance 2.0 系列、Seedance 2.5 模型，当输入包含视频时，存在最低 token 用量限制

[For the Seedance 2.0 series and Seedance 2.5, a minimum token usage applies when the input contains
video.] If the estimate falls below the floor, the request is billed at the floor. This is why the
with-video prices are ranges rather than single figures.

## Draft mode billing (verbatim, translated)

> Seedance 2.5 样片（Draft）模式包含两步任务，每个任务独立计费

[Seedance 2.5 Draft mode consists of two tasks, each billed separately.] Step 1 is billed as a 480p
video. Step 2 is billed at the target resolution (1080p only), with the token rate chosen by whether
**step 1** had a video input; the draft video's own duration is excluded from the token estimate.

## IP licensing surcharge

> 生成视频时，不同版权单价不同 … 单条视频版权费用 = Σ（每个输入 IP 的单价 × 视频时长（秒））

[Different IP have different unit prices when generating video … per-video IP cost = Σ (unit price of
each input IP × video duration in seconds).] Prices are only shown in the console's experience centre,
so no figure is recorded here. This is a separate charge from token billing and applies to
copyrighted characters/IP supplied as references.

Two asymmetries matter and are easy to miss: 2.5 **drops 4K** (2.0 standard has it) and **adds
standalone audio reference** (2.0 requires an accompanying image or video). So 2.5 is not a strict
superset of 2.0 on output spec.

## Task types and their hard constraints (verbatim, translated)

> Seedance 2.5 determines the task type from the input assets and the prompt intent.

| Task type | Trigger | Special constraint |
| --- | --- | --- |
| Text-to-video | text only | none |
| First-frame / first-and-last-frame | `content.role` = `first_frame` / `last_frame` | `ratio` **must** be `adaptive`; output aspect ratio is forced to the first-frame image |
| Reference-to-video | at least one `reference_image` / `reference_video` / `reference_audio` | none |
| Video editing | at least one `reference_video` plus edit intent | `ratio` **must** be `adaptive`, `duration` **must** be `-1`; the reference video must be 4–30 s |
| Video extension | at least one `reference_video` plus extend intent | `ratio` **must** be `adaptive` |

Edit prompts must contain at least one of 编辑视频 / 增加 / 加上 / 删除 / 去掉 / 修改 / 替换 / 改成;
extension prompts at least one of 向前/向后延长 / 延续 / 续写. Setting
`omni_reference_task_type` to `auto` / `edit` / `extend` moves validation earlier: explicit `edit`
or `extend` fails synchronously (`InvalidParameter.TaskTypeConstraint`), while a mismatch between the
declared and the model's inferred task type still fails asynchronously
(`InvalidParameter.TaskTypeMismatch`). This is a real operational hazard: the same request can be
accepted and then fail after submission.

## Duration and ratio behaviour (verbatim, translated)

- `duration` default `-1`, range `[4, 30]`. With `-1` on an editing task the output matches the
  source video's duration "and may be slightly shorter than the video being edited, by no more than
  0.4 seconds"; on other tasks the model picks a whole number of seconds in `[4, 30]`.
- `ratio` default `adaptive`. In editing, extension and first/first-last-frame tasks only `adaptive`
  is accepted.
- Documented pixel dimensions: 480p 16:9 854×480, 21:9 992×432; 720p 16:9 1280×720, 21:9 1470×630;
  1080p 16:9 1920×1080, 21:9 2206×946.

## Output format

- `output_format`: `mp4` (default) or `mov`. `mov` is H.264 with yuv444p chroma and PCM audio,
  intended for colour-critical post; the vendor warns player compatibility is limited and recommends
  mov as both input and output for editing and extension.
- 1080p is 10-bit H.265/HEVC, with the same playback caveat the 2.0 page carries for 4K.

## Input limits (transcribed, translated)

- **Images:** URL, Base64 or asset ID; jpeg/png/webp/bmp/tiff/gif/heic/heif; aspect ratio 0.4–2.5;
  each side 300–6000 px; ≤ 30 MB each; request body ≤ 64 MB. Counts: 1 (first frame), 2
  (first+last), **1–30 (omni reference)**.
- **Videos:** mp4/mov (H.264/H.265 + AAC/MP3, PCM for mov); 480p–4K; **non-editing tasks 2–30 s per
  clip, editing tasks 4–30 s**; ≤ 10 clips with combined duration ≤ 30 s; ≤ 200 MB each; 24–60 fps
  in; per-side 300–6000 px; total pixels 407,696–8,295,044.
- **Audio:** wav/mp3; **2–30 s per clip**, ≤ 10 clips, combined ≤ 30 s, ≤ 15 MB each.
- **Text:** prompt ≤ 500 Chinese characters or ≤ 1,000 English words recommended
  ([API reference](../seedance-2-5-create-task-api/2026-10-26.md)).
- **Retention:** task records kept 7 days; output video URL valid 24 hours with a 100-download cap.

## Languages (verbatim, translated)

> Seedance 2.5 natively supports prompt input and audio-video generation in multiple languages,
> covering Chinese, English, Spanish, Indonesian, Malay, Thai, Arabic, Portuguese, Vietnamese,
> Japanese and Korean — 11 languages.

The create-task API reference sharpens this: all models take Chinese and English; the 2.0 series
additionally takes Spanish, Indonesian, Portuguese and Japanese, so **2.5's five genuinely new
languages are Malay, Thai, Arabic, Vietnamese and Korean**
([API reference](../seedance-2-5-create-task-api/2026-10-26.md)).

## Draft ("样片") mode — 2.5 only (transcribed, translated)

- `draft: true` generates a **480p** preview. Any other resolution errors. Token usage and unit price
  equal a normal 480p generation.
- The draft task ID is valid **7 days** from `created_at`.
- The final pass submits `content: [{type: "draft_task", draft_task: {id: ...}}]` with
  `resolution` fixed to **1080p**; other resolutions error.
- The two steps are billed independently. The final pass reuses prompt, references, duration, ratio,
  seed, audio setting and task type automatically — passing them again is an error — while
  `return_last_frame`, `output_format`, `watermark`, `service_tier`, `execution_expires_after`,
  `priority`, `callback_url` and `safety_identifier` may be set afresh.
- Seedance 2.0 has no draft mode on any tier (matrix row above), so the cheap-iterate workflow is a
  2.5-only capability on this platform.

## Activation, rate limits, retention

- Activation requires **account balance > 200 CNY**, a 200 CNY+ dedicated savings plan, or a Seedance
  2.5 resource pack ([activation rules record](../seedance-2-5-pricing/2026-10-26.md) documents the
  same threshold on the pricing/activation pages).
- Rate limits, per primary account, same model regardless of version: **600 RPM / 10 concurrent**
  tasks for enterprise accounts, **180 RPM / 3 concurrent** for individual accounts; exceeding either
  returns 429. Non-inference API QPS: get task 20, list tasks 1, cancel/delete 20.

## Prompt guidance the vendor gives

Base formula: 主体 + 动作/事件 + 场景与环境 + 视觉风格 + 运镜/切镜 + 声音 (subject + action + scene +
visual style + camera/shot + sound). Reference assets are addressed as `@图片1` / `@视频1` / `@音频1`;
music in `()`, sound effects in `<>`, dialogue in `{}`, subtitles in `【】`. A prompt-optimisation
skill is published as `npx skills add … --skill sd25-pe`.

## Restrictions (verbatim, translated)

> Seedance 2.5 does not support directly uploading reference images or videos containing real human
> faces.

Workarounds are the same three the 2.0 family documents: reuse of this account's own model outputs
from the last 30 days, preset digital characters, and authorised real-person assets.

## Gaps

- No published latency or queue-time figure.
- The page never says how many extension rounds are allowed, only that extension exists and that the
  output ratio is preserved.
- No statement of what the 1080p 10-bit pipeline does to SDR/HDR signalling; "HDR content" is named as
  a use case only.

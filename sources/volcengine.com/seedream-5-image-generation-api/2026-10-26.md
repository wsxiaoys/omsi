# Volcengine Ark: Image generation API (`/api/v3/images/generations`)

- Origin: Volcengine 火山方舟 documentation, "图片生成 API" (Image generation API),
  <https://docs.volcengine.com/docs/82379/1541523?lang=zh>
- Evidence kind: official documentation (first-party API reference)
- Publication date: none stated on the page. Capture date 2026-10-26.
- Relevant models: Doubao Seedream 5.0 pro / 5.0 flash / 5.0 lite / 4.5 / 4.0. This record
  extracts only what the page says about **pro** (and about pro-vs-others parameter support, which
  is needed to state Pro's limits).
- Capture type: Chinese text quoted verbatim with my translation in brackets; parameter lists
  transcribed.

## Scope statement (verbatim)

> 本文介绍 Doubao Seedream 5.0 pro、Doubao Seedream 5.0 flash、Doubao Seedream 5.0 lite、Doubao
> Seedream 4.5 及 Doubao Seedream 4.0 图片生成模型的调用 API
>
> [This page documents the image-generation API for the Doubao Seedream 5.0 pro, 5.0 flash, 5.0
> lite, 4.5 and 4.0 models.]

Endpoint: `POST https://ark.cn-beijing.volces.com/api/v3/images/generations`, API-key auth.

## Pro's capability envelope on Ark (verbatim)

> Seedream 5.0 pro new、Seedream 5.0 flash new
> 图层拆分：支持将单张图片拆解为底图（1 张）+ 多个图层输出（最多 16 个图层）。
> 交互编辑：支持通过坐标、框选、箭头等多种方式指定编辑位置，精准编辑图片。
> 生成单图（不支持配置 sequential_image_generation）
> 多图生图：输入多张参考图片（2-10）+ 文本提示词，生成单张图片。
> 单图生图：输入单张参考图片 + 文本提示词，生成单张图片。
> 文生图：输入文本提示词，生成单张图片。
> 暂不支持组图生成、联网搜索、流式输出。

> [Layer decomposition: supports splitting a single image into one base image + multiple output
> layers (up to 16 layers). Interactive editing: supports specifying the edit location by
> coordinates, box selection, arrows and other means, for precise editing. Single-image generation
> (configuring `sequential_image_generation` is not supported). Multi-image image-to-image: 2–10
> reference images + a text prompt → one image. Single-image image-to-image. Text-to-image. Group
> generation, web search and streaming output are not currently supported.]

That last sentence is the cleanest first-party statement of Pro's functional limits: **no group
generation, no web search, no streaming.**

## Parameter support, by model (from the per-parameter "模型支持" notes)

| Parameter | Pro | Flash | Lite / 4.5 / 4.0 |
| --- | --- | --- | --- |
| `layer_decomposition` (max 16 layers) | yes | yes | no |
| `background: transparent` | yes | yes | not listed |
| `optimize_prompt_options.mode: fast` | **yes** | no | no |
| `sequential_image_generation` (group output) | no | no | yes |
| `sequential_image_generation_options.max_images` | no | no | yes (1–15) |
| `stream` (streaming) | no | no | yes |
| `tools` / `web_search` | no | no | yes (lite) |
| `output_format` png/jpeg | yes | yes | yes |

`optimize_prompt_options.mode` is documented as: `standard` (default) "生成内容的质量更高，耗时较长"
[higher-quality content, longer]; `fast` "生成内容的耗时更短，效果略低于标准模式；Seedream 5.0 flash /
lite / 4.5 当前不支持" [shorter, slightly lower quality; currently unsupported by flash / lite / 4.5].

## Resolution (`size`), pro and flash image generation (verbatim)

> 方式 1（推荐）：指定分辨率档位，并在 prompt 中用自然语言描述图片宽高比、图片形状或图片用途，最终由模型判断生成图片的大小。
> 默认值：2K。可选值：1K、1.5K、2K
> 价格说明：1.5K 与 1K 价格相同（详情参见 模型价格），且图片生成效果更优。
> 方式 2：指定宽高像素值（宽x高）
> 总像素取值范围：[1280x720（921600）, 2048x2048x1.1025（4624220）]
> 宽高比取值范围：[1/16, 16]

> [Method 1 (recommended): pick a resolution tier and describe the aspect ratio, shape or purpose in
> natural language; the model decides the final size. Default 2K; valid 1K, 1.5K, 2K. 1.5K is
> priced the same as 1K and gives better quality. Method 2: specify width×height in pixels. Total
> pixel range [921,600, 4,624,220]; aspect ratio range [1/16, 16].]

Reference width/height values the page gives for the tiers (common ratios only):

| Tier | 1:1 | 4:3 | 3:4 | 16:9 | 9:16 | 3:2 | 2:3 | 21:9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 1K | 1024×1024 | 1152×864 | 864×1152 | 1280×720 | 720×1280 | 1248×832 | 832×1248 | 1512×648 |
| 2K | 2048×2048 | 2304×1728 | 1728×2304 | 2848×1600 | 1600×2848 | 2496×1664 | 1664×2496 | 3136×1344 |

Several of these match the pixel dimensions of showcase images on ByteDance's own product page
exactly (3136×1344, 2848×1600, 2496×1664), which is consistent with those gallery images being
native 2K outputs. Two others (2469×1664, 2720×1440) match nothing in this table, so the gallery
also contains non-standard or resized images.

## Input-image limits

- Image-generation scenario, pro/flash: **up to 10 reference images** ("Seedream 5.0 pro / Seedream
  5.0 flash 最多支持传入 10 张参考图"). Lite / 4.5 / 4.0 allow **14**.
- Per image: jpeg/png/webp/bmp/tiff/gif/heic/heif, aspect ratio [1/16, 16], both dimensions > 14 px,
  ≤ 30 MB, total pixels [196, 6000×6000 (36 MP)].
- Layer-decomposition scenario: **exactly one** input image (`image` is required, passing more than
  one errors), png/jpeg only, ≤ 30 MB, total pixels [512×512 (262 144), 36 MP].

## Layer-decomposition behaviour and failure modes (verbatim)

> 任一图层生成失败，整体请求报错，不支持部分成功。
> 若提示词要求的拆分数量超过上限，可能导致部分图层信息丢失。
> 响应结构体 data 中，将返回每个产出图层的位置和内容信息，包括图层顺序（z_index）、边界框信息（bounding_box）、名称（name）和描述（description）。

> [If any layer fails to generate, the whole request errors; partial success is not supported. If
> the prompt asks for more layers than the limit, some layer information may be lost. The response
> returns each layer's position and content info: z_index, bounding_box, name, description.]

## Prompt-language support (verbatim)

> 提示词语言支持：所有模型均支持中英文提示词；
> Seedream 5.0 pro / Seedream 5.0 flash 额外支持俄语、阿拉伯语、菲律宾语、泰语、土耳其语、韩语、马来语、西班牙语、葡萄牙语、印尼语、法语、德语、越南语、日语。
> 提示词字数建议：中文提示词不超过 300 字，英文提示词不超过 600 词。

> [All models support Chinese and English prompts. Seedream 5.0 pro / flash additionally support
> Russian, Arabic, Filipino, Thai, Turkish, Korean, Malay, Spanish, Portuguese, Indonesian, French,
> German, Vietnamese, Japanese. Suggested prompt length: ≤300 Chinese characters, ≤600 English
> words.]

That is **14 additional languages beyond Chinese and English** — a different count from the
developer's "over ten" and from fal's "14 languages total". See the model page.

## Other documented behaviour

- `response_format: url` links expire after 24 hours ("该链接将在生成后 24 小时内失效").
- `watermark` default `true` on Ark; `true` adds an "AI 生成" mark in the bottom-right corner.
- `background: transparent` is image-to-image only, requires exactly one input image with an alpha
  channel, and errors if `output_format` is `jpeg`.
- `usage.output_tokens` is `sum(width × height) / 256`, rounded; `usage.input_images` is pro/flash
  only.
- The model-list page gives a maximum of 500 IPM for pro (see
  [model list](../seedream-5-pro-model-list/2026-10-26.md)); this API page does not restate a rate
  limit.

## Known gaps

- The page documents the China endpoint only. The BytePlus (international) API is documented
  separately.
- No latency, throughput-per-second, or quality metric appears anywhere on the page.
- The `size` Method-1 mapping table is described as "不限于以下标准值，仅列常见" [not limited to these
  standard values; only common ones listed], so the exact pixel size for an arbitrary prompt
  instruction is not predictable from the docs.
- Nothing on the page describes *how* the model resolves spatial annotations (coordinate syntax is
  on a separate editing-guide page that was not captured).

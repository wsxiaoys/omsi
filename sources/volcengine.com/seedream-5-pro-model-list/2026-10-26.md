  <https://www.volcengine.com/docs/ark/model-list?lang=zh>
- Evidence kind: official documentation (ByteDance's own cloud console docs; Volcengine Ark is the
  China-region first-party API for these models)
- Publication date: none stated on the page. Capture date 2026-10-26.
- Relevant models: `doubao-seedream-5-0-pro-260628`, `doubao-seedream-5-0-flash-260915`,
  `doubao-seedream-5-0-260128` (= `doubao-seedream-5-0-lite-260128`), plus the 4.5 / 4.0 rows for

## Image-generation table (verbatim cells)

Header row: `模型 ID (Model ID)` · `能力支持` [capability support] · `限流 非刚性保障，受平台负载/调用方式影响，详见 文档 最大 IPM 张 / 分钟` [rate limit, not a hard guarantee, max images per minute]

| Model ID | Capability support | Max IPM |
| --- | --- | --- |
| `doubao-seedream-5-0-pro-260628` | 图层拆分 / 单图生成 / 文生图 / 单张图生图 / 多参考图生图 | 500 |
| `doubao-seedream-5-0-flash-260915` | 图层拆分 / 单图生成 / 文生图 / 单张图生图 / 多参考图生图 | 500 |
| `doubao-seedream-5-0-260128`（同时支持：`doubao-seedream-5-0-lite-260128`）**即将下线** | 单图生成 / 文生图 / 单张图生图 / 多参考图生图 / 组图生成 / 文生组图 / 单张图生组图 / 多参考图生组图 | 500 |
| `doubao-seedream-4-5-251128` **即将下线** | same as the lite row | 500 |
| `doubao-seedream-4-0-250828` **即将下线** | same as the lite row | 500 |

"即将下线" = "to be taken offline". Capability labels translate as: 图层拆分 = layer
decomposition; 单图生成 = single-image generation; 文生图 = text-to-image; 单张图生图 = single-image
image-to-image; 多参考图生图 = multi-reference image-to-image; 组图生成 / 文生组图 / 单张图生组图 /
多参考图生组图 = group-image generation and its text-to-group / single-to-group / multi-to-group
variants.

## What this establishes

- **There is no plain "Seedream 5.0" model on the first-party API.** The 5.0 generation has three
  tiers, each with its own model ID: `pro` (260628), `flash` (260915), and `lite` (260128).
- **`doubao-seedream-5-0-lite-260128` is an alias of `doubao-seedream-5-0-260128`,** not of Pro.
  The parenthetical in the Pro column is on the lite row only. Lite is therefore a separate,
  earlier model (2026-01-28 snapshot) that Ark now marks for retirement, while Pro (2026-06-28
  snapshot) is the current flagship.
- **Pro and Flash support layer decomposition; Lite, 4.5 and 4.0 do not.** Conversely, group-image
  generation is a Lite/4.5/4.0 capability and is absent from the Pro and Flash rows.
- The 5.0 tier set on Ark does not match fal's catalogue, which also carries a Flash tier but whose
  landing page still says "Seedream 5.0 ships in two tiers" — see the fal records.
- "推荐模型" [recommended models] at the top of the page lists "Doubao Seedream 5.0 pro" as
  "最新图像创作模型" [the newest image-creation model].

## Known gaps

- The table gives capability *labels*, not limits: no resolution ranges, no reference-image counts,
  no latency. Those are on the separate image-generation API page.
- "即将下线" carries no retirement date on this page.
- The model-ID suffix convention (`YYMMDD`) is not documented here. It looks like a snapshot date,
  but the page does not say whether it is a training cut-off, a publish date, or both.

Reading the Pro row: output price depends on scenario and on **261 万像素 = 2.61 megapixels**.
Single-image generation is **CNY 0.30** at or below 2.61 MP and **CNY 0.60** above it; layer
decomposition is **CNY 0.15** and **CNY 0.30** at the same threshold. Input images cost CNY 0.02
each after the first.

Billing notes, verbatim (with translation):

> [For the Seedream 5.0 lite / 4.5 / 4.0 group-image scenario, billing is by the number of images

## What this establishes

- Pro is priced **1.4× Lite at the base tier and 2.7× Lite above 2.61 MP** (CNY 0.30 / 0.60 vs
  Lite's flat 0.22), and **2.5× / 5× Flash** (0.30 / 0.60 vs Flash's flat 0.12).
- The 2.61 MP threshold sits between the 1K and 2K resolution tiers documented on the API page:
  1K outputs (e.g. 1280×720 = 0.92 MP, 1024×1024 = 1.05 MP) fall below it, while 2K outputs
  (2048×2048 = 4.19 MP, 2848×1600 = 4.56 MP) fall above it. So in practice "1K price" and "2K
  price" is the real two-step schedule, and the 1.5K tier is billed at the 1K rate — the API page
  says so explicitly.
- Layer decomposition is billed per layer, not per request, and is the cheaper scenario per layer.

## Known gaps

- **China region only.** This page is `ark.cn-beijing`. BytePlus (international) prices were not
  captured; no USD first-party figure exists in this record. Host prices in USD (fal, Replicate) are
  recorded separately and are not comparable line-for-line.
- The price rows use the unsuffixed model names (`doubao-seedream-5-0-pro`), so the page does not
  say whether a future snapshot would be repriced.
- No free-tier / quota statement was captured; the "首张免费" line is a per-request input-image
  waiver, not a free trial.
- The page does not define which dimension "261 万像素" measures for multi-image requests (per output
  image, presumably) — inferred, not stated.

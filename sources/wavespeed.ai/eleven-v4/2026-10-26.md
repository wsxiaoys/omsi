## Captured content

### Endpoint identity

- `POST https://api.wavespeed.ai/api/v3/elevenlabs/eleven-v4`
- `POST https://api.wavespeed.ai/api/v3/elevenlabs/eleven-v4-turbo`

Both appear in WaveSpeed's ElevenLabs provider listing alongside `eleven-v3`, `turbo-v2.5`,
`multilingual-v2`, `flash-v2.5`, `music-v2.5`, `sound-effects-v2`, `scribe-v2`, `dubbing`,
`audio-isolation`, `voice-changer` and `forced-alignment`.

### Parameters (verbatim table, Eleven V4)

| Parameter | Required | Description |
| --- | --- | --- |
| `text` | Yes | "Text to convert into speech. Supports 1–10000 characters. Inline audio tags can be included to guide delivery." |
| `voice_id` | Yes | "Suggested voice name or custom voice ID (voice list). Default: Alicia." |
| `stability` | No | "Controls delivery consistency. Range: 0–1. Default: 0.5." |
| `similarity` | No | "Controls similarity to the selected voice. Range: 0–1. Default: 0.75." |

Note the field name: WaveSpeed calls it `similarity`, fal and ElevenLabs call it `similarity_boost`.

### Notes (verbatim)

> * `text` supports 1–10000 characters.
> * Spaces, punctuation, and audio tags count toward pricing.
> * Requests are billed proportionally by character count.
> * Voice availability depends on access to the selected voice.
> * Audio tags guide delivery but do not guarantee an exact performance.
> * SSML, separate style controls, and speed controls are not exposed by this endpoint.
> * The endpoint returns an audio file rather than a live audio stream.

Page boilerplate also warns: "This website uses AI models provided by third parties. Documentation
prices are for reference and may be outdated. The Generate button shows an estimate; the final task
charge prevails."

Output is described as "MP3 output — Receive the generated speech as a downloadable audio file"; no
other format is offered.

## What this establishes

- A **second independent host** serves both v4 variants at the vendor's exact list price ($0.08 /
  $0.04 per 1,000 characters), prorated per character rather than rounded to a 1,000-character block.
  Two independent hosts agreeing with the vendor's own price is strong evidence the rate is a real
  list price, not a single reseller's markup.
- WaveSpeed accepts the vendor's full **10,000-character** range, where fal caps at 5,000 — the same
  model, two different host limits. WaveSpeed also accepts a `voice_id` (preset name or custom voice
  ID), where fal exposes preset names only.
- WaveSpeed's surface is narrower than fal's on output formats (MP3 only, no PCM/Opus/μ-law, no
  timestamps, no seed, no `language_code`, no text-normalization switch) and it is asynchronous
  (submit a prediction, poll for the result) rather than a synchronous `fal.run` call.

## Gaps

- No publication date, model version, or upstream ElevenLabs checkpoint is stated.
- No watermark statement.
- No statement of whose ElevenLabs workspace/credentials proxy the calls, or whether a caller's own
  cloned voice IDs work.
- `voice_id` is marked required while the README also says a default of "Alicia" applies — the page
  contradicts itself on whether the field is optional.
- The site's own disclaimer says documentation prices "may be outdated"; the price table is presented
  as reference, not as a contract.

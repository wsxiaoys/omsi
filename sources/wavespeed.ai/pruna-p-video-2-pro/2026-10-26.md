## Price formula (verbatim, text-to-video)

```
{ "total_price": (base_price * 4 / 7) * $min([15, ($exists(duration) ? duration : 5)]) *
  (resolution = "480p" ? (mode = "cost" ? 0.5 : mode = "quality" ? 2 : 1)
                       : (mode = "cost" ? 1.25 : mode = "quality" ? 3.75 : 1.75)) }
```

With `base_price = 35000` (i.e. $0.035/s) this reproduces Pruna's published list price exactly at
every 480p/768p × cost/speed/quality cell: $0.01, $0.02, $0.04, $0.025, $0.035, $0.075 per second.
The same formula is attached to the image-to-video endpoint. There is **no** 1080p/2k/4k term.

## Request schema, text-to-video (verbatim field descriptions)

- `prompt` (required), `aspect_ratio` enum `["16:9","9:16","4:3","3:4","3:2","2:3","1:1"]` default
  `"16:9"`
- `duration` integer, min 5, max 15, default 5
- `resolution` enum `["480p","768p"]`, default `"768p"`
- `mode` enum `["speed","quality","cost"]`, default `"speed"` — "cost for lower-cost generation with
  the same output quality as speed, speed for faster generation, or quality for higher-quality
  generation"
- `prompt_upsampler` enum `["off","turbo","max"]`, default `"turbo"` — "does not change the price"
- `seed` integer

Image-to-video adds `image` (required, "First-frame reference image … determines the output canvas")
and `last_image` ("Optional last-frame reference image").

## Summary

An independent host record that corroborates Pruna's price schedule arithmetic exactly, corroborates
the 5–15 s / 480p–768p / three-mode / three-upsampler envelope, and dates the host's own endpoint
creation. It is narrower than the vendor: no 1080p/2k/4k tiers, no `enable_safety_filter`, and the
reference-to-video and avatar products are separate endpoints. Its `created_at` of 2026-09-14 for
image-to-video is the earliest dated evidence found anywhere that P-Video-2-Pro existed.

## Gaps

- `created_at` is when WaveSpeed added the endpoint, not the model's release date; the gap between
  the two is unknown.
- The page does not say whose weights or whose pipeline serve the request (proxy or re-host).
- No output frame rate, container, or audio specification is stated.

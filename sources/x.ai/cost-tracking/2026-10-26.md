# xAI docs: Cost Tracking (`cost_in_usd_ticks`)

- Origin: xAI developer documentation, "Cost Tracking",
  <https://docs.x.ai/developers/cost-tracking> (`.md` capture)
- Evidence kind: official documentation (billing mechanics)
- Publication date: none stated; live page
- Capture date: 2026-10-26
- Relevant models: every xAI inference model, explicitly including video generation; used on the
  Grok Imagine Video 1.5 page to convert a logged `cost_in_usd_ticks` value into dollars

## Tick definition (verbatim)

> Every inference response from the xAI API includes the exact cost you were charged for that
> request, returned via a `cost_in_usd_ticks` field in the `usage` object of chat completions,
> Responses API, image generation, and video generation responses.

> The cost is expressed in **ticks**, where 1 USD = 10,000,000,000 ticks (10^10). To convert to
> dollars:
>
> ```text
> cost_usd = cost_in_usd_ticks / 10,000,000,000
> ```

> For example, a response with `"cost_in_usd_ticks": 37756000` cost $0.0038. An image generation
> with `"cost_in_usd_ticks": 400000000` cost $0.04.

> This is the actual amount billed, after all applicable discounts […] have been applied.

## Worked example from this page's own capture set

A Replicate prediction log recorded by xAI's own organisation account on 2026-06-01 shows a
completed 5-second, 720p `grok-imagine-video-1.5` generation whose xAI response carried
`"usage": {"cost_in_usd_ticks": 7100000000}`
([Replicate](../../replicate.com/grok-imagine-video-1.5/2026-10-26.md)). Applying the documented
conversion:

- 7,100,000,000 ticks ÷ 10^10 = **$0.71** for a 5-second 720p clip
- $0.71 ÷ 5 s = **$0.142 per second at 720p**

## What this establishes

- The conversion factor is first-party and unambiguous, so any `cost_in_usd_ticks` value in a
  captured response can be turned into dollars without guessing.
- The observed 720p rate (~$0.14/s) matches fal's published 720p rate for the same model exactly and
  does **not** match xAI's published flat "$0.080 per second". The natural reading is that
  $0.080/s is the 480p (entry) rate and the Models page's single figure is not a flat rate — but
  xAI never states that, so this is an inference from one logged request plus a host price list.

## Gaps

- The page gives no per-model or per-resolution table; it explains the unit only.
- Only one video-generation tick value was captured, at one resolution and duration. No 480p or
  1080p tick value exists in this corpus to confirm the whole schedule.
- The example log records the *upstream xAI* cost; it does not show what the host charged.

## What this establishes

- The canonical model ID is **`grok-4.7`**, and this page is xAI's own model-card equivalent for
  it. There is **no "Aliases" line**, unlike the `grok-4.5` page, which lists `grok-4.5-latest`
  and `grok-build-latest` ([4.5 page](../grok-4-5-model-page/2026-10-26.md)). Nothing on this
  page names a dated snapshot such as `grok-4.7-<date>`.
- Input modalities are **text and image**; output is **text only**. No audio, video, or file
  modality is claimed here.
- **500,000-token** context window, matching every other Grok 4.x text page captured.
- **Reasoning is on and is configurable** across four efforts, default `high`. The page does not
  say reasoning can be disabled; the reasoning guide says it cannot
  ([reasoning](../text-reasoning/2026-10-26.md)).
- Pricing is a **two-tier prompt-length** schedule, not a single rate: $2.00 / $0.50 / $6.00 per
  1M input / cached input / output tokens below 200k prompt tokens, doubling to $4.00 / $1.00 /
  $12.00 once the prompt reaches 200k. The doubling applies to **all** tokens in the request, so
  a 200k-token prompt is materially more expensive than a 199k one.
- Rate limits: **150 rps** and **50M tokens/minute** — tied with `grok-4.6` and `grok-4.5`.
- Batch API is supported with a **20% discount**, but only in `us-east-1` and `us-west-2`, while
  interactive traffic is served from three regions including `us-central-1`.

## What this establishes

- **Three separate first-party image model IDs**, each with its own price and rate limit:
  `grok-imagine-image` ($0.02), `grok-imagine-image-quality` ($0.05),
  `grok-imagine-image-2.0` ($0.04).
- `grok-imagine-image` accepts **text and image input** and returns images, i.e. the same slug
  serves both generation and editing rather than a separate edit model.
- The only dated identifier on the base page is the alias `grok-imagine-image-2026-03-02`. No
  launch date is stated.
- The base model page lists **no `-latest` alias**, unlike `grok-imagine-image-quality`. Per the
  alias convention documented on the Models page, `<modelname>` is aliased to the latest stable
  version and `<modelname>-<date>` pins a release, so `grok-imagine-image` currently resolves to
  the `2026-03-02` snapshot.
- Region coverage differs: the base model adds `us-saltlake-2`; the other two do not list it.
- Batch API support differs across the three tiers (base yes, quality no, 2.0 yes).

# xAI docs: Imagine image generation

- Origin: xAI developer documentation, "Image Generation",
  <https://docs.x.ai/developers/model-capabilities/images/generation> (`.md` capture)
- Evidence kind: official documentation (API guide)
- Publication date: none stated; live page
- Capture date: 2026-10-26
- Relevant models: `grok-imagine-image`, `grok-imagine-image-quality`, `grok-imagine-image-2.0`

## Endpoint and defaults (verbatim)

> Generate images from text prompts with Grok Imagine models. The API supports batch generation of
> multiple images, and control over aspect ratio, resolution, and quality.

Endpoint in every example: `POST https://api.x.ai/v1/images/generations`. The guide's examples all
use `"model": "grok-imagine-image-2.0"`; `grok-imagine-image` is not used in any example on this
page.

> Images are returned as URLs by default. URLs are temporary, so download or process promptly. You
> can also request [base64 output](#base64-output) for embedding images directly.

## `n` — multiple images (verbatim)

> Generate multiple images in a single request with the `n` parameter (`1`–`10`). On the REST API
> and OpenAI-compatible SDKs, `n` is optional and defaults to `1`.

## `aspect_ratio` (verbatim table)

> | Ratio | Use case |
> |-------|----------|
> | `1:1` | Social media, thumbnails |
> | `16:9` / `9:16` | Widescreen, mobile, stories |
> | `4:3` / `3:4` | Presentations, portraits |
> | `3:2` / `2:3` | Photography |
> | `2:1` / `1:2` | Banners, headers |
> | `19.5:9` / `9:19.5` | Modern smartphone displays (iPhone) |
> | `20:9` / `9:20` | Modern smartphone displays (Android) |
> | `21:9` | Cinematic widescreen |
> | `5:2` | Wide banners |
> | `auto` | Model auto-selects the best ratio for the prompt |

> When omitted, the default is `auto`, which lets the model pick the best ratio for the prompt.

## `resolution` (verbatim)

> You can specify different resolutions of the output image with the `resolution` parameter.
> Currently supported image resolutions are:
>
> * `1k` (default when omitted)
> * `2k`

## `quality` (verbatim)

> Control generation quality with the optional `quality` parameter. Allowed values are `low`,
> `medium`, and `auto`. When omitted, the default is `auto`, which lets the service choose the
> quality for each request. Auto currently uses `low` for image generation and `medium` for image
> editing. Images are billed at the quality they are served at (see Pricing). Pass `low` or
> `medium` to pin a specific quality. **The parameter is only supported for
> `grok-imagine-image-2.0`.**

## `response_format`, deferred generation, moderation (verbatim, abridged)

> Control the output format with the `response_format` parameter. When omitted, the default is
> `url`, which returns temporary hosted URLs.

> Image generation normally completes within the request. For long-running batches, or to avoid
> holding a connection open, set `deferred: true` on `/v1/images/generations` or
> `/v1/images/edits`. The request returns a `request_id` immediately; poll
> `GET /v1/images/{request_id}` for the result. […] Results are stored alongside deferred chat
> completions and retained for 24 hours.

> **Moderation** — Check whether the generated image passed content moderation:
> `if response.respect_moderation:`

## What this establishes

- Resolution is capped at **2K** on this guide; there is no 4K tier.
- Aspect ratios reach 21:9 and 5:2 (the guide notes elsewhere that these two were added in the
  August 2026 release; see `sources/x.ai/release-notes/2026-10-26.md`).
- `n` up to **10** per request on the xAI API.
- `quality` is explicitly a **2.0-only** parameter, so the base `grok-imagine-image` tier has no
  quality knob: its cost is flat per image.
- Output URLs are temporary; `b64_json` or the Files API is required for retention.

## Gaps

- The guide does not state per-model resolution or aspect-ratio support, so it is not explicit
  whether `grok-imagine-image` (1.0) accepts all 16 aspect ratios, or whether 1.5K applies to it.
- No latency figures, no quality comparison between tiers, no failure or refusal rates.
- No statement about negative prompts, seeds, or reproducibility.

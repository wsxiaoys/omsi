# xAI docs: release notes (Imagine entries)

- Origin: xAI developer documentation, "Release Notes",
  <https://docs.x.ai/developers/release-notes> (`.md` capture)
- Evidence kind: official documentation (dated changelog entries)
- Publication date: entries are grouped by month; no day-level dates are published
- Capture date: 2026-10-26
- Relevant models: `grok-imagine-image`, `grok-imagine-image-quality`, `grok-imagine-image-2.0`,
  `grok-imagine-image-pro`, `grok-imagine-video`, `grok-imagine-video-1.5`

## January 2026 — image generation revamp (verbatim, full entry)

> ### Video Generation & Next-Gen Image Generation
>
> [Video Generation](https://docs.x.ai/developers/model-capabilities/video/generation) and a revamped
> [Image Generation](https://docs.x.ai/developers/model-capabilities/images/generation) are now available.

The notes run newest-first and this entry sits between "March" and "December 2025", so the section
heading is **January 2026**. This is the earliest first-party entry that describes the current
image-generation API. An earlier entry, "March 2025 — Image Generation Model available on API",
describes the preceding generation of image model.

## August 2026 — Imagine image API updates (verbatim)

> ### Imagine image API updates
>
> * **Auto quality.** The `quality` parameter on `grok-imagine-image-2.0` now accepts `auto`, and
>   the default when `quality` is omitted has moved from `medium` to `auto`. Auto currently uses
>   `low` for image generation and `medium` for image editing. Images are billed at the quality
>   they are served at. Pass `low` or `medium` explicitly to pin a specific quality.
> * **Five reference images.** Image editing now accepts up to 5 source images per request (was 3).
> * **New aspect ratios.** Image generation and editing accept `21:9` (cinematic widescreen) and
>   `5:2` (wide banners).

## September 2026 — quality tier retirement notice (verbatim)

> ### grok-imagine-image-quality retirement on November 2
>
> On November 2, 2026, `grok-imagine-image-quality` is retired. Requests to the slug will be served
> by `grok-imagine-image-2.0` with `quality` set to `low`, with no change to the request or response
> shape and at a lower per-image price. `grok-imagine-image` (1.0) is not affected.

## July 2026 — video model modalities (verbatim)

> ### grok-imagine-video-1.5 modalities
>
> `grok-imagine-video-1.5` now supports text-to-video, image-to-video, and reference-to-video
> (including optional preset voices), with native 1080p for T2V and I2V. Text-to-video on this
> model runs as text-to-image then image-to-video under the hood.

## What this establishes

- The current Imagine image-generation API is a **January 2026** release; xAI calls it "next-gen"
  and "revamped", which is consistent with a new model rather than a rename of the March 2025 image
  model.
- Editing reference capacity went 3 → 5 in August 2026, and 21:9 / 5:2 were added at the same time.
  Both are described as API-level changes, not as 2.0-only.
- **`grok-imagine-image` (1.0) is explicitly stated to be unaffected** by the quality-tier
  retirement, which is the clearest first-party signal that 1.0 remains a supported, distinct model
  after November 2, 2026.
- The video model's text-to-video path runs *through* an image model, so image and video are
  related but separately addressed.

## Gaps

- No day-level dates anywhere in the changelog, so "January 2026" is the finest first-party
  granularity available for the image API launch.
- The January entry does not name the model slug that shipped; the slug `grok-imagine-image` is
  only attested by the model page and by hosts.
- No entry announces `grok-imagine-image` (1.0) itself, and none announces its eventual
  replacement. Only `-quality` has a published retirement.

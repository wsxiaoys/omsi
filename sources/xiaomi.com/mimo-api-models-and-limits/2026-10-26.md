# MiMo API model catalogue, rate limits, hyperparameters

- **Origin:** three sibling docs on the Xiaomi MiMo API Open Platform plus its public model
  catalogue endpoint:
  1. "Models", <https://mimo.mi.com/static/docs/quick-start/summary/model.md>
  2. "Rate Limit", <https://mimo.mi.com/static/docs/api/guidance/rate-limit.md>
  3. "Model Hyperparameters", <https://mimo.mi.com/static/docs/api/guidance/model-hyperparameters.md>
  4. `GET https://platform.xiaomimimo.com/api/v1/models` (the platform's own OpenAI-compatible
     catalogue JSON).
  All retrieved 2026-10-26.
- **Evidence kind:** official documentation (first-party API reference and catalogue metadata).
- **Publication date:** none stated on any of the three docs pages.
- **Capture date:** 2026-10-26
- **Relevant models:** `mimo-v2.6-pro`, `mimo-v2.6-flash`, `mimo-v2.6-pro-ultraspeed`;
  `mimo-v2.5-asr` and `mimo-v2.5-tts*` appear only in the surrounding tables.
- **Capture type:** full raw Markdown of docs 1–3; catalogue JSON summarised (full field set
  quoted below), not saved as an artifact.

## Capability matrix, verbatim (doc 1)

> "`mimo-v2.6-pro` / `mimo-v2.6-flash`: **Full-modal Understanding**, Text Generation, Deep
> Thinking, Streaming Output, Function Call, Structured Output, Web Search"

> "Context Window: 1M / Maximum Output: 128K / Maximum RPM: 100 / Maximum TPM: 10M"

The UltraSpeed row shares "Context Window: 1M / Maximum Output: 128K" but its rate limit is
"Customized services available, please contact us" (doc 2 says "Reserved quota").

Quick selection guide, verbatim: `mimo-v2.6-pro` for "Complex projects, long-term tasks,
high-value work, cybersecurity and scientific research requirements"; `mimo-v2.6-flash` for
"Frequent Calls and Large-Scale Tasks in Professional Office Scenarios"; and
`mimo-v2.6-pro-ultraspeed` for "Production scenarios with strong real-time interaction and
sensitivity to response speed".

## Hyperparameter constraint, verbatim (doc 3)

> "In thinking mode, the `mimo-v2.6-flash`, `mimo-v2.6-pro`, `mimo-v2.6-pro-ultraspeed` models do
> not support customizing the `temperature` and `top_p` parameters. Even if these parameters are
> passed in, the actual effective values will be forcibly set by the model to its recommended
> default values of `1.0` and `0.95`."

Defaults and ranges outside thinking mode: temperature default 1.0, range [0, 1.5]; top_p default
0.95, range [0.01, 1.0] — identical for all three V2.6 models.

`created` 1790006400 is 2026-09-21T16:00:00Z — 2026-09-22 00:00 Beijing time.

Catalogue descriptions, verbatim: Pro is "the flagship foundation model developed by Xiaomi.
Built at a scale of over 1T parameters … The model features a 1M-token context window and native
multimodal capabilities. Optimized for agentic workflows". Flash is "an open-source foundation
model … Mixture-of-Experts architecture with 309B total parameters and 15B activated per token".
UltraSpeed is "the fast speed edition … Built from the same 1T MiMo-V2.6-Pro checkpoint, it
matches the original model in quality while delivering roughly 10x the output speed."

**Conflict to preserve:** the launch post says UltraSpeed delivers "up to 20x" the output speed;
the platform's own catalogue says "roughly 10x"; OpenRouter repeats "roughly 10x". Two vendor
surfaces, two multipliers.

**Moderation flag:** Xiaomi's own catalogue marks both models `is_moderated: true`, while
OpenRouter's catalogue record for the same models reports `is_moderated: false`. The vendor's
own API therefore describes the models as moderated; the host's metadata does not.

## Gaps

- No knowledge cutoff, no per-model deprecation date, no batch-API limits, no Token Plan quota
  mapping to models.
- `max_output_length` 131072 (128K) is the platform figure; OpenRouter's top-provider value for
  Pro is also 131,072 but some hosts advertise up to 945,000 completion tokens, which is a host
  configuration rather than a model limit.
- The catalogue JSON is generated by the platform and carries no version or `last-modified`
  field, so it cannot be dated beyond the capture.

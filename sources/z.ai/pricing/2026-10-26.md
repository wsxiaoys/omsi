## Summary

First-party billing basis: per token, with a cached-input rate at ~18.6% of input
($0.26 against $1.40, i.e. an **81.4% cache discount** — the same figure Artificial Analysis
prints as "Cache Discount 81%"), free cache storage for a limited time, and web search billed
per call at $0.01.

## Gaps

- No batch/off-peak discount rate for the API itself; the 50% off-peak discount documented for
  GLM Coding Plan points is a subscription quota, not a token price
  ([GLM-5.3 docs](../glm-5-3-docs/2026-10-26.md)).
- No context-length tiering, no regional pricing, no per-request fees, no rate limits.
- No statement of when "Limited-time Free" cache storage ends.
- Subscription plan prices (GLM Coding Plan) are not on this page; only the per-token API
  rates are.
